## 3.总结分析

录音中老师主要梳理了前几章的答题思路以及第三至第六章的考试重点：

### 建模与灵敏度分析

求解利润最大化问题时，需先建立模型并使用单纯形法求解出终表（中间表）。基于终表可以进行灵敏度分析，例如判断借用新设备是否合算（比较影子价格与租金），以及生产新产品是否能增加利润（判断其检验数是否大于零）。

### 第三章（对偶理论）

重点考察对偶性质，如弱对偶性、互补松弛定理，以及原问题无界时对偶问题无可行解等性质。题型可能涉及选择题、判断题和证明题（推荐使用反证法）。

### 第四章（运输问题）

重点考察“产销不平衡”的转换问题。当销大于产时，需增加虚拟产地（运费/单位成本设为0）；当产大于销时，需增加虚拟销地。

### 第五章（目标规划/指派问题）

主要考察基础的建模板与求解过程。

### 第六章（整数规划）

重点是建模，特别是如何引入 0-1 变量来处理逻辑约束条件（如“互斥约束”、“条件约束”等）。此外，也提到了割平面法的基本步骤和方程处理方法。

### 核心关键词提取（按热度降序）

#### 🔥 高热度关键词（考试核心与难点）

* 
**灵敏度分析**：文本中多次强调，是结合终表进行综合考察的重点 。


* 
**对偶问题 / 对偶性质**：第三章的重点，涉及定理证明及与原问题的关系 。


* 
**互补松弛性**：被老师多次提及并要求重点复习证明及应用的性质 。


* 
**最优解 / 无界解 / 无可行解**：在对偶定理和解的判断中高频出现的解的状态 。


* 
**产销不平衡**：运输问题中的考察重点，需要掌握如何转化为产销平衡 。


* 
**建模**：贯穿目标规划等多章的基础要求，尤其强调绝对约束和偏差变量的构建 。


* 
**终表**：求解盈利最大化或进行后续分析的基石 。



#### 核心热度关键词（重要知识点与方法）

* 
**影子价格**：结合资源增加或减少进行决策分析的关键指标 。


* 
**原问题**：与对偶问题相对应的基础模型 。


* 
**指派问题**：第六章整数规划的重点，强调了具体的打分步骤和调整过程 。


* 
**目标规划**：第五章核心，涉及极小值偏差变量及决策变量非负的细节 。


* 
**割平面解法**：整数规划中涉及中表操作的求解方法 。



#### 基础热度关键词（概念与细节）

* 
**单纯形法**：求解建模问题得到终表的基础方法 。


* 
**对偶定理 / 弱对偶性**：对偶理论中的具体定理名称 。


* 
**松弛变量 / 偏差变量**：在互补松弛性和目标规划中需要翻译和处理的变量 。


* 
**虚拟化工厂 / 虚拟销地**：处理产销不平衡时所需的假设技巧 。
