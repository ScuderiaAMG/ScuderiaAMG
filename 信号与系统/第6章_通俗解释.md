# 第6章 信号的矢量空间分析 — 通俗解释

---

## 6.1 信号矢量空间的基本概念

**核心思想：把信号当成"向量"来分析。**

我们在高中都学过平面向量：两个向量可以加在一起，向量可以乘以一个数（拉伸或缩短）。现在，把这个想法搬到信号世界——**把一个信号看成一个向量**。

### 线性空间

就是一个"封闭的集合"。什么意思？集合里任意两个信号加起来还在这个集合里，任意一个信号放大或缩小几倍也还在这个集合里。这就是线性空间。

> 比如所有周期信号放在一起，就是一个线性空间——两个周期信号叠加依然是周期信号。

### 范数——信号有多"大"

范数就是给信号量一个"大小"的尺子。常见的有三种：

- **一阶范数**：把信号的绝对值全部加起来 → 代表信号的"总强度"
- **二阶范数**：信号的平方和再开根号 → 二阶范数的平方就是**信号的能量**（这个最重要）
- **无穷范数**：信号的最大峰值 → 信号的"最高点"是多少

### 内积——两个信号有多"像"

内积衡量两个信号之间的"相似度"。两个信号在区间上逐点相乘再积分，得到的结果：

- 如果是 **0** → 两个信号"正交"（互相垂直，完全不相关）
- 如果是**最大值** → 两个信号方向一致，完全相似

### 柯西-施瓦茨不等式

这是一个保证：**两个信号的内积绝对值，永远不会超过它们各自"长度"的乘积。** 简单说就是，两个信号的相似度被它们各自的能量所限制。

---

## 6.2 信号的正交分解

**核心思想：把任意信号拆成几个"互相无关"的简单信号之和。**

### 为什么要做正交分解？

就好比你描述一个人所在的位置，可以说"往东走 3 步再往北走 4 步"——你把一个复杂的位置拆成了"东方向"和"北方向"两个独立的成分。信号的正交分解也是这个道理：把一个复杂信号拆成若干个"正交基底信号"的加权和。

### 怎么做？

用信号 f2(t) 去近似 f1(t)，要求误差最小：

c12 = <f1, f2> / <f2, f2>

分子是 f1 和 f2 的内积，分母是 f2 自身的能量。得出的系数 c12 就是最佳的"配合比例"。

**几何直觉**：这其实就是把 f1 向 f2 方向做"投影"，投影的垂足就是最佳近似点。

### 正交函数集

一组函数，两两之间内积都是 0，就构成正交函数集。用它们来分解信号有一个好处：**各个系数之间互不影响**，可以单独算，先算哪个都行。

---

## 6.3 完备正交函数集 + 帕塞瓦尔定理

**核心思想：如果正交基底足够"全"，就可以毫无误差地表示任何信号。**

### 完备正交函数集

"完备"意味着这套基底已经够用了——不存在任何一个信号跟这套基底里的所有函数都正交（除了零信号）。也就是说，这套基底可以组合出空间里的任意信号，没有遗漏。

两个最经典的完备正交函数集：
- **三角函数集**：{1, cos t, cos 2t, ..., sin t, sin 2t, ...} → 这就是傅里叶级数的基石
- **复指数函数集**：{e^(jnΩt)} → 指数形式的傅里叶级数

### 帕塞瓦尔定理

这是一个很美的定理：**信号的能量 = 各分量能量之和。**

就好比一个蛋糕的总热量，等于每块切出来的蛋糕热量加起来。不管你从哪个角度"切"（分解），能量总量不变。这也意味着：**时域算出来的能量 = 频域算出来的能量**，两者是等价的。

### 能量信号 vs 功率信号

- **能量信号**：总能量有限，平均功率为零（比如一个单独的脉冲信号）
- **功率信号**：总能量无穷大，但平均功率有限（比如一直持续的周期信号）

## 6.6 相关函数

**核心思想：用一把"尺子"去量两个信号在不同时间偏移下的相似度。**

### 相关系数

两个信号的相关系数其实就是它们"夹角"的余弦值：
- 系数 = ±1 → 两个信号完全一样（只是一个放大缩小版）
- 系数 = 0 → 两个信号完全正交，毫不相关
- 系数越大 → 用其中一个去近似另一个，误差越小

### 自相关函数

把一个信号延迟一段时间 τ，然后跟原来的自己比一下有多像：

Rxx(τ) = ∫ x(t) x(t - τ) dt

**自相关的直观理解**：你把一个信号复制一份，平移了一点距离，叠上去看它们有多重合。如果信号是随机的，稍微挪一点就完全不像了；如果信号是周期的，每隔一个周期又会很像。

**三条重要性质**：
1. τ = 0 时自相关最大 → 信号跟自己完全重合，当然最像
2. R(0) = 信号的总能量 → 这一点非常关键
3. 自相关函数是偶函数 → 往前往后平移，相似度变化是对称的

### 互相关函数

跟自相关一样，只不过比较的是**两个不同的信号**：

Rxy(τ) = ∫ x(t) y(t - τ) dt

**应用场景**：雷达测距。发射一个信号，碰到目标弹回来（延迟了 τ0），互相关峰值出现的位置就是 τ0，距离 = 光速 × τ0 / 2。

### 相关 vs 卷积

两者就**差一个"反褶"**。卷积要把一个信号翻过来再平移相乘积分；相关不需要翻转，直接平移相乘积分。所以如果信号本身就是偶对称的，卷积和相关结果完全相同。

## 6.7 能量谱与功率谱

**核心思想：把信号的能量（或功率）在频率轴上"摊开来看"，看每个频率分量贡献了多少。**

### 能量谱密度

对于能量有限的信号（比如一个短脉冲），做傅里叶变换得到 F(ω)，那么：

能量谱密度 = |F(ω)|^2

信号的每个频率分量对总能量的贡献就是 |F(ω)|^2。总能量 = 能量谱密度在全部频率上的积分。

### 功率谱密度

对于功率有限的周期信号，取一段做傅里叶变换 F_T(ω)，然后：

功率谱密度 = lim(T→∞) |F_T(ω)|^2 / T

### 维纳-欣钦关系

这是一个非常重要的定理：**自相关函数和功率谱/能量谱是一对傅里叶变换对。**

也就是说，知道了自相关函数 —傅里叶变换→ 就能得到谱密度；反过来也一样。

**直观理解**：一个信号变化越"慢"（低频多），它的自相关函数就拖得越宽；信号变化越"乱"（高频多），自相关函数就很窄很尖锐。

### 白噪声的例子

白噪声的功率谱在所有频率上都是常数（像白光包含所有颜色一样），对应的自相关函数是一个冲激函数 δ(τ)——说明白噪声在任意两个不同时刻的取值完全不相关，一片混乱。

## 6.8 希尔伯特变换

**核心思想：把信号的所有频率分量都移相 90°，但不改变幅度。**

### 定义

希尔伯特变换本质上是把原始信号跟 h(t) = 1/(πt) 做卷积：

Ĥ(t) = f(t) * 1/(πt)

### 频率响应

H(ω) = -j · sign(ω)

- 对正频率 → 移相 -90°
- 对负频率 → 移相 +90°
- 幅度完全不衰减

所以它是一个**全通 90° 移相器**。

### 有趣的性质

- 做两次希尔伯特变换 → 信号反号：H[H[f]] = -f
- cos t 的希尔伯特变换 = sin t
- sin t 的希尔伯特变换 = -cos t
- 原信号和它的希尔伯特变换是**正交的**

### 解析信号

用希尔伯特变换可以构造一个很优雅的东西——**解析信号**：

z(t) = f(t) + j Ĥ(t)

它有什么好处？**它的频谱只在正频率上有值，负频率全部为零。** 这在通信系统分析中非常实用，因为负频率本来就是数学上的一个"冗余"，去掉之后分析更简洁。

## 6.9 匹配滤波器

**核心思想：设计一个滤波器，让信号从噪声里"冒"出来的时候最容易检测。**

### 问题背景

通信或雷达系统中，你发射了一个已知形状的信号 s(t)，收到的却是 s(t) + 噪声 n(t)。你怎么设计一个滤波器，让滤波后的输出在某个时刻信号最强、噪声最弱？

### 设计思路

目标：最大化**输出信噪比**（信号瞬时功率 ÷ 噪声平均功率）。

用柯西-施瓦茨不等式推导出来的结果非常漂亮：

h(t) = k · s(t_m - t)

**翻译成大白话**：匹配滤波器的冲激响应，就是把你要检测的信号**时间上镜像翻转**，再**延迟到** t_m 时刻。

比如你发送的信号波形从左到右是一个上升的斜坡，那滤波器就该是一个下降的斜坡。

### 匹配滤波器的美妙之处

输出信号 = 输入信号和 h(t) 做卷积 = 输入信号做**自相关**：

s_o(t) = R_ss(t - t_m)

也就是说，匹配滤波器在 t_m 时刻的输出值恰好就是输入信号的总能量 E_s，跟信号的形状无关。而噪声因为不"匹配"，经过滤波器后被大大抑制。

### 雷达测距的应用

1. 雷达发射脉冲 s(t)
2. 信号碰到目标，延迟 τ 后弹回来
3. 匹配滤波器输出是一个自相关函数，峰值出现在 τ 时刻
4. 距离 = 光速 × τ / 2

波形越"尖锐"（自相关函数峰值越窄），测距就越准。这就是为什么雷达喜欢用复杂的编码脉冲，而不是简单的方波。

## 6.11 CDMA（码分多址通信）

**核心思想：多个用户在同一频率、同一时间通信，靠"正交编码"来区分彼此。**

### 类似场景

想象一个大房间里，很多人同时在说话。如果大家说的是不同语言，你只听你懂的那种，别人的话对你来说就是背景噪音。CDMA 就是这个道理——**每个用户分配一个独特的"密码"（地址码），各用户的密码相互正交**。

### 工作原理

**发送端**：
- 用户 1 的数据 × 地址码 c1(t) × 载波 cos(ω0 t)
- 用户 2 的数据 × 地址码 c2(t) × 载波 sin(ω0 t)
- 两路混在一起发出去

**接收端**：
- 要解出用户 1 的数据 → 用 c1(t) 做相关运算
- 由于 c1 和 c2 正交，用户 2 的信号在相关运算后被"消掉"了
- 低通滤波后只剩下用户 1 的数据

### CDMA 的核心要求

地址码必须满足：
- **自相关函数在零点有尖锐的峰值**（方便同步检测）
- **互相关函数尽可能小**（互不干扰）

### 优点

- 抗干扰能力强
- 容量大且灵活
- 保密性好（不知道地址码就解不出来）
- 所有用户共享同一频段，频谱利用率高

## 全章脉络回顾

```
信号 → 当作向量（6.1）
  → 用正交基底拆解（6.2）
  → 拆解的能量守恒——帕塞瓦尔（6.3）
  → 衡量信号之间的相似度——相关（6.6）
  → 相似度傅里叶变换就是谱——维纳-欣钦（6.7）
  → 移相 90° 的工具——希尔伯特变换（6.8）
  → 用相关性从噪声中抓信号——匹配滤波器（6.9）
  → 用正交码让多用户同时通信——CDMA（6.11）
```

整章实际上是用**向量空间**这把钥匙，把信号分解、相关分析、频谱分析、滤波器设计、多用户通信串成了一条完整的逻辑链。
