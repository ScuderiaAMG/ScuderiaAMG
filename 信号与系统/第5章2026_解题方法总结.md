## 5.1 连续时间LTI系统的频域分析

### 方法一：正弦信号激励下求系统响应

**适用题型：** 已知 $H(j\omega)$（幅频和相频特性）和正弦输入 $f(t)$，求输出 $y(t)$。

**解题步骤：**

1. **分解输入信号** — 将 $f(t)$ 分解为若干正弦分量之和：$f(t) = \sum A_k \cos(\omega_k t + \theta_k)$

2. **逐频率计算** — 对每个频率分量 $\omega_k$：
   - 查 $H(j\omega_k)$ 的幅值 $|H(j\omega_k)|$ 和相位 $\varphi(\omega_k)$
   - 若 $\omega_k$ 在通带外（$|H(j\omega_k)| = 0$），该分量被滤除

3. **写出输出分量** — $y_k(t) = |H(j\omega_k)| \cdot A_k \cos(\omega_k t + \theta_k + \varphi(\omega_k))$

4. **叠加输出** — $y(t) = \sum y_k(t)$

**关键公式：**
$$y(t) = |H(j\omega_0)| A \cos(\omega_0 t + \theta_0 + \varphi_0)$$

**例题模板（例1）：**
> 已知 $|H(j\omega)| = \begin{cases} 1.5, & |\omega| \leq 20 \\ 0, & |\omega| > 20 \end{cases}$，$\varphi(\omega) = -60°$
> $f(t) = 2\cos(10t + 90°) + 5\cos(25t + 120°)$

解：
- $\omega = 10$（在通带内）：$y_1(t) = 1.5 \times 2 \cos(10t + 90° - 60°) = 3\cos(10t + 30°)$
- $\omega = 25$（在阻带内）：$y_2(t) = 0$
- $y(t) = 3\cos(10t + 30°)$

---

### 方法二：RC电路频域分析法

**适用题型：** 已知电路结构和参数，求系统函数 $H(j\omega)$ 及输出。

**解题步骤：**

1. **建立系统函数** — 画出频域等效电路，利用阻抗分压关系：
   $$H(j\omega) = \frac{Y(j\omega)}{F(j\omega)}$$

   对于RC低通：$H(j\omega) = \frac{1/(j\omega C)}{R + 1/(j\omega C)} = \frac{1/RC}{j\omega + 1/RC}$

2. **写出幅频和相频表达式：**
   $$|H(j\omega)| = \frac{1/RC}{\sqrt{\omega^2 + (1/RC)^2}}, \quad \varphi(\omega) = -\arctan(\omega RC)$$

3. **代入各频率计算：** 对每个 $\omega_k$ 计算 $|H(j\omega_k)|$ 和 $\varphi(\omega_k)$

4. **写出总输出：** $y(t) = \sum |H(j\omega_k)| A_k \cos(\omega_k t + \theta_k + \varphi(\omega_k))$

**例题模板（例2）：**
> RC电路，$1/RC = 1000$，$f(t) = \cos(100t) + \cos(3000t)$

解：
- $\omega = 100$: $|H(j100)| = 0.995, \varphi(100) = -5.71°$
- $\omega = 3000$: $|H(j3000)| = 0.316, \varphi(3000) = -71.6°$
- $y(t) = 0.995\cos(100t - 5.71°) + 0.316\cos(3000t - 71.6°)$

**MATLAB验证方法：** 使用 `freqs` 或 `bode` 绘制频率响应曲线，用 `lsim` 仿真时域输出。

### 方法三：周期信号激励 — 傅里叶级数法

**适用题型：** 输入为周期信号，已知 $H(j\omega)$，求稳态输出。

**解题步骤：**

1. **求输入的傅里叶级数系数** $F_n$：
   $$F_n = \frac{1}{T} \int_{-T/2}^{T/2} f(t) e^{-jn\Omega t} dt \quad \text{或直接查表}$$

2. **计算离散频率点上的系统函数：**
   $$H(jn\Omega) = \frac{1/RC}{jn\Omega + 1/RC} \quad \text{（RC电路）}$$

3. **输出频谱：** $Y_n = H(jn\Omega) \cdot F_n$

4. **时域输出：** $y(t) = \sum_{n=-\infty}^{\infty} Y_n e^{jn\Omega t}$

**例题模板（例4 — 方波通过RC）：**
> $f(t)$ 为周期方波（$T = 2$），RC电路

解：
- $F_n = 0.5\text{Sa}(\frac{n\pi}{2})$
- $Y_n = \frac{1/RC}{jn\Omega + 1/RC} \cdot 0.5\text{Sa}(\frac{n\pi}{2})$
- $y(t) = \sum_{n} Y_n e^{jn\Omega t}$

**关键技巧：** 对于含 $\text{Sa}$ 函数的频谱，可利用对称性和衰减特性只取前几项近似。

---

### 方法四：非周期信号激励 — 傅里叶变换法（频域卷积法）

**适用题型：** 输入为非周期信号（如矩形脉冲），求零状态响应。

**解题步骤（四步法）：**

$$\boxed{F(j\omega) \;\to\; Y(j\omega) = F(j\omega)H(j\omega) \;\to\; y(t) = \mathcal{F}^{-1}[Y(j\omega)]}$$

1. **求输入的傅里叶变换** $F(j\omega) = \mathcal{F}[f(t)]$
   - 利用常用变换对和性质表
   - 矩形脉冲 → $\tau\text{Sa}(\frac{\omega\tau}{2})e^{-j\omega\frac{\tau}{2}}$

2. **建立系统函数** $H(j\omega)$（由电路或微分方程得到）

3. **频域相乘：** $Y(j\omega) = F(j\omega) \cdot H(j\omega)$

4. **傅里叶反变换：** $y(t) = \mathcal{F}^{-1}[Y(j\omega)]$
   - 常用**部分分式展开法**将 $Y(j\omega)$ 分解为基本变换对之和
   - 利用 $e^{-j\omega t_0}$ 对应时域平移性质

**例题模板（例5 — RC阶跃响应）：**
> $e(t) = 2u(t) - u(t - \tau)$，RC电路

解：
1. $E(j\omega) = \frac{2}{j\omega}(1 - e^{-j\omega\tau}) = 2\tau\text{Sa}(\frac{\omega\tau}{2})e^{-j\omega\tau/2}$
2. $H(j\omega) = \frac{1/RC}{j\omega + 1/RC}$
3. $U_0(j\omega) = \frac{2}{j\omega}(1 - e^{-j\omega\tau})\cdot\frac{1/RC}{j\omega + 1/RC}$
4. 部分分式展开 + 反变换：
   $$u_0(t) = 2[1 - e^{-t/RC}]u(t) - 2[1 - e^{-(t-\tau)/RC}]u(t - \tau)$$

**关键变换对记忆：**
$$e^{-\alpha t}u(t) \leftrightarrow \frac{1}{j\omega + \alpha}$$
$$u(t) \leftrightarrow \pi\delta(\omega) + \frac{1}{j\omega}$$
$$\delta(t - t_0) \leftrightarrow e^{-j\omega t_0}$$

## 5.2 无失真传输

### 方法：无失真传输的判断与设计

**适用题型：**
- 判断系统是否无失真
- 设计无失真传输系统参数
- 分析信号经传输后的失真类型

**核心判据：**

**频域条件：** $H(j\omega) = K e^{-j\omega t_0}$，即：
$$\begin{cases} |H(j\omega)| = K \quad \text{（常数，全通）} \\ \varphi(\omega) = -\omega t_0 \quad \text{（线性相位，过原点）} \end{cases}$$

**时域条件：** $y(t) = K f(t - t_0)$

**解题步骤：**

1. **写出系统的** $H(j\omega)$ 表达式（或幅频 $|H(j\omega)|$ 和相频 $\varphi(\omega)$）

2. **检验幅度条件：** $|H(j\omega)|$ 是否为常数（与频率无关）？

3. **检验相位条件：** $\varphi(\omega)$ 是否与 $\omega$ 成正比（过原点直线）？
   - 可通过检查群延迟 $\tau_g = -\frac{d\varphi}{d\omega}$ 是否为常数辅助判断

4. **判断结论：**
   - 两条均满足 → 无失真传输
   - 幅度不恒定 → 幅度失真
   - 相位非线性 → 相位失真（不同频率延迟不同，波形改变）

**典型反例分析：**

| 条件 | $|H(j\omega)| = K$ | $\varphi(\omega) = -\omega t_0$ | 结论 |
|:---|:---:|:---:|:---|
| 理想低通 | ❌（通带外为0） | ✅（通带内线性） | 有幅度失真 |
| 常相位系统 | ✅ | ❌（常相位≠过原点） | 有相位失真 |

**验证无失真传输（例 — RLC电路）：**
> 给定 RLC 电路，求参数使 $H(j\omega) = 1$（即 $K=1, t_0=0$）

当 $R_1 = R_2 = 1$ 时，$H(j\omega) = 1$，满足无失真条件。

---

### 相位失真例题的波形辨别

**题型：** 给出三个信号，判断哪个是无失真延迟，哪个有相位失真。

$$f_1(t) = [\sin(2\pi t) + \sin(5\pi t)][u(t) - u(t-1)]$$
$$f_2(t) = [\sin(2\pi(t-1)) + \sin(5\pi(t-1))][u(t-1) - u(t-2)]$$
$$f_3(t) = [\sin(2\pi t - 2\pi) + \sin(5\pi t - 2\pi)][u(t-1) - u(t-2)]$$

**判据：**
- $f_2$ 中 $2\pi(t-1) = 2\pi t - 2\pi$ 和 $5\pi(t-1) = 5\pi t - 5\pi$ — 不同频率的延迟量**不同**（$\Delta\varphi \propto \omega$，但 $\Delta\varphi / \omega = 1$ 相同） → 这是**时移**，无失真
- $f_3$ 中两分量相位均为 $-2\pi$（常数），$\varphi / \omega$ 随频率变化 → **相位失真**

## 5.3 理想滤波器

### 方法一：求理想低通滤波器的冲激响应 $h(t)$

**解题步骤：**

1. **写出频域表达式：**
   $$H_{LP}(j\omega) = G_{2\omega_c}(\omega) \cdot e^{-j\omega t_0} = \begin{cases} e^{-j\omega t_0}, & |\omega| \leq \omega_c \\ 0, & |\omega| > \omega_c \end{cases}$$

2. **傅里叶反变换求 $h(t)$：**
   $$h(t) = \frac{1}{2\pi}\int_{-\omega_c}^{\omega_c} e^{-j\omega t_0} e^{j\omega t} d\omega = \frac{1}{2\pi}\int_{-\omega_c}^{\omega_c} e^{j\omega(t - t_0)} d\omega$$

3. **求积分：**
   $$h(t) = \frac{\omega_c}{\pi} \text{Sa}[\omega_c(t - t_0)]$$

**结论：** $h(t)$ 是 $\text{Sa}$ 函数，峰值在 $t = t_0$，非因果（$t < 0$ 时非零）。

---

### 方法二：求理想低通滤波器的阶跃响应 $r(t)$

**解题步骤：**

1. **输入输出频域：** $e(t) = u(t)$ → $E(j\omega) = \pi\delta(\omega) + \frac{1}{j\omega}$

2. **输出频谱：** $R(j\omega) = H(j\omega) \cdot E(j\omega) = \frac{1}{j\omega} e^{-j\omega t_0}$（通带内）

3. **傅里叶反变换：**
   $$r(t) = \frac{1}{2} + \frac{1}{\pi}\text{Si}[\omega_c(t - t_0)]$$

   其中 $\text{Si}(y) = \int_0^y \frac{\sin x}{x} dx$ 为正弦积分。

**关键结论 — 上升时间公式：**
$$t_r = \frac{2\pi}{\omega_c} = \frac{1}{B}, \quad B \cdot t_r = 1$$

其中 $B = f_c = \omega_c/(2\pi)$。带宽与上升时间成反比。

---

### 方法三：滤波器的频谱图解法

**适用题型：** 已知输入 $f(t)$ 和滤波器 $H(j\omega)$，求输出 $y(t)$。

**解题步骤（频谱图解法）：**

1. **求 $F(j\omega)$** — 将 $f(t)$ 的频谱画出
2. **画出 $H(j\omega)$** — 标明通带范围
3. **$Y(j\omega) = F(j\omega) \cdot H(j\omega)$** — 保留 $F(j\omega)$ 在通带内的部分
4. **识别 $Y(j\omega)$ 的形式** — 对应基本变换对写出 $y(t)$

**例题模板（例1 — 带通滤波）：**
> $f(t) = 20\cos(100t)[\cos(10^4t)]^2$，$H(j\omega) = G_{240}(\omega)$

解：
1. 三角化简：$\cos^2\alpha = \frac{1+\cos 2\alpha}{2}$
   $$f(t) = 10\cos(100t) + 5(\cos 20100t + \cos 19900t)$$

2. $F(j\omega)$ 含三个频率分量：$\pm 100$, $\pm 19900$, $\pm 20100$

3. 滤波器 $|\omega| \leq 120$ 保留：只通过 $\omega = \pm 100$

4. $Y(j\omega) = 10\pi[\delta(\omega+100) + \delta(\omega-100)]$ → $y(t) = 10\cos(100t)$

**谱线筛选法则：**
$$\boxed{\text{先在频域用滤波器截取 } F(j\omega) \text{ 的对应部分，再反变换回时域}}$$

---

### 方法四：四种理想滤波器的频率响应写作

| 滤波器类型 | $H(j\omega)$ 表达式（含相位 $e^{-j\omega t_0}$） |
|:---|:---|
| **低通 (LPF)** | $H_{LP}(j\omega) = G_{2\omega_c}(\omega) \cdot e^{-j\omega t_0}$ |
| **高通 (HPF)** | $H_{HP}(j\omega) = [1 - G_{2\omega_c}(\omega)] \cdot e^{-j\omega t_0}$ |
| **带通 (BPF)** | $H_{BP}(j\omega) = [G_{2\omega_c}(\omega+\omega_0) + G_{2\omega_c}(\omega-\omega_0)] \cdot e^{-j\omega t_0}$ |
| **带阻 (BSF)** | $H_{BS}(j\omega) = [1 - H_{BP}(j\omega)] \cdot e^{-j\omega t_0}$ |

其中 $G_{2\omega_c}(\omega)$ 是宽度为 $2\omega_c$ 的矩形门函数。截止频率满足 $|H(j\omega_c)| = 1/\sqrt{2} \approx 0.707$。

### 方法五：系统级联的频谱分析

**适用题型：** 信号通过多个滤波器+调制环节的级联系统。

**解题策略：** 逐步画出各节点频谱图，利用调制性质（频谱搬移）和滤波性质（频谱截取）。

**关键调制性质：**
$$\mathcal{F}[x(t)\cos\omega_0 t] = \frac{1}{2}\{X[j(\omega+\omega_0)] + X[j(\omega-\omega_0)]\}$$

## 5.4 调制与解调

### 方法一：幅度调制的频谱分析法

**解题步骤：**

1. **确定调制信号和载波：** $f_s(t) = f(t) \cos(\omega_0 t)$

2. **频谱搬移公式：**
   $$F_s(j\omega) = \frac{1}{2}\{F[j(\omega - \omega_0)] + F[j(\omega + \omega_0)]\}$$

3. **画频谱图：** 将 $F(j\omega)$ 分别移至 $\pm\omega_0$ 处，幅值减半

4. **滤波处理：** 用带通/低通滤波器截取所需部分

**关键变换对：**
$$\text{Sa}(\omega_c t) \leftrightarrow \frac{\pi}{\omega_c} G_{2\omega_c}(\omega)$$

**例题模板（例1 — 调制+滤波）：**
> $f(t) = \frac{1}{2}\text{Sa}(2t)$，$F(j\omega) = \frac{1}{2}G_4(\omega)$
> $f_1(t) = f(t)\cos(1000t)$

解：
$$F_1(j\omega) = \frac{1}{4}[G_4(\omega+1000) + G_4(\omega-1000)]$$

经带通 $H(j\omega) = G_2(\omega)$（中心在 $\pm 1000$）后：
$$Y(j\omega) = \frac{1}{4}[G_2(\omega+1000) + G_2(\omega-1000)]$$
$$y(t) = \frac{1}{2}\text{Sa}(t)\cos(1000t)$$

---

### 方法二：同步解调的信号恢复

**解题步骤：**

1. **乘以同步载波：**
   $$g(t) = y(t)\cos(\omega_0 t) = f(t)\cos^2(\omega_0 t) = \frac{1}{2}[f(t) + f(t)\cos(2\omega_0 t)]$$

2. **频谱分析：**
   $$G(j\omega) = \frac{1}{2}F(j\omega) + \frac{1}{4}\{F[j(\omega+2\omega_0)] + F[j(\omega-2\omega_0)]\}$$

3. **低通滤波：** 保留 $\frac{1}{2}F(j\omega)$，滤除 $2\omega_0$ 分量
   $$Y_{out}(j\omega) = \frac{1}{2}F(j\omega) \;\to\; y_{out}(t) = \frac{1}{2}f(t)$$

**二次调制解调技巧（例2）：**
> $f_1(t) = \frac{1}{2}\text{Sa}(t) \cdot \cos^2(1000t) = \frac{1}{2}[\frac{1}{2}\text{Sa}(t) + \frac{1}{2}\text{Sa}(t)\cos(2000t)]$

再经低通滤波器即可恢复 $\frac{1}{4}\text{Sa}(t)$。

## 5.5 时域均衡与小波变换基础

### 方法一：频域均衡（系统补偿）

**适用题型：** 已知系统函数 $H(s)$ 和输入信号，分析输出信号的包络变化。

**解题步骤：**

1. **将 $H(s)$ 转换为 $H(j\omega)$：** 代入 $s = j\omega$

2. **简化 $H(j\omega)$ 表达式：** 对极点/零点进行合并简化，使分母写成 $1 + j(\omega - \omega_0)$ 等形式

3. **将输入分解为频谱分量：**
   $$v_1(t) = (1 + \cos t)\cos(100t) = \cos(100t) + \frac{1}{2}\cos(101t) + \frac{1}{2}\cos(99t)$$

4. **分别计算各频率的 $H(j\omega)$：**
   - $H(j100) = 1$
   - $H(j101) = \frac{\sqrt{2}}{2}e^{-j45°}$
   - $H(j99) = \frac{\sqrt{2}}{2}e^{j45°}$

5. **合成输出并提取包络：**
   $$v_2(t) = \cos(100t) + \frac{\sqrt{2}}{2}\cos(101t - 45°) + \frac{\sqrt{2}}{2}\cos(99t + 45°)$$
   $$= \left[1 + \frac{\sqrt{2}}{2}\cos(t - 45°)\right]\cos(100t)$$

   包络为 $1 + \frac{\sqrt{2}}{2}\cos(t - 45°)$。

**关键公式（双频合成技巧）：**
$$\cos(\omega_0 t + \alpha) + \cos(\omega_0 t + \beta) = 2\cos\frac{\alpha-\beta}{2} \cdot \cos(\omega_0 t + \frac{\alpha+\beta}{2})$$

---

### 方法二：小波变换的计算

**适用题型：** 给定母小波 $w(t)$，分析尺度变换后的频谱。

**解题步骤：**

1. **求母小波频谱 $W(\omega) = \mathcal{F}[w(t)]$：**
   例如 $w(t) = \frac{1}{\pi t}\sin(\pi t)\cos(3\pi t) = \text{Sa}(\pi t)\cos(3\pi t)$
   $$W(\omega) = \frac{1}{2}[G_{2\pi}(\omega-3\pi) + G_{2\pi}(\omega+3\pi)]$$

2. **利用尺度变换性质：** $h_a(t) = \frac{1}{a}w(-\frac{t}{a})$
   $$H_a(\omega) = aW(-a\omega) = \frac{a}{2}[G_{2\pi}(-a\omega-3\pi) + G_{2\pi}(-a\omega+3\pi)]$$

3. **分析尺度效应：**
   - 中心频率：$\omega_0/a = 3\pi/a$
   - 带宽：$B/a = 2\pi/a$
   - $a > 1$ → 时域展宽、频域压缩（低频分析）
   - $a < 1$ → 时域压缩、频域展宽（高频分析）

**关键变换对：**
$$f(bt) \leftrightarrow \frac{1}{|b|}F\left(\frac{\omega}{b}\right)$$
$$\text{Sa}(\omega_c t) \leftrightarrow \frac{\pi}{\omega_c}G_{2\omega_c}(\omega)$$
$$x(t)\cos(\omega_0 t) \leftrightarrow \frac{1}{2}[X(\omega+\omega_0) + X(\omega-\omega_0)]$$

## 5.6 取样与取样定理

### 方法一：确定取样频率与奈奎斯特率

**解题步骤：**

1. **确定信号最高频率 $\omega_m$（或 $f_m$）：** 找到 $F(\omega) \neq 0$ 的 $\omega$ 范围上限

2. **奈奎斯特取样频率：** $\omega_s \geq 2\omega_m$（或 $f_s \geq 2f_m$）

3. **最大取样间隔：**
   $$T_s \leq \frac{\pi}{\omega_m} = \frac{1}{2f_m}$$

**记忆口诀：** 取样频率至少是信号最高频率的**两倍**。

---

### 方法二：理想信号重构（Sa 内插公式）

**解题步骤：**

1. **理想冲激取样：**
   $$f_s(t) = \sum_{n=-\infty}^{\infty} f(nT_s) \delta(t - nT_s)$$

2. **频域分析：**
   $$F_s(\omega) = \frac{1}{T_s}\sum_{n=-\infty}^{\infty} F(\omega - n\omega_s)$$

3. **通过理想低通重构：** 取 $\omega_c = \omega_s/2$
   $$H(\omega) = T_s G_{2\omega_c}(\omega), \quad h(t) = T_s \cdot \frac{\omega_c}{\pi}\text{Sa}(\omega_c t)$$

4. **时域重构公式（内插公式）：**
   $$f(t) = \sum_{n=-\infty}^{\infty} f(nT_s) \text{Sa}[\omega_c(t - nT_s)]$$

   取 $\omega_c = \omega_s/2 = \omega_m$，$T_s = \pi/\omega_m$：
   $$f(t) = \sum_{n=-\infty}^{\infty} f(nT_s) \text{Sa}[\omega_m(t - nT_s)]$$

---

### 方法三：实际取样（零阶保持/平顶取样）分析

**适用题型：** 分析零阶保持（ZOH）或一阶保持取样的频谱。

**解题步骤（零阶保持）：**

1. **零阶保持的冲激响应：** $h_0(t) = u(t) - u(t - T_s)$

2. **频率响应：**
   $$H_0(\omega) = T_s \text{Sa}\left(\frac{\omega T_s}{2}\right) e^{-j\omega T_s/2}$$

3. **实际取样输出频谱：**
   $$F_{s0}(\omega) = F_s(\omega) \cdot H_0(\omega) = \sum_{n=-\infty}^{\infty} F(\omega - n\omega_s) \cdot \text{Sa}\left(\frac{\omega T_s}{2}\right) e^{-j\omega T_s/2}$$

4. **补偿滤波器（孔径效应校正）：**
   $$H_{0r}(j\omega) = \frac{e^{j\omega T_s/2}}{\text{Sa}(\omega T_s/2)}$$

**一阶保持（线性内插）：**
$$h_1(t) = (1 - |t|/T_s)[u(t + T_s) - u(t - T_s)]$$
$$H_1(\omega) = T_s \text{Sa}^2\left(\frac{\omega T_s}{2}\right)$$
$$H_{1r}(j\omega) = \frac{1}{\text{Sa}^2(\omega T_s/2)}$$

**关键对比：**

| 保持方式 | $H(\omega)$ 因子 | 补偿滤波器 |
|:---|:---|:---|
| 零阶保持 | $\text{Sa}(\omega T_s/2)$ | $1/\text{Sa}(\omega T_s/2)$ |
| 一阶保持 | $\text{Sa}^2(\omega T_s/2)$ | $1/\text{Sa}^2(\omega T_s/2)$ |

## 5.7 PCM（脉冲编码调制）

### 方法：PCM 系统理解与量化分析

**PCM 三步流程：**

1. **取样 (Sampling)：** 按奈奎斯特率对模拟信号时间离散化
2. **量化 (Quantization)：** 将连续幅度值四舍五入到最近的离散电平
3. **编码 (Encoding)：** 用二进制码表示量化值

**关键概念：**
- 量化间隔 = 满量程电压范围 / 量化级数
- 量化级数 $= 2^n$（$n$ 比特量化）
- 量化噪声 = 量化值与原信号的差值

**与本课程其他章节的联系：**
- 取样定理（5.6）→ 确定取样频率
- 理想低通滤波器（5.3）→ 恢复原信号
- 无失真传输条件（5.2）→ $H(j\omega) = K e^{-j\omega t_0}$ 保证 PCM 传输不失真

## 综合解题策略总结

```
输入信号 f(t)
    │
    ├─ 正弦信号 → 方法5.1-一：直接用 H(jω₀) 的幅值和相位
    │
    ├─ 周期信号 → 方法5.1-三：傅里叶级数法（Fn → Yn = H·Fn → y(t)）
    │
    ├─ 非周期信号 → 方法5.1-四：傅里叶变换法（F(jω)·H(jω) → 反变换）
    │
    ├─ 需要调制/解调 → 5.4节方法：频谱搬移 + 滤波
    │
    ├─ 需要取样重构 → 5.6节方法：Nyquist判据 + Sa内插
    │
    └─ 需要判断失真/设计滤波器 → 5.2/5.3节方法
```

**推荐的通用解题思路（频域法）：**

$$\boxed{\text{时域 } f(t) \;\xrightarrow{\mathcal{F}}\; \text{频域 } F(j\omega) \;\xrightarrow{\times H(j\omega)}\; Y(j\omega) \;\xrightarrow{\mathcal{F}^{-1}}\; \text{时域 } y(t)}$$

- 遇到复杂时域卷积 → 转频域乘法
- 遇到频谱截取/搬移 → 先用文字描述再用公式
- 反变换困难时 → 使用部分分式展开或查表
