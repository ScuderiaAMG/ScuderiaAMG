## 6.1 信号空间的基本概念

### 6.1.1 信号向量与信号空间

将信号视为向量空间中的元素，借鉴线性代数的方法分析信号。

**线性空间的基本要素：**
- 信号集合 $V$ 和数域（实数域 $\mathbb{R}$ 或复数域 $\mathbb{C}$）
- 加法封闭性：若 $x, y \in V$，则 $x + y \in V$
- 数乘封闭性：若 $x \in V, \alpha \in \mathbb{R}$，则 $\alpha x \in V$

**信号空间的维度：**
- 有限维空间：$\dim V = n$，信号可由有限个基向量线性表示
- 无限维空间：如函数空间 $L^2[a, b]$

**基与坐标：**
若 $\{e_1, e_2, \ldots, e_n\}$ 是 $n$ 维空间 $V$ 的一组基，则任意 $x \in V$ 可唯一表示为：
$$x = x_1 e_1 + x_2 e_2 + \cdots + x_n e_n = \sum_{i=1}^{n} x_i e_i$$

其中 $(x_1, x_2, \ldots, x_n)$ 称为 $x$ 在该基下的坐标。

### 6.1.2 范数（Norm）

**范数的定义与性质：**

向量 $x$ 的范数 $\|x\|$ 满足：
1. **正定性：** $\|x\| \geq 0$，且 $\|x\| = 0 \Leftrightarrow x = 0$
2. **齐次性：** $\|\alpha x\| = |\alpha| \|x\|$
3. **三角不等式：** $\|x + y\| \leq \|x\| + \|y\|$

**常见的 $p$-范数（$l^p$ 范数）：**

$$\|x\|_p \triangleq \left(\sum_{i=1}^{N} |x_i|^p\right)^{1/p}, \quad 1 \leq p < \infty$$

- **1-范数（$l^1$）：** $\|x\|_1 = \sum_{i=1}^{N} |x_i|$
- **2-范数（$l^2$，欧几里得范数）：** $\|x\|_2 = \sqrt{\sum_{i=1}^{N} |x_i|^2}$
- **无穷范数（$l^\infty$）：** $\|x\|_\infty = \max_{1 \leq i \leq N} |x_i|$

**示例：** $x = (1, 1)$ 时：
- $\|x\|_1 = 2$
- $\|x\|_2 = \sqrt{2}$
- $\|x\|_\infty = 1$

### 6.1.3 内积（Inner Product）

**内积的定义与性质：**

信号 $x(t)$ 和 $y(t)$ 在区间 $[a, b]$ 上的内积定义为：
$$\langle x, y \rangle = \int_a^b x(t) y^*(t) \, dt \quad \text{（连续情形）}$$

$$\langle x, y \rangle = \sum_{i=1}^N x_i y_i^* \quad \text{（离散情形）}$$

**内积的性质：**
1. **共轭对称性：** $\langle x, y \rangle = \overline{\langle y, x \rangle}$
2. **线性性：** $\langle \alpha x + \beta y, z \rangle = \alpha \langle x, z \rangle + \beta \langle y, z \rangle$
3. **正定性：** $\langle x, x \rangle \geq 0$，等号当且仅当 $x = 0$

**由内积诱导的范数：**
$$\|x\| = \sqrt{\langle x, x \rangle}$$

### 6.1.4 Cauchy-Schwarz 不等式

$$|\langle x, y \rangle| \leq \|x\| \cdot \|y\|$$

等号成立当且仅当 $x$ 与 $y$ 线性相关（$x = \lambda y$）。

**夹角公式：**
$$\cos\theta = \frac{\langle x, y \rangle}{\|x\| \cdot \|y\|}, \quad -1 \leq \cos\theta \leq 1$$

当 $\langle x, y \rangle = 0$ 时，称 $x$ 与 $y$ 正交（$\theta = \pi/2$）。

## 6.2 信号的正交分解

### 6.2.1 正交基与正交展开

设 $\{V_1, V_2, \ldots, V_n\}$ 是一组正交基，满足：
$$\langle V_l, V_m \rangle = 0 \quad (l \neq m)$$
$$\langle V_m, V_m \rangle = K_m \quad (\text{不归一化时})$$

任意向量 $A$ 可展开为：
$$A = C_1 V_1 + C_2 V_2 + \cdots + C_r V_r + \cdots + C_n V_n$$

其中系数：
$$C_r = \frac{\langle A, V_r \rangle}{\langle V_r, V_r \rangle}$$

### 6.2.2 三维空间中的正交分解

向量 $\vec{V} = x\vec{i} + y\vec{j} + z\vec{h}$，其中 $\vec{i}, \vec{j}, \vec{h}$ 构成标准正交基。

将 $\vec{V}$ 分解为 $\vec{V}_1 = x\vec{i} + y\vec{j}$（在 $xy$ 平面内的分量）和 $\vec{V}_e = z\vec{h}$（垂直于平面的分量），且 $\langle \vec{V}_1, \vec{V}_e \rangle = 0$。

### 6.2.3 函数空间中的正交分解（Gram-Schmidt 思想）

**核心问题：** 用一组正交函数逼近目标函数。

对于函数 $f_1(t)$ 和 $f_2(t)$，求系数 $c_{12}$ 使误差最小：

$$f_e(t) = f_1(t) - c_{12} f_2(t)$$

使误差能量最小化：
$$\frac{d}{dc_{12}} \int_{t_1}^{t_2} [f_1(t) - c_{12} f_2(t)]^2 dt = 0$$

解得：
$$c_{12} = \frac{\int_{t_1}^{t_2} f_1(t) f_2(t) \, dt}{\int_{t_1}^{t_2} f_2^2(t) \, dt} = \frac{\langle f_1(t), f_2(t) \rangle}{\langle f_2(t), f_2(t) \rangle}$$

此时 $f_e(t) \perp f_2(t)$（$f_e(t)$ 与 $f_2(t)$ 正交）。

### 6.2.4 函数正交分解例题

**例1 — 斜线信号的三角逼近：**
$$f(t) = \begin{cases} t, & 0 \leq t \leq 3 \\ 3, & t > 3 \end{cases} \quad \text{（或 } f(t) = t \text{, } 0 \leq t \leq 3\text{）}$$

用 $\sin(\frac{\pi}{3}t)$ 在 $[0, 3]$ 上逼近：

$$c_{12} = \frac{\int_0^3 f(t) \sin(\frac{\pi}{3}t) \, dt}{\int_0^3 \sin^2(\frac{\pi}{3}t) \, dt} = \frac{2}{\pi}$$

误差函数：
$$f_e(t) = f(t) - \frac{2}{\pi} \sin\left(\frac{\pi}{3}t\right)$$

**例2 — $\sin t$ 与 $\cos t$ 在 $(0, 2\pi)$ 上：**
$$\int_0^{2\pi} \cos t \cdot \sin t \, dt = 0$$

故 $\cos t$ 与 $\sin t$ 在 $(0, 2\pi)$ 上正交，$c_{12} = 0$。

### 6.2.5 多个函数的正交分解

对 $f(t)$ 用 $n$ 个函数 $\{g_r(t)\}$ 逼近：

$$f(t) \approx \sum_{r=1}^n c_r g_r(t)$$

误差能量：
$$\varepsilon = \int_{t_1}^{t_2} \left[f(t) - \sum_{r=1}^n c_r g_r(t)\right]^2 dt$$

当 $\{g_r(t)\}$ 为正交函数集时，各系数独立求解：
$$c_r = \frac{\langle f(t), g_r(t) \rangle}{\langle g_r(t), g_r(t) \rangle}$$

**Bessel 不等式（贝塞尔不等式）：**
$$\sum_{r=1}^n c_r^2 \|g_r\|^2 \leq \|f\|^2$$

## 6.3 完备正交函数集与傅里叶级数

### 6.3.1 完备正交函数集的概念

在区间 $[t_1, t_1+T]$（或 $[a, b]$）上定义的函数集合 $\{\varphi_k(t)\}$ 若满足：

1. **正交性：** $\langle \varphi_m, \varphi_n \rangle = \int_{t_1}^{t_1+T} \varphi_m(t) \varphi_n^*(t) \, dt = 0$，$m \neq n$
2. **完备性：** 不存在非零函数与该集合中所有函数正交

则称该函数集为**完备正交函数集**。

### 6.3.2 三角函数集

三角函数集 $\{1, \cos\Omega t, \cos 2\Omega t, \ldots, \cos n\Omega t, \ldots, \sin\Omega t, \sin 2\Omega t, \ldots, \sin n\Omega t, \ldots\}$ 在 $[t_1, t_1+T]$ 上满足正交性（其中 $\Omega = 2\pi/T$）：

正交性验证（$m \neq n$）：
$$\int_{t_1}^{t_1+T} \cos m\Omega t \cdot \sin n\Omega t \, dt = 0$$
$$\int_{t_1}^{t_1+T} \cos m\Omega t \cdot \cos n\Omega t \, dt = 0$$
$$\int_{t_1}^{t_1+T} \sin m\Omega t \cdot \sin n\Omega t \, dt = 0$$

自相关积分（$T = 2\pi/\Omega$）：
$$\int_{t_1}^{t_1+T} \cos^2 n\Omega t \, dt = \frac{T}{2} \quad (n \neq 0), \quad \int_{t_1}^{t_1+T} \sin^2 n\Omega t \, dt = \frac{T}{2}$$

$$\int_{t_1}^{t_1+T} 1^2 \, dt = T$$

### 6.3.3 傅里叶级数（三角函数形式）

周期为 $T$ 的函数 $f(t)$ 在 $[t_1, t_1+T]$ 上可展开为：
$$f(t) = \frac{a_0}{2} + \sum_{n=1}^{\infty} (a_n \cos n\Omega t + b_n \sin n\Omega t)$$

其中 $\Omega = 2\pi/T$，系数为：

$$a_n = \frac{2}{T} \int_{t_1}^{t_1+T} f(t) \cos n\Omega t \, dt, \quad n = 0, 1, 2, \ldots$$

$$b_n = \frac{2}{T} \int_{t_1}^{t_1+T} f(t) \sin n\Omega t \, dt, \quad n = 1, 2, 3, \ldots$$

### 6.3.4 指数形式的傅里叶级数

利用复指数函数集 $\{e^{jn\Omega t}, n = 0, \pm 1, \pm 2, \ldots\}$（$T = 2\pi/\Omega$）：

**正交性：**
$$\int_{t_1}^{t_1+T} e^{jm\Omega t} \cdot e^{-jn\Omega t} \, dt = \begin{cases} 0, & m \neq n \\ T, & m = n \end{cases}$$

**展开式：**
$$f(t) = \sum_{n=-\infty}^{\infty} F_n e^{jn\Omega t}$$

**系数公式：**
$$F_n = \frac{1}{T} \int_{t_1}^{t_1+T} f(t) e^{-jn\Omega t} \, dt$$

**三角形式与指数形式的关系：**
$$F_0 = \frac{a_0}{2}, \quad F_n = \frac{a_n - jb_n}{2}, \quad F_{-n} = \frac{a_n + jb_n}{2} \quad (n > 0)$$

### 6.3.5 正交性与功率关系

**Parseval 定理（周期信号）：**
$$\frac{1}{T} \int_{t_1}^{t_1+T} f^2(t) \, dt = \sum_{n=-\infty}^{\infty} |F_n|^2 = \left(\frac{a_0}{2}\right)^2 + \frac{1}{2}\sum_{n=1}^{\infty} (a_n^2 + b_n^2)$$

物理意义：周期信号的平均功率等于各谐波分量功率之和。

### 知识点提取

#### 6.1 信号矢量空间方法论的基本概念

* 
**线性空间**：集合中任意两元素相加，或任意元素与数值相乘后，结果仍属于该集合 。


* 
**基与维数**：能够线性表示空间中任意向量的一组线性无关的向量称为基 。基向量的个数即为空间的维数 。


* 
**范数（Norm）**：表示信号的大小，满足正定性、正齐性和三角形不等式 。


* 一阶范数：信号绝对值的积分或求和，表示信号作用的强度 。


* 二阶范数：$||x||_2 = [\int_{-\infty}^{\infty} |x(t)|^2 dt]^{1/2}$，其平方表示信号的能量 。


* 无穷范数：表示信号可测得的峰值或幅度 。




* 
**内积**：用于反映两信号间的相对位置（相似度）关系 。


* 连续复信号内积定义：$\langle x, y \rangle = \int_{-\infty}^{\infty} x(t)y^*(t)dt$ 。


* 当内积为0时，两信号正交 。




* 
**柯西-施瓦茨不等式**：$|\langle x, y \rangle|^2 \le \langle x, x \rangle \langle y, y \rangle$ 。



#### 6.2 信号的正交函数分解

* 
**正交分解的目的**：将任意信号分解为单元信号之和，简化系统分析 。


* 
**误差最小化与系数计算**：用信号 $f_2(t)$ 近似表示 $f_1(t)$ 时，为使均方误差最小，其投影系数应为 $c_{12} = \frac{\langle f_1(t), f_2(t) \rangle}{\langle f_2(t), f_2(t) \rangle}$ 。


* 
**正交函数集**：若集合中任意两个不同函数 $g_i(t)$ 和 $g_j(t)$ 的内积为0，则该集合为正交函数集 。任意信号可近似表示为这些基函数的线性组合：$f(t) \approx \sum_{r=1}^n c_r g_r(t)$ 。


* 通项系数公式：$c_r = \frac{\int_{t_1}^{t_2} f(t)g_r^*(t) dt}{\int_{t_1}^{t_2} g_r(t)g_r^*(t) dt}$ 。




* 
**复变函数正交**：需满足 $\int_{t_1}^{t_2} f_1(t)f_2^*(t) dt = 0$ 。



#### 6.3 完备正交函数集、帕塞瓦尔定理

* 
**完备正交函数集**：若信号空间中不存在与集中所有函数都正交的信号，或用该函数集表示信号的均方误差趋于0，则为完备正交函数集 。常见的有三角函数集和复指数函数集 。


* **能量信号与功率信号**：
* 能量信号：能量有限（$0 < E < \infty$）且平均功率为0（$P = 0$）的信号。通常是非周期的、在有限区间有值的信号 。


* 功率信号：平均功率有限（$0 < P < \infty$）且能量无穷大（$E = \infty$）的信号。通常是周期信号 。




* 
**帕塞瓦尔定理**：一个信号所含有的能量（或功率）恒等于此信号在完备正交函数集中各分量能量（或功率）之和 。数学表达式为 $\int_{t_1}^{t_2} f^2(t) dt = \sum_{r=1}^{\infty} c_r^2 \int_{t_1}^{t_2} g_r^2(t) dt$ 。

### 常见题型及解答通式通法

#### 题型一：求一个信号在另一个信号上的正交投影（最佳近似表示）

**解题目标**：用信号 $f_2(t)$ 在给定区间内近似表示 $f_1(t)$，并使均方误差最小。
**通式通法**：

1. 
**明确区间与函数**：确定积分区间 $[t_1, t_2]$，原信号 $f_1(t)$，以及用于逼近的基信号 $f_2(t)$ 。


2. 
**计算分子（两信号内积）**：计算 $\int_{t_1}^{t_2} f_1(t)f_2(t) dt$（若为复信号则为 $\int_{t_1}^{t_2} f_1(t)f_2^*(t) dt$） 。


3. 
**计算分母（基信号能量）**：计算 $\int_{t_1}^{t_2} f_2^2(t) dt$（若为复信号则为 $\int_{t_1}^{t_2} |f_2(t)|^2 dt$） 。


4. 
**求系数**：将步骤2的结果除以步骤3的结果，得到系数 $c_{12}$ 。


5. 
**写出结果**：近似表达式为 $f_1(t) \approx c_{12}f_2(t)$ 。若题目要求求误差函数，则计算 $f_e(t) = f_1(t) - c_{12}f_2(t)$ 。



#### 题型二：判断信号是能量信号还是功率信号

**解题目标**：根据定义计算信号的能量和功率，归类信号属性。
**通式通法**：

1. 
**观察信号特征**：若为一般周期信号，通常直接判定为功率信号 ；若为在有限区间有值的非周期信号，通常为能量信号 。


2. 
**计算平均功率 $P$**：使用公式 $P = \lim_{T \to \infty} \frac{1}{T} \int_{-T/2}^{T/2} f^2(t) dt$ 。


* 若计算结果满足 $0 < P < \infty$，则判定为**功率信号** 。


* 若计算结果 $P = 0$，进入下一步 。




3. 
**计算总能量 $E$**：使用公式 $E = \int_{-\infty}^{\infty} f^2(t) dt$ 。


* 若计算结果满足 $0 < E < \infty$，则判定为**能量信号** 。

## 6.6 相关函数

### 6.6.1 相关函数的基本概念

**相关的物理意义：** 描述两个信号在不同时刻的相似程度。

**自相关函数（Auto-correlation）：**
$$R_{xx}(\tau) = \int_{-\infty}^{\infty} x(t) x^*(t - \tau) \, dt = \int_{-\infty}^{\infty} x(t+\tau) x^*(t) \, dt$$

或用对称定义：
$$R_{xx}(\tau) = \langle x(t), x(t - \tau) \rangle$$

**互相关函数（Cross-correlation）：**
$$R_{xy}(\tau) = \int_{-\infty}^{\infty} x(t) y^*(t - \tau) \, dt = \int_{-\infty}^{\infty} x(t+\tau) y^*(t) \, dt$$

### 6.6.2 自相关函数的性质

1. **最大值在原点的性质：** $R_{xx}(0) \geq |R_{xx}(\tau)|$，$\forall\tau$
   - $R_{xx}(0) = \int_{-\infty}^{\infty} |x(t)|^2 dt = E$（信号的总能量）

2. **共轭对称性（实信号为偶函数）：**
   - $R_{xx}(-\tau) = R_{xx}^*(\tau)$
   - 若 $x(t)$ 为实信号，则 $R_{xx}(-\tau) = R_{xx}(\tau)$

3. **$R_{xx}(0)$ 为信号能量：** $R_{xx}(0) = \int_{-\infty}^{\infty} |x(t)|^2 dt$

### 6.6.3 互相关函数的性质

1. $R_{xy}(\tau) = R_{yx}^*(-\tau)$
2. $|R_{xy}(\tau)| \leq \sqrt{R_{xx}(0) \cdot R_{yy}(0)}$（Cauchy-Schwarz 推论）
3. 若 $x(t)$ 与 $y(t)$ 相互独立（不相关），则 $R_{xy}(\tau) = 0$

### 6.6.4 相关函数计算例题

**例1 — 矩形脉冲的自/互相关：**

给定两个信号 $x(t)$ 和 $y(t)$，计算相关函数：
- 利用 $R_{xy}(\tau) = \int_{-\infty}^{\infty} x(t) y(t-\tau) \, dt$ 进行积分计算
- 对 $x(-t)$ 和 $y(-t)$ 同理计算

**例2 — 有限长信号的相关：**

$$\begin{aligned} x(t) &= \begin{cases} 1, & 0 < t < 1 \\ 0, & \text{其他} \end{cases} \\ y(t) &= \begin{cases} 1, & 0 < t < 2 \\ 0, & \text{其他} \end{cases} \end{aligned}$$

通过图解法和分段积分计算自相关和互相关函数。

### 6.6.5 相关的应用

1. **信号检测：** 利用已知模板信号的互相关检测信号的存在性
2. **时延估计：** $R_{xy}(\tau)$ 的峰值位置 $\tau_0 = t_2 - t_1$ 对应两信号间的时延
3. **系统辨识：** 通过输入输出的互相关分析系统的冲激响应

### 6.6.6 距离测量应用

利用相关进行雷达/声纳测距：
- 发射信号 $x_1(t)$，接收信号 $x_2(t) = x_1(t - \tau_0)$
- $R_{12}(\tau) = R_{11}(\tau - \tau_0)$，峰值位置即 $\tau_0$
- 距离：$d = v \cdot \tau_0 / 2$（其中 $v$ 为波速）

**示例：**
$$R_{12}(\tau) = \int x_1(t) x_2(t-\tau) dt = R_{11}(\tau - \tau_0)$$
$$\tau_0 = t_2 - t_1, \quad v = \frac{L}{t_2 - t_1}$$

## 6.7 能量谱与功率谱

### 6.7.1 能量信号与功率信号

**能量信号：** $E = \int_{-\infty}^{\infty} |f(t)|^2 dt < \infty$（如非周期信号）

**功率信号：** $E = \infty$ 但 $P = \lim_{T \to \infty} \frac{1}{T} \int_{-T/2}^{T/2} |f(t)|^2 dt < \infty$（如周期信号）

### 6.7.2 Parseval 定理（能量定理）

对于能量信号 $f(t)$ 及其傅里叶变换 $F(\omega)$：

$$E = \int_{-\infty}^{\infty} |f(t)|^2 dt = \frac{1}{2\pi} \int_{-\infty}^{\infty} |F(\omega)|^2 d\omega$$

**物理意义：** 信号的总能量既可以在时域计算，也可以在频域计算（能量守恒）。

### 6.7.3 能量谱密度（ESD）

定义能量谱密度：
$$\mathcal{E}(\omega) = |F(\omega)|^2$$

能量为：
$$E = \frac{1}{2\pi} \int_{-\infty}^{\infty} \mathcal{E}(\omega) \, d\omega = \int_{-\infty}^{\infty} \mathcal{E}(f) \, df$$

### 6.7.4 功率谱密度（PSD）

对于周期信号 $f_T(t)$（周期为 $T$），截断函数：
$$f_T(t) = \begin{cases} f(t), & |t| \leq T/2 \\ 0, & |t| > T/2 \end{cases}$$

**Parseval 定理（功率形式）：**
$$P = \frac{1}{T} \int_{-T/2}^{T/2} |f(t)|^2 dt = \sum_{n=-\infty}^{\infty} |F_n|^2$$

功率谱密度定义为：
$$\mathcal{P}(\omega) = \lim_{T \to \infty} \frac{|F_T(\omega)|^2}{T}$$

平均功率：
$$P = \frac{1}{2\pi} \int_{-\infty}^{\infty} \mathcal{P}(\omega) \, d\omega$$

### 6.7.5 Wiener-Khinchin 定理

**能量信号：** 自相关函数与能量谱密度构成傅里叶变换对：
$$\mathcal{E}(\omega) = \int_{-\infty}^{\infty} R(\tau) e^{-j\omega\tau} \, d\tau$$
$$R(\tau) = \frac{1}{2\pi} \int_{-\infty}^{\infty} \mathcal{E}(\omega) e^{j\omega\tau} \, d\omega$$

即：$R(\tau) \leftrightarrow \mathcal{E}(\omega) = |F(\omega)|^2$

**功率信号：**
$$\mathcal{P}(\omega) = \int_{-\infty}^{\infty} R(\tau) e^{-j\omega\tau} \, d\tau$$
$$R(\tau) = \frac{1}{2\pi} \int_{-\infty}^{\infty} \mathcal{P}(\omega) e^{j\omega\tau} \, d\omega$$

其中 $R(\tau) = \lim_{T \to \infty} \frac{1}{T} \int_{-T/2}^{T/2} f(t+\tau) f^*(t) \, dt$。

### 6.7.6 R(0) 的物理意义

$$R(0) = \frac{1}{2\pi} \int_{-\infty}^{\infty} \mathcal{E}(\omega) \, d\omega = E \quad \text{（能量信号）}$$
$$R(0) = \frac{1}{2\pi} \int_{-\infty}^{\infty} \mathcal{P}(\omega) \, d\omega = P \quad \text{（功率信号）}$$

## 6.8 希尔伯特变换

### 6.8.1 希尔伯特变换的定义

信号 $f(t)$ 的希尔伯特变换 $\hat{f}(t)$ 定义为：

$$\hat{f}(t) = \mathcal{H}[f(t)] = \frac{1}{\pi} \int_{-\infty}^{\infty} \frac{f(\tau)}{t - \tau} \, d\tau = f(t) * \frac{1}{\pi t}$$

即 $\hat{f}(t)$ 是 $f(t)$ 与 $h(t) = 1/(\pi t)$ 的卷积。

### 6.8.2 希尔伯特变换的频率响应

系统函数：
$$H(\omega) = -j \cdot \text{sgn}(\omega)$$

幅度和相位：
$$|H(\omega)| = 1, \quad \varphi(\omega) = \begin{cases} -\pi/2, & \omega > 0 \\ +\pi/2, & \omega < 0 \end{cases}$$

**物理意义：** 希尔伯特变换是一个 $-90°$（对正频率）或 $+90°$（对负频率）的**全通移相器**。

### 6.8.3 希尔伯特变换的性质

1. **双重希尔伯特变换：** $\mathcal{H}[\mathcal{H}[f(t)]] = -f(t)$（两次变换恢复原信号，负号）

2. **正交性：** $\int_{-\infty}^{\infty} f(t) \hat{f}(t) \, dt = 0$（$f(t)$ 与 $\hat{f}(t)$ 正交）

3. **余弦/正弦关系：**
   - $\mathcal{H}[\cos\omega_0 t] = \sin\omega_0 t$
   - $\mathcal{H}[\sin\omega_0 t] = -\cos\omega_0 t$

4. **卷积性质：** $\mathcal{H}[f(t) * g(t)] = \hat{f}(t) * g(t) = f(t) * \hat{g}(t)$

### 6.8.4 解析信号

由实信号 $f(t)$ 构造解析信号：
$$z(t) = f(t) + j\hat{f}(t)$$

其频谱为：
$$Z(\omega) = \begin{cases} 2F(\omega), & \omega > 0 \\ F(0), & \omega = 0 \\ 0, & \omega < 0 \end{cases}$$

即解析信号只含正频率分量，是单边谱信号。

## 6.9 匹配滤波器

### 6.9.1 匹配滤波器的引出

**问题背景：** 信号 $s(t)$ 被加性噪声 $n(t)$ 污染，接收信号为 $r(t) = s(t) + n(t)$。如何设计滤波器 $H(j\omega)$ 使输出在 $t = t_m$ 时刻的信噪比最大？

**输出信噪比：**
$$\text{SNR} = \frac{s_o^2(t_m)}{n_o^2(t_m)}$$

其中：
$$s_o(t_m) = \frac{1}{2\pi} \int_{-\infty}^{\infty} H(j\omega) S(j\omega) e^{j\omega t_m} \, d\omega$$
$$\overline{n_o^2(t_m)} = \frac{N_0}{2\pi} \int_{-\infty}^{\infty} |H(j\omega)|^2 \, d\omega \quad \text{（白噪声，功率谱密度 } N_0/2\text{）}$$

### 6.9.2 匹配滤波器的频域解

利用 Schwarz 不等式最大化 SNR，得到最佳滤波器为：

$$H(j\omega) = k S^*(-j\omega) e^{-j\omega t_m}$$

或等价地：
$$H(j\omega) = k S(-\omega) e^{-j\omega t_m} \quad \text{（实信号）}$$

其中 $k$ 为任意常数。

**最大输出信噪比：**
$$\text{SNR}_{\max} = \frac{1}{2\pi N_0} \int_{-\infty}^{\infty} |S(j\omega)|^2 \, d\omega = \frac{E_s}{N_0}$$

其中 $E_s$ 为信号 $s(t)$ 的总能量。

### 6.9.3 匹配滤波器的时域形式

对 $H(j\omega) = k S^*(-j\omega) e^{-j\omega t_m}$ 取傅里叶反变换：

$$h(t) = k s^*(t_m - t)$$

对实信号：$h(t) = k s(t_m - t)$

**物理意义：** 匹配滤波器的冲激响应是输入信号的**时间反转**（以 $t_m$ 为参考点）。

### 6.9.4 匹配滤波器的输出

匹配滤波器的输出为输入与 $h(t)$ 的卷积：

$$s_o(t) = s(t) * h(t) = s(t) * [k s(t_m - t)]$$
$$= k \int_{-\infty}^{\infty} s(\tau) s(t_m - t + \tau) \, d\tau = k R_{ss}(t - t_m)$$

即匹配滤波器的输出是输入信号的**自相关函数**（平移至 $t_m$）。

### 6.9.5 物理可实现性条件

$h(t) = k s(t_m - t)$ 要满足因果性（$t < 0$ 时 $h(t) = 0$），需要：
$$t_m \geq T \quad \text{（$T$ 为信号 $s(t)$ 的持续时间）}$$

当 $t_m = T$ 时（取最小延迟）：
$$h(t) = k s(T - t), \quad 0 \leq t \leq T$$

**例题分析：**
- $s(t) = \sin(\omega_c t), \, 0 \leq t \leq T_0$（正弦脉冲）
- $h(t) = s(T - t)$（取 $k=1, t_m=T$）
- 匹配滤波器的输出 $r(t) = f(t) * f(-t) \approx R_{ss}(t-T)$

### 6.9.6 匹配滤波器例题

**例 — 正弦脉冲的匹配滤波：**
- $f(t) = \sin(0.5\pi t)[u(t) - u(t - 20)]$
- $h(t) = f(-t)$（非因果匹配滤波器）
- 因果匹配滤波器：$h_m(t) = f(T - t) = -\sin(0.5\pi t)$，$-20 \leq t \leq 0$
- $y(t) = r(t) * h_m(t) = f(t - \tau) * f(-t)$（自相关形式）

**自相关函数计算：**
$$s_o(T) = R_{ss}(0) = \int_{-\infty}^{\infty} s^2(t) \, dt = E_s$$

### 6.9.7 自相关和互相关的图解计算例题

给定 $s_1(t)$ 和 $s_2(t)$（矩形脉冲信号）：
- $R_{11}(\tau) = s_1(\tau) * s_1(-\tau)$ — 三角波
- $R_{22}(\tau) = s_2(\tau) * s_2(-\tau)$ — 三角波
- 互相关 $R_{12}(\tau)$ — 梯形波

通过图解法理解卷积和相关函数的几何意义。

## 6.11 CDMA（码分多址）

### 6.11.1 CDMA 基本原理

CDMA（Code Division Multiple Access，码分多址）利用正交编码实现多用户同时通信。

**正交调制方案：**

两路信号 $g_1(t)$ 和 $g_2(t)$ 分别用正交载波调制：

$$s(t) = g_1(t) \cos(\omega_0 t) + g_2(t) \sin(\omega_0 t)$$

### 6.11.2 解调过程

接收端乘以相应的载波后低通滤波：

**恢复 $g_1(t)$（乘以 $\cos\omega_0 t$）：**
$$\begin{aligned} s(t) \cos(\omega_0 t) &= g_1(t) \cos^2(\omega_0 t) + g_2(t) \sin(\omega_0 t) \cos(\omega_0 t) \\ &= \frac{1}{2} g_1(t)[1 + \cos(2\omega_0 t)] + \frac{1}{2} g_2(t) \sin(2\omega_0 t) \end{aligned}$$

低通滤波去掉 $2\omega_0$ 分量后得到 $\frac{1}{2} g_1(t)$。

**恢复 $g_2(t)$（乘以 $\sin\omega_0 t$）：**
同理得到 $\frac{1}{2} g_2(t)$。

### 6.11.3 扩频码的正交性

CDMA 系统中每个用户分配唯一的扩频码 $c_k(t)$：

$$R_{k,i}(\tau) = \int_0^T c_k(t - \tau) c_i(t) \, dt$$

理想情况下：
$$R_{k,i}(\tau) = \begin{cases} T, & k = i, \tau = 0 \\ \ll T, & k \neq i \text{ 或 } \tau \neq 0 \end{cases}$$

### 6.11.4 CDMA 系统结构

- 发送端：$a_k(t)$ 是第 $k$ 个用户的数据，用扩频码 $c_k(t)$ 和载波 $\cos(\omega_0 t)$ 调制
- 接收端：用相应的 $c_i(t - \tau_{i1}) \cos(\omega_0 t - \tau_{i1})$ 进行解扩和解调
- 通过相关接收恢复各用户数据

**CDMA 的优势：**
- 多用户共享同一频带
- 利用码的正交性区分用户
- 抗干扰和抗多径能力强
