## 5.1 连续时间LTI系统的频域分析

### 5.1.1 系统函数 H(jω)

**定义：**
- 系统函数（频率响应）定义为系统零状态响应的傅里叶变换与激励的傅里叶变换之比：

$$H(j\omega) = \frac{Y(j\omega)}{F(j\omega)} = |H(j\omega)| e^{j\varphi(\omega)}$$

- $H(j\omega)$ 是单位冲激响应 $h(t)$ 的傅里叶变换：$H(j\omega) = \mathcal{F}[h(t)]$
- $h(t) = \mathcal{F}^{-1}[H(j\omega)]$

**物理意义：**
- $|H(j\omega)|$ — 幅频特性（幅度响应）
- $\varphi(\omega)$ — 相频特性（相位响应）

**系统响应求解：**
- 时域：$y_{zs}(t) = h(t) * f(t)$
- 频域：$Y_{zs}(j\omega) = H(j\omega) F(j\omega)$

### 5.1.2 正弦信号激励下的系统响应

当输入 $f(t) = A\cos(\omega_0 t)$ 时：

$$F(j\omega) = A\pi[\delta(\omega + \omega_0) + \delta(\omega - \omega_0)]$$

输出频谱：
$$Y(j\omega) = H(j\omega)F(j\omega) = A[H(-j\omega_0)\delta(\omega + \omega_0) + H(j\omega_0)\delta(\omega - \omega_0)]$$

$$= A|H(j\omega_0)|[e^{-j\varphi_0}\delta(\omega + \omega_0) + e^{j\varphi_0}\delta(\omega - \omega_0)]$$

其中 $\varphi_0 = \varphi(\omega_0)$。

时域输出：
$$y(t) = |H(j\omega_0)|A\cos(\omega_0 t + \varphi_0)$$

**结论：** 正弦信号通过LTI系统后，仍为同频率的正弦信号，幅度乘以 $|H(j\omega_0)|$，相位增加 $\varphi(\omega_0)$。

### 5.1.3 例题分析

**例1 — 给定H(jω)求解输出：**
- 已知 $|H(j\omega)| = 1.5$（$|\omega| \leq 20$），$|H(j\omega)| = 0$（$|\omega| > 20$），$\varphi(\omega) = -60°$
- $f(t) = 2\cos(10t + 90°) + 5\cos(25t + 120°)$
- 对于 $\omega = 10$：$y_1(t) = |H(j10)| \cdot 2\cos(10t + 90° - 60°) = 3\cos(10t + 30°)$
- 对于 $\omega = 25$：$|H(j25)| = 0$（超出通带），$y_2(t) = 0$
- **输出：** $y(t) = 3\cos(10t + 30°)$

**例2 — RC低通电路分析：**
- 电路：$f(t)$ 通过电阻 R 和电容 C 组成的RC电路输出 $y(t)$
- $1/RC = 1000$，输入 $f(t) = \cos(100t) + \cos(3000t)$

系统函数：
$$H(j\omega) = \frac{1/(j\omega C)}{R + 1/(j\omega C)} = \frac{1}{j\omega RC + 1} = \frac{1/RC}{j\omega + 1/RC}$$

幅频和相频：
$$|H(j\omega)| = \frac{1/RC}{\sqrt{\omega^2 + (1/RC)^2}}, \quad \varphi(\omega) = -\arctan(\omega RC)$$

- 当 $\omega = 100$ rad/s：$|H(j100)| = 0.995$，$\varphi(100) = -5.71°$
- 当 $\omega = 3000$ rad/s：$|H(j3000)| = 0.316$，$\varphi(3000) = -71.6°$
- **输出：** $y(t) = 0.995\cos(100t - 5.71°) + 0.316\cos(3000t - 71.6°)$

**MATLAB仿真验证：** 可通过MATLAB绘制幅频、相频曲线及输入输出波形进行验证。

### 5.1.4 周期信号激励下的系统响应

**傅里叶级数法：**

对于周期信号 $f(t) = \sum_{n=-\infty}^{\infty} F_n e^{jn\Omega t}$：

$$y(t) = \sum_{n=-\infty}^{\infty} H(jn\Omega) F_n e^{jn\Omega t}$$

其中 $Y_n = H(jn\Omega) F_n$

**例 — 周期性方波通过RC电路：**
- $f(t)$ 为周期方波，周期 T = 2
- 傅里叶系数：$F_n = 0.5\text{Sa}(\frac{n\pi}{2})$，n = 0, ±1, ±2, ...
- RC系统函数：$H(jn\Omega) = \frac{1/RC}{jn\Omega + 1/RC}$
- 输出：$Y_n = H(jn\Omega) \cdot 0.5\text{Sa}(\frac{n\pi}{2})$
- 时域响应：$y(t) = \sum_{n=-\infty}^{\infty} Y_n e^{jn\Omega t}$

### 5.1.5 非周期信号激励下的系统响应

利用傅里叶变换：
$$Y(j\omega) = F(j\omega) H(j\omega)$$
$$y(t) = \mathcal{F}^{-1}[Y(j\omega)]$$

**例 — RC电路阶跃响应：**
- $e(t) = 2u(t) - u(t - \tau)$
- $E(j\omega) = 2[\pi\delta(\omega) + \frac{1}{j\omega}] - e^{-j\omega\tau}[\pi\delta(\omega) + \frac{1}{j\omega}] = \frac{2}{j\omega}(1 - e^{-j\omega\tau}) = 2\tau\text{Sa}(\frac{\omega\tau}{2}) e^{-j\frac{\omega\tau}{2}}$
- $H(j\omega) = \frac{1}{j\omega RC + 1} = \frac{1/RC}{j\omega + 1/RC}$
- $U_0(j\omega) = E(j\omega) H(j\omega)$
- 时域输出：$u_0(t) = 2[1 - e^{-t/RC}]u(t) - 2[1 - e^{-(t-\tau)/RC}]u(t - \tau)$

## 5.2 无失真传输

### 5.2.1 无失真传输的定义

**时域条件：** 系统输出 $y(t)$ 是输入 $f(t)$ 的精确副本，仅幅度缩放和时延不同：

$$y(t) = K f(t - t_0)$$

其中 $K$ 为常数增益，$t_0$ 为延迟时间。

**频域条件：**

对时域条件两边取傅里叶变换：
$$Y(j\omega) = K F(j\omega) e^{-j\omega t_0}$$

因此系统函数为：
$$H(j\omega) = K e^{-j\omega t_0}$$

即：
- **幅频特性：** $|H(j\omega)| = K$（常数，全通带）
- **相频特性：** $\varphi(\omega) = -\omega t_0$（线性相位）

### 5.2.2 无失真传输的物理意义

- 幅度响应为常数，所有频率分量均匀放大/衰减
- 相位响应是过原点的直线（线性相位），各频率分量延迟相同的时间 $t_0$
- 群延迟 $\tau_g = -\frac{d\varphi}{d\omega} = t_0$ 为常数

### 5.2.3 信号相位失真的例子

对于 $f(t) = A_1\sin(\omega_1 t) + A_2\sin(2\omega_1 t)$：

$$y(t) = KA_1\sin(\omega_1 t - \varphi_1) + KA_2\sin(2\omega_1 t - \varphi_2)$$

若要求无失真，必须有：
$$\varphi_1 = \omega_1 t_0, \quad \varphi_2 = 2\omega_1 t_0$$
即 $\varphi_1/\omega_1 = \varphi_2/(2\omega_1) = t_0$（相位与频率成正比）

若 $\varphi_1 = \varphi_2 = t_0$（常数相位），则不同频率分量延迟不同，产生相位失真。

### 5.2.4 信号波形比较例题

三个信号对比：
- $f_1(t) = [\sin(2\pi t) + \sin(5\pi t)][u(t) - u(t-1)]$
- $f_2(t) = [\sin(2\pi(t-1)) + \sin(5\pi(t-1))][u(t-1) - u(t-2)]$ — 时移 $(t-1)$
- $f_3(t) = [\sin(2\pi t - 2\pi) + \sin(5\pi t - 2\pi)][u(t-1) - u(t-2)]$ — 常数相位 $2\pi$

$f_2$ 与 $f_1$ 是时移关系；$f_3$ 因相位为常数（非频率的线性函数），波形与 $f_1$ 不同，产生失真。

### 5.2.5 电路无失真传输条件例题

给定RLC电路，求解使系统满足无失真传输的条件：
$$H(j\omega) = K e^{-j\omega t_0}$$

当 $R_1 = R_2 = 1$ 时，$H(j\omega) = 1$，满足无失真传输条件。

## 5.3 理想滤波器

### 5.3.1 理想低通滤波器（LPF）

**频率响应：**
$$H_{LP}(j\omega) = G_{2\omega_c}(\omega) \cdot e^{-j\omega t_0}$$

其中 $G_{2\omega_c}(\omega)$ 为矩形窗函数（门函数），带宽为 $2\omega_c$。

- 通带：$|\omega| \leq \omega_c$，$|H(j\omega)| = 1$
- 阻带：$|\omega| > \omega_c$，$|H(j\omega)| = 0$
- 截止频率 $\omega_c$ 满足 $|H(j\omega_c)| = 1/\sqrt{2} \approx 0.707$

**单位冲激响应：**

$$h(t) = \mathcal{F}^{-1}[H(j\omega)] = \frac{1}{2\pi}\int_{-\omega_c}^{\omega_c} 1 \cdot e^{-j\omega t_0} e^{j\omega t} d\omega$$
$$= \frac{\omega_c}{\pi} \text{Sa}[\omega_c(t - t_0)]$$

**特点：**
- $h(t)$ 是非因果的（$t < 0$ 时不为零），物理不可实现
- 主瓣宽度为 $2\pi/\omega_c$

### 5.3.2 理想低通滤波器的阶跃响应

输入 $e(t) = u(t)$（$E(j\omega) = \pi\delta(\omega) + \frac{1}{j\omega}$）：

$$r(t) = \frac{1}{2} + \frac{1}{\pi} \text{Si}[\omega_c(t - t_0)]$$

其中 $\text{Si}(y) = \int_0^y \frac{\sin x}{x} dx$ 为正弦积分函数。

**上升时间：**
$$t_r = \frac{2\pi}{\omega_c} = \frac{1}{B}$$

其中 $B = f_c = \frac{\omega_c}{2\pi}$。

**阶跃响应特点：**
- 响应超前于输入（非因果性）
- 存在过冲和振荡（Gibbs现象）
- $B \cdot t_r = 1$（带宽与上升时间之积为常数）

### 5.3.3 理想高通滤波器（HPF）

**频率响应：**
$$H_{HP}(j\omega) = [1 - G_{2\omega_c}(\omega)] \cdot e^{-j\omega t_0}$$

- 通带：$|\omega| \geq \omega_c$
- 阻带：$|\omega| < \omega_c$
- 截止频率满足 $|H(j\omega_c)| = 1/\sqrt{2}$

### 5.3.4 理想带通滤波器（BPF）

**频率响应：**
$$H_{BP}(j\omega) = [G_{2\omega_c}(\omega + \omega_0) + G_{2\omega_c}(\omega - \omega_0)] \cdot e^{-j\omega t_0}$$

- 通带：$\omega_0 - \omega_c \leq |\omega| \leq \omega_0 + \omega_c$
- 中心频率为 $\omega_0$

### 5.3.5 理想带阻滤波器（BSF）

**频率响应：**
$$H_{BS}(j\omega) = [1 - H_{BP}(j\omega)] \cdot e^{-j\omega t_0}$$

- 阻带：$\omega_0 - \omega_c \leq |\omega| \leq \omega_0 + \omega_c$
- 与带通滤波器互补

### 5.3.6 滤波器应用例题

**例1 — 带通滤波：**
$f(t) = 20\cos(100t)[\cos(10^4 t)]^2$，$H(j\omega) = G_{240}(\omega)$

利用三角恒等式化简：
$$\cos^2\alpha = \frac{1+\cos 2\alpha}{2}$$
$$\cos\alpha + \cos\beta = 2\cos[(\alpha+\beta)/2]\cos[(\alpha-\beta)/2]$$

$$f(t) = 10\cos(100t) + 5(\cos 20100t + \cos 19900t)$$

$$F(j\omega) = 10\pi[\delta(\omega+100) + \delta(\omega-100)] + 5\pi[\delta(\omega+20100) + \delta(\omega-20100) + \delta(\omega+19900) + \delta(\omega-19900)]$$

滤波器只保留 $|\omega| \leq 120$ 内的分量：$Y(j\omega) = 10\pi[\delta(\omega+100) + \delta(\omega-100)]$

$$y(t) = 10\cos(100t)$$

**例2 — 多频信号滤波：**
$f(t)$ 含多种频率分量（5Hz系统），通过低通滤波器：
- $f(t) = -4 + 2\sin(4\pi t) + 6\cos(12\pi t) + 3\sin(16\pi t) + 4\cos(16\pi t)$
- 滤波器仅保留低频：$y(t) = -4 + 2\sin(4\pi t)$

**例3 — 级联滤波系统：**
两个滤波器级联，信号经调制—滤波—解调的过程，通过频谱图解分析各级输出。

### 5.3.7 综合计算例题

已知 $f(t) = 2 + \cos\omega t - \sin(\cdot)$ 和不同 $h(t)$，求 $y(t)$：
- $F(j\omega) = 8\pi\delta(\omega) + \pi[\delta(\omega+4) + \delta(\omega-4)] - j\pi[\delta(\omega+8) - \delta(\omega-8)]$

(1) $h(t) = \text{Sa}(5t)$：$H(j\omega) = 0.2 G_{10}(\omega)$，$y(t) = 0.8 + 0.2\cos(4t)$

(2) $h(t) = e^{-t}u(t)$：$H(j\omega) = \frac{1}{j\omega+1}$，$y(t) = 4 + \frac{1}{\sqrt{1+4^2}}\cos(4t - \arctan 4) - \frac{1}{\sqrt{1+8^2}}\sin(8t - \arctan 8)$

(3) $h(t) = \text{Sa}(\pi t)\cos(8t)$：$y(t) = -\frac{1}{2}\sin(8t)$

## 5.4 调制与解调

### 5.4.1 幅度调制原理

**调制过程：**

$$f_s(t) = f(t) \cos(\omega_0 t)$$

其中 $f(t)$ 为调制信号（基带信号），$\cos(\omega_0 t)$ 为载波信号。

**频谱分析：**
$$F_s(j\omega) = \frac{1}{2} \{F[j(\omega - \omega_0)] + F[j(\omega + \omega_0)]\}$$

调制将基带频谱搬移到 $\pm\omega_0$ 处（频谱搬移）。

### 5.4.2 同步解调原理

**解调过程：**

$$g(t) = y(t) \cdot s(t) = f(t) \cos^2(\omega_0 t) = \frac{1}{2}[f(t) + f(t)\cos(2\omega_0 t)]$$

频谱：
$$G(j\omega) = \frac{1}{2}F(j\omega) + \frac{1}{4}\{F[j(\omega - 2\omega_0)] + F[j(\omega + 2\omega_0)]\}$$

通过低通滤波器后，滤除 $2\omega_0$ 分量，恢复原信号 $\frac{1}{2}f(t)$。

### 5.4.3 调制解调例题

**例1 — 单边带调制分析：**
- $f(t) = \frac{1}{2}\text{Sa}(2t)$，$F(j\omega) = \frac{1}{2}G_4(\omega)$（利用 $\text{Sa}(\omega_c t) \leftrightarrow \frac{\pi}{\omega_c}G_{2\omega_c}(\omega)$）
- $f_1(t) = f(t)\cos(1000t)$
- $F_1(j\omega) = \frac{1}{4}[G_4(\omega+1000) + G_4(\omega-1000)]$
- 经带通滤波器 $H(j\omega) = G_2(\omega)$（中心在 $\pm 1000$ 附近）：
- $Y(j\omega) = \frac{1}{4}[G_2(\omega+1000) + G_2(\omega-1000)]$
- $y(t) = \frac{1}{2}\text{Sa}(t)\cos(1000t)$

**例2 — 二次调制解调：**
- $f_0(t) = \frac{1}{2}\text{Sa}(t)$，$F_0(j\omega) = \frac{1}{2}G_2(\omega)$
- $f_1(t) = f_0(t)\cos^2(1000t) = \frac{1}{2}[f_0(t) + f_0(t)\cos(2000t)]$
- $F_1(j\omega) = \frac{1}{2}F_0(j\omega) + \frac{1}{4}[F_0(j(\omega+2000)) + F_0(j(\omega-2000))]$
- 经低通 $H(j\omega) = G_2(\omega)$：$Y(j\omega) = \frac{1}{2}F_0(j\omega) = \frac{1}{4}G_2(\omega)$
- $y(t) = \frac{1}{2}\text{Sa}(t)$

## 5.5 时域均衡与小波变换基础

### 5.5.1 频域均衡

**系统辨识与补偿：**
- 利用系统函数 $H(j\omega)$ 分析系统特性
- 例：$H(s) = \frac{V_2(s)}{V_1(s)} = \frac{2s}{(s+1)^2+100^2}$ 的分析

$$H(j\omega) = \frac{2j\omega}{(j\omega+1)^2 + 100^2} = \frac{2j\omega}{(j\omega)^2 + 2j\omega + 1 + 100^2}$$

进一步化简：
$$H(j\omega) = \frac{2j\omega}{j(\omega+100)(\omega-100) + 2j\omega} = \frac{1}{1 + j(\omega-100)}$$

**例题分析：**
输入 $v_1(t) = (1 + \cos t)\cos(100t) = \cos(100t) + \frac{1}{2}\cos(101t) + \frac{1}{2}\cos(99t)$

系统响应：
- $H(j100) = 1$
- $H(j101) = \frac{\sqrt{2}}{2}e^{-j45°}$
- $H(j99) = \frac{\sqrt{2}}{2}e^{j45°}$

输出：
$$v_2(t) = \cos(100t) + \frac{\sqrt{2}}{2}\cos(101t - 45°) + \frac{\sqrt{2}}{2}\cos(99t + 45°)$$
$$= \left[1 + \frac{\sqrt{2}}{2}\cos(t - 45°)\right]\cos(100t)$$

**包络分析：** 输出信号可视为载波 $\cos(100t)$ 被包络调制，包络为 $1 + \frac{\sqrt{2}}{2}\cos(t - 45°)$。

### 5.5.2 小波变换基础

**小波变换定义：**

连续小波变换：
$$W_f(a,b) = \frac{1}{\sqrt{a}}\int_{-\infty}^{\infty} f(t) \psi^*\left(\frac{t-b}{a}\right) dt$$

其中 $\psi(t)$ 为母小波，$a$ 为尺度参数（伸缩），$b$ 为平移参数。

**与小波函数的关系：**

令 $h_a(t) = \frac{1}{a} w\left(-\frac{t}{a}\right)$，则：

$$f(t) * h_a(t) = \int_{-\infty}^{\infty} f(\tau) h_a(t-\tau) d\tau = \frac{1}{a}\int_{-\infty}^{\infty} f(\tau) w\left(\frac{\tau-t}{a}\right) d\tau$$

**频域表示：**
$$\mathcal{F}[h_a(t)] = H_a(\omega) = aW(-a\omega)$$

其中 $W(\omega) = \mathcal{F}[w(t)]$。

**尺度性质：**
$$f(bt) \leftrightarrow \frac{1}{|b|} F\left(\frac{\omega}{b}\right)$$

### 5.5.3 小波函数示例

母小波：$w(t) = \frac{1}{\pi t} \sin(\pi t) \cos(3\pi t) = \text{Sa}(\pi t) \cos(3\pi t)$

频谱：
$$W(\omega) = \frac{1}{2}[G_{2\pi}(\omega-3\pi) + G_{2\pi}(\omega+3\pi)]$$

$H_a(\omega) = aW(-a\omega) = \frac{a}{2}[G_{2\pi}(-a\omega-3\pi) + G_{2\pi}(-a\omega+3\pi)]$

- $W(\omega)$ 的中心频率 $\omega_0 = 3\pi$，带宽 $B = 2\pi$
- 尺度变化使中心频率移至 $\omega_0/a$，带宽变为 $B/a$

## 5.6 取样与取样定理

### 5.6.1 理想取样

**时域取样：**

$$f_s(t) = f(t) \cdot \delta_T(t) = \sum_{n=-\infty}^{\infty} f(nT_s) \delta(t - nT_s)$$

其中 $\delta_T(t) = \sum_{n=-\infty}^{\infty} \delta(t - nT_s)$ 为周期冲激串。

**频域分析：**

$$\delta_T(t) \text{的频谱：} \mathcal{F}[\delta_T(t)] = \omega_s \sum_{n=-\infty}^{\infty} \delta(\omega - n\omega_s), \quad \omega_s = \frac{2\pi}{T_s}$$

$$F_s(\omega) = \frac{1}{2\pi} F(\omega) * \mathcal{F}[\delta_T(t)] = \frac{1}{T_s}\sum_{n=-\infty}^{\infty} F(\omega - n\omega_s)$$

取样使原信号频谱以 $\omega_s$ 为周期重复。

### 5.6.2 取样定理（Nyquist-Shannon Sampling Theorem）

**时域取样定理：**

若 $f(t)$ 是带限信号（$F(\omega) = 0, |\omega| > \omega_m$），取样角频率 $\omega_s \geq 2\omega_m$（或 $f_s \geq 2f_m$），则 $f(t)$ 可由其取样值 $f(nT_s)$ 唯一确定。

- $\omega_s = 2\omega_m$ 称为**奈奎斯特率**（Nyquist rate）
- $T_s = \frac{\pi}{\omega_m} = \frac{1}{2f_m}$ 为最大取样间隔

### 5.6.3 信号重构（内插公式）

通过理想低通滤波器 $H(\omega) = T_s G_{2\omega_c}(\omega)$（$\omega_c = \omega_s/2$）：

$$h(t) = \frac{T_s \omega_c}{\pi} \text{Sa}(\omega_c t) = \text{Sa}\left(\frac{\omega_s t}{2}\right)$$

重构公式（内插公式）：
$$f(t) = f_s(t) * h(t) = \sum_{n=-\infty}^{\infty} f(nT_s) \text{Sa}[\omega_c(t - nT_s)]$$

当 $\omega_c = \omega_s/2 = \omega_m$，$T_s = \pi/\omega_m$：

$$f(t) = \sum_{n=-\infty}^{\infty} f(nT_s) \text{Sa}[\omega_m(t - nT_s)]$$

即用 $\text{Sa}$ 函数作为内插函数，由取样值恢复原信号。

### 5.6.4 实际取样（平顶取样/零阶保持）

**零阶保持取样：**

$$f_{s0}(t) = f_s(t) * h_0(t)$$

其中 $h_0(t) = u(t) - u(t - T_s)$（矩形脉冲）。

$$H_0(\omega) = T_s \text{Sa}\left(\frac{\omega T_s}{2}\right) e^{-j\omega T_s/2}$$

$$F_{s0}(\omega) = F_s(\omega) \cdot H_0(\omega) = \sum_{n=-\infty}^{\infty} F(\omega - n\omega_s) \cdot \text{Sa}\left(\frac{\omega T_s}{2}\right) e^{-j\omega T_s/2}$$

### 5.6.5 内插重构滤波器

**零阶保持的补偿滤波器：**

$$H_{0r}(j\omega) = \frac{1}{H_0(\omega)} = \frac{e^{j\omega T_s/2}}{\text{Sa}(\omega T_s/2)}$$

用于补偿零阶保持带来的孔径失真。

**一阶保持（线性内插）：**

$$h_1(t) = \begin{cases} 1 - \frac{|t|}{T_s}, & |t| \leq T_s \\ 0, & \text{其他} \end{cases}$$

$$\mathcal{F}[h_1(t)] = T_s \text{Sa}^2\left(\frac{\omega T_s}{2}\right)$$

$$H_{1r}(j\omega) = \frac{1}{\text{Sa}^2(\omega T_s/2)}$$

## 5.7 PCM（脉冲编码调制）

### 5.7.1 PCM基本概念

PCM（Pulse Code Modulation，脉冲编码调制）是将模拟信号转换为数字信号的编码方式。

**基本流程：**
1. **取样（Sampling）：** 按取样定理对模拟信号进行时间离散化
2. **量化（Quantization）：** 将连续的取样值近似为有限个离散电平
3. **编码（Encoding）：** 将量化值用二进制码表示

### 5.7.2 量化过程

将信号幅度范围等分为若干量化区间，每个区间用其中间值（或边界值）表示。

例如：将信号值 $f(t)$ 量化为最接近的离散值：
- 1.46 → 1.5，1.52 → 1.5
- 1.22 → 1.2，0.87 → 0.9，0.89 → 0.9
- 0.34 → 0.3，0.46 → 0.5，0.22 → 0.2，0.06 → 0.1

### 5.7.3 量化误差

量化过程引入的误差称为**量化噪声**，量化间隔越小（量化比特数越多），量化噪声越小。

### 5.7.4 PCM与系统频域分析的联系

PCM系统涉及：
- 取样定理（5.6节）
- 理想低通滤波器重构（5.3节）
- 无失真传输条件 $H(j\omega) = K e^{-j\omega t_0}$（5.2节）
