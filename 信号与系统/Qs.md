### **2-14 题解析**

**题目要求**：求下列两组卷积，并注意相互间的区别。

#### **(1) 已知 $f(t) = u(t) - u(t-1)$，求 $s(t) = f(t) * f(t)$**

**解题步骤**：
这是一个标准的矩形脉冲信号与自身卷积的问题（又称自卷积）。$f(t)$ 是一个宽度为 1，高度为 1 的门函数（矩形波），定义域在 $0 \le t \le 1$。
利用卷积的分配律和时移特性来计算，或者利用阶跃函数卷积的公式推导更为简便。

已知基础公式：$u(t) * u(t) = t \cdot u(t)$
根据线性时不变系统的时移特性：若 $f_1(t) * f_2(t) = y(t)$，则 $f_1(t-t_1) * f_2(t-t_2) = y(t - t_1 - t_2)$。

将 $s(t)$ 展开：
$s(t) = [u(t) - u(t-1)] * [u(t) - u(t-1)]$
$s(t) = u(t)*u(t) - u(t)*u(t-1) - u(t-1)*u(t) + u(t-1)*u(t-1)$
$s(t) = u(t)*u(t) - 2[u(t)*u(t-1)] + u(t-1)*u(t-1)$

应用基础公式和时移特性代入：
**$s(t) = t u(t) - 2(t-1)u(t-1) + (t-2)u(t-2)$**

**波形结果说明**：这是一个底边宽度为 2、顶点在 $t=1$ 处、峰值为 1 的等腰三角形脉冲。

* 当 $0 \le t < 1$ 时，$s(t) = t$
* 当 $1 \le t < 2$ 时，$s(t) = t - 2(t-1) = 2 - t$
* 其他时间为 0。

#### **(2) 已知 $f(t) = u(t-1) - u(t-2)$，求 $s(t) = f(t) * f(t)$**

**解题步骤**：
此处的 $f(t)$ 可以看作是第 (1) 问中的信号向右平移了 1 个单位时间。
令 $f_1(t) = u(t) - u(t-1)$，那么本题的 $f(t) = f_1(t-1)$。

直接利用卷积的时移特性：
$s(t) = f(t) * f(t) = f_1(t-1) * f_1(t-1)$
已知 $f_1(t) * f_1(t)$ 的结果为第 (1) 问的答案，将其整体向右平移 $(1 + 1) = 2$ 个单位时间即可。

将第 (1) 问结果中的 $t$ 全部替换为 $(t-2)$：
**$s(t) = (t-2) u(t-2) - 2(t-3)u(t-3) + (t-4)u(t-4)$**

**相互间的区别（分析结论）**：
两组卷积的结果波形**形状完全相同**（都是底宽为 2、高度为 1 的等腰三角形），但**发生的时间不同**。
第 (2) 问的激励信号比第 (1) 问延迟了 1 个单位时间，由于两个信号都延迟了 1，根据时移特性，卷积结果总共延迟了 $1 + 1 = 2$ 个单位时间。这直观地验证了卷积的**时移特性**。

### **2-15 题解析**

已知：

* $f_1(t) = u(t+1) - u(t-1)$ （中心在 $t=0$，宽度为 2 的矩形脉冲，幅度为1）
* $f_2(t) = \delta(t+5) + \delta(t-5)$ （两个冲激信号，分别在 $t=-5$ 和 $t=5$ 处）
* $f_3(t) = \delta(t+\frac{1}{2}) + \delta(t-\frac{1}{2})$ （两个冲激信号，分别在 $t=-0.5$ 和 $t=0.5$ 处）

**利用核心性质**：任意信号与冲激函数的卷积，等于该信号的平移：$f(t) * \delta(t \pm t_0) = f(t \pm t_0)$。

#### **(1) 求并画出 $s_1(t) = f_1(t) * f_2(t)$**

**计算过程**：
$s_1(t) = f_1(t) * [\delta(t+5) + \delta(t-5)]$
$s_1(t) = f_1(t+5) + f_1(t-5)$

由于 $f_1(t)$ 是区间在 $[-1, 1]$ 上的矩形脉冲：

* $f_1(t+5)$ 是将 $f_1(t)$ 向左平移 5，脉冲区间变为 $[-6, -4]$。
* $f_1(t-5)$ 是将 $f_1(t)$ 向右平移 5，脉冲区间变为 $[4, 6]$。

**波形画法描述**：
画出两个独立分开的矩形方波。

1. 第一个方波位于 $t$ 轴的 $[-6, -4]$ 区间，高度为 1。
2. 第二个方波位于 $t$ 轴的 $[4, 6]$ 区间，高度为 1。
由于两个区间距离很远，波形不发生重叠。

#### **(4) 求并画出 $s_4(t) = f_1(t) * f_3(t)$**

**计算过程**：
$s_4(t) = f_1(t) * [\delta(t+0.5) + \delta(t-0.5)]$
$s_4(t) = f_1(t+0.5) + f_1(t-0.5)$

此时分析两个平移后的信号：

* $f_1(t+0.5)$ 是向左平移 0.5，原区间 $[-1, 1]$ 变为 $[-1.5, 0.5]$，高度为 1。
* $f_1(t-0.5)$ 是向右平移 0.5，原区间 $[-1, 1]$ 变为 $[-0.5, 1.5]$，高度为 1。

因为平移距离（0.5）小于脉冲自身宽度（2），这两个矩形脉冲**在中间部分发生了重叠**，需要进行叠加：

* 当 $t \in [-1.5, -0.5)$ 时，只有第一个脉冲有值，幅度为 $1$。
* 当 $t \in [-0.5, 0.5)$ 时，两个脉冲都有值，幅度相加为 $1 + 1 = 2$。
* 当 $t \in [0.5, 1.5]$ 时，只有第二个脉冲有值，幅度为 $1$。
* 其余位置全为 $0$。

**波形画法描述**：
画出一个形似“凸”字形（或颁奖台形状）的阶梯波形：

1. 横坐标 $[-1.5, -0.5]$ 区间，画一条高度为 1 的水平线段。
2. 横坐标 $[-0.5, 0.5]$ 区间（中心区域），波形向上突起，画一条高度为 2 的水平线段。
3. 横坐标 $[0.5, 1.5]$ 区间，画一条高度为 1 的水平线段。
（各水平线段之间用垂直线连接即可）

### **题 2-16 解析**

**题目要求**：已知 $r(t) = e^{-t}u(t) * \sum_{k=-\infty}^{\infty} \delta(t-3k)$，证明在 $0 \le t \le 3$ 时 $r(t) = Ae^{-t}$，并求出 $A$ 的值。

**证明与求解步骤**：

**1. 利用卷积与冲激函数的性质展开表达式**
根据任意信号与冲激函数卷积的时移性质 $f(t) * \delta(t - t_0) = f(t - t_0)$，并且卷积运算满足对加法的分配律，我们可以将求和符号提出：


$$r(t) = \sum_{k=-\infty}^{\infty} [e^{-t}u(t) * \delta(t-3k)]$$

$$r(t) = \sum_{k=-\infty}^{\infty} e^{-(t-3k)}u(t-3k)$$

**2. 分析指定区间 $0 \le t < 3$ 内的有效项**
我们需要找出在 $0 \le t < 3$ 这个时间段内，哪些项是不为零的。
阶跃函数 $u(t-3k)$ 只有当其自变量 $t - 3k \ge 0$，即 $k \le \frac{t}{3}$ 时才为 1，否则为 0。
因为我们考察的区间是 $0 \le t < 3$，所以 $\frac{t}{3}$ 的范围是 $[0, 1)$。
这意味着只有当整数 $k \le 0$ 时（即 $k = 0, -1, -2, -3, \dots$），$u(t-3k)$ 的值才为 1。而对于 $k \ge 1$ 的项，在 $t < 3$ 时均为 0。

**3. 化简无穷级数**
将 $k \le 0$ 的项代入并化简，令 $m = -k$（则 $m = 0, 1, 2, \dots$）：


$$r(t) = \sum_{k=-\infty}^{0} e^{-(t-3k)}$$

$$r(t) = \sum_{m=0}^{\infty} e^{-(t+3m)}$$


将 $e^{-t}$ 提取出来：


$$r(t) = e^{-t} \sum_{m=0}^{\infty} e^{-3m} = e^{-t} \sum_{m=0}^{\infty} (e^{-3})^m$$

这是一个首项为 1，公比为 $e^{-3}$ 的无穷等比数列求和。因为 $|e^{-3}| < 1$，该级数收敛，利用求和公式 $S = \frac{a_1}{1 - q}$：


$$\sum_{m=0}^{\infty} (e^{-3})^m = \frac{1}{1 - e^{-3}}$$

**4. 得出结论**
将求和结果代回 $r(t)$：


$$r(t) = \left( \frac{1}{1 - e^{-3}} \right) e^{-t}$$


这就证明了在 $0 \le t \le 3$ （严格来说是 $t < 3$ 的右开区间）内，$r(t)$ 具有 $Ae^{-t}$ 的形式，并且常数 $A$ 的值为：


$$A = \frac{1}{1 - e^{-3}} = \frac{e^3}{e^3 - 1}$$

### **题 2-21 解析**

已知系统的冲激响应为 $h(t) = e^{-2t}u(t)$。这代表一个典型的一阶连续系统。

#### **(1) 求给定激励下的响应 $r(t)$**

**已知激励信号：** $e(t) = e^{-t}[u(t) - u(t-2)] + \beta\delta(t-2)$

利用线性系统的叠加原理，将激励分为三部分：$e(t) = e_1(t) - e_2(t) + e_3(t)$
其中：

* $e_1(t) = e^{-t}u(t)$
* $e_2(t) = e^{-t}u(t-2)$
* $e_3(t) = \beta\delta(t-2)$

分别求这三部分与 $h(t)$ 的卷积响应：
**第一部分：求 $r_1(t) = e_1(t) * h(t)$**


$$r_1(t) = e^{-t}u(t) * e^{-2t}u(t) = \int_0^t e^{-\tau} e^{-2(t-\tau)} \text{d}\tau$$

$$r_1(t) = e^{-2t} \int_0^t e^{\tau} \text{d}\tau = e^{-2t}(e^t - 1) = (e^{-t} - e^{-2t})u(t)$$

**第二部分：求 $r_2(t) = e_2(t) * h(t)$**
注意 $e_2(t)$ 可以变形为含 $u(t-2)$ 的形式来利用时移特性：


$$e_2(t) = e^{-t}u(t-2) = e^{-2} \cdot e^{-(t-2)}u(t-2)$$


令 $x(t) = e^{-t}u(t)$，则 $e_2(t) = e^{-2}x(t-2)$。
因为 $x(t) * h(t) = r_1(t)$，所以根据时移和齐次性：


$$r_2(t) = e^{-2} r_1(t-2) = e^{-2} \left[ e^{-(t-2)} - e^{-2(t-2)} \right] u(t-2)$$

$$r_2(t) = (e^{-t} - e^{-2t+2})u(t-2)$$

**第三部分：求 $r_3(t) = e_3(t) * h(t)$**
冲激信号的卷积直接等于冲激响应的平移和缩放：


$$r_3(t) = \beta\delta(t-2) * h(t) = \beta h(t-2) = \beta e^{-2(t-2)}u(t-2) = \beta e^{-2t+4}u(t-2)$$

**合并总响应：**


$$r(t) = r_1(t) - r_2(t) + r_3(t)$$

$$r(t) = (e^{-t} - e^{-2t})u(t) - (e^{-t} - e^{-2t+2} - \beta e^{-2t+4})u(t-2)$$

#### **(2) 确定 $\beta$ 值使 $t > 2$ 时系统响应为零**

**已知激励信号：** $e(t) = x(t)[u(t) - u(t-2)] + \beta\delta(t-2)$

**物理概念分析（“消除状态”法）：**
在 $t > 2$ 时，输入信号 $x(t)[u(t) - u(t-2)]$ 已经结束。系统在 $t > 2$ 时的响应，完全是由 $t=2$ 时刻系统内部积累的“状态”（即零输入响应的初始值）决定的。
要想让 $t > 2$ 时响应彻底为 0，就必须利用 $t=2$ 时刻的冲激信号 $\beta\delta(t-2)$ 产生一个“相反的状态”，将系统之前积累的状态**瞬间抵消清零**。

**计算步骤：**
利用卷积积分公式，直接计算 $t > 2$ 时的总响应 $r(t)$，并令其等于 0。


$$r(t) = \int_{-\infty}^{\infty} e(\tau) h(t-\tau) \text{d}\tau \quad (t > 2)$$

代入 $e(\tau)$ 和 $h(t-\tau)$（因为 $t > 2$，且被积区间内 $t > \tau$，所以 $u(t-\tau) = 1$）：


$$r(t) = \int_{0}^{2} x(\tau) e^{-2(t-\tau)} \text{d}\tau + \int_{-\infty}^{\infty} \beta\delta(\tau-2) e^{-2(t-\tau)} \text{d}\tau$$

计算这两部分积分：
第一部分（$x(t)$ 积累的响应）：$e^{-2t} \int_{0}^{2} x(\tau) e^{2\tau} \text{d}\tau$
第二部分（冲激产生的响应）：$\beta e^{-2(t-2)} = \beta e^{-2t} e^{4}$

令总响应 $r(t) = 0$：


$$e^{-2t} \int_{0}^{2} x(\tau) e^{2\tau} \text{d}\tau + \beta e^{-2t} e^4 = 0$$

由于对于任意 $t$，指数项 $e^{-2t} \neq 0$，可以将其约掉：


$$\int_{0}^{2} x(\tau) e^{2\tau} \text{d}\tau + \beta e^4 = 0$$

解得 $\beta$：


$$\beta = -e^{-4} \int_{0}^{2} x(\tau) e^{2\tau} \text{d}\tau$$

**结论：** $\beta$ 的值必须是这样一个与 $x(t)$ 在 $[0, 2]$ 区间积分相关的表达式，才能确保系统产生的反向突变刚好抵消掉 $x(t)$ 注入系统的能量。
