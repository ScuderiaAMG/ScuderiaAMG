# 数据结构记忆背诵

## 图

以下是关于数据结构中图的基本概念和知识：

### 图的定义

图是由顶点（Vertex）集合和边（Edge）集合组成的数据结构，通常表示为\(G=(V,E)\)，其中\(G\)表示图，\(V\)是顶点的集合，\(E\)是边的集合。

### 图的存储结构

- **邻接矩阵**：用一个二维数组来表示图中顶点之间的邻接关系。对于无向图，邻接矩阵是对称的；对于有向图，邻接矩阵不一定对称。如果图中边带有权重，通常用一个特殊的值（如\(0\)或\(\infty\)）表示不存在边，其他值表示边的权重。

- **邻接表**：对图中的每个顶点建立一个链表，链表中的节点表示与该顶点相邻的顶点以及边的信息（如权重等）。对于有向图，每个顶点的链表存储的是该顶点的出边信息；对于无向图，每个顶点的链表存储的是与该顶点相连的边的信息。
  
  ### 图的遍历

- **深度优先搜索（DFS）**：从图中的某个顶点开始，沿着一条路径尽可能深地访问顶点，直到无法继续或访问完所有顶点，然后回溯到前一个顶点，继续探索其他路径，直到访问完所有顶点。

- **广度优先搜索（BFS）**：从图中的某个顶点开始，先访问该顶点的所有邻接顶点，然后再依次访问这些邻接顶点的邻接顶点，直到访问完所有顶点。
  
  ### 图的应用

- **最短路径问题**：如Dijkstra算法、Floyd算法等，用于在带权图中找到两个顶点之间的最短路径。

- **最小生成树问题**：如Prim算法、Kruskal算法等，用于在连通带权无向图中找到一棵最小生成树，即连接所有顶点且边权之和最小的树。

- **拓扑排序**：用于对有向无环图（DAG）中的顶点进行排序，使得对于图中的任意一条有向边\((u, v)\)，顶点\(u\)在排序中都出现在顶点\(v\)之前。常用于任务调度、课程安排等场景。

int search_depth(BTNode *T) {
    BTNode *Queue[MAX_NODE], *p = T;
    int front = 0, rear = 0, depth = 0, level;
    /*  level总是指向访问层的最后一个结点在队列的位置  */
    if (T != NULL) {
        Queue[++rear] = p;    /*   根结点入队  */
        level = rear;    /*  根是第1层的最后一个节点  */
        while (front < rear) {
            p = Queue[++front];
            if (p->Lchild != NULL)
                Queue[++rear] = p->Lchild;    /*   左结点入队  */
            if (p->Rchild != NULL)
                Queue[++rear] = p->Rchild;    /*   右结点入队  */
            if (front == level)  
                /*  正访问的是当前层的最后一个结点  */
            {
                depth++;
                level = rear;
            }
        }
    }
    return depth;
}

            }
        }

     p = p->next;
    }

// 8. 删除单链表中值重复的结点
ListNode* remove_duplicates(ListNode *L) {
    if (L == NULL) {
        return L;
    }
    ListNode *prev = L;
    ListNode *current = L->next;
    // 用于记录已经出现过的值
    int *visited = (int *)malloc(10000 * sizeof(int)); // 假设值的范围不太大，这里开辟一个足够大的数组
    for (int i = 0; i < 10000; i++) {
        visited[i] = 0;
    }
    visited[prev->val] = 1;
    while (current) {
        if (visited[current->val]) {
            prev->next = current->next;
            free(current);
            current = prev->next;
        } else {
            visited[current->val] = 1;
            prev = current;
            current = current->next;
        }
    }
    free(visited);
    return L;
}

int IndexString(StringType s, StringType t, int pos) {
    char *p, *q;

    list->Gdata.ptr.tp = tailList;
    return list;
}

// 获取广义表表头
GLNode* getHead(GLNode *list) {
    if (list == NULL || list->tag == 0) {
        return NULL;
    }
    return list->Gdata.ptr.hp;
}

// 获取广义表表尾
GLNode* getTail(GLNode *list) {
    if (list == NULL || list->tag == 0) {
        return NULL;
    }
    return list->Gdata.ptr.tp;
}

// 释放广义表内存
void freeGeneralizedList(GLNode *list) {
    if (list == NULL) {
        return;
    }
    if (list->tag == 0) {
        free(list);
    } else {
        freeGeneralizedList(list->Gdata.ptr.hp);
        freeGeneralizedList(list->Gdata.ptr.tp);
        free(list);
    }
}
