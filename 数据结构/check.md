def newton_divided_difference(x, y):
    n = len(x)
    table = [[0 for _ in range(n)] for _ in range(n)]
    for i in range(n):
        table[i][0] = y[i]
    for j in range(1, n):
        for i in range(n - j):
            table[i][j] = (table[i + 1][j - 1] - table[i][j - 1]) / (x[i + j] - x[i])
    return table

x = [1, 2, 3, 4, 5]
y = [1, 4, 7, 8, 6]
table = newton_divided_difference(x, y)
for row in table:
    print(row)

为了求出这五个数据点 $(1,1), (2,4), (3,7), (4,8), (5,6)$ 的四次牛顿插值多项式，我们需要先构造**牛顿均差（差商）表**。

牛顿插值多项式的基本公式为：


$$N(x) = f[x_0] + f[x_0, x_1](x - x_0) + f[x_0, x_1, x_2](x - x_0)(x - x_1) + \dots + f[x_0, \dots, x_n](x - x_0)\dots(x - x_{n-1})$$

### 第一步：计算均差（差商）表

根据均差的定义 $f[x_i, x_{i+1}] = \frac{y_{i+1} - y_i}{x_{i+1} - x_i}$，依次计算各阶均差：

| $x_i$ | 零阶均差 $f(x_i)$ | 一阶均差 | 二阶均差 | 三阶均差 | 四阶均差 |
| --- | --- | --- | --- | --- | --- |
| **1** | **1** |  |  |  |  |
|  |  | $\frac{4-1}{2-1} = \mathbf{3}$ |  |  |  |
| 2 | 4 |  | $\frac{3-3}{3-1} = \mathbf{0}$ |  |  |
|  |  | $\frac{7-4}{3-2} = 3$ |  | $\frac{-1-0}{4-1} = \mathbf{-\frac{1}{3}}$ |  |
| 3 | 7 |  | $\frac{1-3}{4-2} = -1$ |  | $\frac{-\frac{1}{6}-(-\frac{1}{3})}{5-1} = \mathbf{\frac{1}{24}}$ |
|  |  | $\frac{8-7}{4-3} = 1$ |  | $\frac{-1.5-(-1)}{5-2} = -\frac{1}{6}$ |  |
| 4 | 8 |  | $\frac{-2-1}{5-3} = -1.5$ |  |  |
|  |  | $\frac{6-8}{5-4} = -2$ |  |  |  |
| 5 | 6 |  |  |  |  |

从表格的第一行（加粗部分），我们可以提取出牛顿插值多项式所需的各项系数：

* $f[x_0] = 1$
* $f[x_0, x_1] = 3$
* $f[x_0, x_1, x_2] = 0$
* $f[x_0, x_1, x_2, x_3] = -\frac{1}{3}$
* $f[x_0, x_1, x_2, x_3, x_4] = \frac{1}{24}$

---

### 第二步：写出牛顿插值多项式

将这些系数代入公式中，其中 $x_0=1, x_1=2, x_2=3, x_3=4$，得到四次牛顿插值多项式：

$$N_4(x) = 1 + 3(x - 1) + 0(x - 1)(x - 2) - \frac{1}{3}(x - 1)(x - 2)(x - 3) + \frac{1}{24}(x - 1)(x - 2)(x - 3)(x - 4)$$

化简去掉零项后，得到**标准的牛顿插值形式**：


$$N_4(x) = 1 + 3(x - 1) - \frac{1}{3}(x - 1)(x - 2)(x - 3) + \frac{1}{24}(x - 1)(x - 2)(x - 3)(x - 4)$$

---

### 第三步：展开为标准多项式（可选）

如果你需要将其完全展开为 $ax^4 + bx^3 + cx^2 + dx + e$ 的形式，我们将每一项展开合并同类项：

$$N_4(x) = \frac{1}{24}x^4 - \frac{3}{4}x^3 + \frac{83}{24}x^2 - \frac{11}{4}x + 1$$

这也是最终唯一确定穿过这五个点的四次多项式方程。
