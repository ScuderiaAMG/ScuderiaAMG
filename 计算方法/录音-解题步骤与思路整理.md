# 《计算方法》录音整理：解题步骤与复习思路

> 来源：`录音.md`。原稿是课堂录音转写，存在少量识别错误；本整理按上下文将明显错词校正为常用术语，并保留老师强调的考点、题型和做题顺序。

## 0. 总体复习思路

1. 本课程期末更像“按章节核心知识点出大题”，不是高考式技巧题。
2. 每道大题通常对应一个章节或一个核心方法，分值约 10 分或十几分。
3. 复习重点应放在中等难度、能覆盖知识点的题型上。
4. 不能只背定义，要能按规范步骤计算：建模、列式、判断条件、代入求解、检查误差或收敛。
5. 老师明确提到“几乎必考”或“大概率考”的内容包括：
   - 误差、有效数字、误差传播；
   - 插值与数据拟合，尤其最小二乘；
   - 数值积分中的高斯求积、Romberg 积分、代数精度；
   - 常微分方程数值解中的改进欧拉法；
   - 非线性方程求根中的二分法、不动点迭代、牛顿法；
   - 线性方程组中的高斯消元、选主元、Jacobi、Gauss-Seidel、SOR 收敛判断。

## 1. 误差部分

### 1.1 考查重点

误差是必考内容，占分不会低。录音中特别强调：算法能不能用，关键看误差大小。

重点包括：

1. 绝对误差、相对误差、误差来源。
2. 有效数字的定义及其与误差限的关系。
3. 一元函数和多元函数的误差传播。
4. 算法设计中如何减少误差传播。

收敛性、稳定性在第一章里只是给定义，录音判断不太会在这里单独出题，因为后续章节会反复用到。

### 1.2 有效数字题的解题步骤

1. 明确近似值 `x*` 和真值 `x` 或误差限。
2. 写出绝对误差：
   \[
   e = x^* - x,\quad |e| = |x^* - x|
   \]
3. 写出相对误差：
   \[
   e_r = \frac{e}{x},\quad |e_r| \approx \frac{|e|}{|x^*|}
   \]
4. 根据有效数字定义判断有效位数。
   常用判断思路是：若近似数从第一位非零数字起有 `n` 位有效数字，则其绝对误差限应不超过该位末位单位的一半。
5. 若题目给的是科学计数法形式，先找到首个非零数字所在位，再判断末位有效数字的数量级。
6. 最后把有效数字位数、绝对误差限、相对误差限对应起来，不要只单独计算其中一个量。

易错点：

1. 不要把小数位数直接等同于有效数字位数。
2. `0` 在首个非零数字前不是有效数字，在首个非零数字后通常参与有效数字判断。
3. 题目常把有效数字、绝对误差、相对误差合在一起考，不太会只问一个定义。

### 1.3 误差传播题的解题步骤

设
\[
y=f(x_1,x_2,\cdots,x_n)
\]
且各输入量有误差 \(\Delta x_i\)。

1. 写出函数关系 `y = f(...)`。
2. 对函数求全微分：
   \[
   \Delta y \approx \sum_{i=1}^{n}\frac{\partial f}{\partial x_i}\Delta x_i
   \]
3. 若求误差限，取绝对值上界：
   \[
   |\Delta y| \le \sum_{i=1}^{n}\left|\frac{\partial f}{\partial x_i}\right| |\Delta x_i|
   \]
4. 若题目是加、减、乘、除的简单形式，可直接套对应传播规律；若较复杂，用偏导或全微分统一处理。
5. 最后根据题目要求给出绝对误差限或相对误差限。

注意点：

1. 多元函数误差传播是重点，因为实际数据处理都是输入变量经过函数得到输出结果。
2. 录音中反复强调“求偏导”是通用方法。
3. 题目可能考“误差线/误差限”的估计，核心仍是偏导上界。

### 1.4 减少误差的算法设计原则

1. 避免两个相近数相减，否则会造成有效数字大量损失。
2. 乘除运算中避免分母过小，否则误差会被放大。
3. 计算机存储位数有限，舍入误差无法避免，所以要从公式设计上降低误差传播。

## 2. 插值与数据拟合

### 2.1 总体判断

本章包含插值和曲线拟合。录音特别强调：数据拟合、最小二乘法是必考方向，因为实际问题中大量使用拟合算法进行数据建模和优化。

插值部分可能考：

1. Lagrange 插值。
2. Newton 插值。
3. 分段插值或样条插值。

录音判断：

1. Lagrange 和 Newton 都可能考，表达不同但本质都在构造插值多项式。
2. 样条插值工程上常用，但方程组复杂，出题可能性相对较低；若考，通常会给出较多公式。
3. Newton 插值的重点是构造差商表。
4. Lagrange 插值的重点是构造基函数并求插值多项式。

### 2.2 Lagrange 插值题步骤

给定节点 \((x_i,y_i)\)，要求插值多项式。

1. 写出 Lagrange 基函数：
   \[
   l_i(x)=\prod_{j\ne i}\frac{x-x_j}{x_i-x_j}
   \]
2. 写出插值多项式：
   \[
   L_n(x)=\sum_{i=0}^{n}y_i l_i(x)
   \]
3. 若题目要求某点函数值，直接代入 \(x\)。
4. 若题目要求某项系数，先展开或只提取对应次数项。
5. 若题目要求误差项，写：
   \[
   R_n(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^{n}(x-x_i)
   \]
   再按题目给出的导数上界估计。

易错点：

1. 基函数分母是 \(x_i-x_j\)，不要写反。
2. 每个 \(l_i(x)\) 在 \(x_i\) 处为 1，在其他节点处为 0。
3. 若只求某点值，不必完全展开多项式。

### 2.3 Newton 插值题步骤

1. 按节点顺序列差商表。
2. 计算一阶差商：
   \[
   f[x_i,x_{i+1}]=\frac{f(x_{i+1})-f(x_i)}{x_{i+1}-x_i}
   \]
3. 继续计算高阶差商：
   \[
   f[x_i,\cdots,x_{i+k}]
   =
   \frac{f[x_{i+1},\cdots,x_{i+k}]-f[x_i,\cdots,x_{i+k-1}]}
   {x_{i+k}-x_i}
   \]
4. 写 Newton 插值多项式：
   \[
   P_n(x)=f[x_0]+f[x_0,x_1](x-x_0)+\cdots+
   f[x_0,\cdots,x_n]\prod_{j=0}^{n-1}(x-x_j)
   \]
5. 代入求值或展开求系数。

易错点：

1. 差商表一错，后面全部错。
2. Newton 插值和 Lagrange 插值结果相同，只是表达形式不同。
3. 新增节点时 Newton 形式更方便。

### 2.4 样条插值与分段插值

录音中的判断是：样条插值很重要，但工程实现和方程组构造较复杂，考试不太可能深挖。若考，通常会给出公式或降低计算量。

复习时至少掌握：

1. 样条插值是分段多项式插值。
2. 三次样条通常要求函数值、一次导数、二次导数在节点处满足连续条件。
3. 解题核心是根据边界条件和连续条件建立方程组。
4. 若题目给出公式，按公式代入即可，不要重新推导复杂方程组。

### 2.5 最小二乘拟合题步骤

最小二乘法是本章最核心的必考内容之一。

#### 线性模型

若假设模型为
\[
y=a+bx
\]

1. 根据数据点 \((x_i,y_i)\) 建立残差：
   \[
   r_i=y_i-(a+bx_i)
   \]
2. 建立目标函数，即误差平方和：
   \[
   S(a,b)=\sum_i [y_i-(a+bx_i)]^2
   \]
3. 对每个待定参数求偏导并令其为 0：
   \[
   \frac{\partial S}{\partial a}=0,\quad
   \frac{\partial S}{\partial b}=0
   \]
4. 得到正规方程组。
5. 解方程组得到 \(a,b\)。
6. 写出拟合函数并按题目要求求预测值或误差。

#### 多项式模型

若模型为
\[
y=a_0+a_1x+\cdots+a_mx^m
\]

1. 建立平方误差和：
   \[
   S=\sum_i\left(y_i-\sum_{j=0}^{m}a_jx_i^j\right)^2
   \]
2. 对每个 \(a_j\) 求偏导并令 0。
3. 得到关于 \(a_0,\cdots,a_m\) 的线性方程组。
4. 解出参数。

#### 超定方程组

录音提到超定方程组也可由最小二乘法处理。

若写成矩阵形式：
\[
Ax\approx b
\]
则正规方程为：
\[
A^TAx=A^Tb
\]

解题时直接列出并求解即可。

#### 非线性模型

若模型对参数不是线性的，如指数模型：
\[
y=ae^{bx}
\]
直接最小二乘会很麻烦。可先作变换：
\[
\ln y=\ln a + bx
\]
令 \(Y=\ln y,\ A=\ln a\)，转化为线性模型：
\[
Y=A+bx
\]
求出 \(A,b\) 后，再还原：
\[
a=e^A
\]

录音强调：关键是让求偏导后能转化为线性方程组；若参数非线性，要想办法变换。

## 3. 数值积分

### 3.1 总体重点

数值积分内容不算太多，但题型清楚。重点包括：

1. 高斯求积公式。
2. Romberg 积分。
3. Simpson 公式、Newton-Cotes 类公式。
4. 代数精度。

### 3.2 高斯求积题步骤

录音判断：高斯求积理论难，但考试题一般不难，因为节点和系数通常会给出。

1. 看积分区间是否为标准区间 \([-1,1]\)。
2. 若不是，作变量替换：
   \[
   x=\frac{b-a}{2}t+\frac{a+b}{2},\quad dx=\frac{b-a}{2}dt
   \]
   将
   \[
   \int_a^b f(x)\,dx
   \]
   化为
   \[
   \frac{b-a}{2}\int_{-1}^{1}f\left(\frac{b-a}{2}t+\frac{a+b}{2}\right)\,dt
   \]
3. 使用题目给出的 Gauss 节点 \(t_i\) 和权重 \(A_i\)：
   \[
   \int_{-1}^{1}g(t)\,dt \approx \sum_i A_i g(t_i)
   \]
4. 代入计算。
5. 若问精度，说明 Gauss 求积代数精度高；`n` 个节点的 Gauss-Legendre 公式通常具有 \(2n-1\) 次代数精度。

易错点：

1. 区间变换后的系数 \((b-a)/2\) 不要漏。
2. 节点是标准区间上的点，不能直接当原区间的点用。
3. 题目若给 Legendre 多项式零点和求积系数，直接代入即可。

### 3.3 Romberg 积分题步骤

Romberg 积分属于中等偏上难度，计算量较大，容易连锁出错。

1. 从复化梯形公式开始，计算第一列：
   \[
   T_1,T_2,T_4,\cdots
   \]
   下标通常表示区间等分数逐次加倍。
2. 利用梯形递推，避免重复计算旧节点：
   \[
   T_{2n}=\frac12 T_n+h_{2n}\sum f(\text{新增节点})
   \]
3. 使用外推思想提高精度。因为梯形公式误差主项为 \(O(h^2)\)，步长减半后误差约变为原来的 \(1/4\)。
4. 构造 Romberg 表：
   \[
   R_{k,0}=T_{2^k}
   \]
   \[
   R_{k,j}=R_{k,j-1}+\frac{R_{k,j-1}-R_{k-1,j-1}}{4^j-1}
   \]
5. 按表格从左到右、从上到下递推。
6. 最后取最高阶外推值作为积分近似。

易错点：

1. 第一列错一个，后面全错。
2. 新增节点不要重复计算。
3. 外推分母是 \(4^j-1\)，不要写成 \(2^j-1\)。
4. 录音建议多手算几次，不练只看理论会出错。

### 3.4 Simpson 与 Newton-Cotes

需要记住常见系数。

1. Simpson 公式常见形式：
   \[
   \int_a^b f(x)\,dx
   \approx
   \frac{b-a}{6}\left[f(a)+4f\left(\frac{a+b}{2}\right)+f(b)\right]
   \]
   系数可看作 \(1/6,4/6,1/6\)。
2. 录音还提到类似 \(1/4,1/2,1/4\) 的系数形式，复习时应结合课堂公式确认对应公式。
3. 单纯梯形或简单公式精度不高，但作为 Romberg 外推的基础很重要。

### 3.5 代数精度题步骤

代数精度是数值积分的重要概念，也是推导求积公式的常用工具。

求积公式：
\[
\int_a^b f(x)\,dx \approx \sum_{i=1}^{n}A_i f(x_i)
\]

若它对所有次数不超过 \(m\) 的多项式都精确成立，而对 \(m+1\) 次多项式不精确，则代数精度为 \(m\)。

解题步骤：

1. 假设待定节点或权重为未知量。
2. 令 \(f(x)=1,x,x^2,\cdots\) 依次代入。
3. 让精确积分值等于求积公式值。
4. 有多少未知量，一般至少列多少个方程。
5. 解线性方程组得到节点或系数。
6. 继续代入下一次幂，验证最高能精确到几次。

易错点：

1. 不要只列一个方程。
2. 若节点和权重都未知，要把它们都算作未知量。
3. 录音提到的“3 个节点中有些节点或系数待求”属于典型题，核心仍是用代数精度条件列方程。

## 4. 常微分方程数值解

### 4.1 总体判断

录音认为这部分是较难的一章，但考试不会要求非常复杂的推导。最常考、最首选的是改进欧拉法。

难点在于：

1. 从积分形式推导迭代公式时会出现隐式项。
2. 泰勒展开、多元函数展开复杂。
3. 高阶方程或方程组要先转化。

考试大概率不会深挖复杂推导，而是考规范套用。

### 4.2 改进欧拉法题步骤

对初值问题：
\[
y'=f(x,y),\quad y(x_0)=y_0
\]
步长为 \(h\)。

1. 先用显式欧拉法预测：
   \[
   \bar y_{n+1}=y_n+h f(x_n,y_n)
   \]
2. 再用梯形/后退思想校正：
   \[
   y_{n+1}=y_n+\frac{h}{2}
   \left[
   f(x_n,y_n)+f(x_{n+1},\bar y_{n+1})
   \right]
   \]
3. 每一步按“预测值 → 校正值”的顺序计算。
4. 更新 \(x_{n+1}=x_n+h\)，继续下一步。

易错点：

1. 预测值 \(\bar y_{n+1}\) 和校正值 \(y_{n+1}\) 不要混淆。
2. 计算 \(f(x_{n+1},\bar y_{n+1})\) 时，第二个参数用预测值。
3. 改进欧拉法可理解为前进欧拉与后退/梯形思想的结合。

### 4.3 高阶方程处理

若题目给高阶微分方程，先化为一阶方程组。

例如：
\[
y''=g(x,y,y')
\]
令：
\[
u_1=y,\quad u_2=y'
\]
则：
\[
u_1'=u_2,\quad u_2'=g(x,u_1,u_2)
\]
再对一阶方程组套用改进欧拉法或题目指定方法。

## 5. 非线性方程求根

### 5.1 总体重点

录音明确提到本部分考点多，重点复习：

1. 二分法。
2. 不动点迭代法。
3. 牛顿迭代法。

还包括：

1. 不动点迭代的加速方法。
2. 割线法、抛物线法等近似方法。
3. 重根情况下牛顿法的修正。
4. 带阻尼/下降因子的牛顿法。

### 5.2 二分法题步骤

1. 找区间 \([a,b]\)，满足：
   \[
   f(a)f(b)<0
   \]
2. 取中点：
   \[
   c=\frac{a+b}{2}
   \]
3. 判断根在哪个子区间：
   - 若 \(f(a)f(c)<0\)，取 \([a,c]\)；
   - 若 \(f(c)f(b)<0\)，取 \([c,b]\)；
   - 若 \(f(c)=0\)，直接得到根。
4. 重复直到满足精度要求。
5. 若题目问至少迭代多少次，用误差估计：
   \[
   \frac{b-a}{2^n}\le \varepsilon
   \]
   或按教材版本使用半区间误差：
   \[
   \frac{b-a}{2^{n+1}}\le \varepsilon
   \]
6. 取对数求 \(n\)，向上取整。

录音强调：题目可能给 log 值，减少计算量；要会用 \(2^n\) 相关公式算精度。

### 5.3 不动点迭代题步骤

把方程 \(f(x)=0\) 改写为：
\[
x=\varphi(x)
\]
迭代格式：
\[
x_{k+1}=\varphi(x_k)
\]

1. 构造迭代函数 \(\varphi(x)\)。
2. 选初值 \(x_0\)。
3. 判断收敛性。常用条件：
   \[
   |\varphi'(x)|\le q<1
   \]
   在相关区间内成立。
4. 若满足收敛条件，开始迭代。
5. 停止条件常用：
   \[
   |x_{k+1}-x_k|<\varepsilon
   \]
6. 若题目要求误差估计，可用教材给出的不动点迭代误差公式。

易错点：

1. 迭代格式不唯一，不同格式收敛性不同。
2. 不能只构造格式就计算，应先判断收敛。
3. 初值附近导数绝对值小于 1 是常用判断依据。
4. 二分法和普通不动点迭代通常是一阶线性收敛。

### 5.4 不动点迭代加速

录音提到通过引入系数调节迭代格式，使新格式在根附近导数绝对值小于 1，从而改善收敛。

通用理解：

1. 原迭代格式可能为：
   \[
   x_{k+1}=\varphi(x_k)
   \]
2. 可构造加权或松弛形式：
   \[
   x_{k+1}=(1-\lambda)x_k+\lambda\varphi(x_k)
   \]
3. 通过选择 \(\lambda\) 使新迭代函数满足收敛条件，甚至提高收敛速度。
4. 录音还提到“预测—校正”式思路，与后面 Gauss-Seidel、松弛法中的加速思想相通。

### 5.5 Newton 法题步骤

Newton 迭代公式必须记住：
\[
x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}
\]

解题步骤：

1. 写出 \(f(x)\)。
2. 求导得到 \(f'(x)\)。
3. 写出 Newton 迭代格式。
4. 选择初值，尽量靠近目标根。
5. 必要时判断收敛性；Newton 法可视为特殊不动点迭代。
6. 逐步代入计算，直到满足：
   \[
   |x_{k+1}-x_k|<\varepsilon
   \]
   或题目指定条件。
7. 给出近似根。

注意点：

1. Newton 法通常二阶收敛，速度快。
2. 初值选择不好可能发散或收敛到其他根。
3. 题目通常只需正确求导并套公式，但规范做法仍应先判断再计算。
4. 有时还需要求二阶导数，用于收敛性分析。

### 5.6 重根 Newton 法

若 \(\alpha\) 是 \(m\) 重根，普通 Newton 法在根附近收敛会变慢。

录音强调的结论：

1. 非重根时 Newton 法二阶收敛。
2. 重根时迭代函数在根处导数为：
   \[
   \varphi'(\alpha)=1-\frac{1}{m}
   \]
   不等于 0，因此收敛阶降低。

两种改进方法：

1. 若已知重数 \(m\)，使用修正 Newton 法：
   \[
   x_{k+1}=x_k-m\frac{f(x_k)}{f'(x_k)}
   \]
2. 构造单根函数，例如：
   \[
   u(x)=\frac{f(x)}{f'(x)}
   \]
   再对 \(u(x)=0\) 使用 Newton 法。

### 5.7 割线法、抛物线法与阻尼思想

1. 割线法用差商近似导数，减少直接求导：
   \[
   x_{k+1}=x_k-
   f(x_k)\frac{x_k-x_{k-1}}{f(x_k)-f(x_{k-1})}
   \]
2. 抛物线法用二次插值逼近函数，思想是用更高阶近似找根。
3. 阻尼 Newton 法或下降因子法通过引入 \(\lambda\) 控制步长：
   \[
   x_{k+1}=x_k-\lambda\frac{f(x_k)}{f'(x_k)}
   \]
   其中 \(0<\lambda\le 1\)。
4. 若全步长 \(\lambda=1\) 导致效果不好，就减小 \(\lambda\)，保证函数值下降，例如要求：
   \[
   |f(x_{k+1})|<|f(x_k)|
   \]

## 6. 线性方程组求解

### 6.1 总体框架

本部分分为两类：

1. 直接法：有限步内求解。
   - 高斯消元法；
   - 选主元消元法；
   - Gauss-Jordan 消元法；
   - LU 分解；
   - Doolittle 分解；
   - Crout 分解；
   - Cholesky 平方根法；
   - 追赶法。
2. 迭代法：通过迭代逼近。
   - Jacobi 法；
   - Gauss-Seidel 法；
   - SOR 松弛法。

### 6.2 高斯消元法步骤

对方程组：
\[
Ax=b
\]

1. 写增广矩阵 \([A|b]\)。
2. 从第一列开始选主元。
3. 计算消元因子：
   \[
   m_{ik}=\frac{a_{ik}}{a_{kk}}
   \]
4. 用第 \(k\) 行消去下面各行的第 \(k\) 列元素。
5. 重复，直到系数矩阵化为上三角矩阵。
6. 回代求解：
   \[
   x_n,\ x_{n-1},\cdots,x_1
   \]
7. 检查是否出现无解或主元为 0 的异常情况。

易错点：

1. 消元因子符号和行变换顺序要一致。
2. 回代时从最后一个未知数开始。
3. 若主元很小，直接消元会放大误差。

### 6.3 选主元消元法

使用原因：计算机精度有限，当系数数量级差异大时，小数可能被舍去，导致结果偏差很大。因此要选绝对值较大的主元，降低舍入误差影响。

#### 列主元/部分主元法

1. 在当前列从当前行往下找绝对值最大的元素。
2. 将该元素所在行换到主元行。
3. 再按高斯消元步骤继续。

这是实际中常用的方法，因为只换行，不需要改变变量顺序。

#### 全主元法

1. 在当前剩余矩阵中找绝对值最大的元素。
2. 需要行交换和列交换。
3. 列交换会改变未知量顺序，最后必须把变量下标换回来。
4. 计算量最大，过程复杂，容易出错。

#### 标准化主元法

录音还提到一种介于全主元和部分主元之间的方法：按行中最大元素作尺度比较，避免不同数量级造成误判。复习时按教材中的“标准化列主元”或“按比例选主元”公式掌握。

### 6.4 Gauss-Jordan 消元法

1. 将增广矩阵继续化到左侧为单位矩阵：
   \[
   [A|b]\to[I|x]
   \]
2. 可直接读出解。
3. 也可用于求逆矩阵：
   \[
   [A|I]\to[I|A^{-1}]
   \]
4. 录音指出该方法直观，但计算复杂度较高，一般不作为主要求解方法。

### 6.5 三角分解与特殊矩阵方法

高斯消元的本质可以看作三角分解：
\[
A=LU
\]

1. Doolittle 分解：通常取 \(L\) 为单位下三角矩阵。
2. Crout 分解：通常取 \(U\) 为单位上三角矩阵。
3. Cholesky 平方根法：用于对称正定矩阵。
4. 追赶法：用于三对角线性方程组。

解题通用流程：

1. 判断矩阵类型。
2. 选择对应分解方法。
3. 先解：
   \[
   Ly=b
   \]
4. 再解：
   \[
   Ux=y
   \]
5. 对三对角方程组，按追赶法递推系数再回代。

录音说明：这部分公式较复杂，课堂上主要作为理解；若考试涉及，通常会给出公式或具体数字。

## 7. 线性方程组迭代法

### 7.1 Jacobi 法

设：
\[
Ax=b
\]
将每个方程解出对应未知量：
\[
x_i^{(k+1)}
=
\frac{1}{a_{ii}}
\left(
b_i-\sum_{j\ne i}a_{ij}x_j^{(k)}
\right)
\]

步骤：

1. 将方程组整理为 Jacobi 迭代格式。
2. 选初始向量 \(x^{(0)}\)。
3. 第 \(k+1\) 轮中，每个分量都只使用第 \(k\) 轮旧值。
4. 计算到满足误差要求。

易错点：

1. Jacobi 法一轮内不能使用刚算出的新值。
2. 可用两个表格分别存旧值和新值。

### 7.2 Gauss-Seidel 法

Gauss-Seidel 法使用已经算出的新值：
\[
x_i^{(k+1)}
=
\frac{1}{a_{ii}}
\left(
b_i
-\sum_{j<i}a_{ij}x_j^{(k+1)}
-\sum_{j>i}a_{ij}x_j^{(k)}
\right)
\]

步骤：

1. 整理每个未知量的迭代公式。
2. 从 \(x_1\) 开始依次计算。
3. 当前轮已经得到的新值，立即用于后面的分量。
4. 继续迭代直到满足精度。

录音强调：

1. Gauss-Seidel 一般比 Jacobi 快。
2. 判断迭代矩阵时，必须先把公式整理成“左边全是 \(x^{(k+1)}\)，右边全是 \(x^{(k)}\)”的标准形式。
3. 不能看到矩阵就直接代入，要先确认它到底是不是迭代矩阵。

### 7.3 迭代矩阵与收敛判断

标准迭代形式：
\[
x^{(k+1)}=Bx^{(k)}+f
\]

收敛核心条件：
\[
\rho(B)<1
\]
其中 \(\rho(B)\) 是迭代矩阵 \(B\) 的谱半径，即全部特征值模的最大值。

解题步骤：

1. 先从迭代公式中整理出 \(B\)。
2. 求特征值：
   \[
   \det(\lambda I-B)=0
   \]
3. 计算每个特征值的模。
4. 取最大模，得到谱半径：
   \[
   \rho(B)=\max_i|\lambda_i|
   \]
5. 若 \(\rho(B)<1\)，迭代收敛；否则不保证收敛或发散。

常用充分条件：

\[
\|B\|<1 \Rightarrow \rho(B)<1
\]

注意点：

1. 矩阵范数不等于谱半径。
2. 对称矩阵等特殊情况可利用特征值性质简化。
3. 录音提到谱半径概念以前考过，大概率要掌握。

### 7.4 SOR 松弛法

SOR 是在 Gauss-Seidel 基础上加入松弛因子 \(\omega\)，用来调节收敛速度。

一般思想：

1. 先得到 Gauss-Seidel 的新估计值。
2. 再与旧值加权：
   \[
   x_i^{(k+1)}
   =
   (1-\omega)x_i^{(k)}
   +
   \omega \cdot \text{Gauss-Seidel 新值}
   \]
3. 写成标准迭代形式：
   \[
   x^{(k+1)}=B_\omega x^{(k)}+f_\omega
   \]
4. 求 \(B_\omega\) 的谱半径。
5. 通过 \(\rho(B_\omega)<1\) 判断收敛。
6. 若题目要求最优 \(\omega\)，比较不同 \(\omega\) 下谱半径大小，取使谱半径最小者。

录音中特别提醒：

1. SOR 中不能把原系数矩阵 \(A\) 直接当迭代矩阵 \(B\)。
2. 必须先把 \(x^{(k+1)}\) 和 \(x^{(k)}\) 的系数整理清楚，再提取迭代矩阵。
3. 某个课堂例题中得到 \(\omega=0.5\) 时谱半径最小，但具体题目必须按给定矩阵重新推导。
4. 若涉及绝对值大小比较，可画出直线或曲线辅助判断，比逐段口头讨论更清楚。

## 8. 录音中的考点强弱汇总

### 8.1 强烈建议重点练

1. 有效数字、绝对误差、相对误差综合题。
2. 多元函数误差传播。
3. Lagrange 插值与 Newton 差商插值。
4. 最小二乘拟合，尤其正规方程。
5. 高斯求积的区间变换与代入。
6. Romberg 积分表。
7. 代数精度求节点或系数。
8. 改进欧拉法。
9. 二分法迭代次数与精度估计。
10. 不动点迭代收敛判断。
11. Newton 法及重根修正。
12. 高斯消元与选主元。
13. Jacobi、Gauss-Seidel、SOR 迭代矩阵和收敛判断。

### 8.2 了解即可或出题可能较低

1. 第一章中单独考收敛性、稳定性定义。
2. 样条插值的复杂方程组推导。
3. 常微分方程数值解中的复杂泰勒展开推导。
4. 线性方程组中复杂三角分解公式的完整推导。
5. 最后涉及问题本身静态误差信息的内容，录音认为一般不会在计算题中深入。

## 9. 做题时的统一检查清单

1. 先判断题型属于哪一章、哪一类方法。
2. 写出已知量、未知量和目标。
3. 若是拟合、积分、迭代、方程组，先写标准公式。
4. 若需要收敛判断，先判断再计算。
5. 若需要构造表格，如差商表、Romberg 表、迭代表，表格第一列必须算准。
6. 若出现矩阵，先确认它是原系数矩阵、分解矩阵，还是迭代矩阵。
7. 若出现参数，如 \(\lambda\)、\(\omega\)，不要直接套旧例题结论，应按本题重新推导。
8. 最后检查精度要求、有效位数、误差限、停止条件是否都满足。
