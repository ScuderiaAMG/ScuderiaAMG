## 一、先把概念讲清楚

### 这门课到底在学什么？

想象你是一个工程师，需要设计一座大桥。在真正动工之前，你会先用数学公式计算桥的受力情况。但问题来了——这些数学公式往往非常复杂，比如要算一个高次方程的根、一个复杂的积分，或者解一个大型方程组。你用手算？可能算到退休都算不完。

**计算方法（数值分析）** 就是教你怎么用计算机来求解这些数学问题。它的核心思想是：**把复杂的数学运算转化为计算机最擅长的加减乘除运算**。

### 为什么要学这个？

打个比方：你要知道一个水池里有多少水。你有三个办法：
1. **理论分析** -- 用流体力学公式推导（太复杂，现实往往不完美）
2. **做实验** -- 拿桶一桶一桶舀（耗时、成本高）
3. **计算模拟** -- 用计算机模拟（省钱、省时、可重复）

计算方法就是第三种手段的理论基础。它已经成为继理论分析和科学实验之后的**第三种科学研究手段**。

### 核心概念：误差

说到"计算"，你可能会想：计算机不是很精确吗？错！计算机有两大限制：

1. **存储有限**：计算机用有限个二进制位存数字，比如 $\pi = 3.1415926535\ldots$ 在计算机里只能存到某一位，后面的被截断了

2. **浮点运算不精确**：在数学上 $1 \div 3 \times 3 = 1$，但在计算机里 $1.0 / 3.0 \times 3.0$ 可能不等于 $1.0$！

这就是为什么我们要学习误差分析：**数学上的等价在计算机上不一定等效**。

### 实际问题求解流程

实际问题求解的闭环流程：

```
实际应用问题 → 数学模型 → 计算模型 → 计算实现 → 实际应用
                 ↑                                |
                 └────────── 修正 ←──────────────┘
```

- **应用问题**：工程或科学中的实际问题
- **数学模型**：用数学语言描述问题（微积分、线性代数等）
- **计算模型**：设计数值算法（计算方法的核心内容）
- **计算实现**：用编程语言（Python、MATLAB等）实现
- **教学理念**：采用**问题引领教学法**，从实际问题求解流程来设计教学

### 课程核心概念
- **核心手段**：将复杂运算转化为加减乘除运算
- **计算结果**：数值解（近似解）
- **重要概念**：误差

### 误差的重要性 -- 代码示例

```cpp
// 错误做法：直接比较浮点数
double x = 1.0;
double y = x/3.0;
if (x == y*3.0)    cout << "They are equal!";
else               cout << "They are NOT equal.";

// 正确做法：引入误差容忍度
double x = 1.0;
double y = x/3.0;
if (fabs(x-y*3.0) < epsilon)    cout << "They are equal!";
else                            cout << "They are NOT equal.";
```

**核心教训**：数学上的等价在计算机上不一定等效！

### 误差实例 -- 解二元一次方程组

方程组：
$$
\begin{cases}
x + 10^5 y = 10^5 \\
x + y = 2
\end{cases}
$$

准确解：
$$
\begin{cases}
x = \frac{200000 - 2}{99999} = 1.00001\ldots \\
y = \frac{99998}{99999} = 0.99998\ldots
\end{cases}
$$

计算机求解过程（保留小数点后5位有效数字，四舍五入）：
1. 方程(1)两边乘以 $1.00000 \times 10^5$，得到新的方程组
2. 方程(1) $-$ 方程(2)
3. 解得 $y = 4.99998 \times 10^{-1}$，带入方程(1)和方程(2)得到不同的 $x$

**说明**：由于舍入误差的存在，不同的求解路径会得到不同的结果。

### 计算方法的内涵
- 数值计算与仿真已成为**第三种科学研究手段**（继理论分析和科学实验之后）
- 用计算模拟代替耗时、高成本的实验
- 为各种数学问题的数值解答研究提供最有效的算法，要求：
  - **理论可靠**：稳定性、收敛（快慢）性
  - **计算复杂性好**：时间、存储开销
  - **计算机上可实现**：有限（可操作）性

### 计算机的发展与计算方法的发展
- 计算机软、硬件的发展为计算方法的实现提供环境，也促进其快速发展
- 好的计算方法（如快速多极值法）可集成到硬件、芯片中
- 计算方法已成为理工科、社会科学等专业人才必备知识和工具
- 计算机有极限有瓶颈，但计算方法的发展是无止境的

## 三、做题方法

### 总体方法论

计算方法课程的学习遵循以下路径：

```
识别实际问题类型
      ↓
建立数学模型
      ↓
选择/设计数值算法
      ↓
分析算法性质（收敛性、稳定性、复杂度）
      ↓
编程实现
      ↓
误差分析与结果验证
```

### 对误差的基本认识

在数值计算中，误差无处不在：

| 误差类型 | 来源 | 可否避免 |
|---------|------|---------|
| 模型误差 | 实际问题抽象为数学模型时的简化 | 不可避免，但可减小 |
| 观测误差 | 测量参数时的仪器误差 | 不可避免，但可减小 |
| 截断误差（方法误差） | 用有限项近似无限过程 | 不可避免，但可控制 |
| 舍入误差 | 计算机字长有限 | 不可避免，但可分析 |

### 程序设计中的误差处理

比较浮点数时，永远不要直接使用 `==` 运算符，应使用容差比较：

```cpp
// 错误
if (x == y) { ... }

// 正确
const double EPSILON = 1e-10;
if (fabs(x - y) < EPSILON) { ... }
```

### 课程学习策略

1. **理解思想重于记忆公式**：每种数值方法的核心思想是什么？为什么这样设计？
2. **重视误差分析**：算法是否稳定？误差如何传播？
3. **动手编程**：将算法实现为代码，观察实际效果
4. **联系实际**：思考每个算法可以解决什么实际问题
