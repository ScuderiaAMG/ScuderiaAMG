# 计算方法中的核心思想与问题主线

这份笔记按知识线索整理：先说明概念，再梳理公式和方法，最后整理常见题型。

## 一、先把概念讲清楚

**计算方法（数值分析）到底是做什么的？**

想象你是一个工程师，需要解决一个实际问题——比如计算火箭的飞行轨迹。你的问题涉及复杂的微分方程，用手算几乎不可能。但计算机只懂加减乘除，不懂微积分。那么，如何让计算机帮你算出答案？

**计算方法的本质**：把复杂的数学问题（积分、微分、解方程等）转化为计算机能做的四则运算，最终得到一个近似解。

**核心流程**就像一条流水线：
1. **实际问题** → 你遇到的具体工程/科学问题
2. **数学模型** → 用数学公式描述问题（如微分方程）
3. **计算模型** → 将数学模型转化为计算机可执行的计算步骤（这是计算方法的核心！）
4. **计算实现** → 用编程语言（Python、MATLAB等）实现计算模型
5. **实际应用** → 将计算结果用于解决原始问题

**为什么要学这门课？**

你学过微积分、线性代数、概率论，这些都是描述世界的语言。但当你真正用计算机去"计算"时，会遇到很多问题：
- 计算机中浮点数有精度限制，$1 \div 3 \times 3 \neq 1$！
- 高次插值会产生Runge现象，结果完全不可用
- 迭代法可能不收敛
- 误差会不断积累

计算方法就是教你如何避开这些陷阱，设计出稳定、高效、精确的数值算法。

### 什么是计算方法？

**提问**：计算方法是做什么用的？

计算方法 = 数值分析 (Numerical Analysis)

**核心功能**：将复杂问题或运算输入计算机，通过数值方法得到近似解。

计算机能处理的运算：加减乘除（$\times, \div, +, -$）

- 对数 $\ln x$
- 开方 $\sqrt{x}$

- 导数 $\frac{d}{dx} f(x)$
- 偏导数 $\frac{\partial f}{\partial x}$
- 积分 $\int_a^b f(x) dx$
- 微分方程

**输入**：复杂问题/运算 $\rightarrow$ **计算机** $\rightarrow$ **输出**：近似解

### 实例1 —— 图像的超分辨率显示

**问题**：低分辨率图像放大后像素点之间的缺失值如何填充？

**解决方案**：插值问题 (Interpolation)
- 当图像放大时，需要推断新增像素点的值
- 根据已知像素点的值，通过插值方法估算未知点的值

### 插值 (Interpolation) 概念

- 页面上显示"插值（Interpolation）"标题，配合图示说明插值的基本概念。
- 插值：通过已知离散数据点，构造一个连续函数来估计未知点的值。

### 插值方法1 —— 最近邻常数插值

- **方法**：取最近的已知像素点的值作为该点的值。
- **效果**：会产生明显的锯齿和马赛克效应。
- 这是最简单的插值方法，但效果最差。

### 插值方法2 —— 线性插值

- **方法**：根据邻近点的值进行线性加权平均。
- **效果**：比最近邻插值平滑，但仍然不够自然。
- 在图像处理中通常指双线性插值 (bilinear interpolation)。

### 插值方法3 —— 多项式插值

- **方法**：用多项式函数来拟合已知数据点。
- **效果**：可以得到更平滑的插值结果。
- 但高次多项式插值可能出现Runge现象（端点震荡）。

### 多项式插值 —— 解题思路

**核心思想**：构造4条曲线分别穿过其中1个数据点后叠加。

- 对于一个需要穿过4个点的插值问题，使用**3次多项式**。
- 基本思路：构造一组基函数，每个基函数只在一个数据点处为1，在其他数据点处为0。
- 最终插值多项式是这些基函数的线性组合。

### 拉格朗日插值法

- **拉格朗日插值法**的具体公式和构造。
- **拉格朗日基函数**的定义和性质。

拉格朗日插值公式：
$$L_n(x) = \sum_{i=0}^{n} y_i l_i(x)$$

其中拉格朗日基函数：
$$l_i(x) = \prod_{j=0, j \neq i}^{n} \frac{x - x_j}{x_i - x_j}$$

基函数性质：$l_i(x_j) = \delta_{ij} = \begin{cases} 1 & i=j \\ 0 & i \neq j \end{cases}$

### 误差 —— 浮点数比较的陷阱

**重要警示**：数学上的等价在计算机上不一定等效！

**错误示例**（直接比较浮点数）：
```cpp
double x = 1.0;
double y = x/3.0;
if (x == y*3.0)
    cout << "They are equal!";
else
    cout << "They are NOT equal.";
// 输出：They are NOT equal.
```

**正确做法**（引入误差容忍度 epsilon）：
```cpp
double x = 1.0;
double y = x/3.0;
if (fabs(x - y*3.0) < epsilon)
    cout << "They are equal!";
else
    cout << "They are NOT equal.";
```

### 计算机中数的浮点表示

**受计算机硬件的限制**：

1. **浮点数的尾数部分**：尾数位数固定为 $t$ 位（如 $t=64$ 位）。
2. **浮点数的阶码**：大小有确定的范围。

**舍入误差界**：
- 为了能在计算机中参与运算，计算机会自动用机器数 $\text{fl}(x)$ 来代替该实数。
- 舍入误差：$\text{fl}(x) - x$。

**误差的传播和积累**：
- 误差的传播和积累方式决定算法的**稳定性**。
- 稳定的算法能控制误差的传播，不稳定的算法会导致误差迅速膨胀。

## 三、解题通法

### 1. 先识别数学模型

把题目归类：

| 模型 | 常用数值方法 |
|------|--------------|
| 方程求根 | 二分法、迭代法、牛顿法 |
| 插值逼近 | Lagrange、Newton、Hermite、样条 |
| 数值积分 | Newton-Cotes、复合公式、高斯求积 |
| 常微分方程 | Euler、Runge-Kutta、线性多步法 |
| 线性方程组 | 直接法、迭代法 |

### 2. 再明确误差来源

答题时要知道误差从哪来：

- 插值：余项和节点选择。
- 积分：代数精度和步长。
- 微分方程：局部截断误差、稳定性。
- 线性方程组：条件数、舍入误差。

### 3. 方法选择原则

- 要保证一定收敛：优先二分法、严格条件下的迭代法。
- 要速度快：优先牛顿法、高阶求积、高阶 Runge-Kutta。
- 数据有误差：优先拟合，不强行插值。
- 矩阵大且稀疏：优先迭代法。

### 4. 标准答题结构

1. 写出数值模型。
2. 给出迭代或计算公式。
3. 代入数据计算。
4. 判断停止条件或误差。
5. 说明结果含义。

### 5. 易错点

- 不要只套公式，要先说明该方法适用条件。
- 近似解必须配合误差或收敛性判断。
- 方法越高阶不一定越好，还要看稳定性和计算量。
