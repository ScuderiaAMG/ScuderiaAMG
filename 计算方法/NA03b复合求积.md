# NA03b 复合求积 (Composite Quadrature)

这份笔记按知识线索整理：先说明概念，再梳理公式和方法，最后整理常见题型。

## 一、先把概念讲清楚

**为什么要用复合求积？**

上节课我们学了牛顿-柯特斯公式，但有两个麻烦：
1. **高次插值有 Runge 现象**：用高次多项式逼近函数时，区间两端会出现剧烈震荡
2. **高阶公式数值不稳定**：$n>7$ 时柯特斯系数出现负数，舍入误差会放大

这就好比用一根很长的软尺去量一条弯曲的河流——尺子越长，越难贴合河道的形状。更好的办法是把河流分成若干小段，用短尺一段一段地量，然后加起来。

**复合求积的核心思想**：分而治之！
- 将积分区间 $[a,b]$ 分成 $n$ 个小区间
- 在每个小区间上用低阶求积公式（如梯形公式或Simpson公式）
- 将结果相加

**复合梯形公式**：把整个区间切成 $n$ 段，每段用梯形公式。结果就像是用折线逼近曲线。

**复合Simpson公式**：每两个小区间合成一段（共需偶数个小区间），每段用Simpson公式。结果就像是用分段抛物线逼近曲线。

**龙贝格（Romberg）算法**：一种"外推加速"技术。先用复合梯形公式算一个粗糙结果，然后不断把区间分半，利用理查森外推消除误差项，逐步得到更精确的结果。就像通过多次测量取平均来消除误差一样。

## 二、知识脉络

### 复合求积的引入动机
- **高次插值**有 **Runge 现象**（区间两端剧烈震荡）
- **高阶 Newton-Cotes 公式**会出现**数值不稳定**（$n>7$ 时柯特斯系数有负值）
- **低阶 Newton-Cotes 公式**有时又不能满足精度要求
- **解决办法**：将积分区间 $[a,b]$ 分成若干小区间，在每个小区间上用低阶求积公式计算，然后将它们加起来——这就是**复合求积方法**

### 复合梯形公式的推导
- 将区间 $[a,b]$ 分成 $n$ 个相等的子区间 $[x_k, x_{k+1}]$，步长 $h = \frac{b-a}{n}$
- 在每个子区间上使用梯形公式：
  $$\int_{x_{k-1}}^{x_k} f(x)dx \approx \frac{h}{2}[f(x_{k-1}) + f(x_k)], \quad k=1,2,\ldots,n$$

### 复合梯形公式
- 相加后得到复合梯形公式：
  $$T_n = \frac{h}{2}\left[f(a) + 2\sum_{k=1}^{n-1} f(x_k) + f(b)\right]$$
- 在每个小区间上的截断误差为 $-\frac{h^3}{12}f''(\xi_k)$

### 复合梯形公式的误差余项
- 总误差：$R_n(f) = \sum_{k=0}^{n-1} \left[-\frac{h^3}{12}f''(\xi_k)\right]$
- 若 $f''(x)$ 在 $[a,b]$ 上连续，由连续函数的介值定理，存在某一 $\xi \in (a,b)$ 使得：
  $$\frac{1}{n}\sum_{k=0}^{n-1} f''(\xi_k) = f''(\xi)$$
- 因此：$R_n(f) = -\frac{b-a}{12}h^2 f''(\xi) = -\frac{(b-a)^3}{12n^2}f''(\xi)$

### 复合 Simpson 公式
- 将 $[a,b]$ 分成 $n$ 个相等子区间（$n$ 为偶数），步长 $h = \frac{b-a}{n}$
- 在每个子区间 $[x_k, x_{k+1}]$ 上使用Simpson公式：
  $$\int_{x_k}^{x_{k+1}} f(x)dx \approx \frac{h}{6}\left[f(x_k) + 4f(x_{k+\frac{1}{2}}) + f(x_{k+1})\right]$$
- 复合Simpson公式：
  $$S_n = \frac{h}{6}\left[f(a) + 4\sum_{k=0}^{n-1} f(x_{k+\frac{1}{2}}) + 2\sum_{k=1}^{n-1} f(x_k) + f(b)\right]$$
- 为方便编程，令 $n' = 2n$ 为偶数，$h' = \frac{b-a}{2n}$：
  $$S_n = \frac{h'}{3}\left[f(a) + 4\sum_{\substack{k=1 \\ k\text{ odd}}}^{2n-1} f(x_k) + 2\sum_{\substack{k=2 \\ k\text{ even}}}^{2n-2} f(x_k) + f(b)\right]$$
- 误差：$R[f] = -\frac{b-a}{180}h^4 f^{(4)}(\xi)$

### 复合 Cotes 公式
- 表达式：$C_n = \frac{h}{90}\left[7f(a) + 32\sum_{k=0}^{n-1} f(x_{k+\frac{1}{4}}) + 12\sum_{k=0}^{n-1} f(x_{k+\frac{1}{2}}) + 32\sum_{k=0}^{n-1} f(x_{k+\frac{3}{4}}) + 14\sum_{k=1}^{n-1} f(x_k) + 7f(b)\right]$
- 每个子区间使用 5 个点的 Cotes 公式

### 收敛速度与例题
- **收敛阶定义**：若 $\lim_{h \to 0} \frac{R[f]}{h^p} = C \neq 0$，则称该公式是 $p$ 阶收敛的
- 各复合公式的收敛速度：
  - $T_n \sim O(h^2)$（复合梯形，2阶收敛）
  - $S_n \sim O(h^4)$（复合Simpson，4阶收敛）
  - $C_n \sim O(h^6)$（复合Cotes，6阶收敛）

**例题1**：计算 $\pi = \int_0^1 \frac{4}{1+x^2}dx$
- 使用复合梯形公式 $T_8$（$n=8$，$h=1/8$）：
  $$T_8 = \frac{1}{16}\left[f(0) + 2\sum_{k=1}^7 f(x_k) + f(1)\right] = 3.138988494$$
- 使用复合Simpson公式 $S_4$（$n=4$，$h=1/8$）：
  $$S_4 = \frac{1}{24}\left[f(0) + 4\sum_{\text{even}} f(x_k) + 2\sum_{\text{odd}} f(x_k) + f(1)\right] = 3.141592502$$
- **注意**：两种方法运算量基本相同，但Simpson公式的精度远高于梯形公式

### 例题2——确定复合梯形公式的等分数
**例2**：用复合梯形公式计算 $\int_0^1 e^x dx$，问积分区间要等分多少才能保证有五位有效数字？
- 精确值具有一位整数，要使近似积分值有五位有效数字，需：
  $$|R_n(f)| = \frac{b-a}{12}h^2|f''(\xi)| \le \frac{1}{2} \times 10^{-4}$$
- 当 $0 < x < 1$ 时，$|f''(x)| = e^x < e$
- 计算得：$\frac{e}{12n^2} \le \frac{1}{2} \times 10^{-4} \Rightarrow n^2 \ge \frac{2e \times 10^4}{12} \Rightarrow n \ge 67.0811$
- 所以至少需要 $n = 68$ 等分

### 区间逐次分半求积法与自适应复化求积法
- **问题**：使用复化求积公式前，需要先验估计节点数目，确定合适步长，但误差估计常常困难
- **解决方案**：采用"**事后估计误差**"的方法
- 在步长逐次减半的过程中，反复利用复化求积公式进行计算
- 同时查看相继两次计算结果的误差是否达到要求
- 直到所求得的积分近似值满足精度要求为止

### 事后估计法（以复合梯形公式为例）
- 将 $[a,b]$ 作 $n$ 等分（步长 $h$）：$I - T_n = -\frac{b-a}{12}h^2 f''(\eta)$
- 将 $[a,b]$ 作 $2n$ 等分（步长 $h/2$）：$I - T_{2n} = -\frac{b-a}{12}\left(\frac{h}{2}\right)^2 f''(\eta)$
- 假定 $f''(\eta) \approx f''(\bar{\eta})$，则有：
  $$I - T_{2n} \approx \frac{1}{4}(I - T_n)$$
- 推导出：$I - T_{2n} \approx \frac{1}{3}(T_{2n} - T_n)$
- **实用判据**：若 $T_{2n}$ 与 $T_n$ 接近，则 $T_{2n}$ 误差很小
- 可用来判断迭代是否停止

### 从复合梯形到复合Simpson——理查森外推
- 用 $T_{2n}$ 的近似误差作为 $T_{2n}$ 的一种补偿：
  $$I \approx T_{2n} + \frac{1}{3}(T_{2n} - T_n) = \frac{4}{3}T_{2n} - \frac{1}{3}T_n$$
- 代入复合梯形公式表达式，可推得：
  $$\frac{4}{3}T_{2n} - \frac{1}{3}T_n = S_n$$
- 即复合梯形公式的线性组合得到**复合Simpson公式**！

### Simpson公式的误差估计
- 对Simpson公式进行类似推导：
  $$\frac{I - S_{2n}}{I - S_n} \approx \frac{1}{16}$$
- 即：$I - S_{2n} \approx \frac{1}{15}(S_{2n} - S_n)$
- 练习：P127 #4.6(2)

### Cotes公式的误差估计
- 对Cotes公式进行类似推导：
  $$\frac{I - C_{2n}}{I - C_n} \approx \frac{1}{64}$$
- 即：$I - C_{2n} \approx \frac{1}{63}(C_{2n} - C_n)$
- Romberg序列由此引出

### Romberg（龙贝格）序列
- 一般形式的龙贝格序列：
  $$T_1^{(k)} = \frac{4T_1^{(k-1)} - T_0^{(k-1)}}{4-1} = S_{2^{k-1}} \quad \text{(Simpson)}$$
  $$T_2^{(k)} = \frac{4^2 T_2^{(k-1)} - T_1^{(k-1)}}{4^2-1} = C_{2^{k-2}} \quad \text{(Cotes)}$$
  $$T_3^{(k)} = \frac{4^3 T_3^{(k-1)} - T_2^{(k-1)}}{4^3-1} = R_{2^{k-3}} \quad \text{(Romberg)}$$
- Romberg算法的计算流程：
  1. $T_1 = T_0^{(0)}$（$n=1$的复合梯形）
  2. $T_2 = T_0^{(1)}$（$n=2$的复合梯形）
  3. $S_1 = T_1^{(0)}$（外推得到Simpson）
  4. $T_4 = T_0^{(2)}$、$S_2 = T_1^{(1)}$、$C_1 = T_2^{(0)}$
  5. $T_8 = T_0^{(3)}$、$S_4 = T_1^{(2)}$、$C_2 = T_2^{(1)}$、$R_1 = T_3^{(0)}$
  6. 逐次比较，直到满足精度

- **Romberg 序列**：
  $$T_{m}^{(k)} = \frac{4^m T_{m-1}^{(k+1)} - T_{m-1}^{(k)}}{4^m - 1}$$

### 高斯型积分的一般理论
- 构造具有 $2n+1$ 次代数精度的求积公式：
  $$\int_a^b \rho(x)f(x)dx \approx \sum_{k=0}^n A_k f(x_k)$$
- 将节点 $x_0,\ldots,x_n$ 以及系数 $A_0,\ldots,A_n$ 都作为待定系数
- 令 $f(x) = 1, x, x^2, \ldots, x^{2n+1}$ 代入可求解
- 这样的节点称为 **Gauss 点**
- **定理**：$x_0,\ldots,x_n$ 为 Gauss 点 $\iff$ $\omega(x) = \prod_{k=0}^n (x-x_k)$ 与任意次数不大于 $n$ 的多项式 $P(x)$（**带权**）正交

### 正交多项式与Gauss点
- 正交多项式族 $\{\varphi_0, \varphi_1, \ldots, \varphi_n, \ldots\}$ 有性质：任意次数不大于 $n$ 的多项式 $P(x)$ 必与 $\varphi_{n+1}$ 正交
- 若取 $\omega(x)$ 为其中的 $\varphi_{n+1}$，则 $\varphi_{n+1}$ 的根就是 Gauss 点

**例题**：构造求积公式 $\int_0^1 \sqrt{x}f(x)dx \approx A_0 f(x_0) + A_1 f(x_1)$
- Step 1：构造正交多项式 $\varphi_2$，设 $\varphi_0(x)=1, \varphi_1(x)=x+a, \varphi_2(x)=x^2+bx+c$
- 由正交条件 $\int_0^1 \sqrt{x} \cdot \varphi_0 \varphi_1 dx = 0$ 和 $\int_0^1 \sqrt{x} \cdot \varphi_0 \varphi_2 dx = 0$ 及 $\int_0^1 \sqrt{x} \cdot \varphi_1 \varphi_2 dx = 0$
- 求得：$a = -\frac{3}{5}$, $b = -\frac{10}{9}$, $c = \frac{5}{21}$
- 即：$\varphi_2(x) = x^2 - \frac{10}{9}x + \frac{5}{21}$

### 求Gauss点与系数
- Step 2：求 $\varphi_2 = 0$ 的两个根，即为 Gauss 点 $x_0, x_1$
  $$x_{0,1} = \frac{10/9 \pm \sqrt{(10/9)^2 - 20/21}}{2}$$
- Step 3：代入 $f(x) = 1, x$ 求解 $A_0, A_1$
- 解线性方程组得：
  - $x_0 \approx 0.8212, x_1 \approx 0.2899$
  - $A_0 \approx 0.3891, A_1 \approx 0.2776$
- 应用：计算 $\int_0^1 \sqrt{x} e^x dx$
  $$\int_0^1 \sqrt{x} e^x dx \approx A_0 e^{x_0} + A_1 e^{x_1} \approx 0.3891 \times e^{0.8212} + 0.2776 \times e^{0.2899} \approx 1.2555$$

### 例——确定求积公式中的待定系数
**例题**：确定求积公式 $\int_{-1}^1 f(x)dx \approx af(-0.6) + bf(0) + cf(0.6)$ 中的待定系数 $a, b, c$，使其代数精度尽量高，并指出公式有几次代数精度，判断是否为Gauss型公式

### 例题求解——建立方程组
- 要使代数精度尽可能高，$a,b,c$ 必须满足方程组（令 $f(x)=1, x, x^2$ 精确成立）：
  $$\begin{cases}
  a + b + c = 2 \\
  -0.6a + 0 + 0.6c = 0 \\
  0.36a + 0 + 0.36c = \frac{2}{3}
  \end{cases}$$
- 解得：$a = c = \frac{5}{9}$, $b = \frac{8}{9}$

### 判定代数精度与Gauss型
- 验证 $f(x) = x^3$：$I(x^3) = 0$，$\tilde{I}(x^3) = 0$，精确
- 验证 $f(x) = x^4$：$I(x^4) = \frac{2}{5}$，$\tilde{I}(x^4) = \frac{5}{9}(0.6^4+0.6^4)=\frac{2}{5}$，精确
- 验证 $f(x) = x^5$：$I(x^5) = 0$，$\tilde{I}(x^5) = 0$，精确
- 验证 $f(x) = x^6$：$I(x^6) = \frac{2}{7}$，$\tilde{I}(x^6) = \frac{5}{9}(0.6^6+0.6^6) \neq \frac{2}{7}$，不精确
- **结论**：代数精度为 **5**
- 公式 $\int_{-1}^1 f(x)dx \approx \frac{5}{9}f(-0.6) + \frac{8}{9}f(0) + \frac{5}{9}f(0.6)$ 是 **Gauss 型求积公式**

## 三、解题通法

### 1. 复合公式的基本流程

把 $[a,b]$ 等分成 $n$ 份，步长
$$
h=\frac{b-a}{n},\quad x_i=a+ih.
$$

在每个小区间用低阶求积公式，再求和。

### 2. 复合梯形公式

$$
T_n=\frac{h}{2}\left[f(x_0)+2\sum_{i=1}^{n-1}f(x_i)+f(x_n)\right].
$$

误差阶：
$$
O(h^2).
$$

### 3. 复合 Simpson 公式

要求 $n$ 为偶数：
$$
S_n=\frac{h}{3}\left[f(x_0)+4\sum_{i=1,3,\dots}^{n-1}f(x_i)+2\sum_{i=2,4,\dots}^{n-2}f(x_i)+f(x_n)\right].
$$

误差阶：
$$
O(h^4).
$$

### 4. Romberg 思路

利用梯形序列加速：
$$
R_{k,j}=R_{k,j-1}+\frac{R_{k,j-1}-R_{k-1,j-1}}{4^j-1}.
$$

题目给表时，按递推从左到右算。

### 5. 易错点

- 复合 Simpson 必须使用偶数个小区间。
- 梯形公式内部点权重为 2，Simpson 奇偶点权重分别为 4 和 2。
- 步长减半时函数值不要重复算已用节点。
