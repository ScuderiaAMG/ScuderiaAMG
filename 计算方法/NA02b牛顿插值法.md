# 牛顿插值法

这份笔记按知识线索整理：先说明概念，再梳理公式和方法，最后整理常见题型。

## 一、先把概念讲清楚

**牛顿插值法解决了拉格朗日插值法的一个痛点：** 拉格朗日插值中，每增加一个新数据点，所有基函数都要重新计算，就像搭好的积木塔要拆了重搭。牛顿法则像"搭乐高"——在已有结构上加新积木就行。

**核心思想：** 将插值多项式写成"嵌套"形式：
$$
N_n(x) = a_0 + a_1(x-x_0) + a_2(x-x_0)(x-x_1) + \cdots + a_n(x-x_0)(x-x_1)\cdots(x-x_{n-1})
$$
增加一个节点时，只需加上一项 $a_{n+1}(x-x_0)\cdots(x-x_n)$，已有系数不变。

**用"爬楼梯"来类比：**
- 第 0 阶：直接取 $f(x_0)$
- 第 1 阶：加上 $x-x_0$ 乘以"变化率"（一阶差商）
- 第 2 阶：加上 $(x-x_0)(x-x_1)$ 乘以"变化率的变化率"（二阶差商）
- 以此类推...

**差商（divided difference）** 是牛顿法的核心工具。它类似于导数，但适用于离散数据——度量函数值随自变量变化的平均变化率。

**等距节点时更简单：** 如果数据点是等间隔的，差商会简化为**差分**（向前差分、向后差分），计算更简便，公式形式也更整齐。

## 二、知识脉络

### 拉格朗日插值法的不足
- **拉格朗日插值的缺点**：虽然容易计算，但若要增加一个节点时，全部基函数 $l_i(x)$ 都需要重新计算。
- **改进思路**：将 $L_n(x)$ 改写成如下形式，希望每加一个节点时，只附加一项上去：
  $$
  N_n(x) = a_0 + a_1(x-x_0) + a_2(x-x_0)(x-x_1) + \cdots + a_n(x-x_0)(x-x_1)\cdots(x-x_{n-1})
  $$
- 系数 $a_0, a_1, a_2$ 通过代入节点条件确定：
  - $a_0 = f_0$
  - $a_1 = \frac{f_1 - f_0}{x_1 - x_0}$
  - $a_2 = \frac{\frac{f_2 - f_0}{x_2 - x_0} - \frac{f_1 - f_0}{x_1 - x_0}}{x_2 - x_1}$

### 改进思路
- 多项式改写形式明确列出
- 增加节点时只需附加一项

### 差商的定义
- **差商（Divided Difference）** 的定义：
  - **0 阶差商**：函数值本身，$f[x_i] = f(x_i)$
  - **1 阶差商**：
    $$
    f[x_i, x_j] = \frac{f(x_i) - f(x_j)}{x_i - x_j}, \quad x_i \neq x_j
    $$
  - **2 阶差商**：
    $$
    f[x_i, x_j, x_k] = \frac{f[x_i, x_j] - f[x_j, x_k]}{x_i - x_k}
    $$
  - **k+1 阶差商**：
    $$
    f[x_0, x_1, \ldots, x_{k+1}] = \frac{f[x_0, x_1, \ldots, x_k] - f[x_1, x_2, \ldots, x_{k+1}]}{x_0 - x_{k+1}}
    $$

### 差商的计算方法（表格法）
- **差商表（表格法）** 结构：

| $x_k$ | $f(x_k)$ | 一阶差商 | 二阶差商 | 三阶差商 | 四阶差商 |
|-------|----------|---------|---------|---------|---------|
| $x_0$ | $f(x_0)$ | | | | |
| $x_1$ | $f(x_1)$ | $f[x_0,x_1]$ | | | |
| $x_2$ | $f(x_2)$ | $f[x_1,x_2]$ | $f[x_0,x_1,x_2]$ | | |
| $x_3$ | $f(x_3)$ | $f[x_2,x_3]$ | $f[x_1,x_2,x_3]$ | $f[x_0,x_1,x_2,x_3]$ | |
| $x_4$ | $f(x_4)$ | $f[x_3,x_4]$ | $f[x_2,x_3,x_4]$ | $f[x_1,x_2,x_3,x_4]$ | $f[x_0,x_1,x_2,x_3,x_4]$ |

- 规定函数值为零阶差商
- 每列相邻两个差商相减除以对应端点差，得到下一列差商

### 差商的性质
- **性质1**：$k$ 阶差商 $f[x_0, x_1, \ldots, x_k]$ 可由函数值 $f(x_0), f(x_1), \ldots, f(x_k)$ 的线性组合表示：
  $$
  f[x_0, x_1, \ldots, x_k] = \sum_{i=0}^{k} \frac{f(x_i)}{(x_i - x_0)(x_i - x_1)\cdots(x_i - x_{i-1})(x_i - x_{i+1})\cdots(x_i - x_k)}
  $$
- **性质2（对称性）**：差商的值与节点 $x_i$ 的顺序无关，即差商具有对称性：
  $$
  f[x_0, x_1, \ldots, x_k] = f[x_{i_0}, x_{i_1}, \ldots, x_{i_k}] \quad (\text{任意排列})
  $$

### 牛顿插值公式
- **牛顿插值基**：利用差商的定义逐步展开：
  - $f(x) = f(x_0) + f[x, x_0](x - x_0)$
  - $f[x, x_0] = f[x_0, x_1] + f[x, x_0, x_1](x - x_1)$
  - $\cdots$
  - $f[x, x_0, \ldots, x_{n-1}] = f[x_0, x_1, \ldots, x_n] + f[x, x_0, \ldots, x_n](x - x_n)$

- **牛顿插值多项式**：
  $$
  N_n(x) = f(x_0) + f[x_0, x_1](x-x_0) + f[x_0, x_1, x_2](x-x_0)(x-x_1) + \cdots + f[x_0, x_1, \ldots, x_n](x-x_0)(x-x_1)\cdots(x-x_{n-1})
  $$

- 简洁形式：
  $$
  N_n(x) = \sum_{k=0}^{n} f[x_0, \ldots, x_k] \prod_{i=0}^{k-1} (x - x_i)
  $$

- 系数：$a_k = f[x_0, x_1, \ldots, x_k]$

- **牛顿插值余项**：
  $$
  R_n(x) = f[x_0, x_1, \ldots, x_n, x] \prod_{i=0}^{n} (x - x_i)
  $$

### 牛顿前插公式概览
- 差商表的递推层次结构图：
  - 第0列：$f(x_0), f(x_1), f(x_2), f(x_3), \ldots$
  - 第1列：$f[x_0,x_1], f[x_1,x_2], f[x_2,x_3], \ldots$
  - 第2列：$f[x_0,x_1,x_2], f[x_1,x_2,x_3], \ldots$
  - 第3列：$f[x_0,x_1,x_2,x_3], \ldots$

### 关键说明与计算流程
- **唯一性**：由唯一性定理可知 $N_n(x) \equiv L_n(x)$，只是算法不同，故其余项也相同：
  $$
  f[x_0, x_1, \ldots, x_k] = \frac{f^{(k)}(\xi)}{k!}, \quad \xi \in (x_{\min}, x_{\max})
  $$
- **实际计算过程（递推）**：
  - 从已知函数值和差商出发，逐步构建牛顿插值多项式
  - 计算流程：
    - $f(x_0) \to f(x_1) \to f[x_0, x_1]$
    - $f(x_1) \to f(x_2) \to f[x_1, x_2]$
    - $f[x_0, x_1] \to f[x_1, x_2] \to f[x_0, x_1, x_2]$
    - 以此类推，直到 $f[x_0, \ldots, x_n]$
  - 增加节点 $x_{n+1}$ 时，只需在差商表底部添加一行

### 例题：—牛顿基本差商公式
- **例**：已知 $x=1,4,9$ 的平方根为 $1,2,3$，利用牛顿基本差商公式求 $\sqrt{7}$ 的近似值。
- **解**：
  - 计算差商表：
    - $f[1]=1, f[4]=2, f[9]=3$
    - $f[1,4] = \frac{2-1}{4-1} = 0.33333$
    - $f[4,9] = \frac{3-2}{9-4} = 0.2$
    - $f[1,4,9] = \frac{0.2 - 0.33333}{9-1} = -0.01667$
  - 二阶牛顿基本差商公式：
    $$
    P_2(x) = 1 + 0.33333(x-1) - 0.01667(x-1)(x-4)
    $$
  - 代入 $x=7$：
    $$
    P_2(7) = 1 + 0.33333 \times 6 - 0.01667 \times 6 \times 3 = 1 + 2 - 0.3 = 2.7
    $$
  - 故 $\sqrt{7} \approx 2.7$

### 等距节点公式与差分
- **等距节点**：$x_i = x_0 + ih,\; i = 0,1,\ldots,n$
- **向前差分（Forward Difference）**：
  $$
  \Delta f_i = f_{i+1} - f_i
  $$
  $$
  \Delta^k f_i = \Delta^{k-1} f_{i+1} - \Delta^{k-1} f_i
  $$
- **向后差分（Backward Difference）**：
  $$
  \nabla f_i = f_i - f_{i-1}
  $$
  $$
  \nabla^k f_i = \nabla^{k-1} f_i - \nabla^{k-1} f_{i-1}
  $$
- **中心差分（Centered Difference）**：
  $$
  \delta f_{i+\frac12} = f_{i+1} - f_i
  $$
  $$
  \delta^k f_i = \delta^{k-1} f_{i+\frac12} - \delta^{k-1} f_{i-\frac12}
  $$

### 差分表
- **差分表（向前差分）**：

| $x_k$ | $f_k$ | $\Delta f_k$ | $\Delta^2 f_k$ | $\Delta^3 f_k$ | $\Delta^4 f_k$ |
|-------|-------|-------------|---------------|---------------|---------------|
| $x_0$ | $f_0$ | | | | |
| $x_1$ | $f_1$ | $\Delta f_0$ | | | |
| $x_2$ | $f_2$ | $\Delta f_1$ | $\Delta^2 f_0$ | | |
| $x_3$ | $f_3$ | $\Delta f_2$ | $\Delta^2 f_1$ | $\Delta^3 f_0$ | |
| $x_4$ | $f_4$ | $\Delta f_3$ | $\Delta^2 f_2$ | $\Delta^3 f_1$ | $\Delta^4 f_0$ |

- **向后差分表**结构类似，以 $\nabla$ 代替 $\Delta$

### 差商与差分的关系
- **等距节点的差商-差分关系**：
  - 一阶差商：$f[x_i, x_{i+1}] = \frac{\Delta f_i}{h}$
  - 二阶差商：$f[x_i, x_{i+1}, x_{i+2}] = \frac{\Delta^2 f_i}{2!h^2}$
  - 三阶差商：$f[x_i, x_{i+1}, x_{i+2}, x_{i+3}] = \frac{\Delta^3 f_i}{3!h^3}$
  - m 阶差商：$f[x_i, x_{i+1}, \ldots, x_{i+m}] = \frac{\Delta^m f_i}{m!h^m}$
  - 向后差分类似：$f[x_{i-m}, \ldots, x_{i-1}, x_i] = \frac{\nabla^m f_i}{m!h^m}$

### 牛顿前差公式与后差公式
- **牛顿前差公式（Newton's forward-difference formula）**：
  - 设 $x = x_0 + th$，则：
    $$
    N_n(x_0 + th) = \sum_{k=0}^{n} \binom{t}{k} \Delta^k f_0
    $$
    其中 $\binom{t}{k} = \frac{t(t-1)\cdots(t-k+1)}{k!}$ 为广义二项式系数。
  - 余项：
    $$
    R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!} h^{n+1} t(t-1)\cdots(t-n), \quad \xi \in (x_0, x_n)
    $$

- **牛顿后差公式（Newton's backward-difference formula）**：
  - 设 $x = x_n + th$，则：
    $$
    N_n(x_n + th) = \sum_{k=0}^{n} (-1)^k \binom{-t}{k} \nabla^k f_n = \sum_{k=0}^{n} \binom{t+k-1}{k} \nabla^k f_n
    $$
  - 常用形式：
    $$
    N_n(x_n + th) = \sum_{k=0}^{n} \binom{t+k-1}{k} \nabla^k f_n
    $$

- **使用原则**：
  - 当 $x$ 靠近 $x_0$（表头）时，使用**前插公式**（表初公式）
  - 当 $x$ 靠近 $x_n$（表末）时，使用**后插公式**（表末公式）

### 牛顿插值的不足
- **优点**：计算较简单，尤其是增加节点时，只需增加一项
- **不足**：牛顿插值和拉格朗日插值都只能保证穿过给定的函数值，**不能拟合函数导数给定的情况**——需要引入厄米插值

## 三、做题方法

### 3.1 牛顿插值法通用步骤

#### 方法一：差商表法（通用，节点任意分布）

**步骤1：列出差商表**
$$
\begin{array}{c|cccc}
x_k & f(x_k) & \text{一阶} & \text{二阶} & \text{三阶} \\ \hline
x_0 & f[x_0] & & & \\
x_1 & f[x_1] & f[x_0,x_1] & & \\
x_2 & f[x_2] & f[x_1,x_2] & f[x_0,x_1,x_2] & \\
x_3 & f[x_3] & f[x_2,x_3] & f[x_1,x_2,x_3] & f[x_0,x_1,x_2,x_3]
\end{array}
$$

每列计算规则（以二阶为例）：
$$
f[x_i, x_{i+1}, x_{i+2}] = \frac{f[x_{i+1}, x_{i+2}] - f[x_i, x_{i+1}]}{x_{i+2} - x_i}
$$

**步骤2：写出牛顿插值多项式**
取差商表对角线的值作为系数：
$$
N_n(x) = f[x_0] + f[x_0,x_1](x-x_0) + f[x_0,x_1,x_2](x-x_0)(x-x_1) + \cdots
$$

**步骤3：代入求值**
将要计算的 $x$ 值代入 $N_n(x)$。

#### 方法二：等距节点法
**步骤1：计算差分表**
**步骤2：判断使用前插或后插**
- $x$ 靠近 $x_0$：前插公式
- $x$ 靠近 $x_n$：后插公式

**步骤3：代入公式计算**
前插公式（$x = x_0 + th$）：
$$
N_n(x_0 + th) = f_0 + \binom{t}{1}\Delta f_0 + \binom{t}{2}\Delta^2 f_0 + \cdots + \binom{t}{n}\Delta^n f_0
$$

### 3.2 典型考试题型

#### 题型1：构造牛顿插值多项式
**例：** 已知 $f(0)=1, f(1)=2, f(2)=9, f(3)=28$
**解：** 计算差商表，得到 $N_3(x) = 1 + x + 2x(x-1) + x(x-1)(x-2) = x^3+1$

#### 题型2：增加节点后的插值
**例：** 在上题基础上增加 $f(4)=65$，求新插值多项式
**解：** 在原差商表底部加一行，计算新一行差商，在原多项式上加一项即可。

#### 题型3：误差估计（差商形式）
- 使用 $R_n(x) = f[x_0,\ldots,x_n,x] \prod_{i=0}^{n} (x-x_i)$
- 或转换为导数形式：$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!} \prod (x-x_i)$

#### 题型4：等距节点插值
**例：** 已知 $x=0,1,2,3,4$ 处的函数值，求 $x=0.5$ 处的近似值
**解：** 计算向前差分，用前插公式（因为 0.5 靠近表头）

### 3.3 公式总结表

#### 差商公式

| 阶数 | 公式 | 说明 |
|------|------|------|
| 0阶 | $f[x_i] = f(x_i)$ | 函数值本身 |
| 1阶 | $f[x_i,x_j] = \frac{f(x_i)-f(x_j)}{x_i-x_j}$ | 一阶差商 |
| 2阶 | $f[x_i,x_j,x_k] = \frac{f[x_i,x_j]-f[x_j,x_k]}{x_i-x_k}$ | 二阶差商 |
| n阶 | $f[x_0,\ldots,x_n] = \frac{f[x_0,\ldots,x_{n-1}]-f[x_1,\ldots,x_n]}{x_0-x_n}$ | n阶差商 |

#### 差分公式（等距节点 $h$）

| 类型 | 定义 |
|------|------|
| 向前差分 | $\Delta f_i = f_{i+1} - f_i$ |
| 向后差分 | $\nabla f_i = f_i - f_{i-1}$ |
| 差商-差分关系 | $f[x_0,\ldots,x_k] = \frac{\Delta^k f_0}{k!h^k} = \frac{\nabla^k f_k}{k!h^k}$ |

#### 牛顿插值公式

| 类型 | 公式 |
|------|------|
| 基本牛顿 | $N_n(x) = \sum_{k=0}^{n} f[x_0,\ldots,x_k] \prod_{i=0}^{k-1} (x-x_i)$ |
| 前差公式 | $N_n(x_0+th) = \sum_{k=0}^{n} \binom{t}{k} \Delta^k f_0$ |
| 后差公式 | $N_n(x_n+th) = \sum_{k=0}^{n} \binom{t+k-1}{k} \nabla^k f_n$ |

### 3.4 常见陷阱与注意事项

1. **差商计算顺序**：计算 $f[x_i,x_{i+1}]$ 时，分子是 $f(x_{i+1})-f(x_i)$，分母是 $x_{i+1}-x_i$，注意别弄反。
2. **系数位置**：牛顿插值的系数是差商表**对角线**上的值，不是任意位置。
3. **前插 vs 后插**：前插用 $\Delta$ 和后插用 $\nabla$ 不要混淆。$x$ 靠近表头用前插，靠近表末用后插。
4. **广义二项式系数**：$\binom{t}{k} = \frac{t(t-1)\cdots(t-k+1)}{k!}$，即使 $t$ 不是整数也适用。
5. **唯一性**：牛顿插值多项式和拉格朗日插值多项式是同一个多项式的不同表达形式，计算结果相同。
6. **不能拟合导数条件**：牛顿插值不能约束导数，需要时要用厄米插值。

### 3.5 牛顿 vs 拉格朗日对比

| 特性 | 拉格朗日插值 | 牛顿插值 |
|------|-------------|---------|
| 公式形式 | $\sum y_k l_k(x)$ | $\sum a_k \prod (x-x_i)$ |
| 增加节点 | 全部重算 | 加一项即可 |
| 计算量 | 较大 | 较小 |
| 理论分析 | 更直观 | 差商概念更抽象 |
| 等距节点 | 可化简 | 有差分公式更方便 |
