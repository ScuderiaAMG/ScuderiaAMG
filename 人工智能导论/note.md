生成式对抗网络（GAN）自2014年提出以来，经历了从基础理论突破到高分辨率、可控化生成的快速迭代。以下是GAN发展演进的代表性工作路径图及其核心贡献梳理。

### **GAN 核心发展路径图**

```text
[ 理论开创 ] GAN (2014)
     │
     ├──> [ 条件引入 ] CGAN (2014)
     │
     └──> [ 架构规范 ] DCGAN (2015)
                │
                ├──> [ 损失重构 ] WGAN (2017)
                │
                ├──> [ 图像翻译 ] Pix2Pix (2017) ──> [ 无监督翻译 ] CycleGAN (2017)
                │
                └──> [ 高清生成 ] ProGAN (2018)
                           │
                           ├──> [ 规模霸权 ] BigGAN (2019)
                           │
                           └──> [ 语义解耦 ] StyleGAN (2018) ──> [ 细节完善 ] StyleGAN2/3 (2019-2021)
```

---

### **代表性工作及其核心贡献（一句话总结）**

* **GAN (Vanilla GAN, 2014)**
    * 提出生成器与判别器相互博弈的对抗训练框架，开创了深度学习领域生成式对抗网络的先河。
* **CGAN (Conditional GAN, 2014)**
    * 通过在生成器和判别器中引入条件变量（如类别标签），首次实现了对生成图像属性的定向控制。
* **DCGAN (Deep Convolutional GAN, 2015)**
    * 首次将卷积神经网络（CNN）全面引入GAN并确立了一系列架构设计规范，大幅提升了模型训练的稳定性和图像质量。
* **WGAN (Wasserstein GAN, 2017)**
    * 利用Wasserstein距离替代传统散度来度量分布差异，从数学理论层面解决了GAN训练极不稳定和模式崩溃（Mode Collapse）的痛点。
* **Pix2Pix (2017)**
    * 提出了一种基于条件GAN的通用框架，利用成对数据集实现了极其惊艳的高质量“图像到图像”翻译任务（如线稿上色、地图转卫星图）。
* **CycleGAN (2017)**
    * 创新性地引入“循环一致性损失”（Cycle-Consistency Loss），突破了必须依赖成对数据的严苛限制，实现了无监督的图像跨域风格迁移（如斑马与马的互相转换）。
* **ProGAN (Progressive GAN, 2018)**
    * 采用从低分辨率到高分辨率逐步添加网络层的渐进式训练策略，首次成功稳定生成了1024x1024分辨率的高清逼真图像。
* **StyleGAN (2018)**
    * 借鉴风格迁移技术重构了生成器网络，引入了能够控制不同尺度图像特征的样式映射网络，实现了对人脸属性（如年龄、性别、发色）的解耦与精细控制。
* **BigGAN (2019)**
    * 通过成倍扩展模型参数与批处理规模，并结合截断技巧（Truncation Trick），在ImageNet等复杂数据集上将类别条件图像生成的质量和多样性推向了当时的极限。
* **StyleGAN2 / StyleGAN3 (2019-2021)**
    * 重新设计了归一化机制以消除前代网络生成图像中的水滴状伪影，并引入了平移/旋转等变性，将高保真图像生成的物理真实感做到了极致。
