文件1：experiment5_main.m — 全部实验综合脚本

  直接运行即可完成所有实验要求，包含以下6个部分：

  实验一：振荡环节阶跃响应（K=4/40/400）

  G(s) = K·ωn² / (s² + 2ζωn·s + ωn²)    % ωn=1, ζ=0.5
  T(s) = G(s) / (1 + G(s))               % 单位负反馈闭环
  三种增益的阶跃响应画在一张图上，并输出 σ%、ts、tp、tr 指标。

  实验二-1：二阶系统瞬态响应指标

  按指导书中的 α = {0, 0.13, 0.33, 0.44, 0.63} 对应不同阻尼比，输出完整的 σ% / tp / ts / ωn / ζ / ωd
  指标表格。

  实验二-2：0型/I型/II型系统稳态误差

  - 0型: G(s)=K/(Ts+1)，阶跃 ess=1/(1+K)
  - I型: G(s)=K/[s(Ts+1)]，阶跃 ess=0，斜坡 ess=1/K
  - II型: G(s)=K/[s²(Ts+1)]，阶跃/斜坡 ess=0

  含阶跃和斜坡两种输入响应，不同 K 值对比。

  实验三：高阶系统稳定性

  三阶I型系统 G(s)=K/[s(T1s+1)(T2s+1)]，用劳斯判据计算临界增益
  Kc，展示稳定/临界/不稳定三种状态，并分析时间常数变化对稳定性的影响。
