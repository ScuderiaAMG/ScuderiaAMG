# 振动与波动公式、定理及解释总结

## 1. 简谐振动

### 基本公式
1. **运动方程**：
   $$\frac{d^2x}{dt^2} + \omega^2 x = 0$$
   - 适用范围：理想简谐振动物体
   - 使用条件：回复力与位移成正比且方向相反
   - 物理量：$x$位移，$\omega$角频率，$t$时间
   - 通俗解释：这是简谐振动最本质的数学特征，表示物体在平衡位置附近受到线性回复力的作用

2. **振动方程**：
   $$x = A\cos(\omega t + \varphi)$$
   - 适用范围：描述简谐振动位移
   - 物理量：
     - $A$：振幅，物体离开平衡位置的最大距离
     - $\omega$：角频率，$\omega = 2\pi\nu = \frac{2\pi}{T}$，决定振动快慢
     - $\varphi$：初相位，表示初始时刻的振动状态
     - $\omega t + \varphi$：相位，唯一确定任意时刻的运动状态
   - 通俗解释：物体在平衡位置附近来回运动，位移按余弦规律变化，就像钟摆或弹簧上的物体振动

3. **速度与加速度**：
   $$v = -\omega A\sin(\omega t + \varphi) = \omega A\cos(\omega t + \varphi + \frac{\pi}{2})$$
   $$a = -\omega^2 A\cos(\omega t + \varphi) = \omega^2 A\cos(\omega t + \varphi + \pi)$$
   - 通俗解释：速度超前位移$\frac{\pi}{2}$，加速度超前速度$\frac{\pi}{2}$（或与位移反相）

4. **周期公式**：
   - 弹簧振子：$T = 2\pi\sqrt{\frac{m}{k}}$
   - 单摆（小角度）：$T = 2\pi\sqrt{\frac{l}{g}}$
   - 物理量：$m$质量，$k$劲度系数，$l$摆长，$g$重力加速度
   - 通俗解释：振动周期由系统自身性质决定，与振幅无关，这是简谐振动的重要特征

5. **振幅与初相确定**：
   $$A = \sqrt{x_0^2 + \left(\frac{v_0}{\omega}\right)^2}$$
   $$\tan\varphi = -\frac{v_0}{\omega x_0}$$
   - 使用条件：已知$t=0$时，$x=x_0$，$v=v_0$
   - 通俗解释：初始位置和速度共同决定了振动的振幅大小和起始相位

### 旋转矢量法
- 振幅$A$：圆周半径
- 角频率$\omega$：匀角速度
- 位相$\omega t+\varphi$：旋转矢量与x轴的夹角
- 通俗解释：用一个匀速旋转的矢量在x轴上的投影来直观表示简谐振动，便于分析相位关系

## 2. 简谐振动的能量

1. **动能**：
   $$E_k = \frac{1}{2}mv^2 = \frac{1}{2}kA^2\sin^2(\omega t + \varphi)$$

2. **势能**：
   $$E_p = \frac{1}{2}kx^2 = \frac{1}{2}kA^2\cos^2(\omega t + \varphi)$$

3. **总能量**：
   $$E = E_k + E_p = \frac{1}{2}kA^2 = \frac{1}{2}m\omega^2A^2$$

4. **平均能量**：
   $$\overline{E_k} = \overline{E_p} = \frac{1}{4}kA^2 = \frac{1}{2}E$$

- 适用范围：无阻尼简谐振动系统
- 通俗解释：在振动过程中，能量在动能和势能之间转换，平衡位置处动能最大，势能为零；最大位移处势能最大，动能为零；总能量保持不变，且与振幅平方成正比

## 3. 振动的合成

### 同方向同频率振动的合成
1. **合振幅**：
   $$A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_2 - \varphi_1)}$$

2. **合振动初相**：
   $$\tan\varphi = \frac{A_1\sin\varphi_1 + A_2\sin\varphi_2}{A_1\cos\varphi_1 + A_2\cos\varphi_2}$$

3. **特殊情况**：
   - 同相($\Delta\varphi = 2k\pi$)：$A = A_1 + A_2$，振动加强
   - 反相($\Delta\varphi = (2k+1)\pi$)：$A = |A_1 - A_2|$，振动减弱

- 通俗解释：当两个振动同时作用在同一点时，它们的效果是叠加的，相位相同则加强，相位相反则减弱

### 拍现象
$$x = 2A_0\cos\left(\frac{\omega_1 - \omega_2}{2}t\right)\cos\left(\frac{\omega_1 + \omega_2}{2}t + \varphi\right)$$
- 拍频：$\nu = |\nu_1 - \nu_2|$
- 适用范围：频率相近的同方向振动
- 通俗解释：两频率相近的声音叠加时，产生强弱交替的变化，如用音叉调琴

### 垂直方向同频率振动的合成
$$\frac{x^2}{A_1^2} + \frac{y^2}{A_2^2} - \frac{2xy}{A_1A_2}\cos(\varphi_2 - \varphi_1) = \sin^2(\varphi_2 - \varphi_1)$$
- 特殊情况：
  - $\Delta\varphi = 0$或$\pi$：直线运动
  - $\Delta\varphi = \frac{\pi}{2}$或$\frac{3\pi}{2}$：椭圆运动
  - $\Delta\varphi = \frac{\pi}{2}$且$A_1 = A_2$：圆运动
- 通俗解释：两个垂直方向的振动合成，形成各种轨迹，如椭圆偏振光

### 李萨如图形
- 频率比：$\frac{\nu_x}{\nu_y} = \frac{N_y}{N_x}$
- 适用范围：相互垂直、频率成整数比的振动
- 通俗解释：用示波器观察两个垂直振动时，形成稳定闭合图形，用于测量频率

## 4. 阻尼振动、受迫振动和共振

### 阻尼振动
1. **运动方程**：
   $$\frac{d^2x}{dt^2} + 2\beta\frac{dx}{dt} + \omega_0^2x = 0$$
   - $\beta = \frac{\gamma}{2m}$：阻尼系数，$\gamma$阻力系数
   - $\omega_0 = \sqrt{\frac{k}{m}}$：固有角频率

2. **三种情况**：
   - 弱阻尼($\beta < \omega_0$)：
     $$x = Ae^{-\beta t}\cos(\omega t + \varphi_0),\ \omega = \sqrt{\omega_0^2 - \beta^2}$$
     适用范围：轻度阻尼系统
   - 临界阻尼($\beta = \omega_0$)：最快回到平衡位置
   - 过阻尼($\beta > \omega_0$)：无振荡地缓慢回到平衡位置
   - 通俗解释：考虑摩擦阻力的振动，振幅随时间指数衰减，如门上的阻尼器

### 受迫振动
1. **运动方程**：
   $$\frac{d^2x}{dt^2} + 2\beta\frac{dx}{dt} + \omega_0^2x = f_0\cos\omega t$$

2. **稳态解**：
   $$x = A_p\cos(\omega t + \alpha)$$
   - 振幅：$A_p = \frac{f_0}{\sqrt{(\omega_0^2 - \omega^2)^2 + 4\beta^2\omega^2}}$
   - 相位：$\tan\alpha = -\frac{2\beta\omega}{\omega_0^2 - \omega^2}$
   - 通俗解释：系统在外力持续驱动下的振动，经暂态过程后达到稳定

### 共振
- **位移共振频率**：$\omega_r = \sqrt{\omega_0^2 - 2\beta^2}$
- **共振振幅**：$A_{max} = \frac{f_0}{2\beta\sqrt{\omega_0^2 - \beta^2}}$
- **弱阻尼近似**($\beta \ll \omega_0$)：$\omega_r \approx \omega_0$，$A_{max} \approx \frac{f_0}{2\beta\omega_0}$
- 通俗解释：当外力频率接近系统固有频率时，振幅急剧增大。可用于乐器发声，也可能导致结构破坏，如Tacoma大桥坍塌

## 5. 机械波

### 波函数
1. **平面简谐波**：
   - 沿x正向：$y = A\cos\left[\omega\left(t - \frac{x}{u}\right) + \varphi\right] = A\cos(\omega t - kx + \varphi)$
   - 沿x负向：$y = A\cos\left[\omega\left(t + \frac{x}{u}\right) + \varphi\right] = A\cos(\omega t + kx + \varphi)$
   - 其中$k = \frac{2\pi}{\lambda} = \frac{\omega}{u}$为波数

2. **波动方程**：
   $$\frac{\partial^2 y}{\partial t^2} = u^2\frac{\partial^2 y}{\partial x^2}$$
   - 适用范围：平面波
   - 通俗解释：描述波在介质中传播的普遍规律

### 波的基本参数
- **波长$\lambda$**：相邻同相位点距离
- **周期$T$**：波传播一个波长所需时间
- **频率$\nu$**：$\nu = \frac{1}{T}$，由波源决定
- **波速$u$**：$u = \lambda\nu$，由介质决定
- **波数$k$**：$k = \frac{2\pi}{\lambda}$，单位长度内包含的波长数
- 通俗解释：波是振动状态的传播，质点本身不随波前进，只在平衡位置振动

## 6. 波的能量和能流

1. **能量密度**：
   $$w = \frac{1}{2}\rho\omega^2A^2\sin^2(\omega t - kx + \varphi)$$
   - $\rho$：介质密度
   - 通俗解释：波传播时携带能量，能量在动能和势能之间转换

2. **平均能量密度**：
   $$\overline{w} = \frac{1}{4}\rho\omega^2A^2$$

3. **能流密度（波强）**：
   $$I = wu = \frac{1}{2}\rho\omega^2A^2u$$
   - 平均能流密度：$\overline{I} = \frac{1}{4}\rho\omega^2A^2u$
   - 通俗解释：波强与振幅平方成正比，表示波传播能量的能力

4. **球面波振幅**：
   $$A \propto \frac{1}{r}$$
   - 适用范围：无吸收的理想介质
   - 通俗解释：球面波的振幅随距离增大而减小，因为能量分布到更大的球面上

## 7. 波的干涉

### 相干条件
- 频率相同
- 振动方向相同（或有平行分量）
- 相位差恒定
- 通俗解释：只有满足这些条件，才能形成稳定的干涉图样

### 干涉条件
1. **合振幅**：
   $$A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos\Delta\phi}$$
   - 相位差：$\Delta\phi = (\varphi_2 - \varphi_1) - \frac{2\pi}{\lambda}(r_2 - r_1)$

2. **加强条件**：
   $$\Delta\phi = 2k\pi \quad \text{或} \quad (r_2 - r_1) - \frac{\lambda}{2\pi}(\varphi_2 - \varphi_1) = k\lambda$$

3. **减弱条件**：
   $$\Delta\phi = (2k+1)\pi \quad \text{或} \quad (r_2 - r_1) - \frac{\lambda}{2\pi}(\varphi_2 - \varphi_1) = (2k+1)\frac{\lambda}{2}$$
   - 通俗解释：波叠加时，有些点始终振动加强，有些点始终振动减弱，形成明暗相间的条纹

## 8. 驻波

1. **驻波方程**：
   $$y = 2A\cos(kx)\cos(\omega t)$$
   - 适用范围：两列振幅相同、频率相同、方向相反的相干波叠加

2. **波节位置**：
   $$x_k = \pm\frac{(2k+1)\lambda}{4} \quad (k = 0, 1, 2, ...)$$

3. **波腹位置**：
   $$x_k = \pm\frac{k\lambda}{2} \quad (k = 0, 1, 2, ...)$$

4. **固定端弦振动**：
   $$l = n\frac{\lambda_n}{2},\ \nu_n = \frac{nu}{2l}$$
   - $u = \sqrt{\frac{T}{\rho}}$，$T$为张力，$\rho$为线密度
   - 通俗解释：弦乐器发声原理，不同振动模式产生不同音高

5. **半波损失**：
   - 波疏→波密反射：有半波损失（相位突变$\pi$），反射点为波节
   - 波密→波疏反射：无半波损失，反射点为波腹
   - 通俗解释：反射时可能发生的相位突变现象，如固定端绳子的反射

## 9. 多普勒效应

1. **机械波多普勒效应**：
   $$\nu_R = \nu_S\frac{u - V_R}{u - V_S}$$
   - 符号规则：相互接近取负号，远离取正号
   - 通俗解释：当救护车驶向你时，警笛声调变高；远离时，声调变低

2. **冲击波（马赫锥）**：
   $$\sin\frac{\alpha}{2} = \frac{u}{V_S} = \frac{1}{M}$$
   - $M = \frac{V_S}{u}$：马赫数，$V_S > u$时出现
   - 通俗解释：超音速飞机飞行时产生的锥形波，会导致音爆

3. **电磁波多普勒效应**：
   - 两者接近：$\nu' = \nu\sqrt{\frac{1+V/c}{1-V/c}}$
   - 两者远离：$\nu' = \nu\sqrt{\frac{1-V/c}{1+V/c}}$
   - 通俗解释：天文学中的红移现象，表明星系正在远离地球，支持大爆炸理论

## 10. 电磁振荡与电磁波

### LC振荡电路
1. **振荡方程**：
   $$\frac{d^2q}{dt^2} + \frac{1}{LC}q = 0$$
   - 角频率：$\omega = \frac{1}{\sqrt{LC}}$
   - 电荷：$q = q_m\cos(\omega t + \varphi)$
   - 电流：$I = -\omega q_m\sin(\omega t + \varphi) = I_m\cos(\omega t + \varphi + \frac{\pi}{2})$
   - 通俗解释：电容器和线圈组成的电路中，电荷和电流周期性变化

2. **能量关系**：
   - 电场能：$W_e = \frac{q^2}{2C}$
   - 磁场能：$W_m = \frac{1}{2}LI^2$
   - 总能量：$W = W_e + W_m = \frac{q_m^2}{2C} = \text{常量}$
   - 通俗解释：能量在电场和磁场之间转换，总能量守恒

### 电磁波
1. **基本性质**：
   - 电场和磁场互相垂直，且垂直于传播方向
   - 波速：$u = \frac{1}{\sqrt{\varepsilon\mu}}$，真空中$c = 3\times10^8\,\text{m/s}$
   - 电场和磁场关系：$E = vB$，$E_m = vH_m$
   - 通俗解释：电磁波是横波，可以在真空中传播，不需要介质

2. **平面电磁波方程**：
   $$E_y = E_m\cos(\omega t - kx)$$
   $$H_z = H_m\cos(\omega t - kx)$$
   - 通俗解释：电磁波中的电场和磁场同步振荡，相互激发

3. **能流密度（坡印廷矢量）**：
   $$\vec{S} = \vec{E}\times\vec{H}$$
   - 平均能流密度：$\overline{S} = \frac{1}{2}E_mH_m$
   - 通俗解释：太阳光照射到地球表面的能量传输，电磁能的传播方式

4. **电磁波谱**：
   - 从无线电波到$\gamma$射线，频率递增，波长递减
   - 通俗解释：所有电磁波本质相同，只是频率不同，应用领域各异
