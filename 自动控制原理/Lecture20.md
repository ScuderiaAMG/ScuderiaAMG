# 第20讲：奈氏稳定判据（Nyquist Stability Criterion）

## 一、奈氏判据原理

### 1.1 奈氏判据的优势

| 优势 | 说明 |
|------|------|
| 作图分析 | 计算量小，信息量大 |
| 信息丰富 | 不但判断稳定性，还给出不稳定根个数和稳定裕度 |
| 支持延迟 | 系统含延迟环节时，利用奈氏判据很方便 |
| 可推广 | 可推广到一类非线性系统和多变量系统 |

### 1.2 幅角原理（数学基础）

设复数平面上的回路 $\Gamma_s$ 的内部为 $I(\Gamma_s)$。若函数 $F(s)$ 在 $I(\Gamma_s)$ 中除有限个极点外处处解析，且在 $\Gamma_s$ 上解析且处处不为零，则：

$$P_{F,\Gamma_s} - Z_{F,\Gamma_s} = \frac{1}{2\pi}\Delta\angle F(s)$$

其中：
- $P$：$F(s)$ 在 $\Gamma_s$ 内部的**极点**个数
- $Z$：$F(s)$ 在 $\Gamma_s$ 内部的**零点**个数
- $\Delta\angle F(s)$：$s$ 沿**顺时针**方向环绕 $\Gamma_s$ 一周时，$F(s)$ 幅角的增量（逆时针为正）

**说明**：
1. $\Gamma_s$ 不经过 $F(s)$ 的极点和零点
2. 幅角增量是绕原点**逆时针**旋转的角度
3. $m$ 重极点（或零点）算作 $m$ 个

### 1.3 幅角原理的几何理解

设 $F(s) = \frac{K \cdot M(s)}{N(s)}$，零点为 $z_i$，极点为 $p_j$。

在 $S$ 平面取封闭曲线 $\Gamma_s$，在 $F$ 平面上的映射为 $\Gamma_F$：

$$\angle F(s) = \sum_{i=1}^{m} \angle(s - z_i) - \sum_{j=1}^{n} \angle(s - p_j)$$

当 $s$ 沿 $\Gamma_s$ **顺时针**转一周时：
- $\Gamma_s$ **外部**的零/极点：对应向量旋转 $0°$
- $\Gamma_s$ **内部**的零/极点：对应向量旋转 $-2\pi$

$$\Delta\{\angle F(s)\} = -2\pi(Z - P)$$

即 $\Gamma_F$ 绕原点**逆时针**旋转的周数 $N$：

$$\boxed{N = P - Z}$$

> 通俗理解：想象你站在原点看一个人沿封闭曲线走一圈。如果曲线包围了你，你的视线会转一整圈；如果不包围你，视线最终回到原方向。每个被包围的极点贡献 $+1$ 圈（逆时针），每个被包围的零点贡献 $-1$ 圈（顺时针）。

### 1.4 辅助函数 $F(s)$ 的选取

引入辅助函数：

$$F(s) = 1 + G(s)H(s)$$

**关键性质**：

| $F(s)$ 的零点 | = 闭环传递函数的极点 |
|---|---|
| $F(s)$ 的极点 | = 开环传递函数的极点 |
| $F(s)$ 的分子和分母阶次 | 均为 $n$ |

> 稳定性问题转化为：**$F(s)$ 的零点是否全部在 $S$ 左半平面**。

### 1.5 从幅角原理到奈氏判据

**思路**：
1. $\Gamma_s$ 取为**包围右半平面**的封闭曲线（D 形围线）
2. 已知开环传函 $G(s)H(s)$ → 知道 $\Gamma_s$ 内的 $P$ 值（右半平面开环极点数）
3. $F(s) = 1 + G(s)H(s)$ 与 $G(s)H(s)$ 只差常数 1 → 坐标平移：$F$ 平面的原点对应 $GH$ 平面的 $(-1, j0)$ 点
4. $\Gamma_F$ 绕 $F$ 平面原点 ↔ $G(s)H(s)$ 的曲线绕 $GH$ 平面的 $(-1, j0)$ 点

**$S$ 平面顺时针包围右半平面时，映射到 $GH$ 平面**：

| 围线段 | $S$ 平面 | $GH$ 平面映射 |
|:---:|------|------|
| 第1段 | $s = -j\omega$（$\omega: +\infty \to 0$） | $G(-j\omega)H(-j\omega)$，即奈氏曲线的共轭部分 |
| 第2段 | $s = j\omega$（$\omega: 0 \to +\infty$） | $G(j\omega)H(j\omega)$，即奈氏曲线本身 |
| 第3段 | $s = Re^{j\theta}$（$R \to \infty$） | 若 $n > m$：映射到原点；若 $n = m$：映射到常数 $b_m/a_n$ |

> **结论1**：开环极点没有虚根和零根时，$S$ 平面上 $\Gamma_s$ 映射到 $GH$ 平面即为完整的奈氏曲线（$\omega: -\infty \to +\infty$）。

### 1.6 含积分环节的增补段

**若开环传函含 $v$ 个积分环节**（原点处有开环极点），$\Gamma_s$ 在原点处增加一个**半径为无穷小的半圆**绕过原点：

$$s = \lim_{r \to 0} re^{j\theta},\quad -90° \leq \theta \leq 90°$$

映射到 $GH$ 平面：

$$G(s)H(s)\Big|_{s = \lim_{r \to 0} re^{j\theta}} = \infty \cdot e^{-jv\theta}$$

> **结论2**：含 $v$ 个积分环节时，除了画 $\omega: -\infty \to +\infty$ 的完整奈氏曲线外，还需增加 $\omega: 0^- \to 0^+$ 时**顺时针绕原点转 $v\pi$ 角度**的无穷大圆弧。

> 通俗理解：积分环节让 $\omega = 0$ 时幅值为无穷大，所以曲线在无穷远处"断开"。增补段就是用无穷大半径的圆弧把断口接上，圆弧转过的角度取决于积分环节的个数。

### 1.7 含虚轴极点的增补段

**若虚轴上有开环极点** $\pm j\omega_0$（重数 $v$），$\Gamma_s$ 在该极点处增加无穷小半圆绕过：

$$s = j\omega_0 + \lim_{r \to 0} re^{j\theta},\quad -90° \leq \theta \leq 90°$$

映射到 $GH$ 平面：

$$G(s)H(s)\Big|_{s \to j\omega_0} = \infty \cdot e^{-jv\theta}$$

> **结论3**：含共轭虚极点 $\pm j\omega_0$ 时，需增加 $\omega: \omega_0^- \to \omega_0^+$ 以及 $\omega: -\omega_0^+ \to -\omega_0^-$ 时**顺时针绕原点转 $v\pi$ 角度**的无穷大圆弧。

### 1.8 奈氏稳定判据（完整表述）

设 $P$ 为 $S$ 平面右半平面的**开环极点数**，$N$ 为奈氏曲线（含增补段）**逆时针**包围 $(-1, j0)$ 点的次数。

**若奈氏曲线不穿过 $(-1, j0)$ 点**：

| 条件 | 结论 |
|------|------|
| $P = N$ | 闭环系统**稳定** |
| $P - N > 0$ | 闭环系统**不稳定**，右半平面闭环极点个数 $Z = P - N$ |

> 注：逆时针包围时 $N > 0$，顺时针包围时 $N < 0$，不包围时 $N = 0$。

**推论**：
- 若奈氏曲线**顺时针**包围 $(-1, j0)$，则 $N < 0$，系统不稳定
- 若开环稳定（$P = 0$），则奈氏曲线**不包围** $(-1, j0)$ 时系统稳定

> 通俗理解：奈氏判据的核心就是"数圈数"——看奈氏曲线绕着 $(-1, j0)$ 这个"危险点"转了几圈。开环有几个右半平面极点，曲线就必须逆时针绕几圈，闭环才能稳定。

### 1.9 奈氏曲线穿过 $(-1, j0)$ 点的情况

**推论**：闭环系统存在纯虚根（或零根），**当且仅当**奈氏曲线穿过 $(-1, j0)$ 点。

**证明**：
- 若闭环有纯虚根 $s_1 = j\omega_1$，则 $1 + G(j\omega_1)H(j\omega_1) = 0$，即 $G(j\omega_1)H(j\omega_1) = -1$ → 曲线经过 $(-1, j0)$
- 若闭环有零根，则 $G(0)H(0) = -1$ → 曲线起点在 $(-1, j0)$

此时幅角原理不直接适用，需要**修正奈氏曲线**。

## 二、奈氏判据例题

### 2.1 例1：含两个积分环节的系统

**题目**：已知 $G(s) = \frac{K(\tau s + 1)}{s^2(Ts + 1)}$，分析稳定性。

**解**：

$$G(j\omega) = \frac{K[-1 - \tau T\omega^2 + j(T-\tau)\omega]}{\omega^2(1+T^2\omega^2)}$$

$P = 0$（无右半平面开环极点），两个积分环节，增补段 $\omega: 0^- \to 0^+$ 顺时针绕原点 $2\pi$。

**分情况讨论**：

| 情况 | 条件 | 奈氏曲线行为 | 稳定性 |
|------|------|------------|:---:|
| $\tau > T$ | 零点作用强 | 不包围 $(-1, j0)$ | **稳定** |
| $\tau < T$ | 极点作用强 | 顺时针包围 $(-1, j0)$ 两周 | **不稳定**，$Z = 0 - (-2) = 2$ |
| $\tau = T$ | 零极抵消 | 穿过 $(-1, j0)$ | **临界稳定**（有虚轴闭环极点） |

> 通俗理解：分子上的零点 $(\tau s+1)$ 把曲线"往上拉"。$\tau$ 越大（零点越靠近虚轴），拉力越强，曲线越不容易包围 $(-1, j0)$。当 $\tau = T$ 时，曲线刚好擦过 $(-1, j0)$。

### 2.2 例2：最小相位系统的开环增益影响

**题目**：已知最小相位系统的开环幅相曲线如图所示（含 3 个积分环节），分析 $K$ 对稳定性的影响。

**解**：$P = 0$（最小相位系统），3 个积分环节，增补段顺时针旋转 $3\pi$。

起点相角 $-270°$，曲线形成多个"圆环"。

**当前位置**：小圆逆时针包围 $(-1, j0)$ 一周，大圆顺时针包围 $(-1, j0)$ 一周 → 等效不包围 → **稳定**。

| $K$ 的变化 | $(-1, j0)$ 的相对位置 | 稳定性 |
|:---:|------|:---:|
| $K$ 增大到 $(-1, j0)$ 进入内层圆 | 被顺时针包围 2 周 | **不稳定** |
| $K$ 减小到 $(-1, j0)$ 进入最外层圆 | 被顺时针包围 2 周 | **不稳定** |
| $K$ 使曲线穿过 $(-1, j0)$ | — | **临界稳定** |

> 通俗理解：$K$ 的变化等价于把整个奈氏曲线"放大"或"缩小"。$(-1, j0)$ 点相对于曲线的位置就变了——有时被包围，有时不被包围，所以系统有条件稳定。

### 2.3 例3：求稳定的 $K$ 范围

**题目**：已知 $K = 500$ 时单位负反馈系统的开环幅相曲线，$P = 0$，$r = 1$。与实轴交点处幅值分别为 $50$、$20$、$0.05$（频率从小到大 $\omega_1$、$\omega_2$、$\omega_3$）。求稳定 $K$ 范围。

**解**：设 $G(s) = K \cdot G_1(s)$，其中 $G_1(s)$ 的开环增益为 1。

$K = 500$ 时各交点幅值：$|G(j\omega_1)| = 50$，$|G(j\omega_2)| = 20$，$|G(j\omega_3)| = 0.05$。

对应的 $G_1$ 值：$|G_1(j\omega_1)| = 1/10$，$|G_1(j\omega_2)| = 1/25$，$|G_1(j\omega_3)| = 1/1000$。

**稳定条件**：$(-1, j0)$ 不被包围。需要：

$$\frac{K}{1000} < 1 < \frac{K}{25} \quad \text{或} \quad \frac{K}{10} < 1$$

解得：

$$\boxed{25 < K < 1000 \quad \text{或} \quad 0 < K < 10}$$

> 通俗理解：$K$ 太大或太小都不行——太大会让 $(-1, j0)$ 被外层圆包围，太小会让它落入内层圆。只有在两个"窗口"内，曲线才不会包围 $(-1, j0)$。

### 2.4 例4：由特征方程构造开环传函

**题目**：已知闭环特征方程 $s^3 + 5Ks^2 + (2K+3)s + 10 = 0$，用奈氏判据确定稳定 $K$ 的范围。

**解**：

**(1) 构造等效开环传函**：

将特征方程写成 $1 + G(s) = 0$ 的形式：

$$s^3 + 3s + 10 + K(5s^2 + 2s) = 0 \implies G(s) = \frac{K(5s^2 + 2s)}{s^3 + 3s + 10}$$

**(2) 判断开环极点数 $P$**：

对 $s^3 + 3s + 10 = 0$ 做劳斯判据：

| $s^3$ | $1$ | $3$ |
|:---:|:---:|:---:|
| $s^2$ | $\varepsilon$ | $10$ |
| $s^1$ | $-10/\varepsilon$ | $0$ |
| $s^0$ | $10$ | |

第一列变号 2 次 → $P = 2$（2 个右半平面开环极点）。

**(3) 绘制奈氏曲线**：

$$G(j\omega) = \frac{K\omega^2(44 + 2\omega^2) + j4K\omega(4 + 3\omega^2 - \omega^4)}{100 + (3\omega - \omega^3)^2}$$

$\omega = 2$ 时，虚部 $= 0$，实部 $= -2K$。

**(4) 稳定条件**：$N = P = 2$（需逆时针包围 $(-1, j0)$ 两次）。

当 $\omega = 2$ 时实部 $= -2K$，需 $-2K < -1$，即：

$$\boxed{K > 1/2}$$

### 2.5 例5：含虚轴极点的系统

**题目**：已知 $G(s) = \frac{10}{s(s+1)(\frac{1}{4}s^2+1)}$，用奈氏判据判断稳定性。

**解**：

开环极点：$s = 0, -1, \pm j2$。虚轴上有极点 $\pm j2$，需增补段。

$$G(j\omega) = \frac{10}{j\omega(1+j\omega)(1-\omega^2/4)}$$

$$|G(j\omega)| = \frac{10}{\omega\sqrt{\omega^2+1} \cdot |1-\omega^2/4|}$$

$$\angle G(j\omega) = \begin{cases} -90° - \arctan\omega, & \omega \leq 2 \\ -270° - \arctan\omega, & \omega > 2 \end{cases}$$

**关键频率分析**：

| $\omega$ | $\|G\|$ | $u(\omega)$ | $v(\omega)$ |
|:---:|:---:|:---:|:---:|
| $0$ | $\infty$ | $-10$ | $-\infty$ |
| $\to 2^-$ | $\to +\infty$ | $\to -\infty$ | $\to -\infty$ |
| $\to 2^+$ | $\to +\infty$ | $+\infty$ | $+\infty$ |
| $\to +\infty$ | $0$ | $0$ | $0$ |

$\omega = 2$ 处有虚轴极点，曲线在无穷远处"断裂"。$\Gamma_s$ 在 $\pm j2$ 处增加无穷小半圆，映射到 $GH$ 平面为无穷大圆弧（顺时针转 $\pi$）。

**判断**：$P = 0$（无右半平面极点），奈氏曲线顺时针包围 $(-1, j0)$ **2 周**。

$$Z = P - N = 0 - (-2) = 2$$

> **系统不稳定，有 2 个右半平面闭环极点。**

### 2.6 修正的奈氏判据（曲线穿过 $(-1, j0)$ 时）

当奈氏曲线穿过 $(-1, j0)$ 点时，需绘制**修正的奈氏曲线**。

**命题5.3**（起点在 $(-1, j0)$ 时——闭环极点在原点）：

令 $u(\omega) = -1, v(\omega) = 0$ 联立，其解 $\omega$ 的重数即为原点处闭环极点的重数 $v$。

修正方法：$\omega: 0^- \to 0^+$ 时，以无穷小半径**逆时针**绕 $(-1, j0)$ 转 $v\pi$ 角度。

**命题5.4**（曲线中途穿过 $(-1, j0)$——闭环极点在虚轴上）：

设虚轴闭环极点为 $\pm j\omega_0$，重数 $v$。修正方法：
- $\omega: \omega_0^- \to \omega_0^+$ 时，逆时针绕 $(-1, j0)$ 转 $v\pi$
- $\omega: -\omega_0^+ \to -\omega_0^-$ 时，逆时针绕 $(-1, j0)$ 转 $v\pi$

**命题5.5**（修正的奈氏判据）：

| 条件 | 结论 |
|------|------|
| $P = N$（修正后） | 闭环系统**临界稳定** |
| $P > N$（修正后） | **不稳定**，$Z = P - N$ |

> 通俗理解：修正就是在曲线"擦过" $(-1, j0)$ 的地方画一个极小的圆弧绕过去——相当于在说"曲线到底是绕着 $(-1, j0)$ 转了一圈还是没转"，这个微小的圆弧就决定了圈数的计算。

### 2.7 例6：修正判据的应用

**题目**：$G(s) = \frac{K(\tau s+1)}{s^2(Ts+1)}$，当 $\tau = T$ 时分析稳定性。

**解**：$\tau = T$ 时，$u(\omega) = -1, v(\omega) = 0$ 的解为 $\omega = \pm\sqrt{K}$。

奈氏曲线在 $\omega = \pm\sqrt{K}$ 时穿过 $(-1, j0)$，闭环极点有纯虚根 $\pm j\sqrt{K}$，单重根（$v = 1$）。

**修正**：
- $\omega: \sqrt{K}^- \to \sqrt{K}^+$ 时，逆时针绕 $(-1, j0)$ 转 $\pi$
- $\omega: -\sqrt{K}^+ \to -\sqrt{K}^-$ 时，对称可得

修正后：逆时针和顺时针各包围 $(-1, j0)$ **1 次**，$P = 0$。

$$Z = P - N = 0 - 0 = 0$$

> **系统临界稳定**（有纯虚闭环极点 $\pm j\sqrt{K}$，但无右半平面极点）。

## 三、奈氏判据推广

### 3.1 "穿越"的概念

在只绘制 $\omega: 0 \to +\infty$ 的幅相曲线时，引入"穿越"概念。

**穿越**：开环幅相曲线穿过 $(-1, j0)$ 点**左边实轴**（即 $-1 \to -\infty$ 段）的情况。

| 穿越类型 | 定义 | 等价于 |
|---------|------|--------|
| **正穿越** $N^+$ | $\omega$ 增大时，曲线**由上而下**穿过负实轴 | 逆时针包围 $(-1, j0)$ 一圈 |
| **负穿越** $N^-$ | $\omega$ 增大时，曲线**由下而上**穿过负实轴 | 顺时针包围 $(-1, j0)$ 一圈 |

> 正穿越时相角**增加**（从 $> -180°$ 变到 $< -180°$），负穿越时相角**减小**。

**奈氏曲线逆时针绕 $(-1, j0)$ 的圈数**：

$$N = 2(N^+ - N^-)$$

> 乘以 2 是因为完整奈氏曲线包含 $\omega: 0 \to +\infty$ 和 $\omega: -\infty \to 0$ 两部分（关于实轴对称）。

**注意**：
- 幅相曲线**起点**在 $(-1, j0)$ 左边实轴时，记**半次**穿越
- 原点处有 $v$ 个积分环节时，增补段从 $\omega = 0^-$ 的逆时针 $v \times 90°$ 处以无穷大半径**顺时针**旋转至 $\omega = 0^+$ 处

### 3.2 幅相曲线上的奈氏判据

设 $P$ 为右半平面开环极点数，$N^+$、$N^-$ 为正负穿越次数。

**若幅相曲线不穿过 $(-1, j0)$**：

| 条件 | 结论 |
|------|------|
| $P = 2(N^+ - N^-)$ | **稳定** |
| $P > 2(N^+ - N^-)$ | **不稳定**，$Z = P - 2(N^+ - N^-)$ |

**若幅相曲线穿过 $(-1, j0)$**（修正后判断）：

| 条件 | 结论 |
|------|------|
| $P = 2(N^+ - N^-)$ | **临界稳定** |
| $P > 2(N^+ - N^-)$ | **不稳定**，$Z = P - 2(N^+ - N^-)$ |

### 3.3 例7：含不稳定极点的系统

**题目**：$G(s) = \frac{K}{(T_1 s - 1)(T_2 s + 1)(T_3 s + 1)}$，$T_1 > T_2 + T_3 > T_2 > T_3 > 0$，判断稳定性。

**解**：$P = 1$（$s = 1/T_1$ 是右半平面极点）。

$$u(\omega) \leq 0 \text{ 恒成立}$$

$$v(\omega) \text{ 先变负后变正（因为 } T_1 > T_2 + T_3 \text{）}$$

**起点**（$\omega = 0$）：$G(j0) = -K$（在负实轴上）。

| $K$ 的范围 | 穿越情况 | $Z$ | 稳定性 |
|:---:|------|:---:|:---:|
| $K < 1$ | 无穿越 | $Z = 1 - 0 = 1$ | **不稳定** |
| $K = 1$ | 起点在 $(-1, j0)$，半次正穿越 | $Z = 1 - 2(0.5 - 0) = 0$ | **临界稳定** |
| $K > 1$，$u(\omega_1) > -1$ | 半次正穿越 | $Z = 1 - 2(0.5) = 0$ | **稳定** |
| $K > 1$，$u(\omega_1) < -1$ | 半次正穿越 + 1 次负穿越 | $Z = 1 - 2(0.5 - 1) = 2$ | **不稳定** |
| $K > 1$，$u(\omega_1) = -1$ | 穿过 $(-1, j0)$ | $Z = 0$ | **临界稳定** |

> 通俗理解：这个系统有一个右半平面极点，所以"天然不稳定"。要让闭环稳定，奈氏曲线必须逆时针绕 $(-1, j0)$ 一圈来"抵消"这个不稳定极点。$K$ 要够大（让起点超过 $(-1, j0)$），但又不能太大（否则曲线又绕回来了）。

---

### 3.4 Bode 图上的奈氏判据

**$GH$ 平面与 Bode 图的对应关系**：

| $GH$ 平面 | Bode 图 |
|-----------|---------|
| 单位圆 | 对数幅频 $0$ dB 线 |
| 单位圆外 | $L(\omega) > 0$ dB |
| 单位圆内 | $L(\omega) < 0$ dB |
| 负实轴 | 相频 $-180°$ 线 |
| 逆时针绕 $(-1, j0)$ | 正穿越（相频由下往上穿 $-180°$ 线） |
| 顺时针绕 $(-1, j0)$ | 负穿越（相频由上往下穿 $-180°$ 线） |

**利用 Bode 图判断稳定性**：

在对数幅频特性 $L(\omega) > 0$ dB 的频段内：

| 穿越类型 | 定义 |
|---------|------|
| 正穿越 $N^+$ | 相频曲线由**下往上**穿过 $-180°$ 线（相角增加） |
| 负穿越 $N^-$ | 相频曲线由**上往下**穿过 $-180°$ 线（相角减小） |

**判据**：

$$Z = P - 2(N^+ - N^-)$$

- $Z = 0$：稳定
- $Z > 0$：不稳定，有 $Z$ 个右半平面闭环极点

**增补段**：设相频起始角度为 $\varphi_0$，则增加一段从 $\varphi_0$ 到 $\varphi_0 + v \times 90°$ 的连线（$v$ 为积分环节数）。

> 通俗理解：在 Bode 图上判断稳定性，就是看**增益大于 1 的频率范围内**，相角有没有"越过" $-180°$ 线。如果相角越过了 $-180°$ 线（负穿越），说明在那个频率下信号既被放大又被反相，系统可能不稳定。

### 3.5 例8：Bode 图判断稳定性

**题目**：$G(s) = \frac{30}{s(0.1s+1)(0.2s+1)}$，用 Bode 图判断稳定性。

**解**：$P = 0$。

Bode 图：
- 转折频率：$\omega = 5$（惯性1），$\omega = 10$（惯性2）
- $\omega_c$（剪切频率）$\approx 11$
- 相频在 $L(\omega) > 0$ 的频段内**负穿越** $-180°$ 线 **1 次**

$$N^+ = 0,\quad N^- = 1$$

$$Z = P - 2(N^+ - N^-) = 0 - 2(0 - 1) = 2$$

> **系统不稳定，有 2 个右半平面闭环极点。**

### 3.6 例9：含积分环节的 Bode 图判据

**题目**：$G(s)H(s) = \frac{500(0.5s+1)(s+1)}{s^2(10s+1)(5s+1)(0.1s+1)(0.025s+1)}$，判断稳定性。

**解**：$P = 0$，2 个积分环节。

**增补段**：相频起始角度 $-180°$（2 个积分环节），增加从 $-180°$ 到 $-180° + 2 \times 90° = 0°$ 的连线。

在 $L(\omega) > 0$ 的频段内：$N^+ = 0$，$N^- = 1$。

$$Z = P - 2(N^+ - N^-) = 0 - 2(0 - 1) = 2$$

> **系统不稳定，有 2 个右半平面闭环极点。**

### 3.7 奈氏判据的陷阱——极零相消

**题目**：系统结构图中，$G(s) = \frac{10}{s(s+1)(0.1s+1)}$，$H(s) = s$，判断稳定性。

**解**：

**(1) 求开环传函**：$G(s)H(s) = \frac{10}{(s+1)(0.1s+1)}$

$P = 0$，奈氏曲线不包围 $(-1, j0)$ → 奈氏判据判断：**稳定**。

**(2) 验证**：闭环传函 $\Phi(s) = \frac{10}{s[\frac{s+1}{0.1s+1} + 10]}$

存在极点 $s = 0$ → 闭环系统**不稳定**！

**问题**：$G(s)$ 的极点 $s = 0$ 和 $H(s)$ 的零点 $s = 0$ **相消**了。求开环传函时，这个极点被消掉了，导致奈氏判据"看不到"它。

> **结论**：当求开环传函出现 $G(s)$ 中的极点和 $H(s)$ 中的零点相消时，**需检查奈氏判据的有效性**。被消掉的极点可能仍然存在于闭环系统中。

## 四、总结

### 4.1 奈氏判据操作步骤

```
① 确定 P：右半平面开环极点数
        ↓
② 绘制完整奈氏曲线（ω: -∞ → +∞）
   - 先画 ω: 0 → +∞ 的幅相曲线
   - 关于实轴对称得到 ω: -∞ → 0 部分
        ↓
③ 画增补段：
   - v 个积分环节：ω: 0⁻ → 0⁺，顺时针绕原点 vπ
   - 虚轴极点 ±jω₀：ω: ω₀⁻ → ω₀⁺，顺时针绕原点 vπ
        ↓
④ 数包围圈数 N（逆时针为正）：
   法1：完整曲线数圈数
   法2：只画 ω: 0→+∞，用穿越法 N = 2(N⁺ - N⁻)
        ↓
⑤ 判断：Z = P - N
   Z = 0 → 稳定
   Z > 0 → 不稳定（Z 个右半平面闭环极点）
        ↓
⑥ 若穿过 (-1, j0)：修正后判断
   P = N → 临界稳定
```

### 4.2 增补段速查

| 情况 | 增补段 |
|------|--------|
| $v$ 个积分环节 | $\omega: 0^- \to 0^+$，无穷大圆弧顺时针转 $v\pi$ |
| 虚轴极点 $\pm j\omega_0$（重数 $v$） | $\omega: \omega_0^- \to \omega_0^+$，无穷大圆弧顺时针转 $v\pi$ |
| 曲线穿过 $(-1, j0)$ | 以无穷小圆弧**逆时针**绕 $(-1, j0)$ 转 $v\pi$ |

### 4.3 Bode 图判据速查

| 要素 | 操作 |
|------|------|
| 观察频段 | 只看 $L(\omega) > 0$ dB 的频段 |
| 正穿越 $N^+$ | 相频由下往上穿 $-180°$ 线 |
| 负穿越 $N^-$ | 相频由上往下穿 $-180°$ 线 |
| 增补段 | 积分环节 $v$ 个：从 $\varphi_0$ 连到 $\varphi_0 + v \times 90°$ |
| 判据 | $Z = P - 2(N^+ - N^-)$，$Z = 0$ 则稳定 |

### 4.4 常见陷阱

| 陷阱 | 说明 |
|------|------|
| 极零相消 | $G(s)$ 的极点与 $H(s)$ 的零点相消时，奈氏判据可能遗漏闭环极点 |
| 穿越计数 | 起点在 $(-1, j0)$ 左边实轴上时，记**半次**穿越 |
| 修正方向 | 穿过 $(-1, j0)$ 时的修正圆弧是**逆时针**（与开环极点增补段方向相反） |
| 临界稳定 | $Z = 0$ 且曲线穿过 $(-1, j0)$ → 临界稳定（有虚轴闭环极点），**不是**稳定 |
