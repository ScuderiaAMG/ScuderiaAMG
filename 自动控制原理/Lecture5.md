## 一、前讲回顾（Lecture 4 要点）

### 1.1 传递函数的一般形式

$$G(s)=\frac{C(s)}{R(s)}=\frac{K s^l (\tau_1 s+1)(\tau_2^2 s^2+2\zeta_2\tau_2 s+1)\cdots(\tau_m' s+1)}{s^v (T_1 s+1)(T_2^2 s^2+2\zeta_2' T_2 s+1)\cdots(T_n' s+1)}$$

其中 $K, \tau_i, \zeta_i, T_j, \zeta_j'$ 为常数，非负整数 $l$ 和 $v$ 不同时为零。

### 1.2 传递函数的七种基本环节（回顾）

| 环节 | 传递函数 | 备注 |
|------|----------|------|
| 比例环节 | $K$ | |
| (理想)微分环节 | $s$ | |
| (理想)一阶微分环节 | $\tau s+1$ | |
| (理想)二阶微分环节 | $\tau^2 s^2+2\zeta\tau s+1$ | |
| 积分环节 | $\frac{1}{s}$ | |
| 惯性环节 | $\frac{1}{Ts+1}$ | |
| 振荡环节(二阶环节) | $\frac{1}{T^2 s^2+2\zeta T s+1}$ | |

### 1.3 前5条等效变换法则（回顾）

| 法则 | 内容 | 等效公式 |
|------|------|----------|
| **法则1** | 串联连接 | $G(s)=G_1(s)G_2(s)$ |
| **法则2** | 并联连接 | $G(s)=G_1(s)\pm G_2(s)$ |
| **法则3** | 反馈连接 | $\Phi(s)=\frac{G(s)}{1\mp H(s)G(s)}$（**减号对应正反馈**） |
| **法则4** | 综合点移动 | 前移：除以 $G(s)$；后移：乘以 $G(s)$ |
| **法则5** | 引出点移动 | 后移：除以 $G(s)$；前移：乘以 $G(s)$ |

> **注意**：前移/后移是相对于信号流向而言——顺着信号流向为**后移**。

### 1.4 闭环传递函数（重点）

$$\Phi(s) = \frac{G(s)}{1 \mp H(s)G(s)}$$

- $G(s)$：前向通路传递函数
- $H(s)$：反馈通路传递函数
- 分母取 $-$（负号）→ **正反馈**；分母取 $+$（正号）→ **负反馈**
- $H(s)=1$ 时称为**单位反馈系统**

## 二、新增等效变换法则（本讲核心）

### 2.1 法则6：相邻综合点/相邻引出点的移动

**两个或若干相邻的综合点可以任意移动位置：**

```
  R     C        →        R     C
  ↓     ↓                 ↓     ↓
  ○  P  ○  Q              ○  Q  ○  P
  ±     ±                 ±     ±
```

**两个或若干相邻的引出点可以任意移动位置。**

### 2.2 重要注意事项

> **引出点与综合点之间一般不做移动！**
> 等效变换时，引出点与综合点尽量**向同类移动**（综合点移向综合点，引出点移向引出点）。

## 三、结构图等效变换 — 六条法则汇总

| 法则 | 操作 | 口诀 |
|------|------|------|
| 法则1 | 串联 → 相乘 | $G = G_1 G_2$ |
| 法则2 | 并联 → 相加 | $G = G_1 \pm G_2$ |
| 法则3 | 反馈 → 公式 | $\Phi = \frac{G}{1 \mp GH}$（负号对应正反馈） |
| 法则4 | 综合点前移 ÷ $G$，后移 × $G$ | "前除后乘" |
| 法则5 | 引出点后移 ÷ $G$，前移 × $G$ | "后除前乘"（与综合点方向相反！） |
| 法则6 | 相邻综合点/引出点可任意换位 | 同类可移，异类不动 |

### 关键对称性记忆

```
综合点移动：前移÷G，后移×G（顺流为后）
引出点移动：前移×G，后移÷G（与综合点恰好相反）
```

## 四、典型例题精讲

### 例题1.1：具有交叉回路的结构图等效变换

**问题**：化简含有交叉反馈的 RC 网络结构图。

**关键步骤**：
1. 先识别交叉回路，分析信号流向
2. 将相邻综合点互换（利用法则6），使交叉解耦
3. 逐个化简内环 → 外环

**结果**：
$$G(s)=\frac{1}{R_1R_2C_1C_2s^2+(R_1C_1+R_2C_2+R_1C_2)s+1}$$

---

### 例题1.2：具有顺馈和反馈交叉回路的结构图等效变换

**结构特点**：前向通路中含有 $G_1(s)$、$G_2(s)$，同时存在顺馈和反馈交叉。

**关键步骤**：
1. 将综合点 A **前移**（移到 $G_1$ 之前），移动支路上**除以** $G_1(s)$
2. 将两个顺馈通路转化为标准反馈形式
3. 用反馈公式合并

**结果**：
$$\frac{C(s)}{R(s)}=\frac{G_2(s)}{1+G_1(s)H_1(s)}+\frac{G_1(s)G_2(s)}{1+G_1(s)H_1(s)}$$

---

### 例题1.3：具有复杂反馈通路的结构图等效变换

**结构特点**：含有嵌套的多层反馈回路（内环+外环+交叉反馈）。

**关键步骤**：
1. 先化简最内层反馈环
2. 合并相邻引出点，整理中间层
3. 逐层向外简化，每次使用反馈公式 $\frac{G}{1\mp GH}$
4. 最终得到总传递函数

**结果**：
$$G(s)=\frac{G_1G_2G_3(1+H_1)(1+H_2)}{(1+G_1H_1)(1+G_3H_2)+G_1G_2G_3H_1H_2}$$

---

### 例题1.4：具有共用反馈通路的结构图等效变换

**结构特点**：多个前向通路共用同一个反馈通路 $H(s)$。

**关键步骤**：
1. 将综合点向相邻综合点移动（利用法则6）
2. 利用加减运算重组：$(a-b)+(c-d)=(a+c)-(b+d)$
3. 移动后的综合点合并
4. 化简并联支路 → 合并反馈

**结果**：
$$G(s)=\frac{G_1G_3+G_2G_4}{1+G_5(G_3H+G_4H)}$$

---

### 例题1.5：综合移动法测试题

**问题**：求含 $C_1$、$C_2$ 交叉路径系统的传递函数。

**关键步骤**：
1. 标记引出点 A、B，综合点 C、E
2. 交替移动综合点和引出点（法则4+5+6）
3. 将交叉结构转化为嵌套反馈的级联
4. 逐层化简

**结果**：
$$G(s)=\frac{C(s)}{R(s)}=\frac{G_1G_2+G_1+G_2+1}{G_1G_2}$$

即：
$$G(s)=\frac{(G_1+1)(G_2+1)}{G_1G_2}$$

## 五、题目解题通法

### 5.1 结构图化简求传递函数的通用步骤

> **核心思想**：通过等效变换消除交叉，化为简单串并联+反馈的标准形式。

**标准流程（五步法）**：

1. **识别结构**：标出所有综合点、引出点，明确前向通路和反馈通路，找出交叉结构
2. **消交叉**：利用法则4/5/6移动综合点或引出点，消除交叉，**同类靠拢**
3. **化内环**：从最内层开始，用反馈公式 $\frac{G}{1\mp GH}$ 逐一化简反馈环
4. **并串并联**：串联相乘、并联相加
5. **得总传函**：重复步骤3-4，直到得到单一块

### 5.2 各类题型的切入策略

| 题型特征 | 切入方法 |
|----------|----------|
| 简单串并联 | 直接串乘并加 |
| 单一反馈回路 | 直接用反馈公式 $\frac{G}{1\mp GH}$ |
| 嵌套反馈（环中环） | 从**最内环**开始，逐层向外 |
| 交叉反馈 | 先移动综合点/引出点消除交叉，再逐层化简 |
| 顺馈+反馈混合 | 将顺馈通路单独处理或移动综合点统一为反馈形式 |
| 多输入系统 | 用**叠加原理**，每次只考虑一个输入，其余置零，最后叠加 |

### 5.3 常见易错点

| 易错点 | 正确做法 |
|--------|----------|
| 正/负反馈符号搞反 | 公式 $\frac{G}{1\mp GH}$：**减号**对应**正反馈**，**加号**对应**负反馈** |
| 综合点与引出点移动方向混淆 | 综合点前移 ÷G、后移 ×G；引出点**相反**：前移 ×G、后移 ÷G |
| 引出点和综合点之间随意移动 | **禁止**！只能同类之间移动 |
| 移动时遗漏串联的传递函数 | 移动后每条支路都要补上（或去掉）跨过的 $G(s)$ |
| 化简顺序不当 | 始终**从内向外**，不要跳跃 |

### 5.4 检验方法

化简完成后，可通过以下方式验证：
- 代入特值（如 $s=0$，即稳态增益）检查原始结构与最终传函是否一致
- 检查最终传函分母阶次是否等于原系统前向通路 × 反馈通路的最长环路阶次
