# 串联滞后-超前校正 习题解答（Lecture26 法2）

---

## 题目

已知单位反馈系统的开环传递函数为：

$$G_0(s) = \frac{20}{s(0.1s+1)(0.05s+1)}$$

要求：
1. 绘制系统的 Bode 图；
2. 设计串联校正装置，使系统满足：
   - 剪切频率 $\omega_c^* = 13 \pm 0.5$ rad/s
   - 相角裕度 $\gamma^* = 50° \pm 5°$

---

## 一、原系统分析

### 1.1 系统型别与开环增益

$$K_v = \lim_{s\to 0} s \cdot G_0(s) = \lim_{s\to 0} \frac{20}{(0.1s+1)(0.05s+1)} = 20$$

系统为 **I 型**，开环增益 $K=20$。

### 1.2 原系统剪切频率 $\omega_{c0}$ 与相角裕度 $\gamma_0$

$$G_0(j\omega) = \frac{20}{j\omega(0.1j\omega+1)(0.05j\omega+1)}$$

幅频特性：$|G_0(j\omega)| = \frac{20}{\omega\sqrt{(0.1\omega)^2+1}\;\sqrt{(0.05\omega)^2+1}}$

相频特性：$\angle G_0(j\omega) = -90° - \arctan(0.1\omega) - \arctan(0.05\omega)$

由 $|G_0(j\omega_{c0})| = 1$，精确求解得：

$$\boxed{\omega_{c0} = 11.43\ \text{rad/s}}$$

代入相频：

$$\gamma_0 = 180° + \angle G_0(j\omega_{c0}) = 180° - 90° - \arctan(1.143) - \arctan(0.572) = \boxed{11.42°}$$

> 原系统相角裕度仅约 $11°$，稳定但阻尼很弱（超调量约 70%），需要校正。

### 1.3 Bode 图概貌

| 频段 | 转折点 | 斜率变化 |
|------|--------|---------|
| 低频 ($\omega \to 0$) | — | $-20$ dB/dec（一个积分环节） |
| $\omega = 10$ rad/s | $1/(0.1s+1)$ 转折 | 斜率变为 $-40$ dB/dec |
| $\omega = 20$ rad/s | $1/(0.05s+1)$ 转折 | 斜率变为 $-60$ dB/dec |

在 $\omega_c^* = 13$ 处：
$$|G_0(j13)| = 0.787,\quad 20\lg|G_0| = -2.09\ \text{dB}$$
$$\angle G_0(j13) = -175.46°,\quad \gamma_0(\omega=13) = 4.54°$$

---

## 二、校正方式选择 —— 按 Lecture26 §8.1 步骤判断

### 2.1 尝试串联超前校正

所需最大超前相角（补偿量取 $\Delta\varphi = 7°$）：

$$\varphi_m = \gamma^* - \gamma_0 + \Delta\varphi = 50° - 11.42° + 7° = 45.58° \leq 55°$$

✅ 相角要求**可满足**。

由 $a = \frac{1+\sin\varphi_m}{1-\sin\varphi_m} = 6.00$，计算 $-10\lg a = -7.78$ dB 对应的频率：

$$\omega_m = 17.86\ \text{rad/s}$$

❌ **$\omega_m$ 远超 $\omega_c^* = 13 \pm 0.5$**。超前校正单独使用无法满足剪切频率要求！

> **分析**：超前校正会将剪切频率"推高"到约 $17.9$ rad/s，远超出 $13 \pm 0.5$ 的范围。

### 2.2 尝试串联滞后校正

取 $\Delta\varphi = 6°$，求满足目标相角的频率：

$$\angle G_0(\omega) = -180° + \gamma^* + \Delta\varphi = -124°$$

由 $-90° - \arctan(0.1\omega) - \arctan(0.05\omega) = -124°$，解得：

$$\omega_1 = 4.12\ \text{rad/s}$$

❌ **$\omega_1$ 远低于 $\omega_c^* = 13 \pm 0.5$**。滞后校正单独使用无法满足剪切频率要求！

> **分析**：滞后校正会将剪切频率"压到"约 $4.1$ rad/s，远低于 $13 \pm 0.5$ 的范围。

### 2.3 结论：必须采用串联滞后-超前校正（法2）

| 校正方式 | 相角裕度 | 剪切频率 | 结论 |
|----------|---------|---------|------|
| 超前校正 | ✅ 可满足 ($\varphi_m=45.6°$) | ❌ $\omega_c \approx 17.9$ 太大 | 不满足 |
| 滞后校正 | ✅ 可满足 | ❌ $\omega_c \approx 4.1$ 太小 | 不满足 |
| **滞后-超前** | ✅ | ✅ 可精确控制 → **法2** | **采用** |

> **选择依据（Lecture26 §5）**：$\omega_c^* = 13 \pm 0.5$ 为**精确值**要求（带容差），应使用 **法2：在期望剪切频率处定点配置**。

## 三、滞后-超前校正设计（法2：精确控制剪切频率）

> **法2 核心思路**（Lecture26 §5.1）：
> 1. 用**超前校正**将 $\omega_c^*$ 处的相角配置到目标相角裕度（留 $\Delta\varphi$ 补偿滞后校正的负相角）
> 2. 用**滞后校正**将 $\omega_c^*$ 处的幅值衰减到 $0$ dB

### 3.1 设计超前校正部分 $G_{c1}(s)$

**① 计算 $\omega_c^*$ 处原系统的相角**

$$\varphi_0(\omega_c^*) = -90° - \arctan(0.1 \times 13) - \arctan(0.05 \times 13) = -90° - 52.43° - 33.03° = -175.46°$$

$$180° + \varphi_0(\omega_c^*) = 180° - 175.46° = 4.54°$$

**② 确定所需最大超前相角**（取 $\Delta\varphi = 5°$ 补偿滞后校正引入的负相角）

$$\boxed{\varphi_m = \gamma^* - \left[180° + \varphi_0(\omega_c^*)\right] + \Delta\varphi = 50° - 4.54° + 5° = 50.46°}$$

**③ 计算超前参数 $a$**

$$a = \frac{1 + \sin\varphi_m}{1 - \sin\varphi_m} = \frac{1 + \sin 50.46°}{1 - \sin 50.46°} = \frac{1 + 0.7709}{1 - 0.7709} = \frac{1.7709}{0.2291} \approx \boxed{7.74}$$

**④ 确定时间常数 $T_m$**（令 $\omega_m = \omega_c^* = 13$）

$$T_m = \frac{1}{\omega_m\sqrt{a}} = \frac{1}{13 \times \sqrt{7.74}} = \frac{1}{13 \times 2.782} = 0.02765\ \text{s}$$

$$aT_m = 7.74 \times 0.02765 = 0.2140\ \text{s}$$

**⑤ 超前校正网络**

$$\boxed{G_{c1}(s) = \frac{aT_m s + 1}{T_m s + 1} = \frac{0.214s + 1}{0.02765s + 1}}$$

**⑥ 超前校正后的开环传递函数**

$$G_{K1}(s) = G_{c1}(s) \cdot G_0(s) = \frac{20(0.214s + 1)}{s(0.1s+1)(0.05s+1)(0.02765s+1)}$$

在 $\omega_c^* = 13$ 处：
- $|G_{c1}(j13)| = \sqrt{a} = \sqrt{7.74} = 2.782 = 8.89$ dB
- $|G_{K1}(j13)| = 0.787 \times 2.782 = 2.188 = 6.80$ dB

> 超前校正后，$\omega_c^*$ 处的幅值为 $+6.80$ dB，需要滞后校正将其衰减到 $0$ dB。

### 3.2 设计滞后校正部分 $G_{c2}(s)$

**⑦ 计算滞后参数 $b$**

$$20\lg b = -20\lg|G_{K1}(j\omega_c^*)| = -6.80\ \text{dB}$$

$$b = 10^{-6.80/20} = 10^{-0.340} = \boxed{0.4571}$$

> $b < 1$，确认滞后校正网络起**衰减**作用 ✅

**⑧ 计算时间常数 $T_b$**

$$\frac{10}{bT_b} = \omega_c^* \quad\Rightarrow\quad T_b = \frac{10}{b \cdot \omega_c^*} = \frac{10}{0.4571 \times 13} = \boxed{1.683\ \text{s}}$$

$$bT_b = 0.4571 \times 1.683 = 0.7692\ \text{s}$$

> $\frac{1}{bT_b} = 1.30$ rad/s，远小于 $\omega_c^*=13$（约 $\frac{1}{10}$），符合滞后校正转折频率远离剪切频率的原则 ✅

**⑨ 滞后校正网络**

$$\boxed{G_{c2}(s) = \frac{bT_b s + 1}{T_b s + 1} = \frac{0.769s + 1}{1.683s + 1}}$$

### 3.3 合成滞后-超前校正网络

$$G_c(s) = G_{c1}(s) \cdot G_{c2}(s) = \frac{(aT_m s + 1)(bT_b s + 1)}{(T_m s + 1)(T_b s + 1)}$$

$$\boxed{G_c(s) = \frac{(0.214s + 1)(0.769s + 1)}{(0.02765s + 1)(1.683s + 1)}}$$

**校正后系统开环传递函数**：

$$G_K(s) = G_c(s) \cdot G_0(s) = \frac{20(0.214s + 1)(0.769s + 1)}{s(0.1s + 1)(0.05s + 1)(0.02765s + 1)(1.683s + 1)}$$

## 四、验算

### 4.1 剪切频率验证

在 $\omega = \omega_c^* = 13$ 处计算各环节幅值贡献：

| 环节 | 幅值 | 幅值(dB) |
|------|------|----------|
| $G_0(j13)$ | $0.7865$ | $-2.09$ |
| $G_{c1}(j13)$（超前，$\omega=\omega_m$） | $\sqrt{7.74} = 2.782$ | $+8.89$ |
| $G_{c2}(j13)$（滞后，高频渐近） | $0.4589$ | $-6.76$ |
| **总计** | **$0.7865 \times 2.782 \times 0.4589 = 1.004$** | **$+0.03$ dB** |

$$\boxed{|G_K(j13)| \approx 1.00\ (0.03\ \text{dB})}$$

→ 校正后剪切频率 $\omega_c = 13$ rad/s，满足 $13 \pm 0.5$ ✅

### 4.2 相角裕度验证

在 $\omega = 13$ rad/s 处计算各环节相角贡献：

| 环节 | 相角贡献 | 数值 |
|------|---------|------|
| $\frac{1}{j\omega}$ | $-90°$ | $-90.00°$ |
| $\frac{1}{0.1j\omega+1}$ | $-\arctan(1.3)$ | $-52.43°$ |
| $\frac{1}{0.05j\omega+1}$ | $-\arctan(0.65)$ | $-33.02°$ |
| $0.214j\omega+1$（超前零点） | $+\arctan(2.782)$ | $+70.24°$ |
| $\frac{1}{0.02765j\omega+1}$（超前极点） | $-\arctan(0.3595)$ | $-19.78°$ |
| $0.769j\omega+1$（滞后零点） | $+\arctan(10.00)$ | $+84.29°$ |
| $\frac{1}{1.683j\omega+1}$（滞后极点） | $-\arctan(21.88)$ | $-87.38°$ |
| **合计** | | **$-128.08°$** |

$$\gamma = 180° + \angle G_K(j13) = 180° - 128.08° = \boxed{51.92°}$$

→ 满足 $\gamma^* = 50° \pm 5°$ ✅

### 4.3 总结

| 指标 | 要求 | 实际 | 判定 |
|------|------|------|:--:|
| 剪切频率 $\omega_c$ | $13 \pm 0.5$ rad/s | $13.00$ rad/s | ✅ |
| 相角裕度 $\gamma$ | $50° \pm 5°$ | $51.92°$ | ✅ |

## 五、设计要点总结

1. **为什么选滞后-超前？** 超前校正单独使用 $\omega_c$ 太高（$\approx 17.9$），滞后校正单独使用 $\omega_c$ 太低（$\approx 4.1$），两者都不满足精确的剪切频率要求。

2. **为什么用法2？** $\omega_c^* = 13 \pm 0.5$ 是精确值要求（带容差的定点目标），法2 的"定点配置"思路天然匹配——在 $\omega_c^*$ 处用超前修相角、用滞后修幅值。

3. **$\Delta\varphi = 5°$ 的选取**：用于补偿滞后校正网络在 $\omega_c^*$ 处引入的负相角（本例实际为 $-3.09°$），$5°$ 的裕量合理。

4. **$b < 1$ 的物理意义**：$b = 0.457 < 1$ 说明滞后网络确实起**衰减**作用（$b > 1$ 则变成超前/放大）。若计算出的 $b \geq 1$，说明超前校正后 $\omega_c^*$ 处幅值仍不足 $0$ dB，需增大 $\varphi_m$ 或调整策略。

5. **验算不可省略**：设计中使用了对数近似和补偿量，最终精确验算确认 $\omega_c$ 和 $\gamma$ 均在要求范围内。

# By Gemini

这是一道经典的自动控制原理设计题。被控对象包含一个右半平面极点（$s=2$），是一个开环不稳定的系统。我们需要通过串联超前校正装置，在指定的截止频率处提供足够的相位超前和幅值补偿，使其不仅满足性能指标，还能保证闭环系统稳定。

以下是完整的解析过程：

### 1. 未校正系统的 Bode 图分析

已知开环传递函数为：


$$G_0(s) = \frac{20}{s^2 - 4}$$


将 $s = j\omega$ 代入，得到频率特性：


$$G_0(j\omega) = \frac{20}{(j\omega)^2 - 4} = \frac{-20}{\omega^2 + 4}$$

* **幅频特性**：$L_0(\omega) = 20\lg|G_0(j\omega)| = 20\lg\left(\frac{20}{\omega^2 + 4}\right)$
* **相频特性**：$\phi_0(\omega) = \angle\left(\frac{-20}{\omega^2 + 4}\right)$

**Bode 图绘制步骤（渐近线作法）：**

1. **低频段**（$\omega \ll 2$ rad/s）：幅值近似为 $20\lg(20/4) = 20\lg(5) \approx 14$ dB，斜率为 $0$ dB/dec。
2. **转折频率**：系统的分母表现为二阶实数形式，转折频率为 $\omega_n = 2$ rad/s。在转折频率后，斜率变为 $-40$ dB/dec。
3. **相频曲线**：由于对于任意的正实数 $\omega$，$\omega^2+4$ 恒为正，因此 $G_0(j\omega)$ 始终是一个**负实数**。所以未校正系统在所有正频率范围内的相角**恒为 $-180^\circ$** 直线。

---

### 2. 设计串联校正装置

**设计目标**：

* 截止频率：$\omega_c = 13 \pm 0.5$ rad/s
* 相角裕度：$\gamma = 50^\circ \pm 5^\circ$

由于原系统相角恒定为 $-180^\circ$，如果不进行补偿，系统在任何截止频率处的相角裕度都是 $0^\circ$，且存在 1 个右半平面开环极点，闭环绝对不稳定。因此我们需要采用**串联相位超前校正**（Lead Compensation）。

**步骤 (1)：计算在目标 $\omega_c = 13$ 处未校正系统的幅值和相角**

* 幅值大小：$|G_0(j13)| = \frac{20}{13^2 + 4} = \frac{20}{173} \approx 0.1156$
* 未校正相角：$\phi_0(13) = -180^\circ$

**步骤 (2)：计算校正装置需要提供的最大相角 $\phi_m$**
根据相角裕度的定义：


$$\gamma = 180^\circ + \phi_0(\omega_c) + \phi_c(\omega_c)$$


要求 $\gamma = 50^\circ$，代入已知量：


$$50^\circ = 180^\circ + (-180^\circ) + \phi_c(13) \implies \phi_c(13) = 50^\circ$$


由于原系统相角不随频率发生明显的滞后衰减（恒定 $-180^\circ$），我们可以直接取校正网络的最大超前角为 **$\phi_m = 50^\circ$**（无需额外增加补偿裕量 $\Delta$）。

**步骤 (3)：计算超前校正网络的参数 $a$ 和 $T$**
设超前校正装置的标准形式为：$G_c(s) = K_c \frac{aTs + 1}{Ts + 1} \quad (a > 1)$
利用最大相角公式 $\sin \phi_m = \frac{a - 1}{a + 1}$，代入 $\phi_m = 50^\circ$：


$$a = \frac{1 + \sin 50^\circ}{1 - \sin 50^\circ} \approx \frac{1 + 0.766}{1 - 0.766} \approx 7.55$$

令该超前网络的最大相角出现在目标截止频率处，即 $\omega_m = \omega_c = 13$：


$$\omega_m = \frac{1}{T\sqrt{a}} \implies 13 = \frac{1}{T\sqrt{7.55}}$$


解得时间常数：


$$T = \frac{1}{13 \times 2.748} \approx 0.028 \text{ s}$$


分子时间常数：


$$aT = 7.55 \times 0.028 \approx 0.211 \text{ s}$$

**步骤 (4)：计算系统增益补偿 $K_c$**
为确保 $\omega_c = 13$ 成为系统的实际截止频率，需满足幅值条件：$|G_c(j13) \cdot G_0(j13)| = 1$。
超前网络本身在 $\omega_m$ 处的幅值放大倍数为 $\sqrt{a} \approx 2.748$。因此：


$$K_c \cdot \sqrt{a} \cdot |G_0(j13)| = 1$$

$$K_c \cdot 2.748 \cdot 0.1156 = 1$$

$$K_c \cdot 0.3177 = 1 \implies K_c \approx 3.15$$

**步骤 (5)：得出最终传递函数**
综合上述参数，最终设计的串联超前校正装置传递函数为：


$$G_c(s) = 3.15 \frac{0.211s + 1}{0.028s + 1}$$

*(注：系统包含1个开环右半平面极点，经过此超前校正后，奈奎斯特曲线成功实现了逆时针包围 $(-1, j0)$ 点 1 次，满足 $Z = P - N = 1 - 1 = 0$，保证了闭环系统的稳定。)*

**定位**：从"分析"到"设计"的转折。之前是已知系统求性能，这一讲是已知性能指标反求系统参数/控制器结构。

## 三大内容

### 1. 参数调节——双指标联合确定参数

已知结构 $G(s) = \frac{K}{s(Ts+1)}$，同时满足稳态误差和动态性能两个指标，求 $K$ 和 $T$。

- 稳态指标 → $K$ 的下限（如 $K \geq 50$）
- 动态指标（$\sigma_p, t_s$）→ $\zeta$ 下限 + $\zeta\omega_n$ 下限 → 反求 $T$
- 本质：$K$ 增大对稳态好、对动态坏，设计就是在矛盾约束间取交集。

### 2. 控制器设计——速度反馈（PD）的参数联调

一个参数 $K_1$ 无法同时调好动态和稳态时，引入速度反馈内环 $K_2 s$，用两个方程联立求解 $(K_1, K_2)$。

| 影响 | $\zeta$ | $\omega_n$ | 开环增益 | 稳态误差 |
|---|---|---|---|---|
| $K_2 s$ 速度反馈 | ↑ 增大（改善） | 不变 | ↓ 减小 | ↑ 增大（恶化） |

> 核心矛盾：速度反馈改善动态但恶化稳态，必须联立方程同时解 $K_1, K_2$。

### 3. 系统辨识——由响应曲线反推参数

已知阶跃响应（稳态值、初始斜率）+ 斜坡 $e_{ss}$，反推 $K, \nu, T, a$：

- 稳态值 → $K$；斜坡 $e_{ss}$ → $\nu$；初始斜率（初值定理）→ $T$


**稳态误差分析处在整个时域分析的收尾阶段**。它的上游知识是：

| 上游知识点 | 出处 | 与误差系数法的关系 |
|---|---|---|
| **终值定理** $e_{ss} = \lim_{s\to 0}sE(s)$ | Lecture 11_2 §1.2 | 两种方法的**共同数学基础** |
| **误差传递函数** $\Phi_e(s)$ | Lecture 11_2 §1.2 | 静态系数法和动态系数法都从它出发 |
| **系统型别 $\nu$**（积分环节个数） | Lecture 11_2 §4.4, Lecture 12 §1.1 | 静态系数法的**核心判据** |
| **开环传递函数** $G(s)H(s)$ | Lecture 2-3 | 决定 $K_p, K_v, K_a$ 的本体 |
| **稳定性判据（劳斯）** | Lecture 8 | 计算稳态误差的**前提**——不稳定系统谈不上稳态 |

## 二、静态误差系数法

### 它是干什么的？

**一句话：对于标准输入信号（阶跃、斜坡、抛物线），不经过终值定理的每一步求极限，而是直接"查表"得出稳态误差。**

它的本质是把终值定理的极限计算结果**预计算好**，封装成三个系数 $K_p$、$K_v$、$K_a$。

### 怎么求？

在开环传递函数 $G(s)H(s) = \frac{K(\tau_1 s+1)\cdots}{s^\nu(T_1 s+1)\cdots}$ 中，定义：

$$\boxed{K_p = \lim_{s\to 0} G(s)H(s)} \qquad \boxed{K_v = \lim_{s\to 0} sG(s)H(s)} \qquad \boxed{K_a = \lim_{s\to 0} s^2 G(s)H(s)}$$

然后查表（Lecture12 §1.3）：

| 系统型别 | $K_p$ | $K_v$ | $K_a$ | 阶跃 $1(t)$ 的 $e_{ss}$ | 斜坡 $t$ 的 $e_{ss}$ | 抛物线 $t^2/2$ 的 $e_{ss}$ |
|---|---|---|---|---|---|---|
| **0 型** | $K$ | $0$ | $0$ | $\frac{1}{1+K}$ | $\infty$ | $\infty$ |
| **I 型** | $\infty$ | $K$ | $0$ | $0$ | $\frac{1}{K}$ | $\infty$ |
| **II 型** | $\infty$ | $\infty$ | $K$ | $0$ | $0$ | $\frac{1}{K}$ |

组合输入直接用叠加公式：

$$\boxed{e_{ss} = \frac{a_1}{1+K_p} + \frac{a_2}{K_v} + \frac{2a_3}{K_a}}$$

### 求出来的东西是什么含义？

- **$K_p$（静态位置误差系数）**：衡量系统跟踪**阶跃信号**的能力。$K_p = \infty$ → 阶跃输入下零稳态误差（"无差系统"）；$K_p = K$（有限值）→ 有恒定偏差，增大 $K$ 可减小但不能消除。

- **$K_v$（静态速度误差系数）**：衡量跟踪**斜坡信号**的能力。$K_v = \infty$ → 斜坡输入下也能做到零误差；$K_v = K$（有限值）→ 输出与输入之间有一个恒定的"速度滞后" $1/K$。

- **$K_a$（静态加速度误差系数）**：衡量跟踪**抛物线信号**的能力。$K_a = \infty$ → 加速信号下零误差；$K_a = K$（有限值）→ 输出"追不上"加速度变化，误差随 $t$ 增大。

**物理直觉**：$K_p, K_v, K_a$ 本质是系统"在低频段的放大能力"——积分环节越多，低频增益越大，跟踪能力越强。这就是为什么 $\nu$ 型系统被称为"无差度"。

### 什么时候用 / 什么时候不能用？

✅ **能用**：标准误差定义（$E(s)=R(s)-B(s)$），主反馈到输入端，标准输入信号（阶跃/斜坡/抛物线）

❌ **不能用**：非标准误差定义（非单位反馈时 $E(s) \neq R(s)-C(s)$），非标准输入（如正弦、指数衰减），需要知道误差时间变化规律时

---

## 三、动态误差系数法

### 它是干什么的？

**一句话：当输入信号不是标准信号（不一定是阶跃/斜坡/抛物线），或者你想知道误差随时间怎么变（不只是最终的极限值），就用动态误差系数法。**

静态系数法只能告诉你 $t \to \infty$ 时的极限值，但不能告诉你误差是常数还是随时间增长、以什么速率增长。动态误差系数法弥补了这个盲区。

### 怎么求？

把误差传递函数 $\Phi_e(s) = \frac{E(s)}{R(s)}$ 在 $s=0$ 处做泰勒展开（升幂排列）：

$$\Phi_e(s) = C_0 + C_1 s + C_2 s^2 + \cdots + C_i s^i + \cdots$$

其中 $\boxed{C_i = \frac{1}{i!}\Phi_e^{(i)}(0)}$ 就是**动态误差系数**。

两种计算方法（Lecture12 §2.2）：

| 方法 | 做法 |
|---|---|
| **定义法** | 对 $\Phi_e(s)$ 逐次求导，代入 $s=0$ |
| **长除法（更实用）** | 将 $\Phi_e(s)$ 分子分母按 $s$ 升幂排列，做多项式除法 |

### 求出来的 $C_i$ 怎么用？

拉氏反变换后得到**时域误差表达式**：

$$\boxed{e_{ss}(t) = C_0 \cdot r(t) + C_1 \cdot \dot{r}(t) + C_2 \cdot \ddot{r}(t) + \cdots}$$

**每个系数的物理含义**：

| 系数 | 名称 | 含义 |
|---|---|---|
| $C_0$ | 动态位置误差系数 | 输入本身的缩放系数——阶跃输入时直接决定误差 |
| $C_1$ | 动态速度误差系数 | 输入**一阶导数**的缩放系数——斜坡变化时产生误差分量 |
| $C_2$ | 动态加速度误差系数 | 输入**二阶导数**的缩放系数——加速变化时产生误差分量 |

**关键**：$e_{ss}(t)$ 是一个**时间函数**，而不只是一个数字。你可以看到误差在随时间怎么变。

### 和静态系数法的关系

对于标准型系统（主反馈到输入端、开环传函为 $\frac{K}{s^\nu}G'(s)$），两者是统一的：

| 型别 | $C_0$ | $C_1$ | $C_2$ |
|---|---|---|---|
| 0 型 | $\frac{1}{1+K_p}$ | — | — |
| I 型 | $0$ | $\frac{1}{K_v}$ | — |
| II 型 | $0$ | $0$ | $\frac{1}{K_a}$ |

**动态误差系数是静态误差系数的推广**——静态只能告诉你 $t \to \infty$ 时极值是否存在及其大小；动态还能告诉你误差的**时间演化规律**。

### 典型例子（Lecture12 例2.1）

系统 $G(s)H(s) = \frac{10}{s(s+1)}$，输入 $r(t) = R_0 + R_1 t + R_2 t^2$。

静态系数法算出来：$e_{ss} = \infty$（因为含 $t^2$ 项），**但这只说"无穷大"，没说是怎么变成无穷大的**。

动态系数法给出（通过长除法求 $C_i$）：

$$e_{ss}(t) = 0.2R_2 \cdot t + (0.1R_1 + 0.18R_2)$$

这就揭示了：**误差以 $0.2R_2$ 的斜率随时间线性增长**——你知道了发散的速度，而不只是"会发散"。

### 什么时候必须用动态系数法？

1. 输入信号是**任意时间函数**（不限于阶跃/斜坡/抛物线模板）
2. 需要知道误差**随时间变化的规律**，而不只是最终值
3. $E(s)$ 在 $s$ 右半平面**不解析**时（静态系数法的极限可能不存在）
4. 非标准误差定义的场合

```
终值定理（Lecture 11_2）
  │  e_ss = lim(s→0) s·E(s)
  │
  ├─→ 静态误差系数法（Lecture 12 §1）
  │     │  预计算的标准模板，只能求极限值
  │     │  前提：标准误差定义 + 标准输入信号
  │     │  上游依赖：系统型别 ν（积分环节个数）
  │     │  产出：Kp, Kv, Ka → e_ss（一个数）
  │     │
  │     └─→ 动态误差系数法（Lecture 12 §2）
  │           │  泰勒展开，能求误差的时间函数
  │           │  前提：Φe(s) 在 s=0 处解析（稳定系统满足）
  │           │  上游依赖：误差传递函数 Φe(s)
  │           │  产出：C₀, C₁, C₂, ... → e_ss(t)（一个时间函数）
  │           │
  │           └─→ 广义形式包含静态系数（C₀=1/(1+Kp), C₁=1/Kv, C₂=1/Ka）
  │
  └─→ 降低稳态误差的途径（Lecture 12 §3）
        ├── 增大开环增益 K（受稳定性约束）
        ├── 增加积分环节 ν（一般 ν ≤ 2）
        ├── 扰动点之前加增益/积分
        ├── 输入顺馈补偿（全补偿/部分补偿）
        └── 扰动顺馈补偿
```

## 五、一句话总结

- **静态误差系数法**：是一种"速查表"——对于阶跃/斜坡/抛物线这三种标准输入，你不用每次都用终值定理算极限，只要看一眼系统的型别 $\nu$ 和开环增益 $K$，就立刻知道最终稳态误差是 0、有限值还是无穷大。

- **动态误差系数法**：是一种"显微镜"——它把误差传递函数在 $s=0$ 附近做泰勒展开，告诉你的不只是最终误差的极限，而是误差作为一个**时间的函数**究竟在怎么演化（是恒定的？线性增长的？还是加速发散的？）。它是静态系数法的**数学推广**——当系统满足标准条件时，$C_0, C_1, C_2$ 分别就是 $1/(1+K_p), 1/K_v, 1/K_a$。

- **两者共同的根**是终值定理 $e_{ss} = \lim_{s\to 0} sE(s)$ 和误差传递函数 $\Phi_e(s)$——它们只是用不同的方式去处理同一个极限问题：一个把结果做成表格方便速查，一个把函数展开成级数以保留更多信息。

# 题目解法

## 根轨迹+稳定性+动态性能综合题（第四章）



这类“根轨迹+稳定性+动态性能”的综合大题，是自动控制原理中非常经典且套路固定的“送分大题”。只要掌握了标准工作流，按部就班地套公式即可。

以下是这类题目的**四步解题通法**及每一步对应的**核心公式**。

---

### 第一步：绘制常规根轨迹

这一步的目标是准确画出系统极点随增益 $K_r$ 变化的运动轨迹。

**1. 确定起点和终点**

* **公式/原则**：起点为开环极点 $p_i$（此时 $K_r=0$），终点为开环零点 $z_j$ 或无穷远处（此时 $K_r \to \infty$）。

**2. 计算渐近线（当极点数 $n$ > 零点数 $m$ 时）**

* **渐近线交点（实轴上）**：

$$\sigma_a = \frac{\sum_{i=1}^n p_i - \sum_{j=1}^m z_j}{n - m}$$


* **渐近线倾角**：

$$\phi_a = \frac{(2k+1)\pi}{n - m}, \quad k = 0, 1, \dots, n-m-1$$



**3. 计算分离点与会合点（极点在实轴上相撞并飞出的点）**

* **公式**：令开环传递函数 $G(s) = \frac{K_r}{M(s)}$。通过解以下微分方程求得：

$$\frac{dK_r}{ds} = 0$$



（解出的 $s$ 值必须在实轴的根轨迹线段上才有效）。

---

### 第二步：临界稳定性与虚轴交点分析

这一步是为了找到系统“恰好稳定”时的边界条件，通常使用劳斯判据。

**1. 写出闭环特征方程**

* **公式**：$1 + G(s)H(s) = 0$。化简为标准多项式形式：

$$a_n s^n + a_{n-1} s^{n-1} + \dots + a_1 s + K_r = 0$$



**2. 寻找临界稳定增益与震荡频率**

* **方法**：列出劳斯阵列。
* **临界增益 $K_{rc}$**：令劳斯阵列中 $s^1$ 行的系数为 0，解出 $K_{rc}$。
* **虚轴交点 $\omega_c$**：将 $K_{rc}$ 代入 $s^2$ 行构成的辅助方程 $A s^2 + B = 0$，解得 $s = \pm j\omega_c$。

**3. 根轨迹增益 ($K_r$) 与开环放大系数 ($K$) 的换算**

* **万能极限公式**（适用于判定系统稳定时的最终 $K$ 值范围）：

$$K = \lim_{s \to 0} s^v G(s)$$



（其中 $v$ 为系统型别，即原点处极点的个数。求出 $K_{rc}$ 后，代入此公式即可得到临界开环放大系数 $K_c$）。

---

### 第三步：根据性能要求反推闭环主导极点

题目通常会给出一个阻尼比 $\zeta$（或超调量），要求计算此时的系统状态。

**1. 定位主导极点 $s_1$**

* **阻尼比夹角公式**：阻尼比 $\zeta$ 对应复平面上一条射线，其与负实轴夹角为：

$$\theta = \arccos\zeta$$


* **求解交点**：将这条射线方程（$\omega = \sigma \tan\theta$）与根轨迹方程（或直接用特征方程）联立，求出交点坐标 $s_1 = -\sigma + j\omega_d$。

**2. 反求此时的根轨迹增益 $K_{r1}$**

* **幅值条件公式**：闭环极点到所有开环极点距离的乘积，除以到所有开环零点距离的乘积：

$$K_{r1} = \frac{\prod_{i=1}^n |s_1 - p_i|}{\prod_{j=1}^m |s_1 - z_j|}$$



**3. 验证“主导极点”条件（韦达定理技巧）**

* **公式**：系统所有闭环极点之和 = 所有开环极点之和。

$$\sum_{k=1}^n s_{k(\text{闭环})} = \sum_{i=1}^n p_{i(\text{开环})}$$


* **验证标准**：算出剩下的一对共轭极点（或实极点）$s_3, s_4$。如果它们的实部距离虚轴的距离，是主导极点 $s_1$ 实部的 **5倍以上**，则主导极点假设成立，高阶系统可降级为二阶系统。

---

### 第四步：计算二阶系统动态性能指标

确认系统可近似为标准二阶系统后，直接套用二阶系统的四大核心公式。
已知主导极点为 $s_1 = -\sigma + j\omega_d$，其中：

* **衰减系数**：$\sigma = \zeta\omega_n$
* **阻尼自然频率**：$\omega_d = \omega_n\sqrt{1-\zeta^2}$
* **无阻尼自然频率**：$\omega_n = |s_1| = \sqrt{\sigma^2 + \omega_d^2}$

**1. 超调量（$\sigma_p$ 或 $\Delta\%$）**

* **公式**：

$$\sigma_p = e^{-\frac{\pi\zeta}{\sqrt{1-\zeta^2}}} \times 100\%$$



**2. 调节时间（$t_s$）**

* **误差带为 5% 时**：

$$t_s = \frac{3}{\zeta\omega_n} = \frac{3}{\sigma}$$


* **误差带为 2% 时**：

$$t_s = \frac{4}{\zeta\omega_n} = \frac{4}{\sigma}$$



**3. 峰值时间（$t_p$）**

* **公式**：

$$t_p = \frac{\pi}{\omega_d}$$
