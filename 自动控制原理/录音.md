### 第2章 系统的数学建模

#### 2.1 力学系统建模（重点）
三个基本环节必须熟练掌握：
1. **质量块**：位移与力
2. **弹簧**：位移与弹性系数（胡克定律）
3. **阻尼器**：阻力与速度成比例，乘以阻尼系数

**典型考题形式**：
- 给出力学系统示意图（如：小车M1—弹簧—阻尼器—小车M2，在M1上施加力F，位移分别为Y1和Y2）
- 要求列写 **F 与 Y1（或Y2）之间的微分方程**
- 或要求列写传递函数

#### 2.2 电学系统建模（重点）
- 电阻R、电感L、电容C 的伏安关系
- 基于基尔霍夫定律列写方程
- 典型考题：给出RLC电路（如C1/C2/C3/R1网络），求 U1 和 U2 之间的微分方程和传递函数

#### 2.3 电机建模（低频考点）
- 教材第20-21页
- 多年未考，若考会给公式
- 记住两个核心关系：
  1. 电压 ∝ 转速（电压越大，转速越快）
  2. 电流 ∝ 转矩（电流越大，力矩越大）

#### 2.4 非线性系统的线性化（重点）
- 方法：**泰勒展开**，在平衡点处展开
- 线性化后得到的是**偏差与偏差之间的关系**（小扰动法）
- 典型例子：倒立摆，sinθ ≈ θ（在平衡点附近）

#### 2.5 传递函数（重点）
- **定义**：零初始条件下，输出的拉氏变换与输入的拉氏变换之比
- **三种表达形式**：
  1. 有理分式形式
  2. 尾一形式（时间常数形式）→ K为静态放大系数
  3. 首一形式（零极点形式）→ K为根轨迹增益（第4章用）
- 传递函数与微分方程的相互转换
- **重点题型**（作业题2.2.5）：已知输入和输出，分别求零初始条件和非零初始条件下的传递函数

#### 2.6 典型环节（重点）
八大典型环节：
1. 比例环节
2. 积分环节
3. 微分环节
4. 惯性环节
5. 振荡环节
6. 一阶微分环节
7. 二阶微分环节
8. 延迟环节 — **一般不考**，只需知道 e^(-τs) 如何处理

> 典型环节的频率特性在第5章也会用到。

#### 2.7 结构图的等效变换（必考，约占第二道大题）
- 串联：相乘
- 并联：相加/相减
- 反馈：负反馈为 G/(1+GH)，正反馈为 G/(1-GH)
- **综合点移动**：前除后乘（向前移→除以绕过的模块；向后移→乘以绕过的模块）
- **引出点移动**：与综合点相反，前乘后除
- **化简策略**：综合点尽量靠拢综合点（可互换），引出点尽量靠拢引出点（可互换）
- 常见以**第二道大题**形式出现

#### 2.8 信号流图与梅森公式（重点）
- 结构图 → 信号流图的转换（注意：什么情况下中间节点可忽略，什么情况下不能）
- **梅森公式**：$T = \frac{1}{\Delta}\sum_{k=1}^{M} P_k \Delta_k$
  - Δ = 1 - (所有回路增益之和) + (两两互不接触回路增益乘积之和) - (三个互不接触回路增益乘积之和) + …
  - P_k：第k条前向通路的增益
  - Δ_k：第k条前向通路对应的余子式
  - **公式不提供，必须记住**
- **注意审题**：如果题目限定必须用结构图等效变换，则用梅森公式不得分；若未限定方法，两种均可。近几年考试一般未限定方法。

### 第3章 时域分析

**三个核心：稳（稳定性）、准（稳态误差）、快（动态性能）**

#### 3.1 稳定性判据

**判断方法一（时域）**：
- 输入单位脉冲信号 δ(t)，若单位脉冲响应 C(t) → 0，则系统稳定
- 关键：C(s) = G(s) · R(s) = G(s) · 1 = G(s)，故直接对 G(s) 做反拉氏变换即可

**判断方法二（S域）**：
- 传递函数的所有极点必须具有**负实部**（在S平面左半平面）
- 充分必要条件

**劳斯判据（必考）**：
- 列劳斯表（根据特征方程 $D(s)=0$）
- 两种特殊情况：
  1. 某行第一列为0，其余不为0 → 用一个很小的 ε 代替0，继续列表
  2. 某行全为0 → 用上一行构造辅助多项式并求导，用求导后的系数替换全零行
- 判稳：观察**第一列符号变化次数** = 右半平面根的个数
- 全零行说明系统**临界稳定或不稳定**（虚轴上有重根→不稳定，单根→临界稳定）

**稳定裕量**：
- 判断有多少根在 S = -σ 左边
- 方法：令 Z = S + σ，代入后在新Z平面使用劳斯判据

**赫尔维茨判据**：**不考**，课堂未讲，无需复习。

#### 3.2 动态性能指标（必考）

分析的前提：给系统注入**单位阶跃信号**，观察响应。

**七个指标**：4个时间指标 + 3个平稳性指标。

##### 一阶系统
- 上升时间 tr：**10%稳态值 → 90%稳态值**（注意：稳态值不一定为1！）
- 延迟时间 td：到50%稳态值的时间 ≈ 0.69T
- 调整时间 ts：进入稳态值±5% 为 3T，进入±2% 为 4T
- 一阶系统无超调，只有时间指标

##### 二阶系统（重点必考）
标准形式涉及参数：
- ζ（阻尼系数）
- ωn（无阻尼自然振荡频率）
- ωd = ωn·√(1-ζ²)（有阻尼自然振荡频率）
- β = arccos(ζ)

**分类**：根据ζ分为5类，最常考**欠阻尼（0 < ζ < 1）**。

四个必记公式：
1. **上升时间 tr** = (π - β) / ωd
2. **峰值时间 tp** = π / ωd
3. **超调量 σ%** = (峰值 - 稳态值) / 稳态值 × 100% = e^(-πζ/√(1-ζ²)) × 100%
4. **调整时间 ts**：5%准则 → 3/(ζωn)，2%准则 → 4/(ζωn)

> tr 和 tp 与 ωd 有关（图中对应虚轴长度）；ts 与 ζωn 有关（图中对应实轴长度）。这部分常与第4章根轨迹结合考查。

##### 高阶系统
- 找**主导极点**：离虚轴最近、且附近无零点的极点对
- 偶极子概念：若极点附近有零点，则该极点贡献很小，可忽略
- 一个主导极点 → 降为一阶系统分析；一对共轭主导极点 → 降为二阶系统分析

#### 3.3 稳态误差（重点）
- 定义：e_ss = lim(t→∞) [r(t) - b(t)]
- **静态误差系数法**：掌握 Kp、Kv、Ka
- 本质来自**终值定理**：e_ss = lim(s→0) s·E(s)
- 若不会用静态误差系数法，直接用终值定理求解
- 可能考：有扰动时设计方法消除/抑制扰动对输出的影响

### 第4章 根轨迹法（必考，第五道大题）

> **重要区分**：第3章分析的是**闭环**传递函数；第4章基于**开环**传递函数研究闭环极点的变化。

#### 根轨迹基本方程
- 特征方程：1 + G(s)H(s) = 0 → G(s)H(s) = -1
- 拆为两个条件：
  1. **幅值条件**：|G(s)H(s)| = 1
  2. **相角条件**：∠G(s)H(s) = (2k+1)π（180°根轨迹）

#### 绘制根轨迹的八条规则

| 规则 | 内容 |
|------|------|
| 规则1 | 起点（开环极点）和终点（开环零点） |
| 规则2 | 分支数 = max(M, N)，M为有限零点数，N为有限极点数 |
| 规则3 | 实轴上的根轨迹：右侧零极点个数之和为**奇数**（180°）或**偶数**（0°） |
| 规则4 | 渐近线：交点 σ_a = (Σ极点 - Σ零点)/(N-M)，角度 φ_a = (2k+1)π/(N-M) |
| 规则5 | 起始角与终止角：由相角条件推导（忘记公式可现场推算） |
| 规则6 | 分离点：解 dK/ds = 0 或 Σ1/(s-p_i) = Σ1/(s-z_i)，需验证是否为根轨迹上的点 |
| 规则7 | 与虚轴交点：劳斯判据法 或 令 s=jω 代入特征方程 |
| 规则8 | 根之和与根之积：N-M ≥ 2 时，根之和为常数 |

- 起点用 ×（叉）表示，终点用 ○（圈）表示
- 标注箭头（K增大方向）和特殊点
- 圆弧根轨迹需会求曲线方程
- 会求给定性能指标（ts、tp等）时对应的K值

#### 零度根轨迹
- 出现在正反馈系统：1 - G(s)H(s) = 0 → G(s)H(s) = 1
- 相角条件变为 **2kπ**
- **受影响的规则**：规则3（实轴根轨迹）、规则4（渐近角）、规则5（起始/终止角）
- **不受影响的规则**：规则6（分离角仍为 (2k+1)π/L）

#### 参数根轨迹
- 作业布置了三道题：180°根轨迹、0°根轨迹、参数根轨迹各一道，每道都必做

#### 非最小相位系统的根轨迹
- **不考**（仅限实验班考查）

### 第5章 频率特性分析（覆盖第六、七道大题）

#### 5.1 频率特性基本概念
- 输入正弦信号 → 稳态输出也是同频率正弦信号 → 幅值和相角发生变化
- 变化规律由 **G(jω)** 决定
- G(jω) = A(ω)·e^(jφ(ω))
  - A(ω)：幅频特性（ω的偶函数）
  - φ(ω)：相频特性（ω的奇函数）
- 实频特性为偶函数，虚频特性为奇函数

#### 5.2 两种图示方法

**① 极坐标图（Nyquist图/幅相曲线）**：
- 在极坐标上绘制 ω: 0 → +∞ 的 G(jω) 轨迹
- 各基本环节的幅相曲线需掌握
- 振荡环节的相角较难记 → 需会现场推导
- 不稳定环节（如 Ts-1）→ 代入 s=jω 推导，判断象限
- 二阶不稳定环节可能考（难度较高）

**② 波特图（Bode图）**：
- 对数幅频 + 对数相频
- 掌握从起始段到各转折频率的绘制方法
- 给Bode图反推传递函数（可能含不稳定环节，去年考过）
- 最小相位系统：幅频和相频有确定对应关系

#### 5.3 Nyquist稳定判据（必考）
- 判据公式：**Z = P - N**
  - P：开环传递函数在右半平面的极点数
  - N：Nyquist曲线包围(-1, j0)的圈数
  - Z：闭环系统在右半平面的极点数（Z=0则稳定）
- 原理：F(s) = 1+G(s)H(s)，F(s)的零点=闭环极点，F(s)的极点=开环极点
- Nyquist曲线绕(-1, j0)的本质：GH平面与F平面差一个1的平移
- **补圈/绕行**：当Nyquist路径经过开环极点时（如虚轴上有极点），需绕过，用无穷小半圆
- 今年可能考**经过(-1, j0)点**（即闭环极点在虚轴上/临界稳定）的处理

#### 5.4 相对稳定性
- **相角裕度 γ**：剪切频率 ωc 处，γ = 180° + ∠G(jωc)
- **幅值裕度 Kg**：相角=-180°处的幅值倒数（dB表示）
- 这两个是频域性能指标，对应第3章时域指标

#### 5.5 闭环频域指标（了解）
- 高阶系统的谐振峰值 Mr 与相角裕度 γ 有关（期望频率法会用到，但不强制要求）
- 时域指标与频域指标的关系：
  - 超调量 σ% ↔ 相角裕度 γ
  - 调整时间 ts ↔ 剪切频率 ωc 和相角裕度 γ
- 这两个关系式若考到会给出，需**会转换**

### 第6章 系统校正（第八道大题）

#### 6.1 校正方法

| 校正方式 | 特点 | 对ωc的影响 |
|----------|------|------------|
| 超前校正 | 利用最大超前角 φm | ωc **后移**（增大），提高快速性 |
| 滞后校正 | 利用高频衰减 | ωc **前移**（减小），提高稳定性 |
| 滞后-超前校正 | 兼具两者优点 | 同时满足相角裕度和剪切频率要求 |

#### 6.2 校正步骤（超前/滞后）
- 具体步骤参考 PPT 中标蓝的公式，**考前必须记住**
- 若 φm > 60°，一级超前环节不够用，需考虑其他方法
- **验算**是得分点，写完必须验算

#### 6.3 关于开环增益的调节
- 若题目给出 Kg 要求（如 ≥ 10dB），但没给 Kp/Kv/Ka 条件
- 可通过调节开环增益使幅值裕度满足要求
- 但需与相角裕度**协同设计**（ωc 变化→相角裕度也变化）

#### 6.4 期望频率法
- **不强制要求**，不会限定必须用此法
- 滞后-超前方法能解决期望频率法能解决的问题
- 掌握最好，不掌握也不必担心

## 六、考场注意事项

1. **审题**：第2题若限定"必须用结构图等效变换"，则用梅森公式不得分；若未限定，两种方法均可。
2. **稳态值**：绝不等于1！一定要根据系统实际稳态输出确定。
3. **公式记忆**：梅森公式、二阶系统四个指标公式、劳斯表、根轨迹八条规则等均不提供，必须熟记。
4. **分离点验证**：解出的点只是必要条件，还需验证（实轴上用规则3，不在实轴上用相角条件）。
5. **校正验算**：做完校正题目务必验算，这是得分点。
6. **不要空题**：校正题步骤简单，即使复习不到位，考前记住标蓝公式写上也能拿分。
7. **根轨迹标注**：起点×、终点○、箭头方向、特殊点均需标注清楚。
8. **不稳定环节**：Bode图反推传递函数时，若相频曲线异常，可能含不稳定环节。
