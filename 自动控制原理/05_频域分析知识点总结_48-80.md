## 第一部分：幅相曲线（Nyquist曲线）的绘制（第48-60页）

### 一、绘制幅相曲线的通用步骤

1. **写出频率特性** — 将开环传递函数 $G(s)$ 中的 $s$ 替换为 $j\omega$，得到幅频特性 $|G(j\omega)|$ 和相频特性 $\angle G(j\omega)$，以及实频特性 $u(\omega)$ 和虚频特性 $v(\omega)$。
2. **分析变化趋势** — 分析 $\omega: 0 \to \infty$ 时 $u$、$v$、$|G|$、$\angle G$ 的单调变化趋势。
3. **判断是否具有特殊形状** — 如是否与坐标轴相交、是否存在渐近线等。
4. **标注箭头和特殊频率值** — 用箭头标出 $\omega$ 从 $0 \to +\infty$ 的方向，标出与实轴/虚轴的交点坐标。

### 二、典型例题分类

#### 类型1：一阶微分环节，$n=m$

- **传递函数**：$G(s)=\frac{Ts}{Ts+1}$
- 实频 $u=\frac{T^2\omega^2}{1+T^2\omega^2}$，虚频 $v=\frac{T\omega}{1+T^2\omega^2}$
- 幅频 $|G|=\frac{T\omega}{\sqrt{1+T^2\omega^2}}$，相频 $\angle G=90^\circ-\arctan(\omega T)$
- **趋势**：$\omega: 0\to\infty$ 时，$u: 0\to 1$，$v: 0\to$先增后减$\to 0$
- 曲线方程为半圆：$u^2 + v^2 - u = 0$，即 $(u-\frac{1}{2})^2 + v^2 = (\frac{1}{2})^2$

#### 类型2：无积分/微分环节，$m=n$

- **传递函数**：$G(s)=\frac{T_1s+1}{T_2s+1}$，$T_1,T_2>0$
- 相频 $\angle G = tg^{-1}(\omega T_1)-tg^{-1}(\omega T_2)$
- 起点：$\omega=0$ 时 $|G|=1$，$\angle G=0^\circ$
- 终点：$\omega\to\infty$ 时 $|G|=T_1/T_2$，$\angle G=0^\circ$
- **三种情况**：
  - $T_1 > T_2$：曲线在上半平面（$v>0$）—— 相位始终为正
  - $T_1 < T_2$：曲线在下半平面（$v<0$）—— 相位始终为负
  - $T_1 = T_2$：$u=1$，$v=0$，曲线退化为一个点

#### 类型3：两个惯性环节，$n>m$

- **传递函数**：$G(s)=\frac{K}{(T_1s+1)(T_2s+1)}$
- $u(\omega)=\frac{K[1-\omega^2T_1T_2]}{(1+\omega^2T_1^2)(1+\omega^2T_2^2)}$，$v(\omega)=\frac{-K\omega(T_1+T_2)}{(1+\omega^2T_1^2)(1+\omega^2T_2^2)}$
- 相频 $\angle G = -tg^{-1}(\omega T_1)-tg^{-1}(\omega T_2)$
- $\omega:0\to\infty$时，$u: K\to 0\to$ 负 $\to 0$，$v: 0\to$ 负 $\to 0$
- $|G|: K\to 0$，$\angle G: 0^\circ \to$ 单调减小 $\to -180^\circ$
- **与虚轴交点**：$\omega=\frac{1}{\sqrt{T_1T_2}}$ 时 $u=0$，$v=-\frac{K\sqrt{T_1T_2}}{T_1+T_2}$

#### 类型4：含一阶微分的零型系统

- **传递函数**：$G(s)=\frac{K(\tau s+1)}{(T_1s+1)(T_2s+1)}$
- 相频 $\varphi(\omega)=tg^{-1}(\omega\tau)-tg^{-1}(\omega T_1)-tg^{-1}(\omega T_2)$
- **三种情况**（取决于 $\tau$ 与 $T_1+T_2$ 和 $\frac{T_1T_2}{T_1+T_2}$ 的关系）：
  1. $\tau < \frac{T_1T_2}{T_1+T_2}$：$u$ 从 $K\to$ 正 $\to 0\to$ 负 $\to 0$，$v$ 从 $0\to$ 负 $\to 0$，始终在下半平面
  2. $\frac{T_1T_2}{T_1+T_2} < \tau < T_1+T_2$：$u: K\to 0$ 变为负再回到 $0$，$v$ 始终负，$\angle G: 0^\circ\to-90^\circ$
  3. $\tau > T_1+T_2$：$u: K\to$ 正 $\to 0$，$v: 0\to$ 正 $\to 0\to$ 负 $\to 0$，曲线先在上半平面再进入下半平面
  4. $\frac{T_1T_2}{T_1+T_2} \le \tau \le T_1+T_2$（第三种情况的边界）：$u: K\to$ 正 $\to 0$，$v: 0\to$ 负 $\to 0$

#### 类型5：I型系统含一阶微分环节

- **传递函数**：$G(s)=\frac{K(\tau s+1)}{s(T_1s+1)(T_2s+1)}$
- 相频 $\angle G = tg^{-1}(\omega\tau)-90^\circ-tg^{-1}(\omega T_1)-tg^{-1}(\omega T_2)$
- **四种情况**（取决于 $\tau$ 的大小）：
  1. $\tau < \frac{T_1T_2}{T_1+T_2}$：$u$ 始终负，$v$ 从 $-\infty\to 0\to$ 正 $\to 0$，与实轴相交
  2. $\frac{T_1T_2}{T_1+T_2} \le \tau < T_1+T_2$：$u$ 始终负，$v$ 始终负，与实轴不相交
  3. $\tau = T_1+T_2$：$u$ 从 $0\to$ 负 $\to 0$，起点在虚轴无穷远处，与实轴不相交
  4. $\tau > T_1+T_2$：$u$ 从正 $\to 0\to$ 负 $\to 0$，起点在虚轴右侧，与实轴不相交

#### 类型6：I型系统含振荡环节

- **传递函数**：$G(s)=\frac{K}{s(T^2s^2+2\zeta T s+1)}$
- $u=-\frac{2K\zeta T\omega}{\omega[(1-T^2\omega^2)^2+4\zeta^2T^2\omega^2]}$，$v=-\frac{K(1-T^2\omega^2)}{\omega[(1-T^2\omega^2)^2+4\zeta^2T^2\omega^2]}$
- 相频 $\angle G = -90^\circ - tg^{-1}\frac{2\zeta T\omega}{1-T^2\omega^2}$（分段处理 $\omega\le 1/T$ 和 $\omega>1/T$）
- $\omega:0\to\infty$时：$u:-2\zeta KT\to 0$，$v:-\infty\to 0\to$ 正 $\to 0$
- $\omega=1/T$ 时与实轴相交：$v=0$，$u=-\frac{KT}{2\zeta}$，$\angle G=-180^\circ$
- 若 $\zeta \ge \frac{1}{2}$，实频单调；若 $\zeta < \frac{1}{2}$，实频先减小后增大

#### 类型7：非最小相位系统

##### 例一：$G(s)=\frac{10(\tau s-1)}{s(s+1)(s+10)}$（右半平面零点）
- 相频 $\angle G = -90^\circ - tg^{-1}(\omega) - tg^{-1}(\omega/10) + (180^\circ - tg^{-1}(\omega\tau))$
- 与实轴交点：令 $\operatorname{Im}[G(j\omega)]=0$

##### 例二：$G(s)=\frac{20}{(s-1)(s+2)(s+5)}$（右半平面极点）
- $\angle G = -tg^{-1}(\omega/2)-tg^{-1}(\omega/5)-(180^\circ-tg^{-1}(\omega))$
- $u(\omega)$ 始终为负，$v(\omega)$ 从 $0\to$ 负 $\to 0\to$ 正

##### 例三：$G(s)=\frac{10}{s(s+1)(s^2+1)}$（含纯虚根）
- 特征：$\omega=1$ 处有间断点（纯虚极点 $s=\pm j$）
- 需分别分析 $\omega:0\to 1^-$ 和 $\omega:1^+\to\infty$
- 幅频在 $\omega=1$ 处趋于 $\infty$

#### 类型8：含延时环节的系统

- **传递函数**：$G(s)=\frac{K_v e^{-\tau s}}{s(Ts+1)}$
- 幅频 $|G|=\frac{K_v}{\omega\sqrt{1+\omega^2T^2}}$，相频 $\angle G=-90^\circ-tg^{-1}(\omega T)-57.3\omega\tau$
- **特点**：$u$、$v$ 随 $\omega$ 增大在正负之间循环变化（因 $\sin(\omega\tau)$ 和 $\cos(\omega\tau)$ 的周期性）
- $\angle G$ 随 $\omega$ 单调负增长且趋于 $-\infty$

### 三、绘制幅相曲线的注意事项（第60页小结）

- 借助实频和虚频特性判断相频特性以及曲线的位置
- 正确判断起点（$\omega=0$）和终点（$\omega\to\infty$）的角度
- 如果存在渐近线，则应标出渐近线的值
- 用箭头标出 $\omega$ 从 $0\to+\infty$ 变化的方向
- 求出幅相曲线与坐标轴的交点，特别是**与负实轴的交点**（对稳定性判据很重要）

## 第二部分：Bode图的绘制（第61-80页）

### 一、Bode图的基本原理（第62-65页）

#### 1. 叠加原理

- 对数幅频特性：$L(\omega)=20\lg|G_1|+20\lg|G_2|+...$
- 对数相频特性：$\angle G=\angle G_1+\angle G_2+...$

#### 2. 典型环节的Bode图特征

| 环节类型 | 转折频率 | 斜率变化 $\Delta L$ | 相角范围 |
|---------|---------|-------------------|---------|
| 比例环节 $K$ | 无 | 0 | $0^\circ$ |
| 积分环节 $1/s$ | 无 | 起始段 $-20\text{dB/dec}$ | $-90^\circ$ |
| 微分环节 $s$ | 无 | 起始段 $+20\text{dB/dec}$ | $+90^\circ$ |
| 惯性环节 $1/(Ts+1)$ | $\omega=1/T$ | $-20\text{dB/dec}$ | $0^\circ \to -90^\circ$ |
| 一阶微分 $Ts+1$ | $\omega=1/T$ | $+20\text{dB/dec}$ | $0^\circ \to +90^\circ$ |
| 振荡环节 $1/(T^2s^2+2\zeta Ts+1)$ | $\omega=1/T$ | $-40\text{dB/dec}$ | $0^\circ \to -180^\circ$ |
| 二阶微分 $T^2s^2+2\zeta Ts+1$ | $\omega=1/T$ | $+40\text{dB/dec}$ | $0^\circ \to +180^\circ$ |
| 延时环节 $e^{-\tau s}$ | 无 | 不影响幅频 | $0^\circ \to -\infty$ |

#### 3. 四个核心结论

**结论1**：对数幅频特性的渐近线由直线段组成，可由典型环节叠加得到。

**结论2**：渐近线起始段的斜率和位置由**比例环节**和**积分（微分）环节**决定：
- 起始段过 $\omega=1$，$L(\omega)=20\lg K$ 点
- 斜率为 $-r \times 20\text{dB/dec}$（$r$ 为积分环节个数）
- 若有 $p$ 个微分环节，起始段斜率 $+p \times 20\text{dB/dec}$

**结论3**：每经过一个转折频率，渐近线斜率改变 $\Delta L$：
- 一阶微分环节：$\Delta L=+20\text{dB/dec}$
- 二阶微分环节：$\Delta L=+40\text{dB/dec}$
- 惯性环节：$\Delta L=-20\text{dB/dec}$
- 振荡环节：$\Delta L=-40\text{dB/dec}$
- 多个环节有相同转折频率时，$\Delta L$ 叠加

**结论4**：转折频率处的幅频修正：
- 惯性环节在转折频率处修正 $-3\text{dB}$
- 一阶微分环节在转折频率处修正 $+3\text{dB}$
- 振荡环节在转折频率处修正 $-20\lg(2\zeta)$

**结论5**：剪切频率（幅值穿越频率）$\omega_c$ 的求法：
- **精确法**：令 $|G(j\omega_c)|=1$ 或 $L(\omega_c)=0\text{dB}$
- **近似法**：确定 $\omega_c$ 所在频率区间（$\omega_1<\omega_c<\omega_2$），用渐近线表达式列方程 $L(\omega_c)=0$：
  - 转折频率低于 $\omega_1$ 的环节 → 采用高频渐近线表达式
  - 转折频率高于 $\omega_2$ 的环节 → 采用低频渐近线表达式

### 二、Bode图绘制五步法（第66页）

**步骤1**：确定各典型环节的转折频率，标注在频率轴上。

**步骤2**：确定起始段斜率和位置，画出渐近线起始段：
- 过 $\omega=1$，$L(\omega)=20\lg K$ 点
- 斜率为 $-r\times 20\text{dB/dec}$（$r$ 为积分环节个数）
- 向左延伸至 $\omega=0$
- 向右延伸至第一个转折频率

**步骤3**：将 $L(\omega)$ 向高频段延伸，每经过一个转折频率，斜率改变相应 $\Delta L$。

**步骤4**：标出剪切频率 $\omega_c$。

**步骤5**：（按要求）计算转折频率处的修正量，绘制精确曲线。

### 三、对数相频特性的绘制方法（第67-68页）

**叠加法步骤**：
1. 写出对数相频特性表达式
2. 绘制各典型环节的对数相频特性曲线
3. 叠加各环节的相频特性
4. 根据相频表达式检查曲线的终点位置（终点相位 $= -(n-m)\times 90^\circ$）

### 四、典型Bode图例题

#### 例1（第69-73页）：含积分+一阶微分+惯性+振荡

$G(s)=\frac{7.5(\frac{1}{3}s+1)}{s(0.5s+1)(0.5^2s^2+0.5s+1)}$

- 比例：$20\lg 7.5=17.5\text{dB}$
- 积分环节：起始段斜率 $-20\text{dB/dec}$
- 一阶微分（转折频率 $\omega=3$）：$\Delta L=+20\text{dB/dec}$
- 惯性环节（转折频率 $\omega=2$）：$\Delta L=-20\text{dB/dec}$
- 振荡环节（转折频率 $\omega=1.414$，$\zeta=0.5$）：$\Delta L=-40\text{dB/dec}$，修正量 $-20\lg(2\zeta)=0\text{dB}$
- 修正：惯性 $-3\text{dB}$，一阶微分 $+3\text{dB}$

#### 例2（第74-75页）：零型系统

$G(s)=\frac{40(s+1)}{(20s+1)(0.5s+1)(0.1s+1)}$

- 无积分环节，起始段斜率 $0\text{dB/dec}$
- $20\lg K \approx 32\text{dB}$
- 转折频率：$\omega=0.05$（惯性1，$-20$），$\omega=1$（一阶微分，$+20$），$\omega=2$（惯性2，$-20$），$\omega=10$（惯性3，$-20$）
- 剪切频率近似值 $\omega_c=4$

#### 例3（第76-77页）：I型系统多转折频率

$G(s)=\frac{100(0.5s+1)}{s(10s+1)(0.1s+1)(0.01s+1)}$

- 一个积分环节，起始段斜率 $-20\text{dB/dec}$
- $20\lg K=40\text{dB}$
- 剪切频率近似值 $\omega_c=5$

### 五、对数相频特性起始与终止位置的判断（第78-79页）

对于系统 $G(s)=\frac{K(\tau s+1)}{s(T_1s+1)(T_2s+1)}$：

- 相频 $\varphi = -90^\circ - tg^{-1}(T_1\omega) - tg^{-1}(T_2\omega) + tg^{-1}(\tau\omega)$

**起始位置**（$\omega\to 0$）：
- 若 $\tau > T_1+T_2$，起始于 $-90^\circ$ 线上方
- 若 $\tau \le T_1+T_2$，起始于 $-90^\circ$ 线下方

**终止位置**（$\omega\to\infty$）：
- 若 $\tau > \frac{T_1T_2}{T_1+T_2}$，终止于 $-180^\circ$ 线上方
- 若 $\tau < \frac{T_1T_2}{T_1+T_2}$，终止于 $-180^\circ$ 线下方

### 六、最小相位系统（第80页）

- **定义**：传递函数的所有极点和零点均在 $s$ 左半平面（不含延时环节）
- **性质1**：幅频特性确定后，其对应的最小相位系统是**唯一**的
- **性质2**：幅频特性相同的系统中，最小相位系统的**相位变化最小**
- **非最小相位系统示例**：
  - $G_2(s)=\frac{T_2s-1}{T_1s+1}$（右半平面零点）
  - $G_3(s)=\frac{T_2s+1}{T_1s-1}$（右半平面极点）
  - $G_4(s)=e^{-\tau s}\frac{T_2s+1}{T_1s+1}$（含延时环节）

## 核心解题流程图

```
已知开环传递函数 G(s)
        │
        ├── 绘制Nyquist幅相曲线 ──────┐
        │   1. 写出 G(jω), |G|, ∠G     │
        │   2. 分离 u(ω), v(ω)         │
        │   3. 分析 ω:0→∞ 的变化趋势   │
        │   4. 求与实轴/虚轴的交点     │
        │   5. 画图，标箭头和特殊值    │
        │                              │
        └── 绘制Bode图 ───────────────┘
            1. 化为典型环节乘积形式
            2. 确定各环节转折频率
            3. 画起始段（过ω=1, L=20lgK, 斜率=-r×20dB/dec）
            4. 依次过转折频率，改变斜率
            5. 求剪切频率 ωc
            6. （可选）修正转折频率处幅值
            7. 叠加法绘制相频曲线
```
