## 一、根轨迹的基本概念

### 1.1 问题的提出

闭环系统的特征根在 S 平面上的位置直接决定了其**稳定性**及**动态特性**，因此需要分析系统参数与闭环特征根的关系：

- **系统分析问题**：如何通过闭环特征根的分布来全面了解闭环系统的特性
- **系统设计问题**：如何根据对闭环系统动态特性的要求来决定闭环特征根的合理分布，进而确定控制器的结构和参数

**求解方法**：

| 方法 | 说明 |
|------|------|
| 解析方法 | 代数方程求解。当系统阶次增高时难以实现或求解工作量巨大 |
| **根轨迹法** | W.R. Evans 1948 年提出，直接根据开环传递函数用几何图示法求出闭环极点 |

### 1.2 根轨迹的定义

> **根轨迹图**：闭环系统的特征根（即闭环极点）随开环传递函数某参数由零变化到无穷大时在 S 平面上的变化轨迹。

**【例1.1】** 已知单位反馈系统 $G(s)H(s) = \frac{K_r}{s(s+2)}$，分析闭环特征根随 $K_r$ 的变化。

**解**：闭环传递函数为

$$\Phi(s) = \frac{G(s)}{1+G(s)H(s)} = \frac{K_r}{s^2 + 2s + K_r}$$

特征方程：$s^2 + 2s + K_r = 0$

特征根：$s_{1,2} = -1 \pm \sqrt{1 - K_r}$

| $K_r$ 范围 | 特征根情况 |
|------------|-----------|
| $K_r = 0$ | $s_1 = 0,\ s_2 = -2$（开环极点） |
| $0 < K_r < 1$ | 两个不相等的负实根 |
| $K_r = 1$ | $s_1 = s_2 = -1$（等实根） |
| $1 < K_r < \infty$ | 共轭复根 $s_{1,2} = -1 \pm j\sqrt{K_r-1}$（实部恒为 -1） |

### 1.3 开环零极点与闭环零极点的关系

设控制系统前向通路传递函数为 $G(s)$，反馈通路传递函数为 $H(s)$：

$$G(s) = \frac{K_{1r} \prod\limits_{j=1}^{f} (s - z_j)}{s^{\nu} \prod\limits_{i=1}^{e} (s - p_i)} = \frac{K_1 \prod\limits_{j=1}^{f} (T_j s + 1)}{s^{\nu} \prod\limits_{i=1}^{e} (T_i s + 1)}$$

$$H(s) = \frac{K_{2r} \prod\limits_{k=1}^{h} (s - z_k)}{\prod\limits_{l=1}^{g} (s - p_l)} = \frac{K_2 \prod\limits_{k=1}^{h} (T_k s + 1)}{\prod\limits_{l=1}^{g} (T_l s + 1)}$$

开环传递函数：

$$G(s)H(s) = \frac{K_r \prod\limits_{j=1}^{m} (s - z_j)}{s^{\nu} \prod\limits_{i=1}^{n} (s - p_i)} = \frac{K \prod\limits_{j=1}^{m} (T_j s + 1)}{s^{\nu} \prod\limits_{i=1}^{n} (T_i s + 1)}$$

其中 $K$ 为**开环放大系数**，$K_r$ 为**开环根轨迹增益**，二者关系：

$$K = \lim_{s \to 0} s^{\nu} G(s)H(s) = K_r \frac{\prod\limits_{j=1}^{m} (-z_j)}{\prod\limits_{i=1}^{n} (-p_i)}$$

即 $K_r$ 与 $K$ 之间仅相差一个比例常数。

**结论**：
- **闭环零点**由前向通路的零点和反馈通路的极点组成。对于单位反馈，闭环零点就是开环零点
- **闭环极点**与开环零点、开环极点以及开环根轨迹增益 $K_r$ 有关
- 根轨迹法的任务：在已知开环零、极点分布的情况下，通过**图解法**求出闭环极点

### 1.4 根轨迹方程

负反馈系统的特征方程为：$1 + G(s)H(s) = 0$，即 $G(s)H(s) = -1$。

当系统有 $m$ 个开环零点和 $n$ 个开环极点时，特征方程可写成：

$$\boxed{K_r \frac{\prod\limits_{j=1}^{m} (s - z_j)}{\prod\limits_{i=1}^{n} (s - p_i)} = -1}$$

称为**根轨迹方程**。

根轨迹方程是一个复数方程，可分离为**幅值条件**和**相角条件**：

| | 公式 | 说明 |
|------|------|------|
| **幅值条件** | $K_r = \frac{\prod_{i=1}^{n} |s - p_i|}{\prod_{j=1}^{m} |s - z_j|}$ | 与 $K_r$ 大小有关 |
| **相角条件** | $\sum_{j=1}^{m} \angle(s - z_j) - \sum_{i=1}^{n} \angle(s - p_i) = (2k+1)\pi,\ k = 0, \pm1, \pm2, \ldots$ | 与 $K_r$ 大小无关 |

> **关键结论**：满足相角条件的点必满足幅值条件（代回可求出对应的 $K_r$），而满足幅值条件的点未必满足相角条件。**相角条件是判断根轨迹上一点的充分必要条件**。

### 1.5 定义

- **180° 根轨迹**：在开环传递函数分子和分母中 $s$ 的最高次幂系数为正的前提下，相角条件对应的角度为 $(2k+1)\pi$，称对应的根轨迹为 180° 根轨迹
- **普通根轨迹**（一般根轨迹）：以开环根轨迹增益 $K_r$ 为可变参数绘制的根轨迹

**【例1.2】** 已知 $G(s)H(s) = \frac{K}{(s+2)^2}$，证明 $s_1 = -2+j4,\ s_2 = -2-j4$ 是闭环极点。

证明思路：验证相角条件 $\angle(s_1 - p_1) + \angle(s_1 - p_2) - \angle(s_1 - z_j) = (2k+1)\pi$。

**【例1.3】** 已知 $G(s)H(s) = \frac{K}{s(s+4)}$，根轨迹上点 $s_1 = -0.5 + j0.5$，求对应的 $K$ 值。

由幅值条件：$K = |s_1 - p_1| \cdot |s_1 - p_2| = |s_1| \cdot |s_1 + 4| = 1$，得 $K = \frac{1}{4}$。

### 规则1：根轨迹的分支数、连续性和对称性

**(1) 分支数**：根轨迹的分支数等于系统特征方程的阶数，即 $m$ 和 $n$ 中的**较大者**（$\max(m, n)$）。

**(2) 连续性**：当 $K_r$ 从 $0 \to \infty$ 连续变化时，根轨迹在 S 平面上是**连续**的。

原因：由幅值条件，$K_r$ 的无限小增量对应 S 平面上长度 $|s-p_i|$ 和 $|s-z_j|$ 的无限小增量，即对应根轨迹上的无穷小位移。

**(3) 对称性**：闭环特征方程是实系数多项式方程，特征根只可能有实根、纯虚根和共轭复根，因此**根轨迹对称于实轴**。

> 利用对称性，只需绘制上半 S 平面的根轨迹，下半平面由对称性得到。

---

### 规则2：根轨迹的起点与终点

由幅值条件：

$$K_r = \frac{\prod_{i=1}^{n} |s - p_i|}{\prod_{j=1}^{m} |s - z_j|}$$

- $K_r = 0$ 时，$s = p_i$（$i = 1, 2, \ldots, n$），即**开环极点是根轨迹的起点**
- $K_r = \infty$ 时，$s = z_j$（$j = 1, 2, \ldots, m$），即**开环零点是根轨迹的终点**

**三种情形**：

| 情形 | 起点 | 终点 |
|------|------|------|
| $n = m$ | $n$ 个开环极点 | $m$ 个开环零点（有限零点） |
| $n > m$ | $n$ 个开环极点 | $m$ 个有限零点 + $(n-m)$ 条趋于无穷远（无限零点） |
| $n < m$ | $n$ 个有限极点 + $(m-n)$ 条来自无穷远（无限极点） | $m$ 个开环零点 |

> **结论**：根轨迹起始于开环极点，终止于开环零点。

---

### 规则3：实轴上的根轨迹

**分析**：考察实轴上某点 $s_0$ 到各开环零极点的相角：
- 实极点/零点在 $s_0$ **右侧**：贡献相角 $-\pi$（极点）或 $+\pi$（零点）
- 实极点/零点在 $s_0$ **左侧或重叠**：贡献相角 $0$
- 共轭极点/零点对：贡献相角互相抵消，总和为 $2\pi$ 或 $-2\pi$

> **【规则3】** 若实轴上某线段**右侧**的开环零、极点的个数之和为**奇数**，则该线段是实轴上的根轨迹。

**【例3.1】** $G(s) = \frac{K(s+1)}{s(0.5s+1)} = \frac{2K(s+1)}{s(s+2)}$

极点数 $n=2$（$p_1=0,\ p_2=-2$），零点数 $m=1$（$z_1=-1$），有 2 条根轨迹分支。实轴上 $0 \to -1$ 和 $-2 \to -\infty$ 区间为根轨迹。

**【例3.2】** $G(s)H(s) = \frac{K_r}{s(s+2)}$，$n=2,\ m=0$

实轴上 $0 \to -2$ 线段右侧有 1 个极点（奇数），该线段是根轨迹。

---

### 规则4：根轨迹的渐近线

当 $n \neq m$ 时，有 $|n-m|$ 条根轨迹趋于或来自无穷远处，这些根轨迹沿**渐近线**（切线方向的射线）运动。

#### 4.1 $n > m$ 时（无穷远处为终点）

$n-m$ 条渐近线在实轴上相交于一点：

$$\boxed{\sigma_a = \frac{\sum_{i=1}^{n} p_i - \sum_{j=1}^{m} z_j}{n - m}}$$

渐近线的倾角（正实轴方向逆时针旋转到渐近线的角度）：

$$\boxed{\phi_a = \frac{(2k+1)\pi}{n - m},\quad k = 0, 1, 2, \ldots, n-m-1}$$

#### 4.2 $n < m$ 时（无穷远处为起点）

$m-n$ 条渐近线与实轴交点和倾角：

$$\sigma_a = \frac{\sum_{i=1}^{n} p_i - \sum_{j=1}^{m} z_j}{n - m} \quad \text{（公式相同）}$$

$$\phi_a = \frac{(2k+1)\pi}{m - n},\quad k = 0, 1, 2, \ldots, m-n-1$$

**证明思路**：渐近线是 $s \to \infty$ 时根轨迹的近似。将根轨迹方程按长除法展开，取主要项，得到近似开环传递函数 $G'(s) = \frac{K_r}{(s - \sigma_a)^{n-m}}$，其根轨迹即是以 $\sigma_a$ 为起点的 $n-m$ 条射线。

**【例4.1】** $G(s)H(s) = \frac{K_r}{s(s+2)}$，$n=2,\ m=0$

- $n-m=2$，$\sigma_a = \frac{0 + (-2) - 0}{2} = -1$
- $\phi_a$：$k=0$ 时 $\phi_a = \frac{\pi}{2}$，$k=1$ 时 $\phi_a = \frac{3\pi}{2}$

**【例4.2】** $G(s)H(s) = \frac{K_r(s+2)}{s(s+1)(s+4)}$，$n=4,\ m=1,\ n-m=3$

- $\sigma_a = \frac{0 + (-1) + (-4) - (-2)}{3} = -1$
- $\phi_a$：$k=0 \to \frac{\pi}{3}$，$k=1 \to \pi$，$k=2 \to \frac{5\pi}{3}$

---

### 规则5：根轨迹的起始角与终止角

- **起始角（出射角）$\theta_{pl}$**：实轴正方向逆时针旋转到根轨迹离开开环极点处的切线的角度
- **终止角（入射角）$\theta_{zl}$**：实轴正方向逆时针旋转到根轨迹进入开环零点处的切线的角度
- 角度范围：$[0^\circ, 360^\circ)$

#### 单重极点/零点的公式

$$\boxed{\theta_{pl} = (2k+1)\pi + \sum_{j=1}^{m} \angle(p_l - z_j) - \sum_{\substack{i=1 \\ i \neq l}}^{n} \angle(p_l - p_i)}$$

$$\boxed{\theta_{zl} = (2k+1)\pi - \sum_{\substack{j=1 \\ j \neq l}}^{m} \angle(z_l - z_j) + \sum_{i=1}^{n} \angle(z_l - p_i)}$$

#### 重根情形

若 $p_l$ 为 $v$ 重根（$p_1 = p_2 = \cdots = p_v$），起始角公式修正为：

$$\theta_{pl} = \frac{1}{v}\left[(2k+1)\pi + \sum_{j=1}^{m} \angle(p_1 - z_j) - \sum_{i=v+1}^{n} \angle(p_1 - p_i)\right]$$

终止角情况类似。

**【例5.1】** $G(s)H(s) = \frac{K_r(s+2+j)(s+2-j)}{(s+1+j2)(s+1-j2)}$

$n=2,\ m=2$。计算 $p_1 = -1-j2$ 的起始角：

$$\theta_{p1} = 180^\circ + [\angle(p_1 - z_1) + \angle(p_1 - z_2)] - \angle(p_1 - p_2) = 180^\circ + 45^\circ + (-71.56^\circ) - 90^\circ = 63.45^\circ$$

取 $k=0$ 得 $\theta_{p1} \approx 206.56^\circ$（也可取 $k$ 调整到 $[0^\circ, 360^\circ)$ 范围）。

**根轨迹曲线形状判断**：当 $G(s)$ 具有分子分母均为二次多项式的形式时，根轨迹的复数部分可能为**圆**。

一般地，若 $G(s) = K_r\frac{s^2 + a s + b}{s^2 + c s + d}$，且 $a \neq c$，则非实轴上的根轨迹为一个圆（圆心和半径可通过相角条件导出）。

### 规则6：根轨迹的分离点与分离角

#### 6.1 分离点

> **分离点**：两条或两条以上根轨迹分支在 S 平面上相遇又立即分开的点。

若有 $l$ 条根轨迹进入分离点 $d$，必有 $l$ 条根轨迹离开 $d$。

**分离点坐标 $d$ 满足方程**：

$$\boxed{\sum_{j=1}^{m} \frac{1}{d - z_j} = \sum_{i=1}^{n} \frac{1}{d - p_i}}$$

（无有限零点时，取 $\sum_{j=1}^{m} \frac{1}{d - z_j} = 0$）

**等价形式**（当 $G(s) = K_r \frac{B(s)}{A(s)}$ 时）：

$$A(s)B'(s) - A'(s)B(s) = 0$$

**注意事项**：
- 根轨迹是实对称的，分离点或位于实轴上，或以共轭形式成对出现
- 若实轴上两个相邻开环极点（或零点）之间有根轨迹，则其间至少存在**一个**分离点
- 分离点方程的根**不全是**分离点，只有那些在根轨迹上的解才是分离点
- 分离点方程可能引入 $K_r < 0$ 的根和开环重极点/重零点的根，应舍去

#### 6.2 分离角

> **分离角**：根轨迹进入分离点的切线与离开分离点的切线之间的夹角。

$$\boxed{\theta_d = \frac{(2k+1)\pi}{l}}$$

其中 $l$ 为进入分离点的根轨迹分支数。

- 离开分离点的 $l$ 条根轨迹的切线倾角等间隔分布
- 进入分离点的 $l$ 条根轨迹的切线倾角也等间隔分布
- 相邻进入与离开分离点的切线方向之间的夹角为 $\pi/l$

#### 6.3 判断分离点重数

若分离点 $d$ 是 $l$ 重根，则 $D(s)$ 对 $s$ 的 $0, 1, 2, \ldots, l-1$ 阶导数在 $s=d$ 处均为 0，而 $l$ 阶导数不为 0。

即 $\frac{d^n D(s)}{ds^n}\big|_{s=d} = 0$ 对 $n = 0, 1, \ldots, l-1$ 成立，对 $n = l$ 不成立。

**【例6.1】** $G(s)H(s) = \frac{K_r}{s(s+2)}$，$n=2,\ m=0$

分离点方程：$\frac{1}{d} + \frac{1}{d+2} = 0 \Rightarrow d = -1$

分离角（$l=2$）：$\theta_d = \frac{\pi}{2}$（垂直离开实轴）

**【例6.2】** $G(s)H(s) = \frac{K_r}{(s+1)(s+2)(s+3)}$，$n=3,\ m=0$

分离点方程：$\frac{1}{d} + \frac{1}{d+1} + \frac{1}{d+2} + \frac{1}{d+3} = 0$

解得 $d_1 \approx -1.42$（在根轨迹上），$d_2 \approx -2.58$（不在根轨迹上，舍去）。

分离角（$l=2$）：$\theta_d = \frac{\pi}{2}$

### 规则7：根轨迹与虚轴的交点

根轨迹与虚轴的交点即闭环特征方程的**纯虚根**。求解方法有两种：

**法1（劳斯判据法）**：
1. 令劳斯阵列第一列含有 $K_r$ 的项为 0，求出 $K_r$
2. 利用全 0 行上一行的系数构成辅助方程，求得根轨迹与虚轴的交点 $\omega$

**法2（直接代入法）**：
1. 将 $s = j\omega$ 代入特征方程 $1 + G(j\omega)H(j\omega) = 0$
2. 令实部和虚部分别为 0：

$$\begin{cases} \text{Re}[1 + G(j\omega)H(j\omega)] = 0 \\ \text{Im}[1 + G(j\omega)H(j\omega)] = 0 \end{cases}$$

3. 求解得 $K_{rc}$（**开环根轨迹增益临界值**）和交点 $\omega$

**【例7.1】** $G(s)H(s) = \frac{K_r}{(s+1)(s+2)(s+3)}$

特征方程：$s^3 + 6s^2 + 11s + 6 + K_r = 0$

令 $s = j\omega$：
$$\begin{cases} \text{Im}: -\omega^3 + 11\omega = 0 \\ \text{Re}: -6\omega^2 + 6 + K_r = 0 \end{cases}$$

解虚部方程：$\omega_1 = 0$（舍去），$\omega_{2,3} = \pm\sqrt{11} \approx \pm 3.3$

代入实部方程：$K_{rc} = 6\omega^2 - 6 = 60$

### 规则8：根之和与根之积

系统特征方程写为：

$$D(s) = s^n + a_1 s^{n-1} + a_2 s^{n-2} + \cdots + a_{n-1} s + a_n = 0$$

- **根之和**：$\sum \lambda_i = -a_1$
- **根之积**：$\prod \lambda_i = (-1)^n a_n$

其中 $a_i$ 随 $K_r$ 变化。

> **重要结论**：若 $n - m \geq 2$，则**根之和与 $K_r$ 无关，为常值**（等于开环极点之和）。此时，当增益 $K_r$ 使某些闭环极点向左移动时，必有另一些极点向右移动，以保持根之和不变。

## 三、绘制根轨迹的标注规范

1. 起点（开环极点 $p_i$）用符号 **×** 标示；终点（开环零点 $z_j$）用符号 **○** 标示
2. 根轨迹由起点到终点对应 $K_r$ 增大，要用**箭头**标示运动方向
3. 需标出特殊点的 $K_r$ 值：起点（$K_r = 0$），终点（$K_r \to \infty$）；实轴上的分离点 $d$；与虚轴的交点 $\omega_c$（$K_r = K_{rc}$）
4. 根据需要标出其他特殊闭环极点及其对应的 $K_r$

## 四、解题通法：绘制普通根轨迹的步骤

```
① 将开环传递函数写成零极点形式:
```

### 常用公式速查

| 公式名称 | 公式 |
|----------|------|
| 幅值条件 | $K_r = \frac{\prod \vert s-p_i \vert}{\prod \vert s-z_j \vert}$ |
| 相角条件 | $\sum \angle(s-z_j) - \sum \angle(s-p_i) = (2k+1)\pi$ |
| 渐近线交点 | $\sigma_a = \frac{\sum p_i - \sum z_j}{n-m}$ |
| 渐近线倾角 | $\phi_a = \frac{(2k+1)\pi}{n-m}$ |
| 起始角 | $\theta_{pl} = (2k+1)\pi + \sum \angle(p_l-z_j) - \sum_{i \neq l} \angle(p_l-p_i)$ |
| 终止角 | $\theta_{zl} = (2k+1)\pi - \sum_{j \neq l} \angle(z_l-z_j) + \sum \angle(z_l-p_i)$ |
| 分离点方程 | $\sum \frac{1}{d-z_j} = \sum \frac{1}{d-p_i}$ |
| 分离角 | $\theta_d = \frac{(2k+1)\pi}{l}$ |
| 与虚轴交点 | $1 + G(j\omega)H(j\omega) = 0$，解 Re = 0, Im = 0 |
| 根之和（$n-m \geq 2$） | $\sum \lambda_i = \sum p_i$（常数） |
