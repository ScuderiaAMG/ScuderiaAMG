# 第19讲：波特图的绘制（Bode Diagrams）

---

## 一、绘制 Bode 图方法

### 1.1 基本原理——典型环节叠加

系统的对数频率特性可由各典型环节的对数频率特性**叠加**而成：

$$L(\omega) = 20\lg|G_1| + 20\lg|G_2| + \cdots = \sum_i L_i(\omega)$$

$$\varphi(\omega) = \angle G_1 + \angle G_2 + \cdots = \sum_i \varphi_i(\omega)$$

> 通俗理解：Bode 图最大的优势就是把乘法变加法。每个环节贡献自己的"那一段"，最后像搭积木一样拼起来。

**结论1**：控制系统的开环对数幅频特性由典型环节的对数幅频特性叠加而成。渐近线由**直线段**组成。

### 1.2 起始段的确定

**结论2**：渐近线起始段的**斜率和位置**由比例环节和积分（微分）环节决定。

当 $\omega \ll 1$ 时，只有比例和积分/微分环节起主要作用：

$$L(\omega) \approx 20\lg K - 20r \cdot \lg\omega$$

其中 $K$ 为开环放大系数，$r$ 为积分环节个数。

| 要素 | 确定方法 |
|------|---------|
| **起始段过哪个点** | 过 $(\omega=1,\ L=20\lg K)$ |
| **起始段斜率** | $-20r$ dB/dec（$r$ 为积分环节个数） |
| 有 $p$ 个微分环节 | 起始段斜率加 $+20p$ dB/dec |

> 通俗理解：低频段只有"大尺度"的环节（比例、积分、微分）起作用，惯性和振荡还没"启动"。所以低频段就是一条直线，由 $K$ 定高度、$r$ 定斜率。

**求 $K$ 的技巧**：将 $s^r G(s)$ 中令 $s=0$ 即得到开环放大系数 $K$。

### 1.3 转折频率处的斜率变化

**结论3**：从低频向高频延伸，每经过一个**转折频率**，斜率改变 $\Delta T$：

| 经过的环节 | 斜率变化 $\Delta T$ |
|-----------|:---:|
| 惯性环节 $\frac{1}{Ts+1}$ | $-20$ dB/dec |
| 振荡环节 $\frac{1}{T^2s^2+2\zeta Ts+1}$ | $-40$ dB/dec |
| 一阶微分环节 $Ts+1$ | $+20$ dB/dec |
| 二阶微分环节 $T^2s^2+2\zeta Ts+1$ | $+40$ dB/dec |

> 若有多个环节的转折频率相同，则 $\Delta T$ **叠加**。例如两个惯性环节转折频率相同，$\Delta T = -40$ dB/dec。

> 通俗理解：每遇到一个转折频率，就相当于"激活"了一个新环节。惯性/振荡让斜率更陡（往下拉），微分让斜率更缓（往上推）。

### 1.4 渐近线的误差修正

**结论4**：渐近对数幅频特性需要修正才能得到精确曲线：

| 环节 | 转折频率处修正量 |
|------|:---:|
| 惯性环节 $\frac{1}{Ts+1}$ | $-3$ dB |
| 一阶微分环节 $Ts+1$ | $+3$ dB |
| 振荡环节 $\frac{1}{T^2s^2+2\zeta Ts+1}$ | $-20\lg(2\zeta)$ dB |
| 二阶微分环节 $T^2s^2+2\zeta Ts+1$ | $+20\lg(2\zeta)$ dB |

> 通俗理解：渐近线是"粗略的折线"，在转折频率附近误差最大。惯性环节的真实值比渐近线低 3 dB，微分环节则高 3 dB。振荡环节的误差取决于阻尼比 $\zeta$——$\zeta$ 越小误差越大（谐振越明显）。

### 1.5 剪切频率 $\omega_c$

**结论5**：**剪切频率**（幅值穿越频率）$\omega_c$ 是对数幅频特性曲线**过 0 dB 线**的频率，即：

$$|G(j\omega_c)| = 1 \quad \text{或} \quad L(\omega_c) = 0 \text{ dB}$$

**求解方法**：

| 方法 | 操作 |
|------|------|
| **精确求解** | 令 $\|G(j\omega)\| = 1$，直接解方程 |
| **近似求解** | 由渐近线列方程：确定 $\omega_c$ 所在的两个转折频率 $\omega_1 < \omega_c < \omega_2$，写出该段的 $L(\omega)$ 近似式，令 $L(\omega_c) = 0$ 求解 |

> 近似求解时：转折频率低于 $\omega_1$ 的环节用高频渐近线，转折频率高于 $\omega_2$ 的环节用低频渐近线。

> 通俗理解：剪切频率是系统"增益刚好为1"的频率，它决定了系统的响应速度——$\omega_c$ 越大，系统响应越快。

### 1.6 分段作图法——五步曲

```
① 确定各典型环节的转折频率，标注在横轴上
        ↓
② 确定起始段的斜率和位置，画出起始渐近线：
   - 向左延伸到 ω=0
   - 向右画到第一个转折频率处
        ↓
③ 向高频延伸，每经过一个转折频率，
   斜率改变相应的 ΔT
        ↓
④ 标出剪切频率 ω_c
        ↓
⑤ （按题目要求）修正转折频率处的误差，
   绘制精确曲线
```

### 1.7 对数相频特性的作图——叠加法

```
① 写出对数相频特性表达式 φ(ω)
        ↓
② 分别绘制各典型环节的对数相频特性
        ↓
③ 逐点叠加（对应频率处相角相加）
        ↓
④ 根据 φ(ω) 表达式检查起点和终点的值
```

**各环节相频速查**：

| 环节 | $\omega \to 0$ | 转折频率处 | $\omega \to +\infty$ |
|------|:---:|:---:|:---:|
| 比例 $K$ | $0°$ | $0°$ | $0°$ |
| 积分 $1/s$ | $-90°$ | $-90°$ | $-90°$ |
| 微分 $s$ | $+90°$ | $+90°$ | $+90°$ |
| 惯性 $\frac{1}{Ts+1}$ | $0°$ | $-45°$ | $-90°$ |
| 一阶微分 $Ts+1$ | $0°$ | $+45°$ | $+90°$ |
| 振荡环节 | $0°$ | $-90°$ | $-180°$ |
| 二阶微分 | $0°$ | $+90°$ | $+180°$ |

## 二、绘制 Bode 图例题

### 2.1 例1：一阶微分与惯性

**题目**：已知 $G(s) = \frac{Ts}{Ts+1}$（$T > 1$），绘制 Bode 图。

**解**：

**各环节**：
- 微分环节 $s$：起始段斜率 $+20$ dB/dec
- 惯性环节 $\frac{1}{Ts+1}$：转折频率 $\omega = 1/T$，$\Delta T = -20$ dB/dec

**对数幅频特性**：

起始段：$L(\omega) = 20\lg T - 20\lg\omega$（即 $20\lg(T/\omega)$）

- $\omega = 1$ 时，$L = 20\lg T$
- $\omega = 1/T$ 时，$L = 20\lg 1 = 0$

过 $(1/T, 0)$ 画斜率为 $+20$ dB/dec 的直线，延伸到转折频率 $1/T$。经过转折频率后，斜率改变 $-20$ dB/dec，变为 $0$ dB/dec（水平线 $L = 0$）。

**对数相频特性**：

$$\varphi(\omega) = 90° - \arctan(\omega T)$$

- $\omega \to 0$：$\varphi \to 90°$
- $\omega = 1/T$：$\varphi = 45°$
- $\omega \to +\infty$：$\varphi \to 0°$

### 2.2 例2：含积分、微分、惯性、振荡的综合系统

**题目**：已知 $G(s) = \frac{7.5(1+s/3)}{s(1+0.5s)(1+0.5s+0.5s^2)}$，绘制 Bode 图。

**解**：

**各环节识别**：

| 编号 | 环节 | 转折频率 | $\Delta T$ |
|:---:|------|:---:|:---:|
| (1) | 比例 $K=7.5$ | — | — |
| (2) | 积分 $1/s$ | — | 起始斜率 $-20$ dB/dec |
| (3) | 一阶微分 $1+s/3$ | $\omega = 3$ | $+20$ dB/dec |
| (4) | 惯性 $\frac{1}{1+0.5s}$ | $\omega = 2$ | $-20$ dB/dec |
| (5) | 振荡 $\frac{1}{1+0.5s+0.5s^2}$ | $\omega = \sqrt{2} \approx 1.414$ | $-40$ dB/dec |

$20\lg K = 20\lg 7.5 = 17.5$ dB

**对数幅频特性绘制**：

**(1) 起始段**：过 $(\omega=1, L=17.5\text{ dB})$，斜率 $-20$ dB/dec。

**(2) 依次经过转折频率**：

| 转折频率 | 经过的环节 | $\Delta T$ | 新斜率 |
|:---:|------|:---:|:---:|
| $1.414$ | 振荡 | $-40$ | $-60$ dB/dec |
| $2$ | 惯性 | $-20$ | $-80$ dB/dec |
| $3$ | 一阶微分 | $+20$ | $-60$ dB/dec |

**(3) 求各转折频率处的 $L(\omega)$**：

$$L(1) = 17.5 \text{ dB}$$

$$L(1.414) = 17.5 - 20\lg(1.414) = 17.5 - 3 = 14.5 \text{ dB}$$

$$L(2) = 14.5 - 60 \times \lg(2/1.414) = 14.5 - 60 \times 0.15 = 14.5 - 9 = 5.5 \text{ dB}$$

$$L(3) = 5.5 - 80 \times \lg(3/2) = 5.5 - 80 \times 0.176 = 5.5 - 14.1 = -8.6 \text{ dB}$$

**(4) 求剪切频率 $\omega_c$**：

$L(2) = 5.5 > 0$，$L(3) = -8.6 < 0$，所以 $\omega_c$ 在 $2$ 和 $3$ 之间。该段斜率为 $-80$ dB/dec：

$$5.5 - 80\lg\frac{\omega_c}{2} = 0 \implies \omega_c = 2 \times 10^{5.5/80} \approx 2.344$$

**误差修正**：

| 环节 | 转折频率 | 修正量 |
|------|:---:|:---:|
| 振荡 ($\zeta=0.5$) | $1.414$ | $-20\lg(2 \times 0.5) = -20\lg 1 = 0$ dB |
| 惯性 | $2$ | $-3$ dB |
| 一阶微分 | $3$ | $+3$ dB |

**对数相频特性**：

$$\varphi(\omega) = -90° + \arctan(\omega/3) - \arctan(0.5\omega) + \varphi_{\text{osc}}(\omega)$$

其中振荡环节相频：

$$\varphi_{\text{osc}}(\omega) = \begin{cases} -\arctan\frac{0.5\omega}{1-0.5\omega^2}, & \omega \leq \sqrt{2} \\[6pt] -\left(180° - \arctan\frac{0.5\omega}{0.5\omega^2-1}\right), & \omega > \sqrt{2} \end{cases}$$

### 2.3 例3：无积分环节的系统

**题目**：已知 $G(s) = \frac{40(1+s)}{(1+20s)(1+0.5s)(1+0.1s)}$，绘制 Bode 图。

**解**：

**各环节**：

| 编号 | 环节 | 转折频率 | $\Delta T$ |
|:---:|------|:---:|:---:|
| (1) | 比例 $K=40$ | — | — |
| (2) | 一阶微分 $1+s$ | $\omega = 1$ | $+20$ dB/dec |
| (3) | 惯性 $\frac{1}{1+20s}$ | $\omega = 0.05$ | $-20$ dB/dec |
| (4) | 惯性 $\frac{1}{1+0.5s}$ | $\omega = 2$ | $-20$ dB/dec |
| (5) | 惯性 $\frac{1}{1+0.1s}$ | $\omega = 10$ | $-20$ dB/dec |

$20\lg K = 20\lg 40 \approx 32$ dB

**无积分环节**，起始段斜率为 $0$ dB/dec（水平线）。

**绘制过程**：

| 区间 | 斜率 |
|------|:---:|
| $\omega < 0.05$ | $0$ dB/dec（水平线 $L=32$ dB） |
| $0.05 < \omega < 1$ | $-20$ dB/dec |
| $1 < \omega < 2$ | $0$ dB/dec（$-20+20=0$） |
| $2 < \omega < 10$ | $-20$ dB/dec |
| $\omega > 10$ | $-40$ dB/dec |

**求剪切频率 $\omega_c$**：

$$20\lg 40 - 20\lg\frac{\omega_c}{0.05} = 0 \implies \omega_c = 40 \times 0.05 = 2$$

更精确：

$$20\lg 40 - 20\lg\frac{1}{0.05} + 20\lg\frac{\omega_c}{1} - 20\lg\frac{\omega_c}{0.05} \implies \omega_c \approx 4$$

（需在 $\omega=2$ 和 $\omega=10$ 之间用近似式求解）

> **最小相位系统的幅频-相频关联**：对数幅频特性斜率越负，对应的负相角越大；相频向正方向变化时，幅频斜率也在增加。

### 2.4 例4：含积分环节的综合系统

**题目**：已知 $G(s) = \frac{100(1+0.5s)}{s(1+10s)(1+0.1s)(1+0.01s)}$，绘制 Bode 图。

**解**：

**各环节**：

| 编号 | 环节 | 转折频率 | $\Delta T$ |
|:---:|------|:---:|:---:|
| (1) | 比例 $K=100$ | — | — |
| (2) | 积分 $1/s$ | — | 起始斜率 $-20$ dB/dec |
| (3) | 一阶微分 $1+0.5s$ | $\omega = 2$ | $+20$ dB/dec |
| (4) | 惯性 $\frac{1}{1+10s}$ | $\omega = 0.1$ | $-20$ dB/dec |
| (5) | 惯性 $\frac{1}{1+0.1s}$ | $\omega = 10$ | $-20$ dB/dec |
| (6) | 惯性 $\frac{1}{1+0.01s}$ | $\omega = 100$ | $-20$ dB/dec |

$20\lg K = 40$ dB，一个积分环节，起始斜率 $-20$ dB/dec。

**绘制**：

| 区间 | 斜率 |
|------|:---:|
| $\omega < 0.1$ | $-20$ dB/dec |
| $0.1 < \omega < 2$ | $-40$ dB/dec |
| $2 < \omega < 10$ | $-20$ dB/dec |
| $10 < \omega < 100$ | $-40$ dB/dec |
| $\omega > 100$ | $-60$ dB/dec |

**求剪切频率**：

精确法：令 $|G(j\omega_c)| = 1$

$$\frac{100\sqrt{1+0.25\omega_c^2}}{\omega_c\sqrt{1+100\omega_c^2}\sqrt{1+0.01\omega_c^2}\sqrt{1+0.0001\omega_c^2}} = 1$$

近似法（$\omega_c$ 在 $2$ 和 $10$ 之间，斜率 $-20$ dB/dec）：

$$20\lg 100 - 20\lg\omega_c - 20\lg\frac{\omega_c}{0.1} + 20\lg\frac{\omega_c}{2} = 0$$

解得 $\omega_c \approx 5$。

### 2.5 例5：对数相频特性的绘制——含零点的系统

**题目**：已知 $G(s) = \frac{K(\tau s + 1)}{s(T_1 s + 1)(T_2 s + 1)}$，绘制对数相频特性曲线。

**解**：

$$\varphi(\omega) = -90° - \arctan(T_1\omega) - \arctan(T_2\omega) + \arctan(\tau\omega)$$

**方法：将滞后（或超前）相角合并，判断起始和终止渐近线位置。**

**起始渐近线**（$\omega$ 很小时）：

$$\varphi \approx -90° - \arctan(T_1+T_2)\omega + \arctan\tau\omega$$

- 若 $\tau > T_1 + T_2$：起始于 $-90°$ 线**上方**（正相角贡献大于负相角）
- 若 $\tau \leq T_1 + T_2$：起始于 $-90°$ 线**下方**

**终止渐近线**（$\omega$ 很大时）：

$$\varphi \approx -90° - 180° + \arctan\frac{T_1+T_2}{T_1 T_2 \omega} + \arctan\tau\omega$$

- 若 $\tau > \frac{T_1 T_2}{T_1+T_2}$：终止于 $-180°$ 线**上方**
- 若 $\tau < \frac{T_1 T_2}{T_1+T_2}$：终止于 $-180°$ 线**下方**

> 通俗理解：零点 $\tau$ 提供正相角（超前），两个极点 $T_1$、$T_2$ 提供负相角（滞后）。相频曲线的"形状"取决于谁在低频段占优、谁在高频段占优。$\tau$ 越大，零点越强，相频越可能出现在上方。

### 2.6 例6：最小相位系统的唯一性

**题目**：已知四个系统具有相同的幅频特性，分析它们的相频差异：

$$G_1(s) = \frac{T_1 s+1}{T_2 s+1},\quad G_2(s) = \frac{T_1 s+1}{-T_2 s+1},\quad G_3(s) = \frac{T_1 s-1}{T_2 s+1},\quad G_4(s) = \frac{(T_1 s+1)e^{-\tau s}}{T_2 s+1}$$

（设 $T_1 = 10T_2$）

**解**：

四个系统的幅频特性**完全相同**：

$$|G_i(j\omega)| = \sqrt{\frac{1+T_1^2\omega^2}{1+T_2^2\omega^2}}$$

但相频特性不同：

| 系统 | 类型 | 相角变化范围 |
|------|------|:---:|
| $G_1$ | 最小相位 | **最小** |
| $G_2$ | 非最小相位（不稳定极点） | 较大 |
| $G_3$ | 非最小相位（不稳定零点） | 较大 |
| $G_4$ | 含延迟 | 最大（无界） |

> **核心结论**：
> - 幅频特性确定后，其对应的**最小相位系统是唯一的**
> - 在幅频特性相同的系统中，**最小相位系统的相位变化最小**（这就是"最小相位"命名的由来）

### 2.7 最小相位系统的幅频-相频对应关系

**对于最小相位系统**，幅频特性和相频特性**一一对应**：

> 某频率段的相角主要由该频率段的**幅频特性斜率**决定，也受相邻频段影响。

**经验规则**：若对数幅频特性的斜率为 $-k \times 20$ dB/dec，对应的相角约为 $-k \times 90°$。

| 幅频斜率 | 对应相角（近似） |
|:---:|:---:|
| $0$ dB/dec | $\approx 0°$ |
| $-20$ dB/dec | $\approx -90°$ |
| $-40$ dB/dec | $\approx -180°$ |
| $+20$ dB/dec | $\approx +90°$ |

> 通俗理解：这就是为什么最小相位系统"好分析"——只看幅频曲线的斜率，就能大致推断相角。斜率越陡，相位滞后越大。

### 2.8 例7：由 Bode 图反求传递函数

**题目**：已知某最小相位系统的渐近对数幅频特性如图所示，求开环传递函数。

图中信息：
- 起始段斜率 $-20$ dB/dec
- 转折频率 $\omega_1 = 2$（斜率变化 $+20$，一阶微分），$\omega_2 = 4$（斜率变化 $-40$，振荡环节）
- $\omega = 1$ 处 $L = 26$ dB

**解**：

**(1) 确定传递函数形式**：

起始段斜率 $-20$ dB/dec → 一个积分环节。转折频率处斜率变化 $+20$ → 一阶微分，$-40$ → 振荡环节。

$$G(s) = \frac{K(1+sT_1)}{s(T_2^2 s^2 + 2\zeta T_2 s + 1)}$$

**(2) 求时间常数**：

$$T_1 = 1/\omega_1 = 1/2 = 0.5,\quad T_2 = 1/\omega_2 = 1/4 = 0.25$$

$$T_2^2 = 0.25^2 = 1/16,\quad \text{故 } T_2^2 s^2 = s^2/16$$

**(3) 求 $K$**：

$\omega = 1$ 处 $L = 26$ dB：

$$20\lg K - 20\lg 1 = 26 \implies K = 10^{26/20} \approx 20$$

**实际上**由图读 $\omega = 1$ 和 $\omega_1 = 2$ 之间的幅值关系：

$$20\lg K = 26 \implies K \approx 20$$

综合得：

$$G(s) = \frac{20(1+0.5s)}{s(s^2/16 + 2\zeta s/4 + 1)} = \frac{20(1+0.5s)}{s(0.0625s^2 + 0.5\zeta s + 1)}$$

> 对数幅频特性确定后，其对应的**最小相位系统是唯一的**。

### 2.9 例8：由 Bode 图反求含振荡环节的系统

**题目**：已知某最小相位系统的渐近对数幅频特性：起始段斜率 $-20$ dB/dec，转折频率 $\omega = 45.3$ 处斜率变化 $-40$（振荡环节），$\omega = 100$ 处 $L = 4.85$ dB（由精确曲线估计）。

**解**：

**(1) 起始段斜率 $-20$** → 一个积分环节。

**(2) 求 $K$**：

$$20\lg K - 20\lg(100) = 4.85 \implies 20\lg K = 4.85 + 40 = 44.85 \implies K = 100$$

**(3) 转折频率 $45.3$，斜率变化 $-40$** → 振荡环节，$T = 1/45.3$：

$$G(s) = \frac{100}{s\left(\frac{s^2}{45.3^2} + \frac{2\zeta s}{45.3} + 1\right)}$$

**(4) 估算阻尼比**：

由精确曲线在转折频率处的峰值 $4.85$ dB：

$$-20\lg(2\zeta) = 4.85 \implies 2\zeta = 10^{-4.85/20} \approx 0.572 \implies \zeta \approx 0.286$$

> 通俗理解：振荡环节在转折频率处的"突起"高度直接反映了阻尼比。突起越高（正误差越大），$\zeta$ 越小，谐振越明显。

### 2.10 例9：由幅相曲线和 Bode 图综合求解

**题目**：已知某单位反馈最小相位系统的幅相曲线和渐近对数幅频特性。A 点频率为 $2$，$a=1$。求 $\omega_1$、$\omega_2$、$\omega_3$ 及闭环系统的 $\zeta$ 和 $\omega_n$。

**解**：

**(1) 由 Bode 图确定开环传函形式**：

起始段 $-20$ dB/dec（积分），转折频率 $\omega_1$ 处变 $-40$ dB/dec（惯性）：

$$G(s) = \frac{K}{s(s+\omega_1)}$$

**(2) 由幅相曲线求参数**：

$$G(j\omega) = \frac{-K}{(\omega_1^2+\omega^2)} - j\frac{K\omega_1}{\omega(\omega_1^2+\omega^2)}$$

由幅相曲线上的信息：
- $\text{Re}[G(j\omega=2)] = -\frac{K}{\omega_1^2+4} = -2a = -2$
- $\text{Re}[G(j\omega \to \infty)] = \frac{-K}{\omega_1^2+\omega^2}$ 的极限关系

解得：$K = 8a = 8$，$\omega_1 = 2$。

**(3) 求 $\omega_2$、$\omega_3$**：

由 Bode 图：
- $\omega_2$（$L$ 从 $0$ 到 $-20$ dB 的转折频率）：$\omega_2 = 2$
- $\omega_3$（剪切频率）：$\omega_3 = 4$

**(4) 求闭环参数**：

$$G(s) = \frac{8}{s(s+2)} \implies \Phi(s) = \frac{8}{s^2+2s+8}$$

与标准形式 $s^2+2\zeta\omega_n s+\omega_n^2$ 对比：

$$\omega_n^2 = 8 \implies \omega_n = 2\sqrt{2},\quad 2\zeta\omega_n = 2 \implies \zeta = \frac{2}{2 \times 2\sqrt{2}} = \frac{1}{2\sqrt{2}} = \frac{\sqrt{2}}{4}$$

### 2.11 例10：由实验 Bode 图确定含不稳定环节的传函

**题目**：实验法测得某控制系统的 Bode 图，已知该系统**不是**最小相位系统。图中：
- 起始段斜率 $-20$ dB/dec
- 转折频率 $\omega_1$、$5$、$10$，斜率依次变化 $+20$、$-20$、$-20$
- $\varphi(\omega)$ 从 $-90°$ 变化到 $-360°$
- $\omega = 1$ 处 $L = 26$ dB
- $\varphi(\omega_1) = -143.57°$

**解**：

**(1) 确定环节类型**：

起始段 $-20$ dB/dec → 积分环节。

斜率变化 $+20, -20, -20$ → 一阶微分 + 两个惯性。

**(2) 判断不稳定环节**：

$\varphi$ 从 $-90°$ 变到 $-360°$。正常最小相位系统（积分+一阶微分+两惯性）的终止相角为：

$$-90° + 90° - 90° - 90° = -180°$$

但实际终止于 $-360°$，额外多滞后 $180°$ → 存在**不稳定环节**。

可能形式：$\frac{1}{-Ts+1}$、$\frac{1}{Ts-1}$、$-Ts+1$、$Ts-1$。

- 起始值 $-90°$ 排除了 $\frac{1}{Ts-1}$（起始 $-180°$）和 $Ts-1$（起始 $+180°$）
- 终止值 $-360°$ 排除了 $\frac{1}{-Ts+1}$（终止 $-270°$）

→ 不稳定环节为 $-Ts+1$（即 $\frac{1}{-Ts+1}$ 的相频变化是 $0° \to +90°$，不符合；$-Ts+1$ 的相频变化是 $0° \to -90°$，符合）。

**(3) 确定传函**：

$$G(s) = \frac{K(1-s/\omega_1)}{s(1+s/5)(1+s/10)}$$

**(4) 求参数**：

由 $\varphi(\omega_1) = -143.57°$：

$$-90° - \arctan(0.1\omega_1) - \arctan(0.2\omega_1) - \arctan(\omega_1/\omega_1) = -143.57°$$

解得 $\omega_1 = 0.5$。

由 $20\lg K - 20\lg 1 = 26$，得 $K = 10^{26/20} \approx 20$。

**修正**：实际上需要考虑转折频率 $\omega_1 = 0.5$ 对 $L(1)$ 的影响：

$$20\lg K - 20\lg\omega_1 = 26 \implies 20\lg K = 26 + 20\lg(0.5) = 26 - 6 = 20 \implies K = 10$$

最终：

$$G(s) = \frac{10(1-2s)}{s(0.1s+1)(0.2s+1)}$$

> 通俗理解：非最小相位系统从 Bode 图的幅频特性无法直接识别（幅频和稳定系统一样），必须结合相频特性才能发现。这就是为什么实验中要同时测量幅频和相频。

## 三、总结

### 3.1 Bode 图绘制要点

| 步骤 | 内容 |
|------|------|
| 起始段 | 过 $(\omega=1,\ L=20\lg K)$，斜率 $-20r$ dB/dec |
| 转折频率 | 按从小到大排列，每经过一个改变斜率 $\Delta T$ |
| 斜率变化 | 惯性 $-20$，振荡 $-40$，一阶微分 $+20$，二阶微分 $+40$ |
| 误差修正 | 惯性 $-3$ dB，一阶微分 $+3$ dB，振荡 $-20\lg(2\zeta)$ |
| 剪切频率 | 令 $L(\omega_c) = 0$，近似法在对应段列方程 |

### 3.2 由 Bode 图反求传函的方法

```
① 起始段斜率 → 积分环节个数 r
        ↓
② 各转折频率处的斜率变化 → 判断环节类型
        ↓
③ ω=1 处 L(ω) → 求开环增益 K
        ↓
④ 转折频率 → 求时间常数 T = 1/ω
        ↓
⑤ 转折频率处的误差峰值 → 估算阻尼比 ζ
        ↓
⑥ 结合相频特性 → 判断是否为最小相位系统
   （非最小相位需额外确定不稳定环节）
```

### 3.3 最小相位系统的核心性质

| 性质 | 说明 |
|------|------|
| **唯一性** | 幅频特性确定后，对应的最小相位系统**唯一** |
| **最小相移** | 在幅频相同的所有系统中，最小相位系统的**相角变化范围最小** |
| **幅频-相频对应** | 斜率 $-k \times 20$ dB/dec 对应相角约 $-k \times 90°$ |
| **可辨识性** | 仅凭幅频特性就能完全确定最小相位系统的传函 |

### 3.4 剪切频率 $\omega_c$ 的工程意义

| 指标 | 与 $\omega_c$ 的关系 |
|------|---------------------|
| 系统响应速度 | $\omega_c$ 越大，响应越快 |
| 系统带宽 | $\omega_c$ 近似反映闭环带宽 |
| 稳定裕度 | $\omega_c$ 处的相角决定**相位裕度** $\gamma = 180° + \varphi(\omega_c)$ |

### 3.5 对数幅频-相频关联速查

| 幅频斜率 | 近似相角 | 典型环节 |
|:---:|:---:|------|
| $0$ dB/dec | $\approx 0°$ | 比例 |
| $-20$ dB/dec | $\approx -90°$ | 积分 / 惯性 |
| $-40$ dB/dec | $\approx -180°$ | 振荡 / 双惯性 |
| $+20$ dB/dec | $\approx +90°$ | 微分 / 一阶微分 |
| $+40$ dB/dec | $\approx +180°$ | 二阶微分 |

> 这一对应关系仅对**最小相位系统**严格成立。非最小相位系统的相角可能偏离很大。
