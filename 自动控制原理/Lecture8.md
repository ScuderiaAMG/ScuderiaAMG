## 一、前讲回顾（Lecture 7 要点）

### 1.1 稳定性的基本概念

| 状态 | 定义 |
|------|------|
| **稳定** | 系统受到扰动偏离平衡状态，撤销扰动后，能重新恢复到原始平衡状态 |
| **不稳定** | 扰动消失后不能恢复原始平衡状态，偏差越来越大 |
| **临界稳定** | 扰动消失后，输出与原始平衡状态间存在恒定偏差，或输出维持等幅振荡 |

### 1.2 两种判别方法（回顾）

**判别方法1（时域）**：初始条件为零，输入单位脉冲函数 $\delta(t)$，

$$\lim_{t\to\infty}c(t)=0 \quad\Rightarrow\quad \text{系统稳定}$$

**判别方法2（$S$ 域）**：传递函数 $\Phi(s)$ 的**所有极点**均在 $S$ 平面的**左半部分**。

## 二、劳斯判据（Routh Criterion）

### 2.1 稳定的必要条件

设闭环特征方程为：

$$a_n s^n + a_{n-1} s^{n-1} + \cdots + a_1 s + a_0 = 0$$

**系统稳定的必要条件是：特征方程各项系数均为正，且不缺项。**

> 注1：若同时为负，左右同乘 $-1$ 化为正。
> 注2：必要条件不满足 ⇒ 一定不稳定；必要条件满足 ⇒ 可能稳定（需进一步用劳斯判据验证）。

**证明思路**：若全部根为负实根或实部为负的共轭复根，则特征方程可分解为 $(s+\alpha)(s+\beta+j\gamma)(s+\beta-j\gamma)$ 的乘积（$\alpha,\beta>0$），展开后系数全部为正。

**快速判断**：

| 情况 | 结论 |
|------|------|
| $5s^3+6s^2+3s-5=0$（一项为负） | 不稳定 |
| $5s^3+6s^2+5=0$（缺项） | 不稳定 |
| $5s^3+6s^2+3s+5=0$（全正，不缺项） | 可能稳定，需劳斯判据 |

---

### 2.2 劳斯阵列表的构建（重点）

对特征方程 $a_n s^n + a_{n-1} s^{n-1} + \cdots + a_0 = 0$（$a_n>0$），构建 Routh 表：

| $s^n$ | $a_n$ | $a_{n-2}$ | $a_{n-4}$ | $a_{n-6}$ | $\cdots$ |
|-------|-------|-----------|-----------|-----------|----------|
| $s^{n-1}$ | $a_{n-1}$ | $a_{n-3}$ | $a_{n-5}$ | $a_{n-7}$ | $\cdots$ |
| $s^{n-2}$ | $b_1$ | $b_2$ | $b_3$ | $\cdots$ | |
| $s^{n-3}$ | $c_1$ | $c_2$ | $c_3$ | $\cdots$ | |
| $\vdots$ | $\vdots$ | $\vdots$ | | | |
| $s^0$ | | | | | |

**计算公式**：

$$b_1 = \frac{a_{n-1}a_{n-2} - a_n a_{n-3}}{a_{n-1}} = -\frac{1}{a_{n-1}}\begin{vmatrix} a_n & a_{n-2} \\ a_{n-1} & a_{n-3} \end{vmatrix}$$

$$b_2 = \frac{a_{n-1}a_{n-4} - a_n a_{n-5}}{a_{n-1}}, \quad b_3 = \frac{a_{n-1}a_{n-6} - a_n a_{n-7}}{a_{n-1}}$$

$$c_1 = \frac{b_1 a_{n-3} - a_{n-1} b_2}{b_1}, \quad \cdots$$

> **技巧**：每一行都须计算到其余项均为0。某一行中各值同乘一个正数**不影响稳定性结论**。

---

### 2.3 稳定的充要条件（判别方法3 — 重点）

> **系统稳定的充要条件**：Routh 表中**第一列各项元素均为正**。
>
> **正实部根的个数** = Routh 表第一列中系数**改变符号的次数**。

适用范围：线性定常系统，闭环特征方程。

---

### 2.4 特殊情况1：某行第一个系数为0

**条件**：劳斯表中某一行的**第一个系数为0**，其余各系数不全为0或没有其余项。

**处理方法**：用一个**小正数 $\varepsilon$** 代替0，继续计算下去。

**判定**：

| 第一列情况 | 结论 |
|------------|------|
| $\varepsilon$ 上下的元素同号（不变号） | 有一对**纯虚根**（或0根），系统**临界稳定** |
| $\varepsilon$ 上下的元素异号（变号） | 系统**不稳定**，变号次数 = 右半平面根的个数 |

**例题1.2**：特征方程为 $s^4+s^3+2s^2+2s+5=0$

| $s^4$ | 1 | 2 | 5 |
|-------|---|---|---|
| $s^3$ | 1 | 2 | |
| $s^2$ | $\varepsilon$(0) | 5 | |
| $s^1$ | $2-5/\varepsilon$ | | |
| $s^0$ | 5 | | |

第一列变号两次 → 系统不稳定，有两个正实部根。

**注意**：若该行**没有其余项**（全为0），也适用特殊情况2。

---

### 2.5 特殊情况2：某行全为零

**条件**：Routh 表中某一行**全为零**（通常出现在 $s^k$ 行，$k$ 为奇数）。

**含义**：存在关于**原点对称**的根（如 $\pm a$、$\pm j\omega$、$\pm a \pm jb$），系统**不稳定**。

**处理方法**：
1. 利用该全零行的**上一行**构成**辅助多项式** $P(s)$
2. 求辅助多项式关于 $s$ 的导数 $\frac{dP(s)}{ds}$，将其系数作为全零行的值
3. 继续计算劳斯表

**判定**：
- 第一列**不变号** → 系统**临界稳定**
- 第一列**变号** → 系统**不稳定**，变号次数 = 右半平面根的个数
- 关于原点对称的根可从**辅助多项式 = 0**解出

**例题1.3**：特征方程 $s^5+2s^4+24s^3+48s^2-25s-50=0$

| $s^5$ | 1 | 24 | -25 |
|-------|---|----|-----|
| $s^4$ | 2 | 48 | -50 |
| $s^3$ | 8（来自 $8s^3+96s$） | 96 | 0 |
| $s^2$ | 24 | -50 | |
| $s^1$ | 112.7 | 0 | |
| $s^0$ | -50 | | |

- 辅助多项式：$2s^4+48s^2-50$ → 求导：$8s^3+96s$（填入 $s^3$ 行）
- 解辅助多项式 = 0：得 $\pm 1$，$\pm j5$
- 进一步分解：$(s^4+24s^2-25)(s+2)=0$ → 5 个特征根：$-2, \pm 1, \pm j5$

---

### 2.6 等幅振荡参数的确定（例题1.4）

**问题类型**：已知等幅振荡频率，反求系统参数。

**例题1.4**：$G(s)=\frac{K(s+1)}{s^3+as^2+2s+1}$，以 $\omega=2\text{ rad/s}$ 做等幅振荡，求 $K,a>0$。

**思路**：
1. 等幅振荡 ⇒ 临界稳定，振荡频率 = 2 rad/s ⇒ 存在共轭虚根 $\pm j2$
2. 列闭环特征方程 $s^3+as^2+(2+K)s+(1+K)=0$
3. 列劳斯表，令 $s^1$ 行第一列为 0（临界稳定条件）
4. 用辅助多项式求关于原点对称的根：$as^2+(1+K)=0$ → $s_{1,2}=\pm j\sqrt{\frac{1+K}{a}}=\pm j2$
5. 联立解得 $K=2,\; a=0.75$

## 三、劳斯判据的应用

### 3.1 应用1：稳定裕量的检验（相对稳定性）

**概念**：相对稳定性指系统有多少**稳定裕量**。特征根越靠近虚轴，相对稳定性越差。

**方法**：
1. 令 $s = z - \sigma$（将 $S$ 平面左移 $\sigma$）
2. 代入特征方程得：$a_n(z-\sigma)^n + a_{n-1}(z-\sigma)^{n-1} + \cdots + a_0 = 0$
3. 对新方程（以 $z$ 为变量）应用劳斯判据
4. 若所有根在 $z$ 的虚轴左边，则系统具有稳定裕量 $\sigma$

**例题2.1**：特征方程 $2s^3+10s^2+13s+4=0$，判断稳定裕量1。

1. 原劳斯表第一列无变号 → 系统稳定
2. 令 $s = z-1$，得 $2z^3+4z^2-z-1=0$
3. 新劳斯表第一列变号一次 → 有一个根在 $s=-1$ 右边
4. 稳定裕量不到 1

---

### 3.2 应用2：使系统稳定的参数范围

**例题2.2**：单位反馈系统，开环传函 $G(s)=\frac{k}{s(T_1 s+1)(T_2 s+1)}$，求 $k$ 的范围。

**步骤**：
1. 列闭环特征方程：$T_1T_2 s^3 + (T_1+T_2)s^2 + s + k = 0$
2. 列劳斯表
3. 令第一列全部为正：

$$T_1+T_2 > kT_1T_2 > 0,\quad k > 0 \quad\Rightarrow\quad \frac{1}{T_1}+\frac{1}{T_2} > k > 0$$

---

### 3.3 应用3：时滞（延迟）系统的稳定性

时滞系统含 $e^{-\tau s}$（不是线性系统），需先做近似：

**方法1**：$e^{-\tau s} = \lim_{n\to\infty} \frac{1}{(1+\tau s/n)^n}$，取 $n$ 为有限值

**方法2**（Pade 近似）：用有理分式近似

$$e^{-\tau s} = 1 - \tau s + \frac{(\tau s)^2}{2!} - \frac{(\tau s)^3}{3!} + \cdots$$

**例题2.3**：特征方程 $s(s+1)+Ke^{-\tau s}=0$，求稳定 $K$ 范围。

用 Pade 近似 $e^{-\tau s} \approx \frac{1-\frac{3}{4}\tau s + \frac{2}{4}\tau^2 s^2/2! - \frac{1}{4}\tau^3 s^3/3!}{1+\frac{1}{4}\tau s}$，代入后用劳斯判据得 $0<K<1.1335$。

> 对比 $\tau=0$ 时只要 $K>0$ 即稳定，可见**时滞使系统稳定性变差**。此方法只能得到**近似**结果，阶次越高近似越好但计算越复杂。

## 四、题目解题通法

### 4.1 题型一：判断系统稳定性（标准劳斯表）

**步骤**：
1. 写出闭环特征方程 $1+G(s)H(s)=0$
2. 检查必要条件：系数是否全正？是否缺项？
3. 列劳斯表（按公式逐行计算）
4. 看第一列：全正→稳定；变号→不稳定，变号次数 = 右半平面根数

### 4.2 题型二：含 $\varepsilon$ 替换（特殊情况1）

**步骤**：
1. 正常列劳斯表，遇到某行第一列为0
2. 用 $\varepsilon$（小正数）代替
3. 继续计算后续行
4. 判断 $\varepsilon$ 上下元素的符号：
   - 同号 → 临界稳定（纯虚根/零根）
   - 异号 → 不稳定

### 4.3 题型三：全零行（特殊情况2）

**步骤**：
1. 发现全零行，取**上一行**构造辅助多项式 $P(s)$
2. 对 $P(s)$ 求导，导数系数填入全零行
3. 继续列劳斯表，判断第一列符号
4. 若需解特征根：令 $P(s)=0$，解出关于原点对称的根

### 4.4 题型四：临界稳定参数求解

**步骤**：
1. 列闭环特征方程
2. 列劳斯表
3. 令 $s^1$ 行第一列为0（获得临界稳定条件）
4. 结合给定的等幅振荡频率 $\omega$，从辅助多项式 $P(s)$ 解出虚根
5. 联立方程求参数

### 4.5 题型五：稳定裕量检验

**步骤**：
1. 令 $s = z - \sigma$
2. 代入特征方程，展开整理得 $z$ 的多项式
3. 对新方程列劳斯表
4. 第一列变号次数 = 在直线 $s=-\sigma$ 右边的根数

### 4.6 题型六：参数稳定范围

**步骤**：
1. 列闭环特征方程
2. 列劳斯表，第一列各元素写成含参数的表达式
3. 令第一列全部 $>0$，解不等式组
4. 求交集，得到稳定参数范围

### 4.7 常见易错点

| 易错点 | 正确做法 |
|--------|----------|
| 只检查必要条件就下结论 | 必要条件满足仅是"可能稳定"，必须列劳斯表验证充要条件 |
| 忘记 $s=z-\sigma$ 是**左移** | $s=z-\sigma$ 是左移 $\sigma$，$s=z+\sigma$ 是右移 |
| 全零行直接用上一行系数而忘记求导 | 必须先构造辅助多项式 $P(s)$，再求导 $\frac{dP(s)}{ds}$ |
| 全零行出现在偶数次幂 | 通常出现在 $s^k$ 行，$k$ 为奇数 |
| 列劳斯表计算错误 | 逐行验算，可采用同乘正数简化 |
| 开环特征方程与闭环特征方程混淆 | 稳定性判断用**闭环**特征方程 $1+G(s)H(s)=0$ |

## 五、本讲知识框架

```
劳斯判据（Routh Criterion）
├── 稳定的必要条件
│   ├── 特征方程各项系数均为正
│   └── 不缺项
├── 劳斯表构建
│   ├── 排列规则（奇偶分行）
│   ├── 递推计算公式
│   └── 同乘正数不影响结论
├── 稳定的充要条件
│   ├── 第一列全为正 → 稳定
│   └── 变号次数 = 右半平面根数
├── 两种特殊情况
│   ├── 特情1：某行第一列为0（ε法）
│   │   ├── ε上下同号 → 临界稳定（纯虚根）
│   │   └── ε上下异号 → 不稳定
│   └── 特情2：某行全为零
│       ├── 辅助多项式 P(s)
│       ├── 求导填入继续
│       └── P(s)=0 → 解出对称根
├── 三大应用
│   ├── 稳定裕量检验（s = z - σ）
│   ├── 参数稳定范围（不等式组）
│   └── 时滞系统稳定性（Pade近似）
└── 解题通法
    ├── 标准型 → 列劳斯表
    ├── ε法 → 代替零 → 看符号
    ├── 全零行 → 辅助多项式 → 求导
    ├── 临界稳定 → 令s¹第一列为0 + 虚根频率
    ├── 稳定裕量 → s = z - σ
    └── 参数范围 → 第一列全>0 → 解不等式
```
