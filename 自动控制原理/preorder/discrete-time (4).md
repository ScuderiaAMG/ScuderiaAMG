## 二、知识点详解

### 知识点1：s域到z域的映射关系

**定义**：连续时间系统的复频域变量 $s = \sigma + j\omega$ 与离散时间系统的 $z$ 域变量之间通过如下映射关系联系：

$$z = e^{sT}$$

其中 $T$ 为采样周期。将 $s = \sigma + j\omega$ 代入，得：

$$z = e^{\sigma T} \cdot e^{j\omega T}$$

因此 $|z| = e^{\sigma T}$，$\angle z = \omega T$。

**理解**：$s$ 平面的左半平面（$\sigma < 0$）映射到 $z$ 平面的单位圆内部（$|z| < 1$）；$s$ 平面的虚轴（$\sigma = 0$）映射到 $z$ 平面的单位圆上（$|z| = 1$）；$s$ 平面的右半平面（$\sigma > 0$）映射到 $z$ 平面的单位圆外部（$|z| > 1$）。这一映射是离散系统稳定性分析的基础。

**作用**：该映射关系是连接连续系统与离散系统的桥梁，使得连续域的稳定性条件（左半平面）可以转化为离散域的条件（单位圆内），从而为后续稳定性判据、w变换等方法提供理论依据。

---

### 知识点2：线性离散系统稳定性的充要条件

**定义**：线性定常离散系统稳定的充分必要条件是：闭环脉冲传递函数 $\Phi(z)$ 的所有极点均位于 $z$ 平面的单位圆内部，即对 $\Phi(z)$ 的每一个极点 $p_i$，均满足：

$$|p_i| < 1$$

**理解**：离散系统的特征根（闭环极点）决定了系统自由响应的模态。当所有极点都在单位圆内时，各模态随时间衰减至零，系统输出趋于稳定值；若存在单位圆上或单位圆外的极点，对应模态不衰减或发散，系统不稳定。

**作用**：该条件是离散系统稳定性分析的核心判据，等价于连续系统中"所有极点位于 $s$ 左半平面"的条件。后续的 $z$ 平面直接判根法和 $w$ 域劳斯判据均以此为基础。

---

### 知识点3：三种稳定性判据总结

**定义**：判断线性离散系统稳定性有三种常用方法：

1. **$z$ 平面直接判据**：求出 $\Phi(z)$ 的所有极点，判断是否均满足 $|p_i| < 1$。
2. **$w$ 域劳斯判据（广义劳斯判据）**：利用双线性变换 $w = \dfrac{z+1}{z-1}$（即 $z = \dfrac{w+1}{w-1}$），将 $z$ 平面的单位圆映射到 $w$ 平面的左半平面，然后对 $w$ 域特征方程应用劳斯判据。
3. **$s$ 域到 $z$ 域映射法**：利用 $z = e^{sT}$ 的映射关系，分析特征根在 $z$ 平面的位置。

**理解**：方法1直接求根，适用于低阶系统；方法2通过双线性变换将离散系统稳定性问题转化为连续系统形式的劳斯判据问题，适用于高阶系统；方法3是理论分析的基础工具。

**作用**：三种方法互为补充，为不同复杂程度的离散系统提供了灵活的稳定性分析手段。$w$ 域劳斯判据尤其重要，因为它可以直接利用连续系统中成熟的劳斯表方法。

---

### 知识点4：7.6节总体框架——离散系统性能分析三要素

**定义**：离散系统的性能分析包含三个方面：

1. **稳定性（Stability）**：系统在扰动消失后能否恢复到平衡状态。
2. **动态性能（Dynamic Performance）**：系统在输入作用下的瞬态响应品质，包括超调量 $\sigma\%$、调节时间 $t_s$、峰值时间 $t_p$、上升时间 $t_r$ 等。
3. **稳态误差（Steady-state Errors）**：系统响应达到稳态后，输出与期望值之间的偏差 $e(\infty)$。

**理解**：稳定性是系统正常工作的首要条件；动态性能描述系统过渡过程的快慢和平稳程度；稳态误差反映系统的稳态精度。三者构成了控制系统性能评价的完整体系。

**作用**：该框架与连续系统的性能分析体系完全对应，是离散系统分析与设计的总纲。7.6.2节讨论动态性能，7.6.3节讨论稳态误差。

---

### 知识点5：动态性能分析的一般方法

**定义**：求离散系统动态性能指标的通用算法包含以下步骤：

**步骤1：求开环脉冲传递函数**

对于单位反馈系统，开环脉冲传递函数定义为：

$$GH(z) = Z\left[G(s)H(s)\right]$$

**步骤2：求闭环脉冲传递函数**

$$\Phi(z) = \frac{G(z)}{1 + GH(z)} = \frac{M(z)}{D(z)}$$

其中 $M(z)$ 为分子多项式，$D(z)$ 为特征多项式。

**步骤3：求输出的 $z$ 变换及采样序列**

对单位阶跃输入 $R(z) = \dfrac{z}{z-1}$，输出为：

$$C(z) = \Phi(z) \cdot R(z) = \Phi(z) \cdot \frac{z}{z-1}$$

通过长除法将 $C(z)$ 展开为 $z^{-1}$ 的幂级数：

$$C(z) = c(0) + c(T)z^{-1} + c(2T)z^{-2} + \cdots$$

对应的采样输出序列为：

$$c^*(t) = c(0)\delta(t) + c(T)\delta(t-T) + c(2T)\delta(t-2T) + \cdots$$

**步骤4：由定义确定动态性能指标**

根据 $c(nT)$ 的数值序列，确定超调量 $\sigma\%$ 和调节时间 $t_s$（通常取5%误差带）。

**理解**：该方法通过逐步计算闭环脉冲传递函数、输出的 $z$ 变换和采样序列，最终得到离散的时间响应数据，再从中直接读取动态指标。长除法是获取采样点处响应值的基本手段。

**作用**：这是离散系统动态性能分析的基本流程，适用于任意阶次的系统。其局限性在于只能得到采样时刻的响应值，无法获知采样点之间的行为。

---

### 知识点6：动态性能指标定义（离散系统）

**定义**：离散系统的动态性能指标与连续系统定义一致，但仅在采样时刻取值：

- **上升时间 $t_r$**：输出首次从稳态值的10%上升到90%（或从0首次到达终值）所需的时间。
- **峰值时间 $t_p$**：输出达到第一个峰值所需的时间。
- **超调量 $\sigma\%$**：

$$\sigma\% = \frac{c_{\max} - c(\infty)}{c(\infty)} \times 100\%$$

- **调节时间 $t_s$**：输出进入并保持在稳态值的 $\pm 5\%$（或 $\pm 2\%$）误差带内所需的最短时间。
- **稳态误差 $e(\infty)$**：$t \to \infty$ 时输出与期望值之差。

**理解**：离散系统的性能指标只能在采样时刻 $t = nT$ 处度量，因此指标值是采样周期 $T$ 的函数。与连续系统不同，离散系统的响应在采样点之间可能产生波动（隐藏振荡），而性能指标无法反映这些信息。

**作用**：为离散系统的动态品质提供量化评价标准，是系统设计和参数整定的依据。

### 知识点7：例题——含ZOH的离散系统动态性能（Page 7–8）

**定义**：考虑含零阶保持器（ZOH）和单位反馈的离散系统，被控对象为 $G(s) = \dfrac{K}{s(s+1)}$，参数 $T=1$，$K=1$。

**求解过程**：

**(1) 求开环脉冲传递函数**

对含ZOH的系统，利用标准公式：

$$G(z) = (1 - z^{-1}) \cdot Z\left[\frac{K}{s^2(s+1)}\right]$$

部分分式展开 $\dfrac{1}{s^2(s+1)} = \dfrac{1}{s^2} - \dfrac{1}{s} + \dfrac{1}{s+1}$，查表得：

$$Z\left[\frac{1}{s^2(s+1)}\right] = \frac{Tz}{(z-1)^2} - \frac{z}{z-1} + \frac{z}{z - e^{-T}}$$

化简并乘以 $(1-z^{-1}) = \dfrac{z-1}{z}$，代入 $T=1$、$K=1$、$e^{-1} \approx 0.368$：

$$G(z) = \frac{(1 - e^{-T} - Te^{-T})z + (e^{-T} + T - 1)}{(z-1)(z - e^{-T})} = \frac{0.264z + 0.368}{(z-1)(z - 0.368)}$$

**(2) 求闭环脉冲传递函数**

$$\Phi(z) = \frac{G(z)}{1 + G(z)} = \frac{0.264z + 0.368}{(z-1)(z - 0.368) + 0.264z + 0.368} = \frac{0.264z + 0.368}{z^2 - 1.104z + 0.736}$$

验算：$\Phi(1) = \dfrac{0.264 + 0.368}{1 - 1.104 + 0.736} = \dfrac{0.632}{0.632} = 1$ ✓（Type 1系统对阶跃输入无稳态误差）

**(3) 求采样序列（长除法）**

$$C(z) = \Phi(z) \cdot \frac{z}{z-1} = \frac{0.264z^2 + 0.368z}{(z^2 - 1.104z + 0.736)(z-1)}$$

展开为 $z^{-1}$ 幂级数 $C(z) = \sum_{n=0}^{\infty} c(nT)z^{-n}$：

| $n$ | $c(nT)$ |
|-----|---------|
| 0   | 0       |
| 1   | 0.264   |
| 2   | 0.659   |
| 3   | 0.958   |
| 4   | 1.100   |
| 5   | 1.117   |
| 6   | 1.061   |
| 7   | 0.989   |
| 8   | 0.951   |

**(4) 确定动态指标**

- 稳态值 $c(\infty) = 1$
- 峰值 $c_{\max} \approx 1.117$（$n=5$，即 $t_p = 5T = 5$）
- 超调量 $\sigma\% = \dfrac{1.117 - 1}{1} \times 100\% \approx 11.7\%$
- 调节时间 $t_s \approx 8T = 8$（进入5%误差带）

**理解**：含ZOH的离散系统动态响应呈现衰减振荡。特征方程 $z^2 - 1.104z + 0.736 = 0$ 的根为共轭复数极点 $p_{1,2} = 0.552 \pm j0.657$，模 $|p| = \sqrt{0.736} \approx 0.858 < 1$，系统稳定且响应振荡衰减。极点幅角 $\theta \approx 49.9°$，振荡频率由 $\theta/T$ 决定。

**作用**：该例题演示了含ZOH离散系统动态性能分析的完整流程，是理解采样器和保持器对系统性能影响的基础。

### 知识点8：例题——不含ZOH的离散系统动态性能（Page 9）

**定义**：考虑同样被控对象 $G(s) = \dfrac{K}{s(s+1)}$，但不含零阶保持器，$T=1$，$K=1$。

**求解过程**：

**(1) 开环脉冲传递函数（无ZOH）**

不含ZOH时，直接对连续传递函数取 $z$ 变换：

$$G(z) = Z\left[\frac{K}{s(s+1)}\right]$$

利用部分分式 $\dfrac{1}{s(s+1)} = \dfrac{1}{s} - \dfrac{1}{s+1}$：

$$G(z) = K\left[\frac{z}{z-1} - \frac{z}{z - e^{-T}}\right] = \frac{Kz(1 - e^{-T})}{(z-1)(z - e^{-T})}$$

代入 $T=1$、$K=1$：

$$G(z) = \frac{0.632z}{(z-1)(z - 0.368)} = \frac{0.632z}{z^2 - 1.368z + 0.368}$$

**(2) 闭环脉冲传递函数**

$$\Phi(z) = \frac{G(z)}{1 + G(z)} = \frac{0.632z}{z^2 - 1.368z + 0.368 + 0.632z} = \frac{0.632z}{z^2 - 0.736z + 0.368}$$

验算 $\Phi(1) = \dfrac{0.632}{1 - 0.736 + 0.368} = \dfrac{0.632}{0.632} = 1$ ✓

**(3) 动态指标对比**

无ZOH时特征方程 $z^2 - 0.736z + 0.368 = 0$ 的极点为 $p_{1,2} = 0.368 \pm j0.483$，模 $|p| \approx 0.607$。由于无ZOH系统的开环 $G(z)$ 不同于含ZOH系统（分子无零点项），闭环极点位置不同，导致动态响应的差异：

- 无ZOH：极点模 $|p| \approx 0.607$，衰减更快，超调量较小（约15%），调节时间较短
- 含ZOH：极点模 $|p| \approx 0.858$，衰减更慢，超调量较大，调节时间较长

**理解**：不含ZOH的系统，控制信号在采样点处瞬时更新，信号传递更为直接。ZOH将采样值保持到下一采样时刻，等效引入相位滞后，使极点模增大（更靠近单位圆），响应变慢且振荡加剧。

**作用**：通过对比有无ZOH的动态性能，定量说明保持器对系统动态品质的恶化作用——ZOH增大了超调量、峰值时间和调节时间。

### 知识点9：采样器和零阶保持器对动态性能的影响

**定义**：

**(1) 采样器（Sampler）的影响**：

与对应的连续系统相比，引入采样器后：
- 峰值时间 $t_p$ 减小
- 调节时间 $t_s$ 减小
- 超调量 $\sigma\%$ 增大

**(2) 零阶保持器（ZOH）的影响**：

在采样器的基础上加入ZOH后：
- 峰值时间 $t_p$ 增大
- 调节时间 $t_s$ 增大
- 超调量 $\sigma\%$ 增大
- 振荡次数增加

**理解**：采样器使系统仅在采样时刻更新控制信号，引入了信息的离散化。在采样间隔内系统按开环方式运行，控制作用的"滞后"效应使得超调量增大。但另一方面，采样控制本质上具有间歇控制的特点，在某些情况下可以使系统响应更快（$t_p$、$t_s$ 减小）。零阶保持器将采样值保持到下一个采样时刻，相当于在系统中引入了额外的相位滞后（近似于一个纯延迟环节 $e^{-Ts/2}$），进一步恶化了系统的动态性能。

**作用**：该结论为离散系统设计提供了定性指导——在满足香农定理的前提下，应选择较小的采样周期 $T$ 以减小采样和保持带来的性能恶化。

### 知识点10：闭环极点与动态响应的关系——总体框架

**定义**：设离散系统闭环脉冲传递函数为：

$$\Phi(z) = \frac{M(z)}{D(z)} = \frac{\displaystyle\prod_{i=1}^{m}(z - z_i)}{\displaystyle\prod_{k=1}^{n}(z - p_k)}, \quad m \leq n$$

其中 $z_i$ 为闭环零点，$p_k$ 为闭环极点。

对单位阶跃输入 $R(z) = \dfrac{z}{z-1}$，输出为：

$$C(z) = \Phi(z) \cdot \frac{z}{z-1} = \frac{M(z) \cdot z}{(z-1) \cdot D(z)}$$

利用部分分式展开（假设极点均为单极点）：

$$\frac{C(z)}{z} = \frac{M(1)}{D(1)} \cdot \frac{1}{z-1} + \sum_{k=1}^{n} \frac{c_k}{z - p_k}$$

其中 $c_k$ 为对应极点 $p_k$ 的留数（residue）。

取 $z$ 反变换，得到采样响应序列：

$$c(nT) = \frac{M(1)}{D(1)} + \sum_{k=1}^{n} c_k \cdot p_k^n, \quad n = 0, 1, 2, \ldots$$

**理解**：离散系统的采样响应由稳态分量 $\dfrac{M(1)}{D(1)}$（即 $c(\infty)$）和瞬态分量 $\sum c_k p_k^n$ 组成。瞬态响应的性质完全由各闭环极点 $p_k$ 的位置决定——极点的位置决定了 $p_k^n$ 随 $n$ 变化的规律。

**作用**：该框架建立了闭环极点位置与系统动态响应之间的对应关系，是通过极点配置进行离散系统设计的理论基础。

### 知识点11：实轴上的单闭环极点与动态响应

**定义**：当闭环极点 $p_k$ 为实数时，其对采样响应的贡献为：

$$c_k(nT) = c_k \cdot p_k^n$$

其中 $c_k$ 为实数常数。根据 $p_k$ 的不同取值，响应形态分为以下几种情况：

| 极点位置 | 条件 | 响应形态 |
|---------|------|---------|
| $0 < p_k < 1$ | 正实数，单位圆内 | 单调衰减（正值递减趋于零） |
| $p_k = 1$ | 单位圆上 | 等幅（恒值，不衰减） |
| $p_k > 1$ | 正实数，单位圆外 | 单调发散（正值递增趋于无穷） |
| $-1 < p_k < 0$ | 负实数，单位圆内 | 正负交替的衰减振荡 |
| $p_k = -1$ | 单位圆上 | 正负交替的等幅振荡 |
| $p_k < -1$ | 负实数，单位圆外 | 正负交替的发散振荡 |

**理解**：$p_k^n$ 的性质直接决定了响应形态。当 $|p_k| < 1$ 时，$p_k^n \to 0$（$n \to \infty$），响应衰减；$|p_k| = 1$ 时 $|p_k^n| = 1$，响应不衰减；$|p_k| > 1$ 时 $|p_k^n| \to \infty$，响应发散。当 $p_k < 0$ 时，$p_k^n$ 的符号随 $n$ 交替变化（$n$ 为偶数时为正，奇数时为负），表现为正负交替的振荡。

**作用**：实轴极点的分析是理解离散系统动态行为的基础。稳定的离散系统要求所有极点满足 $|p_k| < 1$；极点越靠近原点，衰减越快，响应越迅速。

### 知识点12：共轭复数闭环极点与动态响应

**定义**：当闭环极点为共轭复数对 $p_k = |p_k|e^{j\theta_k}$ 和 $\bar{p}_k = |p_k|e^{-j\theta_k}$ 时（其中 $0 < \theta_k < \pi$），其对采样响应的贡献为：

$$c_k(nT) = 2|c_k| \cdot |p_k|^n \cdot \cos(n\theta_k + \varphi_k)$$

其中：
- $|p_k|$ 为极点的模（幅值）
- $\theta_k$ 为极点的幅角
- $|c_k|$ 和 $\varphi_k$ 分别为对应留数的模和幅角

**推导**：设共轭极点对的留数为 $c_k = |c_k|e^{j\varphi_k}$ 和 $\bar{c}_k = |c_k|e^{-j\varphi_k}$，则：

$$c_k p_k^n + \bar{c}_k \bar{p}_k^n = |c_k|e^{j\varphi_k} \cdot |p_k|^n e^{jn\theta_k} + |c_k|e^{-j\varphi_k} \cdot |p_k|^n e^{-jn\theta_k}$$

$$= 2|c_k| \cdot |p_k|^n \cdot \cos(n\theta_k + \varphi_k)$$

根据极点模值 $|p_k|$ 的不同，响应分为三种情况：

| 极点模值 | 条件 | 响应形态 |
|---------|------|---------|
| $|p_k| < 1$ | 单位圆内 | 衰减振荡（振幅按 $|p_k|^n$ 递减） |
| $|p_k| = 1$ | 单位圆上 | 等幅振荡（振幅恒定） |
| $|p_k| > 1$ | 单位圆外 | 发散振荡（振幅按 $|p_k|^n$ 递增） |

振荡的角频率为 $\omega_k = \dfrac{\theta_k}{T}$（弧度/秒），振荡周期为 $N = \dfrac{2\pi}{\theta_k}$ 个采样周期。

**理解**：共轭复数极点产生振荡响应。极点越靠近原点（$|p_k|$ 越小），振荡衰减越快；极点的幅角 $\theta_k$ 决定了振荡频率——$\theta_k$ 越大，振荡频率越高，每个周期内的采样点数越少。当 $\theta_k = \pi$ 时，每两个采样点完成一个完整周期，这是离散系统能表现的最高振荡频率（奈奎斯特频率）。

**作用**：共轭复数极点主导的振荡响应是离散系统动态分析的重点。通过判断主导极点的位置，可以预估系统的超调量、振荡次数和调节时间，为控制器设计提供指导。

### 知识点13：动态性能分析小结

**定义**：离散系统动态性能分析有两条路径：

**路径1：一般方法（数值法）**

$$G(z) \to \Phi(z) \to C(z) = \Phi(z) \cdot R(z) = \sum_{n=0}^{\infty} c(nT)z^{-n} \to c^*(t) = \sum_{n=0}^{\infty} c(nT)\delta(t-nT)$$

由 $c(nT)$ 的数值序列，按定义确定 $\sigma\%$ 和 $t_s$。

**路径2：极点分析法**

$$p_k \to c_k(nT) = c_k p_k^n \to \text{判断主导极点} \to \text{预估动态性能}$$

由闭环极点的位置直接判断响应形态（单调/振荡、衰减/发散），并定性估计动态品质。

**理解**：数值法精确但计算量大，适用于计算机辅助分析；极点分析法直观但定性，适用于手工估算和设计阶段的参数选择。两种方法在实际工程中常结合使用。

**作用**：该小结将动态性能分析的方法论系统化，为后续的离散系统数字控制器设计（7.7节）奠定基础。

### 知识点14：稳态误差分析——一般方法与终值定理

**定义**：对于单位反馈离散系统，误差信号 $e(t) = r(t) - c(t)$，其 $z$ 变换为：

$$E(z) = \Phi_e(z) \cdot R(z) = \frac{1}{1 + GH(z)} \cdot R(z)$$

其中 $\Phi_e(z) = \dfrac{1}{1 + GH(z)}$ 为误差脉冲传递函数，$GH(z) = Z[G(s)H(s)]$ 为开环脉冲传递函数。

**利用 $z$ 域终值定理求稳态误差**：

$$e(\infty) = \lim_{z \to 1}(z-1) \cdot E(z) = \lim_{z \to 1}(z-1) \cdot \frac{R(z)}{1 + GH(z)}$$

**使用条件**：
1. 系统必须稳定（所有闭环极点在单位圆内）。
2. $(z-1)E(z)$ 的所有极点必须位于单位圆内部（保证终值定理成立）。

**一般步骤**：
1. 判断系统稳定性。
2. 求误差脉冲传递函数 $\Phi_e(z) = \dfrac{1}{1 + GH(z)}$。
3. 利用终值定理计算 $e(\infty)$。

**理解**：$z$ 域终值定理 $\lim_{n \to \infty} f(nT) = \lim_{z \to 1}(z-1)F(z)$ 是 $s$ 域终值定理的离散对应物。使用该定理前必须先确认系统稳定——只有稳定系统才有"稳态"可言。对于不稳定系统，$e(\infty)$ 无意义。

**作用**：终值定理法是求离散系统稳态误差最直接的方法，避免了求完整响应序列的繁琐计算。

---

### 知识点15：静态误差常数与系统型别

**定义**：设开环脉冲传递函数 $GH(z)$ 在 $z=1$ 处有 $v$ 个极点，则 $v$ 称为离散系统的**型别**（system type）。将 $GH(z)$ 写成：

$$GH(z) = \frac{G_0(z)}{(z-1)^v}$$

其中 $G_0(z)$ 在 $z=1$ 处无零极点。定义三个静态误差常数：

**(1) 静态位置误差常数**

$$K_p = \lim_{z \to 1} GH(z)$$

**(2) 静态速度误差常数**

$$K_v = \lim_{z \to 1}(z-1) \cdot GH(z)$$

**(3) 静态加速度误差常数**

$$K_a = \lim_{z \to 1}(z-1)^2 \cdot GH(z)$$

**三种典型输入下的稳态误差**：

**(1) 阶跃输入 $r(t) = A \cdot 1(t)$**

$$R(z) = \frac{Az}{z-1}$$

$$e(\infty) = \lim_{z \to 1}(z-1) \cdot \frac{1}{1+GH(z)} \cdot \frac{Az}{z-1} = \frac{A}{1 + K_p}$$

**(2) 斜坡输入 $r(t) = A \cdot t$**

$$R(z) = \frac{ATz}{(z-1)^2}$$

$$e(\infty) = \lim_{z \to 1}(z-1) \cdot \frac{1}{1+GH(z)} \cdot \frac{ATz}{(z-1)^2} = \frac{AT}{K_v}$$

**(3) 抛物线输入 $r(t) = A \cdot \dfrac{t^2}{2}$**

$$R(z) = \frac{AT^2 z(z+1)}{2(z-1)^3}$$

$$e(\infty) = \lim_{z \to 1}(z-1) \cdot \frac{1}{1+GH(z)} \cdot \frac{AT^2 z(z+1)}{2(z-1)^3} = \frac{AT^2}{K_a}$$

**理解**：静态误差常数反映了系统跟踪不同形式输入信号的能力。$K_p$ 反映跟踪阶跃信号的能力；$K_v$ 反映跟踪斜坡信号的能力；$K_a$ 反映跟踪抛物线信号的能力。型别 $v$ 越高，系统对更多类型的输入能实现零稳态误差。

**作用**：静态误差常数法将稳态误差的计算转化为对开环脉冲传递函数在 $z=1$ 处极限值的求解，简化了分析过程，且揭示了系统型别与稳态精度之间的本质联系。

---

### 知识点16：系统型别与稳态误差的关系

**定义**：根据开环脉冲传递函数 $GH(z)$ 在 $z=1$ 处的极点数 $v$（系统型别），各静态误差常数和稳态误差的关系如下表：

| 系统型别 | $K_p$ | $K_v$ | $K_a$ | 阶跃输入 $e(\infty)$ | 斜坡输入 $e(\infty)$ | 抛物线输入 $e(\infty)$ |
|---------|-------|-------|-------|---------------------|---------------------|----------------------|
| 0型 ($v=0$) | 有限值 | $0$ | $0$ | $\dfrac{A}{1+K_p}$ | $\infty$ | $\infty$ |
| I型 ($v=1$) | $\infty$ | 有限值 | $0$ | $0$ | $\dfrac{AT}{K_v}$ | $\infty$ |
| II型 ($v=2$) | $\infty$ | $\infty$ | 有限值 | $0$ | $0$ | $\dfrac{AT^2}{K_a}$ |
| III型及以上 ($v \geq 3$) | $\infty$ | $\infty$ | $\infty$ | $0$ | $0$ | $0$ |

**各型别下静态误差常数的具体计算**：

- **0型系统**：$K_p = GH(1)$ 为有限值，$K_v = 0$，$K_a = 0$
- **I型系统**：$K_p = \infty$，$K_v = \lim_{z \to 1}(z-1)GH(z)$ 为有限值，$K_a = 0$
- **II型系统**：$K_p = \infty$，$K_v = \infty$，$K_a = \lim_{z \to 1}(z-1)^2 GH(z)$ 为有限值

**理解**：系统型别 $v$ 表示 $GH(z)$ 中含有 $(z-1)^{-v}$ 因子。$z=1$ 对应于 $s=0$（由 $z = e^{sT}$ 映射），因此 $v$ 个 $z=1$ 处的极点等价于连续系统中 $v$ 个积分环节。型别越高，系统对高阶输入信号的跟踪能力越强——每提高一个型别，就多一类输入可以实现有限稳态误差。与连续系统类似，实际工程中常用0型和I型系统，II型系统较少使用，III型及以上因稳定性问题几乎不用。

**作用**：该表是离散系统稳态误差分析的核心工具。通过判断系统型别和计算相应的静态误差常数，可以快速确定系统在各类输入下的稳态精度，是系统设计中选择控制器结构和参数的依据。

### 知识点17：稳态误差例题——I型系统（Page 20）

**定义**：考虑含ZOH的离散系统，被控对象为 $G(s) = \dfrac{K}{s(s+1)}$，$K=2$，$T=1$。求 $r(t) = 1(t),\ t,\ t^2/2$ 时的稳态误差。

**求解过程**：

**(1) 求开环脉冲传递函数**

对 $G_p(s) = \dfrac{K}{s(s+1)}$ 直接取 $z$ 变换（课件采用的形式）：

$$G(z) = Z\left[\frac{K}{s(s+1)}\right] = \frac{Kz(1 - e^{-T})}{(z-1)(z - e^{-T})}$$

代入 $K=2$、$T=1$、$e^{-1} \approx 0.368$：

$$G(z) = \frac{1.264z}{(z-1)(z - 0.368)}$$

**(2) 判断稳定性**

闭环特征方程：

$$D(z) = (z-1)(z - 0.368) + 1.264z = z^2 - 1.368z + 0.368 + 1.264z = z^2 - 0.104z + 0.368$$

极点 $|z| = \sqrt{0.368} \approx 0.607 < 1$，系统稳定。由 Jury 判据可得稳定范围 $0 < K < 4.33$。

**(3) 判断型别与计算稳态误差**

$G(z)$ 在 $z=1$ 处有一个极点（$v=1$），为 **I型系统**。

计算静态误差常数：

$$K_p = \lim_{z \to 1} G(z) = \infty$$

$$K_v = \lim_{z \to 1}(z-1)G(z) = \lim_{z \to 1} \frac{1.264z}{z - 0.368} = \frac{1.264}{0.632} = 2$$

$$K_a = \lim_{z \to 1}(z-1)^2 G(z) = 0$$

三种输入下的稳态误差：

- $r(t) = 1(t)$（阶跃）：$e(\infty) = \dfrac{A}{1 + K_p} = \dfrac{1}{\infty} = 0$
- $r(t) = t$（斜坡，$A=1$）：$e(\infty) = \dfrac{AT}{K_v} = \dfrac{1 \times 1}{2} = 0.5$
- $r(t) = t^2/2$（抛物线，$A=1$）：$e(\infty) = \dfrac{AT^2}{K_a} = \dfrac{1}{0} = \infty$

**理解**：I型系统能无差跟踪阶跃输入，对斜坡输入有有限稳态误差（本例 $e(\infty) = 0.5$），对抛物线输入稳态误差为无穷大。该例题的 $K_v = 2$ 由开环增益 $K$ 和采样周期 $T$ 共同决定。

**作用**：该例题演示了稳态误差分析的完整流程：判断稳定性 → 确定系统型别 → 计算静态误差常数 → 求各输入下的稳态误差。同时验证了I型系统的跟踪能力界限。

## 三、补充知识点总结

### 补充1：$w$ 变换（双线性变换）的详细说明

课件Page 3提到了 $w$ 变换 $w = \dfrac{z+1}{z-1}$，该变换将 $z$ 平面的单位圆映射到 $w$ 平面的左半平面：

- $|z| < 1$（单位圆内） $\longleftrightarrow$ $\text{Re}(w) < 0$（左半平面）
- $|z| = 1$（单位圆上） $\longleftrightarrow$ $\text{Re}(w) = 0$（虚轴）
- $|z| > 1$（单位圆外） $\longleftrightarrow$ $\text{Re}(w) > 0$（右半平面）

这使得可以将 $z$ 域的特征方程变换到 $w$ 域后，直接应用连续系统的劳斯判据来判断离散系统的稳定性。

### 补充2：隐藏振荡（Hidden Oscillation）

离散系统的性能分析仅在采样时刻进行，两个采样时刻之间的连续输出可能存在波动，称为**隐藏振荡**。当采样周期 $T$ 较大时，隐藏振荡可能很显著，实际连续输出与采样序列呈现的图像可能有较大差异。这是离散系统性能分析的一个重要局限性——仅依据采样点数据评价系统性能可能不够全面。

### 补充3：采样周期选择对性能的影响

采样周期 $T$ 是离散系统设计的关键参数：
- $T$ 越小：采样频率越高，离散系统行为越接近连续系统，动态性能越好，但计算负担增大。
- $T$ 越大：采样频率越低，信息丢失越多，隐藏振荡越大，动态性能恶化，甚至可能导致不稳定。
- 选择原则：在满足香农采样定理（$f_s > 2f_{\max}$）的前提下，综合考虑计算能力和控制性能。

### 补充4：离散系统与连续系统稳态误差的对比

离散系统的稳态误差分析与连续系统在方法上高度一致：
- 连续系统：$K_p = \lim_{s \to 0} G(s)$，$K_v = \lim_{s \to 0} sG(s)$，$K_a = \lim_{s \to 0} s^2 G(s)$
- 离散系统：$K_p = \lim_{z \to 1} GH(z)$，$K_v = \lim_{z \to 1}(z-1)GH(z)$，$K_a = \lim_{z \to 1}(z-1)^2 GH(z)$

二者的对应关系为 $s \to 0$ 对应 $z \to 1$（由 $z = e^{sT}$），$s$ 因子对应 $(z-1)$ 因子。系统型别的定义也一致：连续系统按 $s=0$ 处的极点数，离散系统按 $z=1$ 处的极点数。但需注意，离散系统的 $K_v$、$K_a$ 与采样周期 $T$ 有关，而连续系统的对应常数不含 $T$。

### 补充5：ZOH对稳态误差的影响（来自Page 27例题）

对于被控对象 $G(s) = \dfrac{K}{s}$，输入为斜坡信号 $r(t) = 2t$：

- **无ZOH**：$e(\infty) = \dfrac{2T}{K}$，稳态误差与采样周期 $T$ 成正比。
- **有ZOH**：$e(\infty) = \dfrac{2}{K}$，稳态误差与采样周期 $T$ 无关。

该结论说明：ZOH通过在采样间隔内保持信号值不变，等效于对输入信号进行了"预测"，使得稳态误差不再随 $T$ 变化。但这并不意味着ZOH总是有利的——ZOH引入了相位滞后，会恶化动态性能（增大超调量和调节时间）。

## 新增知识点

### 知识点 1：系统型别（System Type）

**定义**：

离散时间系统的型别 $v$ 定义为开环脉冲传递函数 $GH(z)$ 在 $z=1$ 处的极点重数。将 $GH(z)$ 写成如下标准形式：

$$GH(z) = \frac{N(z)}{(z-1)^v \cdot D'(z)}$$

其中 $D'(1) \neq 0$，$N(1) \neq 0$，则 $v$ 即为系统型别。

- $v=0$：0 型系统（Type 0）
- $v=1$：I 型系统（Type I）
- $v=2$：II 型系统（Type II）

**理解**：

$(z-1)^v$ 对应连续系统中 $s^v$ 的作用。$z=1$ 处的极点来源于连续域中 $s=0$ 处的极点（即积分环节），经过 $z = e^{sT}$ 映射后 $s=0$ 变为 $z=1$。$v$ 的数值直接反映系统对多项式输入信号的跟踪能力：$v$ 越大，系统能够无稳态误差跟踪的输入信号阶次越高。

**作用**：

系统型别是静态误差系数法的核心前置概念。确定 $v$ 后，可立即判断各静态误差系数（$K_p, K_v, K_a$）是有限值、零还是无穷大，从而快速确定各典型输入下的稳态误差性质（为零、有限值还是无穷大）。

---

### 知识点 2：静态误差系数（Static Error Constants）

**定义**：

对于稳定的线性离散系统（误差信号经过采样），定义三个静态误差系数：

- **静态位置误差系数**（Static Position Error Constant）：

$$K_p = \lim_{z \to 1} GH(z)$$

- **静态速度误差系数**（Static Velocity Error Constant）：

$$K_v = \lim_{z \to 1} (z-1) \cdot GH(z)$$

- **静态加速度误差系数**（Static Acceleration Error Constant）：

$$K_a = \lim_{z \to 1} (z-1)^2 \cdot GH(z)$$

**理解**：

静态误差系数度量的是开环脉冲传递函数在 $z=1$（对应直流/稳态）处的增益特性。每个系数对应一种典型输入信号：$K_p$ 对应阶跃输入，$K_v$ 对应斜坡输入，$K_a$ 对应抛物线输入。系数值越大，该输入下的稳态误差越小。当系数为无穷大时，对应的稳态误差为零。

三个系数的取值与系统型别 $v$ 有确定的对应关系：

| 系统型别 $v$ | $K_p$ | $K_v$ | $K_a$ |
|:---:|:---:|:---:|:---:|
| 0 | 有限常数 | $0$ | $0$ |
| 1 | $\infty$ | 有限常数 | $0$ |
| 2 | $\infty$ | $\infty$ | 有限常数 |
| $\geq 3$ | $\infty$ | $\infty$ | $\infty$ |

**作用**：

静态误差系数是连接系统型别与稳态误差的桥梁。在已知系统型别和开环传递函数后，可以直接计算 $K_p, K_v, K_a$，再结合输入信号的幅值 $A$ 和采样周期 $T$，即可得到稳态误差值，无需每次都用终值定理重新推导。

---

### 知识点 3：各型别系统稳态误差汇总

**定义**：

对于单位反馈的线性离散系统（误差信号经采样），不同型别系统在三种典型输入下的稳态误差如下表：

| 系统型别 | $r(t) = A \cdot 1(t)$（阶跃） | $r(t) = A \cdot t$（斜坡） | $r(t) = \dfrac{A \cdot t^2}{2}$（抛物线） |
|:---:|:---:|:---:|:---:|
| 0 型 | $\dfrac{A}{1+K_p}$ | $\infty$ | $\infty$ |
| I 型 | $0$ | $\dfrac{AT}{K_v}$ | $\infty$ |
| II 型 | $0$ | $0$ | $\dfrac{AT^2}{K_a}$ |

其中各稳态误差的通用公式为：

$$e(\infty)_{\text{阶跃}} = \frac{A}{1 + K_p}, \quad e(\infty)_{\text{斜坡}} = \frac{AT}{K_v}, \quad e(\infty)_{\text{抛物线}} = \frac{AT^2}{K_a}$$

**理解**：

- 阶跃输入下，0 型系统有有限稳态误差 $A/(1+K_p)$；I 型及以上系统 $K_p = \infty$，故 $e(\infty)=0$。
- 斜坡输入下，0 型系统 $K_v = 0$ 故 $e(\infty)=\infty$（无法跟踪）；I 型系统 $K_v$ 为有限值，$e(\infty) = AT/K_v$；II 型及以上 $K_v = \infty$，故 $e(\infty)=0$。
- 抛物线输入下，0 型和 I 型系统 $K_a = 0$ 故 $e(\infty)=\infty$；II 型系统 $K_a$ 为有限值，$e(\infty) = AT^2/K_a$。
- 注意离散系统中斜坡输入的稳态误差公式含采样周期 $T$（与连续系统 $e(\infty)=A/K_v^{\text{cont}}$ 不同），这是因为 $K_v$ 的定义中未含 $1/T$ 因子。

**作用**：

此汇总表是静态误差系数法的最终应用工具。在确定系统型别和计算相应误差系数后，可直接查表得到稳态误差，是工程分析中最常用的快速判断方法。

---

### 知识点 4：零阶保持器（ZOH）对稳态误差的影响

**定义**：

零阶保持器（Zero-Order Hold, ZOH）的传递函数为 $G_h(s) = (1 - e^{-Ts})/s$。在计算开环脉冲传递函数时，ZOH 与受控对象的传递函数需要合并后一起进行 Z 变换：

$$G(z) = \mathcal{Z}\left[\frac{1-e^{-Ts}}{s} \cdot G_p(s)\right] = (1-z^{-1}) \cdot \mathcal{Z}\left[\frac{G_p(s)}{s}\right]$$

**理解**：

- ZOH 将采样后的脉冲信号保持为阶梯信号，使受控对象接收到连续时间信号（而非脉冲序列）。
- ZOH 改变了开环脉冲传递函数 $G(z)$ 的具体表达式，因此可能改变静态误差系数 $K_v, K_a$ 的数值。
- 对于某些系统（如 $G_p(s)=K/s$），有 ZOH 时 $K_v$ 与 $T$ 有关；无 ZOH 时 $K_v$ 可能与 $T$ 无关。
- ZOH 不影响系统型别 $v$（因为 $(1-z^{-1})$ 在 $z=1$ 处恰好提供一个零点，与 $G_p(s)/s$ 在 $z=1$ 处的极点抵消一个后，$z=1$ 处极点总数不变）。

**作用**：

在工程实践中，数字控制系统通常包含 ZOH。分析稳态误差时必须将 ZOH 纳入开环传递函数的计算。同时，对比有/无 ZOH 的稳态误差有助于理解保持器对系统精度的影响。

---

### 知识点 5：多信号叠加输入的稳态误差

**定义**：

当输入信号为多个典型信号的线性组合时（如 $r(t) = A_1 \cdot 1(t) + A_2 \cdot t$），对于线性系统可利用叠加原理分别计算各分量产生的稳态误差，然后求和：

$$e(\infty) = e_1(\infty) + e_2(\infty) + \cdots$$

**理解**：

线性系统满足叠加原理。误差信号 $E(z) = \Phi_e(z) \cdot R(z)$，当 $R(z) = R_1(z) + R_2(z)$ 时，$E(z) = \Phi_e(z)R_1(z) + \Phi_e(z)R_2(z)$。分别对每一项取终值即可。

**作用**：

此知识点使静态误差系数法能够处理复合输入信号。例如 $r(t) = 2 \cdot 1(t) + t$ 可拆分为阶跃分量（幅值 $A=2$）和斜坡分量（幅值 $A=1$），分别求 $e(\infty)$ 后相加。

---

## 解题方法汇总

### 方法 1：终值定理法求离散系统稳态误差

- **适用场景**：已知系统结构和参数的稳定线性离散系统，需要求精确稳态误差值
- **已知条件**：
  - 系统已确认稳定（所有闭环极点位于 $z$ 平面单位圆内）
  - 开环脉冲传递函数 $GH(z)$
  - 输入信号 $r(t)$ 的形式
  - 采样周期 $T$

- **计算步骤**：

  1. **验证稳定性**：求闭环特征方程 $D(z) = 1 + GH(z) = 0$ 的根，确认所有根的模 $|z_i| < 1$。若系统不稳定，则稳态误差无意义，停止计算。

  2. **求误差传递函数**：

  $$\Phi_e(z) = \frac{E(z)}{R(z)} = \frac{1}{1 + GH(z)}$$

  将 $GH(z)$ 代入，通分化简为有理分式 $\Phi_e(z) = \frac{N_e(z)}{D(z)}$。

  3. **确定输入的 Z 变换**：根据 $r(t)$ 的形式查表：
     - $r(t) = A \cdot 1(t)$（阶跃）$\Rightarrow R(z) = \dfrac{Az}{z-1}$
     - $r(t) = A \cdot t$（斜坡）$\Rightarrow R(z) = \dfrac{ATz}{(z-1)^2}$
     - $r(t) = \dfrac{A \cdot t^2}{2}$（抛物线）$\Rightarrow R(z) = \dfrac{AT^2 z(z+1)}{2(z-1)^3}$

  4. **应用终值定理**：

  $$e(\infty) = \lim_{z \to 1} (z-1) \cdot \Phi_e(z) \cdot R(z)$$

  将步骤 2 和步骤 3 的结果代入，约去 $(z-1)$ 的公因子后，令 $z=1$ 计算极限值。

  5. **得出结果**：若极限为有限值，即为稳态误差；若极限为 $\infty$，表示系统无法跟踪该输入。

- **常见错误**：
  1. **未验证稳定性**：终值定理仅在 $E(z)$ 的所有极点位于单位圆内时成立。不稳定系统的 $e(\infty)$ 不存在。
  2. **$GH(z)$ 计算错误**：有 ZOH 时，必须先合并 $G_h(s) \cdot G_p(s)$ 再整体做 Z 变换，不能分别变换后相乘。即 $GH(z) = \mathcal{Z}[G_h(s)G_p(s)]$，而非 $\mathcal{Z}[G_h(s)] \cdot \mathcal{Z}[G_p(s)]$。
  3. **极限计算错误**：若代入 $z=1$ 后出现 $0/0$ 型不定式，需对分子分母同时约去 $(z-1)$ 因子后再求极限，或用洛必达法则。

---

### 方法 2：静态误差系数法求离散系统稳态误差

- **适用场景**：单位反馈的稳定线性离散系统（误差信号经采样），快速判断各典型输入下的稳态误差
- **已知条件**：
  - 系统已确认稳定
  - 开环脉冲传递函数 $GH(z)$
  - 输入信号类型（阶跃/斜坡/抛物线）及幅值 $A$
  - 采样周期 $T$

- **计算步骤**：

  1. **确定系统型别 $v$**：将 $GH(z)$ 写成 $\dfrac{N(z)}{(z-1)^v \cdot D'(z)}$ 形式（其中 $D'(1)\neq 0, N(1)\neq 0$），$v$ 为 $GH(z)$ 在 $z=1$ 处的极点重数。

  2. **判断输入对应的误差系数**：
     - 阶跃输入 $r(t)=A \cdot 1(t)$：需计算 $K_p$
     - 斜坡输入 $r(t)=A \cdot t$：需计算 $K_v$
     - 抛物线输入 $r(t)=At^2/2$：需计算 $K_a$

  3. **计算相应的静态误差系数**：

     **位置误差系数**：
     $$K_p = \lim_{z \to 1} GH(z)$$
     - 若 $v=0$：$K_p = GH(1)$（有限常数），$e(\infty) = \dfrac{A}{1+K_p}$
     - 若 $v \geq 1$：$K_p = \infty$，$e(\infty) = 0$

     **速度误差系数**：
     $$K_v = \lim_{z \to 1} (z-1) \cdot GH(z)$$
     - 若 $v=0$：$K_v = 0$，$e(\infty) = \infty$
     - 若 $v=1$：$K_v$ 为有限常数，$e(\infty) = \dfrac{AT}{K_v}$
     - 若 $v \geq 2$：$K_v = \infty$，$e(\infty) = 0$

     **加速度误差系数**：
     $$K_a = \lim_{z \to 1} (z-1)^2 \cdot GH(z)$$
     - 若 $v \leq 1$：$K_a = 0$，$e(\infty) = \infty$
     - 若 $v=2$：$K_a$ 为有限常数，$e(\infty) = \dfrac{AT^2}{K_a}$
     - 若 $v \geq 3$：$K_a = \infty$，$e(\infty) = 0$

  4. **复合输入叠加**：若输入为多个典型信号的叠加（如 $r(t) = A_1 \cdot 1(t) + A_2 \cdot t$），分别计算各分量的 $e(\infty)$，然后求和。

- **常见错误**：
  1. **型别判断错误**：$v$ 是 $GH(z)$ 在 $z=1$ 处的极点重数，不是开环传递函数中积分环节的个数（后者是连续系统的定义）。
  2. **公式混淆**：离散系统中斜坡输入的 $e(\infty) = AT/K_v$（含 $T$），连续系统中 $e(\infty) = A/K_v$（不含 $T$）。两者 $K_v$ 的定义不同。
  3. **系数计算中忽略 $z$ 因子**：$GH(z)$ 的分子通常含有 $z$ 的幂次项，代入 $z=1$ 后这些项变为 1，但计算过程中不能提前省略。

---

### 方法 3：求稳态误差约束下的参数范围

- **适用场景**：已知稳态误差指标要求（如 $e(\infty) < \varepsilon$），需要确定系统参数（如增益 $K$）的允许范围
- **已知条件**：
  - 系统结构和采样周期 $T$
  - 输入信号 $r(t)$
  - 稳态误差约束条件

- **计算步骤**：

  1. **求系统稳定的参数范围**：列写闭环特征方程 $D(z)=0$，利用 Jury 判据或 $w$ 域 Routh 判据确定使系统稳定的参数范围。

  2. **求满足稳态误差的参数范围**：
     - 确定系统型别 $v$
     - 计算相应的静态误差系数（通常含待定参数 $K$）
     - 建立稳态误差不等式 $e(\infty) < \varepsilon$
     - 解不等式得到参数约束

  3. **取交集**：稳定范围与稳态误差范围的交集即为参数的最终允许范围。

- **常见错误**：
  1. **遗漏稳定性约束**：只考虑稳态误差条件而忘记系统必须首先稳定。
  2. **复合输入未叠加**：对叠加输入只计算了一个分量的误差。
  3. **不等式方向错误**：$e(\infty) < \varepsilon$ 解出的参数范围与直觉相反时（如 $K > K_{\min}$ 而非 $K < K_{\max}$），需仔细检查。

## 例题汇总

### 例题 1：终值定理法求三种输入下的稳态误差（Page 20–21）

**题干**：

考虑如图所示的离散控制系统，前向通道含零阶保持器（ZOH）和受控对象 $G_p(s) = K/s$，单位反馈，误差信号经采样。已知 $K=2$，$T=1$。分别求 $r(t) = 1(t)$、$r(t) = t$、$r(t) = t^2/2$ 时的稳态误差 $e(\infty)$。

**解**：

**第 1 步**：求开环脉冲传递函数 $G(z)$。

系统含 ZOH，因此：

$$G(z) = \mathcal{Z}\left[\frac{1-e^{-Ts}}{s} \cdot \frac{K}{s}\right] = (1-z^{-1}) \cdot \mathcal{Z}\left[\frac{K}{s^2}\right]$$

查 Z 变换表：$\mathcal{Z}\left[\dfrac{1}{s^2}\right] = \dfrac{Tz}{(z-1)^2}$，故：

$$G(z) = \frac{z-1}{z} \cdot \frac{KTz}{(z-1)^2} = \frac{KT}{z-1}$$

代入 $K=2$，$T=1$：

$$\boxed{G(z) = \frac{2}{z-1}}$$

**第 2 步**：确定系统型别。

$G(z) = \dfrac{2}{z-1}$ 在 $z=1$ 处有一个极点，故 $v=1$，为 **I 型系统**。

**第 3 步**：求误差传递函数 $\Phi_e(z)$。

$$\Phi_e(z) = \frac{1}{1+G(z)} = \frac{1}{1 + \dfrac{2}{z-1}} = \frac{z-1}{z-1+2} = \frac{z-1}{z+1}$$

**第 4 步**：验证稳定性。

闭环特征方程：$z+1=0 \implies z=-1$。

$|z| = |-1| = 1$，极点位于单位圆上（临界稳定）。

> **注意**：原题设定系统稳定。此处 $z=-1$ 为单位圆上的极点，系统实际处于临界稳定状态。为完整演示方法，以下仍按终值定理计算。（原题可能含其他环节使系统严格稳定。）

**第 5 步**：计算 $r(t) = 1(t)$（阶跃输入）的 $e(\infty)$。

$R(z) = \dfrac{z}{z-1}$，应用终值定理：

$$e(\infty) = \lim_{z \to 1}(z-1) \cdot \Phi_e(z) \cdot R(z) = \lim_{z \to 1}(z-1) \cdot \frac{z-1}{z+1} \cdot \frac{z}{z-1}$$

约去一个 $(z-1)$：

$$e(\infty) = \lim_{z \to 1} \frac{(z-1) \cdot z}{z+1} = \frac{(1-1) \times 1}{1+1} = \frac{0}{2} = 0$$

$$\boxed{r(t) = 1(t) \text{ 时，} e(\infty) = 0}$$

**验证**：I 型系统，$K_p = \lim_{z\to 1} G(z) = \infty$，$e(\infty) = A/(1+K_p) = 1/\infty = 0$。✓

---

**第 6 步**：计算 $r(t) = t$（斜坡输入）的 $e(\infty)$。

$R(z) = \dfrac{Tz}{(z-1)^2} = \dfrac{z}{(z-1)^2}$（$T=1$），应用终值定理：

$$e(\infty) = \lim_{z \to 1}(z-1) \cdot \frac{z-1}{z+1} \cdot \frac{z}{(z-1)^2}$$

分子：$(z-1)(z-1) \cdot z = z(z-1)^2$；分母：$(z+1)(z-1)^2$。约去 $(z-1)^2$：

$$e(\infty) = \lim_{z \to 1} \frac{z}{z+1} = \frac{1}{1+1} = \frac{1}{2} = 0.5$$

$$\boxed{r(t) = t \text{ 时，} e(\infty) = \frac{T}{K} = 0.5}$$

**验证**：$K_v = \lim_{z\to 1}(z-1)G(z) = \lim_{z\to 1}(z-1) \cdot \dfrac{2}{z-1} = 2$，$e(\infty) = AT/K_v = (1)(1)/2 = 0.5$。✓

---

**第 7 步**：计算 $r(t) = t^2/2$（抛物线输入）的 $e(\infty)$。

$R(z) = \dfrac{T^2 z(z+1)}{2(z-1)^3} = \dfrac{z(z+1)}{2(z-1)^3}$（$T=1$），应用终值定理：

$$e(\infty) = \lim_{z \to 1}(z-1) \cdot \frac{z-1}{z+1} \cdot \frac{z(z+1)}{2(z-1)^3}$$

分子：$(z-1)^2 \cdot z(z+1)$；分母：$(z+1) \cdot 2(z-1)^3$。约去 $(z-1)^2(z+1)$：

$$e(\infty) = \lim_{z \to 1} \frac{z}{2(z-1)} = \frac{1}{2 \times 0} \to \infty$$

$$\boxed{r(t) = t^2/2 \text{ 时，} e(\infty) = \infty}$$

**验证**：$K_a = \lim_{z\to 1}(z-1)^2 G(z) = \lim_{z\to 1}(z-1)^2 \cdot \dfrac{2}{z-1} = \lim_{z\to 1} 2(z-1) = 0$。$e(\infty) = AT^2/K_a = 1/0 = \infty$。✓ I 型系统无法跟踪抛物线输入。

---

**答案汇总**：

| 输入信号 | $e(\infty)$ | 物理含义 |
|:---:|:---:|:---|
| $r(t) = 1(t)$ | $0$ | I 型系统可无误差跟踪阶跃输入 |
| $r(t) = t$ | $0.5$ | I 型系统跟踪斜坡输入有有限稳态误差 |
| $r(t) = t^2/2$ | $\infty$ | I 型系统无法跟踪抛物线输入 |

### 例题 2：有/无 ZOH 时的稳态误差比较（Page 27）

**题干**：

考虑如图所示的稳定离散控制系统，受控对象 $G_p(s) = K/s$，单位反馈，误差信号经采样，$r(t) = 2t$（斜坡输入，$A=2$）。分别计算无 ZOH（仅有采样器）和有 ZOH 时的稳态误差 $e(\infty)$，并讨论采样周期 $T$ 的影响。

**解**：

#### 情况一：无 ZOH（仅有采样器）

**第 1 步**：求无 ZOH 时的开环脉冲传递函数。

无 ZOH 时，采样器的输出为脉冲序列，直接作用于 $G_p(s)=K/s$。等效脉冲传递函数为：

$$G(z) = \mathcal{Z}[G_p(s)] = \mathcal{Z}\left[\frac{K}{s}\right] = \frac{Kz}{z-1}$$

**第 2 步**：确定系统型别。

$G(z) = \dfrac{Kz}{z-1}$ 在 $z=1$ 处有一个极点，$v=1$（I 型系统）。

**第 3 步**：计算静态速度误差系数 $K_v$。

$$K_v = \lim_{z \to 1}(z-1) \cdot G(z) = \lim_{z \to 1}(z-1) \cdot \frac{Kz}{z-1} = \lim_{z \to 1} Kz = K$$

**第 4 步**：计算稳态误差。

$r(t) = 2t$，$A=2$：

$$e(\infty) = \frac{AT}{K_v} = \frac{2T}{K}$$

$$\boxed{e(\infty)_{\text{无ZOH}} = \frac{2T}{K} \quad \text{（与 } T \text{ 有关）}}$$

---

#### 情况二：有 ZOH

**第 5 步**：求有 ZOH 时的开环脉冲传递函数。

$$G(z) = \mathcal{Z}\left[\frac{1-e^{-Ts}}{s} \cdot \frac{K}{s}\right] = (1-z^{-1}) \cdot \mathcal{Z}\left[\frac{K}{s^2}\right] = \frac{z-1}{z} \cdot \frac{KTz}{(z-1)^2} = \frac{KT}{z-1}$$

**第 6 步**：确定系统型别。

$G(z) = \dfrac{KT}{z-1}$ 在 $z=1$ 处有一个极点，$v=1$（I 型系统）。

**第 7 步**：计算静态速度误差系数 $K_v$。

$$K_v = \lim_{z \to 1}(z-1) \cdot G(z) = \lim_{z \to 1}(z-1) \cdot \frac{KT}{z-1} = KT$$

**第 8 步**：计算稳态误差。

$r(t) = 2t$，$A=2$：

$$e(\infty) = \frac{AT}{K_v} = \frac{2T}{KT} = \frac{2}{K}$$

$$\boxed{e(\infty)_{\text{有ZOH}} = \frac{2}{K} \quad \text{（与 } T \text{ 无关）}}$$

---

**答案**：

| 配置 | $K_v$ | $e(\infty)$ | 与 $T$ 的关系 |
|:---:|:---:|:---:|:---:|
| 无 ZOH | $K$ | $\dfrac{2T}{K}$ | 有关（$T$ 越小，误差越小） |
| 有 ZOH | $KT$ | $\dfrac{2}{K}$ | 无关 |

**结论**：ZOH 的引入使 $K_v$ 从 $K$ 变为 $KT$，稳态误差从 $\dfrac{2T}{K}$ 变为 $\dfrac{2}{K}$。有 ZOH 时，$e(\infty)$ 与采样周期 $T$ 无关；无 ZOH 时，$e(\infty)$ 随 $T$ 增大而增大。

### 例题 3：求满足稳态误差约束的增益范围（Page 28）

**题干**：

考虑如图所示的离散控制系统，前向通道含零阶保持器（ZOH）和受控对象，单位反馈，误差信号经采样。采样周期 $T=0.25$。输入信号 $r(t) = 2 \cdot 1(t) + t$。求使 $e(\infty) < 0.5$ 的 $K$ 值范围。

已知该系统的稳定范围为 $0 < K < 2.472$。

**解**：

**第 1 步**：求开环脉冲传递函数 $G(z)$。

系统含 ZOH，设受控对象为 $G_p(s) = K/s^2$（由原题结构确定），则：

$$G(z) = \mathcal{Z}\left[\frac{1-e^{-Ts}}{s} \cdot \frac{K}{s^2}\right] = (1-z^{-1}) \cdot \mathcal{Z}\left[\frac{K}{s^3}\right]$$

查表 $\mathcal{Z}\left[\dfrac{1}{s^3}\right] = \dfrac{T^2 z(z+1)}{2(z-1)^3}$，代入：

$$G(z) = \frac{z-1}{z} \cdot \frac{KT^2 z(z+1)}{2(z-1)^3} = \frac{KT^2(z+1)}{2(z-1)^2}$$

代入 $T=0.25$，$T^2=0.0625$：

$$G(z) = \frac{0.0625K(z+1)}{2(z-1)^2} = \frac{0.03125K(z+1)}{(z-1)^2}$$

> **注**：此处受控对象具体形式依据原题结构图确定。从原题给出的结果 $v=1$ 和 $K_v = KT$ 反推，开环传递函数实际为：
>
> $$G(z) = \frac{KT}{z-1} = \frac{0.25K}{z-1}$$
>
> 以下按此结果继续计算。

**第 2 步**：确定系统型别。

$G(z) = \dfrac{0.25K}{z-1}$ 在 $z=1$ 处有一个极点，$v=1$（**I 型系统**）。

**第 3 步**：计算静态速度误差系数 $K_v$。

$$K_v = \lim_{z \to 1}(z-1) \cdot G(z) = \lim_{z \to 1}(z-1) \cdot \frac{0.25K}{z-1} = 0.25K = KT$$

**第 4 步**：分解输入信号，分别计算稳态误差。

$r(t) = 2 \cdot 1(t) + t$ 可分解为：

- **阶跃分量**：$r_1(t) = 2 \cdot 1(t)$，$A_1 = 2$
  - I 型系统：$K_p = \infty \implies e_1(\infty) = \dfrac{A_1}{1+K_p} = 0$

- **斜坡分量**：$r_2(t) = t$，$A_2 = 1$
  - I 型系统：$e_2(\infty) = \dfrac{A_2 T}{K_v} = \dfrac{1 \times 0.25}{0.25K} = \dfrac{1}{K}$

**第 5 步**：叠加求总稳态误差。

$$e(\infty) = e_1(\infty) + e_2(\infty) = 0 + \frac{1}{K} = \frac{1}{K}$$

**第 6 步**：建立稳态误差不等式。

$$e(\infty) < 0.5 \implies \frac{1}{K} < 0.5 \implies K > 2$$

**第 7 步**：与稳定范围取交集。

- 稳定范围（已知）：$0 < K < 2.472$
- 稳态误差范围：$K > 2$

取交集：

$$\boxed{2 < K < 2.472}$$

**答案**：使 $e(\infty) < 0.5$ 的 $K$ 值范围为 $2 < K < 2.472$。

**验证**：
- 取 $K = 2.2$（在范围内）：$e(\infty) = 1/2.2 \approx 0.455 < 0.5$ ✓；稳定 ✓
- 取 $K = 1.5$（不在范围内）：$e(\infty) = 1/1.5 \approx 0.667 > 0.5$ ✗
- 取 $K = 2.5$（不在范围内）：$e(\infty) = 1/2.5 = 0.4 < 0.5$ ✓，但 $K > 2.472$ 系统不稳定 ✗

## 补充：动态性能与闭环极点的关系（Page 11–16 复习要点）

> 此部分虽不在 Page 21–30 范围内，但作为本章性能分析的完整知识体系，在此补充总结。

### 1. 实轴上的单闭环极点

闭环传递函数部分分式展开后，实轴上的单极点 $p_k$ 对应的时域响应分量为：

$$c_k(nT) = c_k \cdot p_k^n$$

| 极点位置 | 响应特性 |
|:---|:---|
| $0 < p_k < 1$ | 正指数衰减，单调趋于零 |
| $p_k = 1$ | 等幅（常数），系统临界稳定 |
| $p_k > 1$ | 正指数增长，发散 |
| $-1 < p_k < 0$ | 正负交替衰减振荡 |
| $p_k = -1$ | 等幅交替振荡 |
| $p_k < -1$ | 正负交替发散 |

### 2. 共轭复数闭环极点

共轭复数极点 $p_k = |p_k|e^{j\theta_k}$ 和 $p_k^* = |p_k|e^{-j\theta_k}$ 对应的时域响应分量为：

$$c_k(nT) = 2|c_k| \cdot |p_k|^n \cdot \cos(n\theta_k + \varphi_k)$$

其中 $|c_k|$ 和 $\varphi_k$ 由部分分式展开系数确定，$|p_k|$ 为极点模值，$\theta_k$ 为极点辐角。

- **衰减率**：由 $|p_k|$ 决定。$|p_k| < 1$ 时衰减振荡；$|p_k| = 1$ 时等幅振荡；$|p_k| > 1$ 时发散振荡。
- **振荡频率**：由 $\theta_k$ 决定，$\omega_k = \theta_k / T$。$\theta_k$ 越大振荡越快。

### 3. 采样器和 ZOH 对动态性能的影响

- **采样器**：减小峰值时间 $t_p$ 和调节时间 $t_s$，但增大超调量 $\sigma\%$。
- **零阶保持器（ZOH）**：增大 $t_p$、$t_s$ 和 $\sigma\%$，并增加振荡次数。
