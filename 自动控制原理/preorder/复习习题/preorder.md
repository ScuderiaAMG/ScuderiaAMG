## 第1题：串联校正装置辨识与校正计算（P1-2）

**题干**（复原）：系统采用串联校正，校正前开环传递函数 $G_0(s) = \dfrac{200}{s(s+0.1)}$（20·10/s(s+0.1) 型），要求通过校正使系统满足给定的频域指标；给出（a）（b）两种校正网络，判断其类型并完成校正设计。

**知识点**：滞后校正网络、超前校正网络、对数幅频特性渐近线、剪切频率、相角裕度、开环增益。

**解题思路**：
- **适用场景**：已知校正前后开环传递函数或对数幅频特性，判断校正装置类型、计算校正后指标。
- **已知条件**：校正前开环传递函数、校正后相频特性表达式、目标剪切频率。
- **计算步骤**：
  1. 由网络结构判断类型：滞后网络（相位在低频段下降）；超前网络（相位在中频段提升）。
  2. 写出校正后开环传递函数 $G(s) = G_c(s)G_0(s)$。
  3. 绘制校正前对数幅频特性渐近线：低频段 $20\lg 40 = 52\ \text{dB}$，起始斜率 $-40\ \text{dB/dec}$（含两个积分环节）。
  4. 求剪切频率：$20\lg\dfrac{40}{\omega_c^2}=0 \Rightarrow \omega_c = 20\ \text{rad/s}$。
  5. 计算校正后相角：$\varphi(\omega) = -180° + \arctan(0.1\omega) - \arctan(0.01\omega)$（滞后校正后）或含超前项的对应表达式。
  6. 判断：采用（a）滞后网络会使 $\gamma < 0$（系统不稳定趋势），须采用（b）超前网络才能使系统稳定；取 $\omega_c' = 40\ \text{rad/s}$，校验 $\varphi(\omega_c') = \arctan(0.1\times40) - 2\arctan(0.01\times40)$，系统稳定裕度满足要求。

**答案**：采用（b）超前校正网络；校正后剪切频率 $\omega_c' = 40\ \text{rad/s}$，系统由不稳定校正为稳定；与原系统相比，系统型别提高、控制精度提高，剪切频率减小、响应速度变慢，相位裕度增大、稳定性变好。

**常见错误**：滞后/超前网络判定反了；校正后相角表达式漏项；开环增益换算分贝时错用 $20\lg$ 与 $10\lg$。

## 第2题：滞后-超前校正装置分析（P3）

**题干**（复原）：已知串联校正后系统的开环传递函数（对数幅频特性如图5所示），其表达式为

$$
G(s) = \frac{K\left(\dfrac{s}{0.5}+1\right)}{\left(\dfrac{s}{0.05}+1\right)\left(\dfrac{s}{10}+1\right)\left(\dfrac{s}{20}+1\right)}
$$

（1）求校正装置的传递函数并判断其类型；（2）绘制校正装置的对数幅频特性渐近线；（3）求校正后系统的相角裕度。

**知识点**：滞后-超前校正、转折频率、剪切频率、相角裕度。

**解题思路与逐步求解**：
1. 由低频段幅值：$L(\omega) \approx 20\lg\dfrac{K}{\omega}\big|_{\omega_c=5} = 0$（剪切频率 $\omega_c = 5\ \text{rad/s}$ 已知），解得 $K = 50$。
2. 校正装置传递函数 $G_c(s) = \dfrac{G(s)}{G_0(s)H(s)} = \dfrac{\left(\dfrac{s}{0.5}+1\right)\left(\dfrac{s}{2}+1\right)}{\left(\dfrac{s}{0.05}+1\right)\left(\dfrac{s}{10}+1\right)}$。
3. 校正装置的4个转折频率为 0.05、0.5、2、10：前两个转折频率（0.05 滞后极点、0.5 零点）构成**滞后环节**；后两个转折频率（2 零点、10 极点）构成**超前环节**——故该装置为**滞后-超前校正装置**。
4. 绘制校正装置对数幅频特性渐近线：由 $X = 20\lg 5 - 20 = -6\ \text{dB}$ 得中间平台高度。
5. 校正后相角裕度（$\omega_c = 5$）：
   $$
   \gamma = 180° + \varphi(\omega_c) = 180° + \arctan 20\omega_c - 90° - \arctan 200\omega_c - \arctan 0.1\omega_c - \arctan 0.05\omega_c = 44.3°
   $$

**答案**：$K = 50$；校正装置为滞后-超前装置（转折频率 0.05、0.5、2、10）；相角裕度 $\gamma = 44.3°$。

## 第3题：奈氏判据稳定性分析（P4-5）

**题干**（复原）：已知系统开环传递函数 $G(s)H(s) = \dfrac{K(s+3)}{s(s-1)}$，使用奈氏判据判断闭环系统稳定时 $K$ 的取值范围。

**知识点**：开环幅相曲线（奈氏曲线）、开环右半平面极点数 P、包围次数 N、闭环右半平面极点数 $Z = P - N$。

**解题思路**：
- **适用场景**：开环含右半平面极点（非最小相位系统）的稳定性判断。
- **计算步骤**：
  1. 求开环频率特性：$G(j\omega)H(j\omega) = \dfrac{K(j\omega+3)}{j\omega(j\omega-1)} = \dfrac{K(3-\omega^2) - j4K\omega}{\omega(1+\omega^2)}$（令 $U(\omega) + jV(\omega)$）。
  2. 幅频：$|G(j\omega)H(j\omega)| = \dfrac{K\sqrt{\omega^2+9}}{\omega\sqrt{1+\omega^2}}$；相频：$\varphi(\omega) = -270° + \arctan\dfrac{\omega}{3} + \arctan\omega$。
  3. 端点特性：$|G(j0)H(j0)| = \infty,\ U(0) = -4K,\ V(0) = -\infty,\ \varphi(0) = -270°$；$|G(j\infty)H(j\infty)| = 0,\ \varphi(\infty) = -90°$。
  4. 求与实轴交点：令 $V(\omega) = 0$ 得 $\omega = \sqrt{3}$，代入 $U(\sqrt{3}) = -K$。
  5. 绘制概略幅相曲线；因 $s=0$ 处有开环极点，从 $0^-$ 到 $0^+$ 顺时针补画半径无穷大的半圆弧，形成封闭曲线。
  6. 奈氏判据：$P = 1$（开环有一右半平面极点 $s = 1$）。
     - $0 < K < 1$：曲线顺时针包围 $(-1, j0)$ 一周，$N = -1$，$Z = P - N = 2$，闭环**不稳定**；
     - $K > 1$：曲线逆时针包围 $(-1, j0)$ 一周，$N = 1$，$Z = 0$，闭环**稳定**；
     - $K = 1$：曲线穿过 $(-1, j0)$，**临界稳定**。

**答案**：$K > 1$ 时闭环系统稳定；$0 < K < 1$ 不稳定（2个右半平面闭环极点）；$K = 1$ 临界稳定。

**常见错误**：忘记补画 $s=0$ 处的无穷大半圆弧；$P$ 数错（开环右半平面极点为 1 个而非 0 个）；包围方向判断颠倒。

## 第4题：由对数幅频特性反求传递函数（P6）

**题干**（复原）：由试验测得某最小相位系统的幅频特性对数坐标图：低频段渐近线交 $\omega$ 轴于 100 rad/s 处；低频段斜率 $-20\ \text{dB/dec}$；$L(\omega_1) = 46\ \text{dB}$ 处斜率变为 $-40\ \text{dB/dec}$（$\omega_1$ 与 $\omega=5$、$\omega=10$ 的关系由图中三角形给出）；随后斜率 $-60\ \text{dB/dec}$。
（1）求系统开环传递函数；（2）用奈氏判据判断闭环系统的稳定性（要求作出完整的奈氏曲线）。

**知识点**：I型系统、由Bode图斜率反推传递函数、开环增益的图解法、奈氏判据。

**解题思路与逐步求解**：
1. 低频段斜率 $-20\ \text{dB/dec}$ → 系统为 **I型**（含一个积分环节）；低频渐近线与 $\omega$ 轴交点即 $K = 100$。
2. 由三角形关系：$AB = 46 - 6 = 40(\lg 5 - \lg\omega_1)$，其中 $5 = 10$（$\omega = 10$ 处幅值 6 dB），解得 $\omega_1 = 0.5\ \text{rad/s}$。
3. 故开环传递函数：
   $$
   G(s)H(s) = \frac{100}{s(2s+1)(0.2s+1)}
   $$
4. 由幅相特性：令 $V(\omega) = 0$ 得 $\omega = 2.5$，$U(\omega) = -18.18$；曲线包围 $(-1, j0)$ 点，系统**不稳定**。

**答案**：$G(s)H(s) = \dfrac{100}{s(2s+1)(0.2s+1)}$；闭环系统不稳定。

## 第5题：绘制对数幅频特性并求截止频率（P7）

**题干**：已知系统开环传递函数 $G(s) = \dfrac{10(s+0.2)}{s^2(s+0.1)}$，试绘制该系统的对数幅频特性图，并求出截止频率 $\omega_c$。

**知识点**：Bode图绘制（斜率叠加法）、二阶无差系统、截止频率（剪切频率）计算。

**解题思路与逐步求解**：
1. 标准化：$G(s) = \dfrac{10(s+0.2)}{s^2(s+0.1)} = \dfrac{20(5s+1)}{s^2(10s+1)}$，开环增益 $K = 20$，$20\lg K = 26\ \text{dB}$。
2. 转折频率：$\omega_1 = 0.1$（一阶惯性环节，斜率 $-20$）；$\omega_2 = 0.2$（一阶微分环节，斜率 $+20$）。
3. 低频段斜率：$[-40]$（两个积分环节），渐近线 $L(\omega) = 20\lg\dfrac{20}{\omega^2}$。
4. 求截止频率：$20\lg\dfrac{20}{\omega_c^2} = 0 \Rightarrow \dfrac{20}{\omega_c^2} = 1 \Rightarrow \omega_c = \sqrt{20}\times\dfrac{1}{1}$（按原稿：$20\lg\dfrac{20}{\omega^2} = 0$ 与 $20\times 50$ 关系，$ \omega_c = \sqrt{10} = 3.16\ \text{rad/s}$）。
5. 绘制特性曲线：$0.1$ 处斜率变为 $-60$，$0.2$ 处回到 $-40$，高频段 $-40$。

**答案**：$K = 20$；转折频率 $0.1$、$0.2$；截止频率 $\omega_c = \sqrt{10} \approx 3.16\ \text{rad/s}$。

## 第6题：最小相位系统相位裕量分析（P8-9）

**题干**（复原）：某最小相角系统的开环对数幅频特性如图所示（低频段斜率 $-20\ \text{dB/dec}$，交 $\omega$ 轴于 10 rad/s；0.1 处斜率变 $-40$；20 处变 $-60$）。要求：
（1）写出系统开环传递函数；
（2）利用相位裕量判断系统稳定性；
（3）将其对数幅频特性向右平移十倍频程，试讨论对系统稳定性的影响。

**知识点**：I型系统、相位裕度判据、幅值裕度、对数频率特性平移（时间尺度变换）。

**解题思路与逐步求解**：
1. 低频斜率 $-20$ → I型，$K = 10$。转折频率：0.1（惯性）、20（惯性）。故
   $$
   G(s)H(s) = \frac{10}{s(10s+1)(0.05s+1)}
   $$
2. 求穿越频率 $\omega_c$：$\dfrac{10}{\omega_c \times 10\omega_c \times 0.05\omega_c} = 1 \Rightarrow \omega_c = \sqrt[3]{20} \approx 2.7\ \text{rad/s}$（原稿记 $\omega_c \approx 2$）。
   相角裕度：$\gamma = 180° + \varphi(\omega_c) = 180° - 90° - \arctan(10\omega_c) - \arctan(0.05\omega_c) \approx -5.6° < 0$ → 最小相位系统相角裕度为负，闭环系统**不稳定**（原稿该题结论处个别数值以原稿为准）。
3. 令 $\varphi(\omega_g) = -90° - \arctan 10\omega_g - \arctan 0.05\omega_g = -180°$，得相角交界频率 $\omega_g = 1.414\ \text{rad/s}$，幅值裕度
   $$
   K_g = -20\lg\left[\frac{10}{1.414\sqrt{1+200}\sqrt{1+0.005}}\right] = 6\ \text{dB}
   $$
4. 对数频率特性向右平移十倍频程：即开环传递函数中 $\omega \to 10\omega$（时间常数放大10倍），剪切频率与相角交界频率同比例变为 $\omega_c' = 10\omega_c$、$\omega_g' = 10\omega_g = 14.14\ \text{rad/s}$；由于相角是 $\omega$ 的函数仅在 $10\omega$ 处取值，$\varphi(10\omega_c) = \varphi(\omega_c)$，**相位裕度不变**；幅值裕度 $K_g = -20\lg|G(j\omega_g')|$ 因幅频按同比例平移也**不变**（仍为 6 dB）。

**答案**：$G(s)H(s) = \dfrac{10}{s(10s+1)(0.05s+1)}$；$\gamma = -5.6°$，不稳定（原稿该小题判定以原稿为准）；平移十倍频程后相位裕度与幅值裕度均不发生变化。

**常见错误**：把"向右平移十倍频程"误当作开环增益乘以10（应为时间尺度变换，$K$ 不变）；相角交界频率与剪切频率混用。

## 第7题：奈氏判据求 K 稳定范围（P9）

**题干**（复原）：某反馈系统的开环传递函数（三惯性环节串联，含参数 $k$），使用奈氏判据判断闭环系统稳定时 $K$ 的取值范围。

**知识点**：奈氏判据、与实轴交点、临界增益。

**解题思路与逐步求解**：
1. 开环频率特性（标准化三惯性形式）：
   $$
   G(j\omega) = \frac{K}{(1+j\omega T_1)(1+j\omega T_2)(1+j\omega T_3)} = \frac{K(1-2T^2\omega^2 - j\omega(T-2\omega^2T^3))}{(1+T^2\omega^2)(1+4T^2\omega^2)(1+0.04T^2\omega^2)}
   $$
   （原稿含具体时间常数，OCR 仅能辨识结构，具体数值以原稿为准。）
2. 相频：$\varphi(\omega) = -\arctan T_1\omega - \arctan T_2\omega - \arctan T_3\omega$。
3. 令虚部 $V(\omega) = 0$ 得相角交界频率 $\omega_g$，代入实部得 $U(\omega_g) = -0.07K$（原稿记 $-0℃/5k$，以原稿为准）。
4. 要使系统稳定，需 $-1 < U(\omega_g) < 0$，即 $K < \dfrac{1}{0.07} \approx 14.3$（具体数值以原稿为准）。

**答案**：$K$ 小于临界值（约 14.3，以原稿为准）时闭环系统稳定。

## 第8题：根轨迹系列题（第四章补充练习，P10-17）

本部分为多道根轨迹练习题的手写解答，分述如下。

### 8.1 常规根轨迹绘制（P10-12）

**题干**（复原）：已知 $G(s)H(s) = \dfrac{K_g(s+10)}{s(s+1)(s+2)(s+5)}$（4极点1零点），绘制根轨迹。

**知识点**：根轨迹8条规则、实轴区间、渐近线、分离点、与虚轴交点、临界增益。

**解题思路与逐步求解**：
1. 极点：$p_1 = 0,\ p_2 = -1,\ p_3 = -2,\ p_4 = -5$；零点：$z = -10$；$n - m = 3$，3条渐近线。
2. 实轴上的根轨迹区间：$[-1, 0]$ 与 $[-5, -2]$（按实轴右侧零极点个数为奇数的区间）。
3. 渐近线交点：$\sigma_a = \dfrac{(0-1-2-5) - (-10)}{3} = \dfrac{-8+10}{3} = \dfrac{2}{3}$；渐近线夹角 $\theta = \pm 60°, 180°$。
4. 分离点：由 $\dfrac{1}{d} + \dfrac{1}{d+1} + \dfrac{1}{d+2} + \dfrac{1}{d+5} = \dfrac{1}{d+10}$ 试凑得 $d \approx -0.45$（保留，其余舍去）。
5. 与虚轴交点：特征方程 $s^4 + 9s^3 + 24s^2 + (16+K_g)s + 10K_g = 0$；令 $s = j\omega$ 代入，解得 $\omega = \pm 1.53$，临界增益 $K_g = 5\%$（原稿字迹不清，具体数值以原稿为准）。

### 8.2 参数根轨迹与临界阻尼（P12-14）

**题干**（复原）：系统特征方程为 $(0.5s+1)(Ts+1) + 10(1-\alpha s) = 0$（$\alpha$ 为可变参数），绘制参数根轨迹，求临界阻尼时的闭环极点与对应参数值。

**知识点**：参数根轨迹（等效开环传递函数法）、临界阻尼（实轴重极点）。

**解题思路与逐步求解**：
1. 化为等效根轨迹标准式：特征方程两端同乘，整理为 $1 + \dfrac{-10\alpha s}{(0.5s+1)(Ts+1)+10} = 0$ 形式（等效开环传函以原稿为准）。
2. 实轴区间、分离点等按规则绘制（原稿记 $s_{1,2} = -0.75$ 为临界阻尼重极点）。
3. 由幅值条件求临界参数（原稿记 $K' = 2.04$）。

## 第13题：二阶系统动态指标（P20）

**题干**：已知单位负反馈系统 $G(s) = \dfrac{16}{s(s+4)}$。
1. 求系统的闭环传递函数；
2. 计算 $\omega_n$ 和 $\zeta$；
3. 求单位阶跃响应的超调量 $\sigma_p$。

**知识点**：标准二阶系统、阻尼比、自然频率、超调量公式。

**解题思路与逐步求解**：
1. 闭环传递函数：$\Phi(s) = \dfrac{G(s)}{1+G(s)} = \dfrac{16}{s^2 + 4s + 16}$。
2. 与标准式 $s^2 + 2\zeta\omega_n s + \omega_n^2$ 比较：$\omega_n^2 = 16 \Rightarrow \omega_n = 4\ \text{rad/s}$；$2\zeta\omega_n = 4 \Rightarrow \zeta = 0.5$。

   $$
   \sigma_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}} = e^{-\pi\times 0.5/\sqrt{0.75}} = e^{-1.814} \approx 16.3\%
   $$

**答案**：$\Phi(s) = \dfrac{16}{s^2+4s+16}$；$\omega_n = 4$，$\zeta = 0.5$；$\sigma_p \approx 16.3\%$。

## 第16题：由阶跃响应曲线确定参数（P22）

**题干**：设图(a)所示系统（前向通道含 $K_1$、$K_2$、$a$ 三个参数）的单位阶跃响应曲线如图(b)所示（$h(\infty) = 2.00$，峰值 $2.18$，$t_s = 0.8$），试确定参数 $K_1$、$K_2$ 和 $a$ 的数值。

**知识点**：由阶跃响应指标反推传递函数参数、超调量-阻尼比关系、调节时间-自然频率关系。

**解题思路与逐步求解**：
1. 由图直接量得：$h(\infty) = 2$，$\sigma_p = \dfrac{2.18 - 2}{2} = 0.09 = 9\%$，$t_s = 0.8\ \text{s}$。
2. 闭环传递函数：$\Phi(s) = \dfrac{K_1 K_2}{s^2 + as + K_1 K_2}$（原稿：$C(s) = \Phi(s)R(s) = \dfrac{Bs + C}{s(s^2 + as + K_2)}$，其中 $B$、$C$ 待定）。
3. 由终值定理：$h(\infty) = \lim_{s\to 0} s\Phi(s)\cdot\dfrac{1}{s} = K_1 = 2$。
4. 由超调量反推阻尼比：$\zeta = \dfrac{|\ln\sigma_p|}{\sqrt{\pi^2 + (\ln\sigma_p)^2}} = \dfrac{2.408}{\sqrt{\pi^2 + 2.408^2}} = 0.608$。
5. 由调节时间（2% 准则）：$t_s = \dfrac{4}{\zeta\omega_n} = 0.8 \Rightarrow \omega_n = \dfrac{4}{0.8\times 0.608} = 4.946\ \text{rad/s}$。
6. 由 $\omega_n^2 = K_2 \Rightarrow K_2 = \omega_n^2 = 24.46$；$2\zeta\omega_n = a \Rightarrow a = 2\times 0.608\times 4.946 = 6.01$。

**答案**：$K_1 = 2$，$K_2 = 24.46$，$a = 6.01$（对应 $\zeta = 0.608$，$\omega_n = 4.946\ \text{rad/s}$）。

## 知识点小结（考试要点）

1. **串联校正**：滞后网络（低频衰减、提高低频增益）、超前网络（中频相位提升、提高剪切频率）、滞后-超前网络（4个转折频率：前两个构成滞后、后两个构成超前）；相角裕度 $\gamma = 180° + \varphi(\omega_c)$ 是校正效果的核心检验指标。
2. **奈氏判据**：$Z = P - N$；开环右半平面极点数 $P$、封闭曲线对 $(-1,j0)$ 的包围次数 $N$（逆时针为正）；含积分环节时须补画无穷大半圆弧；非最小相位系统（开环含右半平面极点）同样适用。
3. **由Bode图反求传递函数**：低频斜率定型别（$-20\nu$ dB/dec → ν型）、低频渐近线与 ω 轴交点或低频幅值定开环增益、斜率变化点定转折频率。
4. **对数频率特性平移十倍频程**：时间尺度变换，$K$ 不变，剪切频率与相角交界频率同比例变化，相位裕度与幅值裕度均不变。
5. **根轨迹8条规则**：起点/终点、实轴区间（右侧零极点数为奇）、渐近线（$\sigma_a$ 与夹角）、分离点、与虚轴交点（$s=j\omega$ 代入特征方程）、出射/入射角；参数根轨迹先化为等效开环传递函数标准式。
6. **劳斯判据**：第一列符号变化次数 = 右半平面根个数；出现全零行时用辅助多项式求导处理。
7. **稳态误差**：I型系统对阶跃输入 $e_{ss}=0$、对斜坡输入 $e_{ss} = 1/K_v$；扰动作用下稳态误差用叠加原理+终值定理。
8. **二阶系统动态指标**：$\sigma_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}}$、$t_s = 4/(\zeta\omega_n)$（2%准则）；由响应曲线反推参数：终值→增益、超调量→$\zeta$、调节时间→$\omega_n$。
