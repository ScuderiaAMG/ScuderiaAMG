## 一、稳定性的概念

### 1.1 稳定性实验

| 物体 | 初始 | 施加外力后 | 撤去外力后 | 结论 |
|------|------|------------|------------|------|
| 水杯 | 平衡直立 | 重心偏移 | **重心恢复** → 回原位 | 稳定 |
| 油笔 | 平衡直立 | 重心偏移 | **重心倒下** → 不回原位 | 不稳定 |

### 1.2 稳定性的定义（三种状态）

系统受到扰动偏离了平衡状态，当撤销扰动后：

| 状态 | 定义 |
|------|------|
| **稳定** | 系统能够重新恢复到原始平衡状态 |
| **不稳定** | 扰动消失后不能恢复原始平衡状态，偏差越来越大 |
| **临界稳定** | 扰动消失后，系统输出与原始平衡状态间存在恒定的偏差，或输出维持等幅振荡（不能恢复到原始状态，但也不发散） |

### 1.3 数学描述方式

**关键设定**：
- 以原始平衡状态为基准，设平衡点为原点（设为 0）
- 用**单位脉冲信号** $\delta(t)$ 模拟扰动
- 单位脉冲信号：$r(t) = \begin{cases} \infty, & t = 0 \\ 0, & t \neq 0 \end{cases},\ \int_{-\infty}^{\infty} r(t) dt = 1$

```
r(t) = δ(t) → [ 系统 G(s) ] → c(t)
```

## 二、稳定性的判据

### 2.1 判别方法一：时域判据

设系统初始条件为零，输入一个理想的单位脉冲函数 $\delta(t)$：
$$\text{若 } \lim_{t \to \infty} c(t) = 0 \text{，则该系统是稳定的。}$$

**例2.1**：已知系统的微分方程 $T\dot{c}(t) + c(t) = r(t)$，判断稳定性。

解：零初始条件下拉氏变换：$TsC(s) + C(s) = R(s)$

若 $r(t) = \delta(t)$，则 $R(s) = 1$，$C(s) = \frac{1}{Ts + 1} = \frac{1}{T} \cdot \frac{1}{s + 1/T}$

$$c(t) = \frac{1}{T} e^{-t/T},\quad \lim_{t \to \infty} c(t) = 0$$

**该系统是稳定的。**

但此方法对高阶系统较繁琐，需用更简洁的判据。

---

### 2.2 判别方法二：S 域判据（重点）

设系统的传递函数为：

$$G(s) = \frac{C(s)}{R(s)} = \frac{b_m s^m + \cdots + b_0}{a_n s^n + \cdots + a_0} = K \frac{\prod_{i=1}^{m}(s - z_i)}{\prod_{j=1}^{n}(s - p_j)}$$

输入 $r(t) = \delta(t)$ 时，$R(s) = 1$，则输出：

$$C(s) = G(s)R(s) = G(s)$$

拉氏反变换（设系统有 $k$ 个实极点和 $r$ 对共轭复极点）：

$$c(t) = \sum_{i=1}^{k} A_i e^{p_i t} + \sum_{j=1}^{r} e^{\sigma_j t} \left[B_j \cos(\omega_j t) + C_j \sin(\omega_j t)\right]$$

---

### 2.3 S 域稳定性判据总结

传递函数 **所有极点均位于 S 平面的左半平面** 时系统稳定。

| 极点位置 | 时域响应 | 系统状态 |
|----------|----------|----------|
| 所有 $p_i < 0$ 且 $\sigma_j < 0$（左半平面） | $\lim_{t \to \infty} c(t) = 0$；负实数极点→指数衰减；共轭复极点（负实部）→衰减振荡 | **稳定** |
| 存在 $p_i > 0$ 或 $\sigma_j > 0$（右半平面） | $t \to \infty$ 时偏差越来越大 | **不稳定** |
| 存在 $p_i = 0$（零根）或 $\sigma_j = 0$（纯虚根），其余在左半平面 | 常值（零根）或等幅振荡（纯虚根） | **临界稳定** |

```
     Im                          Im                          Im
     │      ╳                    │      ╳                    │   ╳
  ╳  │   ╳                     │                           │
─────┼───── Re    稳定      ─────┼───── Re   不稳定      ──╳──┼───── Re  临界稳定
     │                          │      ╳                    │
  ╳  │   ╳                  ╳  │   ╳                       │   ╳
     │                          │                           │
  (全部在左半平面)            (存在右半平面极点)           (零根或纯虚根对)
```

> **核心结论**：线性定常系统稳定的**充要条件**是：传递函数的**所有极点**都具有**负实部**（均在 S 平面左半部分）。

## 三、案例：车辆侧翻稳定性分析

### 3.1 问题背景

约 75% 的车辆侧翻事故与皮卡、货车、SUV 类型车辆有关。这些车辆为什么更容易失稳？

### 3.2 车辆悬架模型

```
                     ms·ay
                      ↓
                  ┌───●───┐
                  │   ms  │ ← 簧上质量
                  │       │
        Y₁ ←─────┤   h   ├─────→ Y₂
        Z₁       │   ●   │       Z₂
                  │  mg   │
                  └───┬───┘
                   Ls/2  Ls/2
                  ← Ls →  (悬架宽度)
```

**转矩平衡方程**：

$$J_x \ddot{\phi} = M_a + M_g - M_r$$

| 转矩 | 公式 | 物理含义 |
|------|------|----------|
| 离心力矩 $M_a$ | $M_a = m_s h a_y$ | 车辆转弯时离心力造成的力矩 |
| 重力矩 $M_g$ | $M_g = m_s g h \sin\phi$ | 重力产生的恢复力矩 |
| 悬架回正力矩 $M_r$ | $M_r = \frac{1}{2}L_s^2 K_\phi \phi + C_\phi \dot{\phi}$ | 悬架弹簧和阻尼产生的回正力矩 |

**系统变量表**：

| 符号 | 含义 |
|------|------|
| $J_x$ | $x$ 轴转动惯量 |
| $m_s$ | 簧上质量（车身 + 载重） |
| $h$ | 连杆长度（重心高度） |
| $\phi$ | 倾斜角（输出） |
| $a_y$ | 离心力加速度（输入/扰动） |
| $C_\phi$ | 连杆阻尼系数 |
| $K_\phi$ | 连杆弹簧系数 |
| $L_s$ | 车身悬架宽度 |

### 3.3 传递函数

线性化后（$\sin\phi \approx \phi$），从离心加速度到倾斜角的传递函数：

$$\frac{\phi(s)}{a_y(s)} = \frac{m_s h}{J_x s^2 + \frac{1}{2}L_s^2 C_\phi s + \left(\frac{1}{2}L_s^2 K_\phi - m_s g h\right)}$$

### 3.4 稳定性条件

单位脉冲响应：

$$\phi(t) = \frac{m_s h}{J_x} \left[a_1 e^{p_1 t} + b_1 e^{p_2 t}\right]$$

其中极点为：

$$p_{1,2} = \frac{-\frac{1}{2}L_s^2 C_\phi \pm \sqrt{\frac{1}{4}L_s^4 C_\phi^2 - 4J_x\left(\frac{1}{2}L_s^2 K_\phi - m_s g h\right)}}{2J_x}$$

**稳定性条件**：

$$\frac{1}{2}L_s^2 K_\phi - m_s g h > 0$$

即：

$$\boxed{m_s g h < \frac{1}{2}L_s^2 K_\phi}$$

### 3.5 影响车辆失稳的因素

| 因素 | 符号 | 影响方向 | 工程解释 |
|------|------|----------|----------|
| 悬架宽度 | $L_s$ | $\uparrow L_s$ → 更稳定 | 宽轮距车辆不易侧翻 |
| 弹簧刚度 | $K_\phi$ | $\uparrow K_\phi$ → 更稳定 | 硬悬架抗侧倾能力更强 |
| 簧上质量（载重） | $m_s$ | $\uparrow m_s$ → 不稳定 | 超载车辆更容易侧翻 |
| 重心高度 | $h$ | $\uparrow h$ → 不稳定 | 高重心车辆（SUV、货车）风险更大 |

> **结论**：皮卡、货车、SUV 容易侧翻的原因是——**重心高（$h$ 大）** 且 **载重大（$m_s$ 大）**，使得 $\frac{1}{2}L_s^2 K_\phi - m_s g h$ 减小甚至变负，系统趋于不稳定。

## 四、回顾：PD控制改进轮式机器人平衡

### 4.1 被控对象

$$J\frac{d^2\theta(t)}{dt^2} = \frac{1}{2}mgh \sin\theta(t) + \tau \quad \xrightarrow{\text{线性化}} \quad J\frac{d^2\theta(t)}{dt^2} = \frac{1}{2}mgh \cdot \theta(t) + \tau$$

被控对象传递函数（从 $\tau$ 到 $\theta$）：

$$G_p(s) = \frac{\theta(s)}{\tau(s)} = \frac{1}{Js^2 - \frac{1}{2}mgh}$$

> 被控对象本身是不稳定的（分母 $Js^2 - \frac{1}{2}mgh$ 有一正一负两个实根）。

### 4.2 比例控制（P控制）——上一讲方案

$$\tau = -k\theta$$

闭环传递函数：

$$G(s) = \frac{\theta(s)}{R(s)} = \frac{k}{Js^2 + k - \frac{1}{2}mgh}$$

令 $\alpha = k - \frac{1}{2}mgh$：
- $\alpha > 0$：纯虚根 → **等幅振荡**（临界稳定）
- $\alpha < 0$：一正一负实根 → **发散**（不稳定）

### 4.3 PD控制——改进方案

引入角速度反馈：$\tau = -k\theta - k_1 \dot{\theta}$（比例-微分控制）

结构图：

```
R(s) → [k] → [+] → [G_p(s)] → θ(s)
         ↑      |
         [k₁s] ←┘
```

闭环传递函数（三阶系统）：

$$G(s) = \frac{\theta(s)}{R(s)} = \frac{k(s + 1 + a/k)}{Js^3 + Js^2 + ks - \frac{1}{2}mgh \cdot s + k + a - \frac{1}{2}mgh}$$

PD 控制引入阻尼项，使系统特征方程含有一次项，有可能使全部极点移至左半平面，实现衰减振荡稳定。

## 六、解题通法总结

### 6.1 稳定性判别通法（三步法）

| 步骤 | 操作 |
|------|------|
| ① | 求系统的传递函数 $G(s) = M(s)/N(s)$（或闭环传递函数） |
| ② | 求解特征方程 $N(s) = 0$ 的所有根（极点） |
| ③ | 根据极点位置判断：全部负实部 → 稳定；存在正实部 → 不稳定；纯虚根/零根且其余负实部 → 临界稳定 |

### 6.2 一阶/二阶系统稳定性快速判别

| 系统阶数 | 特征方程 | 稳定条件 |
|----------|----------|----------|
| 一阶系统 | $a_1 s + a_0 = 0$ | $a_1 > 0,\ a_0 > 0$（极点 $p = -a_0/a_1 < 0$） |
| 二阶系统 | $a_2 s^2 + a_1 s + a_0 = 0$ | $a_2, a_1, a_0$ **同号**（全部 $>0$ 或全部 $<0$） |

**二阶系统详细判别**：

设特征方程 $s^2 + 2\zeta\omega_n s + \omega_n^2 = 0$（首一多项式）：

| 条件 | 极点分布 | 稳定性 |
|------|----------|--------|
| $\zeta > 0,\ \omega_n > 0$ | 负实根或负实部共轭复根 | **稳定**（衰减） |
| $\zeta = 0$ | 纯虚根 $\pm j\omega_n$ | **临界稳定**（等幅振荡） |
| $\zeta < 0$ | 正实部共轭复根 | **不稳定**（渐扩振荡） |
| $\omega_n^2 < 0$ | 一正一负实根 | **不稳定**（发散） |

### 6.3 稳定性与传递函数各形式中参数的对应关系

| 传递函数形式 | 稳定条件 |
|--------------|----------|
| 有理分式 $G(s) = \frac{M(s)}{N(s)}$ | $N(s) = 0$ 的根全部在左半平面 |
| 零极点形式 $G(s) = k^* \frac{\prod(s - z_i)}{\prod(s - p_j)}$ | 所有 $p_j$ 的实部 $< 0$ |
| 时间常数形式 $G(s) = K \frac{\cdots}{\cdots}$ | 所有时间常数 $T_j > 0$ |

### 6.4 车辆侧翻类实际问题的分析框架

```
① 分析物理过程（力/力矩平衡）
    ↓
② 建立微分方程（非线性）
    ↓
③ 在工作点线性化（小偏差法）
    ↓
④ 拉氏变换 → 传递函数
    ↓
⑤ 求解特征方程 → 判定稳定性
    ↓
⑥ 提取稳定性条件（不等式）
    ↓
⑦ 分析各参数对稳定性的影响 → 工程建议
```
