# 第2讲：控制系统的微分方程模型

---

## 一、控制系统的微分方程

### 1.1 数学模型概述

**数学模型**：描述系统（或环节）的输出变量与输入变量（或内部变量）之间关系的数学表达式。

**建立数学模型的目的**：定量地给出系统中一些变量之间的相互关系，从而对系统进行各种分析和设计，包括稳定性和动态响应的性能分析。

**数学模型的形式**：

| 关系类型 | 数学形式 |
|----------|----------|
| 静态关系 | 代数方程 |
| 动态关系 | 微分方程 / 偏微分方程 / 差分方程 |

### 1.2 建立数学模型的方法

| 方法 | 定义 | 特点 |
|------|------|------|
| **机理建模** | 根据系统的运动学或动力学规律和机理建立数学表达式 | 要求已知所有元部件的结构及对应的物理机理 |
| **实验建模（辨识）** | 人为给系统施加典型输入信号，记录输出响应数据，通过辨识方法用数学模型逼近该过程 | 不需要了解系统内部情况，但不精确 |

**建模原则**：准确性、简化性。

### 1.3 建立微分方程的一般步骤

```
系统原理线路图 → 确定输入量、输出量 → 列写各元件的微分方程 → 消去中间变量 → 整理为标准形式
```

### 1.4 线性定常系统微分方程的一般形式

$$a_n \frac{d^n c(t)}{dt^n} + a_{n-1} \frac{d^{n-1} c(t)}{dt^{n-1}} + \cdots + a_1 \frac{dc(t)}{dt} + a_0 c(t) = b_m \frac{d^m r(t)}{dt^m} + b_{m-1} \frac{d^{m-1} r(t)}{dt^{m-1}} + \cdots + b_1 \frac{dr(t)}{dt} + b_0 r(t)$$

- $c(t)$ 为输出量，$r(t)$ 为输入量
- 通常将输出的 0 阶导数项系数 $a_0$ 化为 1（即将等式两侧同除以 $a_0$）
- 对于实际物理系统：$n \geq m$，且大多数系统 $n > m$

### 1.5 例1.1：机械位移系统（弹簧-质量-阻尼器）

```
      k
F(t) → |→ [m] → y(t)
        |→ f →|
```

**已知**：外力 $F(t)$ 作用于质量块 $m$，弹簧弹性系数 $k$，阻尼器阻尼系数 $f$。

**物理规律**：
- 阻尼器阻力：$F_1(t) = -f \frac{dy(t)}{dt}$（大小与速度成正比，方向与运动方向相反）
- 弹簧恢复力：$F_2(t) = -ky(t)$（大小与位移成正比，方向与运动方向相反）
- 质量块运动方程（牛顿第二定律）：$m \frac{d^2 y(t)}{dt^2} = F(t) + F_1(t) + F_2(t)$

**微分方程**（消去中间变量 $F_1, F_2$）：

$$m \frac{d^2 y(t)}{dt^2} + f \frac{dy(t)}{dt} + ky(t) = F(t)$$

**标准形式**（等式两边同除以 $k$，令 $T = \sqrt{\frac{m}{k}},\ \zeta = \frac{f}{2\sqrt{mk}},\ K = \frac{1}{k}$）：

$$T^2 \frac{d^2 y(t)}{dt^2} + 2\zeta T \frac{dy(t)}{dt} + y(t) = KF(t)$$

| 参数 | 含义 |
|------|------|
| $T$ | 时间常数 |
| $\zeta$ | 阻尼比 |
| $K$ | 比例系数（传递系数），静态时输出与输入之比 |

---

### 1.6 例1.2：RLC电路系统

```
    R     L
ur →[ ]→[ ]→┐
             [C] → uc
             ┘
```

**已知**：$u_r$ 为输入电压，$u_c$ 为输出电压，$i$ 为回路电流。

**列写方程**：
- KVL回路方程：$u_r = Ri + L\frac{di}{dt} + u_c$
- 电容特性：$i = C\frac{du_c}{dt}$

**消去中间变量 $i$**，得微分方程：

$$LC \frac{d^2 u_c(t)}{dt^2} + RC \frac{du_c(t)}{dt} + u_c(t) = u_r(t)$$

令 $T_1 = L/R$，$T_2 = RC$：

$$T_1 T_2 \frac{d^2 u_c(t)}{dt^2} + T_2 \frac{du_c(t)}{dt} + u_c(t) = u_r(t)$$

**相似系统**：机械位移系统与 RLC 电路系统的微分方程结构完全一致。若选择适当的参数，当输入相同时，两个系统的输出具有相同的响应曲线。二者称为**相似系统**。

> 相似系统的意义：可以用电路系统模拟机械系统进行研究（电路参数调节更方便）。

### 1.7 例1.3：直流电动机

```
      Ra    La
ua → [ ] → [ ] → [电动机] → θm (转角输出)
            ↑ Eb         ↓ ML (负载转矩)
            ← Kb·ω       → J, f (转动惯量, 粘性摩擦)
```

**系统变量与参数**：

| 符号 | 含义 | 分类 |
|------|------|------|
| $u_a$ | 电枢端电压 | **输入** |
| $\theta_m$ | 电动机转角 | **输出** |
| $M_L$ | 负载转矩 | **扰动输入** |
| $\omega = d\theta_m/dt$ | 电动机转速 | 中间变量 |
| $i_a$ | 电枢电流 | 中间变量 |
| $E_b$ | 电枢反电势 | 中间变量 |
| $M_m$ | 电磁转矩 | 中间变量 |
| $R_a, L_a$ | 电枢电阻和电感 | 参数 |
| $K_b$ | 反电势系数 | 参数 |
| $C_m$ | 力矩系数 | 参数 |
| $J$ | 转动惯量 | 参数 |
| $f$ | 粘性摩擦系数 | 参数 |

**列写方程**（四个基本方程）：

1. **电枢回路电压平衡方程**：$u_a = R_a i_a + L_a \frac{di_a}{dt} + E_b$
2. **反电势方程**：$E_b = K_b \frac{d\theta_m}{dt}$（反电势大小与角速度成正比，方向与电枢电压相反）
3. **电磁转矩方程**：$M_m = C_m i_a$
4. **转矩平衡方程**：$M_m = J\frac{d^2\theta_m}{dt^2} + f\frac{d\theta_m}{dt} + M_L$

**消去中间变量** $i_a, E_b, M_m$，得到以 $\theta_m$ 为输出的三阶微分方程：

$$JL_a \frac{d^3\theta_m}{dt^3} + (JR_a + fL_a)\frac{d^2\theta_m}{dt^2} + (fR_a + C_m K_b)\frac{d\theta_m}{dt} = C_m u_a - L_a \frac{dM_L}{dt} - R_a M_L$$

**以转速 $\omega$ 为输出**的二阶方程：

$$JL_a \frac{d^2\omega}{dt^2} + (JR_a + fL_a)\frac{d\omega}{dt} + (fR_a + C_m K_b)\omega = C_m u_a - L_a \frac{dM_L}{dt} - R_a M_L$$

**简化情况**：

| 条件 | 简化结果 | 说明 |
|------|----------|------|
| $L_a \approx 0$（电感可忽略） | $(fR_a + C_m K_b)\omega + JR_a \frac{d\omega}{dt} = C_m u_a$ | 降为一阶 |
| $M_L = 0$（空载，且 $L_a \approx 0$） | $JR_a \frac{d\omega}{dt} + (fR_a + C_m K_b)\omega = C_m u_a$ | 一阶线性 |
| $R_a \approx 0$（电阻可忽略） | $K_b \omega = u_a$ | **测速发电机**，线性元件 |

### 1.8 例1.4：水箱液位系统

**已知**：$Q_1$ 为流入量（输入），$Q_2$ 为流出量，$h$ 为液位高度（输出），$C$ 为水箱截面积。

**物质守恒**（流体不可压缩）：

$$C \frac{dh}{dt} = Q_1 - Q_2$$

**流量公式**（节流阀开度固定）：$Q_2 = k\sqrt{h}$，其中 $k = \alpha\sqrt{2g}/\gamma$（$g$ 为重力加速度，$\gamma$ 为液体密度，$\alpha$ 为流体系数）。

**微分方程**：

$$C \frac{dh}{dt} + k\sqrt{h} = Q_1$$

> 这是一个**一阶非线性微分方程**。

### 1.9 轮式机器人平衡控制系统

**系统描述**：设俯仰角为 $\theta$，机器人主体质量为 $m$，高度为 $h$，转动惯量为 $J$。机器人主体受到重力的转矩和电机作用的转矩 $\tau$。

**微分方程**（由转动定律 $J\ddot{\theta} = \sum M$）：

$$J \frac{d^2\theta(t)}{dt^2} = \frac{1}{2}mgh \sin\theta(t) + \tau$$

> 这是一个**二阶非线性微分方程**（含 $\sin\theta$ 非线性项）。

---

### 1.10 微分方程的求解——拉普拉斯变换法

**求解步骤**：
1. 对线性微分方程每一项进行拉氏变换，使微分方程变成以 $s$ 为变量的代数方程（注意初始条件的处理）
2. 求解代数方程，得到输出变量象函数的表达式
3. 将象函数展开成部分分式
4. 对部分分式进行拉氏反变换，得到微分方程的解

**常用拉氏变换对**：

| $f(t)$ | $F(s)$ |
|--------|--------|
| $\delta(t)$（单位脉冲） | $1$ |
| $1(t)$（单位阶跃） | $\frac{1}{s}$ |
| $t$ | $\frac{1}{s^2}$ |
| $\frac{1}{2}t^2$ | $\frac{1}{s^3}$ |
| $e^{-at}$ | $\frac{1}{s+a}$ |
| $\sin bt$ | $\frac{b}{s^2 + b^2}$ |
| $\cos bt$ | $\frac{s}{s^2 + b^2}$ |
| $e^{-at}\sin bt$ | $\frac{b}{(s+a)^2 + b^2}$ |
| $e^{-at}\cos bt$ | $\frac{s+a}{(s+a)^2 + b^2}$ |

**微分定理**（处理初始条件的关键）：
- 一阶导：$\mathcal{L}\left[\frac{df(t)}{dt}\right] = sF(s) - f(0)$
- 二阶导：$\mathcal{L}\left[\frac{d^2 f(t)}{dt^2}\right] = s^2 F(s) - sf(0) - f'(0)$

## 二、非线性系统的线性化

### 2.1 为什么要进行线性化

1. 严格来说，几乎所有元件或系统的运动方程都是非线性方程，非线性微分方程的求解和控制系统性能研究非常复杂
2. 如果研究的是系统在**某个工作点附近**的性能，把它看作线性关系不会产生很大误差
3. 线性化后可以应用**叠加原理**等，使得研究问题非常方便

### 2.2 线性化方法：小偏差法（小信号理论）

**定义**：在给定工作点的邻域将非线性函数展开为泰勒级数，忽略级数中的高阶项，得到只包含偏差一次项的线性方程。

**条件**：
1. 变量在工作点附近作小范围变化（小偏差条件）
2. 在工作点附近存在各阶导数或偏导数（光滑性条件）

**泰勒展开**：设 $y = f(x)$，在工作点 $(x_0, y_0)$ 处（$y_0 = f(x_0)$）：

$$y = f(x) = f(x_0) + \left.\frac{df(x)}{dx}\right|_{x=x_0}(x - x_0) + \frac{1}{2!}\left.\frac{d^2 f(x)}{dx^2}\right|_{x=x_0}(x - x_0)^2 + \cdots$$

若偏差 $\Delta x = x - x_0$ 很小，忽略二阶及以上高阶无穷小项：

$$\Delta y = y - y_0 = f(x) - f(x_0) \approx \left.\frac{df(x)}{dx}\right|_{x=x_0} \cdot \Delta x = K \cdot \Delta x$$

其中 $K = \left.\frac{df(x)}{dx}\right|_{x=x_0}$ 表示 $y = f(x)$ 曲线在 $(x_0, y_0)$ 处切线的斜率。

**结论**：非线性函数在工作点处可以用**该点的切线方程线性化**。

**多变量情况**（$y = f(x_1, x_2)$）：

$$\Delta y \approx \left.\frac{\partial f}{\partial x_1}\right|_{(x_{10}, x_{20})}\Delta x_1 + \left.\frac{\partial f}{\partial x_2}\right|_{(x_{10}, x_{20})}\Delta x_2$$

### 2.3 例2.1：水箱系统的线性化

原非线性方程：$C\frac{dh}{dt} + \sqrt[3]{h} = Q_1$

在工作点 $(Q_{10} = 6, h_0 = 4)$ 处线性化。

**步骤**：
1. 设非线性项 $Q_2(h) = \sqrt[3]{h}$
2. 在 $h_0 = 4$ 处泰勒展开一次近似：$Q_2(h) \approx \sqrt[3]{h_0} + \left.\frac{d\sqrt[3]{h}}{dh}\right|_{h_0} \Delta h = \sqrt[3]{4} + \frac{1}{3} \cdot 4^{-2/3} \cdot \Delta h$
3. 代入原方程：$C\frac{d(\Delta h)}{dt} + \sqrt[3]{4} + \frac{1}{3} \cdot 4^{-2/3}\Delta h = \Delta Q_1 + Q_{10}$
4. 利用平衡点关系 $Q_{10} = \sqrt[3]{4}$，消去常数项
5. 得线性化增量方程：

$$C \frac{d\Delta h}{dt} + 0.75 \Delta h = \Delta Q_1$$

### 2.4 轮式机器人平衡控制系统的线性化

原非线性方程：$J \frac{d^2\theta(t)}{dt^2} = \frac{1}{2}mgh \sin\theta(t) + \tau$

**工作点选择**：$\theta_0 = 0$（直立平衡位置）

在 $\theta_0 = 0$ 处，$\sin\theta \approx \theta$（因为 $\sin\theta = \theta - \frac{\theta^3}{3!} + \cdots$，忽略高阶项）：

$$J \frac{d^2\Delta\theta(t)}{dt^2} = \frac{1}{2}mgh \cdot \Delta\theta + \Delta\tau$$

---

### 2.5 线性化注意事项

1. **工作点依赖性**：线性化是针对某一工作点进行的，工作点不同，得到的线性化方程系数不同。必须首先确定元件的工作点。
2. **偏差范围限制**：略去了泰勒级数中二阶以上的无穷小项。如果输入量变化范围较大，用小偏差法建立线性模型必然会带来较大误差。
3. **符号约定**：线性化后的微分方程通常是**增量方程**，实用上为简便直接采用 $y$ 和 $x$ 来表示增量 $\Delta y$ 和 $\Delta x$。
4. **本质非线性**：若非线性特性函数具有**间断点、折断点或非单值关系**（如继电器特性、饱和特性、滞环特性、间隙特性等），无法作线性化处理，只能应用**非线性理论**来研究。

## 三、案例：轮式机器人平衡动力学分析

### 3.1 控制目标与方案

**控制目标**：保持机器人直立（$\theta^* = 0$）。

**控制方案**：比例控制器 $\tau = k(\theta^* - \theta) = -k\theta$

### 3.2 闭环系统方程

将控制律代入线性化后的被控对象方程：

$$J \frac{d^2\theta(t)}{dt^2} = \frac{1}{2}mgh \cdot \theta(t) - k\theta(t)$$

$$J \frac{d^2\theta(t)}{dt^2} + \left(k - \frac{1}{2}mgh\right)\theta(t) = 0$$

### 3.3 拉氏变换求解

令 $\alpha = k - \frac{1}{2}mgh$，对上述方程取拉氏变换（注意初始条件）：

$$J[s^2\Theta(s) - s\theta(0) - \dot{\theta}(0)] + \alpha\Theta(s) = 0$$

$$\Theta(s) = \frac{\theta(0)s + \dot{\theta}(0)}{Js^2 + \alpha}$$

### 3.4 分类讨论

**情况一：$\alpha > 0$（即 $k > \frac{1}{2}mgh$）**

$$\Theta(s) = \frac{\theta(0)}{J} \cdot \frac{s}{s^2 + \frac{\alpha}{J}} + \frac{\dot{\theta}(0)}{J} \cdot \frac{1}{s^2 + \frac{\alpha}{J}}$$

拉氏反变换：

$$\theta(t) = \frac{\theta(0)}{J} \cos\left(\sqrt{\frac{\alpha}{J}} t\right) + \frac{\dot{\theta}(0)}{J} \sin\left(\sqrt{\frac{\alpha}{J}} t\right)$$

$\theta(t)$ 随时间作**等幅振荡**（临界稳定）。

**情况二：$\alpha < 0$（即 $k < \frac{1}{2}mgh$）**

$$\Theta(s) = \frac{1}{J}\left(\frac{c_1}{s + \sqrt{\frac{-\alpha}{J}}} + \frac{c_2}{s - \sqrt{\frac{-\alpha}{J}}}\right)$$

$$\theta(t) = \frac{c_1}{J} e^{-\sqrt{-\alpha/J} \cdot t} + \frac{c_2}{J} e^{\sqrt{-\alpha/J} \cdot t}$$

$\theta(t)$ 随时间**趋向无穷大**（不稳定，发散倒塌）。

### 3.5 结论

- 控制增益 $k$ 必须满足 $k > \frac{1}{2}mgh$ 才能使系统不至于发散（达到临界稳定）
- 仅用比例控制（P控制）只能实现等幅振荡，无法使系统衰减到平衡点（需要引入微分控制 PD）

## 四、解题通法总结

### 4.1 建立微分方程模型的通法（六步法）

| 步骤 | 内容 | 关键点 |
|------|------|--------|
| ① | **明确输入量、输出量** | 根据控制目标确定；扰动也是一种输入 |
| ② | **分析系统组成** | 拆分系统为各元件/环节，画出原理图 |
| ③ | **列写各元件方程** | 利用物理定律：牛顿定律（机械）、KVL/KCL（电路）、物质守恒（流体） |
| ④ | **补充特性/约束方程** | 如 $i = C\frac{du}{dt}$、$u = L\frac{di}{dt}$、$F_{\text{弹簧}} = -kx$、$E_b = K_b\omega$ 等 |
| ⑤ | **消去中间变量** | 保留输入量和输出量，消去其余所有中间变量 |
| ⑥ | **整理为标准形式** | 输出及导数在左，输入及导数在右；输出 0 阶导系数化为 1 |

**常见系统建模公式速查**：

| 系统类型 | 微分方程 | 阶数 |
|----------|----------|------|
| 弹簧-质量-阻尼器 | $m\ddot{y} + f\dot{y} + ky = F(t)$ | 二阶 |
| RLC串联电路 | $LC\ddot{u}_c + RC\dot{u}_c + u_c = u_r$ | 二阶 |
| 直流电动机（转角） | $JL_a\theta^{(3)} + (JR_a + fL_a)\ddot{\theta} + (fR_a + C_m K_b)\dot{\theta} = C_m u_a$ | 三阶 |
| 直流电动机（转速） | $JL_a\ddot{\omega} + (JR_a + fL_a)\dot{\omega} + (fR_a + C_m K_b)\omega = C_m u_a$ | 二阶 |
| 水箱液位系统 | $C\dot{h} + k\sqrt{h} = Q_1$ | 一阶（非线性） |
| 轮式机器人平衡 | $J\ddot{\theta} - \frac{1}{2}mgh\sin\theta = \tau$ | 二阶（非线性） |

### 4.2 微分方程阶数的快速判断

系统中每个独立的**储能元件**贡献一阶：
- 机械系统：质量块（动能存储）+ 弹簧（势能存储）→ 二阶
- RLC电路：$L$（磁场储能）+ $C$（电场储能）→ 二阶
- 直流电动机（转角输出）：$L_a$（电感储能）+ $J$（转动惯量）→ 三阶
- 水箱系统：水箱（质量存储）→ 一阶

### 4.3 相似系统判别通法

**判别依据**：比较两个系统微分方程的**结构形式**（阶数、各项对应关系），而非参数数值。

两个系统若微分方程的结构完全相同，则它们互为**相似系统**。相似系统对相同输入的输出响应曲线完全一致。

**典例**：机械位移系统 $m\ddot{y} + f\dot{y} + ky = F$ 与 RLC 电路 $LC\ddot{u}_c + RC\dot{u}_c + u_c = u_r$

| 机械参数 | 电气参数 |
|----------|----------|
| 质量 $m$ | 电感 $L$ |
| 阻尼系数 $f$ | 电阻 $R$ |
| 弹性系数 $k$ | 电容倒数 $1/C$ |
| 外力 $F$ | 输入电压 $u_r$ |
| 位移 $y$ | 输出电压 $u_c$ |

### 4.4 非线性系统线性化通法（五步法）

| 步骤 | 内容 |
|------|------|
| ① | **确定工作点** $(x_0, y_0)$：通常选平衡状态或额定工作状态（平衡点处各阶导数为 0） |
| ② | **识别非线性项**：找出方程中所有非线性运算（$\sin\theta$, $\sqrt{h}$, $x_1x_2$, $x^2$ 等） |
| ③ | **对每个非线性项泰勒展开**（取一次近似）：$f(x) \approx f(x_0) + f'(x_0)(x - x_0)$ |
| ④ | **代入原方程**，利用平衡点条件消去常数项 |
| ⑤ | **写为增量形式**，用 $x$, $y$ 直接表示增量（工程简化约定） |

**常用非线性函数的线性化公式**：

| 非线性函数 | 工作点 | 线性化结果 |
|------------|--------|------------|
| $\sin x$ | $x_0 = 0$ | $\sin x \approx x$ |
| $\cos x$ | $x_0 = 0$ | $\cos x \approx 1$ |
| $\sqrt{x}$ | $x_0$ | $\sqrt{x} \approx \sqrt{x_0} + \frac{1}{2\sqrt{x_0}}\Delta x$ |
| $\sqrt[3]{x}$ | $x_0$ | $\sqrt[3]{x} \approx \sqrt[3]{x_0} + \frac{1}{3}x_0^{-2/3}\Delta x$ |

### 4.5 拉氏变换求解线性微分方程通法

| 步骤 | 操作 |
|------|------|
| ① | **拉氏变换**：对微分方程两边取拉氏变换，利用微分定理代入初始条件 |
| ② | **求解 $Y(s)$**：整理为 $Y(s) = \frac{N(s)}{D(s)}$ 的有理分式形式 |
| ③ | **部分分式展开**：根据 $D(s)$ 根的类型分解 |
|  | — 单实根 $s_i$：$\frac{A_i}{s - s_i}$ |
|  | — 重实根：$\frac{A_1}{s-s_i} + \frac{A_2}{(s-s_i)^2} + \cdots$ |
|  | — 共轭复根 $\alpha \pm j\beta$：$\frac{As + B}{(s+\alpha)^2 + \beta^2}$ |
| ④ | **查表反变换**：逐项反变换得 $y(t)$ |

### 4.6 线性/非线性系统判断通法

利用**叠加原理**验证（详见 Lecture1）：

设 $r_1 \to c_1$，$r_2 \to c_2$，构造 $r_3 = k_1 r_1 + k_2 r_2$。

若对任意 $k_1, k_2$ 恒有：将 $r_3$ 代入方程得到的 $c_3$ 等于 $k_1 c_1 + k_2 c_2$，则为**线性**；否则为**非线性**。

**快速判别**：
- 方程中存在**常数项**（非零偏置 $b$）→ 非线性
- 方程中存在**非线性运算**（乘积项、高次项、$\sin$、$\sqrt{\ }$、绝对值等）→ 非线性
- 只有输入输出满足**齐次可加的线性微分方程**才是线性系统
