# 控制系统的传递函数学习笔记

## 一、 传递函数的基本概念

传递函数是控制系统中用于在复数域（s域）描述线性定常系统动态性能的数学模型 。

* 
**定义**：线性定常系统的传递函数为**零初始条件**下，系统输出量的拉氏变换与系统输入量的拉氏变换之比 。


* **零初始条件的含义**：
* 系统的输入在 $t>0$ 时才作用于系统，即在 $t=0$ 时系统输入及其各项导数均为零 。


* 输入量在加于系统之前，系统为稳态，即在 $t=0$ 时输出及其所有导数项为零 。




* 传递函数摒弃了非零初始状态对响应的影响，专门用来考察系统本身的特性 。



## 二、 传递函数是如何生成的？

生成传递函数的核心在于将时域的微分方程转换为复频域的代数方程。具体步骤如下：

1. 
**建立微分方程**：首先写出描述线性定常系统的 $n$ 阶常微分方程 ：



$$a_{n}\frac{d^{n}c(t)}{dt^{n}}+a_{n-1}\frac{d^{n-1}c(t)}{dt^{n-1}}+\cdot\cdot\cdot+a_{0}c(t) = b_{m}\frac{d^{m}r(t)}{dt^{m}}+b_{m-1}\frac{d^{m-1}r(t)}{dt^{m-1}}+\cdot\cdot\cdot+b_{0}r(t)$$


其中 $c(t)$ 是输出量， $r(t)$ 是输入量， $a_i$ 和 $b_j$ 是与系统结构和参数有关的常系数 。


2. 
**引入零初始条件**：假设输入 $r(t)$ 和输出 $c(t)$ 及其各阶导数在 $t=0$ 时的值均为0 。


3. 
**求拉氏变换**：基于零初始条件，对等式两边分别求拉氏变换，算符 $\frac{d}{dt}$ 直接用复数 $s$ 置换 。令 $C(s)=L[c(t)]$， $R(s)=L[r(t)]$，得到代数方程 ：



$$[a_{n}s^{n}+a_{n-1}s^{n-1}+\cdot\cdot\cdot+a_{0}]C(s) = [b_{m}s^{m}+b_{m-1}s^{m-1}+\cdot\cdot\cdot+b_{0}]R(s)$$


4. 
**计算比值**：将输出与输入作比，得到传递函数的标准有理分式形式 ：



$$G(s)=\frac{C(s)}{R(s)}=\frac{b_{m}s^{m}+b_{m-1}s^{m-1}+\cdot\cdot\cdot+b_{0}}{a_{n}s^{n}+a_{n-1}s^{n-1}+\cdot\cdot\cdot+a_{0}}=\frac{M(s)}{N(s)}$$



**物理系统生成案例**：

* 
**机械位移系统**：微分方程为 $\frac{m}{k}\frac{d^{2}y(t)}{dt^{2}}+\frac{f}{k}\frac{dy(t)}{dt}+y(t)=\frac{1}{k}F(t)$，对其求拉氏变换得到传递函数为 $G(s)=\frac{1}{ms^{2}+fs+k}$ 。


* 
**电路系统（RLC）**：微分方程为 $LC\frac{d^{2}u_{c}(t)}{dt^{2}}+RC\frac{du_{c}(t)}{dt}+u_{c}(t)=u_{r}(t)$，传递函数为 $G(s)=\frac{U_{c}(s)}{U_{r}(s)}=\frac{1}{LCs^{2}+RCs+1}$ 。



## 三、 传递函数的三种呈现形式

传递函数 $G(s)=\frac{M(s)}{N(s)}$ 中的分母多项式 $N(s)$ 称为系统的特征多项式， $N(s)=0$ 称为特征方程 。 $N(s)=0$ 的根为极点， $M(s)=0$ 的根为零点 。
传递函数有以下三种常见形式：

1. 
**有理分式形式**：即上述按 $s$ 的降幂排列的多项式比值形式 。


2. 
**零极点形式**：将分子和分母因式分解 ：



$$G(s)=k^{*}\frac{\prod_{i=1}^{m}(s-z_{i})}{\prod_{j=1}^{n}(s-p_{j})}$$


其中 $z_i$ 为零点， $p_j$ 为极点， $k^*$ 称为根轨迹增益 。


3. 
**时间常数形式**：将多项式变为尾一多项式（常数项为1）后分解 ：



$$G(s)=K\frac{s^{l}(\tau_{1}s+1)(\tau_{2}^{2}s^{2}+2\xi_{2}\tau_{2}s+1)...}{s^{v}(T_{1}s+1)(T_{2}^{2}s^{2}+2\xi_{2}^{\prime}T_{2}s+1)...}$$


其中 $T$ 和 $\tau$ 称为时间常数， $K$ 为传递系数或静态放大系数（即 $s=0$ 时的稳态比值） 。 $K$ 与 $k^*$ 的关系为 $K=k^{*}\frac{\prod(-z_{i})}{\prod(-p_{j})}$ 。



## 四、 传递函数的性质与局限性

* 
**固有特性**：传递函数反映系统自身固有特性，与输入信号和初始条件无关 。


* 
**异物同构**：不同的物理系统可能有相同的传递函数，而同一系统也可以有不同的传递函数（如多输入多输出系统使用传递函数矩阵） 。


* 
**与脉冲响应的关系**：传递函数与单位脉冲响应之间是拉氏变换与拉氏反变换的关系。即 $C(s)=G(s)R(s)$，当输入为单位脉冲 $\delta(t)$ 时， $R(s)=1$，此时 $C(s)=G(s)$ 。


* 
**物理现实性条件**：一般情况下，传递函数分子的阶数 $m$ 与分母的阶数 $n$ 满足 $n \ge m$。因为现实系统具有惯性且能量有限，不可能产生无延迟的无穷大响应 。


* 
**局限性**：只适用于线性定常系统，不反映初始状态信息，也不反映系统内部任何信息 。



## 五、 如何求拉氏变换（包含非零初始条件的求解）

在标准传递函数的定义中，我们假设了零初始条件。但如果系统具有**非零初始条件**，我们需要运用拉氏变换的微分定理来全面求解系统响应 。

1. **拉氏变换的微分定理**：
对于 $n$ 阶导数，其拉氏变换公式为 ：



$$L\left[\frac{d^{n}c(t)}{dt^{n}}\right]=s^{n}C(s)-\sum_{k=1}^{n}\frac{d^{k-1}c(0)}{dt^{k-1}}s^{n-k}$$


2. **构建全响应方程**：
将非零初始条件代入微分方程的拉氏变换中，可以将总输出 $C(s)$ 分解为两部分 ：



$$C(s) = C_{1}(s) + C_{2}(s)$$


* 
**零输入响应 $C_{1}(s)$**：由初始条件产生，与输入无关。当输入有关的初始条件为0时，它仅由输出的初始条件和传递函数的分母多项式 $N(s)$ 决定 。


* 
**零状态响应 $C_{2}(s)$**：由输入信号产生，与初始条件无关。这部分等于传递函数乘以输入的拉氏变换，即 $C_{2}(s) = G(s)R(s)$ 。




3. **运用留数定理求解拉氏反变换**：
为了从 $s$ 域回到时间域 $t$，通常需要利用部分分式展开（留数定理） 。



$$C(s) = \sum_{j=1}^{n}\frac{Res[C(s)]}{s-p_{j}}$$


据此可以通过传递函数的特征根（即分母的根 $p_j$）确定系统的模态，并求出待定系数，最后通过拉氏反变换得出时域解 $c(t)$ 。



## 六、 案例：轮式机器人平衡控制系统

通过建立轮式机器人的微分方程 $J\frac{d^{2}\theta(t)}{dt^{2}}=\frac{1}{2}mgh\theta+\tau$，引入控制器 $\tau = k(-\theta)$ 。 * **传递函数求解**：在零初始条件下，解得闭环传递函数为 $G(s)=\frac{\theta(s)}{R(s)}=\frac{k}{Js^{2}+k-\frac{1}{2}mgh}$ 。

* **动力学分析（非零初始条件应用）**：若参考输入为0，分析其零输入响应 $\theta(s)=\frac{\theta(0)s+\dot{\theta}(0)}{Js^{2}+(k-\frac{1}{2}mgh)}$ 。令 $\alpha = k-\frac{1}{2}mgh$ ：


* 当 $\alpha > 0$ 时，系统特征根为纯虚根，系统表现为等幅振荡（摇摆） 。


* 当 $\alpha < 0$ 时，系统特征根包含正实数部分， $\theta(t)$ 随时间趋向无穷，系统发散倒塌 。


***********************

补充微分方程转化为传递函数的完整推导过程，是掌握《自动控制原理》建模部分的核心。

根据传递函数的定义，所有推导**必须基于零初始条件**的前提 。即系统在 $t=0$ 时，输入量、输出量及其各阶导数均为零 。根据拉氏变换的微分定理，在零初始条件下，对函数求 $n$ 阶导数的拉氏变换直接等于 $s^n$ 乘以该函数的拉氏变换，即 $L\left[\frac{d^nf(t)}{dt^n}\right] = s^n F(s)$ 。

以下是课件中涉及的所有系统的微分方程转化为传递函数的完整步骤推导：

1. 机械位移系统 

* **已知微分方程**：


$$\frac{m}{k}\frac{d^{2}y(t)}{dt^{2}}+\frac{f}{k}\frac{dy(t)}{dt}+y(t)=\frac{1}{k}F(t)$$



其中，$y(t)$ 是系统输出（位移），$F(t)$ 是系统输入（力）。


* **推导步骤**：
1. **假定零初始条件**：设 $y(0)=0$, $\dot{y}(0)=0$, $F(0)=0$。
2. **两边同取拉氏变换**：

$$L\left[\frac{m}{k}\frac{d^{2}y(t)}{dt^{2}}\right] + L\left[\frac{f}{k}\frac{dy(t)}{dt}\right] + L[y(t)] = L\left[\frac{1}{k}F(t)\right]$$


3. **应用微分定理**，将时域变量转换为复频域变量 $Y(s)$ 和 $F(s)$：

$$\frac{m}{k}s^{2}Y(s) + \frac{f}{k}sY(s) + Y(s) = \frac{1}{k}F(s)$$


4. **提取公因式 $Y(s)$**：

$$\left(\frac{m}{k}s^{2} + \frac{f}{k}s + 1\right)Y(s) = \frac{1}{k}F(s)$$


5. **求输出与输入之比（并化简）**，等式两边同乘 $k$：

$$(ms^{2} + fs + k)Y(s) = F(s)$$



$$G(s) = \frac{Y(s)}{F(s)} = \frac{1}{ms^{2}+fs+k}$$








2. 电路系统 (RLC电路) 

* **已知微分方程**：


$$LC\frac{d^{2}u_{c}(t)}{dt^{2}}+RC\frac{du_{c}(t)}{dt}+u_{c}(t)=u_{r}(t)$$



其中，$u_{c}(t)$ 是输出电压，$u_{r}(t)$ 是输入电压。


* **推导步骤**：
1. **假定零初始条件**：设电容初始电压和电感初始电流均为零，即 $u_c(0)=0$, $\dot{u}_c(0)=0$。
2. **两边同取拉氏变换**：

$$L\left[LC\frac{d^{2}u_{c}(t)}{dt^{2}}\right] + L\left[RC\frac{du_{c}(t)}{dt}\right] + L[u_{c}(t)] = L[u_{r}(t)]$$


3. **应用微分定理**，代入 $U_c(s)$ 和 $U_r(s)$：

$$LCs^{2}U_{c}(s) + RCsU_{c}(s) + U_{c}(s) = U_{r}(s)$$


4. **提取公因式**：

$$(LCs^{2} + RCs + 1)U_{c}(s) = U_{r}(s)$$


5. **求输出与输入之比**：


$$G(s) = \frac{U_{c}(s)}{U_{r}(s)} = \frac{1}{LCs^{2}+RCs+1}$$








3. 直流电机系统 (多输入系统) 

* **已知微分方程**：


$$T\frac{d\omega(t)}{dt}+\omega(t)=K_{1}u_{a}(t)+K_{2}M_{L}(t)$$


其中，输出为转速 $\omega(t)$，输入有两个：电枢电压 $u_{a}(t)$ 和负载转矩 $M_{L}(t)$ 。


* **推导步骤**：
1. **假定零初始条件**，并对等式两边求拉氏变换：


$$Ts\Omega(s) + \Omega(s) = K_{1}U_{a}(s) + K_{2}M_{L}(s)$$





2. **提取公因式**：

$$(Ts + 1)\Omega(s) = K_{1}U_{a}(s) + K_{2}M_{L}(s)$$


3. 
**应用叠加原理分别求传递函数** ：


* 
**求电枢电压到转速的传递函数**：令负载转矩 $M_{L}(s) = 0$ 。



$$(Ts + 1)\Omega(s) = K_{1}U_{a}(s) \implies G_1(s) = \frac{\Omega(s)}{U_{a}(s)} = \frac{K_{1}}{Ts+1}$$





* 
**求负载转矩到转速的传递函数**：令电枢电压 $U_{a}(s) = 0$ 。



$$(Ts + 1)\Omega(s) = K_{2}M_{L}(s) \implies G_2(s) = \frac{\Omega(s)}{M_{L}(s)} = \frac{K_{2}}{Ts+1}$$







4. 写成矩阵形式，满足 $\Omega(s) = G(s)\begin{bmatrix}U_a(s)\\M_L(s)\end{bmatrix}$：


$$G(s) = \begin{bmatrix} \frac{K_1}{Ts+1} & \frac{K_2}{Ts+1} \end{bmatrix}$$








4. 轮式机器人平衡控制系统 (闭环系统) 

* **已知被控对象微分方程与控制律**：
被控对象：$J\frac{d^{2}\theta(t)}{dt^{2}}=\frac{1}{2}mgh\theta(t)+\tau(t)$ 控制器设计：闭环系统中加入了负反馈，控制量 $\tau(t) = k(r(t) - \theta(t))$（在课件图示中，设参考输入为 $R(s)$，误差为 $\theta^* - \theta$，放大增益为 $k$） 。


* **推导步骤**：
1. **将控制律代入微分方程**，建立反映参考输入 $r(t)$ 与输出 $\theta(t)$ 关系的方程：

$$J\frac{d^{2}\theta(t)}{dt^{2}} = \frac{1}{2}mgh\theta(t) + k(r(t) - \theta(t))$$


2. **移项整理**，将输出项放左边，输入项放右边：

$$J\frac{d^{2}\theta(t)}{dt^{2}} + \left(k - \frac{1}{2}mgh\right)\theta(t) = kr(t)$$


3. **假定零初始条件，并对等式两边求拉氏变换**：

$$Js^{2}\theta(s) + \left(k - \frac{1}{2}mgh\right)\theta(s) = kR(s)$$


4. **提取公因式 $\theta(s)$**：

$$\left[Js^{2} + \left(k - \frac{1}{2}mgh\right)\right]\theta(s) = kR(s)$$


5. **求输出与输入之比**，得到闭环传递函数：


$$G(s) = \frac{\theta(s)}{R(s)} = \frac{k}{Js^{2}+k-\frac{1}{2}mgh}$$








5. 线性定常系统的一般形式 

* **已知 $n$ 阶线性常微分方程**：


$$a_{n}\frac{d^{n}c(t)}{dt^{n}}+a_{n-1}\frac{d^{n-1}c(t)}{dt^{n-1}}+\cdot\cdot\cdot+a_{1}\frac{dc(t)}{dt}+a_{0}c(t) = b_{m}\frac{d^{m}r(t)}{dt^{m}}+\cdot\cdot\cdot+b_{1}\frac{dr(t)}{dt}+b_{0}r(t)$$





* **推导步骤**：
1. 设 $r(t)$ 和 $c(t)$ 及其各阶导数在 $t=0$ 时的值为 $0$，满足零初始条件 。


2. 对等式两边各项分别求拉氏变换，令 $C(s)=L[c(t)]$， $R(s)=L[r(t)]$ ：



$$a_{n}s^{n}C(s)+a_{n-1}s^{n-1}C(s)+\cdot\cdot\cdot+a_{0}C(s) = b_{m}s^{m}R(s)+\cdot\cdot\cdot+b_{0}R(s)$$


3. 提出公因子：


$$(a_{n}s^{n}+a_{n-1}s^{n-1}+\cdot\cdot\cdot+a_{0})C(s) = (b_{m}s^{m}+b_{m-1}s^{m-1}+\cdot\cdot\cdot+b_{0})R(s)$$





4. 移项作比，得到标准传递函数：


$$G(s) = \frac{C(s)}{R(s)} = \frac{b_{m}s^{m}+b_{m-1}s^{m-1}+\cdot\cdot\cdot+b_{0}}{a_{n}s^{n}+a_{n-1}s^{n-1}+\cdot\cdot\cdot+a_{0}}$$
