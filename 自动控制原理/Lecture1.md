# Lecture 1 — 自动控制系统简介

---

## 一、自动控制系统的基本构成

### 1.1 基本概念

- **自动控制**：在不用人直接操纵的情况下，利用控制器使控制对象的某一物理量按一定规律变化。
- **自动控制系统**：完成控制目的而不需要人的介入。包括**控制对象**以及参与实现其被控制量自动控制的装置或元部件。

### 1.2 人工控制中人的三个作用

人在控制过程中起三个作用——自动控制即用机器替代这三个作用：

| 作用 | 人工 | 自动（对应元件） |
|------|------|------------------|
| 观测 | 眼睛观察指示值 | 测量元件（如热电偶） |
| 比较与决策 | 人脑比较、判断、给出控制量 | 控制器 |
| 执行 | 用手调节 | 执行器（如变速器、电机） |

### 1.3 闭环自动控制系统方块图（重点）

```
                               扰动
                                |
给定值 → 比较元件 → 控制器 → 执行器 → 被控对象 → 被控制量
            ↑                                    |
            |←———— 测量变送元件 ←——————————————|
                    (负反馈)
```

### 1.4 系统各组成元件定义（重点）

| 元件 | 定义 |
|------|------|
| **被控对象** | 运动规律或状态需要控制的装置 |
| **控制器** | 使被控对象具有期望性能或状态的控制设备。将系统输出与参考输入比较，根据偏差按预定控制规律给出控制量 |
| **执行器** | 执行来自控制器的指令，将控制作用施加于被控对象 |
| **测量变送元件** | 测量系统输出量并传递给输入端的反馈元件，供比较元件将其与给定值比较 |

### 1.5 系统的变量（重点）

| 变量 | 定义 |
|------|------|
| **给定值（参考输入）** | 系统输出量应达到的数值 |
| **反馈信号** | 从系统输出端取出并反向送回到系统输入端的信号 |
| **被控制量（输出信号）** | 表征控制对象运动规律或状态的物理量 |
| **控制变量** | 由控制器改变的量，对被控参数有较好的调节能力 |
| **扰动** | 使系统输出量偏离期望值的信号。分**内扰**（系统内部产生）和**外扰**（系统外部产生） |

### 1.6 负反馈与正反馈

- **负反馈**：反馈信号的符号与被比较信号**相反**（核心，用于自动控制）
- **正反馈**：反馈信号的符号与被比较信号**相同**

## 二、自动控制系统的分类（7种分类方式）

### 2.1 按信号的传递路径分

| 类型 | 特点 | 优点 | 缺点 |
|------|------|------|------|
| **开环控制** | 控制器与对象之间只有顺向作用，无反向联系 | 结构简单、成本低廉、易于实现 | 对扰动无抑制能力，控制精度低 |
| **闭环控制（反馈控制）** | 控制器与对象之间既有顺向作用又有反向联系，利用负反馈减小误差 | 可自动补偿系统内部和外部干扰引起的误差，有效提高精度 | 参数应适当选择，否则可能不能正常工作 |
| **复合控制** | 开环+闭环结合，附加输入信号或扰动信号的顺馈通路 | 控制精度高，可抑制几乎所有可量测扰动 | 补偿器参数需有较高稳定性 |

### 2.2 按系统输入信号的变化规律分

| 类型 | 特点 |
|------|------|
| **恒值控制系统** | 被控制量保持恒定或基本恒定 |
| **程序控制系统** | 被控制量按预定规律变化，给定值为确定的已知函数 |
| **随动控制系统（伺服系统）** | 给定值变化规律预先不能确定，但输出能准确迅速地再现输入变化 |

### 2.3 按系统传输信号的性质分

| 类型 | 特点 | 数学描述 |
|------|------|----------|
| **连续系统** | 一切组成部分的输出都是输入部分的连续函数 | 微分方程 |
| **离散系统** | 系统内部一部分或全部信号是断续或离散的 | 差分方程 |

- 离散系统子类：若离散信号取**脉冲** → 脉冲控制系统；若离散信号以**数码形式**传递 → 采样数字控制系统

### 2.4 按系统变量是否仅是时间的函数分

| 类型 | 特点 | 数学描述 |
|------|------|----------|
| **集中参数系统** | 变量仅仅是时间的函数 | 微分方程 |
| **分布参数系统** | 变量不仅是时间函数，还是空间函数 | 偏微分方程 |

### 2.5 按输入输出变量的个数分

- **SISO**：单输入单输出（Single Input Single Output）
- **MIMO**：多输入多输出（Multiple Input Multiple Output）

### 2.6 按系统参数是否随时间发生变化分

| 类型 | 特点 |
|------|------|
| **定常系统** | 微分方程的各项系数为**常数** |
| **时变系统** | 微分方程的系数为**时间的函数** |

### 2.7 按数学模型是否满足叠加原理分

| 类型 | 特点 |
|------|------|
| **线性系统** | 组成系统的所有元件或子系统都是线性的 |
| **非线性系统** | 系统中至少有一个元件或子系统是非线性的 |

**叠加原理**包含两个性质：
- **加和性**（可加性）：$f(x_1 + x_2) = f(x_1) + f(x_2)$——多个输入同时作用时，总输出 = 每个输入单独作用时产生的响应之和
- **齐次性**（均匀性）：$f(kx) = kf(x)$——输入放大或缩小 k 倍，响应也放大或缩小 k 倍

## 三、自动控制系统的基本要求（三大性能——重点）

### 3.1 系统的两种工作状态

| 状态 | 定义 |
|------|------|
| **静态（稳态）** | 被控量处于平衡状态 |
| **动态（过渡过程）** | 被控量偏离给定值后，经过控制作用从一个平衡状态过渡到新平衡状态的过程 |

### 3.2 常见的被控量动态特性（四种过渡过程形态）

| 过程类型 | 特征 | 稳定性判定 |
|----------|------|------------|
| **单调过程** | 被控量单调变化到达新平衡，过渡时间长 | 稳定 |
| **衰减振荡过程** | 振荡幅度不断衰减，最终达到新稳态值 | 稳定（理想） |
| **等幅振荡过程** | 持续等幅振荡，始终不能到达新稳态值 | **临界稳定**（幅度大→不稳定；幅度小且生产允许→可认为稳定） |
| **渐扩振荡过程** | 振荡幅值越来越大，大大超过允许误差范围 | **典型不稳定** |

### 3.3 三大基本要求（重点）

| 要求 | 含义 | 指标 |
|------|------|------|
| **稳定性** | 保证控制系统正常工作的**先决条件**。系统应绝对稳定，且希望有一定**稳定裕度**，防止参数变化对稳定性的破坏 | 是否稳定、稳定裕度 |
| **动态性能** | 系统实现跟踪或消除干扰影响的性能 | **快速性**（过渡过程时间短）+ **平稳性**（振荡幅度小、衰减快） |
| **稳态性能** | 过渡过程结束后，被控量与期望值的偏差 | **稳态误差越小越好**，体现最终响应的准确度 |

> 总结：**稳（稳定性）→ 快（快速性）→ 准（准确性/稳态误差）**

## 四、题目解题通法

### 题型一：识别控制系统各组成元件

**通法**：对照闭环方块图，逐一定位：

1. **被控对象**：哪个装置的运动规律/状态需要被控制？
2. **被控制量**：被控对象的哪个物理量是控制目标？（如温度、转速、位置）
3. **给定值**：期望的被控制量数值对应什么信号？
4. **测量变送元件**：什么元件在测量被控制量并转换成反馈信号？
5. **比较元件**：给定值与反馈信号在何处比较？（注意符号）
6. **控制器**：根据偏差发出控制指令的元件
7. **执行器**：接收控制器指令并施加作用于被控对象的元件
8. **扰动**：哪些因素会使输出偏离期望值？

### 题型二：判断开环/闭环/复合控制

**通法**：
- 看信号流是否有从输出端返回输入端的**反馈通路**：
  - 无反馈通路 → **开环控制**
  - 有反馈通路 → **闭环控制**
  - 有反馈通路 + 额外的前馈（顺馈）通路 → **复合控制**

### 题型三：判断线性/非线性系统（叠加原理检验）

**通法（核心）**：

> 设输入 $x_1$ 对应输出 $y_1$，输入 $x_2$ 对应输出 $y_2$。
> 令 $x_3 = k_1 x_1 + k_2 x_2$（$k_1, k_2$ 为任意常数）。
> 若**恒有** $y_3 = k_1 y_1 + k_2 y_2$，则系统为**线性**；否则为**非线性**。

**操作步骤**：
1. 写出系统输入-输出满足的微分/差分方程
2. 设两个输入 $x_1, x_2$ 各自满足方程，分别得输出 $y_1, y_2$
3. 构造 $x_3 = k_1 x_1 + k_2 x_2$ 代入方程
4. 检查 $y_3$ 是否恒等于 $k_1 y_1 + k_2 y_2$
5. 不恒等 ⇒ **非线性系统**

**常见考点**：方程中含有**常数项**（非零偏置）时，不满足叠加原理，必为非线性系统。

> 例：$\dot{c}(t) = a \cdot r(t) + b$（$b \neq 0$），因为有常数项 $b$，所以是**非线性系统**。

### 题型四：系统分类综合判断题

**通法**：按 7 种分类方式逐一判断：

1. 信号传递路径 → 开环/闭环/复合
2. 输入信号变化规律 → 恒值/程序/随动
3. 信号传输性质 → 连续/离散
4. 变量维数 → 集中参数/分布参数
5. 输入输出个数 → SISO/MIMO
6. 参数是否时变 → 定常/时变
7. 叠加原理 → 线性/非线性

### 题型五：判断四种动态过程类型

**通法**：观察过渡过程曲线的趋势——
- 单调趋近稳态值 → **单调过程**
- 振荡且振幅递减 → **衰减振荡过程**
- 振荡且振幅不变 → **等幅振荡过程**
- 振荡且振幅递增 → **渐扩振荡过程**
