## 一、稳态误差的定义

### 1.1 基本概念

| 概念 | 定义 |
|------|------|
| **误差 $e(t)$** | 参考输入信号 $r(t)$ 与反馈信号 $b(t)$ 的差值：$e(t) = r(t) - b(t)$ |
| **稳态响应** | 控制系统最终状态的表现形式 |
| **稳态误差 $e_{ss}$** | 系统实际输出值与希望输出值之间的**最终偏差** |

### 1.2 稳态误差的计算方法：终值定理法（重点）

**时域定义**：

$$e_{ss} = e(\infty) = \lim_{t\to\infty} e(t) = \lim_{t\to\infty}[r(t) - b(t)]$$

**$S$ 域计算（终值定理）**：

$$e_{ss} = \lim_{t\to\infty} e(t) = \lim_{s\to 0} sE(s)$$

**标准计算步骤**：

1. 求**误差传递函数**：

$$\Phi_e(s) = \frac{E(s)}{R(s)} = \frac{1}{1 + G_1(s)G_2(s)H(s)}$$

2. 由终值定理求稳态误差：

$$e_{ss} = \lim_{s\to 0} sE(s) = \lim_{s\to 0} s \cdot \Phi_e(s) \cdot R(s)$$

### 1.3 典型控制结构图

```
                          N(s)
                           ↓
R(s) → ⊗ → G₁(s) → ⊗ → G₂(s) → Y(s)
        ↑ -                     |
        |                       |
        ←——— H(s) ←—————————————|
```

- $G_1(s)$、$G_2(s)$：前向通路传递函数
- $H(s)$：反馈通路传递函数
- $R(s)$：参考输入
- $N(s)$：扰动输入
- $E(s)$：误差信号
- $B(s)$：反馈信号

### 1.4 简单案例：比例控制下的稳态误差

系统：车辆动力学 $\dot{v}(t) = u(t)$，控制器 $u(t) = K_1 e(t)$，单位反馈。

开环传函：$G(s) = \frac{K_1}{s}$，单位反馈 $H(s) = 1$

误差传递函数：$\Phi_e(s) = \frac{1}{1 + K_1/s} = \frac{s}{s + K_1}$

输入 $r(t) = 30 \cdot 1(t)$（即 $R(s) = \frac{30}{s}$）：

$$e_{ss} = \lim_{s\to 0} s \cdot \frac{s}{s+K_1} \cdot \frac{30}{s} = \lim_{s\to 0} \frac{30s}{s+K_1} = 0$$

此时无扰动情况下稳态误差为 **0**。

## 二、扰动输入下控制系统的稳态误差（重点）

### 2.1 同时存在参考输入和扰动输入

利用**叠加原理**分别计算：

**(1) 仅参考输入 $R(s)$ 作用（令 $N(s)=0$）**

$$\Phi_{er}(s) = \frac{E(s)}{R(s)} = \frac{1}{1 + G_1(s)G_2(s)H(s)}$$

**(2) 仅扰动输入 $N(s)$ 作用（令 $R(s)=0$）**

$$\Phi_{en}(s) = \frac{E(s)}{N(s)} = \frac{-G_2(s)H(s)}{1 + G_1(s)G_2(s)H(s)}$$

**(3) 总误差（叠加）**

$$E(s) = \Phi_{er}(s) \cdot R(s) + \Phi_{en}(s) \cdot N(s)$$

$$E(s) = \frac{R(s)}{1 + G_1(s)G_2(s)H(s)} + \frac{-G_2(s)H(s) \cdot N(s)}{1 + G_1(s)G_2(s)H(s)}$$

### 2.2 扰动下稳态误差的计算

$$e_{ss} = \lim_{s\to 0} sE(s) = \lim_{s\to 0} s\left[\Phi_{er}(s) \cdot R(s) + \Phi_{en}(s) \cdot N(s)\right]$$

### 2.3 案例：有扰动时的稳态误差

系统：$G_1(s) = K_1$，$G_2(s) = \frac{1}{s}$，$H(s) = 1$

扰动：$n(t) = 10 \cdot 1(t)$（即 $N(s) = \frac{10}{s}$）

输入：$r(t) = 30 \cdot 1(t)$（即 $R(s) = \frac{30}{s}$）

$$E(s) = \frac{30/s}{1 + K_1/s} + \frac{-\frac{1}{s} \cdot 10/s}{1 + K_1/s} = \frac{30 - \frac{10}{s}}{s + K_1}$$

$$e_{ss} = \lim_{s\to 0} s \cdot \frac{30s - 10}{s(s + K_1)} = \lim_{s\to 0} \frac{30s - 10}{s + K_1} = -\frac{10}{K_1}$$

> **结论**：存在阶跃扰动时，纯比例控制无法消除稳态误差。增大 $K_1$ 可减小稳态误差，但不能消除。

## 三、定速巡航控制综合设计案例（核心）

### 3.1 问题分析

车辆动力学：$\dot{v}(t) = u(t) + n(t)$（$n(t)$ 为外部扰动）

- 设计目标：车速稳定在 30 m/s
- 初始控制器：$u(t) = K_1 e(t)$（纯比例控制）
- 存在问题：有扰动时稳态误差 ≠ 0

### 3.2 改进方案一：比例+积分（PI）控制结构

**$S$ 域**：

$$U(s) = \frac{K_1}{s}E(s) - V(s)$$

**时域**：

$$\begin{cases} \dot{z}(t) = e(t) \\ u(t) = K_1 z(t) - v(t) \end{cases}$$

其中 $z(t)$ 是误差的积分项，$-v(t)$ 是速度反馈用于改善动态性能。

控制结构变为：

```
                    N(s)
                     ↓
R(s) → ⊗ → K₁/s → ⊗ → 1/s → V(s)
        ↑ -    |          |
        |      ←—— 1 ←————  (内环速度反馈)
        |                     |
        ←————————————————————|
```

### 3.3 改进后的等效结构（内环化简后）

等效前向通路中引入了一个 $s+1$ 环节（速度内环反馈的结果）：

$$E(s) = \frac{30/s}{1 + \frac{K_1}{s(s+1)}} + \frac{-\frac{1}{s+1} \cdot 1/s}{1 + \frac{K_1}{s(s+1)}}$$

$$E(s) = \frac{30s - 1}{s^2 + s + K_1}$$

$$e_{ss} = \lim_{s\to 0} s \cdot \frac{30s - 1}{s^2 + s + K_1} = \lim_{s\to 0} \frac{s(30s-1)}{s^2+s+K_1} = 0$$

> **结论**：通过在前向通路中引入**积分环节**（PI 控制），可以**完全消除**阶跃扰动下的稳态误差。

### 3.4 总结：消除稳态误差的设计策略

| 控制器类型 | 传递函数 | 阶跃扰动下 $e_{ss}$ | 能否消除 |
|------------|----------|---------------------|----------|
| 比例控制（P） | $U(s) = K_1 E(s)$ | $-\frac{10}{K_1}$ | 不能，只能减小 |
| 比例+积分+速度反馈 | $U(s) = \frac{K_1}{s}E(s) - V(s)$ | $0$ | **能** |

## 四、题目解题通法

### 4.1 题型一：给定系统结构图，求参考输入下的稳态误差

**步骤**：
1. 写出误差传递函数 $\Phi_e(s) = \frac{E(s)}{R(s)} = \frac{1}{1 + G_o(s)}$（$G_o(s)$ 为开环传函）
2. 由输入 $R(s)$ 写出 $E(s) = \Phi_e(s) \cdot R(s)$
3. 终值定理：$e_{ss} = \lim_{s\to 0} sE(s)$

### 4.2 题型二：同时有参考输入和扰动，求总稳态误差

**步骤**：
1. 令 $N(s)=0$，求 $\Phi_{er}(s) = \frac{E(s)}{R(s)}$
2. 令 $R(s)=0$，求 $\Phi_{en}(s) = \frac{E(s)}{N(s)}$
3. 叠加：$E(s) = \Phi_{er}(s)R(s) + \Phi_{en}(s)N(s)$
4. 终值定理：$e_{ss} = \lim_{s\to 0} sE(s)$

### 4.3 题型三：求扰动误差传递函数 $\Phi_{en}(s)$

**步骤**：
1. 令 $R(s)=0$
2. 找出从 $N(s)$ 到 $E(s)$ 的通路
3. 注意**符号**（扰动通常与输入反向作用于误差）
4. 公式：$\Phi_{en}(s) = \frac{-G_2(s)H(s)}{1 + G_1(s)G_2(s)H(s)}$（扰动在 $G_1$ 之后、$G_2$ 之前引入时）

> 若扰动引入位置不同，须重新推导。

### 4.4 题型四：判断能否消除某类输入的稳态误差

**关键判据**：看开环传函 $G_o(s)$ 在 $s=0$ 处有多少个积分环节（即系统的**型别**）。

| 型别 | 对阶跃输入 | 对斜坡输入 | 对抛物线输入 |
|------|-----------|-----------|-------------|
| 0 型 | 有差 | 无穷大 | 无穷大 |
| I 型 | **无差** | 有差 | 无穷大 |
| II 型 | 无差 | **无差** | 有差 |

> 对扰动而言，扰动引入点**之前**的积分环节数决定了扰动误差的型别。

### 4.5 常见易错点

| 易错点 | 正确做法 |
|--------|----------|
| 忘记终值定理适用条件 | $sE(s)$ 的所有极点必须在 $S$ 左半平面（稳定系统才能用终值定理） |
| 扰动传函符号搞错 | 注意信号流向：扰动经 $G_2(s)$ 到输出再反馈回误差，通常是**负号** |
| 叠加时遗漏扰动项 | 总 $E(s)$ = 参考输入引起的 + 扰动引起的 |
| 混淆 $e(t)=r(t)-y(t)$ 与 $e(t)=r(t)-b(t)$ | 标准定义：$e(t)=r(t)-b(t)$（反馈信号之差），仅在单位反馈时 $b(t)=y(t)$ |
| 扰动引入位置不同，公式不同 | 必须从结构图实际推导，不能套用固定公式 |
