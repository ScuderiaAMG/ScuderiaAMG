# 第28讲：校正综合例题

## 例1：串联校正——由Bode图确定校正装置

### 题目

最小相位系统加入串联校正前、后的开环对数幅频特性如图曲线 I、II 所示。画出串联校正装置的对数幅频特性，并写出串联校正装置的传递函数。

### 解题步骤

#### 第一步：观察校正前后曲线差异

与校正前曲线 I 相比，校正后曲线 II 有三个关键变化：

1. **起始段幅值增大** $8\,\text{dB}$
2. **在频率 $\omega = 0.7$ 处**，斜率减少 $-20\,\text{dB/dec}$（即多了一个极点）
3. **在频率 $\omega = 5$ 处**，斜率增加 $+20\,\text{dB/dec}$（即多了一个零点），恢复与原系统一致的斜率

> **通俗理解**：校正装置的对数幅频特性就是"校正后减去校正前"。低频段抬升说明增益 $K > 1$，中间段斜率下降说明有个极点，高频段斜率回升说明有个零点——整体效果是"压低高频、抬高低频"，这正是**滞后校正**的典型特征。

#### 第二步：确定校正装置参数

校正装置有 2 个转折频率：$\omega_1 = 0.7$，$\omega_2 = 5$。

起始段斜率为 $0\,\text{dB/dec}$，由低频增益：

$$20\lg K = 8 \implies K = 10^{8/20} = 2.51$$

#### 第三步：写出传递函数

$$G_c(s) = \frac{2.51\left(\dfrac{1}{5}s + 1\right)}{\left(\dfrac{1}{0.7}s + 1\right)} = \frac{2.51(0.2s + 1)}{1.43s + 1}$$

> **结论**：这是一个**滞后校正装置**。零点 $\omega_2 = 5$ 比极点 $\omega_1 = 0.7$ 更远离原点（零点频率更高），低频增益增大、高频衰减，符合滞后校正"低通滤波"的本质。

## 例2：串联校正——二阶系统的两种设计方法

### 题目

某单位反馈二阶系统单位阶跃响应曲线如图所示（$\sigma_{p0} = 40\%$，$t_{p0} = 2\,\text{s}$），设计适当的串联校正环节，使系统的单位阶跃响应满足 $\sigma_p^* \leq 20\%$，$t_s^* \leq 1.5\,\text{s}$。

### 第一步：由阶跃响应求原系统传递函数

由 $\sigma_{p0} = 40\%$，$t_{p0} = 2\,\text{s}$：

$$\zeta = \frac{-\ln\sigma_p}{\sqrt{(\ln\sigma_p)^2 + \pi^2}} = \frac{-\ln 0.4}{\sqrt{(\ln 0.4)^2 + \pi^2}} = 0.28$$

$$\omega_d = \frac{\pi}{t_p} = \frac{\pi}{2} = 1.571,\quad \omega_n = \frac{\omega_d}{\sqrt{1-\zeta^2}} = 1.636$$

原系统开环传递函数（标准二阶系统形式 $G(s) = \frac{\omega_n^2}{s(s + 2\zeta\omega_n)}$）：

$$G_0(s) = \frac{2.676}{s(s + 0.916)}$$

### 第二步：作原系统Bode图

原系统剪切频率 $\omega_{c0} = 1.636$，相角裕度 $\gamma_0 = 29.245°$。

> **通俗理解**：原系统 $\gamma_0$ 仅 $29°$，对应超调量 $40\%$，动态性能较差。校正的核心任务是**增大相角裕度**。

---

### 方法一：超前校正网络设计

#### 由时域指标转化为频域指标

利用经验公式：

$$\sigma_p = 0.16 + 0.4\left(\frac{1}{\sin\gamma} - 1\right) \leq 0.2$$

$$t_s = \frac{\pi}{\omega_c}\left[2 + 1.5\left(\frac{1}{\sin\gamma} - 1\right) + 2.5\left(\frac{1}{\sin\gamma} - 1\right)^2\right] \leq 1.5$$

解得：$\gamma^* \geq 65.38°$，$\omega_c^* \geq 4.56$。

#### 设计超前校正

取 $\omega_c^* = 4.6$，令 $\omega_m = \omega_c^*$（最大超前相角出现在新剪切频率处）。

由 $L(\omega_c^*) + 10\lg a = 0$：

$$20\lg\frac{2.676}{\omega_c^*\sqrt{1 + (0.916\omega_c^*)^2}} \approx -10\lg a$$

解得 $a \approx 55$，则：

$$T = \frac{1}{\omega_m\sqrt{a}} = 0.0293$$

幅值补偿后的超前校正网络传递函数：

$$G_c(s) = \frac{1.612s + 1}{0.0293s + 1}$$

#### 验算

校正后开环传递函数：

$$G_K(s) = \frac{2.676(1.612s + 1)}{s(s + 0.916)(0.0293s + 1)}$$

$\omega_c^* = 4.6$，相角裕度 $\gamma^* = 87.99°$，**满足设计要求**。

---

### 方法二：直接二阶系统设计法

#### 思路

校正前后均为二阶系统，可直接由性能指标确定期望的闭环传递函数，再反推校正装置。

> **通俗理解**：如果校正后仍保持二阶结构，那"期望开环传函"和"原开环传函"一除，就是校正装置——思路非常直接。

#### 计算

由 $\sigma_p^* \leq 20\%$ 取 $\sigma_p^* = 0.2$：

$$\zeta = \frac{|\ln\sigma_p|}{\sqrt{(\ln\sigma_p)^2 + \pi^2}} = 0.456$$

由 $t_s^* \leq 1.5$ 取 $t_s^* = 1.5$：

$$\omega_n = \frac{3}{t_s\zeta} = \frac{3}{1.5 \times 0.456} = 4.39$$

期望开环传递函数：

$$G_K(s) = \frac{\omega_n^2}{s(s + 2\zeta\omega_n)} = \frac{19.27}{s(s + 4)}$$

校正装置传递函数：

$$G_c(s) = \frac{G_K(s)}{G_0(s)} = \frac{7.20(s + 0.916)}{s + 4}$$

> **比较**：方法二更简洁直接，得到的校正装置结构简单（一个零点、一个极点），本质上也是超前校正。

## 例3：串联校正——超前校正的三种设计方法

### 题目

设单位反馈系统的开环传递函数为 $G_0(s) = \frac{2500K}{s(s+25)}$，要求：
- 速度误差系数 $K_v^* = 100\,\text{s}^{-1}$
- 相角裕度 $\gamma^* \geq 45°$
- 剪切频率 $\omega_c^* \geq 65\,\text{rad/s}$

### 第一步：确定增益

$$G_0(s) = \frac{100K}{s\left(\dfrac{s}{25} + 1\right)}$$

由 $K_v^* = 100\,\text{s}^{-1}$ 得 $K = 1$。

### 第二步：原系统性能

由 $\frac{2500}{\omega \cdot \omega} = 1$ 得 $\omega_{c0} = 50$，则：

$$\gamma_0 = 180° - 90° - \arctan\frac{\omega_{c0}}{25} = 27°$$

### 选择校正方式的判断

> **通俗理解**：校正后要求 $\omega_c^* \geq 65 > \omega_{c0} = 50$，即剪切频率要**提高**。滞后校正会降低 $\omega_c$，因此**不可行**。只能选择**超前校正**或**期望频率特性法**。

---

### 方法一：从相角裕度期望值出发

#### 计算所需超前相角

取补偿量 $\Delta\varphi = 10°$（因为超前校正使 $\omega_c$ 右移，原系统在新 $\omega_c$ 处相角更负，需预留裕量）：

$$\varphi_m = \gamma^* - \gamma_0 + \Delta\varphi = 45° - 27° + 10° = 28°$$

#### 求参数 $a$

$$a = \frac{1 + \sin\varphi_m}{1 - \sin\varphi_m} = \frac{1 + \sin 28°}{1 - \sin 28°} = 2.77$$

#### 求 $\omega_m$

由 $20\lg\frac{2500}{\omega \cdot \omega} = -10\lg a$，解得 $\omega_m = 64.5\,\text{rad/s}$。

#### 求 $T$

$$T = \frac{1}{\omega_m\sqrt{a}} \approx 0.0093$$

校正装置：

$$G_c(s) = \frac{0.026s + 1}{0.0093s + 1}$$

#### 验算

校正后 $G_K(s) = \frac{2500(0.026s + 1)}{s(s + 25)(0.0093s + 1)}$

由幅值条件得 $\omega_{c1} = 65$，$\gamma_1 = 49°$，**满足设计要求**。

> **注意**：若补偿量取较小值（如 $5°$），则 $\varphi_m = 23°$，$a$ 偏小，校正后相角裕度不达标。因此预留 $\Delta\varphi$ 不能太小。

---

### 方法二：从期望剪切频率出发

令 $\omega_m = \omega_c^* = 65$，由 $L(\omega_c^*) + 10\lg a = 0$：

$$20\lg\frac{100}{\omega_c^*\sqrt{1 + (\omega_c^*/25)^2}} \approx -10\lg a$$

解得 $a = 3.3$，则 $T = \frac{1}{\omega_m\sqrt{a}} = 0.0085$。

校正装置：

$$G_c(s) = \frac{0.028s + 1}{0.0085s + 1}$$

#### 验算

校正后 $\omega_{c1} = \omega_c^* = 65$（由设计保证），相角裕度：

$$\gamma_1 = 180° - 90° + \arctan(0.028 \times 65) - \arctan(0.04 \times 65) - \arctan(0.0085 \times 65) = 53° > 45°$$

**满足要求**。

#### 讨论：这种方法是否总可行？

$a = 3.3$ 时超前网络最大超前相角：

$$\varphi_m = \arcsin\frac{a-1}{a+1} = 32.34°$$

原系统在 $\omega_c^* = 65$ 处的相角为 $\varphi(65) = -159°$。

校正后相角叠加：$-159° + 32.34° = -126.66°$，距 $-180°$ 还有 $53.34°$ 的裕量（$> 45°$），因此设计有效。

> **关键判断**：如果原系统在期望剪切频率处负的相角过大（比如接近 $-180°$），则即使超前网络提供最大超前角，仍可能无法产生足够的相角裕度。此方法**并非总是可行**的。

---

### 方法三：期望频率特性法

#### 确定中频段

为保持稳态性能，低频段应与原系统重合。由 $\gamma^* \geq 45°$：

$$M_r \approx \frac{1}{\sin\gamma} \implies M_r \leq 1.414$$

取 $M_r = 1.4$。

取 $\omega_2 = 0.28\omega_c^* < \omega_c^*\frac{M_r - 1}{M_r}$，由渐近幅频特性方程：

$$20\lg 100 - 20\lg\frac{25}{1} - 40\lg\frac{0.28\omega_c^*}{25} = 0 - 20\lg\frac{0.28\omega_c^*}{\omega_c^*}$$

解得 $\omega_c^* = 94.49$。

此时与原系统交点频率为 $26.45$，取为 $\omega_2$。验证 $\omega_2 \leq \omega_c^*\frac{M_r - 1}{M_r}$，满足要求。

#### 确定高频段

当 $\omega_c^* = 94.49$ 时：

$$\omega_3 \geq \omega_c^*\frac{M_r + 1}{M_r} = 161.98$$

取 $\omega_3 = 162$，在 $\omega_3$ 处画斜率为 $-40\,\text{dB/dec}$ 的直线。

#### 校正装置

$$G_c(s) = \frac{\dfrac{1}{26.45}s + 1}{\dfrac{1}{162}s + 1}$$

是一个**超前校正装置**。

#### 验算

校正后 $G_K(s) = \frac{100\left(\dfrac{s}{26.45} + 1\right)}{s\left(\dfrac{s}{25} + 1\right)\left(\dfrac{s}{162} + 1\right)}$

$\omega_{c1} = 84.3$，$\gamma_1 = 61.6°$，**满足要求**。

## 例4：串联校正——滞后校正与期望频率特性法

### 题目

单位反馈系统 $G_0(s) = \frac{8}{s(0.5s+1)(0.25s+1)}$，要求：
- 相角裕度 $\gamma^* \geq 40°$
- 幅值裕度 $K_g^* \geq 10\,\text{dB}$
- 剪切频率 $\omega_c^* > 1\,\text{rad/s}$

### 原系统分析

由幅值条件求得 $\omega_{c0} = 3.25$：

$$\gamma_0 = 180° - 90° - \arctan(0.5\omega_c) - \arctan(0.25\omega_c) = -7.5°$$

> **通俗理解**：原系统不稳定（$\gamma_0 < 0$）。在 $\omega_{c0}$ 处相角负的斜率较大（$-60\,\text{dB/dec}$ 段），超前校正即使能提供超前角，也难以克服如此大的相角滞后。而 $\omega_{c0} = 3.25$ 已大于要求的 $\omega_c^* > 1$，故应采用**滞后校正**——降低 $\omega_c$ 到相角较好的低频区域。

---

### 超前校正的尝试（失败）

由 $\gamma^* \geq 40°$，选择 $\varphi_m = \gamma^* - \gamma_0 + \Delta\varphi = 40° + 7.5° + 12.5° = 60°$。

$$a = \frac{1 + \sin 60°}{1 - \sin 60°} \approx 14$$

由 $20\lg\frac{8}{\omega\sqrt{0.25\omega^2+1}\sqrt{0.25\omega^2+1}} \approx -10\lg a$，得 $\omega_m = 5.70\,\text{rad/s}$。

$$T = \frac{1}{\omega_m\sqrt{a}} \approx 0.047$$

校正装置 $G_c(s) = \frac{0.658s + 1}{0.047s + 1}$。

验算：$\omega_{c1} = 5.7$，$\gamma_1 = 24.5°$，**不满足要求**。

> **失败原因**：在高频段（$\omega \approx 5.7$），原系统相角已严重滞后，超前校正提供的相角补偿不足以弥补。

---

### 滞后校正设计

#### 选择新剪切频率

根据 $\gamma^* \geq 40°$ 和滞后相角的影响，选择 $\Delta\varphi = 6°$：

$$\varphi(\omega) = -180° + \gamma^* + \Delta\varphi = -134°$$

解得 $\omega_1 = 1.1\,\text{rad/s}$。

#### 求参数 $b$

$$L(\omega_1) = 20\lg\frac{8}{1.1} - 10\lg(1 + 0.5^2 \times 1.1^2) - 10\lg(1 + 0.25^2 \times 1.1^2) = 15.7\,\text{dB}$$

令 $20\lg b = -L(\omega_1)$，得 $b = 0.164$。

#### 求参数 $T$

由第二个转折频率 $\frac{1}{bT} = \frac{\omega_1}{10}$：

$$T = \frac{10}{b\omega_1} = 55.43$$

校正装置：

$$G_c(s) = \frac{9.1s + 1}{55.43s + 1}$$

#### 验算

校正后 $G_K(s) = \frac{8(9.1s + 1)}{s(0.5s + 1)(0.25s + 1)(55.43s + 1)}$

$\omega_{c1} = 1.11$：

$$\gamma_1 = 180° - 90° + \arctan(9.1 \times 1.1) - \arctan(0.5 \times 1.1) - \arctan(0.25 \times 1.1) - \arctan(55.43 \times 1.1) = 41.05° > 40°$$

由 $\varphi(\omega) = -180°$ 得 $\omega_{g1} = 2.73$：

$$K_{g1} = -20\lg|G_K(j\omega_{g1})| = 12.58\,\text{dB} > 10\,\text{dB}$$

**全部满足要求**，滞后校正装置合适。

---

### 期望频率特性法设计

#### 确定中频段参数

由 $\gamma^* \geq 40°$，$M_r \approx \frac{1}{\sin\gamma} \leq 1.56$，取 $M_r = 1.4$。

如果期望频率特性 $\omega_3 = 2$，则高频段斜率保持与原系统相同（$-60\,\text{dB/dec}$），可简化校正装置。

令 $2 \geq \omega_c^*\frac{M_r + 1}{M_r}$，则 $\omega_c^* \leq 1.17$，可行。高频段已确定。

> **通俗理解**：由于期望频率特性法基于渐近线求解，实际剪切频率一般比设计值偏小。因此尽量选择**偏大**的 $\omega_c^*$ 进行设计，取 $\omega_c^* = 1.15$。

#### 确定中频段下界

$$\omega_2 \leq \omega_c^*\frac{M_r - 1}{M_r} = 0.328$$

为保证十倍频程要求，由 $\omega_3 = 2$，取 $\omega_2 = 0.1$。

#### 确定低频段

在 $\omega_2$ 处绘制 $-40\,\text{dB/dec}$ 射线向左延伸，求与原系统的交点：

$$20\lg 8 - 20\lg\frac{\omega}{1} = 0 - 20\lg\frac{0.1}{\omega_c^*} - 40\lg\frac{\omega}{0.1}$$

交点频率 $\omega = 0.0144$，在此处绘制 $-20\,\text{dB/dec}$ 射线向左延伸，作为低频段。

#### 校正装置

$$G_c(s) = \frac{10s + 1}{69.44s + 1}$$

#### 验算

校正后 $G_K(s) = \frac{8(10s + 1)}{s(0.5s + 1)(0.25s + 1)(69.44s + 1)}$

$\omega_{c1} = 1.00$，$\gamma_1 = 44.5°$，$\omega_{g1} = 2.74$，$K_{g1} = 13.78\,\text{dB}$。

**全部满足要求**。

## 例5：串联校正——超前、滞后与期望频率特性法的综合对比

### 题目

单位反馈系统 $G_0(s) = \frac{K}{s(0.1s+1)(2s+1)}$，要求：
- $K_v^* \geq 10$
- $\gamma^* \geq 40°$

### 原系统分析

由 $K_v \geq 10$ 得 $K = 10$。

$$20\lg K - 20\lg\frac{0.5}{1} - 40\lg\frac{\omega}{0.5} = 0 \implies \omega_{c0} = 2.236$$

$$\gamma_0 = 180° - 90° - \arctan(0.1\omega_{c0}) - \arctan(2\omega_{c0}) \approx 0°$$

> **通俗理解**：原系统处于临界稳定边缘（$\gamma_0 \approx 0°$），需要大幅增加相角裕度。

---

### 超前校正尝试

选择超前相角 $\varphi_m = \gamma^* - \gamma_0 + \Delta\varphi = 40° + 0° + 15° = 55°$。

$$a = \frac{1 + \sin 55°}{1 - \sin 55°} \approx 10$$

由 $20\lg\frac{10}{\omega \times 2\omega \times 1} = -10\lg a$，得 $\omega_m = 3.98\,\text{rad/s}$。

$$T = \frac{1}{\omega_m\sqrt{a}} \approx 0.079$$

校正装置 $G_c(s) = \frac{0.79s + 1}{0.079s + 1}$。

验算：$\omega_{c1} = 3.95$，$\gamma_1 = 40.56°$，**满足要求**。

> **注意**：补偿量 $\Delta\varphi$ 需取足够大（如 $15°$），若取 $10°$ 则校正后 $\gamma$ 仅约 $37°$，不满足要求。

---

### 滞后校正尝试

由 $\gamma^* \geq 40°$，选择：

$$\varphi(\omega) = \gamma^* + 6° - 180° = -134°$$

解得 $\omega_1 = 0.44\,\text{rad/s}$。

令 $20\lg b = -20\lg|G_0(j\omega_1)|$，得 $b = 0.06$。

$$T = \frac{10}{b\omega_1} = 378.78$$

校正装置 $G_c(s) = \frac{22.73s + 1}{378.78s + 1}$。

验算：$\omega_{c1} = 0.45$，$\gamma_1 = 40.19°$，**满足要求**。

> **对比**：超前校正保持了较高的 $\omega_c$（响应快），滞后校正 $\omega_c$ 很低（响应慢但稳定裕度好）。两种方案都可行，但动态响应速度差异很大。

---

### 增加性能要求后的设计（$\gamma^* \geq 50°$，$\omega_c^* \geq 4\,\text{rad/s}$）

题目变为：$K_v^* \geq 10$，$\gamma^* \geq 50°$，$\omega_c^* \geq 4\,\text{rad/s}$。

#### 超前校正（失败）

$\varphi_m = 60°$，$a \approx 14$。原系统 $-10\lg a$ 处频率 $\omega_m = 4.33$，$T = 0.062$。

校正后 $\omega_{c1} = 4$，$\gamma_1 = 45.25°$，**不满足** $\gamma^* \geq 50°$。

#### 滞后校正（不可行）

$\omega_c^* \geq 4 > \omega_{c0} = 2.236$，滞后校正使 $\omega_c$ 更小，**不可行**。

#### 滞后-超前校正

暂时未找到可行解。

#### 期望频率特性法（成功）

由 $M_r \approx \frac{1}{\sin\gamma} \leq 1.3$，取 $M_r = 1.2$，$\omega_c^* = 5$。

$$\omega_2 \leq \omega_c^*\frac{M_r - 1}{M_r} = 0.83,\quad \omega_3 \geq \omega_c^*\frac{M_r + 1}{M_r} = 9.17$$

**中频段**：过 $\omega_c^* = 5$ 作 $-20\,\text{dB/dec}$ 直线。求与原系统交点：

$$0 - 20\lg\frac{\omega}{5} = 20\lg 10 - 20\lg\frac{0.5}{1} - 40\lg\frac{\omega}{0.5}$$

解得 $\omega = 1 > 0.83$，不能选为 $\omega_2$，取 $\omega_2 = 0.5$。

**低频段**：从 $\omega_2 = 0.5$ 作 $-40\,\text{dB/dec}$ 向左延伸：

$$0 - 20\lg\frac{0.5}{5} - 40\lg\frac{\omega}{0.5} = 20\lg 10 - 20\lg\frac{\omega}{1}$$

解得 $\omega_1 = 0.25$，画 $-20\,\text{dB/dec}$ 向左延伸与原系统重叠。

**高频段**：原系统转折频率 $10 > 9.17$，选 $\omega_3 = 10$，画 $-40\,\text{dB/dec}$ 向右延伸到 $\omega_4 = 20$，再画 $-60\,\text{dB/dec}$ 与原系统平行。

**校正装置**：

$$G_c(s) = \frac{(2s + 1)^2}{(4s + 1)(0.05s + 1)}$$

这是一个**滞后-超前校正装置**。

**验算**：

$$G_K(s) = \frac{10(2s + 1)}{s(0.1s + 1)} \cdot \frac{4s + 1}{0.05s + 1}$$

$\omega_{c1} = 4.47$，$\gamma_1 = 50.11°$，**满足所有设计要求**。

> **通俗理解**：当性能要求同时涉及高相角裕度和高剪切频率时，单独的超前或滞后校正都难以满足要求。期望频率特性法可以系统地构造出滞后-超前校正装置，兼顾低频段稳态性能和高频段动态性能。

## 补充：反馈校正

### 反馈校正的原理

除了与串联校正一样可改善系统性能外，反馈校正还能**抑制反馈环内不利因素对系统的影响**。

采用局部反馈校正的系统，校正装置反向连接在一些环节上，形成**局部反馈回路（内回路）**。

> **注意**：为保证局部回路的稳定性，被包围的环节不宜过多，一般为 **2 个**。

### 理论基础

设无反馈校正时系统开环传递函数 $G_0(s) = G_1(s)G_2(s)G_3(s)G_4(s)$。

内回路开环传递函数 $G_{lK}(s) = G_2(s)G_3(s)H(s)$。

内回路闭环传递函数 $G_{lB}(s) = \frac{G_2(s)G_3(s)}{1 + G_{lK}(s)}$。

校正后系统开环传递函数：

$$G_K(s) = G_1(s)G_{lB}(s)G_4(s) = \frac{G_0(s)}{1 + G_{lK}(s)}$$

当 $|G_{lK}(j\omega)| \gg 1$ 时：

$$G_K(j\omega) \approx \frac{G_0(j\omega)}{G_{lK}(j\omega)} = \frac{G_1(j\omega)G_4(j\omega)}{H(j\omega)}$$

> **通俗理解**：在强反馈区域，校正后系统的特性几乎**只取决于未被包围的环节 $G_1$、$G_4$ 和反馈装置 $H$**，而与被包围环节 $G_2$、$G_3$ 的参数变化无关。这就是反馈校正能抑制不利因素的原因。

### 期望频率特性法设计反馈校正的步骤

**前提条件**：内回路稳定，$G_{lB}(s)$ 的极点都在 $s$ 左半平面。

1. 绘制原系统渐近对数幅频特性曲线 $20\lg|G_0(j\omega)|$
2. 绘制期望幅频特性曲线 $20\lg|G_K(j\omega)|$（与串联校正不同，此处无需迁就原系统曲线）
3. 由 $20\lg|G_0(j\omega)| - 20\lg|G_K(j\omega)|$ 得到 $20\lg|G_{lK}(j\omega)|$ 及 $G_{lK}(s)$，**校验内回路的稳定性**
4. 根据 $G_{lK}(s) = G_2(s)G_3(s)H(s)$ 求得 $20\lg|H(j\omega)|$ 及反馈校正装置传递函数 $H(s)$
5. 校验

---

### 反馈校正例题

#### 题目

某系统结构图中，$G_1(s) = \frac{238}{0.06s+1}$，$G_2(s) = \frac{228}{0.36s+1}$，$G_3(s) = \frac{0.0208}{s}$，设计反馈校正装置使 $\sigma_p^* \leq 25\%$，$t_s^* \leq 1\,\text{s}$。

#### 第一步：原系统分析

$$G_0(s) = G_1(s)G_2(s)G_3(s) = \frac{1130}{s(0.06s + 1)(0.36s + 1)}$$

$\omega_{c0} = 36.18$，$\gamma_0 = -60.88°$（不稳定）。

#### 第二步：性能指标转化

由 $\sigma_p^*$ 和 $t_s^*$ 得频域性能指标：

$$\gamma^* \geq 54.39°,\quad M_r \leq 1.23,\quad \omega_c^* \geq 7.78$$

取 $\omega_c^* = 10$：

$$\omega_2 \leq \omega_c^*\frac{M_r - 1}{M_r} = 1.87,\quad \omega_3 \geq \omega_c^*\frac{M_r + 1}{M_r} = 18.13$$

取 $\omega_2 = 1.1$。为简化，取原转折频率 $\frac{1}{0.06}$ 为 $\omega_3 = 16.7$。

#### 第三步：绘制期望对数幅频特性

- **中频段**：过 $\omega_c^* = 10$ 作 $-20\,\text{dB/dec}$ 直线，左至 $\omega_2 = 1.1$，右至 $\omega_3 = 16.7$
- **低频段**：从 $\omega_2$ 处作 $-40\,\text{dB/dec}$ 向左与原系统相交于 $E$ 点：

$$0 - 20\lg\frac{1.1}{10} - 40\lg\frac{\omega_E}{1.1} = 20\lg 1130 - 20\lg\frac{\omega_E}{1}$$

交点频率 $\omega_E = 0.009$。

- **高频段**：从 $\omega_3$ 处作 $-40\,\text{dB/dec}$ 向右与原系统相交于 $D$ 点：

$$0 - 20\lg\frac{1/0.06}{10} - 40\lg\frac{\omega_D}{1/0.06} = 20\lg 1130 - 20\lg\frac{1/0.36}{1} - 40\lg\frac{1/0.06}{1/0.36} - 60\lg\frac{\omega_D}{1/0.06}$$

交点频率 $\omega_D = 313.89$。

#### 第四步：期望开环传递函数

$$G_K(s) = \frac{K(0.9s + 1)}{s^2(0.06s + 1)}$$

由 $20\lg K - 40\lg\frac{1/0.9}{1} - 20\lg\frac{10}{1/0.9} = 0$ 得 $K = 11.11$。

#### 第五步：内回路开环传递函数

由 $L_0 - L_K$ 得 $20\lg|G_2(j\omega)H(j\omega)|$：

$$G_2(s)H(s) = \frac{G_0(s)}{G_K(s)} = \frac{K_{lK}s}{(T_1 s + 1)(T_2 s + 1)}$$

其中 $T_1 = \frac{1}{1.1} = 0.9$，$T_2 = \frac{1}{2.78} = 0.36$。

由 $\omega_E = 0.009$ 时 $L_K(\omega_E) = 0$，可得 $K_{lK} = \frac{1}{0.009} = 111$。

$$G_2(s)H(s) = \frac{111s}{(0.9s + 1)(0.36s + 1)}$$

#### 第六步：校验内回路稳定性及近似条件

内回路显然稳定。在剪切频率处：

$$|G_2(j\omega_c^*)H(j\omega_c^*)| = \frac{111\omega_c^*}{\sqrt{(0.9\omega_c^*)^2 + 1}\sqrt{(0.36\omega_c^*)^2 + 1}} \approx \frac{111\omega_c^*}{0.9\omega_c^* \times 0.36\omega_c^*} = 34.26 \gg 1$$

满足近似条件，误差较小。

#### 第七步：反馈校正装置

$$H(s) = \frac{G_2(s)H(s)}{G_2(s)} = \frac{0.487s}{0.9s + 1}$$

#### 第八步：验算

校正后：

$$G_K(s) = \frac{G_1(s)G_2(s)G_3(s)}{1 + G_2(s)H(s)} = \frac{1130(0.9s + 1)}{s(0.06s + 1)[0.324s^2 + 112.26s + 1]}$$

$\omega_{c1} = 8.2$，$\gamma_1 = 54.79°$，$\sigma_{p1} \approx 24.96\%$，$t_{s1} \approx 0.94\,\text{s}$。

**全部满足要求**。

## 补充：PID 控制

### PID 控制概述

PID 控制在工业上广泛采用，其核心优势是：**被控对象数学模型未知时仍能实现有效设计**。

PID 控制由**比例（P）**、**积分（I）**、**微分（D）** 三种控制作用组合。

---

### 比例控制（P）

控制器传递函数：$G_c(s) = K_p$

$$u(t) = K_p \cdot e(t)$$

**对系统的影响**：
- $K_p$ 增大 → 开环增益增大 → 稳态误差降低，控制精度提高
- $K_p$ 增大 → 幅值裕度 $K_g$ 减小 → 相对稳定性下降

> **结论1**：P 控制提高控制精度，降低相对稳定性。

**示例**：对系统 $G(s) = \frac{Ke^{-\tau s}}{Ts+1}$ 施加 P 控制，单位阶跃输入的稳态误差：

$$e_{ss} = \frac{1}{1 + K_p K}$$

$K_p$ 增大则 $e_{ss}$ 降低，但 $e_{ss} \neq 0$（有差控制）。

**优点**：及时、快速。
**缺点**：稳态误差不为 0，降低相对稳定性，甚至可能导致不稳定。

---

### 积分控制（I）

控制器传递函数：$G_c(s) = \frac{K_i}{s}$

$$u(t) = K_i \int_0^t e(\tau)\,d\tau$$

**对系统的影响**：
- 提高系统型别（如 I 型 → II 型），可消除稳态误差
- 产生 $90°$ 滞后相角，稳定性变差

> **结论2**：I 作用提高控制精度（有差变无差），但稳定性变差。**很少单独使用**。

**优点**：改善稳态精度。
**缺点**：滞后相角对稳定性不利，调节缓慢、不及时。

---

### 比例微分控制（PD）

控制器传递函数：$G_c(s) = K_p(1 + T_d s)$

$$u(t) = K_p\left[e(t) + T_d \frac{de(t)}{dt}\right]$$

**对系统的影响**：
- $\angle(1 + T_d s) = \arctan(T_d\omega) > 0$，提供超前相角
- 提高系统相角裕度，改善相对稳定性

> **结论3**：D 作用主要改善动态性能。由于产生超前相角，使系统能在稳定范围内增大比例增益，从而间接改善稳态误差。微分作用**不能单独使用**。

**优点**：抑制振荡、提高稳定性。
**缺点**：对高频噪声反应迅速，容易造成误操作。

**示例**：对系统 $G(s) = \frac{1}{Js^2}$（如卫星姿态控制）：

- 采用 P 控制：$\Phi(s) = \frac{K_p}{Js^2 + K_p}$，$\zeta = 0$，**等幅振荡，临界稳定**
- 采用 PD 控制：$\Phi(s) = \frac{T_d s + 1}{\frac{J}{K_p}s^2 + T_d s + 1}$，只要 $T_d > 0$ 系统就稳定

---

### 比例积分控制（PI）

控制器传递函数：

$$G_c(s) = K_p\left(1 + \frac{1}{T_i s}\right) = \frac{K_p(T_i s + 1)}{T_i s}$$

**实质**：增加左半平面开环零点（$-1/T_i$）和位于原点的开环极点。

> **结论4**：PI 控制减小稳态误差，改善稳态性能。相角为 $-90° + \arctan(T_i\omega)$，只要 $T_i$ 足够大，就不会严重影响稳定性。

---

### PID 控制

控制器传递函数：

$$G_c(s) = K_p\left(1 + \frac{1}{T_i s} + T_d s\right)$$

$$u(t) = K_p\left[e(t) + \frac{1}{T_i}\int_0^t e(\tau)\,d\tau + T_d \frac{de(t)}{dt}\right]$$

**实质**：利用**积分作用改善稳态性能**，利用**微分作用改善动态性能**。

$\frac{1}{T_i}$ 和 $T_d$ 可看作积分和微分作用的"权系数"，权系数越大，对应作用越强。

---

### PID 参数对控制性能的影响（结论5）

| 参数 | 影响 |
|------|------|
| $K_p$ 增大 | 稳态误差下降，但稳定性下降 |
| $T_i$ 减小 | 积分作用增强，消除稳态误差能力增强，但稳定性下降 |
| $T_d$ 增大 | 微分作用增强，改善动态性能，超前作用增强，相对稳定性加强，但对高频噪声放大 |

---

### PID 参数整定方法

#### 方法一：动态响应法（齐格勒-尼柯尔斯法则）

**适用条件**：
- 被控对象的单位阶跃响应必须呈 **S 形**
- 被控对象不能包含积分环节和主导共轭复数极点
- 在**开环**条件下测得响应曲线

**步骤**：

1. 实验求得被控对象对单位阶跃输入的 S 形响应曲线
2. 做拐点切线，确定延迟时间 $\tau$ 和时间常数 $T$
3. 被控对象近似为 $G(s) = \frac{Ke^{-\tau s}}{Ts + 1}$
4. 查表确定 PID 参数

**动态响应法调整法则表**：

| 类型 | $K_p$ | $T_i$ | $T_d$ |
|------|:-----:|:-----:|:-----:|
| P | $\dfrac{T}{\tau}$ | $\infty$ | $0$ |
| PI | $0.9\dfrac{T}{\tau}$ | $3.3\tau$ | $0$ |
| PID | $1.2\dfrac{T}{\tau}$ | $2\tau$ | $0.5\tau$ |

例如 PID 控制器：

$$G_c(s) = 1.2\frac{T}{\tau}\left(1 + \frac{1}{2\tau s} + 0.5\tau s\right) = \frac{0.6T}{s}\left(s + \frac{1}{\tau}\right)^2$$

即 PID 控制器有一个位于原点的开环极点和一对位于 $-1/\tau$ 的开环零点。

---

#### 方法二：临界增益法（齐格勒-尼柯尔斯法则）

**适用条件**：$K_p$ 增大能使系统产生等幅振荡。

**步骤**：

1. 在**闭环**状态下，设 $T_i = \infty$，$T_d = 0$（即纯 P 控制器）
2. 令 $K_p$ 从 0 逐渐增大，直到系统响应**首次出现等幅振荡**，此时增益为临界增益 $K_{ps}$，振荡周期为 $T_s$
3. 查表确定 PID 参数

**临界增益法调整法则表**：

| 类型 | $K_p$ | $T_i$ | $T_d$ |
|------|:-----:|:-----:|:-----:|
| P | $0.5K_{ps}$ | $\infty$ | $0$ |
| PI | $0.45K_{ps}$ | $0.83T_s$ | $0$ |
| PID | $0.6K_{ps}$ | $0.5T_s$ | $0.125T_s$ |

PID 控制器传递函数：

$$G_c(s) = 0.6K_{ps}\left(1 + \frac{1}{0.5T_s s} + 0.125T_s s\right) = \frac{0.075K_{ps}T_s}{s}\left(s + \frac{4}{T_s}\right)^2$$

> **注意**：如果 $K_p$ 增大无法使系统产生等幅振荡，则**不能用该法**。

---

### PID 整定例题1：临界增益法

#### 题目

系统 $G(s) = \frac{1}{s(s+1)(s+5)}$，利用临界增益法确定 PID 控制器参数，使超调量不超过 $30\%$。

#### 第一步：求临界增益和振荡周期

令 $T_i = \infty$，$T_d = 0$，闭环传递函数：

$$\Phi(s) = \frac{K_p}{s(s+1)(s+5) + K_p}$$

特征方程 $s^3 + 6s^2 + 5s + K_p = 0$。

劳斯表：

| $s^3$ | $1$ | $5$ |
| $s^2$ | $6$ | $K_p$ |
| $s^1$ | $\frac{30 - K_p}{6}$ | |
| $s^0$ | $K_p$ | |

等幅振荡条件：$\frac{30 - K_p}{6} = 0 \implies K_{ps} = 30$。

由 $6s^2 + 30 = 0$ 得 $s_{1,2} = \pm j\sqrt{5}$。

振荡频率 $\omega = \sqrt{5}$，振荡周期 $T_s = \frac{2\pi}{\sqrt{5}} = 2.81$。

#### 第二步：查表得 PID 参数

$$G_c(s) = \frac{0.075 \times 30 \times 2.81}{s}\left(s + \frac{4}{2.81}\right)^2 = \frac{6.3(s + 1.4)^2}{s}$$

#### 第三步：验算与微调

将该控制器加入系统，超调量为 $62\%$，**不满足** $30\%$ 的要求，需要微调。

微调方案：
- **方案一**：保持 $K_p$ 不变，将零点从 $-1.4$ 移到 $-0.6$，超调量约 $20\%$
- **方案二**：零点不动，调整 $K_p$ 到 $39.42$，超调量约 $28\%$

> **通俗理解**：齐格勒-尼柯尔斯法则保证峰值与第二峰值之比为 4:1（超调量约 $10\% \sim 60\%$），只是一个**粗略的起始点**。要精确满足性能指标，还需根据 P、I、D 各自的功能进行**参数微调**。

---

### PID 整定例题2：时域分析法整定 PID

#### 题目

单位反馈系统 $G_0(s) = \frac{20}{s(0.2s+1)}$，要求 $\sigma_p \leq 5\%$，$t_s \leq 1.5\,\text{s}$（$\Delta = 5\%$）。判断能否用动态响应法或临界增益法进行 PID 整定？如果不行，用时域分析方法整定。

#### 原系统性能

无 PID 控制（$G_c = 1$）时：$\zeta = 0.25$，$\omega_n = 10$，$\sigma_p = 44.4\%$，不满足。

#### 能否用实验法？

- **动态响应法**：由于存在积分环节，阶跃响应不是 S 形 → **不可用**
- **临界增益法**：设 $G_c = K_p$，闭环特征方程 $s^2 + 5s + 100K_p = 0$。劳斯表第一列元素恒正，$K_p$ 增大无法使系统等幅振荡 → **不可用**

#### 时域分析法整定

取 $\sigma_p = 4.32\%$（对应 $\zeta = 0.707$），$t_s = 1.5$：

$$\zeta = 0.707,\quad \omega_n = \frac{3}{t_s\zeta} = 2.83$$

校正后主导极点：

$$s_{1,2} = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2} = -2 \pm j2$$

施加 PID 控制后的开环传递函数：

$$G_K(s) = \frac{100}{s(s+5)} \cdot \frac{K_p(T_i T_d s^2 + T_i s + 1)}{T_i s}$$

闭环特征方程：

$$T_i s^3 + (100K_p T_i T_d + 5T_i)s^2 + (100K_p T_i)s + 100K_p = 0$$

由主导极点得因式 $(s^2 + 4s + 8)$，设另一极点为 $-20a$（$a \geq 1$ 保证主导地位）：

$$s^3 + (4 + 20a)s^2 + (8 + 80a)s + 160a = 0$$

对应系数相等，当 $a = 1$ 时：

$$K_p = 1.6,\quad T_i = 0.55,\quad T_d = 0.241$$

即为所设计的 PID 控制器参数。

## 校正方法选择总结

### 串联校正方式选择

| 校正方式 | 适用场景 | 核心效果 | 局限性 |
|----------|---------|---------|--------|
| **超前校正** | $\omega_c$ 需提高，原系统在高频段相角不至于太负 | 增大相角裕度，提高 $\omega_c$，加快响应 | 若高频段相角已严重滞后，则无法提供足够补偿 |
| **滞后校正** | $\omega_c$ 允许降低，原系统在低频段相角较好 | 降低 $\omega_c$ 到相角好的区域，提高 $\gamma$ | $\omega_c$ 下降导致响应变慢，带宽变窄 |
| **滞后-超前校正** | 同时需要高 $\gamma$ 和高 $\omega_c$ | 兼顾低频稳态和高频动态 | 结构复杂，参数多 |
| **期望频率特性法** | 综合设计，可系统地构造校正装置 | 系统化方法，直接构造期望特性 | 基于渐近线，需验算 |

### 反馈校正 vs 串联校正

| 对比维度 | 串联校正 | 反馈校正 |
|---------|---------|---------|
| 结构 | 串在前向通道中 | 构成局部反馈回路 |
| 抗干扰 | 不能抑制环内参数变化 | **可抑制环内不利因素** |
| 设计方法 | Bode 图叠加 | 期望频率特性法（$L_0 - L_K$） |
| 注意事项 | — | 需校验内回路稳定性和 $|G_{lK}| \gg 1$ |

### PID 控制的作用总结

| 控制作用 | 传递函数 | 实质 | 主要改善 |
|---------|---------|------|---------|
| P | $K_p$ | 增益调节 | 稳态精度（但降低稳定性） |
| I | $K_i/s$ | 增加原点极点 | 稳态精度（有差变无差） |
| D | $K_p T_d s$ | 增加超前相角 | 动态性能（阻尼、稳定性） |
| PI | $K_p(1 + 1/T_i s)$ | 增加原点极点+左半零点 | 稳态性能 |
| PD | $K_p(1 + T_d s)$ | 增加左半零点 | 动态性能 |
| PID | $K_p(1 + 1/T_i s + T_d s)$ | 综合三种作用 | 稳态+动态全面改善 |

## 设计流程对比表

### 串联校正设计流程

```
① 确定开环增益 K（满足稳态误差要求）
        ↓
② 绘制原系统 Bode 图，求 ω_c0 和 γ_0
        ↓
③ 选择校正方式：
   ├─ ω_c* > ω_c0 → 超前校正
   ├─ ω_c* < ω_c0 → 滞后校正
   ├─ 两者都不行 → 滞后-超前 / 期望频率特性法
   └─ 不确定 → 期望频率特性法（通用）
        ↓
④ 设计校正装置参数
   ├─ 超前：φ_m = γ* - γ_0 + Δφ → a → T
   ├─ 滞后：φ(ω) = -180° + γ* + Δφ → ω_1 → b → T
   └─ 期望频率特性法：确定 ω_2, ω_3, ω_c* → 构造 L_K
        ↓
⑤ 写出 G_c(s)，验算校正后 γ, K_g, ω_c
        ↓
⑥ 若不满足 → 调整参数或换方法
```

### 期望频率特性法设计流程

```
① 确定低频段：与原系统重合（保持稳态性能）
        ↓
② 确定中频段：
   - 由 γ* → M_r → ω_2, ω_3 的范围
   - 过 ω_c* 作 -20dB/dec 直线
   - ω_2 ≤ ω_c*·(M_r-1)/M_r
   - ω_3 ≥ ω_c*·(M_r+1)/M_r
        ↓
③ 确定高频段：尽量与原系统平行（简化校正装置）
        ↓
④ 确定低频连接段：-40dB/dec 过渡
        ↓
⑤ G_c(s) = G_K(s)/G_0(s)，验算
```

### PID 整定方法对比

| 方法 | 条件 | 适用性 | 精度 |
|------|------|--------|------|
| 动态响应法 | S 形阶跃响应，无积分环节 | 受限 | 粗略，需微调 |
| 临界增益法 | 能产生等幅振荡 | 受限 | 粗略，需微调 |
| 时域分析法 | 已知传递函数 | 通用 | 精确 |
| 频域设计法 | 已知 Bode 图 | 通用 | 精确 |
