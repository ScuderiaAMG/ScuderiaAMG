## 一、前测习题精讲（期末常见题型）

### 测试1：由性能指标反求极点位置

**题目**：二阶系统要求 $\zeta = \frac{1}{\sqrt{2}}$，$t_s = 0.5$（$\Delta = 2\%$），求极点位置。

**解**：

由 $t_s \approx \frac{4}{\zeta\omega_n} = 0.5$ 得 $\zeta\omega_n = 8$

由 $\zeta = \frac{1}{\sqrt{2}}$ 得 $\omega_n = 8\sqrt{2}$

则 $s_{1,2} = -\zeta\omega_n \pm j\omega_n\sqrt{1-\zeta^2} = -8 \pm j8$

---

### 测试2：由性能指标反求系统参数

**题目**：系统结构图如下，要求 $\sigma_p = 20\%$，$t_p = 1\text{s}$，确定参数 $k$ 和 $\tau$，并计算 $t_r$、$t_s$。

```
R(s) → [k/(s+1)] → [τs+1] → C(s)
              ↑__________________|
```

**解**：

1. 闭环传递函数：$\Phi(s) = \frac{k}{s^2 + (1+k\tau)s + k}$

2. 对比标准形式得：$\omega_n = \sqrt{k}$，$\zeta = \frac{1+k\tau}{2\sqrt{k}}$

3. 由 $\sigma_p = e^{-\pi\zeta/\sqrt{1-\zeta^2}} = 0.2$ → $\zeta = 0.456$

4. 由 $t_p = \frac{\pi}{\omega_n\sqrt{1-\zeta^2}} = 1$ → $\omega_n = 3.53$

5. 则 $k = \omega_n^2 = 12.46$，$\tau = \frac{2\zeta\omega_n - 1}{k} = 0.178$

6. $t_r = \frac{\pi - \theta}{\omega_d} = 0.651$，$t_s = \frac{3}{\zeta\omega_n} = 1.864$（$\Delta=5\%$）或 $\frac{4}{\zeta\omega_n} = 2.485$（$\Delta=2\%$）

---

### 测试3：增益 $K$ 对动态性能的影响

**题目**：单位反馈系统 $G(s) = \frac{5K}{s(s+34.5)}$，比较 $K = 13.5, 200, 1500$ 时的动态性能。

**解**：闭环传函 $\Phi(s) = \frac{5K}{s^2 + 34.5s + 5K}$

| $K$ | $\omega_n$ | $\zeta$ | $t_p$ | $\sigma_p$ | $t_s$ | 状态 |
|-----|------------|---------|-------|------------|-------|------|
| 13.5 | 8.22 | 2.10 | $\infty$ | 0 | 1.44 | 过阻尼（降为一阶近似） |
| 200 | 31.6 | 0.546 | 0.12 | 13% | 0.174 | 欠阻尼 |
| 1500 | 86.2 | 0.2 | 0.037 | 52.7% | 0.174 | 欠阻尼 |

> **关键规律（重点）**：
> - $K$ 增大 → $\sigma_p$ 增大，$t_p$ 减小，$t_s$ **不变**（欠阻尼时，实部 $\zeta\omega_n$ 不变）
> - $K$ 减小 → $\sigma_p$ 减小，$t_p$ 增大，过阻尼时 $t_s$ 增大
> - **结论**：仅靠比例调节（调节 $K$），难以**兼顾**快速性和平稳性

---

### 测试4：在 $S$ 平面上绘制满足性能指标的极点区域

**题目**：已知单位反馈系统开环传函 $G(s) = \frac{\omega_n^2}{s(s+2\zeta\omega_n)}$，在 $S$ 平面上绘制满足以下条件的闭环特征根分布区域：

**(1)** $0.707 \leq \zeta < 1$ 且 $\omega_n \geq 2$

**解**：由 $\theta = \arccos\zeta$ 得 $0° < \theta \leq 45°$（$\zeta=0.707$ 对应 $\theta=45°$），$\omega_n = |s_{1,2}| \geq 2$。区域为 $\theta \in (0°, 45°]$ 且 $r \geq 2$ 的扇形（除去实轴）。

**(2)** $t_p \leq 0.5$ 且 $1 \leq t_s \leq 1.2$（$\Delta = 2\%$）

**解**：由 $t_p = \frac{\pi}{\omega_d}$ 得 $\omega_d \geq 6.283$（虚部约束）；由 $t_s = \frac{4}{\zeta\omega_n}$ 得 $3.333 \leq \zeta\omega_n \leq 4$（实部约束）。区域为 $\omega_d \geq 6.283$ 和 $3.333 \leq \sigma \leq 4$ 交叠的带状区域。

## 二、高阶系统的时域响应

### 2.1 高阶系统的数学模型

闭环传递函数：

$$\Phi(s) = \frac{k(s - z_1)(s - z_2)\cdots(s - z_m)}{(s - p_1)(s - p_2)\cdots(s - p_n)}$$

当闭环极点全在 $S$ 平面左半部时，系统稳定。

设系统有 $q$ 个互不相同的实极点 $p_j$，$r$ 对互不相同的复极点 $-\zeta_l\omega_{nl} \pm \omega_{nl}\sqrt{\zeta_l^2-1}$。

### 2.2 高阶系统单位阶跃响应的一般形式（重点）

$$c(t) = a_0 + \sum_{j=1}^{q} a_j e^{-p_j t} + \sum_{l=1}^{r} b_l e^{-\zeta_l\omega_{nl}t}\cos(\omega_{nl}\sqrt{1-\zeta_l^2}\,t) + \sum_{l=1}^{r} c_l e^{-\zeta_l\omega_{nl}t}\sin(\omega_{nl}\sqrt{1-\zeta_l^2}\,t)$$

| 分量 | 含义 |
|------|------|
| $a_0$ | **稳态分量** |
| $\sum a_j e^{-p_j t}$ | **一阶环节的动态分量**（实极点贡献） |
| 后两项 | **二阶环节的动态分量**（共轭复极点贡献） |

> **结论1**：高阶系统的单位阶跃响应 = 一阶和二阶环节响应的**叠加**。
> 各分量的相对大小由**系数**和**衰减快慢**两个因素决定。

### 2.3 高阶系统动态响应的四个重要结论（重点）

**结论2：衰减速度与极点位置的关系**

> 离虚轴越远（$p_j$ 和 $\zeta_l\omega_{nl}$ 越大）的闭环极点，其对应动态响应分量**衰减越快**。

**结论3：偶极子（Dipole）**

> 距离很近的零、极点对称为**偶极子**。若一对零极点的位置十分靠近，该极点对应的系数会**非常小**，从而该极点所对应的响应分量对系统的过渡过程**几乎没有影响**。

**结论4：主导极点（Dominant Pole）——核心概念**

> 如果离虚轴**最近**的极点**附近没有零点**，且**其余极点都远离虚轴**，则该闭环极点所对应的动态分量在系统响应过程中起**主要作用**，称为**主导极点**。主导极点对应的分量衰减最慢。

- 高阶系统一般具有振荡性，主导极点往往是**共轭复极点**
- 主导极点的**实部绝对值应为其他极点的 1/5 或更小**（越小近似精度越高）
- 工程中常采用主导极点对系统进行**降阶近似**：只保留一、二个主导极点，将高阶系统近似成一阶或二阶系统分析

## 三、主导极点近似法（解题通用方法）

### 3.1 近似步骤

1. 求闭环传递函数的所有极点
2. 识别主导极点（距虚轴最近，实部绝对值 ≤ 其他极点实部绝对值的 1/5）
3. 检查主导极点附近有无零点（偶极子可对消）
4. 保留主导极点，略去非主导极点，构造降阶传递函数
5. **保持稳态增益不变**（即 $\Phi(0)$ 不变）调整增益
6. 对降阶后的低阶系统按一阶/二阶方法分析

### 3.2 例题1.1

闭环传函零点为 $s = -20.06$，极点为 $p_1 = -20$，$p_2 = -60$，$p_{3,4} = -10 \pm j71.4$。

- 主导极点：$p_{3,4} = -10 \pm j71.4$（实部 -10）
- $p_1 = -20$ 的实部是主导极点的 2 倍，可考虑忽略
- $p_2 = -60$ 远离虚轴（6 倍），可忽略
- 偶极子：$z = -20.06$ 与 $p_1 = -20$ 距离很近，相互抵消

近似传递函数：$\Phi'(s) \approx \frac{5.2 \times 10^3}{s^2 + 20s + 5.2 \times 10^3}$，$\omega_n = 72.11$，$\zeta = 0.139$

### 3.3 例题1.2

单位反馈系统 $G(s) = \frac{10}{s(0.5s+1)(0.2s+1)}$

闭环极点：$s_1 = -5.52$，$s_{2,3} = -0.74 \pm j1.133$

- 主导极点：$s_{2,3} = -0.74 \pm j1.133$（实部 $-0.74$）
- $s_1 = -5.52$ 的实部 ≈ 主导极点的 7.5 倍，可忽略
- 主导极点附近没有零点

近似传递函数：$\Phi'(s) = \frac{1.83}{s^2 + 1.48s + 1.83}$，$\omega_n = 1.353$，$\zeta = 0.547$

性能指标：$t_r = 1.9$，$t_p = 2.77$，$\sigma_p = 12.8\%$，$t_s \approx 4.05 \sim 5.4$

## 四、增加零极点对系统动态性能的影响（重点）

### 4.1 对比实验

三系统对比（由同一低阶系统 $G_0 = \frac{10}{s^2+6s+25}$ 加减零极点得到）：

| 系统 | $\sigma_p$ | $t_s$ | 变化 |
|------|------------|-------|------|
| $G_{B1}$（原二阶） | 37% | 1.6 | 基准 |
| $G_{B2}$（加零点） | 54.5% | 1.48 | $\sigma_p \uparrow$，$t_s \downarrow$ |
| $G_{B3}$（加极点） | 5.5% | 1.4 | $\sigma_p \downarrow$，$t_s \uparrow$（此处因非主导极点） |

### 4.2 结论（重点记忆）

> **结论1：增加极点** → 超调量**减小**，调节时间**增加**。
> 原因：极点具有**滤波（阻尼）作用**，输出经滤波后振荡减弱。

> **结论2：增加零点** → 超调量**加大**，响应初期速度**加快**。
> 原因：零点具有**微分作用**。

### 4.3 附加极点位置的影响

对三阶系统 $\Phi(s) = \frac{1}{(s^2+s+1)(Ts+1)}$ 取不同 $T$：

- $T$ 大（附加极点靠近虚轴，实部小）→ 滤波作用大，振荡明显减弱
- $T$ 小（附加极点远离虚轴，实部大）→ 滤波作用小，接近原二阶响应

## 五、$S$ 平面区域与性能指标的对偶关系（题型四拓展）

| 性能指标约束 | $S$ 平面区域特征 |
|-------------|-----------------|
| $\zeta \geq \zeta_0$ | 等阻尼线 $\theta \leq \arccos\zeta_0$（扇形区域） |
| $\omega_n \geq c$ | 极点模 $|s| \geq c$（圆外区域） |
| $\sigma = \zeta\omega_n \geq a$ | 实部 $\leq -a$（左半平面带状区域左侧） |
| $\omega_d \geq b$ | 虚部 $|\text{Im}(s)| \geq b$（水平带状区域外侧） |
| $t_s \leq T$（$\Delta=2\%$） | $\zeta\omega_n \geq \frac{4}{T}$ |
| $t_p \leq \tau$ | $\omega_d \geq \frac{\pi}{\tau}$ |
| $\sigma_p \leq \sigma_0$ | $\zeta \geq$ 由 $\sigma_0$ 反解的值 |

## 六、题目解题通法

### 6.1 题型一：高阶系统降阶（主导极点法）

**步骤**：
1. 求所有闭环极点
2. 找出离虚轴最近的极点（主导极点候选）
3. 检查主导极点附近是否有零点（偶极子可对消）
4. 确认非主导极点实部绝对值 ≥ 主导极点实部绝对值的 **5 倍**
5. 略去非主导极点，保持 $\Phi(0)$ 不变构造降阶传函
6. 按一阶/二阶方法求性能指标

### 6.2 题型二：分析零极点增减对性能的影响

**步骤**：
1. 确定基准系统
2. 识别新增的是零点还是极点
3. 零点 → $\sigma_p \uparrow$（微分加快响应，但增大超调）
4. 极点 → $\sigma_p \downarrow$（滤波抑制振荡，但可能延长调节时间）

### 6.3 题型三：由性能指标绘制 $S$ 平面极点区域

**步骤**：
1. 将每个性能指标要求转化为对 $\zeta$、$\omega_n$、$\zeta\omega_n$、$\omega_d$ 的约束
2. 在 $S$ 平面上分别画出每个约束对应的区域（扇形、圆、带状）
3. 取**交集**

### 6.4 题型四：由性能指标反求系统参数（综合题）

**步骤**：
1. 写出闭环传函的标准形式
2. 由 $\sigma_p$ 反解 $\zeta$
3. 由 $t_s$ 或 $t_p$ 反解 $\omega_n$
4. 对照传函系数，解出物理参数（$K$、$\tau$ 等）

### 6.5 常见易错点

| 易错点 | 正确做法 |
|--------|----------|
| 降阶后忘记保持稳态增益 | 必须调整 $\Phi'(0) = \Phi(0)$ |
| 任意对消零极点 | 必须是**距离很近**的偶极子（在同一数量级内），且均在左半平面 |
| 把非主导极点全部删去 | 只删去满足"5 倍以上"条件的极点 |
| 混淆零极点的作用 | 零点→微分（加快+增大超调）；极点→滤波（抑制振荡+可能减慢） |
| 过阻尼时套用欠阻尼公式 | 过阻尼用一阶近似或过阻尼解析公式 |
| $\zeta\omega_n$ 不变时 $t_s$ 不变 | 仅欠阻尼下工程近似公式成立 |

## 七、本讲知识框架

```
高阶系统动态性能分析
├── 高阶系统响应分解

│   └── 叠加原理
├── 四个重要结论
│   ├── 结论1：响应 = 一阶+二阶叠加
│   ├── 结论2：极点越远离虚轴，衰减越快
│   ├── 结论3：偶极子（零极点相近 → 影响可忽略）
│   └── 结论4：主导极点（离虚轴最近，实部为其他的1/5以下）
├── 主导极点近似法
│   ├── 识别主导极点
│   ├── 对消偶极子
│   ├── 略去非主导极点
│   ├── 保持稳态增益不变
│   └── 降阶后分析（一阶/二阶法）
├── 零极点增减影响
│   ├── 加零点：σp↑，初始响应↑（微分作用）
│   └── 加极点：σp↓，ts可能↑（滤波/阻尼作用）
├── S平面区域←→性能指标

    ├── 主导极点降阶法

    ├── S平面区域绘制
    └── 性能指标反求参数
```
