# 第26讲：串联滞后-超前校正

## 三、串联滞后-超前校正

### 3.1 为什么需要滞后-超前校正？

回顾前面学过的两种串联校正方式：

**串联超前校正**：
- ✅ 提高相角裕度（系统更"稳"）
- ✅ 剪切频率变大，快速性变好（系统更"快"）
- ❌ 高频段右移，抗干扰（高频噪声）能力降低

**串联滞后校正**：
- ✅ 降低剪切频率以提高相角裕度
- ✅ 间接提高开环放大系数，改善稳态性能
- ✅ 高频段左移，抗干扰能力提高
- ❌ 牺牲了快速性

> **通俗理解**：超前校正是"踩油门"——让系统反应更快，但容易引入噪声；滞后校正是"踩刹车"——让系统更稳但变慢。当单独使用任一种方法都无法满足要求时，就把两种方法**结合起来**——既要稳又要快，这就是**滞后-超前校正**。

有时单独采用串联超前校正或串联滞后校正都无法奏效，需要综合两种方法进行系统校正。

---

### 3.2 滞后-超前校正的核心思想

> **核心思想**：
> - **滞后校正**主要用来校正开环频率的**低频区**特性（改善稳态性能）
> - **超前校正**主要用于改变**中频区**特性的形状和参数（改善动态性能）

**注意事项**：
1. 在确定**超前**校正装置时，要考虑到滞后装置加入后对系统动态性能的影响，参数选择应**留有裕量**
2. 在确定**滞后**校正装置时，尽量**不影响**由超前装置校正好了的系统的动态指标

---

### 3.3 设计方法概述

根据对剪切频率 $\omega_c^*$ 的要求不同，有两种设计方法：

| 方法 | 适用场景 | 核心思路 |
|------|---------|---------|
| **法1** | $\omega_c^*$ 有**下界**要求（$\omega_c^* \geq$ 某值） | 先设计超前校正，再设计滞后校正 |
| **法2** | $\omega_c^*$ 有**精确值**要求（$\omega_c^*$ = 某值 $\pm$ 容差） | 在期望剪切频率处配置相角和幅值 |

---

## 四、法1：先超前后滞后（$\omega_c^*$ 有下界要求）

### 4.1 法1 设计思路

> **通俗理解**：
> 1. 先用超前校正"猛踩油门"——把相角裕度尽量提高（提供最大超前相角 $\varphi_m = 60°$）
> 2. 再用滞后校正"轻踩刹车"——把剩下不够的相角裕度补上，同时尽量不影响已校正好的动态指标

**具体分配方式**：
- 需要增加的总相位 = $\gamma^* - \gamma_0 + \Delta\varphi$（$\Delta\varphi$ 为补偿量）
- 一部分由**超前校正**完成（取 $\varphi_m = 60°$，充分利用超前能力）
- 另一部分由**滞后校正**完成（弥补剩余的相角差）

---

### 4.2 法1 完整设计步骤（8步）

```
① 根据稳态性能要求，确定开环放大系数 K
        ↓
② 绘制原系统 Bode 图，计算剪切频率 ω_c0 和相角裕度 γ_0
        ↓
③ 令 φ_m = 60°，由 a = (1+sinφ_m)/(1-sinφ_m) 计算 a
        ↓
④ 计算 L_0(ω) = -10lg(a) 处的频率 ω_1，令 ω_m = ω_1
        ↓
⑤ 由 ω_m = 1/(T_m√a) 计算 T_m，得到超前校正网络 G_c1(s) = (aT_m s + 1)/(T_m s + 1)
   以及校正后系统 G_K1(s) = G_c1(s)·G_0(s)
        ↓
⑥ 选择补偿量 Δφ（通常取 5°~6°），计算 G_K1(s) 相角
   φ_K1(ω) = -180° + γ* + Δφ 处的频率 ω_2
        ↓
⑦ 令 20lg(b) + 20lg|G_K1(jω_2)| = 0 得 b
   令 10/(bT_b) = ω_2 得 T_b
   则滞后校正网络 G_c2(s) = (bT_b s + 1)/(T_b s + 1)
        ↓
⑧ 验算。校正后 G_K(s) = G_c2(s)·G_c1(s)·G_0(s)
```

### 4.3 例1：先超前后滞后设计（$\omega_m$ 由幅值条件确定）

#### 题目

已知单位反馈系统的开环传函：

$$G_0(s) = \frac{K}{s(s+1)(s+2)}$$

要求系统满足下列性能指标：
1. 稳态速度误差系数 $K_v^* = 10\ \text{s}^{-1}$
2. 相角裕度 $\gamma^* \geq 50°$，剪切频率 $\omega_c^* \geq 1\ \text{rad/s}$

设计串联校正装置。

#### 解题过程

**(0) 确定开环放大系数**

对于 I 型系统，稳态速度误差系数：

$$K_v = \lim_{s \to 0} s \cdot G_0(s) = \lim_{s \to 0} s \cdot \frac{K}{s(s+1)(s+2)} = \frac{K}{2}$$

由 $K_v^* = 10$，得 $K = 20$。

**(1) 绘制原系统 Bode 图，计算 $\omega_{c0}$ 和 $\gamma_0$**

$$G_0(s) = \frac{20}{s(s+1)(s+2)}$$

在剪切频率处 $|G_0(j\omega_{c0})| = 1$，由近似计算：

$$\frac{20}{\omega \cdot \omega \cdot \omega} = 1 \implies \omega_{c0} = \sqrt[3]{20} \approx 2.71\ \text{rad/s}$$

> 注：此处因为在 $\omega_{c0} = 2.71$ 处，$\omega \gg 1$ 且 $\omega > 2$，三个环节均按 $-20\text{dB/dec}$ 衰减，故近似为 $\omega^3$。

相角裕度：

$$\gamma_0 = 180° + \angle G_0(j\omega_{c0}) = 180° - 90° - \arctan(2.71) - \arctan\left(\frac{2.71}{2}\right) \approx -33°$$

> $\gamma_0 = -33°$，系统不稳定（相角裕度为负），需要校正。

**(2) 选择校正方式**

- **超前校正？** 需提供 $50° + 33° + \Delta\varphi \approx 90°$ 的超前相角 → 单级超前校正**无法提供**这么大相角（最大约 $55°$），**不合适**。
- **滞后校正？** 取 $\Delta\varphi = 6°$，由 $\varphi(\omega) = -180° + 50° + 6° = -124°$ 求出 $\omega_1 = 0.42\ \text{rad/s}$，剪切频率太低，**不合适**。
- → 考虑用**滞后-超前校正**。

**(3) 先设计超前校正部分**

取 $\varphi_m = 60°$（充分利用超前校正的相角提供能力）。

由公式：

$$a = \frac{1 + \sin\varphi_m}{1 - \sin\varphi_m} = \frac{1 + \sin 60°}{1 - \sin 60°} = \frac{1 + 0.866}{1 - 0.866} = \frac{1.866}{0.134} \approx 13.928$$

确定 $\omega_m$：在超前校正中，$\omega_m$ 处的幅值提升为 $10\lg a$，因此需要找到原系统幅值为 $-10\lg a$ 的频率：

$$20\lg\frac{20}{\omega \cdot \omega \cdot \omega} = -10\lg a = -10\lg 13.928 \approx -11.44\ \text{dB}$$

解得 $\omega_m = 4.210\ \text{rad/s}$。

由 $\omega_m = \frac{1}{T_m\sqrt{a}}$ 求得：

$$T_m = \frac{1}{\omega_m \sqrt{a}} = \frac{1}{4.210 \times \sqrt{13.928}} = \frac{1}{4.210 \times 3.732} \approx 0.0636\ \text{s}$$

进行幅值衰减补偿后的超前校正装置为：

$$G_{c1}(s) = \frac{aT_m s + 1}{T_m s + 1} = \frac{13.928 \times 0.0636 s + 1}{0.0636 s + 1} = \frac{0.886s + 1}{0.0636s + 1}$$

串联超前校正后系统的开环传递函数：

$$G_{K1}(s) = G_{c1}(s) \cdot G_0(s) = \frac{20(0.886s + 1)}{s(s+1)(s+2)(0.0636s + 1)}$$

超前校正后的效果：
- 剪切频率 $\omega_{c1} = 4.21\ \text{rad/s}$
- 相角裕度 $\gamma_1 = 8.775°$

> **分析**：超前校正后相角裕度从 $-33°$ 提高到了 $8.775°$，但效果仍然微弱——因为在 $\omega_{c1} = 4.21$ 处，原系统相角负向增长速度很快（三个惯性环节叠加），超前校正提供的相角不足以达到 $50°$ 的要求。

**(4) 再设计滞后校正部分**

用滞后网络将相位裕度进一步提高到 $50°$。

取补偿量 $\Delta\varphi = 5°$（滞后校正在 $\omega_2$ 处会引入少量负相角，需预留裕量）。

令 $G_{K1}(s)$ 的相角等于目标值：

$$\varphi_{K1}(\omega) = -180° + \gamma^* + \Delta\varphi = -180° + 50° + 5° = -125°$$

解方程：

$$-90° - \arctan(\omega) - \arctan\left(\frac{\omega}{2}\right) - \arctan(0.886\omega) + \arctan(0.0636\omega) = -125°$$

> 注：超前网络分母 $0.0636s+1$ 引入负相角 $-\arctan(0.0636\omega)$，上式中写为其绝对值形式 $\arctan(0.0636\omega)$（前面已有负号）；分子 $0.886s+1$ 引入正相角 $+\arctan(0.886\omega)$。

解得 $\omega_2 = 1.05\ \text{rad/s}$。

由幅值条件求 $b$：在 $\omega_2$ 处，滞后校正需要将幅值衰减到 $0\ \text{dB}$：

$$20\lg b = -20\lg|G_{K1}(j\omega_2)| \implies b = 0.126$$

由 $\frac{10}{bT_b} = \omega_2$ 求得：

$$T_b = \frac{10}{b \cdot \omega_2} = \frac{10}{0.126 \times 1.05} \approx 75.59\ \text{s}$$

串联滞后校正网络的传递函数：

$$G_{c2}(s) = \frac{bT_b s + 1}{T_b s + 1} = \frac{0.126 \times 75.59 s + 1}{75.59 s + 1} = \frac{9.524s + 1}{75.59s + 1}$$

**(5) 合成滞后-超前校正网络**

$$G_c(s) = G_{c1}(s) \cdot G_{c2}(s) = \frac{(0.886s + 1)(9.524s + 1)}{(0.0636s + 1)(75.59s + 1)}$$

**(6) 验算**

校正后系统开环传递函数：

$$G_K(s) = G_{c2}(s) \cdot G_{c1}(s) \cdot G_0(s) = \frac{20(0.886s + 1)(9.524s + 1)}{s(s+1)(s+2)(0.0636s + 1)(75.59s + 1)}$$

- 剪切频率 $\omega_{c2} = 1.05\ \text{rad/s} \geq 1\ \text{rad/s}$ ✅
- 相角裕度 $\gamma_2 = 50.026° \geq 50°$ ✅

> **满足设计要求！**

---

### 4.4 关于 $\omega_m$ 配置的讨论

**问题**：超前部分的设计中，是否必须将最大超前相角 $\varphi_m$ 配置在剪切频率处（即 $\omega_m = \omega_1$，由幅值条件确定）？

**回答**：**不一定！** 因为滞后校正部分有幅值衰减作用，必然会改变超前校正后的剪切频率。而且正如上例所示，如果相角负向增长速度快，将 $\omega_m$ 配置在较高频率处会**削弱**相角超前作用。

**最佳配置**：最大超前相角 $\varphi_m$ 配置在何处最好，**受期望剪切频率 $\omega_c^*$ 的限制**。

---

### 4.5 例1 变体：$\omega_m$ 直接配置在原剪切频率处

#### 题目（同上）

$$G_0(s) = \frac{20}{s(s+1)(s+2)},\quad \gamma^* \geq 50°,\quad \omega_c^* \geq 1\ \text{rad/s}$$

$\omega_{c0} = 2.71\ \text{rad/s}$，$\gamma_0 = -33°$。

#### 解题过程

**(1) 先设计超前校正**

仍取 $\varphi_m = 60°$，$a = 13.928$。

**关键区别**：直接将 $\varphi_m$ 叠加到**当前剪切频率**处，即令：

$$\omega_m = \omega_{c0} = \frac{1}{T_m\sqrt{a}} = 2.71\ \text{rad/s}$$

解得：

$$T_m = \frac{1}{2.71 \times \sqrt{13.928}} = \frac{1}{2.71 \times 3.732} \approx 0.099\ \text{s}$$

幅值补偿后超前校正装置：

$$G_{c1}(s) = \frac{aT_m s + 1}{T_m s + 1} = \frac{13.928 \times 0.099 s + 1}{0.099 s + 1} = \frac{1.38s + 1}{0.099s + 1}$$

超前校正后的开环传递函数：

$$G_{K1}(s) = \frac{20(1.38s + 1)}{s(s+1)(s+2)(0.099s + 1)}$$

此时：
- 剪切频率 $\omega_{c1} = 5.25\ \text{rad/s}$（剪切频率增大了）
- 相角裕度 $\gamma_1 = -3.68°$（仍为负值！）

> **通俗分析**：虽然 $\omega_m$ 配在了原剪切频率处，但超前校正的幅值提升使剪切频率右移到了 $5.25$，而在这个更高的频率处，原系统相角下降更快，所以相角裕度依然为负。不过没关系——接下来滞后校正会把剪切频率"拉回来"。

**(2) 再设计滞后校正**

取 $\Delta\varphi = 5°$，令 $G_{K1}(s)$ 的相角等于目标值：

$$\varphi_{K1}(\omega) = -180° + \gamma^* + \Delta\varphi = -180° + 50° + 5° = -125°$$

解得 $\omega_2 = 1.41\ \text{rad/s}$。

由幅值条件精确求解：

$$20\lg b = -20\lg|G_{K1}(j\omega_2)| \implies b = 0.138$$

由 $\frac{10}{bT_b} = \omega_2$ 得：

$$T_b = \frac{10}{0.138 \times 1.41} \approx 51.39\ \text{s}$$

串联滞后校正网络：

$$G_{c2}(s) = \frac{bT_b s + 1}{T_b s + 1} = \frac{0.138 \times 51.39 s + 1}{51.39 s + 1} = \frac{6.68s + 1}{51.39s + 1}$$

**(3) 合成校正网络**

$$G_c(s) = \frac{(1.38s + 1)(6.68s + 1)}{(0.099s + 1)(51.39s + 1)}$$

**(4) 验算**

校正后系统：

$$G_K(s) = \frac{20(1.38s + 1)(6.68s + 1)}{s(s+1)(s+2)(0.099s + 1)(51.39s + 1)}$$

- 剪切频率 $\omega_{c2} = 1.35\ \text{rad/s} \geq 1\ \text{rad/s}$ ✅
- 相角裕度 $\gamma_2 = 51.17° \geq 50°$ ✅

> **满足设计要求！** 而且比第一种方法的 $\omega_{c2}$ 更高（$1.35 > 1.05$），快速性更好。

---

### 4.6 两种 $\omega_m$ 配置方式对比

| 对比项 | 方法A（$\omega_m$ 由幅值条件确定） | 方法B（$\omega_m = \omega_{c0}$） |
|:---:|:---:|:---:|
| $\omega_m$ | $4.21\ \text{rad/s}$ | $2.71\ \text{rad/s}$ |
| $T_m$ | $0.0636\ \text{s}$ | $0.099\ \text{s}$ |
| $G_{c1}(s)$ 超前部分 | $\frac{0.886s+1}{0.0636s+1}$ | $\frac{1.38s+1}{0.099s+1}$ |
| 超前校正后 $\omega_{c1}$ | $4.21$ | $5.25$ |
| 超前校正后 $\gamma_1$ | $8.775°$ | $-3.68°$ |
| 滞后校正后 $\omega_{c2}$ | $1.05$ | $1.35$ |
| 滞后校正后 $\gamma_2$ | $50.026°$ | $51.17°$ |
| 是否满足要求 | ✅ | ✅ |

> **结论**：两种方法都能满足要求。方法B的最终剪切频率更高（快速性更好），方法A的中间过程相角裕度更好。实际设计中可根据具体情况选择。

## 五、法2：精确控制剪切频率（$\omega_c^*$ 有精确值要求）

### 5.1 法2 设计思路

当 $\omega_c^*$ 有一个**精确的目标值**（如 $\omega_c^* = 10 \pm 0.5\ \text{rad/s}$）时，法1 的思路就不太适用了——因为法1 无法精确控制最终剪切频率的位置。

**改进思路**：
1. 用**超前校正**将**期望剪切频率处**的相角配置到期望的相角裕度（需要一定的补偿量 $\Delta\varphi$ 以弥补滞后校正带来的负相角）
2. 用**滞后校正**将**期望剪切频率处**的幅值变为 $0\ \text{dB}$

> **通俗理解**：法2 的思路是"定点施工"——先确定好要在哪个频率点工作（$\omega_c^*$），然后在这个频率点上，用超前校正把相角"修"到合适的值，再用滞后校正把幅值"压"到 $0\ \text{dB}$。

---

### 5.2 法2 完整设计步骤（6步）

```
① 根据稳态性能要求，确定开环放大系数 K
        ↓
② 绘制原系统 Bode 图，计算剪切频率 ω_c0 和相角裕度 γ_0
        ↓
③ 计算原系统在 ω_c* 处的相角 φ(ω_c*)
   令最大超前相角 φ_m = γ* - [180° + φ(ω_c*)] + Δφ
   则 a = (1+sinφ_m)/(1-sinφ_m)
        ↓
④ 令 ω_m = ω_c*；由 ω_m = 1/(T_m√a) 得 T_m
   则幅值补偿后 G_c1(s) = (aT_m s + 1)/(T_m s + 1)
   校正后 G_K1(s) = G_c1(s)·G_0(s)
        ↓
⑤ 令 ω_2 = ω_c*
   由 20lg(b) = -20lg|G_K1(jω_c*)| 得 b
   由 10/(bT_b) = ω_2 得 T_b
   则滞后校正 G_c2(s) = (bT_b s + 1)/(T_b s + 1)
        ↓
⑥ 验算。校正后 G_K(s) = G_c2(s)·G_c1(s)·G_0(s)
```

### 5.3 例2：精确控制剪切频率的滞后-超前校正

#### 题目

设系统的开环传递函数为：

$$G_0(s) = \frac{K}{s(0.1s + 1)(0.05s + 1)}$$

要求系统满足下列性能指标：
1. 稳态速度误差系数 $K_v^* \geq 50$
2. 剪切频率 $\omega_c^* = 10 \pm 0.5\ \text{rad/s}$
3. 相角裕度 $\gamma^* = 40° \pm 3°$

试用频率响应法确定合适的串联校正装置。

#### 解题过程

**(0) 确定开环放大系数**

$$K_v = \lim_{s \to 0} s \cdot G_0(s) = \lim_{s \to 0} \frac{K}{(0.1s+1)(0.05s+1)} = K$$

由 $K_v^* \geq 50$，取 $K = 50$。

$$G_0(s) = \frac{50}{s(0.1s + 1)(0.05s + 1)}$$

**(1) 绘制原系统 Bode 图**

由 $|G_0(j\omega)| = 1$ 精确求出：

$$\omega_{c0} = 18\ \text{rad/s},\quad \gamma_0 = -13°$$

> 原系统相角裕度为负，不稳定，需要校正。

**(2) 尝试超前校正**

由 $\gamma^* = 40°$，选择：

$$\varphi_m = \gamma^* - \gamma_0 + \Delta\varphi = 40° + 13° + 7° = 60°$$

（$\Delta\varphi$ 达到最大超前校正相角补偿量）

$$a = \frac{1 + \sin 60°}{1 - \sin 60°} \approx 14$$

由幅值条件：

$$20\lg\frac{50}{\omega \cdot 0.1\omega \cdot 0.05\omega} = -10\lg a$$

解出 $\omega_m = 33.45\ \text{rad/s}$。

> **问题**：$\omega_m = 33.45\ \text{rad/s}$ 远大于期望的 $\omega_c^* = 10$，**不符合剪切频率要求**。
> 若继续设计，可得 $T_m = 0.008$，校正后 $\gamma_1 = 17.6°$，**不满足要求**。

**(3) 尝试滞后校正**

由 $\gamma^* = 40°$，取补偿相角 $\Delta\varphi = 6°$：

$$\varphi(\omega) = \gamma^* + \Delta\varphi - 180° = -134°$$

解得 $\omega_1 = 5.47\ \text{rad/s}$。

> **问题**：$\omega_1 = 5.47\ \text{rad/s}$，**不符合 $\omega_c^* = 10 \pm 0.5$ 的要求**。
> 据此可继续求得 $b = 0.129$，$T_b = 14.17$，校正后 $\gamma_1 = 40.99°$。
> 虽然相角裕度满足，但剪切频率不在要求范围内。

**(4) 采用滞后-超前校正（法2）**

**分析**：
- 法1 的超前校正设计思路，无法精确控制剪切频率在 $10$ 左右
- 需要采用**法2**：在期望剪切频率 $\omega_c^* = 10$ 处定点配置

**(4a) 设计超前校正部分**

原系统在 $\omega_c^* = 10$ 处的相角：

$$\varphi(\omega_c^*) = -90° - \arctan(0.1 \times 10) - \arctan(0.05 \times 10) = -90° - \arctan(1) - \arctan(0.5)$$

$$= -90° - 45° - 26.57° = -161.57° \approx -162°$$

为使 $\gamma^* = 40°$，取补偿量 $\Delta\varphi = 5°$（弥补滞后校正引入的负相角），需要的最大超前相角：

$$\varphi_m = \gamma^* - (180° + \varphi(\omega_c^*)) + \Delta\varphi = 40° - (180° - 162°) + 5° = 40° - 18° + 5° = 27°$$

由公式计算 $a$：

$$a = \frac{1 + \sin\varphi_m}{1 - \sin\varphi_m} = \frac{1 + \sin 27°}{1 - \sin 27°} = \frac{1 + 0.454}{1 - 0.454} = \frac{1.454}{0.546} \approx 2.66$$

为使 $\omega_c^* = 10$ 时对应最大超前相角 $\varphi_m$，令：

$$\omega_m = \omega_c^* = 10\ \text{rad/s}$$

由 $\omega_m = \frac{1}{T_m\sqrt{a}}$ 得：

$$T_m = \frac{1}{\omega_m \sqrt{a}} = \frac{1}{10 \times \sqrt{2.66}} = \frac{1}{10 \times 1.631} \approx 0.06\ \text{s}$$

幅值补偿后的超前校正装置：

$$G_{c1}(s) = \frac{aT_m s + 1}{T_m s + 1} = \frac{2.66 \times 0.06 s + 1}{0.06 s + 1} = \frac{0.16s + 1}{0.06s + 1}$$

串联超前校正后的开环传递函数：

$$G_{K1}(s) = G_{c1}(s) \cdot G_0(s) = \frac{50(0.16s + 1)}{s(0.1s + 1)(0.05s + 1)(0.06s + 1)}$$

**(4b) 设计滞后校正部分**

用串联滞后校正将期望剪切频率 $\omega_c^*$ 处的幅值变为 $0\ \text{dB}$。

计算 $\omega_c^* = 10\ \text{rad/s}$ 时 $G_{K1}$ 的幅值：

$$20\lg|G_{K1}(j10)| = 14\ \text{dB}$$

> 即在 $\omega = 10$ 处，超前校正后的系统幅值为 $14\ \text{dB}$，需要滞后校正将其衰减到 $0\ \text{dB}$。

因此需要滞后校正装置产生 $14\ \text{dB}$ 的幅值衰减。令：

$$20\lg b = -20\lg|G_{K1}(j\omega_c^*)| = -14\ \text{dB}$$

解得：

$$b = 10^{-14/20} \approx 0.2$$

取 $\frac{10}{bT_b} = \omega_c^*$：

$$T_b = \frac{10}{b \cdot \omega_c^*} = \frac{10}{0.2 \times 10} = 5\ \text{s}$$

串联滞后校正网络：

$$G_{c2}(s) = \frac{bT_b s + 1}{T_b s + 1} = \frac{0.2 \times 5 s + 1}{5 s + 1} = \frac{s + 1}{5s + 1}$$

**(4c) 合成校正网络**

滞后-超前校正网络：

$$G_c(s) = G_{c1}(s) \cdot G_{c2}(s) = \frac{(0.16s + 1)(s + 1)}{(0.06s + 1)(5s + 1)}$$

**(4d) 校验**

校正后系统：

$$G_K(s) = G_{c2}(s) \cdot G_{c1}(s) \cdot G_0(s) = \frac{50(0.16s + 1)(s + 1)}{s(0.1s + 1)(0.05s + 1)(0.06s + 1)(5s + 1)}$$

**求剪切频率**：

$$|G_K(j10)| = \frac{50 \times \sqrt{(0.16 \times 10)^2 + 1} \times \sqrt{10^2 + 1}}{10 \times \sqrt{(0.1 \times 10)^2 + 1} \times \sqrt{(0.05 \times 10)^2 + 1} \times \sqrt{(0.06 \times 10)^2 + 1} \times \sqrt{(5 \times 10)^2 + 1}}$$

$$= \frac{50 \times \sqrt{3.56} \times \sqrt{101}}{10 \times \sqrt{2} \times \sqrt{1.25} \times \sqrt{1.36} \times \sqrt{2501}}$$

$$\approx \frac{50 \times 1.887 \times 10.05}{10 \times 1.414 \times 1.118 \times 1.166 \times 50.01} \approx \frac{948}{922} \approx 1$$

因此校正后剪切频率 $\omega_{c2} = 10\ \text{rad/s}$ ✅

**求相角裕度**：

$$\gamma_2 = 180° + \angle G_K(j10)$$

各环节在 $\omega = 10$ 处的相角贡献：

| 环节 | 相角 |
|------|------|
| $\frac{1}{j\omega}$ | $-90°$ |
| $\frac{1}{j0.1\omega + 1}$ | $-\arctan(1) = -45°$ |
| $\frac{1}{j0.05\omega + 1}$ | $-\arctan(0.5) = -26.6°$ |
| $j0.16\omega + 1$ | $+\arctan(1.6) = +58.0°$ |
| $\frac{1}{j0.06\omega + 1}$ | $-\arctan(0.6) = -31.0°$ |
| $j\omega + 1$ | $+\arctan(10) = +84.3°$ |
| $\frac{1}{j5\omega + 1}$ | $-\arctan(50) = -88.9°$ |

$$\gamma_2 = 180° + (-90° - 45° - 26.6° + 58.0° - 31.0° + 84.3° - 88.9°)$$

$$= 180° + (-162° + 58° + 84.3° - 31° - 88.9° - 45°)$$

> 注：课件中计算为 $\gamma_2 = -162° + 58° - 30° + 84.3° - 88.9° + 180° = 41.4°$

$$\gamma_2 = 41.4°$$

满足 $\gamma^* = 40° \pm 3°$ 的要求 ✅

> **所有性能指标均满足！设计完成。**

## 六、法1 与法2 的对比总结

| 对比项 | 法1（先超前后滞后） | 法2（定点配置） |
|:---:|------|------|
| **适用场景** | $\omega_c^*$ 有下界要求 | $\omega_c^*$ 有精确值要求 |
| **超前部分设计** | 令 $\varphi_m = 60°$，由幅值条件确定 $\omega_m$ | 在 $\omega_c^*$ 处配置所需超前相角 |
| **滞后部分设计** | 在满足相角裕度的频率处进行幅值衰减 | 在 $\omega_c^*$ 处将幅值衰减到 $0\ \text{dB}$ |
| **$\omega_m$ 的位置** | 由 $-10\lg a$ 处的频率确定，或取 $\omega_{c0}$ | 直接令 $\omega_m = \omega_c^*$ |
| **对 $\omega_c$ 的控制** | 不精确，最终 $\omega_c$ 由两步校正共同决定 | **精确**，最终 $\omega_c \approx \omega_c^*$ |
| **$\varphi_m$ 的大小** | 固定取 $60°$（充分利用超前能力） | 由 $\gamma^* - (180° + \varphi(\omega_c^*)) + \Delta\varphi$ 计算 |

## 七、滞后-超前校正的关键公式速查

| 名称 | 公式 |
|------|------|
| 超前校正参数 $a$ | $a = \frac{1 + \sin\varphi_m}{1 - \sin\varphi_m}$ |
| 超前校正时间常数 $T_m$ | $T_m = \frac{1}{\omega_m \sqrt{a}}$ |
| 超前校正传函 | $G_{c1}(s) = \frac{aT_m s + 1}{T_m s + 1}$ |
| 滞后校正参数 $b$ | $20\lg b = -20\lg\|G_{K1}(j\omega_2)\|$ |
| 滞后校正时间常数 $T_b$ | $T_b = \frac{10}{b \cdot \omega_2}$ |
| 滞后校正传函 | $G_{c2}(s) = \frac{bT_b s + 1}{T_b s + 1}$ |
| 总校正传函 | $G_c(s) = G_{c1}(s) \cdot G_{c2}(s) = \frac{(aT_m s + 1)(bT_b s + 1)}{(T_m s + 1)(T_b s + 1)}$ |

> **物理意义**：滞后-超前校正装置的传函可以写成四个一阶环节的乘积——分子上一个超前零点 $(aT_m s + 1)$ 和一个滞后零点 $(bT_b s + 1)$，分母上一个超前极点 $(T_m s + 1)$ 和一个滞后极点 $(T_b s + 1)$。其中 $a > 1$（超前），$b < 1$（滞后）。

## 八、设计步骤总结

### 8.1 通用设计流程

```
第一步：根据稳态性能指标确定开环放大系数 K
        ↓
第二步：绘制原系统 Bode 图，求 ω_c0 和 γ_0
        ↓
第三步：判断校正方式
   ├── 单独超前校正是否可行？（所需 φ_m 是否 ≤ 55°？）
   ├── 单独滞后校正是否可行？（ω_c 是否在合理范围？）
   └── 都不行 → 采用滞后-超前校正
        ↓
第四步：根据 ω_c* 的要求选择设计方法
   ├── ω_c* 有下界 → 法1（先超前后滞后）
   └── ω_c* 有精确值 → 法2（定点配置）
        ↓
第五步：设计超前校正部分 G_c1(s)
        ↓
第六步：设计滞后校正部分 G_c2(s)
        ↓
第七步：合成 G_c(s) = G_c1(s)·G_c2(s)
        ↓
第八步：验算校正后系统的 ω_c 和 γ 是否满足要求
```

### 8.2 关键注意事项

1. **补偿量 $\Delta\varphi$**：通常取 $5° \sim 6°$，用于弥补滞后校正在新剪切频率处引入的负相角
2. **$\omega_m$ 的选取**：
   - 法1中，$\omega_m$ 可由幅值条件（$-10\lg a$ 处频率）确定，也可直接取 $\omega_{c0}$
   - 法2中，$\omega_m$ 直接取 $\omega_c^*$
3. **滞后校正的 $\frac{10}{bT_b}$ 规则**：使滞后校正的转折频率 $\frac{1}{bT_b}$ 远离剪切频率（约 $\frac{1}{10}$），避免滞后校正的负相角影响相角裕度
4. **验算不可省略**：由于设计过程中使用了近似和补偿量，最终必须验算校正后系统是否真正满足所有指标
