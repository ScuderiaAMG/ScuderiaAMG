# 第25讲：串联滞后校正

---

## 一、串联滞后校正的基本原理

### 1.1 核心思想

滞后校正装置具有**幅值衰减作用**，叠加到原系统后可以使系统的**剪切频率 $\omega_c$ 变小**。

> **通俗理解**：超前校正是"抬高相位、主动出击"，而滞后校正是"压低幅频、以退为进"。它不直接提供超前相角，而是通过把剪切频率往低频方向"推"，利用原系统在低频处本身就更大的相位裕度来满足要求。

### 1.2 什么时候用滞后校正？

当原系统的相角裕度 $\gamma_0$ **不满足**性能要求，且**所需的超前相角过大**（例如需要超过 $60^\circ$ 的超前量），串联超前校正很难奏效时，就应考虑采用**串联滞后校正**。

| 场景 | 适用校正方式 |
|------|------------|
| 需要提供的超前相角 $< 60^\circ$ | 串联超前校正 |
| 需要提供的超前相角 $> 60^\circ$ | **串联滞后校正** |
| 不要求增加带宽、不要求提高快速性 | 串联滞后校正 |
| 要求增加频带宽度、提高快速性 | **不宜**用滞后校正 |

### 1.3 滞后校正的Bode图特征

滞后校正网络的传递函数为：

$$G_c(s) = \frac{1 + bTs}{1 + Ts}, \quad 0 < b < 1$$

其中 $b$ 为衰减系数（$b < 1$），$T$ 为时间常数。

其Bode图特征如下：

- **幅频特性**：在低频段（$\omega < \frac{1}{T}$），幅值为 $0\text{ dB}$；在高频段（$\omega > \frac{1}{bT}$），幅值衰减为 $20\lg b < 0\text{ dB}$。
- **相频特性**：产生**负的相角**（即相角滞后），最大滞后相角出现在 $\omega_m = \frac{1}{T\sqrt{b}}$ 处。
- **转折频率**：第一个转折频率为 $\frac{1}{T}$（低频侧），第二个转折频率为 $\frac{1}{bT}$（高频侧）。

滞后校正装置的**最大幅值衰减**为 $20\lg b$（发生在高频段 $\omega > \frac{1}{bT}$）。

## 二、串联滞后校正的设计方法

### 2.1 设计思路

**核心策略**：将滞后校正装置的**最大幅值衰减区**（$20\lg b$）叠加到原系统上，使原系统某个较低频率 $\omega_1$ 处成为新的剪切频率。

具体操作：

1. **确定目标频率 $\omega_1$**：在原系统的相频特性上，找到一个频率 $\omega_1$，使得该频率处的相角恰好满足期望的相角裕度要求（再扣除一定的补偿量 $\Delta\varphi$）。

2. **确定参数 $b$**：利用滞后校正的最大幅值衰减 $20\lg b$，恰好将 $\omega_1$ 处原系统的幅值压低到 $0\text{ dB}$，使 $\omega_1$ 成为校正后系统的剪切频率。

3. **确定参数 $T$**：为了降低滞后校正装置在 $\omega_1$ 处产生的**相角滞后**对系统的不利影响，应让滞后校正的第二个转折频率 $\frac{1}{bT}$ **尽量远离** $\omega_1$。

### 2.2 如何确定参数 $b$

在频率 $\omega_1$ 处，原系统的幅值为 $L_0(\omega_1) = 20\lg|G_0(j\omega_1)|$。

要使 $\omega_1$ 成为校正后的剪切频率，需满足：

$$20\lg b + L_0(\omega_1) = 0$$

即：

$$20\lg b = -L_0(\omega_1)$$

由此可解出：

$$b = 10^{-L_0(\omega_1)/20}$$

> **通俗理解**：$b$ 的作用就是把原系统在 $\omega_1$ 处的幅值"压"到 $0\text{ dB}$，使该频率变成新的剪切频率。

### 2.3 如何确定参数 $T$

为降低滞后校正装置在 $\omega_1$ 处的**相角滞后作用**，应尽量保持 $\omega_1$ 附近的相频特性基本不变。

**方法**：让滞后校正的第二个转折频率 $\frac{1}{bT}$ 距离 $\omega_1$ **十倍频程**（即一个十倍频），即令：

$$\frac{10}{bT} = \omega_1$$

由此解得：

$$T = \frac{10}{b \cdot \omega_1}$$

> **为什么取十倍频程？** 当第二个转折频率距 $\omega_1$ 为十倍频程时，滞后校正在 $\omega_1$ 处产生的滞后相角 **$< 6^\circ$**，对系统相角裕度的影响很小，可以接受。

### 2.4 确定目标频率 $\omega_1$ 的修正公式

由于滞后校正在 $\omega_1$ 处会产生少量相角滞后（约 $5^\circ \sim 6^\circ$），在寻找 $\omega_1$ 时必须**预先补偿**这部分相角损失。

修正后的公式为：

$$\gamma^* = 180^\circ + \varphi_0(\omega_1) - \Delta\varphi$$

即：

$$\varphi_0(\omega_1) = -180^\circ + \gamma^* + \Delta\varphi$$

其中：
- $\gamma^*$ 为期望的相角裕度
- $\varphi_0(\omega_1)$ 为原系统在 $\omega_1$ 处的相角
- $\Delta\varphi$ 为补偿量，**通常取 $6^\circ$**

> **通俗理解**：因为滞后校正在 $\omega_1$ 处会"偷走"大约 $6^\circ$ 的相位，所以我们在找 $\omega_1$ 时要多预留 $6^\circ$ 的余量。

## 三、串联滞后校正的完整步骤

```
第1步：根据稳态性能要求（如 K_v*），确定开环放大系数 K
       ↓
第2步：绘制原系统的 Bode 图，计算原系统的相角裕度 γ₀
       ↓
第3步：判断采用何种校正
       - 若所需超前角 > 60°，选用滞后校正
       - 选取补偿量 Δφ（通常取 6°）
       - 计算 φ₀(ω₁) = -180° + γ* + Δφ
       - 在原相频特性上找到对应频率 ω₁
       ↓
第4步：确定参数 b
       - 令 20lgb + L₀(ω₁) = 0
       - 解出 b = 10^(-L₀(ω₁)/20)
       ↓
第5步：确定参数 T
       - 令 10/(bT) = ω₁
       - 解出 T = 10/(b·ω₁)
       - 得到校正网络 G_c(s) = (1 + bTs)/(1 + Ts)
       ↓
第6步：验算
       - 写出校正后开环传递函数 G_K(s) = G₀(s)·G_c(s)
       - 绘制校正后 Bode 图
       - 计算校正后的相角裕度 γ₁
       - 验证是否满足 γ₁ ≥ γ*
```

## 四、典型例题

### 例1：串联滞后校正设计（完整步骤）

**题目**：已知原系统的开环传递函数为：

$$G_0(s) = \frac{K}{s(0.1s+1)(0.2s+1)}$$

试设计合适的串联校正装置，使系统满足以下性能要求：

1. 速度误差系数 $K_v^* = 30\text{ s}^{-1}$
2. 相角裕度 $\gamma^* \geq 40^\circ$

---

#### 第1步：确定开环放大系数

由速度误差系数的定义：

$$K_v = \lim_{s \to 0} s \cdot G_0(s) = \lim_{s \to 0} s \cdot \frac{K}{s(0.1s+1)(0.2s+1)} = K$$

由性能要求 $K_v^* = 30\text{ s}^{-1}$，得：

$$K = K_v^* = 30$$

满足性能要求 (1)。

---

#### 第2步：绘制原系统Bode图，计算相角裕度

原系统开环传递函数：

$$G_0(s) = \frac{30}{s(0.1s+1)(0.2s+1)}$$

**求原系统剪切频率 $\omega_{c0}$**：

在剪切频率处，幅值为 $0\text{ dB}$，即 $|G_0(j\omega_{c0})| = 1$：

$$\frac{30}{\omega_{c0} \times 0.1\omega_{c0} \times 0.2\omega_{c0}} = 1$$

（因为在 $\omega_{c0}$ 较大时，$0.1\omega \gg 1$，$0.2\omega \gg 1$，所以 $|0.1j\omega+1| \approx 0.1\omega$，$|0.2j\omega+1| \approx 0.2\omega$）

$$\frac{30}{0.02\omega_{c0}^3} = 1 \implies \omega_{c0}^3 = 1500 \implies \omega_{c0} = \sqrt[3]{1500} \approx 11.44 \approx 11\text{ rad/s}$$

**求原系统相角裕度 $\gamma_0$**：

$$\varphi_0(\omega_{c0}) = -90^\circ - \arctan(0.1 \times 11.44) - \arctan(0.2 \times 11.44)$$

$$= -90^\circ - \arctan(1.144) - \arctan(2.288)$$

$$= -90^\circ - 48.8^\circ - 66.4^\circ = -205.2^\circ$$

$$\gamma_0 = 180^\circ + \varphi_0(\omega_{c0}) = 180^\circ - 205.2^\circ \approx -25^\circ$$

**原系统相角裕度 $\gamma_0 \approx -25^\circ$，不满足 $\gamma^* \geq 40^\circ$ 的要求。**

**判断采用何种校正**：

需要的超前相角为：

$$\gamma^* - \gamma_0 = 40^\circ - (-25^\circ) = 65^\circ > 60^\circ$$

需要提供超过 $60^\circ$ 的超前相角，串联超前校正很难奏效。因此**采用串联滞后校正**。

---

#### 第3步：确定目标频率 $\omega_1$

考虑滞后校正产生的相角滞后影响，取补偿量 $\Delta\varphi = 6^\circ$。

由修正公式：

$$\gamma^* = 180^\circ + \varphi_0(\omega_1) - \Delta\varphi$$

代入数据：

$$40^\circ = 180^\circ + \varphi_0(\omega_1) - 6^\circ$$

$$\varphi_0(\omega_1) = -180^\circ + 40^\circ + 6^\circ = -134^\circ$$

在原系统的相频特性上，找到相角为 $-134^\circ$ 对应的频率 $\omega_1$：

$$-90^\circ - \arctan(0.1\omega_1) - \arctan(0.2\omega_1) = -134^\circ$$

$$\arctan(0.1\omega_1) + \arctan(0.2\omega_1) = 44^\circ$$

利用反正切和公式 $\arctan a + \arctan b = \arctan\frac{a+b}{1-ab}$（当 $ab < 1$ 时）：

$$\arctan\frac{0.1\omega_1 + 0.2\omega_1}{1 - 0.1\omega_1 \times 0.2\omega_1} = 44^\circ$$

$$\frac{0.3\omega_1}{1 - 0.02\omega_1^2} = \tan 44^\circ \approx 0.9657$$

$$0.3\omega_1 = 0.9657(1 - 0.02\omega_1^2)$$

$$0.3\omega_1 = 0.9657 - 0.01931\omega_1^2$$

$$0.01931\omega_1^2 + 0.3\omega_1 - 0.9657 = 0$$

解一元二次方程：

$$\omega_1 = \frac{-0.3 + \sqrt{0.09 + 4 \times 0.01931 \times 0.9657}}{2 \times 0.01931} = \frac{-0.3 + \sqrt{0.09 + 0.0746}}{0.03862}$$

$$= \frac{-0.3 + \sqrt{0.1646}}{0.03862} = \frac{-0.3 + 0.4057}{0.03862} = \frac{0.1057}{0.03862} \approx 2.737\text{ rad/s}$$

**得 $\omega_1 = 2.737\text{ rad/s}$。**

---

#### 第4步：确定参数 $b$

在 $\omega_1 = 2.737\text{ rad/s}$ 处，原系统的幅值为：

$$L_0(\omega_1) = 20\lg|G_0(j\omega_1)|$$

由于 $\omega_1 = 2.737$ 较小，$0.1\omega_1 = 0.2737 < 1$，$0.2\omega_1 = 0.5474 < 1$，两个惯性环节的幅值近似为 1：

$$L_0(\omega_1) \approx 20\lg\frac{30}{\omega_1 \times 1 \times 1} = 20\lg\frac{30}{2.737} = 20\lg(10.96) \approx 20.8\text{ dB}$$

令滞后校正在高频段的幅值衰减恰好抵消原系统在 $\omega_1$ 处的幅值：

$$20\lg b + L_0(\omega_1) = 0$$

$$20\lg b = -20.8\text{ dB}$$

$$\lg b = -1.04 \implies b = 10^{-1.04} \approx 0.09$$

**得 $b = 0.09$。**

---

#### 第5步：确定参数 $T$

令滞后校正的第二个转折频率 $\frac{1}{bT}$ 距 $\omega_1$ 十倍频程：

$$\frac{10}{bT} = \omega_1$$

$$T = \frac{10}{b \cdot \omega_1} = \frac{10}{0.09 \times 2.737} = \frac{10}{0.2463} \approx 40.6\text{ s}$$

**得 $T = 40.6$ 秒。**

由此得到串联滞后校正网络的传递函数：

$$G_c(s) = \frac{1 + bTs}{1 + Ts} = \frac{1 + 0.09 \times 40.6s}{1 + 40.6s} = \frac{1 + 3.654s}{1 + 40.6s}$$

即：

$$\boxed{G_c(s) = \frac{3.654s + 1}{40.6s + 1}}$$

**验证**：
- 第一个转折频率：$\frac{1}{T} = \frac{1}{40.6} = 0.0246\text{ rad/s}$
- 第二个转折频率：$\frac{1}{bT} = \frac{1}{0.09 \times 40.6} = \frac{1}{3.654} = 0.2737\text{ rad/s}$
- 十倍频程验证：$10 \times \frac{1}{bT} = 10 \times 0.2737 = 2.737 = \omega_1$ ✓

---

#### 第6步：验算

校正后系统的开环传递函数为：

$$G_K(s) = G_0(s) \cdot G_c(s) = \frac{30}{s(0.1s+1)(0.2s+1)} \cdot \frac{3.654s+1}{40.6s+1}$$

$$= \frac{30(3.654s+1)}{s(0.1s+1)(0.2s+1)(40.6s+1)}$$

**求校正后的剪切频率 $\omega_{c1}$**：

在低频段（$\omega$ 较小时），$3.654\omega > 1$ 但 $40.6\omega > 1$，$0.1\omega < 1$，$0.2\omega < 1$：

$$\frac{30 \times 3.654\omega}{\omega \times 1 \times 1 \times 40.6\omega} = 1$$

$$\frac{109.62}{40.6\omega} = 1 \implies \omega_{c1} = \frac{109.62}{40.6} = 2.7\text{ rad/s}$$

**求校正后的相角裕度 $\gamma_1$**：

$$\gamma_1 = 180^\circ + \varphi_K(\omega_{c1})$$

$$= 180^\circ - 90^\circ - \arctan(0.1 \times 2.7) - \arctan(0.2 \times 2.7) - \arctan(40.6 \times 2.7) + \arctan(3.654 \times 2.7)$$

逐项计算：

| 项 | 值 |
|---|---|
| $-90^\circ$ | $-90^\circ$ |
| $-\arctan(0.27)$ | $-15.1^\circ$ |
| $-\arctan(0.54)$ | $-28.4^\circ$ |
| $-\arctan(109.62)$ | $-89.5^\circ$ |
| $+\arctan(9.866)$ | $+84.2^\circ$ |

$$\gamma_1 = 180^\circ - 90^\circ - 15.1^\circ - 28.4^\circ - 89.5^\circ + 84.2^\circ = 41.3^\circ$$

**$\gamma_1 = 41.3^\circ \geq 40^\circ = \gamma^*$，满足设计要求！** ✓

---

### 例1小结

| 项目 | 校正前 | 校正后 |
|------|:---:|:---:|
| 开环传递函数 | $\frac{30}{s(0.1s+1)(0.2s+1)}$ | $\frac{30(3.654s+1)}{s(0.1s+1)(0.2s+1)(40.6s+1)}$ |
| 剪切频率 $\omega_c$ | $11.44\text{ rad/s}$ | $2.7\text{ rad/s}$ |
| 相角裕度 $\gamma$ | $-25^\circ$ | $41.3^\circ$ |
| 稳定性 | 不稳定 | **稳定** |

校正网络：$G_c(s) = \frac{3.654s + 1}{40.6s + 1}$，参数 $b = 0.09$，$T = 40.6\text{ s}$。

## 五、串联滞后校正对系统的影响

### 5.1 正面影响

| 影响 | 说明 |
|------|------|
| **减小剪切频率** | 使 $\omega_c$ 变小，系统带宽降低 |
| **增加相角裕度** | 在新的剪切频率处，原系统相角更大，相角裕度提高，**相对稳定性增强** |
| **改善幅值裕度** | 幅值衰减作用使幅值裕度变好。因此在保持相对稳定性不变的前提下，可以**提高开环放大系数**，从而**间接改善稳态性能** |
| **提高抗干扰能力** | 降低了剪切频率，系统带宽变小，对高频噪声的抑制能力增强 |

### 5.2 负面影响

| 影响 | 说明 |
|------|------|
| **响应速度变慢** | 剪切频率降低，系统带宽变小，快速性下降 |
| **频带变窄** | 不适合要求增加频带宽度、提高快速性的场合 |

### 5.3 不宜采用串联滞后校正的情况

1. **期望剪切频率 $\omega_c^*$ 大于原剪切频率 $\omega_{c0}$ 时**：滞后校正只能使 $\omega_c$ 减小，无法增大。
2. **要求增加频带宽度、提高快速性的场合**：滞后校正会降低带宽，与要求矛盾。
3. **原系统在低频段的相角已经很小（接近 $-180^\circ$）时**：找不到满足条件的 $\omega_1$。

> **通俗理解**：滞后校正本质上是"以牺牲速度换稳定性"。如果系统本身就要求快速响应，或者要求更高的带宽，那就不适合用滞后校正，而应该考虑超前校正或滞后-超前校正。

## 六、设计步骤总结

### 6.1 串联滞后校正六步法

```
第1步 ─ 确定 K
│        由稳态性能指标（K_v*、K_p*、K_a*）确定开环放大系数 K
│
第2步 ─ 绘制 Bode 图
│        绘制原系统 Bode 图，计算原系统相角裕度 γ₀
│
第3步 ─ 确定 ω₁
│        ① 判断校正方式（需超前角 > 60° → 滞后校正）
│        ② 取补偿量 Δφ = 6°
│        ③ 计算 φ₀(ω₁) = -180° + γ* + Δφ
│        ④ 在原相频特性上找到对应频率 ω₁
│
第4步 ─ 确定 b
│        令 20lgb + L₀(ω₁) = 0，解出 b
│
第5步 ─ 确定 T
│        令 10/(bT) = ω₁，解出 T = 10/(b·ω₁)
│        得到 G_c(s) = (1 + bTs)/(1 + Ts)
│
第6步 ─ 验算
         写出 G_K(s) = G₀(s)·G_c(s)
         绘制校正后 Bode 图，验算 γ₁ ≥ γ*
```

### 6.2 关键公式速查表

| 步骤 | 公式 |
|------|------|
| 求 $\omega_1$ | $\varphi_0(\omega_1) = -180^\circ + \gamma^* + \Delta\varphi$（$\Delta\varphi$ 通常取 $6^\circ$） |
| 求 $b$ | $20\lg b = -L_0(\omega_1)$，即 $b = 10^{-L_0(\omega_1)/20}$ |
| 求 $T$ | $T = \dfrac{10}{b \cdot \omega_1}$ |
| 校正网络 | $G_c(s) = \dfrac{1 + bTs}{1 + Ts}$ |
| 校正后系统 | $G_K(s) = G_0(s) \cdot G_c(s)$ |

### 6.3 超前校正 vs 滞后校正对比

| 对比项 | 串联超前校正 | 串联滞后校正 |
|--------|:---:|:---:|
| 核心机制 | 提供超前相角 | 幅值衰减 |
| 剪切频率 $\omega_c$ | **增大** | **减小** |
| 带宽 | **增加** | **减小** |
| 响应速度 | **提高** | **降低** |
| 抗干扰能力 | 降低 | **提高** |
| 适用场景 | 需要提高快速性 | 需要提高稳定性，不要求快速性 |
| 最大超前/滞后角 | 一般 $< 60^\circ$ | 所需超前角 $> 60^\circ$ |
