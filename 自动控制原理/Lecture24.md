# 第24讲：串联超前校正

---

## 引导：串联校正概述

**串联校正**：校正后频率特性由**校正装置的频率特性**与**原系统的频率特性**的叠加。适宜用频率法设计。

本讲涵盖四种串联校正方法：
1. 串联超前校正（本讲重点）
2. 串联滞后校正
3. 串联滞后-超前校正
4. 期望频率特性法校正

---

## 一、串联超前校正

### 1.1 基本原理

**核心思想**：利用超前校正装置的**最大超前相角** $\varphi_m$ 来补偿原系统相角裕度的不足 $\gamma^* - \gamma_0$。

> **通俗语言**：原系统的相角裕度不够（$\gamma_0 < 0$ 或 $\gamma_0 < \gamma^*$），就像一座桥不够宽，我们需要在中频段"垫"一个超前相角，把相角裕度"抬"上去。串联超前校正装置就是提供这个"垫脚石"的工具。

**图示说明**：
- 原系统：$\gamma_0 < 0$，不满足性能要求，相角还差 $\gamma^* - \gamma_0$
- 校正装置：在中频段提供超前相角，补偿 $\gamma^* - \gamma_0$
- 校正装置在 $\omega_m$ 处产生最大超前相角 $\varphi_m$

**关键问题**：采用哪一个相角值来增大相角裕度最好？

**答案**：利用**最大超前相角** $\varphi_m = \gamma^* - \gamma_0$ 来补偿性能差距。

---

### 1.2 超前校正装置的频率特性

超前校正装置的传递函数：

$$G_c(s) = \frac{aTs + 1}{Ts + 1}, \quad a > 1$$

其对数频率特性：

| 特征 | 表达式 |
|------|--------|
| 最大超前相角 | $\varphi_m = \arcsin\frac{a-1}{a+1}$ |
| 最大超前相角频率 | $\omega_m = \frac{1}{T\sqrt{a}}$ |
| 最大超前相角处幅值 | $L_c(\omega_m) = 10\lg a$ (dB) |
| 两个转折频率 | $\frac{1}{aT}$ 和 $\frac{1}{T}$ |

---

### 1.3 叠加位置的确定

**问题**：将最大超前相角叠加到哪个位置？

**策略**：将最大超前相角叠加到**原剪切频率** $\omega_{c0}$ 处。

**幅值变化**：叠加后，原剪切频率 $\omega_{c0}$ 处的幅值变为 $10\lg a$。

**剪切频率的移动**：
- 由于叠加了正幅值 $10\lg a$，剪切频率**增大（右移）**
- 剪切频率右移后，负相角增多
- 基于 $\gamma^* - \gamma_0$ 估算的超前相角**不够用**

> **通俗语言**：就像你给桥加宽了一块板，但桥变长了（剪切频率右移），新的尽头处地基更软（负相角更大），所以一开始就要多备一些板材。

---

### 1.4 补偿量 $\Delta\varphi$ 的确定

由于剪切频率增大导致负相角增多，需增加相角补偿量 $\Delta\varphi$：

$$\boxed{\varphi_m = \gamma^* - \gamma_0 + \Delta\varphi}$$

其中：
- $\Delta\varphi$ 取决于**原系统相频特性**在剪切频率附近的变化情况
- 变化缓慢 → $\Delta\varphi$ 取较小值
- 变化较快 → $\Delta\varphi$ 取较大值
- **通常取** $\Delta\varphi \in [5^\circ, 20^\circ]$

---

### 1.5 $\omega_m$ 的确定方法

为保证叠加 $\varphi_m$ 处的幅值为 0 dB，需要找到原系统对数幅值等于 $-10\lg a$ 处的频率：

$$L_0(\omega_1) = -10\lg a$$

令 $\omega_m = \omega_1$。

> **通俗语言**：校正装置在 $\omega_m$ 处提供 $+10\lg a$ 的幅值，所以我们要在原系统幅值恰好为 $-10\lg a$ 的地方放置 $\omega_m$，这样两者叠加后该处幅值刚好为 0 dB，就是新的剪切频率。

---

### 1.6 参数 $a$ 的确定

由最大超前相角 $\varphi_m$ 求参数 $a$：

$$\boxed{a = \frac{1 + \sin\varphi_m}{1 - \sin\varphi_m}}$$

---

## 二、完整设计步骤

### 串联超前校正的六个步骤

| 步骤 | 内容 |
|------|------|
| **第1步** | 根据稳态性能要求，确定开环放大系数 $K$ |
| **第2步** | 绘制原系统 Bode 图，计算剪切频率 $\omega_{c0}$ 和相角裕度 $\gamma_0$ |
| **第3步** | 确定补偿量 $\Delta\varphi$，由 $\varphi_m = \gamma^* - \gamma_0 + \Delta\varphi$ 确定 $\varphi_m$，则 $a = \frac{1+\sin\varphi_m}{1-\sin\varphi_m}$ |
| **第4步** | 计算原系统对数幅频 $L_0(\omega) = -10\lg a$ 处的频率 $\omega_1$，令 $\omega_m = \omega_1$ |
| **第5步** | 根据 $\omega_m = \frac{1}{T\sqrt{a}}$ 计算参数 $T$，得到超前校正网络传函 $G_c(s) = \frac{aTs+1}{Ts+1}$ |
| **第6步** | 写出校正后系统开环传函 $G_K(s) = G_0(s)G_c(s)$，绘制 Bode 图，验算结果 |

## 三、例题：串联超前校正设计

### 题目

已知单位反馈系统的开环传递函数：

$$G_0(s) = \frac{K}{s(0.1s+1)(0.001s+1)}$$

设计串联校正装置，使校正后系统满足：
1. 相角裕度 $\gamma^* \geq 45^\circ$
2. 稳态速度误差系数 $K_v^* = 1000\ \text{s}^{-1}$

---

### 第1步：确定开环放大系数

系统前向通道含一个积分环节，由稳态速度误差系数：

$$K_v = \lim_{s \to 0} s \cdot G_0(s) = \lim_{s \to 0} \frac{K}{(0.1s+1)(0.001s+1)} = K$$

$$K = K_v^* = 1000$$

满足要求 (2)。

---

### 第2步：绘制原系统 Bode 图

$$G_0(s) = \frac{1000}{s(0.1s+1)(0.001s+1)}$$

**转折频率**：
- $\omega_1 = \frac{1}{0.1} = 10\ \text{rad/s}$
- $\omega_2 = \frac{1}{0.001} = 1000\ \text{rad/s}$

**Bode 图特征**：

| 频段 | 斜率 |
|------|------|
| $\omega < 10$ | $-20\ \text{dB/dec}$（积分环节） |
| $10 < \omega < 1000$ | $-40\ \text{dB/dec}$（加一个惯性环节） |
| $\omega > 1000$ | $-60\ \text{dB/dec}$（再加一个惯性环节） |

**剪切频率** $\omega_{c0} = 100\ \text{rad/s}$

**相角裕度**：

$$\gamma_0 = 180^\circ - 90^\circ - \arctan(0.1 \times 100) - \arctan(0.001 \times 100)$$
$$= 180^\circ - 90^\circ - \arctan 10 - \arctan 0.1$$
$$= 180^\circ - 90^\circ - 84.3^\circ - 5.7^\circ \approx 0^\circ$$

$\gamma_0 \approx 0^\circ$，不满足 $\gamma^* \geq 45^\circ$。**采用串联超前校正**。

---

### 第3步：确定 $\varphi_m$ 和 $a$

由于 $\gamma_0 \approx 0^\circ$，为使 $\gamma^* \geq 45^\circ$，串联校正装置提供的最大超前相角需大于 $45^\circ$。

因校正后剪切频率变大，需给 $\varphi_m$ 增加补偿相角 $\Delta\varphi$。

该例中**相频特性曲线在剪切频率附近变化缓慢**，取 $\Delta\varphi = 10^\circ$：

$$\varphi_m = \gamma^* - \gamma_0 + \Delta\varphi = 45^\circ - 0^\circ + 10^\circ = 55^\circ$$

由公式求 $a$：

$$a = \frac{1 + \sin 55^\circ}{1 - \sin 55^\circ} = \frac{1 + 0.8192}{1 - 0.8192} = \frac{1.8192}{0.1808} \approx 10.059$$

---

### 第4步：确定 $\omega_m$

求原系统对数幅值为 $-10\lg a = -10\lg 10.059 = -10.026\ \text{dB}$ 处的频率。

列方程（在 $\omega > 1000$ 频段，斜率为 $-60\ \text{dB/dec}$，但此处 $\omega$ 在 $10 \sim 1000$ 之间，斜率为 $-40\ \text{dB/dec}$）：

$$20\lg\frac{1000}{\omega \times 0.1\omega \times 1} = -10.026$$

$$20\lg\frac{1000}{0.1\omega^2} = -10.026$$

$$\frac{1000}{0.1\omega^2} = 10^{-10.026/20} = 10^{-0.5013} \approx 0.3153$$

$$0.1\omega^2 = \frac{1000}{0.3153} \approx 3172$$

$$\omega^2 = 31720$$

$$\omega_1 = 178\ \text{rad/s}$$

令 $\omega_m = \omega_1 = 178\ \text{rad/s}$。

---

### 第5步：确定 $T$，写出校正装置传函

由 $\omega_m = \frac{1}{T\sqrt{a}}$ 求得：

$$T = \frac{1}{\omega_m \sqrt{a}} = \frac{1}{178 \times \sqrt{10.059}} = \frac{1}{178 \times 3.172} \approx 0.00177\ \text{s}$$

超前校正装置（含比例衰减）：

$$G_c(s) = \frac{1}{a} \cdot \frac{aTs + 1}{Ts + 1} = \frac{1}{10.059} \cdot \frac{10.059 \times 0.00177 s + 1}{0.00177s + 1}$$

$$= \frac{1}{10.059} \cdot \frac{0.0178s + 1}{0.00177s + 1}$$

**串联幅值衰减补偿后**（乘以 $a = 10.059$ 抵消衰减）：

$$\boxed{G_c(s) = \frac{0.0178s + 1}{0.00177s + 1}}$$

---

### 第6步：验算

校正后的开环传递函数：

$$G_K(s) = G_0(s) \cdot G_c(s) = \frac{1000(0.0178s + 1)}{s(0.1s + 1)(0.001s + 1)(0.00177s + 1)}$$

**求校正后剪切频率**：

在 $\omega$ 较大时（$\omega > 10$，处于 $-40\ \text{dB/dec}$ 段），列方程：

$$\frac{1000 \times 0.0178\omega}{\omega \times 0.1\omega \times 1} = 1$$

$$\frac{17.8}{0.1\omega} = 1 \implies \omega = 178\ \text{rad/s}$$

校正后剪切频率 $\omega_{c1} = 178\ \text{rad/s}$。

**求校正后相角裕度**：

$$\gamma_1 = 180^\circ - 90^\circ - \arctan(0.1 \times 178) - \arctan(0.001 \times 178) - \arctan(0.00177 \times 178) + \arctan(0.0178 \times 178)$$

逐项计算：

| 项 | 值 |
|---|:---:|
| $\arctan(0.1 \times 178) = \arctan(17.8)$ | $\approx 86.8^\circ$ |
| $\arctan(0.001 \times 178) = \arctan(0.178)$ | $\approx 10.1^\circ$ |
| $\arctan(0.00177 \times 178) = \arctan(0.315)$ | $\approx 17.5^\circ$ |
| $\arctan(0.0178 \times 178) = \arctan(3.168)$ | $\approx 72.5^\circ$ |

$$\gamma_1 = 180^\circ - 90^\circ - 86.8^\circ - 10.1^\circ - 17.5^\circ + 72.5^\circ = 48.12^\circ$$

$$\boxed{\gamma_1 = 48.12^\circ > 45^\circ \quad \checkmark}$$

**满足设计要求 (1)**。

## 四、串联超前校正对系统的影响

### 4.1 正面影响

| 影响 | 说明 |
|------|------|
| **提高相角裕度** | 超前相角直接补偿相角裕度不足 |
| **减小负斜率** | 减小对数幅频特性在剪切频率上的负斜率，提高稳定性 |
| **增大剪切频率** | 提高系统频带宽度，可提高响应速度 |
| **不影响稳态性能** | 幅值补偿后不影响系统稳态性能 |

### 4.2 不宜采用串联超前校正的情况

| 情况 | 原因 |
|------|------|
| **原系统不稳定或稳定裕量很小**，且开环相频特性在剪切频率附近有**较大负斜率** | $\Delta\varphi$ 不足以补偿剪切频率提高导致的滞后相角 |
| $\varphi_m > 60^\circ$ | 参数 $a$ 太大，校正装置难以实现 |

> **通俗语言**：超前校正不是万能的。如果原系统在剪切频率附近相角下降太快（负斜率大），校正后剪切频率右移会导致更大的相角滞后，超前校正"追不上"。另外，如果需要补偿的相角太大（$>60^\circ$），参数 $a$ 会很大，物理上难以实现。

## 五、设计步骤总结

```
串联超前校正设计流程
═══════════════════

① 由稳态性能要求 → 确定开环放大系数 K
        ↓
② 绘制原系统 Bode 图 → 读出 ω_c0 和 γ_0
        ↓
③ 确定 Δφ（通常 5°~20°）
   计算 φ_m = γ* - γ_0 + Δφ
   计算 a = (1+sin φ_m)/(1-sin φ_m)
        ↓
④ 求 L_0(ω) = -10lg a 处的频率 ω_1
   令 ω_m = ω_1
        ↓
⑤ 由 ω_m = 1/(T√a) 求 T
   写出 G_c(s) = (aTs+1)/(Ts+1)
        ↓
⑥ 写出校正后开环传函 G_K(s) = G_0(s)·G_c(s)
   验算 γ_1 ≥ γ* ？
   → 满足 → 设计完成
   → 不满足 → 增大 Δφ，重新迭代
```

## 六、速查表

### 6.1 串联超前校正核心公式

| 项目 | 公式 |
|------|------|
| 超前校正传函 | $G_c(s) = \frac{aTs+1}{Ts+1}$，$a > 1$ |
| 最大超前相角 | $\varphi_m = \arcsin\frac{a-1}{a+1}$ |
| 由 $\varphi_m$ 求 $a$ | $a = \frac{1+\sin\varphi_m}{1-\sin\varphi_m}$ |
| 最大超前相角频率 | $\omega_m = \frac{1}{T\sqrt{a}}$ |
| 最大超前处幅值 | $L_c(\omega_m) = 10\lg a$ (dB) |
| 需补偿的超前角 | $\varphi_m = \gamma^* - \gamma_0 + \Delta\varphi$ |
| $\omega_m$ 确定条件 | $L_0(\omega_m) = -10\lg a$ |

### 6.2 参数选择经验值

| 参数 | 推荐范围 | 说明 |
|------|:---:|------|
| $\Delta\varphi$ | $5^\circ \sim 20^\circ$ | 相频变化慢取小，变化快取大 |
| $\varphi_m$ | $< 60^\circ$ | 超过则 $a$ 太大，不宜用超前校正 |
| $a$ | $< 20$ | $a$ 越大，校正装置越难实现 |

### 6.3 校正效果对比

| 性能指标 | 校正前 | 校正后 |
|----------|:---:|:---:|
| 相角裕度 | 小（可能为负） | 增大（$\geq \gamma^*$） |
| 剪切频率 | $\omega_{c0}$ | $\omega_{c1} > \omega_{c0}$（增大） |
| 频带宽度 | 窄 | 宽（响应快） |
| 稳态性能 | — | 不变 |
