## 三、根轨迹的绘制例题

### 例3.1：$G(s)H(s) = \frac{K_r}{s(s+1)(s+2)}$

**(1) 三条根轨迹**，连续且对称于实轴。

**(2) 起点**：$p_1=0$，$p_2=-1$，$p_3=-2$；终点均在无穷远处（$m=0$）。

**(3) 实轴上**：$0 \to -1$ 和 $-2 \to -\infty$ 为根轨迹。必存在一个分离点。

**(4) 渐近线**：$n-m=3$

$$\sigma_a = \frac{0 + (-1) + (-2)}{3} = -1,\quad \phi_a = \frac{\pi}{3},\ \pi,\ \frac{5\pi}{3}$$

**(5) 分离点方程**：$\frac{1}{d} + \frac{1}{d+1} + \frac{1}{d+2} = 0$

解得 $d_1 = -0.42$（分离点），$d_2 = -1.58$（不在根轨迹上，舍去）。

分离角（$l=2$）：$\frac{\pi}{2}$

**(6) 与虚轴交点**：令 $s=j\omega$ 代入特征方程 $s^3 + 3s^2 + 2s + K_r = 0$

虚部：$-\omega^3 + 2\omega = 0 \Rightarrow \omega_1 = 0,\ \omega_{2,3} = \pm\sqrt{2}$

实部：$-3\omega^2 + K_r = 0 \Rightarrow K_{rc} = 6$

---

### 例3.2：$G(s)H(s) = \frac{K_r(s+2)}{s^2 + 2s + 2}$（圆弧根轨迹）

**(1)** $n=2$（$p_{1,2} = -1 \pm j1$），$m=1$（$z_1 = -2$），两条根轨迹分支。

**(2)** 实轴上：$-2 \to -\infty$ 为根轨迹。

**(3) 分离点方程**：$\frac{1}{d+2} = \frac{1}{d+1+j} + \frac{1}{d+1-j}$

解得 $d_1 = -3.414$（分离点），$d_2 = -0.586$（不是分离点）。分离角 $\frac{\pi}{2}$。

**(4) 起始角**：

$$\theta_{p1} = 180^\circ + \angle(p_1 - z_1) - \angle(p_1 - p_2) = 180^\circ + 45^\circ - 90^\circ = 135^\circ$$

$$\theta_{p2} = 180^\circ + 45^\circ + 90^\circ = 315^\circ\ (= -45^\circ)$$

**(5) 根轨迹曲线**可由相角条件证明是一个**圆弧**：

圆心位于 $(-2, j0)$，半径为 $\sqrt{2}$。

证明方法：令 $s = u + jv$，由相角条件导出 $(u+2)^2 + v^2 = 2$。

---

### 圆弧根轨迹的通用结论

- 由**两个开环极点（实或复数）+ 一个开环实零点**构成的二阶系统，只要实零点没有位于两个实极点之间，根轨迹的复数部分是**以实零点为圆心、以实零点到分离点的距离为半径**的圆（或圆的一部分）
- 由**两个开环零点（实或复数）+ 一个开环实极点**构成的二阶系统，只要实极点没有位于两个实零点之间，根轨迹的复数部分是**以实极点为圆心、以实极点到分离点的距离为半径**的圆（或圆的一部分）

### 例3.3：$G(s)H(s) = \frac{K_r}{s(s+2)(s^2 + 2s + 2)}$（四阶系统）

$n=4$，$m=0$。$p_1=0$，$p_2=-2$，$p_{3,4}=-1 \pm j1$。

**(1)** 实轴上：$0 \to -2$ 为根轨迹。

**(2) 渐近线**：$\sigma_a = -1$，$\phi_a = \frac{\pi}{4},\ \frac{3\pi}{4},\ \frac{5\pi}{4},\ \frac{7\pi}{4}$

**(3) 分离点方程**：解得 $d = -1$（四重分离点）。分离角 $\frac{\pi}{2}$（$l=4$）。

**(4) 起始角**：

$$\theta_{p3} = 360^\circ - [\angle(p_3-0) + \angle(p_3+2) + \angle(p_3-p_4)] = 360^\circ - 135^\circ - 45^\circ - 90^\circ = 90^\circ$$

实际上 $\theta_{p3} = 270^\circ$（即 $-90^\circ$），$\theta_{p4} = 90^\circ$。

**(5) 由相角条件**可验证：两个复数极点 $-1 \pm j1$ 连线构成的线段上所有点都满足相角条件，因此该垂直线段是根轨迹。

**(6) 与虚轴交点**（劳斯判据）：$K_{rc} = 5$，$\omega_c = \pm 1$。

---

### 例3.4：$G(s)H(s) = \frac{K_r}{s(s+4)(s^2 + 4s + 20)}$（三次分离）

$n=4$，$m=0$。$p_1=0$，$p_2=-4$，$p_{3,4}=-2 \pm j4$。

**(1)** 实轴上：$0 \to -4$ 为根轨迹。

**(2) 渐近线**：$\sigma_a = -2$，$\phi_a = \frac{\pi}{4},\ \frac{3\pi}{4},\ \frac{5\pi}{4},\ \frac{7\pi}{4}$

**(3) 分离点方程**：解得 $d_1 = -2$，$d_{2,3} = -2 \pm j\sqrt{6}$。

三个分离点，分离角均为 $\frac{\pi}{2}$（四次分离）。

**(4) 起始角**：$\theta_{p3} = 270^\circ\ (=-90^\circ)$，$\theta_{p4} = 90^\circ$。

**(5) 与虚轴交点**：$\omega_c = \pm\sqrt{10}$，$K_{rc} = 260$。

---

### 例3.5：$G(s)H(s) = \frac{K_r}{s(s+4)(s^2 + 4s + 5)}$（三次分离）

类似例3.4，$p_{3,4} = -2 \pm j$。分离点 $d_1 = -2$，$d_{2,3} = -0.775,\ -3.225$。三次分离角均为 $\frac{\pi}{2}$。$\omega_c = \pm\sqrt{10}/2$，$K_{rc} = 185/4$。

---

### 例3.6：$G(s)H(s) = \frac{K_r}{s(s+3)(s^2 + 2s + 2)}$（四阶系统）

$p_1=0$，$p_2=-3$，$p_{3,4}=-1 \pm j1$。

$\sigma_a = -1.25$。分离点 $d_1 = -2.3$（唯一分离点）。起始角 $\theta_{p3} = 288.43^\circ$，$\theta_{p4} = 71.57^\circ$。$K_{rc} \approx 8.16$，$\omega_c \approx \pm 1.095$。

> 由于 $n-m > 2$，根之和为常数（$=-5$），不可能出现所有四条根轨迹汇集到同一点的分离。

---

### 例3.7：$G(s) = \frac{K(s^2 + 6s + 13)}{s(s+2)(s+4)(s+6)}$（带零点的四阶系统）

$n=4$，$m=2$。$p_1=0$，$p_2=-2$，$p_3=-4$，$p_4=-6$；$z_{1,2} = -3 \pm j2$。

实轴上 $[-6,-4]$ 和 $[-2,0]$ 为根轨迹。$\sigma_a = -3$，$\phi_a = \frac{\pi}{2},\ \frac{3\pi}{2}$。

分离点：$d_1 = -3$，$d_2 = -5.0155$，$d_3 = -0.9845$，$d_{4,5} = -3 \pm j3.4731$。

---

### 例3.8-3.9：零极点相消的影响

**【核心结论】**（设前向通路 $G(s)$，反馈通路 $H(s)$）：

开环零极点存在相消时，需检查闭环是否有对应相消：

| 相消类型 | 处理 |
|----------|------|
| $G(s)$ 中零点和极点相消 | 相消不影响结果（闭环也有对应相消） |
| $H(s)$ 中零点和极点相消 | 相消不影响结果（闭环也有对应相消） |
| $G(s)$ 的零点和 $H(s)$ 的极点相消 | 相消不影响结果 |
| **$G(s)$ 的极点和 $H(s)$ 的零点相消** | 应在根轨迹图中**增加一个分支**：从被消去的开环极点出发，终止于对应的开环零点 |

> 例3.8：极点 $-5$ 与零点 $-5$ 相消是 $G(s)$ 的极点与 $H(s)$ 的零点相消，需补充分支。
> 例3.9：极点 $-4$ 与零点 $-4$ 相消是 $G(s)$ 中相消，且闭环零点也有 $-4$，不影响。

## 四、广义根轨迹

### 4.1 广义根轨迹的概念

普通根轨迹的三个前提：
1. 可变参数是 $K_r$（$0 \to +\infty$）
2. 开环传递函数 $s$ 最高次幂系数为正
3. 系统为负反馈

**广义根轨迹**：其他情况下的根轨迹统称广义根轨迹。以其他参数作为可变参数绘制的根轨迹叫**参数根轨迹**。

### 4.2 0° 根轨迹（正反馈系统）

正反馈系统的特征方程：$1 - G(s)H(s) = 0$，即 $G(s)H(s) = 1$。

**相角条件**：

$$\sum_{j=1}^{m} \angle(s - z_j) - \sum_{i=1}^{n} \angle(s - p_i) = 2k\pi,\ k = 0, \pm1, \pm2, \ldots$$

称为 **0° 相角条件**。

> 负反馈 → 180° 根轨迹；正反馈 → 0° 根轨迹。幅值条件不变。

**0° 根轨迹需修改的三条规则**：

| 规则 | 180° 根轨迹 | 0° 根轨迹 |
|------|------------|----------|
| **规则3**（实轴） | 右侧零极点数为**奇数** | 右侧零极点数为**偶数** |
| **规则4**（渐近线倾角） | $\phi_a = \frac{(2k+1)\pi}{n-m}$ | $\phi_a = \frac{2k\pi}{n-m}$ |
| **规则5**（起始/终止角） | $(2k+1)\pi + \cdots$ | $2k\pi + \cdots$ |

分离点方程不变，但需考虑规则3变化的影响。分离角规则不变（仍为 $\frac{(2k+1)\pi}{l}$）。

#### 正反馈根轨迹例题

**【例4.1】** $G(s)H(s) = \frac{K_r}{s(s+1)(s+2)}$（正反馈）

- 实轴根轨迹：$0 \to +\infty$ 和 $-1 \to -2$
- 分离点：$d_2 = -1.58$（$d_1 = -0.42$ 不在正反馈根轨迹上，舍去）
- 渐近线：$\sigma_a = -1$，$\phi_a = 0^\circ,\ 120^\circ,\ 240^\circ$
- 与虚轴交点：$K_{rc} = 6$，$\omega_c = \pm\sqrt{2}$

**【例4.2】** $G(s)H(s) = \frac{K(s+2)}{s(s+3)(s^2+2s+2)}$（正反馈）

- 实轴根轨迹（0°规则）：$-3 \to -\infty$，$-2 \to +\infty$
- 起始角：$\theta_{p3} = 288.43^\circ$，$\theta_{p4} = 71.57^\circ$
- 分离点：$d_1 = -0.8026$，$d_{2,3} = -2.3487 \pm j0.8447$

### 4.3 参数根轨迹

**方法**：将系统特征方程写为 $1 \pm G(s)H(s) = 0$，以参数 $A: 0 \to \infty$ 为变量。

1. 将含参数 $A$ 的项合并：$1 \pm G(s)H(s) = Q(s) \pm A \cdot P(s) = 0$
2. 两边除以 $Q(s)$：$1 \pm A \cdot \frac{P(s)}{Q(s)} = 0$
3. 则 $A \cdot \frac{P(s)}{Q(s)} = \mp 1$ 即为**等效根轨迹方程**，$A \cdot \frac{P(s)}{Q(s)}$ 为**等效开环传递函数**
4. 视根轨迹方程等于 $+1$ 还是 $-1$，选择 0° 或 180° 根轨迹规则

> 等效开环传递函数与原系统有**相同的闭环极点**，但闭环零点一般不相同。

**【例4.3】** $G(s)H(s) = \frac{2}{s(Ts+1)(s+2)}$，以 $T$ 为可变参数。

特征方程：$Ts^2(s+2) + s^2 + 2s + 2 = 0$

等效开环传递函数：$G'(s)H'(s) = \frac{Ts^2(s+2)}{s^2 + 2s + 2}$

等效系统有 3 个零点 $z_{1,2}=0$，$z_3=-2$ 和 2 个极点 $p_{1,2}=-1 \pm j1$。

按 180° 根轨迹规则绘制（$m > n$）。实轴上：$-\infty \to -2$。起始角：$\theta_{p1} = 45^\circ$，$\theta_{p2} = 315^\circ$。与虚轴无交点。

### 4.4 非最小相位系统

> **最小相位系统**：所有开环零点和开环极点都位于 S 平面左半部的（负）反馈控制系统。
> **非最小相位系统**：在 S 右半平面有开环零极点的（负）反馈控制系统。

**绘制规则确定方法**：将开环传递函数写成标准形式，确保分子和分母中 $s$ 的最高次幂系数为正。若有负号提出，按 0° 根轨迹规则作图；否则按 180° 根轨迹规则。

**【例4.4】** $G(s)H(s) = \frac{K_r(s+1)}{s(s-1)(s^2 + 2s + 2)}$（右半平面极点）

- 负反馈，分子分母最高次幂系数已为正 → 按 180° 根轨迹规则
- $p_1=0$，$p_2=1$（右半平面），$p_{3,4}=-1 \pm j1$，$z_1=-1$
- 实轴：$0 \to 1$ 和 $-1 \to -\infty$
- 渐近线：$n-m=3$，$\sigma_a = \frac{0+1+(-1+j1)+(-1-j1)-(-1)}{3} = 0$
- 分离点：$d_1 = 0.55$，$d_2 = -1.55$
- 起始角：$\theta_{p3} \approx 251.6^\circ$，$\theta_{p4} \approx 108.4^\circ$

## 六、解题通法总结

### 5.1 普通根轨迹绘制步骤（8步法）

```
① 化为零极点形式 → 标出 p_i(×), z_j(○)
② 确定 n, m → 确定分支数和终点
③ 规则3: 实轴上的根轨迹
④ 规则4: 渐近线（交点 σ_a, 倾角 φ_a）
⑤ 规则5: 起始角/终止角（如有复数零极点）
⑥ 规则6: 分离点 → 解分离点方程 → 验证是否在根轨迹上
⑦ 规则7: 与虚轴交点（s=jω 代入或劳斯判据）
⑧ 规则8: 根之和（n-m≥2时）验证 → 标注箭头和 K_r
```

### 5.2 确定采用哪套规则的判断方法

```
特征方程 → 化为 s 最高次幂系数为正的形式
  → 根轨迹方程 = -1 → 180° 根轨迹规则
  → 根轨迹方程 = +1 → 0° 根轨迹规则
```

### 5.3 三类根轨迹规则对照

| 规则 | 180° 根轨迹 | 0° 根轨迹 |
|------|------------|----------|
| 相角条件 | $(2k+1)\pi$ | $2k\pi$ |
| 实轴上的根轨迹 | 右侧极点+零点数为**奇数** | 右侧极点+零点数为**偶数** |
| 渐近线倾角 | $\phi_a = \frac{(2k+1)\pi}{n-m}$ | $\phi_a = \frac{2k\pi}{n-m}$ |
| 渐近线交点 | 相同 | 相同 |
| 起始角 | $(2k+1)\pi + \sum\angle(p-z_j) - \sum_{i\neq l}\angle(p-p_i)$ | $2k\pi + \sum\angle(p-z_j) - \sum_{i\neq l}\angle(p-p_i)$ |
| 分离点方程 | 相同 | 相同 |
| 分离角 | $\frac{(2k+1)\pi}{l}$ | $\frac{(2k+1)\pi}{l}$ |

### 5.4 参数根轨迹求解步骤

```
① 写出闭环特征方程 1 ± G(s)H(s) = 0
② 将含参数 A 的项合并: Q(s) ± A·P(s) = 0
③ 写等效开环传递函数: G_eq(s) = A·P(s)/Q(s)
④ 确定使用 180° 还是 0° 根轨迹规则
⑤ 根据 G_eq(s) 的零极点绘制根轨迹
```

### 5.5 零极点相消的判断

| 相消位置 | 是否需补画分支 |
|----------|:----------:|
| $G(s)$ 中零极点相消 | 不需要 |
| $H(s)$ 中零极点相消 | 不需要 |
| $G(s)$ 零点与 $H(s)$ 极点相消 | 不需要 |
| **$G(s)$ 极点与 $H(s)$ 零点相消** | **需要** |
