# 第3讲：控制系统的传递函数

---

## 一、传递函数的基本概念

### 1.1 为什么需要传递函数

微分方程模型是时域描述，直观但存在不足：
- 如果系统结构改变或某个参数变化，就要重新列写并求解微分方程
- 不便于系统分析和设计

用拉氏变换求解微分方程时，可以得到控制系统在**复域**的数学模型——**传递函数**：
- 可表征系统的动态特性
- 可用于研究结构参数变化对系统性能的影响

### 1.2 传递函数的定义

**传递函数**：线性定常系统在**零初始条件**下，系统输出量的拉氏变换与系统输入量的拉氏变换之比。

$$G(s) = \frac{C(s)}{R(s)}$$

**几点说明**：
- 传递函数只适用于**线性定常**系统（非线性、时变系统没有传递函数）
- 必须满足零初始条件，否则不能直接用上述定义
- 传递函数摒弃了非零初始状态对响应的影响，专门用来考察系统本身的特性

**零初始条件的含义**：
1. 系统的输入在 $t > 0$ 时才作用于系统，即在 $t = 0^-$ 时系统输入及其各项导数均为零
2. 输入量在加于系统之前，系统为稳态，即在 $t = 0^-$ 时输出及其所有导数项为零

### 1.3 从微分方程到传递函数

设线性定常系统由 $n$ 阶线性常微分方程描述：

$$a_n \frac{d^n c(t)}{dt^n} + a_{n-1} \frac{d^{n-1} c(t)}{dt^{n-1}} + \cdots + a_0 c(t) = b_m \frac{d^m r(t)}{dt^m} + \cdots + b_0 r(t)$$

在**零初始条件**下，对等式两边求拉氏变换（$\frac{d}{dt} \to s$）：

$$[a_n s^n + a_{n-1} s^{n-1} + \cdots + a_0]C(s) = [b_m s^m + b_{m-1} s^{m-1} + \cdots + b_0]R(s)$$

得标准形式：

$$G(s) = \frac{C(s)}{R(s)} = \frac{b_m s^m + b_{m-1} s^{m-1} + \cdots + b_0}{a_n s^n + a_{n-1} s^{n-1} + \cdots + a_0} = \frac{M(s)}{N(s)}$$

---

### 1.4 典型系统传递函数速查

| 系统 | 微分方程 | 传递函数 |
|------|----------|----------|
| 机械位移系统 | $\frac{m}{k}\ddot{y} + \frac{f}{k}\dot{y} + y = \frac{1}{k}F$ | $G(s) = \frac{1}{ms^2 + fs + k}$ |
| RLC电路系统 | $LC\ddot{u}_c + RC\dot{u}_c + u_c = u_r$ | $G(s) = \frac{1}{LCs^2 + RCs + 1}$ |
| 直流电动机（一阶） | $T\dot{\omega} + \omega = K_1 u_a + K_2 M_L$ | $G_1(s) = \frac{K_1}{Ts+1},\ G_2(s) = \frac{K_2}{Ts+1}$ |
| 轮式机器人（闭环） | $J\ddot{\theta} + (k - \frac{1}{2}mgh)\theta = kr$ | $G(s) = \frac{k}{Js^2 + k - \frac{1}{2}mgh}$ |

---

### 1.5 传递函数的基本概念（核心术语）

$$G(s) = \frac{M(s)}{N(s)} = \frac{b_m s^m + b_{m-1} s^{m-1} + \cdots + b_0}{a_n s^n + a_{n-1} s^{n-1} + \cdots + a_0}$$

| 术语 | 定义 |
|------|------|
| **特征多项式** | 分母多项式 $N(s)$ |
| **特征方程** | $N(s) = 0$ |
| **极点（特征根）** | $N(s) = 0$ 的根 |
| **零点** | $M(s) = 0$ 的根 |
| **系统阶次** | 分母多项式的阶次 $n$ |
| **零极点分布图** | 在复数平面上，用 ◯ 表示零点，用 ╳ 表示极点 |

---

### 1.6 传递函数的三种呈现形式

#### 形式一：有理分式形式

$$G(s) = \frac{b_m s^m + b_{m-1} s^{m-1} + \cdots + b_0}{a_n s^n + a_{n-1} s^{n-1} + \cdots + a_0}$$

按 $s$ 的降幂排列的标准多项式比值形式。

#### 形式二：零极点形式

将分子分母因式分解：

$$G(s) = \frac{b_m}{a_n} \cdot \frac{(s - z_1)(s - z_2) \cdots (s - z_m)}{(s - p_1)(s - p_2) \cdots (s - p_n)} = k^* \frac{\prod_{i=1}^{m}(s - z_i)}{\prod_{j=1}^{n}(s - p_j)}$$

| 符号 | 含义 |
|------|------|
| $z_i$ | 系统的零点 |
| $p_j$ | 系统的极点 |
| $k^* = b_m / a_n$ | **根轨迹增益** |

- 零极点完全取决于系统参数
- 若零极点为复数，必**共轭成对出现**

#### 形式三：时间常数形式（尾一多项式形式）

将分子、分母多项式变为常数项为 1 的多项式，在实数范围内因式分解：

$$G(s) = K \cdot \frac{s^l (\tau_1 s + 1)(\tau_2^2 s^2 + 2\xi_2 \tau_2 s + 1) \cdots}{s^v (T_1 s + 1)(T_2^2 s^2 + 2\xi_2' T_2 s + 1) \cdots}$$

| 符号 | 含义 |
|------|------|
| $\tau_i, T_j$ | **时间常数** |
| $K$ | **传递系数（静态放大系数）**，即 $s = 0$ 时输出与输入的稳态比值 |

**$K$ 与 $k^*$ 的关系**：

$$K = k^* \cdot \frac{\prod_{i=1}^{m}(-z_i)}{\prod_{j=1}^{n}(-p_j)}$$

> 一次因子对应实数零极点，二次因子对应共轭复数零极点。

---

### 1.7 例题：三种形式的转换

已知 $G(s) = \frac{s + 2}{2s^2 + 10s + 8}$，求零点、极点、根轨迹增益和传递系数。

**解**：

化为零极点形式：
$$G(s) = \frac{s + 2}{2(s^2 + 5s + 4)} = \frac{0.5(s + 2)}{(s + 1)(s + 4)}$$

- **零点**：$z = -2$
- **极点**：$p_1 = -1,\ p_2 = -4$
- **根轨迹增益**：$k^* = 0.5$

化为时间常数形式：
$$G(s) = \frac{2(0.5s + 1)}{8(0.25s^2 + 1.25s + 1)} = 0.25 \cdot \frac{0.5s + 1}{0.25s^2 + 1.25s + 1}$$

- **传递系数**：$K = 0.25$

## 二、传递函数的性质与求解

### 2.1 传递函数的七大性质

| # | 性质 | 说明 |
|---|------|------|
| 1 | **与微分方程等价** | 将微分方程算符 $d/dt$ 用复数 $s$ 置换即得传递函数（零初始条件）；反之亦然 |
| 2 | **反映系统固有特性** | 传递函数与输入信号和初始条件无关，仅由系统本身的结构和参数决定 |
| 3 | **异物同构性** | 不同的物理系统可能有相同的传递函数；同一系统可以有不同的传递函数（多输入多输出时用传函阵） |
| 4 | **单入单出** | 一个传递函数只能表示一个输入对一个输出的函数关系；MIMO 系统用**传递函数矩阵**（$n \times m$ 阶） |
| 5 | **与脉冲响应的关系** | 传递函数与单位脉冲响应是拉氏变换与反变换关系：$C(s) = G(s)R(s)$，当 $r(t) = \delta(t)$ 时 $R(s) = 1$，故 $C(s) = G(s)$，即 $g(t) = \mathcal{L}^{-1}[G(s)]$ |
| 6 | **物理现实性条件** | $n \geq m$（分母阶次 $\geq$ 分子阶次），因为现实系统具有惯性且能量有限 |
| 7 | **局限性** | 只适用于线性定常系统；不反映初始状态信息；不反映系统内部任何信息 |

**关于 $n \geq m$ 的说明**：若 $m > n$，例如 $G(s) = s$，则当输入为单位阶跃 $1(t)$ 时：
$$c(t) = \mathcal{L}^{-1}[s \cdot \frac{1}{s}] = \mathcal{L}^{-1}[1] = \delta(t)$$
输出为冲激信号，这在物理上无法实现。

---

### 2.2 传递函数的求解

#### 情况一：零初始条件（标准方法）

**例2.1**：已知系统在零初始条件下，输入 $r(t) = 1(t)$，输出 $c(t) = 1 - 2e^{-t} + e^{-2t}\ (t \geq 0)$，求 $G(s)$。

**解**：
- $R(s) = \frac{1}{s}$
- $C(s) = \frac{1}{s} - \frac{2}{s+1} + \frac{1}{s+2}$
- $G(s) = \frac{C(s)}{R(s)} = s \cdot C(s) = 1 - \frac{2s}{s+1} + \frac{s}{s+2} = \frac{s^2 + 3s + 2 - 2s(s+2) + s(s+1)}{(s+1)(s+2)} = \frac{2}{(s+1)(s+2)}$

**通法**：分别求输入输出的拉氏变换，直接作比。$G(s) = C(s)/R(s)$。

---

#### 情况二：非零初始条件（重点）

**核心知识点**：非零初始条件下，系统的**全响应 = 零输入响应 + 零状态响应**

对一般微分方程在非零初始条件下取拉氏变换（利用微分定理）：

$$C(s) = \underbrace{\frac{f(s, a_i, c(0), \dot{c}(0), \cdots) + g(s, b_j, r(0), \dot{r}(0), \cdots)}{a_n s^n + \cdots + a_0}}_{C_1(s):\text{ 零输入响应}} + \underbrace{\frac{(b_m s^m + \cdots + b_0)R(s)}{a_n s^n + \cdots + a_0}}_{C_2(s):\text{ 零状态响应}}$$

| 分量 | 由什么产生 | 特性 |
|------|-----------|------|
| **零输入响应** $C_1(s)$ | 由初始条件产生，与输入无关 | 分母为 $N(s)$；改变输入不改变零输入响应 |
| **零状态响应** $C_2(s)$ | 由输入信号产生，与初始条件无关 | $C_2(s) = G(s)R(s)$，传递函数定义成立 |

由于线性系统满足叠加原理：
$$\text{全响应} = \text{零输入响应} + \text{零状态响应}$$

---

#### 留数定理求拉氏反变换（部分分式展开）

以无重根情况为例：

**零输入响应**：
$$C_1(s) = \sum_{j=1}^{n} \frac{\operatorname{Res}_{s=p_j}[C_1(s)]}{s - p_j}$$
其中 $p_j$ 为 $N(s) = 0$ 的根（系统的特征根）。

**零状态响应**：设输入象函数 $R(s) = \frac{R_N(s)}{\prod_{k=1}^{l}(s - q_k)}$

$$C_2(s) = \sum_{j=1}^{n} \frac{\operatorname{Res}_{s=p_j}[C_2(s)]}{s - p_j} + \sum_{k=1}^{l} \frac{\operatorname{Res}_{s=q_k}[C_2(s)]}{s - q_k}$$
其中 $q_k$ 为输入象函数分母 = 0 的根。

> 零状态响应由两部分叠加：系统固有模态（特征根 $p_j$）+ 输入函数决定的模态（$q_k$）

---

#### 例2.2：非零初始条件下求传递函数

**已知**：$c(0) = -1,\ \dot{c}(0) = 0$，$r(t) = 1(t)$，输出 $c(t) = 1 - 4e^{-t} + 2e^{-2t}\ (t \geq 0)$，求 $G(s)$。

**解**（待定系数法）：

**Step 1**：由 $C(s)$ 结构判断系统特征根。从 $c(t)$ 的形式可知系统有两个特征根 $-1$ 和 $-2$。

**Step 2**：设零输入响应 $c_1(t) = ae^{-t} + be^{-2t}$。

代入初始条件：
$$\begin{cases} c_1(0) = a + b = c(0) = -1 \\ \dot{c}_1(0) = -a - 2b = \dot{c}(0) = 0 \end{cases}$$

解得 $a = -2,\ b = 1$，即 $c_1(t) = -2e^{-t} + e^{-2t}$。

**Step 3**：求零状态响应 $c_2(t) = c(t) - c_1(t) = 1 - 2e^{-t} + e^{-2t}$。

**Step 4**：求传递函数：
$$R(s) = \frac{1}{s},\quad C_2(s) = \frac{1}{s} - \frac{2}{s+1} + \frac{1}{s+2}$$

$$G(s) = \frac{C_2(s)}{R(s)} = s \cdot C_2(s) = \frac{2}{(s+1)(s+2)} = \frac{2}{s^2 + 3s + 2}$$

---

#### 验证练习

已知 $G(s) = \frac{2}{s^2 + 3s + 2}$，$c(0) = -1,\ \dot{c}(0) = 0$，$r(t) = 1(t)$，求系统的全响应 $c(t)$。

**方法一**（通过微分方程）：
- 由 $G(s)$ 得微分方程：$\ddot{c} + 3\dot{c} + 2c = 2r$
- 非零初始条件下取拉氏变换，代入 $c(0), \dot{c}(0), R(s)$，反变换

**方法二**（零输入 + 零状态）：
- 零状态响应：$c_2(t) = \mathcal{L}^{-1}[G(s) \cdot \frac{1}{s}] = 1 - 2e^{-t} + e^{-2t}$
- 零输入响应：由特征根 $-1, -2$ 设 $c_1(t) = a_1 e^{-t} + a_2 e^{-2t}$，代入初始条件求 $a_1, a_2$
- 全响应：$c(t) = c_2(t) + c_1(t)$

结果：$c(t) = 1 - 4e^{-t} + 2e^{-2t}\ (t \geq 0)$

## 三、案例：轮式机器人平衡控制系统的改进设计

### 3.1 传递函数

被控对象 + 比例控制器 $\tau = k(\theta^* - \theta)$，闭环传递函数：

$$G(s) = \frac{\theta(s)}{R(s)} = \frac{k}{Js^2 + k - \frac{1}{2}mgh}$$

### 3.2 零输入响应分析

令 $\alpha = k - \frac{1}{2}mgh$，参考输入 $R(s) = 0$ 时（只考虑初始扰动）：

$$\theta(s) = \frac{\theta(0)s + \dot{\theta}(0)}{Js^2 + \alpha}$$

| 条件 | 特征根 | 时域响应 | 系统表现 |
|------|--------|----------|----------|
| $\alpha > 0$ | 纯虚根 $\pm j\sqrt{\alpha/J}$ | $\theta(t) = \frac{\theta(0)}{J}\cos(\sqrt{\alpha/J}\,t) + \frac{\dot{\theta}(0)}{J}\sin(\sqrt{\alpha/J}\,t)$ | 等幅振荡（临界稳定） |
| $\alpha < 0$ | 实根 $\pm\sqrt{-\alpha/J}$（一正一负） | $\theta(t) \to \infty$ | 发散倒塌（不稳定） |

### 3.3 问题：如何克服等幅振荡？

仅用**比例控制（P控制）**只能实现等幅振荡（临界稳定），无法使系统衰减收敛到平衡点。

**改进方向**：引入**微分控制（PD控制）**——在控制器中加入角速度反馈 $\tau = k_p(\theta^* - \theta) - k_d \dot{\theta}$，使传递函数分母出现一阶导数项（阻尼项），实现衰减振荡。

## 四、解题通法总结

### 4.1 由已知条件求传递函数的三种通法

| 情况 | 方法 |
|------|------|
| 已知微分方程 | 零初始条件下，将 $d/dt$ 替换为 $s$，求 $C(s)/R(s)$ |
| 已知零初始条件的输入输出响应 | $G(s) = C(s)/R(s)$，分别拉氏变换后作比 |
| 已知非零初始条件的输入输出响应 | ① 从 $c(t)$ 形式判断特征根 → ② 设零输入响应 $c_1(t)$，用初始条件待定系数 → ③ $c_2(t) = c(t) - c_1(t)$ → ④ $G(s) = \mathcal{L}[c_2(t)]/R(s)$ |

### 4.2 非零初始条件求解传递函数的通法（待定系数法流程图）

```
已知: c(0), ċ(0), ..., r(t), c(t)
         ↓
① 从 c(t) 的指数项 e^(pt) 判断特征根 p_j
         ↓
② 设零输入响应: c₁(t) = Σ A_j·e^(p_j·t)
         ↓
③ 用初始条件代入 c₁(t) 及其导数，解待定系数 A_j
         ↓
④ 求零状态响应: c₂(t) = c(t) - c₁(t)
         ↓
⑤ 求传递函数: G(s) = L[c₂(t)] / R(s)
```

### 4.3 传递函数三种形式的互化

$$G(s) = \underbrace{\frac{b_m s^m + \cdots + b_0}{a_n s^n + \cdots + a_0}}_{\text{有理分式形式}} = \underbrace{k^* \frac{\prod(s - z_i)}{\prod(s - p_j)}}_{\text{零极点形式}} = \underbrace{K \cdot \frac{\prod(\tau_m s + 1)(\tau^2 s^2 + 2\xi\tau s + 1)\cdots}{\prod(T_n s + 1)(T^2 s^2 + 2\xi' T s + 1)\cdots}}_{\text{时间常数形式}}$$

**转换关键公式**：
- 根轨迹增益：$k^* = \frac{b_m}{a_n}$
- 传递系数：$K = k^* \cdot \frac{\prod(-z_i)}{\prod(-p_j)}$（即 $s = 0$ 时 $G(s)$ 的值）

### 4.4 由传递函数求全响应的两种方法

| 方法 | 步骤 | 适用场景 |
|------|------|----------|
| **方法一（微分方程法）** | $G(s)$ → 微分方程 → 取拉氏变换（代入初始条件）→ 解出 $C(s)$ → 反变换 | 直接且通用 |
| **方法二（分解法）** | 零状态响应 $c_2(t) = \mathcal{L}^{-1}[G(s)R(s)]$ + 零输入响应 $c_1(t)$（由特征根设形式，用初始条件定系数） | 物理意义清晰，便于分析 |

### 4.5 传递函数的重要性质速查

| 性质 | 关键结论 |
|------|----------|
| 固有性 | $G(s)$ 只与系统结构和参数有关，与输入和初始条件无关 |
| 相似性 | 不同物理系统可有相同 $G(s)$ |
| 多输入多输出 | 用传递函数矩阵 $G(s)_{n \times m}$ |
| 脉冲响应 | $g(t) = \mathcal{L}^{-1}[G(s)]$ |
| 物理可实现 | $n \geq m$ |
| 零初始条件 | $C(s) = G(s)R(s)$ 仅在此条件下成立 |
