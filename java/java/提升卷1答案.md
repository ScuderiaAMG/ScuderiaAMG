## 一、阅读题（共40分）

### 1.1（10分）运行结果

```
148523690|5239a
```

**解析**：Java类初始化顺序：
1. **类加载阶段（仅一次）**：先父类静态块 → 后子类静态块，按继承链从顶向下。所以先 A 静态块输出 `1`，再 B 静态块输出 `4`，再 C 静态块输出 `8`。输出：**`148`**
2. **第一次 `new C()`**：
   - A 实例初始化块 `2` → A 构造器 `3` → B 实例初始化块 `5` → B 无参构造器 `6` → C 实例初始化块 `9` → C 无参构造器 `0`
   - 输出：**`523690`**
3. **`|` 分隔符**
4. **第二次 `new C(10)`**（静态块不再执行！类已加载）：
   - A 实例初始化块 `2` → A 构造器 `3` → B 实例初始化块 `5` → `super(x)` 调用 B(int) `7` → C 实例初始化块 `9` → C(int) 自身代码 `a`
   - 输出：**`5239a`**

最终输出：`148523690|5239a`

### 1.2（10分）

**（1）运行结果**：
```
Cat meows
Animal class
Cat purrs
Not a Cat
Animal speaks
Cat meows
```

**（2）静态方法与实例方法的区别**：
- `a.info()` 输出 `"Animal class"` 而非 `"Cat class"`，因为**静态方法不能被重写（Override），只能被隐藏（Hide）**。静态方法的调用在**编译时**根据**引用类型**决定——`a` 的引用类型是 `Animal`，所以调用 `Animal.info()`。
- 实例方法 `speak()` 的调用则在**运行时**根据**实际对象类型**决定（动态绑定/晚联编），所以 `a.speak()` 调用的是 `Cat.speak()`。
- **核心区别**：静态方法 → 编译时绑定（看引用类型）；实例方法 → 运行时绑定（看实际对象类型）。

### 1.3（10分）运行结果

```
x=10
y=20
param=100
localVar=30
y=20
```

**解析**：
- 局部内部类 `LocalInner` 可以访问外部类的**实例成员** `x`（即便是 `private`）和**静态成员** `y`
- 局部内部类可以访问方法中的局部变量 `param` 和 `localVar`，但前提是它们必须是 `final` 或 effectively final
- 静态嵌套类 `StaticNested` **只能访问**外部类的静态成员 `y`，不能访问实例成员 `x`

### 1.4（10分）

**（1）运行结果**：
```
Result: 8
Result: 28
Calculator reset
Result: 0
```

**解析**：
- `calcs[0]` 是 `Adder`：`calculate(3,5)` → `result = 8`，`displayResult()` 输出 `Result: 8`
- `calcs[1]` 是 `Multiplier`：`calculate(4,7)` → `result = 28`（4×7），输出 `Result: 28`
- `calcs[2]` 也是 `Multiplier`：`calculate(6,8)` → `result = 48`；但 `reset()` 未被重写，直接调用父类 `Calculator.reset()` → `result = 0`，输出 `Calculator reset`，然后 `displayResult()` 输出 `Result: 0`

**（2）**：
- `displayResult()` 声明为 `final` 意味着**任何子类都不能重写该方法**，保证所有子类使用统一的显示逻辑。
- `reset()` 在 `Adder` 中重写而 `Multiplier` 中不重写，体现了两点：① **继承**——`Multiplier` 直接复用父类的 `reset()` 实现；② **多态**——子类可以根据需要选择性地重写父类方法。

**（3）**：
**不能**。`final` 和 `abstract` 是两个矛盾的修饰符：`abstract` 要求该类必须有子类来实现抽象方法，而 `final` 禁止该类被继承。两者语义互斥，编译器会报错。

## 二、改错题（共20分）

### 2.1（10分）

**错误**：`Child.process()` 重写父类方法时抛出了比父类更宽泛的异常。父类 `Parent.process()` 声明 `throws Exception`，子类重写时声明 `throws RuntimeException, IOException`。虽然 `RuntimeException` 是非受检异常可以抛出，但 `IOException` 与父类的 `Exception` 关系特殊——实际上这里 `IOException` 是 `Exception` 的子类，按理说窄化是合法的。但真正的问题是：父类抛出 `Exception`，子类重写时**试图同时抛出 IOException（受检异常，Exception的子类）和RuntimeException（非受检异常）**。

**核心问题**：实际上这段代码在 Java 中是**编译通过**的——因为 `IOException` 是 `Exception` 的子类（异常窄化），`RuntimeException` 是非受检异常。所以这里的"错误"需要重新审视。

**重新分析**：真正的问题是代码**没有编译错误**。但题目设计中的陷阱在于——子类抛出了两个异常类型，如果要把这个作为改错题，实际错误应该是**未处理的方法调用异常**或**逻辑问题**。

**修正后的改错题应该是**：`Child.process()` 抛出了 `Exception` 的**子类之外**的异常（比如抛出比父类更宽的异常）。此处为题目设计——实际应该改动为：

如果子类改为：
```java
@Override
public void process() throws Exception {
    System.out.println("Child processing");
}
```
这样与父类一致，或只抛出非受检异常：
```java
@Override
public void process() {
    System.out.println("Child processing");
}
```

**补充说明（考查知识点）**：Java重写规则中，子类重写方法的**受检异常**不能比父类更宽泛，但可以不抛出或抛出更窄的受检异常。非受检异常（RuntimeException及其子类）不受此限制。

### 2.2（10分）

**错误**：`Diagram` 类同时实现了 `Drawable` 和 `Scalable` 两个接口，而这两个接口都有一个同名的 `default` 方法 `printInfo()`。Java 编译器无法确定使用哪个接口的默认实现，导致**编译错误**。

**修改办法**：在 `Diagram` 类中**必须重写** `printInfo()` 方法来解决冲突：

```java
class Diagram implements Drawable, Scalable {
    @Override
    public void draw() {
        System.out.println("Drawing diagram");
    }
    
    @Override
    public void scale(double factor) {
        System.out.println("Scaling by " + factor);
    }
    
    @Override
    public void printInfo() {
        // 方案一：自己实现
        System.out.println("This is a diagram (drawable & scalable)");
        // 方案二：选择某个接口的实现
        // Drawable.super.printInfo();
        // 方案三：两个都调用
        // Drawable.super.printInfo();
        // Scalable.super.printInfo();
    }
}
```

**关键知识点**：当一个类实现多个接口且这些接口有同名默认方法时，该类必须显式重写该方法来解决二义性，否则编译不通过。

### 3.1（15分）泛型工具类与排序 — 参考代码

```java
public class Pair<T extends Comparable<T>> {
    private T first;
    private T second;
    
    public Pair(T first, T second) {
        this.first = first;
        this.second = second;
    }
    
    public T getFirst() { return first; }
    public T getSecond() { return second; }
    
    public T getMax() {
        // first.compareTo(second) > 0 表示 first > second
        if (first.compareTo(second) >= 0) {
            return first;
        } else {
            return second;
        }
    }
    
    public void swap() {
        T temp = first;
        first = second;
        second = temp;
    }
    
    @Override
    public String toString() {
        return "Pair[" + first + ", " + second + "]";
    }
    
    public static void main(String[] args) {
        // 测试 Integer
        Pair<Integer> intPair = new Pair<>(15, 8);
        System.out.println("初始: " + intPair);
        System.out.println("较大值: " + intPair.getMax());
        intPair.swap();
        System.out.println("交换后: " + intPair);
        System.out.println("交换后较大值: " + intPair.getMax());
        
        System.out.println("---");
        
        // 测试 String
        Pair<String> strPair = new Pair<>("Java", "Python");
        System.out.println("初始: " + strPair);
        System.out.println("较大值(字典序): " + strPair.getMax());
        strPair.swap();
        System.out.println("交换后: " + strPair);
    }
}
```

**运行结果**：
```
初始: Pair[15, 8]
较大值: 15
交换后: Pair[8, 15]
交换后较大值: 15
---
初始: Pair[Java, Python]
较大值(字典序): Python
交换后: Pair[Python, Java]
```

### 3.2（12分）自定义异常与验证框架 — 参考代码

```java
class ValidationException extends Exception {
    private int errorCode;
    
    public ValidationException(String message, int errorCode) {
        super(message);
        this.errorCode = errorCode;
    }
    
    public int getErrorCode() { return errorCode; }
}

class User {
    private String username;
    private String email;
    private int age;
    
    public User(String username, String email, int age) 
            throws ValidationException {
        // 验证用户名：长度3-20，只允许字母数字
        if (username == null || username.length() < 3 || username.length() > 20
                || !username.matches("[a-zA-Z0-9]+")) {
            throw new ValidationException("用户名不合法: " + username, 1);
        }
        
        // 验证邮箱：必须包含 @ 和 .
        if (email == null || !email.contains("@") || !email.contains(".")) {
            throw new ValidationException("邮箱不合法: " + email, 2);
        }
        
        // 验证年龄：1-150
        if (age < 1 || age > 150) {
            throw new ValidationException("年龄不合法: " + age, 3);
        }
        
        this.username = username;
        this.email = email;
        this.age = age;
    }
    
    @Override
    public String toString() {
        return "User[用户名=" + username + ", 邮箱=" + email + ", 年龄=" + age + "]";
    }
}

public class UserTest {
    public static void main(String[] args) {
        // 测试用例数组
        Object[][] testCases = {
            {"alice", "alice@example.com", 25},
            {"ab", "bob@test.com", 30},           // 用户名太短
            {"charlie123", "no-at-sign", 28},      // 邮箱无@
            {"dave456", "dave@test.com", 200},     // 年龄超限
            {"eve", "eve@test", -5}                // 用户名短+邮箱无.+年龄负数
        };
        
        for (Object[] tc : testCases) {
            String username = (String) tc[0];
            String email = (String) tc[1];
            int age = (Integer) tc[2];
            
            try {
                User user = new User(username, email, age);
                System.out.println("创建成功: " + user);
            } catch (ValidationException e) {
                String errorMsg;
                switch (e.getErrorCode()) {
                    case 1: errorMsg = "[用户名错误]"; break;
                    case 2: errorMsg = "[邮箱错误]"; break;
                    case 3: errorMsg = "[年龄错误]"; break;
                    default: errorMsg = "[未知错误]";
                }
                System.out.println(errorMsg + " " + e.getMessage());
            }
        }
    }
}
```

**运行结果**：
```

[用户名错误] 用户名不合法: ab
[邮箱错误] 邮箱不合法: no-at-sign
[年龄错误] 年龄不合法: 200
[用户名错误] 用户名不合法: eve
```

### 3.3（13分）模板方法模式 — 数据处理器 — 参考代码

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

abstract class DataProcessor {
    protected List<Integer> data;
    
    public DataProcessor(int[] arr) {
        data = new ArrayList<>();
        for (int val : arr) {
            data.add(val);
        }
    }
    
    // 抽象方法：子类定义处理规则
    protected abstract int process(int value);
    
    // 模板方法：final确保处理流程不被修改
    public final List<Integer> processAll() {
        List<Integer> result = new ArrayList<>();
        for (int val : data) {
            result.add(process(val));
        }
        return result;
    }
    
    public int getSummary() {
        int sum = 0;
        for (int val : processAll()) {
            sum += val;
        }
        return sum;
    }
    
    public void printData() {
        System.out.println("原始数据: " + data);
    }
}

class SquareProcessor extends DataProcessor {
    public SquareProcessor(int[] arr) {
        super(arr);
    }
    
    @Override
    protected int process(int value) {
        return value * value;
    }
}

class DoubleProcessor extends DataProcessor {
    public DoubleProcessor(int[] arr) {
        super(arr);
    }
    
    @Override
    protected int process(int value) {
        return value * 2;
    }
}

public class ProcessorTest {
    public static void main(String[] args) {
        int[] testData = {1, 2, 3, 4, 5};
        
        // 测试 SquareProcessor
        DataProcessor squareProc = new SquareProcessor(testData);
        squareProc.printData();
        System.out.println("平方处理后: " + squareProc.processAll());
        System.out.println("平方和: " + squareProc.getSummary());
        
        System.out.println("---");
        
        // 测试 DoubleProcessor
        DataProcessor doubleProc = new DoubleProcessor(testData);
        doubleProc.printData();
        System.out.println("翻倍处理后: " + doubleProc.processAll());
        System.out.println("翻倍和: " + doubleProc.getSummary());
    }
}
```

**运行结果**：
```
原始数据: [1, 2, 3, 4, 5]
平方处理后: [1, 4, 9, 16, 25]
平方和: 55
---
原始数据: [1, 2, 3, 4, 5]
翻倍处理后: [2, 4, 6, 8, 10]
翻倍和: 30
```
