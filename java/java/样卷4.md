```java
    public static void main(String[] args) {
        String filename = "test.txt";
        
        try {
            FileWriter fw = new FileWriter(filename);
            PrintWriter pw = new PrintWriter(fw);
            pw.println("Line 1: Hello");
            pw.println("Line 2: World");
            pw.close();
            System.out.println("File written successfully");

                System.out.println("Read: " + line);
            }
            br.close();
        } catch (IOException e) {
            System.out.println("IO Error: " + e.getMessage());
        }
    }
}
```

### 1.4（10分）阅读以下程序，回答问题。

```java
import java.util.*;

enum Season {
    SPRING("温暖"),
    SUMMER("炎热"),
    AUTUMN("凉爽"),
    WINTER("寒冷");
    
    private String description;
    
    Season(String description) {
        this.description = description;
    }
    
    public String getDescription() {
        return description;
    }
}

public class EnumTest {
    public static void main(String[] args) {
        for (Season s : Season.values()) {
            System.out.println(s + " -> " + s.getDescription());
        }
        
        Season current = Season.SUMMER;
        switch (current) {
            case SPRING:
                System.out.println("春天来了");
                break;
            case SUMMER:
                System.out.println("夏天到了，注意防暑");
                break;
            case AUTUMN:
                System.out.println("秋高气爽");
                break;
            case WINTER:
                System.out.println("冬天来了，注意保暖");
                break;
        }
    }
}
```

**问题**：（1）写出程序运行结果。（2）说明 `enum` 和普通类有什么区别？

## 三、写代码题（共40分）

请根据要求编写完整的Java程序。

### 3.1（15分）文件复制工具

编写程序：
- 定义方法 `public static void copyFile(String sourcePath, String destPath)` 
- 使用 `FileInputStream` 和 `FileOutputStream` 以字节流方式复制文件
- 使用缓冲区（`byte[] buffer = new byte[1024]`）提高复制效率
- 使用 `try-catch-finally` 确保流被正确关闭
- 在 `main` 方法中调用该方法，从命令行参数获取源文件和目标文件路径
- 如果源文件不存在，输出提示信息

### 3.2（12分）对象序列化

编写程序：
- 定义类 `Student`，实现 `Serializable` 接口
  - 包含属性：`String name`、`int age`、`String studentId`
  - 提供构造方法和 `toString()` 方法
- 定义方法 `public static void serializeStudent(Student s, String filename)`，将 `Student` 对象序列化到文件
- 定义方法 `public static Student deserializeStudent(String filename)`，从文件反序列化读取 `Student` 对象
- 在 `main` 方法中：创建 `Student` 对象 → 序列化保存 → 反序列化读取 → 打印读取的对象信息
