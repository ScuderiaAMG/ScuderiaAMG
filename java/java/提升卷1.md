### 1.2（10分）阅读以下程序，回答问题。

```java
class Animal {
    public static void info() { System.out.println("Animal class"); }
    public void speak() { System.out.println("Animal speaks"); }
}

class Cat extends Animal {
    public static void info() { System.out.println("Cat class"); }
    @Override
    public void speak() { System.out.println("Cat meows"); }
    public void purr() { System.out.println("Cat purrs"); }
}

public class PolyTest {
    public static void main(String[] args) {
        Animal a = new Cat();
        a.speak();
        a.info();
        
        Cat c = (Cat) a;
        c.purr();
        
        Animal a2 = new Animal();
        if (a2 instanceof Cat) {
            ((Cat) a2).purr();
        } else {
            System.out.println("Not a Cat");
        }
        
        Animal[] zoo = {new Animal(), new Cat()};
        for (Animal animal : zoo) {
            animal.speak();
        }
    }
}
```

**问题**：
（1）写出程序运行结果。
（2）为什么 `a.info()` 输出的是 `"Animal class"` 而不是 `"Cat class"`？静态方法的调用规则与实例方法有何不同？

### 1.4（10分）阅读以下程序，回答问题。

```java
abstract class Calculator {
    protected int result;
    
    public Calculator() { result = 0; }
    
    public abstract void calculate(int a, int b);
    
    public final void displayResult() {
        System.out.println("Result: " + result);
    }
    
    public void reset() {
        result = 0;
        System.out.println("Calculator reset");
    }
}

class Adder extends Calculator {
    @Override
    public void calculate(int a, int b) {
        result = a + b;
    }
    
    @Override
    public void reset() {
        super.reset();
        System.out.println("Adder reset complete");
    }
}

class Multiplier extends Calculator {
    @Override
    public void calculate(int a, int b) {
        result = a * b;
    }
}

public class CalcTest {
    public static void main(String[] args) {
        Calculator[] calcs = new Calculator[3];
        calcs[0] = new Adder();
        calcs[1] = new Multiplier();
        calcs[2] = new Multiplier();
        
        calcs[0].calculate(3, 5);
        calcs[0].displayResult();
        
        calcs[1].calculate(4, 7);
        calcs[1].displayResult();
        
        calcs[2].calculate(6, 8);
        calcs[2].reset();
        calcs[2].displayResult();
    }
}
```

**问题**：
（1）写出程序运行结果。
（2）`displayResult()` 方法被声明为 `final`，这意味着什么？`reset()` 方法在 `Adder` 中被重写，在 `Multiplier` 中没有，这体现了面向对象的什么特点？
（3）能否将 `Calculator` 类声明改为 `final abstract class Calculator`？为什么？

### 3.1（15分）泛型工具类与排序

编写程序：
- 定义一个泛型类 `Pair<T extends Comparable<T>>`，包含两个私有属性 `T first` 和 `T second`，构造方法初始化这两个属性
- 提供方法 `T getFirst()`、`T getSecond()`、`T getMax()`（返回两个元素中较大的那个）、`void swap()`（交换两个元素）
- 在 `main` 方法中，创建 `Pair<Integer>` 和 `Pair<String>` 对象，测试各方法并输出结果，特别是测试 `getMax()` 和 `swap()` 的效果

### 3.2（12分）自定义异常与验证框架

编写程序：
- 定义一个自定义异常类 `ValidationException`，继承 `Exception`，包含一个 `int errorCode` 属性和对应的构造方法及getter
- 定义一个类 `User`，包含私有属性 `String username`（长度3-20，只允许字母数字）、`String email`（必须包含@和.）、`int age`（1-150）
- `User` 的构造方法中验证所有属性，任一不合法抛出 `ValidationException`，并携带不同的 `errorCode`（1=用户名非法，2=邮箱非法，3=年龄非法）
- 编写 `main` 方法，使用 `try-catch` 测试多个 `User` 对象的创建（合法+各种非法），捕获异常后根据 `errorCode` 输出对应的中文错误提示

### 3.3（13分）模板方法模式 — 数据处理器

编写程序：
- 定义一个抽象类 `DataProcessor`，包含：
  - 一个 `protected List<Integer> data` 属性
  - 构造方法接收 `int[]` 数组并转换为List
  - 抽象方法 `protected int process(int value)`（单个数据的处理规则）
  - `final` 方法 `public List<Integer> processAll()`（模板方法：遍历所有数据调用 `process()`，返回处理后的列表）
  - 普通方法 `public int getSummary()`：对 `processAll()` 的结果求和
- 定义子类 `SquareProcessor`：`process()` 返回 `value * value`
- 定义子类 `DoubleProcessor`：`process()` 返回 `value * 2`
- 在 `main` 方法中，分别测试两种处理器的 `processAll()` 和 `getSummary()` 效果，并输出原始数据、处理后数据及汇总值
