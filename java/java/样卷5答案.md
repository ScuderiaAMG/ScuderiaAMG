### 1.3（10分）运行结果

```
Inner accessing: Outer message
Static nested: Outer static message
```

**解析**：
- 成员内部类 `InnerClass` 可以访问外部类的**实例成员** `msg`（即使 `msg` 是 `private`），因为内部类隐式持有外部类引用
- 静态嵌套类 `StaticNestedClass` 只能访问外部类的**静态成员** `staticMsg`，不能直接访问实例变量 `msg`

**（1）运行结果**：

**（2）防御性编程技巧**：
- `data == null` 检查：**空引用检查（Null Check）**，防止对 `null` 对象调用 `.length` 导致 `NullPointerException`
- `data.length == 0` 检查：**空数组边界检查（Empty Check）**，防止 `sum / data.length` 发生除以零的 `ArithmeticException`（虽然本题中 `data.length > 0` 时除法不会抛异常，但在计算平均值时，对空数组进行除法操作是不合理的）

## 二、改错题（共20分）

### 2.1（10分）

**错误**：`Thread.sleep(5000)` 声明了 `throws InterruptedException`（已检查异常），但在 `main` 方法中**既没有 `try-catch` 捕获，也没有在方法签名中声明 `throws InterruptedException`** → **编译错误**。

**修改办法**：用 `try-catch` 包裹 `Thread.sleep()`：
```java
try {
    Thread.sleep(5000);
} catch (InterruptedException e) {
    e.printStackTrace();
}
System.out.println("5 seconds passed");
```

### 2.2（10分）

**错误**：`oos.writeObject(new Object());` —— `Object` 类**没有实现 `Serializable` 接口**。`ObjectOutputStream.writeObject()` 要求写入的对象必须实现 `Serializable` 接口，否则会在运行时抛出 **`java.io.NotSerializableException`**。

虽然程序用 `catch (Exception e)` 捕获了异常，程序不会崩溃，但序列化的数据文件 `data.ser` 是不完整的（第三个对象写入失败），反序列化时读取第三个对象会出问题。

**修改办法**：
- 删除 `oos.writeObject(new Object());`，只写入可序列化的对象
- 或创建一个实现 `Serializable` 的自定义类替代 `Object`
```java
// 改为可序列化的对象
oos.writeObject(Integer.valueOf(456));
```

**补充说明**：`oos.writeObject(123)` 这里 `123` 是 `int` 字面量，会被自动装箱为 `Integer`，而 `Integer` 实现了 `Serializable`，所以可以正常写入。反序列化时 `(int) ois.readObject()` 会将返回的 `Integer` 自动拆箱，这是合法操作。

### 3.1（15分）Swing窗口程序 — 参考代码

```java
import javax.swing.*;
import java.awt.*;
import java.awt.event.*;

public class StudentInfoGUI {
    private JTextField nameField;
    private JTextField idField;
    private JTextField ageField;

    public StudentInfoGUI() {
        JFrame frame = new JFrame("学生信息录入");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setLayout(new GridLayout(4, 2));

        // 姓名行
        frame.add(new JLabel("姓名："));
        nameField = new JTextField();
        frame.add(nameField);

        // 学号行
        frame.add(new JLabel("学号："));
        idField = new JTextField();
        frame.add(idField);

        // 年龄行
        frame.add(new JLabel("年龄："));
        ageField = new JTextField();
        frame.add(ageField);

        // 按钮行
        JButton submitBtn = new JButton("提交");
        JButton clearBtn = new JButton("清空");
        frame.add(submitBtn);
        frame.add(clearBtn);

        // 使用内部类实现事件监听
        submitBtn.addActionListener(new ActionListener() {
            public void actionPerformed(ActionEvent e) {
                System.out.println("姓名: " + nameField.getText());
                System.out.println("学号: " + idField.getText());
                System.out.println("年龄: " + ageField.getText());
                System.out.println("---");
            }
        });

        clearBtn.addActionListener(new ActionListener() {
            public void actionPerformed(ActionEvent e) {
                nameField.setText("");
                idField.setText("");
                ageField.setText("");
                System.out.println("已清空所有文本框");
            }
        });

        frame.setSize(350, 200);
        frame.setVisible(true);
    }

    public static void main(String[] args) {
        // 在事件调度线程中创建GUI
        SwingUtilities.invokeLater(new Runnable() {
            public void run() {
                new StudentInfoGUI();
            }
        });
    }
}
```

### 3.2（12分）排序工具类 — 参考代码

```java
public class SortUtil {

    // 冒泡排序
    public static void bubbleSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
    }

    // 选择排序
    public static void selectionSort(int[] arr) {
        int n = arr.length;
        for (int i = 0; i < n - 1; i++) {
            int minIndex = i;
            for (int j = i + 1; j < n; j++) {
                if (arr[j] < arr[minIndex]) {
                    minIndex = j;
                }
            }
            int temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }

    // 打印数组
    public static void printArray(int[] arr) {
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i]);
            if (i < arr.length - 1) {
                System.out.print(", ");
            }
        }
        System.out.println();
    }

    // 复制数组（辅助方法）
    public static int[] copyArray(int[] arr) {
        int[] copy = new int[arr.length];
        for (int i = 0; i < arr.length; i++) {
            copy[i] = arr[i];
        }
        return copy;
    }

    public static void main(String[] args) {
        int[] original = {64, 34, 25, 12, 22, 11, 90};

        System.out.print("排序前数组: ");
        printArray(original);

        // 冒泡排序
        int[] arr1 = copyArray(original);
        bubbleSort(arr1);
        System.out.print("冒泡排序后: ");
        printArray(arr1);

        // 选择排序
        int[] arr2 = copyArray(original);
        selectionSort(arr2);
        System.out.print("选择排序后: ");
        printArray(arr2);
    }
}
```

**运行结果**：
```
排序前数组: 64, 34, 25, 12, 22, 11, 90
冒泡排序后: 11, 12, 22, 25, 34, 64, 90
选择排序后: 11, 12, 22, 25, 34, 64, 90
```

### 3.3（13分）学生管理系统综合题 — 参考代码

```java
import java.util.ArrayList;

class Student {
    private String id;
    private String name;
    private double score;

    public Student(String id, String name, double score) {
        this.id = id;
        this.name = name;
        this.score = score;
    }

    public String getId() {
        return id;
    }

    public String getName() {
        return name;
    }

    public double getScore() {
        return score;
    }

    public String toString() {
        return "Student [学号=" + id + ", 姓名=" + name
                + ", 成绩=" + score + "]";
    }
}

class StudentManager {
    private ArrayList<Student> students = new ArrayList<Student>();

    public void addStudent(Student s) {
        students.add(s);
        System.out.println("添加成功: " + s.getName());
    }

    public Student findById(String id) {
        for (Student s : students) {
            if (s.getId().equals(id)) {
                return s;
            }
        }
        return null;
    }

    public void removeById(String id) {
        Student s = findById(id);
        if (s != null) {
            students.remove(s);
            System.out.println("删除成功: " + s.getName());
        } else {
            System.out.println("未找到学号为 " + id + " 的学生");
        }
    }

    public void printAll() {
        if (students.isEmpty()) {
            System.out.println("暂无学生信息");
            return;
        }
        System.out.println("=== 所有学生信息 ===");
        for (Student s : students) {
            System.out.println(s);
        }
    }

    public double getAverageScore() {
        if (students.isEmpty()) {
            return 0;
        }
        double sum = 0;
        for (Student s : students) {
            sum += s.getScore();
        }
        return sum / students.size();
    }
}

public class StudentSystemTest {
    public static void main(String[] args) {
        StudentManager manager = new StudentManager();

        // 添加学生
        manager.addStudent(new Student("S001", "张三", 85.5));
        manager.addStudent(new Student("S002", "李四", 92.0));
        manager.addStudent(new Student("S003", "王五", 78.5));

        // 打印所有学生
        manager.printAll();

        // 查找学生
        System.out.println("\n--- 查找学号 S002 ---");
        Student found = manager.findById("S002");
        if (found != null) {
            System.out.println("找到: " + found);
        }

        // 删除学生
        System.out.println("\n--- 删除学号 S001 ---");
        manager.removeById("S001");

        // 再次打印
        manager.printAll();

        // 平均成绩
        System.out.println("\n平均成绩: " + manager.getAverageScore());
    }
}
```
