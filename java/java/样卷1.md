public class TestArray {
    public static void main(String[] args) {
        int[] a = {3, 7, 2, 9, 4};
        int max = a[0];
        int min = a[0];
        for (int i = 1; i < a.length; i++) {
            if (a[i] > max) {
                max = a[i];
            }
            if (a[i] < min) {
                min = a[i];

        System.out.println("sum=" + (max + min));
    }
}

## 三、写代码题（共40分）

请根据要求编写完整的Java程序。

### 3.1（15分）学生成绩统计

编写一个类 `ScoreManager`，要求：
- 有一个 `int[]` 数组成员变量存储学生成绩
- 构造方法接收一个 `int[]` 数组参数初始化成绩
- 方法 `double getAverage()` 计算并返回平均分
- 方法 `int getMax()` 返回最高分
- 方法 `int getMin()` 返回最低分
- 编写 `main` 方法测试，创建对象并输出统计结果

### 3.2（12分）银行账户类

编写一个类 `BankAccount`，要求：
- 私有成员变量：`String accountNo`（账号）、`String ownerName`（户主姓名）、`double balance`（余额）
- 构造方法初始化账号、户主姓名和初始余额
- 方法 `void deposit(double amount)` 存款（余额增加）
- 方法 `void withdraw(double amount)` 取款（余额减少，余额不足时提示"余额不足"）
- 方法 `void printInfo()` 打印账户信息
- 编写 `main` 方法测试，创建账户，进行存取款操作并打印信息

### 3.3（13分）接口与实现

编写程序：
- 定义一个接口 `Flyable`，包含方法 `void fly()`
- 定义类 `Bird` 实现 `Flyable` 接口，`fly()` 方法输出 "鸟儿用翅膀飞翔"
- 定义类 `Airplane` 实现 `Flyable` 接口，`fly()` 方法输出 "飞机用引擎飞行"
- 在 `main` 方法中，创建 `Bird` 和 `Airplane` 对象，通过 `Flyable` 接口引用调用 `fly()` 方法，体现多态特性
