## 一、阅读题（共40分）

### 1.1（10分）运行结果

```
list size: 4
list[1]: banana
set size: 3
map size: 3
apple count: 10
```

**解析**：
- `ArrayList` 允许重复元素，添加了4个元素（含重复的 "apple"），`size()` 返回 `4`
- `list.get(1)` 返回索引1处的元素 `"banana"`
- `HashSet` 不允许重复元素，第二次 `add("apple")` 返回 `false`，`size()` 返回 `3`
- `HashMap` 的键不允许重复，第二次 `put("apple", 10)` **覆盖**了之前的 `("apple", 5)`，`size()` 返回 `3`
- `map.get("apple")` 返回最新覆盖的值 `10`

### 1.2（10分）运行结果

```
Queue elements:
5 4 3 2 1 0 
Queue is empty: true
```

**解析**：队列遵循 **FIFO（先进先出）** 原则。循环 `for (int i = 5; i >= 0; i--)` 依次添加 `5, 4, 3, 2, 1, 0`。`remove()` 从队列头部取出元素，所以按添加顺序 `5, 4, 3, 2, 1, 0` 输出。最后队列为空。

### 1.3（10分）运行结果

```
Original: [10, 20, 30, 40]
After add: [5, 10, 20, 30, 40]
After set: [5, 99, 20, 30, 40]
After remove: [5, 99, 30, 40]
```

**解析**：
- 初始列表：`[10, 20, 30, 40]`
- `iter.add(5)`：在迭代器当前位置（最前面）插入 `5` → `[5, 10, 20, 30, 40]`
- 第一次 `iter.next()` 返回 `10`（索引1），`iter.set(99)` 替换为 `99` → `[5, 99, 20, 30, 40]`
- 第二次 `iter.next()` 返回 `20`（索引2），`iter.remove()` 删除它 → `[5, 99, 30, 40]`

### 1.4（10分）

**（1）运行结果**：
```
Value: 100
T type: java.lang.Integer
U type: java.lang.String
T type: java.lang.Integer
U type: java.lang.Double
```

**（2）区别**：
- `MyBox<T>` 中的 `T` 是**类级别的泛型参数**，在创建 `MyBox<Integer>` 对象时被绑定为 `Integer`，该对象的所有方法中 `T` 都代表 `Integer`。
- `inspect<U>` 中的 `U` 是**方法级别的泛型参数**，独立于类的泛型参数，在**每次方法调用时**根据传入的实参类型确定。第一次调用 `inspect("Hello")` 时 `U` 为 `String`，第二次调用 `inspect(3.14)` 时 `U` 为 `Double`。

## 二、改错题（共20分）

### 2.1（10分）

**错误**：使用**原始类型（Raw Type）** `List`（第156行），没有泛型参数。`list.add("Hello")` 添加了 `String` 类型，而 `(Integer) list.get(1)` 试图将 `String` 强制转换为 `Integer`。虽然**编译能通过**（原始类型绕过了泛型检查），但**运行时会抛出 `ClassCastException`**（String 不能转为 Integer）。

**修改办法**：使用泛型约束集合类型，使编译期就能发现类型不匹配问题：
```java
List<Integer> list = new LinkedList<Integer>();
list.add(new Integer(100));
// list.add("Hello");   // 编译错误，String 不能添加到 List<Integer>
```

---

### 2.2（10分）

**错误**：`map.remove("Li")` 之后，`int deleted = map.get("Li");` —— 此时键 `"Li"` 已被删除，`get("Li")` 返回 `null`。然后 `deleted.toString()` 试图在 `int` 类型变量上调用 `.toString()`。但 `int` 是基本类型，不能为 `null`——将 `null` **自动拆箱**为 `int` 时会抛出 **`NullPointerException`**。

**修改办法**：使用包装类 `Integer` 接收可能为 `null` 的返回值，并进行 `null` 检查：
```java
Integer deleted = map.get("Li");
if (deleted != null) {
    System.out.println("After remove: " + deleted.toString());
} else {
    System.out.println("After remove: Li 已被删除，不存在");
}
```

## 三、写代码题（共40分）

### 3.1（15分）泛型栈实现 — 参考代码

```java
import java.util.ArrayList;

public class MyStack<T> {
    private ArrayList<T> list = new ArrayList<T>();

    public void push(T item) {
        list.add(item);
    }

    public T pop() {
        if (list.isEmpty()) {
            return null;
        }
        return list.remove(list.size() - 1);
    }

    public T peek() {
        if (list.isEmpty()) {
            return null;
        }
        return list.get(list.size() - 1);
    }

    public boolean isEmpty() {
        return list.isEmpty();
    }

    public int size() {
        return list.size();
    }

    public static void main(String[] args) {
        MyStack<String> stack = new MyStack<String>();

        stack.push("Hello");
        stack.push("World");
        stack.push("Java");

        System.out.println("栈大小: " + stack.size());
        System.out.println("栈顶元素: " + stack.peek());

        while (!stack.isEmpty()) {
            System.out.println("弹出: " + stack.pop());
        }

        System.out.println("栈是否为空: " + stack.isEmpty());
    }
}
```

### 3.2（12分）单词频率统计 — 参考代码

```java
import java.util.Map;
import java.util.TreeMap;

public class WordCount {
    public static void main(String[] args) {
        if (args.length == 0) {
            System.out.println("请提供单词参数！");
            System.out.println("用法: java WordCount word1 word2 ...");
            return;
        }

        Map<String, Integer> map = new TreeMap<String, Integer>();

        for (String word : args) {
            Integer count = map.get(word);
            if (count == null) {
                map.put(word, 1);
            } else {
                map.put(word, count + 1);
            }
        }

        System.out.println("单词频率统计（按字典序）：");
        for (Map.Entry<String, Integer> entry : map.entrySet()) {
            System.out.println(entry.getKey() + ": " + entry.getValue());
        }
    }
}
```

### 3.3（13分）异常处理与文件输出 — 参考代码

```java
import java.io.*;

class EmptyContentException extends Exception {
    public EmptyContentException(String msg) {
        super(msg);
    }
}

public class FileWriteTest {

    public static void writeToFile(String filename, String content)
            throws IOException, EmptyContentException {
        if (content == null || content.trim().isEmpty()) {
            throw new EmptyContentException("文件内容不能为空！");
        }

        FileWriter fw = new FileWriter(filename);
        PrintWriter pw = new PrintWriter(fw);
        pw.print(content);
        pw.close();
        System.out.println("文件写入成功: " + filename);
    }

    public static void main(String[] args) {
        // 测试正常写入
        try {
            writeToFile("test.txt", "Hello Java World!");
        } catch (IOException e) {
            System.out.println("IO异常: " + e.getMessage());
        } catch (EmptyContentException e) {
            System.out.println("内容异常: " + e.getMessage());
        }

        // 测试空内容异常
        try {
            writeToFile("empty.txt", "");
        } catch (IOException e) {
            System.out.println("IO异常: " + e.getMessage());
        } catch (EmptyContentException e) {
            System.out.println("内容异常: " + e.getMessage());
        }
    }
}
```
