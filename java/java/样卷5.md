```java
public class TwoDimensionalArray {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 2, 3},
            {4, 5, 6},
            {7, 8, 9}
        };
        
        int diagonalSum = 0;
        for (int i = 0; i < matrix.length; i++) {
            diagonalSum += matrix[i][i];
        }
        System.out.println("主对角线元素和: " + diagonalSum);
        
        int[][] pascal = new int[4][];
        for (int i = 0; i < pascal.length; i++) {
            pascal[i] = new int[i + 1];
            pascal[i][0] = pascal[i][i] = 1;
            for (int j = 1; j < i; j++) {
                pascal[i][j] = pascal[i-1][j-1] + pascal[i-1][j];
            }
        }
        
        for (int i = 0; i < pascal.length; i++) {
            for (int j = 0; j < pascal[i].length; j++) {
                System.out.print(pascal[i][j] + " ");
            }
            System.out.println();
        }
    }
}
```

### 1.4（10分）阅读以下程序，回答问题。

```java
class DataProcessor {
    private int[] data;
    
    public DataProcessor(int[] data) {
        this.data = data;
    }
    
    public void process() {
        if (data == null || data.length == 0) {
            System.out.println("No data to process");
            return;
        }
        
        int sum = 0;
        try {
            for (int i = 0; i < data.length; i++) {
                sum += data[i];
            }
            double avg = (double) sum / data.length;
            System.out.println("Sum: " + sum);
            System.out.println("Average: " + avg);
        } catch (ArithmeticException e) {
            System.out.println("Arithmetic error");
        }
    }
}

public class ProcessTest {
    public static void main(String[] args) {
        new DataProcessor(new int[]{85, 92, 78, 95, 88}).process();
        new DataProcessor(new int[]{}).process();
        new DataProcessor(null).process();
    }
}
```

**问题**：（1）写出程序运行结果。（2）程序中对 `data == null` 和 `data.length == 0` 的检查分别属于什么防御性编程技巧？
