### 1.3（10分）

**（1）未开启断言（`java AssertTest`）**：
```
10 / 2 = 5
10 / 0 = Infinity
Program ended
```
解释：未开启断言时，`assert` 语句被忽略。`10 / 0` 在 Java 整数除法中会抛出 `ArithmeticException`，但这里 `a` 和 `b` 都是 `int` 类型... 

**更正**：`int` 类型的 `10 / 0` 会抛出 `ArithmeticException: / by zero`，程序会异常终止。

**（1）修正后 — 未开启断言（`java AssertTest`）**：
```
10 / 2 = 5
Exception in thread "main" java.lang.ArithmeticException: / by zero
    at AssertTest.divide(AssertTest.java:3)
    at AssertTest.main(AssertTest.java:9)
```

**（2）开启断言（`java -ea AssertTest`）**：
```
10 / 2 = 5
Exception in thread "main" java.lang.AssertionError: 除数不能为零！
    at AssertTest.divide(AssertTest.java:2)
    at AssertTest.main(AssertTest.java:9)
```
解释：开启断言后，`assert b != 0` 检查失败，抛出 `AssertionError`，程序在除法执行之前就终止了。

|------|-------------|----------------|

## 二、改错题（共20分）

### 2.1（10分）

**错误**：`FileWriter` 构造方法声明了 `throws IOException`（已检查异常），但 `main` 方法既没有使用 `try-catch` 捕获，也没有在方法签名中用 `throws` 声明 → **编译错误**：未报告的异常错误 `IOException`。

同样的，`fw.write()` 和 `fw.close()` 也会抛出 `IOException`。

**修改办法**：用 `try-catch-finally` 包裹文件操作：
```java
import java.io.*;

public class FileError {
    public static void main(String[] args) {
        FileWriter fw = null;
        try {
            fw = new FileWriter("output.txt");
            fw.write("Hello World");
            System.out.println("Done");
        } catch (IOException e) {
            System.out.println("IO错误: " + e.getMessage());
        } finally {
            try {
                if (fw != null) fw.close();
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
    }
}
```

### 2.2（10分）

**错误1**：`JDBC` 相关的已检查异常（`SQLException`、`ClassNotFoundException`）没有被捕获或声明 → **编译错误**。

**错误2**：缺少 `Class.forName("com.mysql.jdbc.Driver")` 加载数据库驱动。

**错误3**：`Connection`、`Statement`、`ResultSet` 等资源没有在 `finally` 块中正确关闭。

**修改办法**：
```java
import java.sql.*;

public class JDBCError {
    public static void main(String[] args) {
        Connection conn = null;
        Statement stmt = null;
        ResultSet rs = null;
        try {
            Class.forName("com.mysql.jdbc.Driver");
            conn = DriverManager.getConnection(
                "jdbc:mysql://127.0.0.1:3306/mydb", "root", "password");
            stmt = conn.createStatement();
            rs = stmt.executeQuery("SELECT * FROM students");
            System.out.println("Query executed");
        } catch (ClassNotFoundException e) {
            System.out.println("驱动未找到: " + e.getMessage());
        } catch (SQLException e) {
            System.out.println("数据库错误: " + e.getMessage());
        } finally {
            try { if (rs != null) rs.close(); } catch (SQLException e) {}
            try { if (stmt != null) stmt.close(); } catch (SQLException e) {}
            try { if (conn != null) conn.close(); } catch (SQLException e) {}
        }
    }
}
```

## 三、写代码题（共40分）

### 3.1（15分）文件复制工具 — 参考代码

```java
import java.io.*;

public class FileCopy {
    public static void copyFile(String sourcePath, String destPath) {
        FileInputStream fis = null;
        FileOutputStream fos = null;

        try {
            File sourceFile = new File(sourcePath);
            if (!sourceFile.exists()) {
                System.out.println("源文件不存在: " + sourcePath);
                return;
            }

            fis = new FileInputStream(sourcePath);
            fos = new FileOutputStream(destPath);

            byte[] buffer = new byte[1024];
            int bytesRead;
            while ((bytesRead = fis.read(buffer)) != -1) {
                fos.write(buffer, 0, bytesRead);
            }
            System.out.println("文件复制成功: " + sourcePath + " -> " + destPath);

        } catch (IOException e) {
            System.out.println("IO错误: " + e.getMessage());
        } finally {
            try { if (fis != null) fis.close(); } catch (IOException e) {}
            try { if (fos != null) fos.close(); } catch (IOException e) {}
        }
    }

    public static void main(String[] args) {
        if (args.length < 2) {
            System.out.println("用法: java FileCopy <源文件> <目标文件>");
            return;
        }
        copyFile(args[0], args[1]);
    }
}
```

### 3.2（12分）对象序列化 — 参考代码

```java
import java.io.*;

class Student implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private int age;
    private String studentId;

    public Student(String name, int age, String studentId) {
        this.name = name;
        this.age = age;
        this.studentId = studentId;
    }

    public String toString() {
        return "Student [姓名=" + name + ", 年龄=" + age
                + ", 学号=" + studentId + "]";
    }
}

public class SerializeDemo {

    public static void serializeStudent(Student s, String filename) {
        try {
            ObjectOutputStream oos = new ObjectOutputStream(
                    new FileOutputStream(filename));
            oos.writeObject(s);
            oos.close();
            System.out.println("序列化成功: " + filename);
        } catch (IOException e) {
            System.out.println("序列化失败: " + e.getMessage());
        }
    }

    public static Student deserializeStudent(String filename) {
        try {
            ObjectInputStream ois = new ObjectInputStream(
                    new FileInputStream(filename));
            Student s = (Student) ois.readObject();
            ois.close();
            return s;
        } catch (IOException | ClassNotFoundException e) {
            System.out.println("反序列化失败: " + e.getMessage());
            return null;
        }
    }

    public static void main(String[] args) {
        Student s1 = new Student("张三", 20, "S2024001");
        serializeStudent(s1, "student.ser");

        Student s2 = deserializeStudent("student.ser");
        if (s2 != null) {
            System.out.println("读取的对象: " + s2);
        }
    }
}
```

### 3.3（13分）JDBC数据库查询 — 参考代码

```java
import java.sql.*;

public class JdbcStudentQuery {
    public static void main(String[] args) {
        Connection conn = null;
        Statement stmt = null;
        ResultSet rs = null;

        String url = "jdbc:mysql://127.0.0.1:3306/School";
        String user = "Hust";
        String password = "3";

        try {
            // 1. 加载驱动
            Class.forName("com.mysql.jdbc.Driver");

            // 2. 建立连接
            conn = DriverManager.getConnection(url, user, password);
            stmt = conn.createStatement();

            // 3. 插入记录
            String insertSql = "INSERT INTO Student (sCode, sName, sPenguin) "
                    + "VALUES ('U2024001', '张三', '123456')";
            int rows = stmt.executeUpdate(insertSql);
            System.out.println("插入了 " + rows + " 条记录");

            // 4. 查询所有记录
            String querySql = "SELECT * FROM Student";
            rs = stmt.executeQuery(querySql);

            System.out.println("=== Student表中的所有记录 ===");
            System.out.println("学号\t姓名\t企鹅号");
            System.out.println("---\t---\t---");
            while (rs.next()) {
                String sCode = rs.getString("sCode");
                String sName = rs.getString("sName");
                String sPenguin = rs.getString("sPenguin");
                System.out.println(sCode + "\t" + sName + "\t" + sPenguin);
            }

        } catch (ClassNotFoundException e) {
            System.out.println("数据库驱动未找到: " + e.getMessage());
        } catch (SQLException e) {
            System.out.println("数据库操作错误: " + e.getMessage());
        } finally {
            // 5. 关闭资源
            try { if (rs != null) rs.close(); } catch (SQLException e) {}
            try { if (stmt != null) stmt.close(); } catch (SQLException e) {}
            try { if (conn != null) conn.close(); } catch (SQLException e) {}
        }
    }
}
```
