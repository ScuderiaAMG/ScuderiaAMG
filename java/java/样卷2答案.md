## 一、阅读题（共40分）

### 1.1（10分）运行结果

```
Parent static block
Child static block
Parent instance block
Parent constructor
Child instance block
Child constructor
---
Parent instance block
Parent constructor
Child instance block
Child constructor
```

**解析**：Java类初始化顺序：
1. **静态初始化块**：类加载时执行，且**仅执行一次**。先父类静态块 → 后子类静态块。
2. 创建对象时（每次 `new`）：先执行父类实例初始化块 → 父类构造方法 → 子类实例初始化块 → 子类构造方法。
3. 第二次 `new Child()` 时静态块不再执行（类已加载），但实例初始化块和构造方法每次都会执行。

### 1.2（10分）运行结果

```
Drawing Shape
Erasing Shape
Drawing Circle
Erasing Circle
Drawing Square
Erasing Shape
```

**解析**：
- `shapes[0]` 是 `Shape` 类型 → 调用 `Shape` 的 `draw()` 和 `erase()`
- `shapes[1]` 是 `Circle` 类型 → 调用 `Circle` 重写的 `draw()` 和 `erase()`（多态/动态绑定）
- `shapes[2]` 是 `Square` 类型 → `Square` 重写了 `draw()`，但 `erase()` 没有重写，所以 `draw()` 调用 `Square` 版本，`erase()` 调用父类 `Shape` 版本

```
张三（组长）在分配任务
```

### 1.4（10分）

**（1）运行结果**：
```
outerVar = 10

outerVar = 10
innerVar = 20
Static inner class method
```

**（2）成员内部类和静态内部类的区别**：

| 区别 | 成员内部类 (`Inner`) | 静态内部类 (`StaticInner`) |
|------|---------------------|---------------------------|
| 创建方式 | 必须先有外部类实例：`out.new Inner()` | 直接通过类名创建：`new Outer.StaticInner()` |
| 访问外部类成员 | 可以访问外部类的**所有**成员（包括 `private` 实例变量） | 只能访问外部类的**静态**成员（不能直接访问实例变量） |
| 是否持有外部类引用 | 隐式持有外部类对象的引用 `Outer.this` | 不持有外部类引用 |

## 二、改错题（共20分）

### 2.1（10分）

**错误**：`Vehicle v = new Vehicle();` —— `Vehicle` 是**抽象类**（`abstract class`），**不能被实例化**。抽象类的作用是作为父类被继承，不能直接 `new` 创建对象。

**修改办法**：改为创建子类对象：
```java
Vehicle v = new Car();
v.run();
v.stop();
```

---

### 2.2（10分）

**错误1**：`SimpleCalculator` 实现了 `Calculator` 接口，但**未实现接口中声明的所有方法**。`Calculator` 接口中有 `add()` 和 `subtract()` 两个方法，但 `SimpleCalculator` 只实现了 `add()`，缺少 `subtract()` 的实现 → **编译错误**。

**修改办法**：在 `SimpleCalculator` 中补充实现 `subtract()` 方法：
```java
public int subtract(int a, int b) {
    return a - b;
}
```

**错误2**：`Calculator calc = new Calculator();` —— `Calculator` 是**接口**，接口不能直接被实例化。

**修改办法**：改为创建实现类对象：
```java
Calculator calc = new SimpleCalculator();
```

## 三、写代码题（共40分）

### 3.1（15分）图形继承体系 — 参考代码

```java
abstract class Shape {
    public abstract double getArea();
    public abstract double getPerimeter();
}

class Circle extends Shape {
    private double radius;

    public Circle(double radius) {
        this.radius = radius;
    }

    public double getArea() {
        return 3.14 * radius * radius;
    }

    public double getPerimeter() {
        return 2 * 3.14 * radius;
    }
}

class Rectangle extends Shape {
    private double width;
    private double height;

    public Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    public double getArea() {
        return width * height;
    }

    public double getPerimeter() {
        return 2 * (width + height);
    }
}

public class ShapeTest {
    public static void main(String[] args) {
        Shape s1 = new Circle(5);
        Shape s2 = new Rectangle(4, 6);

        System.out.println("圆形：面积=" + s1.getArea()
            + "，周长=" + s1.getPerimeter());
        System.out.println("矩形：面积=" + s2.getArea()
            + "，周长=" + s2.getPerimeter());
    }
}
```

**运行结果**：
```
圆形：面积=78.5，周长=31.400000000000002
矩形：面积=24.0，周长=20.0
```

### 3.2（12分）自定义异常 — 参考代码

```java
class AgeException extends Exception {
    public AgeException(String msg) {
        super(msg);
    }
}

class Person {
    private String name;
    private int age;

    public Person(String name, int age) throws AgeException {
        if (age < 0 || age > 150) {
            throw new AgeException("年龄不合法: " + age);
        }
        this.name = name;
        this.age = age;
    }

    public void printInfo() {
        System.out.println("姓名: " + name + ", 年龄: " + age);
    }
}

public class AgeTest {
    public static void main(String[] args) {
        // 测试合法年龄
        try {
            Person p1 = new Person("张三", 25);
            p1.printInfo();
        } catch (AgeException e) {
            e.printStackTrace();
        }

        // 测试非法年龄
        try {
            Person p2 = new Person("李四", 200);
            p2.printInfo();
        } catch (AgeException e) {
            System.out.println("异常: " + e.getMessage());
            e.printStackTrace();
        }

        System.out.println("程序继续执行...");
    }
}
```

### 3.3（13分）静态工厂模式 — 参考代码

```java
public class Product {
    private String name;
    private double price;

    // 私有构造方法
    private Product(String name, double price) {
        this.name = name;
        this.price = price;
    }

    // 静态工厂方法
    public static Product createProduct(String name, double price) {
        if (price < 0) {
            System.out.println("价格不能为负数！");
            return null;
        }
        return new Product(name, price);
    }

    public void printInfo() {
        System.out.println("产品名称: " + name + "，价格: " + price);
    }

    public static void main(String[] args) {
        Product p1 = Product.createProduct("笔记本电脑", 5999.0);
        if (p1 != null) {
            p1.printInfo();
        }

        Product p2 = Product.createProduct("鼠标", -50.0);
        if (p2 != null) {
            p2.printInfo();
        }

        Product p3 = Product.createProduct("键盘", 299.0);
        if (p3 != null) {
            p3.printInfo();
        }
    }
}
```

**运行结果**：
```
产品名称: 笔记本电脑，价格: 5999.0
价格不能为负数！
产品名称: 键盘，价格: 299.0
```
