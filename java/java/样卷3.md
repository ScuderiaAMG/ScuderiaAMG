### 3.1（15分）泛型栈实现

编写程序：
- 定义一个泛型类 `MyStack<T>`，实现栈的基本操作
- 使用 `ArrayList<T>` 作为内部存储结构
- 方法 `void push(T item)` 将元素压入栈顶
- 方法 `T pop()` 弹出并返回栈顶元素（栈空时返回 `null`）
- 方法 `T peek()` 查看栈顶元素但不弹出（栈空时返回 `null`）
- 方法 `boolean isEmpty()` 判断栈是否为空
- 方法 `int size()` 返回栈中元素个数
- 在 `main` 方法中测试：创建 `MyStack<String>`，压入三个字符串，依次弹出并打印

### 3.2（12分）单词频率统计

编写程序：
- 从命令行参数接收一系列单词（`String[] args`）
- 使用 `Map<String, Integer>` 统计每个单词出现的次数
- 遍历 `Map` 打印每个单词及其出现次数
- 使用 `TreeMap` 使输出按单词字典序排列
- 示例运行：`java WordCount apple banana apple orange banana apple`

### 3.3（13分）异常处理与文件输出

编写程序：
- 定义方法 `public static void writeToFile(String filename, String content)`，将 `content` 内容写入指定文件

- 定义自定义异常类 `EmptyContentException`，继承 `Exception`
