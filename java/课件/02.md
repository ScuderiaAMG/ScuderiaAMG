# 02 面向对象程序设计基本概念

---

## 一、本章概述

本章主要涵盖以下内容：

**基本概念**：
- 对象（Object）
- 类（Class）

**OOP的主要特征**：
- 封装（Encapsulation）
- 继承（Inheritance）
- 多态（Polymorphism）

---

## 二、面向对象程序设计概述

### 2.1 什么是面向对象程序设计

**面向对象程序设计（Object Oriented Programming，OOP）** 是使用**类和对象**将现实世界中真实的或抽象的实体在程序中建立模型。

简单地说，面向对象编程描述的是**对象之间的相互作用**。

### 2.2 OOP中的核心概念

OOP涉及以下五个核心概念：
1. **对象（Object）**
2. **消息（Message）**
3. **类（Class）**
4. **继承（Inheritance）**
5. **接口（Interface）**

---

## 三、对象（Object）

### 3.1 对象的概念

- 软件对象是**现实对象在程序中的模型**
- 现实世界对象的两个特征：**状态（state）** 与**行为（behavior）**
- 软件对象也具有状态与行为：
  - **状态**：以一个或多个**变量**保存
  - **行为**：用**方法（method）**实现行为

### 3.2 对象的定义

> 对象由**变量**与相关的**方法**结合起来构成的。

### 3.3 实例（Instance）

一个特定的对象称为**实例**。

---

## 四、消息（Message）

### 4.1 什么是消息

对象之间通过**发送消息**进行**交互与通信**。

### 4.2 消息的构成

消息由三部分构成：
1. **接收消息的对象**
2. **方法名称**
3. **方法的参数**

### 4.3 消息机制的好处

- 对象的行为是通过它的**方法**表达的，所以消息传递支持对象之间的**所有交互**
- 相互交换消息的对象可以在**不同的进程**，甚至在**不同的机器**上

---

## 五、类（Class）

### 5.1 类与对象的关系

- **类**是同种对象的**集合与抽象**
- 类描述对象的**数据**和**行为**
- 类的**实例化**就是对象

### 5.2 从现实世界到计算机世界的映射

```
现实世界          概念世界          计算机世界
  实体  ──抽象──→  抽象数据类型  ──转换──→  类
                                          │
                                          │实例化
                                          ↓
  实体  ←──映射──  对象          ←────  对象
```

### 5.3 类的定义

> A class is a blueprint, or prototype, that defines the variables and the methods common to all objects of a certain kind.
>
> 一个类是一个**蓝图**或**原型**，它定义了某一特定种类对象都具有的**变量**与**方法**。

### 5.4 类中的变量与方法

**变量**：
| 类型 | 说明 |
|------|------|
| **实例变量（instance variable）** | 包含特定对象的状态 |
| **类变量（class variable）** | 由类的所有实例共享 |

**方法**：
| 类型 | 说明 |
|------|------|
| **实例方法（instance method）** | 通过实例进行访问的方法 |
| **类方法（class method）** | 通过类进行调用的方法 |

---

## 六、继承（Inheritance）

### 6.1 什么是继承

- 自然界通过继承而繁衍发展
- 程序中的继承是**从抽象到具体**的过程

### 6.2 父类与子类

**子类（Subclass）**：
> A class that is derived from a particular class.
>
> 从某个特定类派生出来的类。

**父类（Superclass）**：
> A class from which a particular class is derived.
>
> 派生出某个特定类的类。

### 6.3 继承的含义

- 子类**继承**父类的状态与方法
- 子类可以**增加新的变量和方法**
- 子类可以**重写（Override）**继承来的方法
- **注**：继承关系可以有多层，子类要继承它所有父类的方法与状态

### 6.4 Java中的Object类

- Java中的**Object类**是**最顶层**的类，所有其它的类都是它**直接或间接**的子类
- 类型是Object的变量可以指向**任意的对象**
- Object提供了运行在JVM中的**所有对象都需要的行为（方法）**

### 6.5 继承的优点

- 通过继承可以**重用父类中的代码**
- 程序员可以定义含有一般行为的**抽象类**。抽象类中的很多方法是没有实现的，可以在抽象类的基础上定义特定的子类，**实现具体的细节**

---

## 七、封装（Encapsulation）

封装是面向对象编程的核心特征之一，包含以下要点：

- 程序的基本封装单元是**类**
- **模块化**：不同对象代码之间有一定独立性，对象可以在系统中方便移动
- **信息隐藏**：通过接口将内部复杂的实现细节隐藏了，保证修改对象信息时，不会对访问它的对象产生影响
- **简化操作**：通过调用简单的接口就可以操纵对象

---

## 八、多态性（Polymorphism）

- 现实世界中的实体具有多态性，如水（液态、固态、气态）
- 多态性应用于面向对象的编程，表现为对象对外的**同一接口**，内部有**不同实现**，因而表现出**不同的行为**

---

## 九、面向对象编程的主要特点总结

| 特征 | 英文 | 核心要点 |
|------|------|----------|
| **封装性** | Encapsulation | 实现**模块化**（modularity）和**信息隐藏**（information hiding），有利于程序的**可移植性** |
| **继承性** | Inheritance | 定义对象之间的**层次关系**，下层的对象继承了上层对象的特性，可以实现程序**代码重用**，并且有效地**组织整个程序** |
| **多态性** | Polymorphism | 使程序运行时对象的一种接口可以提供**多种不同的操作**，提高程序的**灵活性** |

## 十、面向对象编程的难点

掌握面向对象的困难之处在于**思路的转换**：

> 我们通常习惯于考虑**解决问题的方法**，而不是考虑**将问题抽象成对象**再去解决它。

---

## 十一、面向对象编程与面向过程编程的区别

### 11.1 核心区别

| 比较维度 | 面向过程编程 | 面向对象编程 |
|----------|-------------|-------------|
| **设计顺序** | 先确定**算法**，再确定**数据结构** | 先确定**数据结构**，再确定**运算** |
| **组织方式** | 建立数据结构存放数据，定义方法（函数）来操作数据 | 构造一个对象模型，将**数据与方法组织在一起** |

### 11.2 示例一：驾驶汽车

**面向过程的程序设计方式**：
- 编写一个方法：`void drivecar()`

**面向对象的程序设计方式**：
- 将一辆汽车看成一个**对象**
- 将所有汽车对象的共性抽取出来，设计一个**类Car**
- 类中有一个方法 `void drive()`
- 用Car类实例化一个具体的对象 `car`
- 调用：`car.drive()`

### 11.3 示例二：求长方形的周长和面积

#### 面向过程的程序设计方式

**思路**：
1. 确定长方形周长和面积的算法
2. 编写两个方法（函数）分别计算长方形的周长和面积
3. 求周长和面积的方法需要两个参数：长和宽

**代码**：
```java
class Rectangle {
    static int perimeter(int length, int width) {
        return 2 * (length + width);
    }
    static int area(int length, int width) {
        return length * width;
    }
    public static void main(String[] args) {
        System.out.println("perimeter = " + Rectangle.perimeter(5, 4));
        System.out.println("area = " + Rectangle.area(5, 4));
    }
}
```

#### 面向对象的程序设计方式

**思路**：
1. 一个长方形可以看成一个**长方形对象**
2. 一个长方形对象有两个**状态**（长和宽）和两个**行为**（求周长和求面积）
3. 将所有长方形的共性抽取出来，设计一个**长方形类**
4. 通过长方形对象的**行为**，就可以求出某个具体的长方形对象的周长和面积

**代码**：
```java
class Rectangle {
    int l, w;
    int perimeter() { return 2 * (l + w); }
    int area()      { return l * w;        }

    public static void main(String[] args) {
        Rectangle rect1 = new Rectangle();
        Rectangle rect2 = new Rectangle();
        rect1.l = 10;
        rect1.w = 5;
        System.out.println("perimeter of rect1 = " + rect1.perimeter());
        System.out.println("area of rect1 = " + rect1.area());
        rect2.l = 6;
        rect2.w = 4;
        System.out.println("perimeter of rect2 = " + rect2.perimeter());
        System.out.println("area of rect2 = " + rect2.area());
    }
}
```

**面向对象方式分析**：
- `rect1`、`rect2` 是Rectangle类的两个实例（对象）
- `l`、`w` 是实例变量，分别存储不同的长和宽数据
- `perimeter()` 和 `area()` 是实例方法，通过具体的实例调用，操作该实例的数据
- 面向对象将数据（长、宽）与操作数据的方法封装在同一个类中

---

## 十二、本章小结

本章系统介绍了面向对象程序设计的核心概念：

1. **对象（Object）**：由变量（状态）和方法（行为）组成的实体，是现实对象在程序中的模型
2. **消息（Message）**：对象间交互通信的机制，由接收对象、方法名称和参数三部分构成
3. **类（Class）**：同种对象的集合与抽象，是创建对象的蓝图或原型
4. **继承（Inheritance）**：从抽象到具体的过程，子类继承父类的状态与方法，并可增加新成员或重写方法；Java中所有类的顶层父类是Object类
5. **封装（Encapsulation）**：通过类实现模块化和信息隐藏，简化操作并提高可移植性
6. **多态（Polymorphism）**：同一接口、不同实现，表现出不同行为，提高程序灵活性
7. **面向对象 vs 面向过程**：面向过程先算法后数据，函数与数据分离；面向对象先数据结构后运算，将数据与方法组织在一起
