## 二、异常（Exception）的概念

### 2.1 什么是异常

Exception是在程序运行时**打断正常程序流程的异常情况**。

**常见异常场景**：

| 场景 | 说明 |
|------|------|
| 文件不存在 | 试图打开的文件不存在 |
| 网络中断 | 网络链接中断 |
| 操作越界 | 操作符越界（如数组越界） |
| 类找不到 | 要加载的类找不到 |

为了保证程序的正常运行，Java专门提供了**异常处理机制**。

### 2.2 异常示例

```java
public class HelloWorld {
    public static void main(String args[]) {
        int i = 0;
        String greetings[] = {"Hello World!", "Hello!",
                "HELLO WORLD!!"};
        while (i < 4) {
            System.out.println(greetings[i]);
            i++;
        }
    }
}
```

**运行结果**：
```
Hello World!
Hello!
HELLO WORLD!
java.lang.ArrayIndexOutOfBoundsException
    at HelloWorld.main(HelloWorld.java:7)
```

程序在访问 `greetings[3]` 时抛出 `ArrayIndexOutOfBoundsException`（数组下标越界异常）。

## 三、Java中的异常类体系

### 3.1 异常类层次结构

Java中定义了各种异常类，`java.lang.Throwable` 是这些类的父类。

```
                    Throwable
                   /         \
              Error           Exception
             /     \         /          \
VirtualMachineError  AWTError  RuntimeException   IOException
                                                   /         \
                                          EOFException   FileNotFoundException
                              /            \
                    ArithmeticException   NullPointerException
                                |
                    IndexOutOfBoundsException
                              ...
```

### 3.2 异常的分类

| 类型 | 说明 | 处理策略 |
|------|------|----------|
| **Error** | 很难恢复的严重错误 | 一般不由程序处理 |
| **RuntimeException** | 程序设计或实现上的问题（如数组越界、空指针等） | 正常的策略是**纠正错误**（修改代码） |
| **其他异常（受检异常）** | 通常是由环境因素引起的（如文件不存在、无效URL等） | 可以在异常处理中处理，例如**提示用户进行正确操作**等 |

**常见RuntimeException子类**：
- `ArithmeticException`：算术异常（如除零）
- `NullPointerException`：空指针异常
- `IndexOutOfBoundsException`：索引越界异常

**常见IOException子类**：
- `EOFException`：文件结束异常
- `FileNotFoundException`：文件未找到异常

## 四、异常处理方法

### 4.1 两种处理方式

Java异常处理机制的核心是：**抛出异常，捕捉异常**。

| 方式 | 说明 |
|------|------|
| **捕获并处理异常** | 使用try-catch-finally在方法内部处理 |
| **将方法中产生的异常抛出** | 使用throws声明，将异常抛给调用者处理 |

### 4.2 抛出异常（Throwing）

当一个方法出现错误引发异常时：
1. 方法创建**异常对象**并交付运行时系统
2. 异常对象中包含了**异常类型**和**异常出现时的程序状态**等异常信息
3. 运行时系统负责**寻找处置异常的代码**并执行

### 4.3 捕获异常（Catching）

在方法抛出异常之后，运行时系统将寻找合适的**异常处理器（Exception Handler）**：

- 潜在的异常处理器是异常发生时依次存留在**调用栈**中的方法的集合
- 当异常处理器所能处理的异常类型与方法抛出的异常类型**相符**时，即为合适的异常处理器
- 运行时系统从发生异常的方法开始，**依次回查调用栈**中的方法，直至找到含有合适异常处理器的方法并执行
- 当运行时系统遍历调用栈而**未找到**合适的异常处理器，则运行时系统**终止**，同时意味着Java程序的**终止**

## 五、捕获并处理异常 —— try、catch 和 finally

### 5.1 基本语法结构

```java
try {
    // code that might throw a particular exception
} catch (MyExceptionType e) {
    // code to execute if a MyExceptionType exception is thrown
} catch (Exception e) {
    // code to execute if a general Exception exception is thrown
} finally {
    // code that always executes
}
```

### 5.2 try语句块

**一般形式**：
```java
try {
    // Java statements — 一条或多条可能产生异常的Java语句
}
```

**规则**：try语句后**必须跟随至少一个**catch或finally语句块。

### 5.3 catch语句块

**一般格式**：
```java
catch (SomeThrowableObject variableName) {
    // Java statements
}
```

**参数说明**：

| 参数 | 说明 |
|------|------|
| `SomeThrowableObject` | 能够被处理的异常类名，必须是`Throwable`类的子类 |
| `variableName` | 异常处理程序中使用的指向被捕获异常对象的变量 |
| `Java statements` | 当捕获到异常时执行的Java语句 |

### 5.4 finally语句块

**功能**：
- 将先前方法的状态清除，并可以将控制转移到程序的其他地方
- finally语句块**无论是否发生异常都要执行**
- 一般用于**关闭文件**或**释放其他系统资源**

### 5.5 完整示例

```java
public void writeList() {
    PrintWriter out = null;
    try {
        System.out.println("Entering try statement");
        out = new PrintWriter(new FileWriter("OutFile.txt"));
        for (int i = 0; i < size; i++) {
            out.println("Value at: " + i + " = " + list.get(i));
        }
    } catch (IndexOutOfBoundsException e) {
        System.err.println("Caught IndexOutOfBoundsException: " +
                e.getMessage());
    } catch (IOException e) {
        System.err.println("Caught IOException: " + e.getMessage());
    } finally {
        if (out != null) {
            System.out.println("Closing PrintWriter");
            out.close();
        } else {
            System.out.println("PrintWriter not open");
        }
    }
}
```

### 5.6 writeList方法三种执行情况

| 情况 | 输出 |
|------|------|
| **出现IOException** | `Entering try statement` → `Caught IOException: OutFile.txt` → `PrintWriter not open` |
| **出现数组越界错误** | `Entering try statement` → `Caught IndexOutOfBoundsException: Index: 10, Size: 10` → `Closing PrintWriter` |
| **正常退出** | `Entering try statement` → `Closing PrintWriter` |

### 5.7 捕获与处理异常示例

```java
public static void main(String args[]) {
    int i = 0;
    String greetings[] = {"Hello World!", "Hello!", "HELLO!"};
    while (i < 4) {
        try {
            System.out.println(greetings[i]);
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.println("Caught Exception");
            break;
        } finally {
            System.out.println("This is always printed");
        }
        i++;
    }
}
```

**输出结果**：
```
Hello World!
This is always printed
Hello!
This is always printed
HELLO!
This is always printed
Caught Exception
This is always printed
```

**说明**：无论是否发生异常，finally块总是执行；当 `i=3` 时捕获 `ArrayIndexOutOfBoundsException`，执行catch块后break退出循环。

## 六、多种异常的同时处理

### 6.1 异常体系中的处理粒度

异常处理可以针对异常体系中的**任意一个类**：

| 处理层级 | 特点 |
|----------|------|
| **叶结点** | 是具体、专用的异常处理 |
| **中间结点/父类** | 是通用的异常处理，可以处理该结点及其子类类型的异常 |

### 6.2 catch子句的顺序原则

对于有多个catch子句的异常程序而言，应该：
1. **尽量将捕获底层异常类（子类）的catch子句放在前面**
2. **尽量将捕获相对高层异常类（父类）的catch子句放在后面**

否则，捕获底层异常类的catch子句将可能**执行不到**（被父类catch先捕获）。

**反面示例**：如果先捕获Exception父类，子类异常catch将永远无法执行：
```java
try {
    // ...
} catch (Exception e) {
    System.err.println("Exception caught: " + e.getMessage());
}
```

## 七、抛出异常 —— throws 和 throw

### 7.1 throws声明

可能产生异常的方法表明将**不处理该异常**，异常将被抛到调用该方法的程序。

**语法**：
```java
public void troublesome() throws IOException {
    // ...
}
```

**重要规则**：如果一个异常在返回到 `main()` 时还未被处理，则程序将**非正常终止**。

### 7.2 throw语句

用于在方法内部**手动抛出异常**。

**语法**：
```java
throw someThrowableObject;
```

### 7.3 throws示例

```java
public void writeList() throws IOException, ArrayIndexOutOfBoundsException {
    PrintWriter out = new PrintWriter(new FileWriter("OutFile.txt"));
    for (int i = 0; i < size; i++)
        out.println("Value at: " + i + " = " + victor.elementAt(i));
    out.close();
}

// 调用方处理异常
try {
    ListOfNumbersDeclared list = new ListOfNumbersDeclared();
    list.writeList();
} catch (Exception e) {
    System.err.println("Caught Exception");
}
```

## 八、自定义异常类

### 8.1 定义自定义异常

自定义异常类是 `Exception` 类的**子类**，可包含普通类的内容（如成员变量、构造方法、成员方法等）。

**示例**：
```java
public class ServerTimeOutException extends Exception {
    private String reason;
    private int port;

    public ServerTimeOutException(String reason, int port) {
        this.reason = reason;
        this.port = port;
    }

    public String getReason() {
        return reason;
    }

    public int getPort() {
        return port;
    }
}
```

### 8.2 抛出自定义异常

```java
public void connectMe(String serverName) throws ServerTimeOutException {
    int success;
    int portToConnect = 80;
    success = open(serverName, portToConnect);
    if (success == -1) {
        throw new ServerTimeOutException("Could not connect", 80);
    }
}
```

### 8.3 捕获并处理自定义异常（含嵌套）

```java
public void findServer() {
    // ...
    try {
        connectMe(defaultServer);
    } catch (ServerTimeOutException e) {
        System.out.println("Server timed out, try another");
        try {
            connectMe(alternateServer);
        } catch (ServerTimeOutException e1) {
            System.out.println("No server available");
        }
    }
}
```

**说明**：try-catch语句块**可以嵌套**。

## 九、异常处理核心机制总结

### 9.1 Java异常处理完整流程

```
方法中产生异常
      │
      ▼
创建异常对象（包含异常类型和程序状态）
      │
      ▼
交付运行时系统
      │
      ├──→ 方法内使用try-catch捕获处理
      │         │
      │         ▼
      │    匹配catch类型，执行处理代码
      │         │
      │         ▼
      │    执行finally块
      │
      └──→ 方法声明throws抛出
                │
                ▼
           调用栈回溯查找处理器
                │
         ┌──────┴──────┐
         │             │
    找到处理器      未找到处理器
         │             │
         ▼             ▼
    执行处理代码    程序终止
```

### 9.2 关键概念对比

| 概念 | 作用 | 位置 |
|------|------|------|
| **try** | 包裹可能产生异常的代码 | 方法体内 |
| **catch** | 捕获并处理指定类型的异常 | try之后 |
| **finally** | 无论是否异常都执行的清理代码 | catch之后 |
| **throws** | 声明方法可能抛出的异常类型 | 方法签名 |
| **throw** | 手动抛出异常对象 | 方法体内 |

### 9.3 异常处理最佳实践

| 原则 | 说明 |
|------|------|
| **具体优先** | catch子句应把子类异常放在前面，父类异常放在后面 |
| **资源释放** | 使用finally块确保资源（文件、网络连接等）被正确释放 |
| **合理抛出** | 方法无法处理的异常应通过throws向上抛出，由调用方决定如何处理 |
| **自定义异常** | 当Java内置异常无法准确描述业务错误时，创建有意义的自定义异常类 |
| **try-catch可嵌套** | 在异常处理中需要尝试其他操作时，可以使用嵌套的try-catch |

## 十、本章小结

本章系统介绍了Java的异常处理机制，涵盖以下核心知识点：

1. **异常（Exception）**：程序运行时打断正常流程的异常情况，如文件不存在、网络中断、数组越界、类找不到等

2. **异常类体系**：以`Throwable`为根，分为`Error`（严重错误，不处理）和`Exception`两类；Exception又分为`RuntimeException`（程序错误，应修正代码）和其他受检异常（环境因素，应处理）

3. **异常处理机制**：抛出异常（创建异常对象交付运行时系统）→ 捕获异常（调用栈回查寻找匹配的异常处理器）

4. **try-catch-finally**：
   - try包裹可能产生异常的代码，后必须至少跟一个catch或finally
   - catch按异常类型捕获处理，顺序应子类在前、父类在后
   - finally无论是否异常都执行，用于释放资源

5. **throws和throw**：
   - throws：方法签名中声明可能抛出但不处理的异常
   - throw：在方法体内手动抛出异常对象

6. **自定义异常**：继承Exception类，可包含普通类的成员变量和方法，用于表达特定业务场景下的错误
