## 二、流（Stream）的概念

### 2.1 什么是流

流是从**源到目的**的字节的有序序列，**先进先出（FIFO）**。

### 2.2 两种基本流

| 流类型 | 方向 | 说明 |
|--------|------|------|
| **InputStream（输入流）** | 源 → 程序 | 从数据源读取数据 |
| **OutputStream（输出流）** | 程序 → 目的 | 向目标写入数据 |

### 2.3 流操作的基本过程

**读取（Reading）**：
```
open a stream
while more information
    read information
close the stream
```

**写入（Writing）**：
```
open a stream
while more information
    write information
close the stream
```

## 三、两种结构的流

### 3.1 节点流（Node Stream）

从**特定源**如磁盘文件或内存某区域进行读或写入。

### 3.2 过滤流（Filter Stream）

使用**其他的流**作为输入源或输出目的地。

**关系图示**：
```
         Node InputStream
              ↓
         Filter InputStream
              ↓
           read()
```

## 四、两种流类体系

### 4.1 概述

`java.io` 包中包含了流式I/O所需要的**所有类**。流式I/O类根据操作的数据类型分成两个层次体系：

| 体系 | 操作数据类型 | 顶层抽象类 |
|------|:----------:|------------|
| **字节流** | 8位字节 | InputStream / OutputStream |
| **字符流** | 16位字符（Unicode） | Reader / Writer |

                    InputStream (抽象类)

**三个基本write()方法**：

| 方法 | 说明 |
|------|------|
| `void write(int c)` | 写一个字节 |
| `void write(byte[] b)` | 写一个字节数组 |
| `void write(byte[] b, int off, int len)` | 写一个字节数组中的部分数据块 |

**其他方法**：

| 方法 | 说明 |

| `void close()` | 关闭流 |
| `void flush()` | 强制将缓存的输出数据写出去 |

## 六、字符流

### 6.1 概述

- `Reader` 和 `Writer` 是字符流的两个**顶层抽象父类**
- 每一个核心输入/输出字节流，都有相应的Reader和Writer版本
- 字符流能处理**Unicode**字符集，故应使用字符流来读写**文本类数据**
- 字节流一般用于读写**二进制数据**

### 6.2 Reader的类层次

```
                    Reader (抽象类)
                   /        |           \
          BufferedReader  InputStreamReader  ...
         (缓冲字符输入流)     /       \
                    FileReader  CharArrayReader
                   (文件字符      (字符数组
                    输入流)        输入流)
                              StringReader
                              (字符串输入流)
                              PipedReader
                              (管道输入流)
```

### 6.3 Reader的基本方法

| 方法 | 说明 |
|------|------|
| `int read()` | 读单个字符 |
| `int read(char cbuf[])` | 读字符放入数组中 |
| `int read(char cbuf[], int off, int len)` | 读字符放入数组的指定位置 |
| `void close()` | 关闭流 |
| `long skip(long n)` | 跳过n个字符 |
| `boolean markSupported()` | 测试打开的流是否支持书签 |
| `void mark(int buf)` | 标记当前流，并建立缓冲区 |
| `void reset()` | 返回标签处 |
| `boolean ready()` | 测试当前流是否准备好进行读 |

### 6.4 Writer的类层次

```
                    Writer (抽象类)
                   /        |           \
          BufferedWriter  OutputStreamWriter  ...
         (缓冲字符输出流)     /       \
                    FileWriter  CharArrayWriter
                   (文件字符      (字符数组
                    输出流)        输出流)
                              StringWriter
                              (字符串输出流)
                              PipedWriter
                              (管道输出流)
                              PrintWriter
                              (打印输出流)
```

### 6.5 Writer的基本方法

| 方法 | 说明 |
|------|------|
| `int write(int c)` | 写单个字符 |
| `int write(char cbuf[])` | 写字符数组 |
| `int write(char cbuf[], int off, int len)` | 写字符数组中的部分数据 |
| `int write(String str)` | 写字符串 |
| `int write(String str, int off, int len)` | 写字符串的一部分 |
| `void close()` | 关闭流 |
| `void flush()` | 强行写 |

### 6.6 字节流与字符流的比较

| 比较维度 | 字节流 | 字符流 |
|----------|--------|--------|
| 顶层类 | InputStream / OutputStream | Reader / Writer |
| 操作数据类型 | 8位字节 | 16位字符（Unicode） |
| 适用场景 | 二进制数据 | 文本数据 |

**公共规则**：所有的流（InputStream、OutputStream、Reader、Writer）在创建时**自动打开**；程序中可以调用 `close()` 方法关闭流，否则Java运行环境的垃圾收集器将**隐含将流关闭**。

## 七、字符集的编码

### 7.1 常见字符编码

| 编码 | 说明 |
|------|------|
| **ASCII** | 基于常用英文字符的编码系统，每个ASCII码与一个8位二进制数对应。最高位是0，十进制数0-127。另有128个扩展ASCII码（最高位为1），包含制表符等。**最通用的单字节编码系统** |
| **GB2312** | 中华人民共和国国家汉字信息交换用编码（《信息交换用汉字编码字符集－基本集》）。一个中文字符用两个字节表示，每个字节最高位都用1来与ASCII码区别 |
| **GBK** | GB2312的扩展（K=扩）。完全兼容GB2312，额外对繁体中文、不常用汉字和许多符号进行编码 |
| **ISO-8859-1** | 西方国家所使用的字符编码集，单字节字符集。英文实际上只用了其中数字小于128的部分 |
| **Unicode** | 通用字符集，对所有语言文字统一编码，每个字符用2个字节表示。英文采取前面加"0"字节策略实现等长兼容（如'a'的ASCII码0x61，Unicode为0x00,0x61） |
| **UTF-8** | UCS Transformation Format。1个7位ASCII码值对应1个字节UTF码；0x0080-0x07ff之间的字符对应2个字节；0x0800-0xffff之间的字符对应3个字节。**变长编码** |

## 十、I/O流的套接（Chaining）

### 10.1 套接概念

一般常通过过滤流将多个流套接在一起，利用各种流的特性**共同处理数据**。

**输入流链（Input Stream Chain）示例**：
```
FileInputStream → BufferedInputStream → DataInputStream → 程序
（从文件获取字节）  （增加缓冲功能）     （读取Java基本数据类型）
```

**输出流链（Output Stream Chain）示例**：
```
程序 → DataOutputStream → BufferedOutputStream → FileOutputStream
       （写Java基本数据类型） （提供数据缓冲功能）    （将数据写入文件）
```

## 十一、常用I/O流类详解

### 11.1 文件流（File Stream）

包括 `FileInputStream` / `FileOutputStream` 和 `FileReader` / `FileWriter`，是**节点流**，对文件系统中的文件进行读写。

**创建方式**：常用文件名或File类的对象创建文件流。

**示例——文件字节拷贝**（CopyBytes.java：利用FileInputStream, FileOutputStream）：
```java
// 将 farrago.txt 的内容拷贝到 outagain.txt
FileInputStream in = new FileInputStream("farrago.txt");
FileOutputStream out = new FileOutputStream("outagain.txt");
int c;
while ((c = in.read()) != -1) {
    out.write(c);
}
in.close();
out.close();
```

**示例——文件字符拷贝**（Copy.java：利用FileReader, FileWriter）：
```java
// 使用字符流进行文本文件拷贝
FileReader in = new FileReader("farrago.txt");
FileWriter out = new FileWriter("outagain.txt");
int c;
while ((c = in.read()) != -1) {
    out.write(c);
}
in.close();
out.close();
```

### 11.2 缓冲流（Buffered Stream）

包括 `BufferedInputStream` / `BufferedOutputStream` 和 `BufferedReader` / `BufferedWriter`，是**过滤流**。

**特点**：
- 数据从原始流**成块读入**或将数据积累到一个大数据块后再**成批输出**
- 可**加快程序的执行**

**新增方法**：

| 类 | 新增方法 | 说明 |
|----|----------|------|
| BufferedReader | `readLine()` | 读取一行文本 |
| BufferedWriter | `newLine()` | 写入一个行分隔符 |

### 11.3 管道流（Pipe Stream）

**功能**：管道用来把一个线程的输出连接到另一个线程的输入。

**管道流模型**：
```
线程1 → 管道输出 ───连接───→ 管道输入 → 线程2 → 管道输出 ───连接───→ 管道输入 → 线程3
```

**对应类**：

| 方向 | 字符流 | 字节流 |
|------|--------|--------|
| 输入 | PipedReader | PipedInputStream |
| 输出 | PipedWriter | PipedOutputStream |

**创建管道连接的两种方式**：

```java
// 方式一：构造时连接
PipedInputStream pin = new PipedInputStream();
PipedOutputStream pout = new PipedOutputStream(pin);

// 方式二：使用connect()方法
PipedInputStream pin = new PipedInputStream();
PipedOutputStream pout = new PipedOutputStream();
pin.connect(pout);  // 或 pout.connect(pin);
```

**管道流的优点**：线程之间通过管道传输数据，与共享缓冲区方法相比，**不需要进行线程同步**，节省内存并提高了程序的运行效率。

**示例**：RhymingWords.java —— 输入一组单词，先将每个单词逆序，再将所有单词排序，最后将单词逆序输出。

### 11.4 数据流（Data Stream）

`DataInputStream` 和 `DataOutputStream` 用于读写**基本数据类型**。

**DataInputStream方法**：

| 方法 | 返回类型 |
|------|:--------:|
| `readByte()` | byte |
| `readBoolean()` | boolean |
| `readShort()` | short |
| `readChar()` | char |
| `readInt()` | int |
| `readFloat()` | float |
| `readLong()` | long |
| `readDouble()` | double |
| `readUTF()` | String |

**DataOutputStream方法**：

| 方法 | 参数类型 |
|------|:--------:|
| `writeByte(int v)` | int |
| `writeBoolean(boolean v)` | boolean |
| `writeShort(short v)` | short |
| `writeChar(int v)` | int |
| `writeInt(int v)` | int |
| `writeFloat(float v)` | float |
| `writeLong(long v)` | long |
| `writeDouble(double v)` | double |
| `writeBytes(String s)` | String |
| `writeChars(String s)` | String |
| `writeUTF(String str)` | String |

**数据流示例**（DataIOTest.java）：
```java
import java.io.*;

public class DataIOTest {
    public static void main(String[] args) throws IOException {
        // 写数据
        DataOutputStream out = new DataOutputStream(
                new FileOutputStream("invoice1.txt"));
        double[] prices = { 19.99, 9.99, 15.99, 3.99, 4.99 };
        int[] units = { 12, 8, 13, 29, 50 };
        String[] descs = { "Java T-shirt", "Java Mug",
                "Duke Juggling Dolls", "Java Pin", "Java Key Chain" };

        for (int i = 0; i < prices.length; i++) {
            out.writeDouble(prices[i]);
            out.writeChar('\t');
            out.writeInt(units[i]);
            out.writeChar('\t');
            out.writeUTF(descs[i]);
            out.writeChar('\n');
        }
        out.close();

        // 读数据
        DataInputStream in = new DataInputStream(
                new FileInputStream("invoice1.txt"));
        double price;
        int unit;
        String desc;
        double total = 0.0;

        try {
            while (true) {
                price = in.readDouble();
                in.readChar();       // throws out the tab
                unit = in.readInt();
                in.readChar();       // throws out the tab
                desc = in.readUTF();
                System.out.println("You've ordered " +
                        unit + " units of " +
                        desc + " at $" + price);
                total = total + unit * price;
            }
        } catch (EOFException e) {
        }
        System.out.println("For a TOTAL of: $" + total);
        in.close();
    }
}
```

**输出**：
```
You've ordered 12 units of Java T-shirt at $19.99
You've ordered 8 units of Java Mug at $9.99
You've ordered 13 units of Duke Juggling Dolls at $15.99
You've ordered 29 units of Java Pin at $3.99
You've ordered 50 units of Java Key Chain at $4.99
For a TOTAL of: $892.88
```

## 十三、随机存取文件类（RandomAccessFile）

### 13.1 概述

### 13.2 创建随机存取文件

**mode参数**：

| mode | 含义 |
|:----:|------|
| `"r"` | 只读 |
| `"rw"` | 读写 |
| `"rwd"` | 读写，同步更新数据 |
| `"rws"` | 读写，同步更新数据和元数据 |

| 方法 | 说明 |

- **所有方法都声明抛出 `IOException`**

## 十四、对象的串行化（Object Serialization）

### 14.1 串行化概念

- 把对象保存到外存，称为**永久化（持久化）**
- 实现 `java.io.Serializable` 接口类的对象可以被输入/输出
- **只有对象的数据被保存**，方法与构造方法不被保存
- 以 `transient` 关键字标记的数据**不被保存**

**示例**：
```java
public class MyClass implements Serializable {
    public transient Thread myThread;     // 不被序列化
    private transient String customerID;  // 不被序列化
    private int total;                    // 被序列化
    // ...
}
```

### 14.2 输出对象（序列化/ObjectOutputStream）

```java
public class SerializeDate {
    SerializeDate() {
        Date d = new Date();  // Date类实现了Serializable接口
        try {
            FileOutputStream f = new FileOutputStream("date.ser");
            ObjectOutputStream s = new ObjectOutputStream(f);
            s.writeObject(d);
            f.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    public static void main(String args[]) {
        SerializeDate b = new SerializeDate();
    }
}
```

### 14.3 输入对象（反序列化/ObjectInputStream）

```java
public class UnSerializeDate {
    UnSerializeDate() {
        Date d = null;
        try {
            FileInputStream f = new FileInputStream("date.ser");
            ObjectInputStream s = new ObjectInputStream(f);
            d = (Date) s.readObject();  // 需要强制类型转换
            f.close();
        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    public static void main(String args[]) {
        UnSerializeDate a = new UnSerializeDate();
    }
}
```

## 十五、I/O体系总结

### 15.1 流分类总览

| 分类维度 | 类型 | 顶层抽象类 |
|----------|------|------------|
| **按数据类型** | 字节流（8位） | InputStream / OutputStream |
| | 字符流（16位Unicode） | Reader / Writer |
| **按结构** | 节点流 | 直接连接特定数据源 |
| | 过滤流 | 依赖其他流进行数据处理 |

### 15.2 关键类对应关系

## 十六、本章小结

本章系统介绍了Java的输入/输出（I/O）体系，涵盖以下核心知识点：

1. **流（Stream）**：从源到目的的字节有序序列（FIFO），分为InputStream（输入）和OutputStream（输出）；操作过程为打开→读取/写入→关闭

2. **节点流与过滤流**：节点流直接连接数据源（文件、内存、管道），过滤流以其他流为输入源/输出目标（缓冲、数据转换、对象序列化等），通过套接（Chaining）组合使用

3. **字节流**：InputStream/OutputStream体系，操作8位字节，适合二进制数据；三个基本read()/write()方法及close()、flush()等辅助方法

4. **字符流**：Reader/Writer体系，操作16位Unicode字符，适合文本数据；BufferedReader新增readLine()，BufferedWriter新增newLine()

5. **字符集编码**：ASCII（单字节英文）、GB2312/GBK（双字节中文）、ISO-8859-1（单字节西欧）、Unicode（双字节通用）、UTF-8（变长编码）

6. **常用I/O流类**：
   - 文件流：FileInputStream/FileOutputStream、FileReader/FileWriter
   - 缓冲流：提供成块读写，减少I/O次数
   - 管道流：线程间直接数据传输，无需同步
   - 数据流：按基本数据类型读写
   - 标准I/O：System.in（键盘）、System.out/System.err（屏幕）

7. **File类**：文件和目录的抽象表示，提供文件信息获取和目录操作，但不提供数据读取方法

8. **RandomAccessFile**：支持文件随机存取，可操作文件指针（seek定位），同时实现DataInput和DataOutput接口

9. **对象序列化**：实现Serializable接口的对象可被永久化保存；transient关键字标记的字段不被序列化；ObjectOutputStream.writeObject()序列化，ObjectInputStream.readObject()反序列化
