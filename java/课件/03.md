## 二、标识符（Identifier）

### 2.1 标识符的组成

标识符包括：
- 变量名
- 类名
- 方法（函数）名

**命名规则**：
- 以**字母**、**_**（下划线）或**$**（美元符号）开头
- **大小写敏感**，且长度没有限定

**示例**：
```
username
user_name
_sys_varl
$change
```

| 约定项 | 规则 | 示例 |
|--------|------|------|
| 开头字符 | _、$ 不作为变量名、方法名开头 | — |

| 类名/接口名 | 首单词第一个字母大写（帕斯卡命名） | — |
| 常量 | 完全大写 | — |
| 单行注释 | `//` 注释一行 | `// 这是注释` |
| 多行注释 | `/* */` 注释一行或多行 | `/* 多行注释 */` |
| 文档注释 | `/** */` 可用javadoc命令转化为HTML文件 | — |

## 四、Java基本数据类型

Java基本数据类型分为四大类：
- **逻辑型**
- **文字型**
- **整数类型**
- **浮点型**

### 4.1 逻辑型（boolean）

- 类型：`boolean`
- 取值：`true`、`false`
- 示例：`boolean truth = true;`
- **注意**：`false` 和 `true` **不对应于任何零或非零的整数值**（与C/C++不同）

### 4.2 文字型（char 和 String）

#### char（字符型）

- 16位的**Unicode（国际码）字符**
- Unicode字符集是一套字符编码系统，可以支持各类文字的字符，达**34168个字符**
- 定义形式：
  - `'a'` —— 直接字符
  - `'\t'` —— 转义字符
  - `'\u????'` —— Unicode表示
- 示例：`char mychar = 'Q';`

#### String（字符串）

- String是**类**（不是基本类型）
- 示例：
  ```java
  String greeting = "Good Morning! \n";
  ```
- 从字符数组创建字符串：
  ```java
  char data[] = {'a', 'b', 'c'};
  String str = new String(data);
  ```
- String**不能修改**（不可变对象）。如需修改，使用**StringBuffer**或**StringBuilder**类。

### 4.3 整数类型（byte, short, int, long）

Java**没有无符号整数类型**。

| 类型 | 长度 | 取值范围 |
|------|------|----------|
| **byte** | 8位 | -2⁷ ~ 2⁷-1 |
| **short** | 16位 | -2¹⁵ ~ 2¹⁵-1 |
| **int** | 32位 | -2³¹ ~ 2³¹-1 |
| **long** | 64位 | -2⁶³ ~ 2⁶³-1 |

#### 整型常量表示

- Java中**缺省整型是int**
- 可有3种形式：十进制、八进制、十六进制

| 十进制 | 八进制 | 十六进制 |
|--------|--------|----------|
| `int 24` | `0771` | `0XAB07` |
| `long 24L` | `0771L` | `0XAB07L` |

### 4.4 浮点型（float 和 double）

| 类型 | 长度 |
|------|------|
| **float** | 32位 |
| **double** | 64位 |

- **缺省是double类型**，如 `3.14` 是double型
- 表达方法：
  - **E或e** —— 科学记数法：`6.02e23`
  - **F或f** —— 表示float类型：`6.02e23F`
  - **D或d** —— 表示double型：`2.718D`

## 五、类的初步概念

### 5.1 用类创建新类型

"日期"类型的两种不同表达：

**方式一（面向过程）**：
```java
int day, month, year;    // 定义年、月、日
int d1, m1, y1;          // 定义一个日期
int d2, m2, y2;          // 定义另一个日期
```

**方式二（面向对象）**：
```java
class Date {
    int day;
    int month;
    int year;
    void setDate(int a, int b, int c) { ... }
}
```

> Java用 **class** 创建新的类型。

### 5.2 类的变量的声明与引用

在Java中，一个类的变量声明后，**不能直接引用**，必须经过**实例化**：

- **基本类型**：声明后直接开空间。
  ```java
  int a;
  a = 12;
  ```

- **非基本类型**：不直接开空间，而是开辟引用空间，数据空间没有开。只有通过**实例化**，才能给数据开辟空间。

**示例**：
```java
Date today;              // 第1步：声明引用
today = new Date();      // 第2步：实例化，开辟数据空间
```

内存模型：`today`（引用）→ `0xabcd`（地址）→ `day=0, month=0, year=0`（实际数据）

### 5.3 引用变量之间的赋值

```java
Date a, b;
a = new Date();    // a指向新创建的Date对象
b = a;             // b也指向同一个Date对象（引用赋值）
```

此时 `a` 和 `b` 指向**同一个对象**，修改 `b` 的内容会影响 `a`。

### 5.4 JDK 1.5/1.6 中的枚举类型（enum）

- 一般用于表示一组**常量**。一个枚举声明实际上定义了一个**类**。
- 定义格式：
  ```java
  [public] enum 枚举类型名 [implements 接口名表] {
      枚举常量定义
      [枚举体定义]
  }
  ```
- 所有的枚举类型都缺省继承于**java.lang.Enum**类。Enum直接继承java.lang.Object且实现了**java.lang.Comparable**接口。
- 编译器在创建一个枚举时也将自动加入一些特殊的方法，如 `values()`。

**示例1**：
```java
public enum Names {
    Li, Zhang, Wang, Zhao, Chen
}
Names name = Names.Wang;
```

## 七、运算符与表达式

### 7.1 与C语言的不同之处

- Java是**强类型**语言，类型限制比C严格，运算符的操作对象的类型会受到更多限制
- Java**不提供指针运算符**，增加了对象操作符 `instanceof`、字符串运算符 `+` 和零填充的右移 `>>>` 等

### 7.2 Java操作符类别

| 类别 | 操作符 |
|------|--------|
| **算术运算** | `+`、`-`、`*`、`/`、`%`、`++`、`--` |
| **关系操作** | `>`、`>=`、`<`、`<=`、`==`、`!=` |
| **位操作** | `>>`、`<<`、`>>>`、`&`、`|`、`^`（逐位异或）、`~`（按位取反） |
| **逻辑操作** | `&`、`|`、`!`、`^`（异或）、`&&`、`||` |
| **赋值操作** | `=`、`+=`、`-=`、`*=`、`/=`、`%=`、`&=`、`|=`、`^=`、`<<=`、`>>=`、`>>>=` |
| **其它操作** | `?:`、`[]`、`.`、`()`、`(type)`、`new`、`instanceof` |

### 7.3 逻辑操作符与位操作符的区分

- 逻辑操作符与位操作符相同的（`&`, `|`），根据**操作数**判定是何种运算符
- `&`、`|` —— 称为**不短路与、或**
- `&&`、`||` —— 称为**短路与、或**

### 7.4 字符串连接运算符 `+`

```java
String salutation = "Dr. ";
String name = "Pete " + "Seymour";
String title = salutation + name;
// title 值为： "Dr. Pete Seymour"
```

### 7.5 Java操作符优先级

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 1 | `()`、`[]`、`{}` | 从左向右 |
| 2 | `!`、`+`、`-`、`~`、`++`、`--` | 从右向左 |
| 3 | `*`、`/`、`%` | 从左向右 |
| 4 | `+`、`-` | 从左向右 |
| 5 | `<<`、`>>`、`>>>` | 从左向右 |
| 6 | `<`、`<=`、`>`、`>=`、`instanceof` | 从左向右 |
| 7 | `==`、`!=` | 从左向右 |
| 8 | `&` | 从左向右 |
| 9 | `^` | 从左向右 |
| 10 | `|` | 从左向右 |
| 11 | `&&` | 从左向右 |
| 12 | `||` | 从左向右 |
| 13 | `?:` | 从右向左 |
| 14 | `=`、`+=`、`-=`、`*=`、`/=`、`&=`、`|=`、`^=`、`~=`、`<<=`、`>>=`、`>>>=` | 从右向左 |

### 7.6 Java强制类型转换

- 一般形式：`(type) expression`
- 示例：`(float)x / 2`
- **限制**：整型与浮点型可以相互转换，但**基本类型和数组、对象等复合类型之间不能互相转换**

### 7.7 位操作示例

```java
public class BitwiseDemo {
    static final int VISIBLE = 1;
    static final int DRAGGABLE = 2;
    static final int SELECTABLE = 4;
    static final int EDITABLE = 8;

    public static void main(String[] args) {
        int flags = 0;
        flags = flags | VISIBLE;
        flags = flags | DRAGGABLE;
        if ((flags & VISIBLE) == VISIBLE) {
            if ((flags & DRAGGABLE) == DRAGGABLE) {
                System.out.println("Flags are Visible and Draggable.");
            }
        }
        flags = flags | EDITABLE;
        if ((flags & EDITABLE) == EDITABLE) {
            System.out.println("Flags are now also Editable.");
        }
    }
}
```

**运行结果**：
```
Flags are Visible and Draggable.
Flags are now also Editable.
```

#### 例题详解：用一个整数保存多个开关状态

这个例题演示的是：用一个 `int` 类型变量中的不同二进制位，分别表示不同的状态是否开启。

也就是说，`flags` 不是只保存一个普通数字，而是把多个“开关”合并保存到同一个整数中。例如：

- 第 1 位表示是否 `VISIBLE`（可见）
- 第 2 位表示是否 `DRAGGABLE`（可拖动）
- 第 3 位表示是否 `SELECTABLE`（可选择）
- 第 4 位表示是否 `EDITABLE`（可编辑）

##### 1. `static final int` 的含义

```java
static final int VISIBLE = 1;
```

这行代码可以拆成三部分理解：

| 关键字 | 含义 |
|--------|------|
| `int` | 表示这是一个整数类型 |
| `final` | 表示赋值之后不能再修改，是一个常量 |
| `static` | 表示属于类本身，不需要创建对象就可以使用 |

所以：

```java
static final int VISIBLE = 1;
```

表示定义了一个类级别的整数常量 `VISIBLE`，它的值固定为 `1`。

在 Java 中，常量通常使用全大写命名，例如：

```java
VISIBLE
DRAGGABLE
SELECTABLE
EDITABLE
```

##### 2. 为什么常量值是 1、2、4、8

这几个值不是随便写的，而是为了让它们分别占用不同的二进制位。

| 常量名 | 十进制 | 二进制 |
|--------|--------|--------|
| `VISIBLE` | `1` | `0001` |
| `DRAGGABLE` | `2` | `0010` |
| `SELECTABLE` | `4` | `0100` |
| `EDITABLE` | `8` | `1000` |

可以看到，每个数的二进制形式中，只有一个位置是 `1`。这样每个状态都对应一个独立的开关，互不影响。

##### 3. `flags` 的作用

```java
int flags = 0;
```

`flags` 用来保存所有状态。

刚开始：

```text
flags = 0
二进制：0000
```

表示所有状态都没有开启。

##### 4. 使用 `|` 开启某个状态

```java
flags = flags | VISIBLE;
```

这里的 `|` 是按位或运算。它的规则是：只要有一个是 `1`，结果就是 `1`。

第一次开启 `VISIBLE`：

```text
flags   = 0000
VISIBLE = 0001
----------------
结果    = 0001
```

所以执行后：

```text
flags = 0001
```

表示 `VISIBLE` 已经开启。

接着执行：

```java
flags = flags | DRAGGABLE;
```

此时：

```text
flags     = 0001
DRAGGABLE = 0010
------------------
结果      = 0011
```

所以现在：

```text
flags = 0011
```

表示同时开启了 `VISIBLE` 和 `DRAGGABLE`。

##### 5. 使用 `&` 判断某个状态是否开启

```java
if ((flags & VISIBLE) == VISIBLE) {
```

这里的 `&` 是按位与运算。它的规则是：两个都是 `1` 时，结果才是 `1`。

当 `flags = 0011` 时，检查是否包含 `VISIBLE`：

```text
flags   = 0011
VISIBLE = 0001
----------------
结果    = 0001
```

结果等于 `VISIBLE`，所以说明 `VISIBLE` 这个状态已经开启。

再检查 `DRAGGABLE`：

```text
flags     = 0011
DRAGGABLE = 0010
------------------
结果      = 0010
```

结果等于 `DRAGGABLE`，所以说明 `DRAGGABLE` 也已经开启。

因此程序会输出：

```text
Flags are Visible and Draggable.
```

##### 6. 开启 `EDITABLE`

后面又执行：

```java
flags = flags | EDITABLE;
```

此时：

```text
flags    = 0011
EDITABLE = 1000
-----------------
结果     = 1011
```

所以现在：

```text
flags = 1011
```

它表示：

| 状态 | 是否开启 |
|------|----------|
| `VISIBLE` | 开启 |
| `DRAGGABLE` | 开启 |
| `SELECTABLE` | 未开启 |
| `EDITABLE` | 开启 |

然后检查：

```java
if ((flags & EDITABLE) == EDITABLE) {
```

计算过程：

```text
flags    = 1011
EDITABLE = 1000
-----------------
结果     = 1000
```

结果等于 `EDITABLE`，所以条件成立，程序输出：

```text
Flags are now also Editable.
```

##### 7. 本例中的两个核心公式

开启某个状态：

```java
flags = flags | 某个状态;
```

也可以简写为：

```java
flags |= 某个状态;
```

判断某个状态是否开启：

```java
(flags & 某个状态) == 某个状态
```

##### 8. 为什么这样写

如果状态很少，可以用多个 `boolean` 变量表示：

```java
boolean visible = true;
boolean draggable = true;
boolean selectable = false;
boolean editable = true;
```

但是使用位操作可以把多个状态压缩到一个整数中：

```java
int flags = VISIBLE | DRAGGABLE | EDITABLE;
```

这一个 `flags` 就表示：

```text
可见 + 可拖动 + 可编辑
```

这种写法常用于权限控制、界面控件状态、文件属性、系统配置、游戏角色状态等场景。

##### 9. 执行过程总表

| 步骤 | 代码 | `flags` 二进制 | 含义 |
|------|------|----------------|------|
| 初始 | `int flags = 0;` | `0000` | 什么状态都没有 |
| 开启可见 | `flags = flags | VISIBLE;` | `0001` | 开启 `VISIBLE` |
| 开启可拖动 | `flags = flags | DRAGGABLE;` | `0011` | 开启 `VISIBLE` 和 `DRAGGABLE` |
| 检查可见 | `flags & VISIBLE` | `0001` | 判断出可见已开启 |
| 检查可拖动 | `flags & DRAGGABLE` | `0010` | 判断出可拖动已开启 |
| 开启可编辑 | `flags = flags | EDITABLE;` | `1011` | 开启 `EDITABLE` |
| 检查可编辑 | `flags & EDITABLE` | `1000` | 判断出可编辑已开启 |

一句话总结：本例通过 `static final int` 定义固定的状态位，用 `|` 把状态加入 `flags`，用 `&` 判断 `flags` 中是否包含某个状态。

## 八、流程控制

### 8.1 流程控制语句

- `while`
- `do … while`
- `for`
- `if … else`

### 8.2 While语句示例

```java
public class WhileDemo {
    public static void main(String[] args) {
        String copyFromMe = "Copy this string until you " +
            "encounter the letter 'g'.";
        StringBuffer copyToMe = new StringBuffer();
        int i = 0;
        char c = copyFromMe.charAt(i);
        while (c != 'g') {
            copyToMe.append(c);
            c = copyFromMe.charAt(++i);
        }
        System.out.println(copyToMe);
    }
}
```

**结果**：`Copy this strin`

### 8.3 do-while语句示例

```java
public class DoWhileDemo {
    public static void main(String[] args) {
        String copyFromMe = "Copy this string until you " +
            "encounter the letter 'g'.";
        StringBuffer copyToMe = new StringBuffer();
        int i = 0;
        char c = copyFromMe.charAt(i);
        do {
            copyToMe.append(c);
            c = copyFromMe.charAt(++i);
        } while (c != 'g');
        System.out.println(copyToMe);
    }
}
```

**结果**：`Copy this strin`

### 8.4 JDK 1.5+ for循环的优化（增强for循环 / for-each）

```java

for (String option : names) {
    System.out.println(option);
}
```

## 九、数组（Array）

### 9.1 数组的基本特点

- 数组中的元素都是**同一种类型**
- 数组的长度在**创建的时候确定**，并且在创建后**固定不变**
- 如果要建立存储**不同类型数据**的集合，或者要求集合的长度可以**动态变化**，可以使用**Collection（集合）类**

### 9.2 数组声明

- 可以声明**基本类型**和**类类型**的数组
- 声明包含两部分：**数组类型**与**数组名称**

**格式**：

| 风格 | 示例 |
|------|------|
| C/C++ 标准形式 | `char s[];` `Point p[];` |
| Java 推荐形式 | `char[] s, m, n;` `Point[] p;` |

> 在Java中数组作为**类**来处理，所以数组声明并**不创建实例对象**，而是创建一个可用来引用该数组的**引用**。

### 9.3 数组的创建

可以像其它对象一样，使用 **new** 来创建，格式：
```
new elementType[arraySize]
```

**示例**：
```java
s = new char[20];      // 创建有20个字符的数组
p = new Point[100];    // 创建100个Point的引用数组
```

### 9.4 数组的初始化

- 数组在创建后，其元素是被**系统自动初始化**的：
  - 字符数组 → `' '`
  - 对象数组 → `null`

**用初始值创建数组**：
```java
String names[] = {"Jack", "Wang", "Lee"};
int a[] = {1, 2, 3};
Date d[] = {new Date(), new Date(), new Date()};
```

### 9.5 对象数组

除了基本类型以外，还可以创建对象类型的数组。

```java
Point[] p;
p = new Point[100];       // 创建100个引用（此时都是null）
```

**创建100个Point对象**：
```java
p[0] = new Point();
p[1] = new Point();
…
```

**对象数组示例**：
```java
public class NewArrayOfStringsDemo {
    public static void main(String[] args) {
        String[] anArray = { "String One", "String Two", "String Three" };
        for (String s : anArray) {
            System.out.println(s.toLowerCase());
        }
    }
```

### 9.6 栈内存与堆内存

| 内存区域 | 存放内容 |
|----------|----------|
| **栈内存** | 存放基本类型的变量、对象的引用和方法调用，遵循**FILO**原则（先进后出） |
| **堆内存** | 存放所有**new出来的对象和数组**。和数据结构中的堆是两码事 |
| **常量池** | 存放基本类型常量和字符串常量（`public static final`） |
| **静态域** | 存放静态成员（`static`定义的） |

#### 为什么需要堆和栈？

通常与**垃圾回收机制**有关，使程序运行时占用内存最小。

- 当一个方法执行时，每个方法都会建立自己的内存栈，在这个方法内定义的变量将会逐个放入这块栈内存里，随着方法的执行结束，这个方法的内存栈也将自然销毁。因此，所有在方法中定义的变量都是放在**栈内存**中的。
- 当程序中创建一个对象时，这个对象将被保存到运行时数据区（**堆内存**）中，以便反复利用（因为对象的创建成本通常较大）。堆内存中的对象不会随方法的结束而销毁——即使方法结束后，这个对象还可能被另一个引用变量所引用（方法的参数传递时很常见），则这个对象依然不会被销毁。只有当一个对象没有任何引用变量引用它时，系统的**垃圾回收机制**才会在合适的时候回收它。

#### 成员变量的赋值问题

类成员变量在类的范围内，存在于**堆内存**中，会有**默认的初始值**，在声明的同时已经给变量赋值了。再次"赋值"实际是使用了语句，而**类体里面只能出现变量和方法，不能出现语句**（除非用花括号括起来）。
