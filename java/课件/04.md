## 二、对象的基本概念

### 2.1 面向对象程序语言的三个关键特点

#### 封装（Encapsulation）

将对象的数据与操作数据的方法相结合，通过方法将对象的数据与实现细节保护起来，就称为封装。

#### 继承（Inheritance）

子类继承父类的状态和行为，子类可以重用父类中的这部分代码。**Java只支持单继承**，类的层次结构为树型而非网状结构。

#### 多态（Polymorphism）

对外一个接口，内部多种实现：
- 通过方法的**重载（Overloading）**实现**编译时多态**
- 通过类之间的**继承性**、**方法重写（Overriding）**以及**晚联编**技术实现**运行时多态**

### 2.2 抽象数据类型

- 在面向对象语言中，在数据类型的声明与操作这些数据的代码声明之间建立紧密联系，这种联系通常描述为一种**抽象数据类型**
- 在Java中，抽象数据类型的概念用**类（class）**来实现

## 三、类和对象

### 3.1 类与对象的定义

- **类**是特定类型对象的定义，包括：对象包含的数据、对象的创建及对象对自身数据操作的方法
- **类**是创建对象的**模板**，**对象**是类的**实例**
- 声明对象变量之后，还不能使用对象。必须用运算符**new**创建对象实体之后，才能使用对象

### 3.2 new关键字的作用

1. 为对象**分配内存空间**
2. 引起对象**构造方法的调用**
3. 为对象**返回一个引用**

### 3.3 对象的内存分配

声明一个引用类型变量时，系统只为该变量分配了**引用空间**，并未创建具体对象；当用 `new` 为对象分配空间后，将对象的引用赋值给引用变量。

**内存模型**：栈内存中存放引用变量，堆内存中存放实际对象数据。

### 3.4 类和对象示例

**类定义**：
```java
class EmpInfo {
    String name;
    String designation;
    String department;
    void print() {
        System.out.println(name + " is " + designation + " at " + department);
    }
}
```

**对象的生成与使用**：
```java
EmpInfo employee = new EmpInfo();
employee.name = "Robert Javaman";
employee.designation = "Manager";
employee.department = "Coffee shop";
employee.print();
```

## 五、成员方法

### 5.1 参数传递机制

- 方法是**传值**的，方法调用不会改变参数的值。即调用时参数传递给方法，就是赋值的过程
- 当**对象作为参数**时，参数的值是该对象的**引用**，这时对象的内容可以在方法中改变，但是对象的**引用不会改变**

### 5.2 可变参数列表（Varargs）

- 定义格式：`类型 … 参数名`
- 可以使方法具有数目不定的多个参数
- 只能作为方法参数列表中的**最后一个**

### 5.3 参数传递示例

```java
public class PassTest {
    float ptValue;

    public void changeInt(int value) {
        value = 55;
    }

    public void changeStr(String value) {
        value = new String("different");
    }

    public void changeObjValue(PassTest ref) {
        ref.ptValue = 99.0f;
    }

    public static void main(String args[]) {
        String str;
        int val;
        PassTest pt = new PassTest();

        val = 11;
        pt.changeInt(val);
        System.out.println("Int value is: " + val);     // 输出: 11 (未改变)

        str = new String("hello");
        pt.changeStr(str);
        System.out.println("Str value is: " + str);     // 输出: hello (未改变)

        pt.ptValue = 101.0f;
        pt.changeObjValue(pt);
        System.out.println("pt value is: " + pt.ptValue); // 输出: 99.0 (对象内容被改变)
    }
}
```

> **关键理解**：基本类型传值不改变原值；引用类型传值时，引用本身不变（不能指向新对象），但引用指向的对象内容可以改变。

## 六、数据封装与隐藏

### 6.1 封装（Encapsulation）

**封装**：基本数据和对数据进行的操作方法的结合。

**优点**：
- 隐藏类中具体实现的细节
- 强迫程序员使用统一的接口访问数据
- 使代码**可维护性**好

### 6.2 数据隐藏（Data Hiding）

使用 **private** 定义的成员变量，只能在成员方法中使用，其它方法中禁止使用。

**优点**：
- 保证对象中数据的**一致性**

### 6.3 封装示例

```java
class Date {
    private int day, month, year;

    void setDate(int a, int b, int c) {
        day = a;
        month = b;
        year = c;
    }
}

// 使用
Date d1;
d1 = new Date();
d1.setDate(30, 9, 2001);
// d1.day = 30;  ← 错误！private变量不能直接访问
```

## 七、重载（Overloading）

### 7.1 重载的含义

在**同一个类**中一个方法名被用来定义**多个方法**。

```java
class Screen {
    public void print(int i) { … }
    public void print(float i) { … }
    public void print(String str) { … }
}
```

### 7.2 重载必须遵守的原则

- **参数表必须不同**，以此区分不同方法体
- **返回类型、修饰符**可相同也可不同

## 八、this关键字

关键字 **this** 用来指向**当前对象本身**。

当类中有两个同名变量，一个属于类（类的成员变量），而另一个属于某个特定的方法（方法中的局部变量），使用 `this` 区分成员变量和局部变量。

```java
class MyDate {
    private int day, month, year;

    public MyDate(int day, int month, int year) {
        this.day = day;
        this.month = month;
        this.year = year;
    }
}
```

## 九、构造方法（Constructor）

### 9.1 构造方法的定义

- 所有的类都有构造方法，用来进行该类对象的**初始化**
- 构造方法定义格式：
  ```java
  [public|protected|private] ClassName([<argument_list>]) { … }
  ```
- **方法名必须与类名相同**
- **不能带返回值**（连void也不写）
- 不是类的方法，不称为类的成员
- **不能直接调用**（只能通过new调用）

### 9.2 默认构造方法

- 如果在类定义中**无构造方法**，Java在编译时自动加入**默认构造方法**：
  ```java
  public Employee() { }
  ```
- 一旦在类中有一个自己声明的构造方法，则**默认的构造方法将不被加到类的定义中**

### 9.3 重载构造方法

在一个构造方法中可以利用另一个构造方法（通过 `this()` 调用）：

```java
class Employee {
    private String name;
    private int salary;

    public Employee(String n, int s) {
        name = n;
        salary = s;
    }

    public Employee(String n) {
        this(n, 0);            // 调用两个参数的构造方法
    }

    public Employee() {
        this("Unknown");       // 调用一个参数的构造方法
    }
}
```

## 十、访问控制（Access Control）

### 10.1 访问级别

- 成员变量和方法有**4种访问级别**：`public`、`protected`、`default`（包级）、`private`
- 类有两种访问级别：`public` 或 `default`

### 10.2 修饰符的作用范围

| 修饰符 | 同一个类 | 同一个包 | 子类（不同包） | 所有类 |
|--------|:--------:|:--------:|:--------------:|:------:|
| **public** | ✓ | ✓ | ✓ | ✓ |
| **protected** | ✓ | ✓ | ✓ | — |
| **default** | ✓ | ✓ | — | — |
| **private** | ✓ | — | — | — |

**形象比喻**：

| 修饰符 | 比喻 |
|--------|------|
| public | 所有人 |
| protected | 本人 + 自己家 + 独立子女（或克隆体） |
| default | 本人 + 自己家（配偶/未分家子女） |
| private | 本人 |

### 10.3 private 访问控制

```java
class Alpha {
    private int iamprivate;
    private void privateMethod() {
        System.out.println("privateMethod");
    }
}

class Beta {
    void accessMethod() {
        Alpha a = new Alpha();
        a.iamprivate = 10;         // illegal!
        a.privateMethod();         // illegal!
    }
}
```

> **注意**：访问控制应用于**class层次**，而不是对象层次。同一类的不同实例可以互相访问私有成员。

### 10.4 default（package）访问控制

同一包内的类可以访问default级别的成员：

```java
package Greek;
class Alpha {
    int iampackage;
    void packageMethod() {
        System.out.println("packageMethod");
    }
}

package Greek;
class Beta {
    void accessMethod() {
        Alpha a = new Alpha();
        a.iampackage = 10;          // ✓ legal
        a.packageMethod();          // ✓ legal
    }
}
```

### 10.5 protected 访问控制

允许类本身、它的子类、以及同一个包中其余的类访问这些成员。

**同一包内访问**：
```java
package Greek;
public class Alpha {
    protected int iamprotected;
    protected void protectedMethod() {
        System.out.println("protectedMethod");
    }
}

package Greek;
class Gamma {
    void accessMethod() {
        Alpha a = new Alpha();
        a.iamprotected = 10;        // ✓ legal
        a.protectedMethod();        // ✓ legal
    }
}
```

**不同包内子类访问**：
```java
package Latin;
import Greek.*;

class Delta extends Alpha {
    void accessMethod(Alpha a, Delta d) {
        d.iamprotected = 10;        // ✓ legal（通过自身/子类访问）
        d.protectedMethod();        // ✓ legal
        a.iamprotected = 10;        // ✗ illegal! 不能通过父类引用直接访问
        a.protectedMethod();        // ✗ illegal! 不能通过父类引用直接访问
    }
}
```

> **重要**：子类不能直接访问不在同一个包中的父类的protected变量和方法，**只能通过自身（或子类）访问**。

## 十一、内部类（Inner Class）

### 11.1 内部类的定义

内部类是在一个类的声明里声明的类。

```java
class A {
    …
    class B {
        …
    }
    …
}
```

内部类可作为类的一个成员使用，一般只在外包类中调用。

### 11.2 内部类的四种形式

1. 在类中定义一个类（**私有内部类**、**静态内部类**）
2. 在方法中定义一个类（**局部内部类**、**匿名内部类**）

### 11.3 内部类的意义

- 完善**多重继承**
- 实现**事件驱动系统**
- 实现**闭包**

### 11.4 内部类示例

```java
class Outer {
    private int index = 100;

    void print() {
        Inner i = new Inner();
        i.print();
    }

    class Inner {
        void print() {
            System.out.println(index);    // 内部类可以访问外部类的私有成员
        }
    }
}

class Test {
    public static void main(String[] args) {
        Outer o = new Outer();
        o.print();
    }
}
```

**编译器对内部类的处理**：
1. 在内部类中偷偷创建了包可见构造器，从而使外部类获得了创建权限
2. 在外部类中偷偷创建了访问私有变量的静态方法，从而使内部类获得了访问权限

这样，类中定义的内部类无论私有、公有、静态都可以被包围它的外部类所访问。

### 11.5 内部类的特点（七条规则）

1. 内部类的类型只用于定义它的类或语句块之内，在外部引用它时，必须给出带有外包类名的完整名称，并且内部类的名字不许与外包类的名字相同
2. 内部类可以访问外包类的**static**或**实例**成员变量
3. 内部类可以在成员方法中定义，该成员方法的局部变量或参数必须是**final**的才能被内部类使用
4. 内部类可以是抽象类或者接口，如果是接口，可以由其他内部类实现
5. 内部类可以使用 `public`、`protected`、`default`、`private` 四种访问权限控制
6. 内部类可以被声明为**static**（普通类是不可以的），这样的内部类就变成了顶层类，相当于把它放在外面，不再是嵌套的内部类，并且它的对象中将不包含指向外包类对象的指针，所以不能再引用外包类对象
7. 只有顶层类可以声明static成员。如果内部类需要static成员，那么内部类必须声明为static类型，否则，一般内部类成员不能被声明为static

### 11.6 四种内部类的详细特点

#### (1) 在方法间定义的非静态内部类
- 外包类和内部类可互相访问自己的私有成员
- 内部类中**不能定义静态成员变量**

#### (2) 在方法间定义的静态内部类
- 只能访问外包类的**静态成员**

#### (3) 在方法中定义的局部内部类
- 该内部类**没有任何的访问控制权限**
- 外包类看不见方法中的局部内部类的成员，但是局部内部类可以访问外包类的任何成员
- 方法体中可以访问局部内部类，但是访问语句必须在定义局部内部类**之后**
- 局部内部类只能访问方法体中的常量，即用**final**修饰的成员

#### (4) 在方法中定义的匿名内部类
- **没有构造器**，取而代之的是将构造器参数传递给超类构造器

## 十二、对象生命周期

对象生命周期包括三个阶段：**创建 → 使用 → 回收**

### 12.1 创建对象

**示例**：
```java
Point origin_one = new Point(23, 94);
Rectangle rect_one = new Rectangle(origin_one, 100, 200);
Rectangle rect_two = new Rectangle(50, 100);
```

**创建对象的两个步骤**：

1. **声明变量**：以 `SomeClass objectVar` 的形式声明保存该对象引用的变量，将来可通过该变量对对象进行操作。**仅分配引用空间并未创建对象！**

2. **对象实例化**：通过 `new` 运算符进行实例化：
   - 为对象分配空间
   - 执行构造方法
   - 为对象返回一个引用

### 12.2 对象实例化过程

构造与初始化对象的过程（调用 `new Xxxx()`）：

1. **开辟内存空间**（变量、方法体代码）及类成员变量的初始化：
   - 数值型：`0`
   - 布尔型：`false`
   - 引用型：`null`
   - 字符串型：`null`

2. **显式初始化**：执行类成员声明时带有的简单赋值表达式
   ```java
   public class Initialized {
       private int x = 5;
       private String name = "Fred";
       …
   }
   ```

3. **执行构造方法**

### 12.3 对象的回收（垃圾收集机制）

- **垃圾收集机制（Garbage Collection）**：Java运行环境当确定某个对象不再被使用时，将其删除
- 一个对象在**没有引用指向它时**，可作为垃圾收集
- **垃圾收集器**：Java运行环境中的垃圾收集器周期性地释放不用对象占用的空间

### 12.4 Java与C++内存管理对比

**C++**：
```cpp
A *a = new A();
A *b = a;
A *c = a;
delete a;    // a使用完，将其删除 → b、c成为悬空指针
```

**Java**：
```java
A a = new A();
A b = a;
A c = a;
a = null;    // a使用完，将其设为null → b、c仍持有引用，对象不会被回收
```

Java的垃圾收集器自动管理内存，避免了C++中的**指针悬空**和**内存泄漏**问题。

## 十三、类的继承与多态

### 13.1 继承的概念

子类表示类之间一种**"属于"（is-a）关系**。

**反例（无继承时）**：
```java
public class Employee {
    String name;
    Date hireDate;
    Date dateofBirth;
    String jobTitle;
    int grade;
    …
}

public class Manager {
    String name;                // 与Employee重复
    Date hireDate;              // 与Employee重复
    Date dateofBirth;           // 与Employee重复
    String jobTitle;            // 与Employee重复
    int grade;                  // 与Employee重复
    String department;          // Manager特有
    Employee[] subordinates;    // Manager特有
    …
}
```

### 13.2 extends关键字

Java中用 **extends** 关键字定义子类：

```java
public class Employee {
    String name;
    Date hireDate;
    Date dateofBirth;
    String jobTitle;
    int grade;
    …
}

public class Manager extends Employee {
    String department;          // 只需声明特有属性
    Employee[] subordinates;
}
```

**子类是从已有的类创建新类的一种方法。**

### 13.3 子类的继承规则

- 子类继承父类的属性、功能（方法），子类中只需声明**特有的**东西
- 带**private**修饰符的属性、方法是**不能被继承**的
- **构造方法不能被继承**
- 在方法中调用构造方法用 `this()`，调用父类的构造方法用 `super()`，而且该语句要出现在子类构造方法的**第一行**

### 13.4 单继承

- Java是**单继承**的，即只能从一个类继承，extends后类名只能有一个
- **单继承的优点**：
  - 代码更可靠
  - 可以用**接口弥补**——用一个类实现多个接口，达到多继承效果

**类层次结构示例**：
```
Employee
├── Engineer
├── Manager
│   └── Director
└── Secretary
```

### 13.5 super关键字

**super** 指向该关键字所在类的**父类**。可以使用 super 访问父类被子类隐藏的变量或**覆盖的方法**。

```java
public class Employee {
    private String name;
    private int salary;

    public String getDetails() {
        return "Name: " + name + "\nSalary:" + salary;
    }
}

public class Manager extends Employee {
    private String department;

    public String getDetails() {
        return super.getDetails() + "\nDepartment: " + department;
    }
}
```

### 13.6 子类对象的初始化

初始化对象是很结构化的，在对对象初始化时，分**三步**：
1. 分配空间，并初始化为0值
2. 按继承关系从顶向下**显式初始化**
3. 按继承关系从顶向下**调用构造方法**

#### 初始化详细流程

**a. 加载类**
1. 为**父类**静态属性分配内存并赋值 / 执行父类静态代码段（按代码顺序）
2. 为**子类**静态属性分配内存并赋值 / 执行子类静态代码段（按代码顺序）

**b. 创建对象**
1. 为**父类**实例属性分配内存并赋值 / 执行父类非静态代码段（按代码顺序）
2. 执行**父类**构造器
3. 为**子类**实例属性分配内存并赋值 / 执行子类非静态代码段（按代码顺序）
4. 执行**子类**构造器

### 13.7 调用父类构造方法

- **缺省**是不带参数的构造方法
- 如果需要调用特殊的父类构造方法，则需在子类构造方法中**第一行**通过 `super(…)` 调用

```java
class Employee {
    public Employee(String n) {
        name = n;
    }
}

class Manager extends Employee {
    public Manager(String s, String d) {
        super(s);          // 必须在第一行调用父类构造方法
        department = d;
    }
}
```

### 13.8 对象实例化过程完整示例

```java
class Meal        { Meal()         { System.out.println("Meal()");        } }
class Bread       { Bread()        { System.out.println("Bread()");       } }
class Cheese      { Cheese()       { System.out.println("Cheese()");      } }
class Lettuce     { Lettuce()      { System.out.println("Lettuce()");     } }
class Lunch extends Meal           { Lunch()    { System.out.println("Lunch()");        } }
class PortableLunch extends Lunch  { PortableLunch() { System.out.println("PortableLunch()"); } }

public class Sandwich extends PortableLunch {
    private Bread b = new Bread();
    private Cheese c = new Cheese();
    private Lettuce l = new Lettuce();
    public Sandwich() { System.out.println("Sandwich()"); }
    static { System.out.println("Static statement"); }

    public static void main(String[] args) {
        new Sandwich();
    }
}
```

**运行顺序**：

## 十四、重写（Overriding）

### 14.1 重写的概念

- 重写是指**子类重写父类的成员方法**
- 子类通过成员变量的隐藏和方法的重写可以把父类的状态和行为改变为**自身的状态和行为**
- 被重写方法的**返回值**、**方法名**、**参数列表**要与父类中的方法**完全一样**

### 14.2 重写示例

```java
class Employee {
    String name;
    int salary;

    public Employee(String name, int salary) {
        this.name = name;
        this.salary = salary;
    }

    public String getDetails() {
        return "Name: " + name + "\nSalary: " + salary;
    }
}

class Manager extends Employee {
    private String department;

    public Manager(String name, int salary, String department) {
        super(name, salary);
        this.department = department;
    }

    public String getDetails() {        // 重写父类方法
        return "Name: " + name + "\nSalary: " + salary
               + "\nDepartment: " + department;
    }
}
```

### 14.3 方法重写的规则

1. **必须返回**与原来方法完全相同的返回值
2. 方法的**访问权限不能缩小**
3. **不能抛出新的异常**——重写方法不能抛出新的受检异常或者比被重写方法更加宽泛的受检异常，可以抛出非受检异常（父类只抛出受检异常情况下）

> 例如：父类的一个方法抛出了一个受检异常 `IOException`，重写该方法时不能抛出 `Exception`，只能抛出 `IOException` 的子类异常，或非受检异常。

**异常分类回顾**：
- `Error` 和 `RuntimeException` 及其子类属于**非受检异常（unchecked）**
- 其它异常属于**受检异常（checked）**

## 十五、多态（Polymorphism）

### 15.1 多态的概念

> An object has only one form, while a variable is polymorphism, since it can refer to objects of different forms. Polymorphism is the ability to have many different forms.

通过覆盖父类的方法来实现，在运行时根据传递的对象引用，来调用相应的方法。

### 15.2 多态的使用

- Java允许**父类对象的变量作为子类对象的变量**使用：
  ```java
  Employee e = new Manager();
  ```
- 但通过该变量（如e）只能访问**父类的方法**，子类特有的部分**被隐藏**
- **运行时**确定使用父类还是子类的方法：
  ```java
  Employee e = new Manager();
  e.getDetails();    // 运行时调用 Manager 的 getDetails() 方法
  ```

### 15.3 构造不同类型数据的集合（上溯造型 / Upcasting）

Java中允许构造如下类型的数组：

```java
Employee[] staff = new Employee[1024];
staff[0] = new Manager();
staff[1] = new Worker();
staff[2] = new Employee();
…
```

staff是由多种类型的对象组成的。Java中任何一个子类的实例都可作为父类的实例使用，可以调用父类具有的方法——这就是**上溯造型（Upcasting）**。

### 15.4 instanceof 及强制类型转换（下溯造型 / Downcasting）

#### instanceof 测试对象类型

```java
Employee a = new Manager();
// a instanceof Manager 为 true
// a instanceof Employee 也为 true
```

#### 强制类型转换（下溯造型）

父类弱、子类强，指向父类的引用不能直接按子类引用，必须要**强制类型转换**后才能作为子类的引用使用。

```java
public void method(Employee e) {
    if (e instanceof Manager) {
        Manager m = (Manager) e;      // 强制类型转换（下溯造型）
        m.department = "…";
        …
    }
}
```
