## 二、Java基础类库（JFC）

### 2.1 JFC概述

**JFC（Java Foundation Classes）** 是Java基础类库，包括开发GUI所需的组件和服务，包含5个部分的API：

| 模块 | 说明 |
|------|------|
| **AWT** | 抽象窗口工具集，包括建立GUI的各种组件与事件处理机制 |
| **Java 2D** | 一套图形API，提供高级二维图形图像处理类，扩展了java.awt和java.awt.image类，提供丰富的绘图风格 |
| **Accessibility** | 辅助工具，支持非传统输入和输出的应用程序（如屏幕阅读器、屏幕放大器、语音处理等） |
| **Drag & Drop** | 拖放功能，提供Java和本地应用程序之间的互操作性，在Java和非Java应用程序之间交换数据 |
| **Swing** | JFC模块的**重点**，用于基于窗口的应用程序开发，提供丰富的组件和工作框架，指定GUI如何独立于平台地展现其视觉效果 |

## 三、抽象窗口工具集（AWT）简介

### 3.1 AWT设计目标与实现方法

- **设计目标**：具有**独立于平台的API**，但同时保留每个平台的界面显示风格 **L&F（Look & Feel）**
- **实现方法**：定义各种组件（Components）类平台独立的API，然后利用特定于平台的各种类的实现（称为**对等组件，Peers**）提供具有特定平台风格的L&F

**架构示意**：
```
平台无关API → Button 类
                ↓
特定于平台的实现 → ButtonPeer (Windows) / ButtonPeer (MacOS) / ButtonPeer (Motif)
```

### 3.2 AWT主要类及层次关系

```

  ├── FlowLayout
  ├── GridBagLayout
  ├── MenuComponent

        ├── Button
        └── Container
              ├── Panel
              │     └── Applet

              ├── Window

              └── ...
```

## 四、Swing简介

### 4.1 Swing的特点

| 特点 | 说明 |
|------|------|
| **全部Java实现** | Swing中的所有组件全部用Java语言实现（**轻量级 Lightweight**） |
| **分离模型** | 组件及与组件相关的数据模型分离 |
| **可设置L&F** | 可设置的组件外观感觉（Look & Feel） |
| **更丰富组件** | 与AWT相比提供更丰富的GUI组件，引入新的特征和更丰富的功能 |

- 都实现了 `Accessible` 接口

- 使用**图标**

## 七、常用容器

### 7.1 容器概述

- 组成GUI的组件（如按钮、标签等）不能独立使用，**必须放在容器内**
- 容器本身也是一个组件，具有组件的所有性质，另外还具有**容纳其它组件**的功能
- 所有的组件都可以通过 `add()` 方法向容器中添加
- 在Swing中，常用的三种类型的容器是：**JFrame**、**JPanel**、**JApplet**

### 7.2 三层容器层次结构

Swing GUI形成 **顶层容器 → 中间层容器 → 基本组件** 的层次包容关系：

| 层次 | 说明 | 常用组件 |
|------|------|----------|
| **顶层容器** | 提供组件需要的绘制与事件处理功能，应用必须至少有一个 | JFrame、JDialog、JApplet |
| **中间层容器** | 由通用容器构成，主要简化组件布局 | JPanel、JScrollPane、JTabbedPane |
| **基本组件** | 直接向用户展示信息或获取用户输入 | JButton、JLabel、JTextField等 |

### 7.4 JFrame（顶层容器）

最常用的顶层容器，一般作为Java Application的**主窗口**。

**向JFrame添加组件的三种方式**：

| 方式 | 说明 |
|------|------|
| `frame.getContentPane().add(component)` | 获取JFrame的内容面板，再用add()方法加入组件 |
| `frame.setContentPane(panel)` | 建立JPanel等中间容器，添加组件到中间容器，再设置为内容面板 |
| `frame.add(child)` | JDK 1.5+后add()方法被重写，自动转交给内容面板 |

**JFrame示例**：
```java
import java.awt.*;
import javax.swing.*;

public class JFrameDemo {
    public static void main(String s[]) {
        // 指定使用当前的Look&Feel装饰窗口（必须在创建窗口前设定）
        JFrame.setDefaultLookAndFeelDecorated(true);
        // 创建并设定关闭窗口操作
        JFrame frame = new JFrame("JFrameDemo");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        // 创建一个JLabel并加到窗口中
        JLabel emptyLabel = new JLabel("");
        emptyLabel.setPreferredSize(new Dimension(175, 100));
        frame.add(emptyLabel, BorderLayout.CENTER);
        // 显示窗口
        frame.pack();
        frame.setVisible(true);
    }
}
```

### 7.5 JPanel（通用容器）

JPanel是存放轻型组件的**通用容器**，缺省情况下是**透明**的，其对象可作为顶层容器的Content Pane使用。

**JPanel示例**：
```java
import java.awt.*;
import javax.swing.*;

public class FrameWithPanel extends JFrame {
    public FrameWithPanel(String str) {
        super(str);
    }

    public static void main(String args[]) {
        FrameWithPanel fr = new FrameWithPanel("Hello !");
        fr.setSize(200, 200);
        fr.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        JPanel pan = new JPanel();
        pan.setSize(200, 100);
        pan.setBackground(Color.yellow);
        pan.setLayout(new GridLayout(2, 1));
        pan.add(new JButton("确定"));
        fr.setContentPane(pan);
        fr.setVisible(true);
    }
}
```

## 八、布局管理器（Layout Manager）

### 8.1 布局管理器概述

为了实现跨平台的特性并获得动态的布局效果，Java在容器（如JFrame、JPanel）中设置了**布局管理器（Layout Manager）** 负责对容器内的组件进行布局。

**核心特点**：
- 容器中组件的布局通常由Layout Manager控制
- Layout Manager负责决定容器的布局策略及容器内组件的排列顺序、大小和位置，以及当窗口移动或调整大小后组件如何变化
- 每个容器都有一个**默认的Layout Manager**，可通过调用 `setLayout()` 方法改变

### 8.2 Java提供的布局管理器

| 布局管理器 | 类型 | 说明 |
|-----------|------|------|
| **FlowLayout** | 流式 | 从左到右、从上到下逐行摆放 |
| **BorderLayout** | 边界 | 分5个区（North/South/West/East/Center） |
| **GridLayout** | 网格 | n行×m列同样大小的网格单元 |
| **CardLayout** | 卡片 | 组件像一系列卡片叠放，一次只能看到最上面的 |
| **GridBagLayout** | 网格包 | 不需要组件尺寸一致，容许组件扩展到多行多列 |
| **BoxLayout** | 箱式 | Swing新增，将组件垂直或水平摆放 |

### 8.3 FlowLayout

**特点**：组件采用从左到右，从上到下逐行摆放。**Panel和Applet默认布局**。

**构造方法**：
```java
setLayout(new FlowLayout(int align, int hgap, int vgap));
// FlowLayout.LEFT / FlowLayout.CENTER / FlowLayout.RIGHT
// 缺省是居中
```

**示例**：
```java
import java.awt.*;
import javax.swing.*;

public class FlowLayoutWindow extends JFrame {
    public FlowLayoutWindow() {
        setLayout(new FlowLayout());
        add(new JLabel("Buttons:"));
        add(new JButton("Button 1"));
        add(new JButton("2"));
        add(new JButton("Button 3"));
        add(new JButton("Long-Named Button 4"));
        add(new JButton("Button 5"));
    }
    public static void main(String args[]) {
        FlowLayoutWindow window = new FlowLayoutWindow();
        window.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        window.setTitle("FlowLayoutWindow Application");
        window.pack();  // 窗口大小设置为适合组件最佳尺寸与布局所需空间
        window.setVisible(true);
    }
}
```

### 8.4 BorderLayout

**特点**：分5个区（North、South、West、East、Center）。**Window、Dialog和Frame默认布局**。

**构造与使用**：
```java
setLayout(new BorderLayout(int hgap, int vgap));
add(new JButton("Center"), "Center");
```

**示例**：
```java
import java.awt.*;
import javax.swing.*;

public class BorderLayoutWindow extends JFrame {
    public BorderLayoutWindow() {
        setLayout(new BorderLayout());
        add(new JButton("North"), "North");
        add(new JButton("South"), "South");
        add(new JButton("East"), "East");
        add(new JButton("West"), "West");
        add(new JButton("Center"), "Center");
    }
    public static void main(String args[]) {
        BorderLayoutWindow window = new BorderLayoutWindow();
        window.setTitle("BorderWindow Application");
        window.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        window.pack();
        window.setVisible(true);
    }
}
```

### 8.5 GridLayout

**特点**：把容器分成 **n行×m列** 同样大小的网格单元，每个单元可充满一个组件。组件从左到右、从上到下填充。

**构造方法**：
```java
setLayout(new GridLayout(int rows, int cols, int hgap, int vgap));
// rows或cols可取0，表示任意数目的行或列；先满足行的限制
```

**示例**：
```java
import java.awt.*;
import javax.swing.*;

public class GridLayoutWindow extends JFrame {
    public GridLayoutWindow() {
        setLayout(new GridLayout(3, 2));
        add(new JButton("Button 1"));
        add(new JButton("2"));
        add(new JButton("Button 3"));
        add(new JButton("Long-Named Button 4"));
        add(new JButton("Button 5"));
        add(new JButton("6"));
        add(new JButton("找茬"));  // 行优先
    }
    public static void main(String args[]) {
        GridLayoutWindow window = new GridLayoutWindow();
        window.setTitle("GridWindow Application");
        window.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        window.pack();
        window.setVisible(true);
    }
}
```

### 8.6 CardLayout

**特点**：把组件像**一系列卡片**一样叠放，一个时刻只能看到最上面的。

**构造方法**：
```java
setLayout(new CardLayout(int hgap, int vgap));
```

**导航方法**：`first()`, `previous()`, `next()`, `last()`, `show()`

**添加组件**：
```java
public Component add(String name, Component comp);
```

**示例**：
```java
import java.awt.*;
import java.awt.event.*;
import javax.swing.*;

public class CardLayoutWindow extends JFrame implements ActionListener {
    JPanel cards;
    CardLayout CLayout = new CardLayout();

    public CardLayoutWindow() {
        setLayout(new BorderLayout());

        // 创建摆放"卡片切换"按钮的panel,并添加到Frame中
        JPanel cp = new JPanel();
        JButton bt = new JButton("卡片切换");
        bt.addActionListener(this);
        cp.add(bt);
        add("North", cp);

        // 创建承放多个卡片的Panel，设置为CardLayout
        cards = new JPanel();
        cards.setLayout(CLayout);

        // 创建第一个panel及其组件
        JPanel p1 = new JPanel();
        p1.add(new JButton("Button 1"));
        p1.add(new JButton("Button 2"));
        p1.add(new JButton("Button 3"));

        // 创建另一个panel及其组件
        JPanel p2 = new JPanel();
        p2.add(new JTextField("TextField", 20));

        // 把两个panel加到cards中
        cards.add("Panel with Buttons", p1);
        cards.add("Panel with TextField", p2);

        // 将cards放入Frame中
        add("Center", cards);
    }

    // 响应点击切换卡片按钮的事件
    public void actionPerformed(ActionEvent e) {
        CLayout.next(cards);  // 显示下一张卡片
    }

    public static void main(String args[]) {
        CardLayoutWindow window = new CardLayoutWindow();
        window.setTitle("CardWindow Application");
        window.pack();
        window.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        window.setVisible(true);
    }
}
```

### 8.7 GridBagLayout

**特点**：不需要组件的尺寸一致，容许组件扩展到多行、多列。功能最灵活也最复杂。

### 8.8 BoxLayout

**特点**：将组件垂直摆放在一列或水平摆放在一行中。Swing新增。

### 8.9 如何选择布局管理器

| 场景 | 推荐布局 |
|------|----------|
| 组件以自然大小紧凑地在一行中显示 | **FlowLayout** |
| 组件大小相同，并且成行或成列显示 | **GridLayout** |
| 组件尽量充满容器空间 | **BorderLayout** 或 **GridBagLayout** |

## 十、AWT事件处理模型

### 10.1 事件处理模型概述

当用户在界面上利用鼠标或键盘进行操作时，监测GUI的操作系统将所发生的事件传送给GUI应用程序，应用程序根据事件的类型作出相应的反应。

**基于Swing的GUI中，仍然采用AWT的事件处理模型**。

### 10.2 事件处理中的3类对象

| 对象 | 说明 |
|------|------|
| **事件（Event）** | 描述所发生事件的对象。Java中有很多不同类型的事件类，用来描述不同类型的用户动作（如按下键盘、拖动或单击鼠标） |
| **事件源（Event Source）** | 产生事件的组件。例如当在一个Button上单击鼠标时产生ActionEvent，这个Button就是事件源 |
| **事件处理器（Event Handler）** | 一个接收事件对象并处理用户交互的方法 |

### 10.3 委托模型（Delegation Model / 监听器模型）

```
  Frame
    └── Panel
          └── Button ──单击──→ ActionEvent
                                  │
                    ┌─────────────┴─────────────┐
                    ▼                           ▼
              监听器1（事件处理器）          监听器2（事件处理器）
         actionPerformed(ActionEvent e)  actionPerformed(ActionEvent e)
```

**核心机制**：
- 需要响应用户操作的组件事先已经注册一个或多个包含事件处理器的对象，称为**监听器（Listener）**
- 每类事件有一个相应的**监听器接口**，定义了接收事件的方法
- 实现该接口的类，其对象可作为监听器注册
- 当界面操作事件产生并被发送到产生事件的组件时，该组件将把事件发送给能接收和处理该事件的监听器
- **事件对象只向已注册的监听器报告**

### 10.4 委托方式事件处理的实现步骤

**步骤1**：在事件处理类的声明中指定要实现的监听器接口，并实现该接口中的所有方法：
```java
public class MyClass implements ActionListener {
    public void actionPerformed(ActionEvent e) {
        // ...响应某个动作的代码...
    }
}
```

**步骤2**：在一个或多个组件上将监听器类的实例注册为监听器：
```java
someComponent.addActionListener(new MyClass());
```

### 10.5 完整事件处理示例

```java
import java.awt.*;
import java.awt.event.*;
import javax.swing.*;

public class TestButton {
    public static void main(String args[]) {
        JFrame f = new JFrame("Test");
        f.setSize(200, 100);
        f.setLayout(new FlowLayout(FlowLayout.CENTER));
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        JButton b = new JButton("Press Me!");
        b.addActionListener(new ButtonHandler());  // 注册监听器
        f.add(b);
        f.setVisible(true);
    }
}

// 定义ActionEvent监听器类
class ButtonHandler implements ActionListener {
    public void actionPerformed(ActionEvent e) {
        System.out.println("Action occurred");
        System.out.println("Button's label is:" + e.getActionCommand());
    }
}
```

## 十一、事件分类与监听器接口

### 11.1 AWT事件类层次

```
java.util.EventObject
  └── java.awt.AWTEvent
        ├── ActionEvent          （动作事件）
        ├── AdjustmentEvent      （调整事件）
        ├── ComponentEvent       （组件事件）
        │     ├── FocusEvent     （聚焦事件）
        │     ├── InputEvent     （输入事件）
        │     │     ├── KeyEvent （键盘事件）
        │     │     └── MouseEvent（鼠标事件）
        │     └── WindowEvent    （窗口事件）
        ├── ItemEvent            （条目事件）
        └── TextEvent            （文本事件）
```

### 11.2 事件接口与方法目录

| 监听器接口 | 适配器类 | 方法 |
|-----------|----------|------|
| **ActionListener** | （无） | `actionPerformed` |
| **AdjustmentListener** | （无） | `adjustmentValueChanged` |
| **ComponentListener** | ComponentAdapter | `componentHidden`, `componentMoved`, `componentResized`, `componentShown` |
| **ContainerListener** | ContainerAdapter | `componentAdded`, `componentRemoved` |
| **FocusListener** | FocusAdapter | `focusGained`, `focusLost` |
| **ItemListener** | （无） | `itemStateChanged` |
| **KeyListener** | KeyAdapter | `keyPressed`, `keyReleased`, `keyTyped` |
| **MouseListener** | MouseAdapter | `mouseClicked`, `mouseEntered`, `mouseExited`, `mousePressed`, `mouseReleased` |
| **MouseMotionListener** | MouseMotionAdapter | `mouseDragged`, `mouseMoved` |
| **TextListener** | （无） | `textValueChanged` |
| **WindowListener** | WindowAdapter | `windowActivated`, `windowClosed`, `windowClosing`, `windowDeactivated`, `windowDeiconified`, `windowIconified`, `windowOpened` |

### 11.3 多监听器

- 可以使用一个监听器处理多个组件可能产生的**多种事件**（实现多个接口）：
```java
public class ComplexListener implements
        MouseMotionListener, MouseListener, ActionListener {
    // ...
}
```
- 可以在一个组件上注册**多个监听器**，多个监听器可以监听同一个事件
- 根据需要多次调用 `addXXXListener()` 方法注册多个监听器

**示例——带有两个监听器的Frame**：
```java
public class TwoListener implements MouseMotionListener, MouseListener {
    JFrame f;
    JTextField tf;

    public void go() {
        f = new JFrame("Two Listener");
        tf = new JTextField(30);
        f.add(tf, "BorderLayout.SOUTH");
        f.addMouseMotionListener(this);
        f.addMouseListener(this);
        // ...
    }

    // MouseMotionListener events
    public void mouseDragged(MouseEvent e) { /* ... */ }
    public void mouseMoved(MouseEvent e)   { /* ... */ }

    // MouseListener events
    public void mouseEntered(MouseEvent e) {
        String s = "The mouse entered";
        tf.setText(s);
    }
    public void mouseClicked(MouseEvent e)  { /* ... */ }
    public void mouseReleased(MouseEvent e) { /* ... */ }
    // ...
}
```

## 十二、事件适配器（Adapter）

### 12.1 适配器的概念

- Adapter类实现了相应Listener接口，但**所有方法体都是空的**
- 用户可以把监听器类声明为Adapter类的子类，便可以**只重写需要的方法**，而不必实现接口中的所有方法

**示例**：
```java
public class MouseClickHandler extends MouseAdapter {
    public void mouseClicked(MouseEvent e) {
        // 只重写需要的方法
    }
}
```

**限制**：用户定义的监听器类只能继承一个适配器类，并且一旦从适配器继承就**不能再继承其它类**（Java单继承）。

### 12.2 使用内部类进行事件处理

既使用Adapter类，又避免多重继承的限制：在一个类中定义**内部类**，由内部类继承相应Adapter类。

**示例**：
```java
public class MyApplet extends Applet {
    // ...
    someObject.addMouseListener(new MyAdapter());

    class MyAdapter extends MouseAdapter {
        public void mouseClicked(MouseEvent e) {
            // ...Event handler implementation goes here...
        }
    }
}
```

### 12.3 使用匿名类进行事件处理

**匿名类（Anonymous Class）** 是没有名字的内部类，可以使用匿名类进行事件处理。

**示例**：
```java
public class MyApplet extends Applet {
    // ...
    someObject.addMouseListener(new MouseAdapter() {
        public void mouseClicked(MouseEvent e) {
            // ...Event handler implementation goes here...
        }
    });
}
```

## 十四、本章小结

本章系统介绍了Java图形化用户界面（GUI）编程，涵盖以下核心知识点：

1. **Java基础类库（JFC）**：包含AWT、Java 2D、Accessibility、Drag & Drop、Swing五个部分，Swing是重点

2. **AWT**：抽象窗口工具集，定义平台独立的组件API，通过平台特定的对等组件（Peers）实现各平台L&F

3. **Swing**：全部用Java实现的轻量级组件，具有分离模型、可设置L&F、比AWT更丰富的组件（JTable、JTree等）

4. **GUI设计步骤**：引入包 → 选择L&F → 创建顶层容器 → 添加Swing组件 → 显示 → 增加事件处理

5. **容器层次**：顶层容器（JFrame）→ 中间层容器（JPanel）→ 基本组件，通过add()方法组装

6. **布局管理器**：
   - FlowLayout：从左到右逐行（Panel默认）
   - BorderLayout：5个方向分区（Frame/Window默认）
   - GridLayout：均匀网格
   - CardLayout：卡片叠放，一次显示一张
   - GridBagLayout：灵活网格，组件可跨行跨列
   - BoxLayout：垂直或水平排列

7. **AWT事件处理模型**：委托模型/监听器模型——事件源产生事件，已注册的监听器接收并处理事件

8. **事件体系**：ActionEvent、ComponentEvent（含FocusEvent/InputEvent/KeyEvent/MouseEvent/WindowEvent）、ItemEvent等

9. **监听器接口与适配器**：实现Listener接口（需实现所有方法）vs 继承Adapter类（只重写需要的方法，但受单继承限制）

10. **内部类与匿名类**：用于事件处理，内部类继承Adapter避免多重继承限制；匿名类写法更简洁

11. **Swing组件**：顶层容器、通用容器、特殊容器、基本控制、不可编辑显示、可编辑显示六大类，涵盖JButton/JTextField/JTable/JTree/JFileChooser等
