# 信号处理与信号产生电路核心知识点总结

## 1. 滤波电路的基本概念与分类

### 1.1 基本概念
- **滤波器**：使有用频率信号通过而抑制或衰减无用频率信号的电子装置
- **有源滤波器**：由有源器件和相关元件构成的滤波器
- **传递函数**：$A(s) = \frac{V_o(s)}{V_i(s)}$
- **频率响应**：$A(j\omega) = |A(j\omega)|\angle\varphi(\omega)$
  - $|A(j\omega)|$：幅频响应
  - $\varphi(\omega)$：相位角，相频响应
- **群时延响应**：$\tau(\omega) = -\frac{d\varphi(\omega)}{d\omega}$

### 1.2 分类
- **低通(LPF)**：允许低频信号通过
- **高通(HPF)**：允许高频信号通过
- **带通(BPF)**：允许某一频段信号通过
- **带阻(BRF)**：阻止某一频段信号通过
- **全通(APF)**：所有频率信号都通过，只改变相位

### 1.3 频率响应逼近方式
- **巴特沃斯**：通带内幅频响应最大限度平坦
- **切比雪夫**：通带内有等波纹，阻带单调
- **反切比雪夫**：通带内平坦，阻带内有波纹
- **椭圆函数**：通带和阻带内都有波纹，过渡带最陡
- **贝塞尔**：具有线性相位特性

### 1.4 实际滤波电路参数
- **通带纹波**($\gamma_{max}$)：通带内最大波动
- **通带截止角频率**($\omega_p$)：通带边界频率
- **阻带截止角频率**($\omega_s$)：阻带边界频率
- **阻带最小衰减量**($\gamma_{min}$)：阻带内最小衰减
- **频率选择性因子**($\omega_s/\omega_p$)：反映过渡带陡峭程度

## 2. 一阶有源滤波电路

### 2.1 一阶低通滤波电路
- **传递函数**：$A(s) = \frac{A_0}{1+s/\omega_c}$
- **幅频响应**：$|A(j\omega)| = \frac{A_0}{\sqrt{1+(\omega/\omega_c)^2}}$
- **特征角频率**：$\omega_c = \frac{1}{RC}$
- **电压增益**：$A_0 = 1 + \frac{R_f}{R_1}$

### 2.2 一阶高通滤波电路
- 电路结构：将低通电路中的电容和电阻对换
- **传递函数**：$A(s) = \frac{A_0(s/\omega_c)}{1+s/\omega_c}$
- **幅频响应**：$|A(j\omega)| = \frac{A_0(\omega/\omega_c)}{\sqrt{1+(\omega/\omega_c)^2}}$

### 2.3 有源滤波器优缺点
- **优点**：
  - 不用电感，体积小、重量轻
  - 有一定电压放大和缓冲作用
- **缺点**：
  - 工作频率难以做得很高
  - 不适宜大功率场合

## 3. 高阶有源滤波电路

### 3.1 二阶压控电压源型低通滤波电路
- **传递函数**：$A(s) = \frac{A_0}{1+\frac{s}{Q\omega_c}+(\frac{s}{\omega_c})^2}$
- **通带增益**：$A_0 = A_{vf}$
- **特征角频率**：$\omega_c = \frac{1}{RC}$
- **等效品质因数**：$Q = \frac{1}{3-A_{vf}}$
- **稳定性条件**：$A_{vf} < 3$
- **巴特沃斯条件**：$Q = 0.707$，通带内幅频响应最大限度平坦

### 3.2 二阶无限增益多路反馈型低通滤波电路
- **通带增益**：$A_0 = -\frac{R_f}{R_1}$
- **特征角频率**：$\omega_c = \frac{1}{\sqrt{C_1C_2R_fR_1R_2}}$
- **等效品质因数**：$Q = \sqrt{\frac{C_1}{C_2}} \times \frac{R_1//R_2//R_f}{R_2//R_f}$

### 3.3 二阶压控电压源型高通滤波电路
- **传递函数**：$A(s) = \frac{A_0(s/\omega_c)^2}{1+\frac{s}{Q\omega_c}+(\frac{s}{\omega_c})^2}$
- **特征角频率**：$\omega_c = \frac{1}{RC}$
- **等效品质因数**：$Q = \frac{1}{3-A_{vf}}$
- **通带增益**：$A_0 = 1 + \frac{R_f}{R_1}$

### 3.4 二阶压控电压源型带通滤波电路
- **传递函数**：$A(s) = \frac{\frac{A_0s}{Q\omega_0}}{s^2+\frac{s\omega_0}{Q}+\omega_0^2}$
- **中心频率**：$\omega_0 = \frac{1}{RC}$
- **通带增益**：$A_0 = \frac{A_{vf}}{3-A_{vf}}$
- **等效品质因数**：$Q = \frac{1}{3-A_{vf}}$
- **截止角频率**：
  - 低频截止：$\omega_L = \omega_0\left(\sqrt{1+\frac{1}{4Q^2}}-\frac{1}{2Q}\right)$
  - 高频截止：$\omega_H = \omega_0\left(\sqrt{1+\frac{1}{4Q^2}}+\frac{1}{2Q}\right)$
- **带宽**：$BW = \frac{f_0}{Q}$

### 3.5 高阶滤波电路
- **n阶巴特沃斯低通**：$|A(j\omega)| = \frac{A_0}{\sqrt{1+(\omega/\omega_c)^{2n}}}$
- 通过级联二阶或一阶有源滤波电路构成
- 通常借助模拟滤波器软件设计工具完成

## 4. 正弦波振荡电路

### 4.1 振荡条件
- **振幅平衡条件**：$|A(j\omega)F(j\omega)| = 1$
- **相位平衡条件**：$\varphi_a(\omega) + \varphi_f(\omega) = 2n\pi$
- **起振条件**：
  - 振幅：$|A(j\omega)F(j\omega)| > 1$
  - 相位：$\varphi_a(\omega) + \varphi_f(\omega) = 2n\pi$

### 4.2 振荡电路基本组成
- 放大电路（含负反馈放大电路）
- 反馈网络（构成正反馈）
- 选频网络（选择满足相位平衡条件的频率）
- 稳幅环节

## 5. RC正弦波振荡电路

### 5.1 RC桥式振荡电路
- **RC串并联选频网络反馈系数**：
  $F(j\omega) = \frac{1}{3+j(\omega/\omega_0-\omega_0/\omega)}$
- **当** $\omega = \omega_0 = \frac{1}{RC}$ **时**：
  - $|F(j\omega)|_{max} = \frac{1}{3}$
  - $\varphi_f = 0$
- **振幅平衡条件**：$A_v = 1 + \frac{R_f}{R_1} = 3$
- **振荡频率**：$f_0 = \frac{1}{2\pi RC}$

### 5.2 RC移相式正弦波振荡电路
- **振荡条件**：
  - $\omega_0 = \frac{1}{\sqrt{6}RC}$
  - $A_v = -29$

### 5.3 稳幅措施
- **热敏电阻**：利用温度特性自动调整增益
- **场效应管(JFET)**：利用可变电阻区特性
- **二极管**：利用其非线性特性

## 6. 非正弦信号产生电路

### 6.1 电压比较器

#### 6.1.1 单门限电压比较器
- **工作特点**：开环状态，极高增益
- **输出特性**：
  - $v_I > V_{REF}$ 时，$v_O = V_{OH}$
  - $v_I < V_{REF}$ 时，$v_O = V_{OL}$

#### 6.1.2 迟滞比较器(施密特触发器)
- **反相输入**：
  - 上门限：$V_{T+} = \frac{R_2V_{OH}+R_1V_{REF}}{R_1+R_2}$
  - 下门限：$V_{T-} = \frac{R_2V_{OL}+R_1V_{REF}}{R_1+R_2}$
  - 回差电压：$\Delta V_T = \frac{R_2}{R_1+R_2}(V_{OH}-V_{OL})$
- **同相输入**：
  - $V_{T+} = V_Z\frac{R_2}{R_1}$
  - $V_{T-} = -V_Z\frac{R_2}{R_1}$

### 6.2 方波产生电路
- **振荡周期**：$T = 2R_fC_1\ln(1+\frac{2R_2}{R_1})$
- **工作原理**：利用RC充放电和迟滞比较器的特性
- **电路组成**：迟滞比较器 + RC充放电支路 + 稳压管限幅

### 6.3 锯齿波产生电路
- **振荡周期**：$T = T_1 + T_2$
  - $T_1 = \frac{2R_6C}{R_2+R_6}$
  - $T_2 = \frac{2(R_5+R_6)R_6C}{R_2(R_5+2R_6)}$
- **特点**：充放电时间常数不同，形成非对称波形

## 核心公式总结

| 电路类型 | 核心公式 | 说明 |
|---------|---------|------|
| 一阶低通 | $\omega_c = \frac{1}{RC}$ | 特征角频率 |
| 二阶低通 | $Q = \frac{1}{3-A_{vf}}$ | 品质因数 |
| 二阶带通 | $BW = \frac{f_0}{Q}$ | 带宽 |
| RC振荡 | $f_0 = \frac{1}{2\pi RC}$ | 振荡频率 |
| 迟滞比较器 | $\Delta V_T = \frac{R_2}{R_1+R_2}(V_{OH}-V_{OL})$ | 回差电压 |
| 方波电路 | $T = 2R_fC_1\ln(1+\frac{2R_2}{R_1})$ | 振荡周期 |

## 电路特点对比

| 电路类型 | 优点 | 缺点 | 典型应用 |
|---------|------|------|----------|
| 一阶有源滤波 | 电路简单，易于实现 | 衰减率低(20dB/十倍频) | 简单滤波需求 |
| 二阶压控电压源 | 增益可调，设计灵活 | 增益受Q值限制 | 音频处理 |
| 二阶多路反馈 | Q值不受增益限制 | 增益为负值 | 信号处理 |
| RC桥式振荡 | 波形好，频率稳定 | 频率受限(<1MHz) | 音频信号源 |
| 迟滞比较器 | 抗干扰能力强 | 有回差，精度稍低 | 噪声环境检测 |

## 设计要点

1. **滤波电路设计**：
   - 根据性能要求选择逼近方式
   - 考虑运放带宽和压摆率限制
   - 注意元件精度和温度稳定性

2. **振荡电路设计**：
   - 保证起振条件 $|AF| > 1$
   - 精确设计选频网络
   - 合理设计稳幅环节

3. **比较器设计**：
   - 根据抗干扰需求选择单门限或迟滞
   - 考虑响应速度和噪声容限
   - 适当添加限幅保护

# 直流电源电路核心知识点总结

## 1. 直流电源基本构成与分类

### 1.1 基本构成
从交流电网到直流稳压电源的转换过程包括四个基本环节：
- **变压器**：降压、隔离
- **整流电路**：交流→脉动直流
- **滤波电路**：滤除脉动
- **稳压电路**：进一步消除纹波，提高电压稳定性和带载能力

### 1.2 电源类型
- **线性电源**：调整管工作在线性放大区，效率较低但纹波小
- **开关电源**：调整管工作在开关状态，效率高(75%-95%)，体积小，重量轻

## 2. 小功率整流滤波电路

### 2.1 单相桥式整流电路
- **工作原理**：利用二极管的单向导电性
- **负载输出电压平均值**：$V_L = 0.9V_2 \approx \frac{2\sqrt{2}}{\pi}V_2$
- **平均整流电流**：$I_D = \frac{1}{2}I_L$
- **最大反向电压**：$V_{RM} = \sqrt{2}V_2$
- **纹波系数**：$\gamma = \frac{V_{L2}-V_{L1}}{V_L} = 0.483$

### 2.2 电容滤波电路
- **特点**：
  - 二极管导电角θ < π，瞬时电流大
  - 变压器二次绕组电流：$I_2 = (1.5 \sim 2)I_L$
  - 二极管整流电流：$I_D = (2 \sim 3)I_L$
  - 负载直流平均电压随RLC增大而升高
- **输出电压**：
  - 当$τ_d \geq (3 \sim 5)\frac{T}{2}$时，$V_L = (1.1 \sim 1.2)V_2$
- **纹波电压**：$V_{\gamma} = \frac{1}{2}V_2 \cdot \frac{T}{2R_LC} = \frac{V_2}{2R_LCf}$

### 2.3 电感滤波电路
- **特点**：
  - 整流二极管导电角增大，无峰值电流
  - 输出特性平滑
- **缺点**：
  - 体积大，笨重
  - 易引起电磁干扰
- **适用场景**：小电压、大电流场合

## 3. 线性稳压电路

### 3.1 线性串联反馈式稳压电路
- **稳压原理**：电压串联负反馈
- **输出电压固定型**：$V_O = (1 + \frac{R_1}{R_2})V_{REF}$
- **输出电压可调型**：
  - $V_O = V_{REF}(1 + \frac{R_2}{R_1}) + I_{adj}R_2$
  - 当$I_{adj} \ll I_1$时，$V_O \approx V_{REF}(1 + \frac{R_2}{R_1})$

### 3.2 低压差稳压电路(LDO)
- **特点**：
  - 输入输出压差可很小
  - MOSFET工作在可变电阻区时负反馈依然有效
  - 低电压情况下效率更高
- **应用示例**：当VO = 2.5V时，VI可低至3.3V甚至更低

### 3.3 线性集成稳压器
- **固定输出型**：
  - 78XX系列：正电压稳压器
  - 79XX系列：负电压稳压器
- **可调输出型**：
  - LM317：正电压可调
  - LM337：负电压可调
- **LDO系列**：
  - TPS79901：输出电压$V_O = [(R_1 + R_2)/R_2] \times 1.193$，范围1.2~6.4V
  - 固定输出型：TPS79915(1.5V)、TPS79918(1.8V)、TPS79925(2.5V)、TPS79933(3.3V)

## 4. 开关稳压电路

### 4.1 开关稳压电路特点
- **优点**：
  - 效率高(75%~95%)
  - 体积小，重量轻
  - 稳压范围宽
- **缺点**：
  - 控制电路复杂
  - 输出电压纹波较大

### 4.2 无变压器开关稳压电路

#### 4.2.1 基本拓扑结构
- **串联型(降压/Buck型)**：
  - $V_O = q \cdot V_I$，其中$q = \frac{t_{on}}{T}$为占空比
  - $V_O < V_I$，调整管与负载串联
  
- **并联型(升压/Boost型)**：
  - $V_O = \frac{V_I}{1-q}$
  - $V_O > V_I$，调整管与负载并联
  
- **极性反转型**：
  - $V_O = -\frac{q}{1-q} \times V_I$
  - 输出电压极性与输入相反

#### 4.2.2 稳压原理
- 通过脉宽调制(PWM)控制占空比
- 反馈控制使$v_F$趋近于$V_{REF}$，稳定输出电压：
  $V_O = (1 + \frac{R_1}{R_2})V_{REF}$

#### 4.2.3 集成开关稳压器
- **LM2596系列**：
  - LM2596-5.0：固定5V输出，输入范围+7.0V~+40V
  - LM2596-ADJ：输出可调，$V_O = 1.23(1 + \frac{R_1}{R_2})$
  
- **TPS564201**：
  - 5V输出，$V_O = 0.76 \times (1 + \frac{R_1}{R_2})$
  - 集成MOSFET，替代外部续流二极管

- **MAX764**：极性反转型DC/DC变换器

### 4.3 带变压器开关稳压电路

#### 4.3.1 反激式开关电源
- **工作原理**：
  - T1导通时：变压器N1储能
  - T1截止时：能量通过N2传递到负载
- **输出电压公式**：
  $V_O = \frac{N_{sec}}{N_{pri}} \cdot \frac{q}{1-q} \cdot V_I$

#### 4.3.2 集成控制器
- 含开关管的集成控制器(如TOPSwitch系列)
- 实现高低压电路隔离
- 内置保护功能(过压、过流、过热保护)

## 核心公式汇总

| 电路类型 | 公式 | 说明 |
|---------|------|------|
| 桥式整流 | $V_L = 0.9V_2$ | 负载输出电压平均值 |
| 电容滤波 | $V_L = (1.1 \sim 1.2)V_2$ | 大容量滤波电容时 |
| 纹波系数 | $V_{\gamma} = \frac{V_2}{2R_LCf}$ | 电容滤波输出纹波 |
| 串联稳压 | $V_O = (1 + \frac{R_1}{R_2})V_{REF}$ | 固定/可调输出电压 |
| Buck变换器 | $V_O = q \cdot V_I$ | 降压型开关电源 |
| Boost变换器 | $V_O = \frac{V_I}{1-q}$ | 升压型开关电源 |
| 反激式电源 | $V_O = \frac{N_{sec}}{N_{pri}} \cdot \frac{q}{1-q} \cdot V_I$ | 带变压器开关电源 |

## 选型与设计要点

1. **线性稳压 vs 开关稳压**：
   - 小功率、低噪声要求→线性稳压
   - 高效率、大功率→开关稳压

2. **LDO应用场景**：
   - 低电压差场合
   - 电池供电设备
   - 噪声敏感电路

3. **开关电源设计考虑**：
   - 电感/电容参数选择
   - 开关频率与效率平衡
   - 电磁兼容性(EMC)设计
   - 热设计与散热

4. **保护电路设计**：
   - 过压保护
   - 过流保护
   - 过热保护
   - 反接保护
