# 第8章 反馈放大电路 - 知识点总结

## 8.1 反馈的基本概念与分类

### 8.1.1 反馈的基本概念
- **反馈定义**：将放大电路输出量（电压或电流）的一部分或全部，通过反馈网络送回到输入回路的过程
- **关键参数**：
  - 开环增益：$A = \frac{x_o}{x_{id}}$
  - 反馈系数：$F = \frac{x_f}{x_o}$
  - 闭环增益：$A_f = \frac{x_o}{x_i}$
- **开环 vs 闭环**：
  - 开环：无反馈通路
  - 闭环：有反馈通路

### 8.1.2 直流反馈与交流反馈
- **直流反馈**：稳定静态工作点
- **交流反馈**：改善动态性能
- **判别方法**：根据反馈信号中包含直流还是交流成分

### 8.1.3 正反馈与负反馈
- **正反馈**：使净输入量增大的反馈
- **负反馈**：使净输入量减小的反馈
- **判别方法**：瞬时极性法
  1. 从输入端开始，沿信号流向标注节点电压变化的极性
  2. 了解基本放大电路的相位关系（共射、共基、共集等）
  3. 确定净输入量的变化情况

### 8.1.4 串联反馈与并联反馈
- **串联反馈**：
  - 输入以电压形式求和（KVL）：$v_{id} = v_i - v_f$
  - 反馈量和输入量接于不同输入端
- **并联反馈**：
  - 输入以电流形式求和（KCL）：$i_{id} = i_i - i_f$
  - 反馈量和输入量接于同一输入端

### 8.1.5 电压反馈与电流反馈
- **电压反馈**：反馈信号与输出电压成比例，$x_f = Fv_o$
- **电流反馈**：反馈信号与输出电流成比例，$x_f = Fi_o$
- **判别方法**：负载短路法
  - 负载短路后反馈量为零：电压反馈
  - 负载短路后反馈量仍存在：电流反馈

### 8.1.6 负反馈放大电路的四种组态

| 组态 | 输入连接 | 输出取样 | 功能 | 特点 |
|------|----------|----------|------|------|
| 电压串联 | 串联 | 电压 | 电压放大器 | 电压控制的电压源(VCVS) |
| 电压并联 | 并联 | 电压 | 互阻放大器 | 电流控制的电压源(CCVS) |
| 电流串联 | 串联 | 电流 | 互导放大器 | 电压控制的电流源(VCCS) |
| 电流并联 | 并联 | 电流 | 电流放大器 | 电流控制的电流源(CCCS) |

## 8.2 负反馈放大电路增益的一般表达式

- **闭环增益表达式**：
  $$A_f = \frac{A}{1+AF}$$
  
- **关键概念**：
  - **反馈深度**：$1+AF$
  - **环路增益**：$AF$
  
- **深度负反馈条件**：$|1+AF| \gg 1$
  $$A_f \approx \frac{1}{F}$$
  
- **自激振荡条件**：$1+AF = 0$，即
  - 幅值条件：$|AF| = 1$
  - 相位条件：$\angle AF = \pm 180^\circ$（产生$-180^\circ$附加相移）

## 8.3 负反馈对放大电路性能的影响

### 8.3.1 提高增益的稳定性
- **闭环增益相对变化量**：
  $$\frac{dA_f}{A_f} = \frac{1}{1+AF} \cdot \frac{dA}{A}$$
- 闭环增益相对变化量比开环减小了$(1+AF)$倍

### 8.3.2 减小反馈环内非线性失真
- 负反馈可减小放大电路内部产生的非线性失真

### 8.3.3 抑制反馈环内噪声
- 信噪比提高：$\left(\frac{S}{N}\right)_{os} = A^2 \cdot \left(\frac{S}{N}\right)_{on}$

### 8.3.4 对输入电阻和输出电阻的影响

**1. 输入电阻变化**
- **串联负反馈**：
  $$R_{if} = (1+AF)R_i$$
  （输入电阻增大）
  
- **并联负反馈**：
  $$R_{if} = \frac{R_i}{1+AF}$$
  （输入电阻减小）

**2. 输出电阻变化**
- **电压负反馈**：
  $$R_{of} = \frac{R_o}{1+AF}$$
  （输出电阻减小，稳定输出电压）
  
- **电流负反馈**：
  $$R_{of} = (1+AF)R_o$$
  （输出电阻增大，稳定输出电流）

### 8.3.5 扩展带宽

**1. 闭环增益带宽**
- **闭环上限频率**：
  $$f_{Hf} = (1+A_MF)f_H$$
  
- **闭环下限频率**：
  $$f_{Lf} = \frac{f_L}{1+A_MF}$$
  
- **通频带**：
  $$BW_f = f_{Hf} - f_{Lf} \approx f_{Hf}$$

**2. 增益-带宽积**
- **开环增益-带宽积**：$|A_M| \cdot f_H$
- **闭环增益-带宽积**：$|A_{Mf}| \cdot f_{Hf} = |A_M| \cdot f_H$
- 增益-带宽积为常数（对标准运放）

## 8.4 深度负反馈条件下的近似计算

### 8.4.1 深度负反馈的特点
- **闭环增益**：$A_f \approx \frac{1}{F}$
- **净输入量近似为零**：$x_{id} = x_i - x_f \approx 0$
- **"两虚"概念**：
  - **虚短**：$v_{id} \approx 0$
  - **虚断**：$i_{id} \approx 0$

### 8.4.2 近似计算带来的误差
- **相对误差**：
  $$E_r = \frac{1}{|1+AF|} \times 100\% = \frac{1}{G} \times 100\%$$
- 其中$G = |AF|$为环路增益，环路增益越大，误差越小

## 8.6 负反馈放大电路的稳定性

### 8.6.1 自激振荡及稳定工作条件

**1. 自激振荡条件**
- **幅值条件**：$|A(j\omega_k)F(j\omega_k)| = 1$
- **相位条件**：$\Delta\phi_a(\omega_k) + \Delta\phi_f(\omega_k) = \pm(2k+1)180^\circ$

**2. 稳定工作条件**
- **相位裕度**：$\varphi_m = 180^\circ - |\Delta\phi_a + \Delta\phi_f| \geq 45^\circ$
- **幅值裕度**：$G_m = -20\lg|AF| \geq 10dB$

**3. 稳定性分析（波特图法）**
- 作出$A$的幅频和相频响应波特图
- 画出$20\lg\frac{1}{|F|}$水平线
- 两线交点对应的相位应满足相位裕度$\geq 45^\circ$

### 8.6.2 频率补偿

**1. 一般性频率补偿思路**
- 确保0分贝水平线上增益$A$的衰减斜率只有$-20dB/$十倍频

**2. 电容滞后补偿**
- 在放大级间加入补偿电容$C$
- 降低上限频率，使高频衰减斜率变为$-20dB/$十倍频

**3. 密勒效应补偿**
- 利用密勒电容效应，将小电容等效为大电容
- 典型应用：集成运放741内部加入补偿电容$C_c$

## 重要设计原则总结

| 目标 | 应采用的反馈类型 |
|------|----------------|
| 稳定直流量 | 直流负反馈 |
| 稳定交流量 | 交流负反馈 |
| 稳定输出电压 | 电压负反馈 |
| 稳定输出电流 | 电流负反馈 |
| 增大输入电阻 | 串联负反馈 |
| 减小输入电阻 | 并联负反馈 |
| 增大输出电阻 | 电流负反馈 |
| 减小输出电阻 | 电压负反馈 |
| 电压→电流转换 | 电流串联负反馈 |
| 电流→电压转换 | 电压并联负反馈 |
| 电压→电压转换 | 电压串联负反馈 |
| 电流→电流转换 | 电流并联负反馈 |
| 电压信号源效果更好 | 串联负反馈 |
| 电流信号源效果更好 | 并联负反馈 |

## 关键公式总结

1. **闭环增益**：$A_f = \frac{A}{1+AF}$

2. **深度负反馈近似**：$A_f \approx \frac{1}{F}$

3. **反馈对输入电阻的影响**：
   - 串联反馈：$R_{if} = (1+AF)R_i$
   - 并联反馈：$R_{if} = \frac{R_i}{1+AF}$

4. **反馈对输出电阻的影响**：
   - 电压反馈：$R_{of} = \frac{R_o}{1+AF}$
   - 电流反馈：$R_{of} = (1+AF)R_o$

5. **带宽扩展**：
   - $f_{Hf} = (1+A_MF)f_H$
   - $f_{Lf} = \frac{f_L}{1+A_MF}$

6. **稳定性条件**：
   - 相位裕度：$\varphi_m \geq 45^\circ$
   - 幅值裕度：$G_m \geq 10dB$
