# 负反馈放大电路题目详解

## 题目1详解

### (1) 判断级间反馈的组态和极性
**瞬时极性分析：**
- 假设输入信号 $v_i$ 在T1基极为"+"极性
- T1为共射放大电路，产生180°相移，T1集电极(T2基极)为"-"极性
- T2为共射放大电路，又产生180°相移，T2集电极(T3基极)为"+"极性
- T3为射极跟随器(共集电路)，相移为0°，T3射极(输出端)为"+"极性
- 反馈信号从输出端经 $R_{f3}$、$R_{f1}$ 反馈到T1射极，T1射极为"+"极性
- 净输入信号 $v_{id} = v_{be1} = v_{b1} - v_{e1}$，由于 $v_{e1}$ 与 $v_{b1}$ 同为"+"极性且增大，$v_{be1}$ 减小，因此是**负反馈**

**组态判断：**
- **输入端**：反馈信号与输入信号在不同节点(T1射极与基极)，属于**串联反馈**
- **输出端**：反馈网络与输出端(射极)并联，反馈信号与输出电压成正比，属于**电压反馈**

**结论**：**电压串联负反馈**

### (2) 反馈作用分析
- 电压负反馈：**稳定输出电压**
- 串联负反馈：**增大输入电阻**
- 电路模型：**电压控制的电压源(VCVS)**，即电压放大器

### (3) 深度负反馈计算
在深度负反馈条件下，满足"虚短"条件：$v_{b1} \approx v_{e1}$

**反馈系数计算：**
反馈网络由 $R_{f1}$ 和 $R_{f3}$ 组成分压器
$$F_v = \frac{v_f}{v_o} = \frac{R_{f1}}{R_{f1} + R_{f3}}$$

**闭环电压增益：**
$$A_{vf} = \frac{v_o}{v_i} \approx \frac{1}{F_v} = 1 + \frac{R_{f3}}{R_{f1}}$$

**闭环增益：**
由于是电压串联负反馈，闭环增益即为闭环电压增益：
$$A_f = A_{vf} = 1 + \frac{R_{f3}}{R_{f1}}$$

## 题目2详解

### (1) 判断级间反馈的组态和极性
**瞬时极性分析：**
- 假设输入信号 $v_i$ 加在运放同相端(+)为"+"极性
- 运放同相放大，输出 $v_o$ 为"+"极性
- 反馈网络将输出信号经 $R_3$、$R_2$ 反馈到运放反相端(-)
- 由于是反相输入端，反馈信号与输入信号相减，净输入减小，因此是**负反馈**

**组态判断：**
- **输入端**：输入信号在同相端，反馈信号在反相端，属于**串联反馈**
- **输出端**：反馈信号与输出电压成正比，属于**电压反馈**

**结论**：**电压串联负反馈**（同相比例放大器）

### (2) 反馈作用分析
- 电压负反馈：**稳定输出电压**
- 串联负反馈：**增大输入电阻**
- 电路模型：**电压控制的电压源(VCVS)**，即电压放大器

### (3) 深度负反馈计算
在深度负反馈条件下，满足"虚短"和"虚断"：
- $v_+ = v_-$
- $i_+ = i_- = 0$

**反馈系数计算：**
反馈网络由 $R_2$ 和 $R_3$ 组成分压器
$$F_v = \frac{v_f}{v_o} = \frac{v_-}{v_o} = \frac{R_2}{R_2 + R_3}$$

**闭环电压增益：**
$$A_{vf} = \frac{v_o}{v_i} = \frac{v_o}{v_+} = \frac{v_o}{v_-} = 1 + \frac{R_3}{R_2}$$

**闭环增益：**
$$A_f = A_{vf} = 1 + \frac{R_3}{R_2}$$

## 题目3详解

### (1) 判断级间反馈的组态和极性
**瞬时极性分析：**
- 假设输入信号 $v_s$ 在T1基极为"+"极性
- T1为共射放大，T1集电极(T2基极)为"-"极性
- T2为共集放大(射极跟随)，T2发射极(T3基极)为"-"极性
- T3为共射放大，T3集电极为"+"极性
- T3的射极跟随器输出 $v_o$ 为"+"极性
- 反馈信号从输出端经 $R_f$ 反馈到T1发射极，T1射极为"+"极性
- 净输入 $v_{be1} = v_{b1} - v_{e1}$ 减小，因此是**负反馈**

**组态判断：**
- **输入端**：反馈信号与输入信号在不同节点(T1射极与基极)，属于**串联反馈**
- **输出端**：反馈信号与输出电压成正比，属于**电压反馈**

**结论**：**电压串联负反馈**

### (2) 反馈作用分析
- 电压负反馈：**稳定输出电压**
- 串联负反馈：**增大输入电阻**
- 电路模型：**电压控制的电压源(VCVS)**，即电压放大器

### (3) 深度负反馈计算
**反馈网络：**
```
      +Vcc
       |
      Rc1     Rc3   Rc4
       |       |     |
       T1      T3    |
       |       |     |
      Re1--Rf-+     RL
       |       |     |
      Rs      Re4    |
       |       |     |
      GND     GND   vo
```

在深度负反馈条件下：
- 虚短：$v_{b1} \approx v_{e1}$
- 虚断：$i_b \approx 0$

**反馈系数计算：**
反馈网络由 $R_f$ 和 $R_{e1}$ 组成分压器
$$F_v = \frac{v_f}{v_o} = \frac{R_{e1}}{R_{e1} + R_f}$$

**闭环电压增益：**
$$A_{vf} = \frac{v_o}{v_s} \approx \frac{1}{F_v} = 1 + \frac{R_f}{R_{e1}}$$

**考虑源电阻 $R_s$ 的影响：**
由于串联负反馈，输入电阻很高，$v_i \approx v_s$
$$A_{vf} = \frac{v_o}{v_s} \approx 1 + \frac{R_f}{R_{e1}}$$

**闭环增益：**
$$A_f = A_{vf} = 1 + \frac{R_f}{R_{e1}}$$

## 题目4详解

### (1) 判断级间反馈的组态和极性
**瞬时极性分析：**
- 假设输入信号在T1基极为"+"极性
- T1为共射放大，T1集电极(T2基极)为"-"极性
- T2为共射放大，T2集电极(T3基极)为"+"极性
- T3为共基放大，T3集电极(输出)为"+"极性
- 反馈信号从输出端经 $R_f$ 反馈到T2发射极
- 由于T2是共射电路，发射极信号与基极信号同相，T2发射极为"-"极性
- 净输入 $v_{be2} = v_{b2} - v_{e2}$，$v_{e2}$ 为"-"极性，$v_{be2}$ 增大，这是正反馈？需要重新分析

**重新分析(更准确)：**
实际上，该电路是典型的**电流串联负反馈**结构：
- 反馈电阻 $R_{e2}$ 串联在T2发射极
- 反馈信号 $v_f = i_e \cdot R_{e2}$ 与输出电流成正比
- 当输出电流增大时，$v_f$ 增大，使净输入 $v_{be2}$ 减小，因此是负反馈

**组态判断：**
- **输入端**：反馈信号在T2发射极，输入信号在T1基极，通过各级耦合，实质是**串联反馈**
- **输出端**：反馈信号与输出电流(通过 $R_{e2}$)成正比，属于**电流反馈**

**结论**：**电流串联负反馈**

### (2) 反馈作用分析
- 电流负反馈：**稳定输出电流**
- 串联负反馈：**增大输入电阻**
- 电路模型：**电压控制的电流源(VCCS)**，即互导放大器

### (3) 深度负反馈计算
**反馈网络：**
```
      +Vcc
       |
      Rc1    Re2    Rc3
       |      |      |
       T1     T2     T3
       |      |      |
      Re1----+------Re4
       |             |
      GND           vo
```

在深度负反馈条件下：
- $v_{be2} \approx 0$，即T2基极电压≈发射极电压
- $i_b \approx 0$

**反馈系数计算：**
反馈信号 $v_f = i_e \cdot R_{e2} \approx i_o \cdot R_{e2}$ (因为 $i_e \approx i_o$)
$$F_g = \frac{v_f}{i_o} = R_{e2}$$

**闭环互导增益：**
$$A_{gf} = \frac{i_o}{v_i} \approx \frac{1}{F_g} = \frac{1}{R_{e2}}$$

**闭环电压增益：**
考虑到输出负载 $R_L$：
$$A_{vf} = \frac{v_o}{v_i} = \frac{i_o \cdot R_L}{v_i} = A_{gf} \cdot R_L = \frac{R_L}{R_{e2}}$$

**闭环增益：**
$$A_f = A_{vf} = \frac{R_L}{R_{e2}}$$

## 总结与要点

1. **反馈组态判断方法**：
   - 用瞬时极性法判断正/负反馈
   - 串联/并联反馈：看反馈信号与输入信号的连接方式
   - 电压/电流反馈：用负载短路法或看取样方式

2. **深度负反馈计算原则**：
   - 串联负反馈：$v_{id} \approx 0$ (虚短)
   - 并联负反馈：$i_{id} \approx 0$ (虚断)
   - 闭环增益 $\approx \frac{1}{F}$

3. **四种反馈组态特点**：
   | 组态 | 输入连接 | 输出取样 | 稳定对象 | 电路模型 |
   |------|----------|----------|----------|----------|
   | 电压串联 | 串联 | 电压 | 输出电压 | VCVS(电压放大器) |
   | 电压并联 | 并联 | 电压 | 输出电压 | CCVS(互阻放大器) |
   | 电流串联 | 串联 | 电流 | 输出电流 | VCCS(互导放大器) |
   | 电流并联 | 并联 | 电流 | 输出电流 | CCCS(电流放大器) |

4. **反馈对电路性能的影响**：
   - 电压负反馈：减小输出电阻，稳定输出电压
   - 电流负反馈：增大输出电阻，稳定输出电流
   - 串联负反馈：增大输入电阻
   - 并联负反馈：减小输入电阻

这些题目涵盖了负反馈放大电路的核心知识点，掌握反馈组态判断和深度负反馈计算是解决此类问题的关键。
