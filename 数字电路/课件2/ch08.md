# 可编程逻辑器件(PLD)核心知识点汇总

## 1. 组合可编程逻辑器件(PLD)

### 1.1 PLD基本概念
- **定义**：可由用户定义和设置逻辑功能的器件
- **特点**：逻辑功能实现灵活、集成度高、处理速度快、可靠性高

### 1.2 PLD基本结构
- **核心组成**：
  - 与门阵列
  - 或门阵列
  - 输入电路
  - 输出电路
  - 反馈输入信号

### 1.3 PLD表示方法
- **连接方式**：
  - 硬线连接单元
  - 被编程接通单元
  - 被编程擦除单元
- **编程连接技术**：熔丝工艺

### 1.4 PLD分类
- **按集成密度**：
  - 低密度(LDPLD)：PROM、PLA、PAL、GAL
  - 高密度(HDPLD)：CPLD、FPGA
- **按与/或阵列编程特性**：
  - 与阵列、或阵列均可编程(PLA)
  - 与阵列固定，或阵列可编程(PROM)
  - 与阵列可编程，或阵列固定(PAL、GAL)

## 2. 时序可编程逻辑器件(GAL)

### 2.1 GAL基本概念
- **定义**：通用阵列逻辑，在PLA和PAL基础上发展的增强型器件
- **特点**：通过编程宏单元实现不同模式，输出功能具有灵活性

### 2.2 GAL与PAL比较
- **PAL缺点**：
  - 双极型熔丝工艺，编程后不可修改
  - 输出结构类型过多，设计使用不便
- **GAL优点**：
  - 采用E²CMOS工艺，可多次编程
  - 输出端设可编程OLMC，实现PAL所有输出模式
  - 工作速度快，功耗小

### 2.3 GAL结构(GAL16V8为例)
- **核心组件**：
  - 可编程与阵列(32×64位)
  - 8个输入缓冲器
  - 8个输出逻辑宏单元(OLMC)
  - 8个三态输出缓冲器
  - 8个反馈/输入缓冲器
  - 输出使能缓冲器

### 2.4 OLMC(输出逻辑宏单元)
- **组成**：
  - 乘积项数据选择器(2选1)
  - 原变量/非变量控制(异或门)
  - 输出数据选择器(2选1)
  - 三态数据选择器(4选1)
  - 反馈数据选择器(4选1)
- **功能配置**：
  - 组合电路模式
  - 同步时序电路模式
  - 不同三态控制方式

### 2.5 GAL控制字
- **GAL16V8**：82位控制字
- **关键控制单元**：
  - AC0(全局控制)
  - AC1(n)(每个OLMC)
  - XOR(n)(每个OLMC)
  - SYN(同步控制)

## 3. CPLD和FPGA

### 3.1 CPLD结构
- **三大核心**：
  - 逻辑块(相当于多个GAL)
  - 可编程内部连线
  - I/O单元
- **逻辑块组成**：
  - 可编程乘积项阵列
  - 乘积项分配网络
  - 宏单元
- **I/O单元**：可编程为输入、输出、双向功能

### 3.2 FPGA基本原理
- **核心单元**：查找表(LUT)
- **LUT特性**：
  - 2输入LUT可实现任意2变量组合逻辑函数
  - 现代FPGA常用4-5输入LUT
  - 多LUT组合实现复杂函数
- **时序电路**：在LUT基础上增加触发器

### 3.3 FPGA结构
- **三大组件**：
  - 可编程逻辑块(CLB)
  - 可编程互联开关
  - I/O块
- **互连结构**：
  - 纵向连线
  - 横向连线
  - 互联开关矩阵

### 3.4 CPLD与FPGA区别
| 特性 | CPLD | FPGA |
|------|------|------|
| **内部结构** | Product-term | Look-up Table |
| **程序存储** | 内部EEPROM | SRAM+外挂EEPROM |
| **资源类型** | 组合电路资源丰富 | 触发器资源丰富 |
| **集成度** | 低 | 高 |
| **使用场合** | 控制逻辑 | 复杂算法 |
| **速度** | 快 | 慢 |
| **布线方式** | 连续式布线 | 非连续式布线 |
| **保密性** | 可加密 | 一般不能保密 |

### 3.5 PLD开发流程
1. 逻辑电路设计
2. 设计输入(原理图/HDL)
3. 逻辑综合
4. 功能仿真
5. 适配
6. 定时仿真
7. 编程(下载)
8. 编程数据装载(FPGA)

### 3.6 编程条件
- 微机
- CPLD/FPGA编程软件
- 专用编程电缆

## 4. 关键技术要点
- **PLD实现**：组合逻辑通过PLA/PAL实现，时序逻辑通过增加触发器和反馈实现
- **GAL通用性**：一片GAL可实现PAL的5种输出工作模式
- **FPGA配置**：基于SRAM，断电后逻辑消失，需外部存储器保存配置
- **CPLD优势**：连续式互连结构提供固定延时通路，延时较小
- **OLMC配置**：通过AC0、AC1、XOR控制字实现不同输出模式
