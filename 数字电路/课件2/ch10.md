### 10 模数与数模转换器（Analog Digital Converter and Digital Analog Converter）

#### 教学基本要求
- 掌握倒T形电阻网络D/A转换器（DAC）、集成D/A转换器的工作原理及相关计算，包括电路结构、电流计算、输出电压公式、精度讨论和应用示例。
- 掌握并行比较、逐次比较、双积分A/D转换器（ADC）的工作原理及其特点，包括详细转换过程、电路图、量化方式、误差分析和技术指标。
- 正确理解D/A、A/D转换器的主要参数，包括分辨率、转换精度、转换时间、输出方式等，并能进行相关计算。

#### 概述
- 将温度、压力、流量、应力等物理量转换为模拟电量，经A/D转换器转为数字量，由计算机进行数字处理（如计算、滤波）、保存等，再经D/A转换器转为模拟量作为控制信号。模拟传感器 → A/D转换器 → 数字控制计算机 → D/A转换器 → 模拟控制器 → 工业生产过程控制对象。
- ADC和DAC已成为计算机系统中不可缺少的接口电路，在模拟电路、模数混合电路和数字电路之间提供接口。
- A/D功能：能将模拟电压成正比地转换成对应的数字量。数字量与转换后的模拟量之间存在误差。
- A/D转换器分类：
  - ① 并行比较型：特点：转换速度快，转换时间10ns ~ 1µs，但电路复杂，需要2^n - 1个比较器（n位）。
  - ② 逐次比较型：特点：转换速度适中，转换时间几µs ~ 100 µs，转换精度高，在转换速度和硬件复杂度之间达到很好的平衡。
  - ③ 双积分型：特点：转换速度慢，转换时间几百µs ~ 几ms，但抗干扰能力最强，能平均噪声。

#### 10.1 D/A转换器

##### 10.1.1 D/A转换器的输入/输出特性及结构框图
- D/A转换器输入/输出特性：将数字量转换为与之成正比的模拟量，A = KD ⇒ v_o = -K N_B，其中N_B为二进制数字量。
- 数字量与转换后的模拟量之间存在误差。
- 结构框图：DAC的数字数据可以并行输入也可串行输入，包括数字输入、参考电压、模拟输出。

##### 10.1.2 D/A转换器的基本原理
- 实现D/A转换的基本思想：将二进制数N_D = (11001)_B转换为十进制数，N_D = b_4 × 2^4 + b_3 × 2^3 + b_2 × 2^2 + b_1 × 2^1 + b_0 × 2^0 = 1×16 + 1×8 + 0×4 + 0×2 + 1×1 = 25。数字量是用代码按数位组合而成，对于有权码，每位代码都有一定的权值，如能将每一位代码按其权的大小转换成相应的模拟量，然后将这些模拟量相加，即可得到与数字量成正比的模拟量，从而实现D/A转换。
- 实现D/A转换的原理电路：使用开关和电阻网络，i_0 = V_REF D_0 / R, i_1 = 2 V_REF D_1 / R, i_2 = 4 V_REF D_2 / R, i_3 = 8 V_REF D_3 / R, v_0 = -R_f (i_3 + i_2 + i_1 + i_0) = -V_REF (D_3 2^3 + D_2 2^2 + D_1 2^1 + D_0 2^0) = -V_REF ∑_{i=0}^{3} D_i · 2^i。
- D/A转换器的分类：
  - 按解码网络结构分类：T型电阻网络DAC、倒T形电阻网络DAC、权电流DAC、权电阻网络DAC。
  - 按模拟电子开关电路分类：CMOS开关型DAC、双极型开关型DAC、电流开关型DAC、ECL电流开关型DAC。

##### 10.1.3 倒T形电阻网络D/A转换器
- 4位倒T形电阻网络D/A转换器：电路包括基准电压V_REF、开关S3-S0、电阻网络（R和2R组合）、求和运算放大器。根据运放线性增益恒等曲线概念，无论模拟开关S处于何种位置，导线相连的环电阻将均衡，地电流或通地。
- 流过各开关支路的电流：I_3 = V_REF / 2R, I_2 = V_REF / 4R, I_1 = V_REF / 8R, I_0 = V_REF / 16R，总电流 I = V_REF / R。流入每个2R电阻的电流从高位到低位按2的整数倍递减。
- 流入运放的总电流 i_Σ = I_0 + I_1 + I_2 + I_3 = (V_REF / R) (D_0 / 2^4 + D_1 / 2^3 + D_2 / 2^2 + D_3 / 2^1)。
- 输出模拟电压 v_o = -i_Σ R_f = - (R_f / R) · (V_REF / 2^4) ∑_{i=0}^{3} (D_i · 2^i)。
- n位倒T形电阻网络DAC通用公式：v_o = - (V_REF / 2^n) · (R_f / R) [∑_{i=0}^{n-1} (D_i · 2^i)]，令 K = (V_REF / 2^n) · (R_f / R), N_B = ∑ (D_i · 2^i), 则 v_o = -K N_B。在电路中输入的每一个二进制数N_B，均能得到与之成正比的模拟电压输出。
- 集成D/A转换器示例：AD7533（10位CMOS电流开关型D/A转换器），使用需：1) 外接运放；2) 运放的反馈电阻可使用内部电阻，也可采用外接电阻。输出 v_O = - (V_REF / 2^{10}) · (R_f / R) [∑_{i=0}^{9} (D_i · 2^i)]。
- 关于D/A转换器精度的讨论：为提高精度，对电路参数的要求：(1) 基准电压稳定性好；(2) 倒T形电阻网络中R和2R电阻比值的精度要高；(3) 每个模拟开关的开关电压降要相等；(4) 为实现电流从高位到低位按2的整数倍递减，模拟开关的导通电阻也相应地按2的整数倍递增。为进一步提高精度，可采用权电流型D/A转换器。

##### 10.1.4 权电流型D/A转换器
- 4位权电流D/A转换器：D_i=1时，开关S_i接运放的反相端；D_i=0时，开关S_i接地。在恒流源电路中，各支路权电流的大小均不受开关导通电阻和压降的影响，这样降低了对开关电路的要求，提高了转换精度。
- 实际的权电流D/A转换器电路：基线电流产生电路，各BJT的发射结电压相等，电压恒定，v_o = i_Σ R_f = (R_f V_REF / 2^4 R_1) (D_3 · 2^3 + D_2 · 2^2 + D_1 · 2^1 + D_0 · 2^0)。

##### *10.1.5 权电容网络D/A转换器
- 权电容网络D/A转换器：使用电容代替电阻，实现权值分配，适用于需要高精度和低功耗的场合（可选内容，未详细展开）。

##### 10.1.6 D/A转换器的输出方式
- 8位D/A转换器在单极性输出时的输入/输出关系：从00000000 (0 V_REF) 到11111111 (±V_REF (255/256))。
- 双极性输出：使用2的补码或偏移二进制码。表示例：
  - 十进制127：2的补码 01111111, 偏移二进制 11111111, 模拟量 +127 V_LSB。
  - 十进制0：2的补码 00000000, 偏移二进制 10000000, 模拟量 0。
  - 十进制-128：2的补码 10000000, 偏移二进制 00000000, 模拟量 -128 V_LSB。
- V_LSB = V_REF / 256。
- 输出计算示例：v_O = -v_1 - (1/2) V_REF = (N_B V_REF / 2^8 + V_REF / 2) - V_REF / 2 = V_REF · (N_B / 256)。

##### 10.1.7 D/A转换器的技术指标
- 分辨率：其定义为D/A转换器模拟输出电压可能被分离的等级数。n位DAC最多有2^n个模拟输出电压。位数越多分辨率越高。分辨率也可以用能分辨的最小输出电压与最大输出电压之比给出，n位D/A转换器的分辨率表示为 1/(2^n - 1)。
- 转换精度：是指对给定的数字量，D/A转换器实际值与理论值之间的最大偏差。产生原因：由于D/A转换器中各元件参数值存在误差，如基准电压不够稳定或运算放大器的零漂等各种因素的影响。几种转换误差：比例系数误差、失调误差和非线性误差等。

##### 10.1.8 D/A转换器的应用
- 脉冲波产生电路：使用74163（具同步清零功能）和与非门构成十进制计数器（0000~1001），结合D/A转换器产生脉冲波。
- 由D/A转换器、计数器和ROM组成的波形产生电路：分析电路；分析计数器；查ROM确定D/A转换器输入；计算对应输出电压；画出波形。对应CP波形，画出输出V0的波形，并标出相应的电压值。
- ROM数据表：A3 A2 A1 A0 对应 D9 D8 D7 D6 值，用于生成特定波形。

#### 10.2 A/D转换器

##### 10.2.1 A/D转换的一般工作过程
- A/D转换器一般要包括采样、保持、量化及编码4个过程。
- 1. 采样：采样信号S(t)的频率愈高，所采得信号经低通滤波器后愈能真实地复现输入信号。合理的采样频率由采样定理确定。
- 2. 保持：采得模拟信号转换为数字信号都需要一定时间，为了给后续的量化编码过程提供一个稳定的值，在取样电路后要求将所采样的模拟信号保持一段时间。
- 3. 量化：采样-保持电路的输出电压还需按某种近似方式归化到与之相应的离散电平上的过程。
  - 量化单位：量化过程中所取最小数量单位。用Δ表示。它是数字信号最低位为1时所对应的模拟量，即1LSB。
  - 量化误差：在量化过程中由于所采样电压不一定能被Δ整除，所以量化前后一定存在误差，用ε表示。
  - 量化方式：两种近似量化方式——只舍不入和四舍五入。
  - a. 只舍不入量化方式: 把不足一个量化单位的部分舍弃; 对于等于或大于一个量化单位部分按一个量化单位处理。
    - 示例：将0~1V电压转换为3位二进制代码，Δ=1LSB=1/8 V。
      - 表：输入1V → 量化7Δ=7/8 V → 编码111；输入7/8 V → 6Δ=6/8 V → 110；... 输入1/8 V → 1Δ=1/8 V → 001；输入0 → 0 → 000。
      - 最大量化误差 |ε_max| = 1LSB = 1/8 V。
    - D/A转换器的输出特性：数字量与转换后的模拟量之间存在误差，呈阶梯状。
  - b. 四舍五入量化方式: 将不足半个量化单位部分舍弃, 对于等于或大于半个量化单位部分按一个量化单位处理。
    - 示例：最小量化单位 Δ=1LSB=2/15 V。
      - 表：输入13/15 V → 7Δ=14/15 V → 111；输入11/15 V → 6Δ=12/15 V → 110；... 输入1/15 V → 1Δ=2/15 V → 001；输入0 → 0 → 000。
      - 最大量化误差 |ε_max| = 1/15 V = LSB/2。
- 4. 编码：量化后的数值最后还需通过编码过程用一个代码表示出来。经编码后得到的代码就是A/D转换器输出的数字量。

##### 10.2.2 并行比较型A/D转换器
- 电路组成：精密参考电压、精密电阻网络、比较器组、D触发器组、优先编码器。
- 工作原理：输入模拟电压U_1同时与各参考电压比较（参考电压由电阻网络分压产生），比较器输出状态由D触发器存储，经优先编码器编码得到数字量。编码器输入低电平有效，I7优先级最高。
- 示例：3位ADC，U_1范围对应比较器输出和编码：
  - 0 ≤ U_1 ≤ V_REF/15 (0Δ) → 所有C=0 → 000。
  - V_REF/15 ≤ U_1 ≤ 3V_REF/15 (1Δ) → C07=1，其他0 → 001。
  - ... 
  - 13V_REF/15 ≤ U_1 ≤ V_REF (7Δ) → 所有C=1 → 111。
- 电路特点：
  - 转换时间最短（<50ns，不考虑延迟可认为同时获得）。
  - 缺点：电路复杂（3位需7比较器、7触发器、8电阻；n位需2^n-1比较器）。
  - 若U_1 > V_REF，饱和输出不变，不能正常转换。

##### 10.2.3 逐次比较型A/D转换器
- 转换原理：类似于天平称重，逐次试加权值（数字）转模拟电压与输入比较，直到相等。
- 电路：采样保持、逐次逼近寄存器（SAR）、D/A转换器、比较器、时钟。
- 转换过程：起始SAR MSB=1，其他0，转DA得V_DA与U_i比；若V_DA > U_i，下位=0保留上位；反之下位=1；逐位到LSB。
- 示例：称重W_x=13g，使用8g,4g,2g,1g砝码：
  - 第一步：加8g <13g，保留。
  - 第二步：加4g (总12g)<13g，保留。
  - 第三步：加2g (总14g)>13g，撤除。
  - 第四步：加1g (总13g)=13g，保留。
- 4位逐次比较过程表（假设输入U_i=13/16 V_REF）：
  - CP1：D3=1, V_DA=8/16 V_REF < U_i, 保留D3=1。
  - CP2：D2=1, V_DA=12/16 V_REF < U_i, 保留D2=1。
  - CP3：D1=1, V_DA=14/16 V_REF > U_i, 置D1=0。
  - CP4：D0=1, V_DA=13/16 V_REF = U_i, 保留D0=1。输出1101。
- 小结：位数多精度高；转换时间10~50μs，与n和时钟频率有关，位少频高时间短。

##### 10.2.4 双积分式A/D转换器
- 原理：对输入信号正向积分固定时间，然后对参考电压反向积分并计时，时间比例对应数字量。
- 特点：转换慢（10ms~1000ms），但抗干扰强，能平均噪声。

##### 10.2.5 A/D转换器的主要技术指标
- 1. 转换精度：用分辨率（输出位数n，位多精度高）和转换误差（实际与理论差）描述。
- 2. 转换时间：从控制信号到稳定输出时间；并行<50ns，逐次10~50μs，间接10ms~1000ms。

##### 10.2.6 集成A/D转换器及其应用
- 示例：AD7533 D/A（10位CMOS），输出 v_o = - (V_REF / 2^{10}) (R_f / R) ∑ (D_i 2^i)。
- 使用注意：
  - (1) 转换过程信号时序配合。
  - (2) 零点和满刻度调节。
  - (3) 参考电压调节。
  - (4) 接地（模拟地AGND、数字地DGND分开，仅一点连接，避免干扰）。
- 应用：跳码产生电路，使用74163和与非门构成计数器，结合D/A产生跳码波形，从0000→1001。
