### **1. 答案与解析**
**答案：** **175.75**

**解析：**
题目要求将无符号十六进制数 $(AF.C)_{16}$ 转换为十进制数。按照位权展开法计算：
*   整数部分 $AF$：$A$ 代表 10，$F$ 代表 15。
    $10 \times 16^1 + 15 \times 16^0 = 160 + 15 = 175$
*   小数部分 $0.C$：$C$ 代表 12。
    $12 \times 16^{-1} = 12 / 16 = 0.75$
*   合并：$175 + 0.75 = 175.75$

### **2. 答案与解析**
**答案：** **111011**

**解析：**
1.  **BCD 转十进制/二进制：**
    8421BCD 码 $(0100\ 0101)$ 对应的十进制数是 45（$0100=4, 0101=5$）。
    将 45 转换为 6 位二进制数：$45 = 32 + 8 + 4 + 1 = 101101_2$。
2.  **二进制转格雷码：**
    设二进制码为 $B_5B_4B_3B_2B_1B_0 = 101101$。
    格雷码 $G_n$ 的计算规则是保留最高位，其余位 $G_i = B_i \oplus B_{i+1}$。
    *   $G_5 = B_5 = 1$
    *   $G_4 = B_5 \oplus B_4 = 1 \oplus 0 = 1$
    *   $G_3 = B_4 \oplus B_3 = 0 \oplus 1 = 1$
    *   $G_2 = B_3 \oplus B_2 = 1 \oplus 1 = 0$
    *   $G_1 = B_2 \oplus B_1 = 1 \oplus 0 = 1$
    *   $G_0 = B_1 \oplus B_0 = 0 \oplus 1 = 1$
    结果为 **111011**。

### **3. 答案与解析**
**答案：** **$B + AC + AD$** (或 $AC+AD+B$)

**解析：**
1.  **根据对偶式 $L'$ 求原函数 $L$：**
    已知 $L' = \overline{AB} \cdot (\overline{BC} + \overline{D})$。
    为了方便应用对偶规则（Dual），先将非标准的“非”项展开（注：对偶规则通常针对与/或运算，变量取反保持不变，但对整体取反的项需先处理）：
    $L' = (\bar{A} + \bar{B}) \cdot (\bar{B} + \bar{C} + \bar{D})$
    应用对偶规则（将 $\cdot$ 换成 $+$，将 $+$ 换成 $\cdot$）得到 $L$：
    $L = (\bar{A} \cdot \bar{B}) + (\bar{B} \cdot \bar{C} \cdot \bar{D}) = \bar{A}\bar{B} + \bar{B}\bar{C}\bar{D}$
    提取公因式 $\bar{B}$：
    $L = \bar{B}(\bar{A} + \bar{C}\bar{D})$
2.  **计算 $L \odot 0$：**
    同或运算 $X \odot 0$ 等价于求非 $\bar{X}$。
    因此我们需要求 $\bar{L}$：
    $\bar{L} = \overline{\bar{B}(\bar{A} + \bar{C}\bar{D})} = B + \overline{(\bar{A} + \bar{C}\bar{D})}$
    利用摩根定律：
    $\bar{L} = B + (A \cdot \overline{\bar{C}\bar{D}}) = B + A(C + D) = B + AC + AD$

### **4. 答案与解析**
**答案：** **$0, 2, 3, 7$**

**解析：**
1.  **分析电路：**
    这是一个 3-8 线译码器（类似 74LS138），输出为低电平有效（即输出为最小项的非，例如 $Y_1 = \overline{m_1}$）。
    输入 $A_2 A_1 A_0$ 对应 $A B C$，连接到与非门（NAND）的输出端子为 $Y_1, Y_4, Y_5, Y_6$。
2.  **推导表达式：**
    输出门是一个与非门：$F = \overline{Y_1 \cdot Y_4 \cdot Y_5 \cdot Y_6}$。
    代入译码器输出特性：$F = \overline{\overline{m_1} \cdot \overline{m_4} \cdot \overline{m_5} \cdot \overline{m_6}}$。
    利用摩根定律：$F = m_1 + m_4 + m_5 + m_6$。
    这表示 $F$ 为最小项之和形式：$F = \sum m(1, 4, 5, 6)$。
3.  **转换为最大项：**
    最大项 $\prod M$ 对应的是函数为 0 的输入组合。
    全集为 $0 \sim 7$，函数包含 $1, 4, 5, 6$，则剩余的为 $0, 2, 3, 7$。
    所以 $F = \prod M(0, 2, 3, 7)$。

### **5. 答案与解析**
**答案：** **$7\text{ns}$**

**解析：**
传输延迟时间 $T_{pd}$ 通常定义为导通延迟 $t_{PHL}$ 和截止延迟 $t_{PLH}$ 的平均值。
从波形图中读取数据：
*   输入上升沿导致输出下降沿的延迟（$t_{PHL}$）标注为 **8ns**。
*   输入下降沿导致输出上升沿的延迟（$t_{PLH}$）标注为 **6ns**。
计算平均值：
$T_{pd} = \frac{t_{PHL} + t_{PLH}}{2} = \frac{8\text{ns} + 6\text{ns}}{2} = 7\text{ns}$。

### **6. 答案与解析**
**答案：** **1** （或 **高电平**）

**解析：**
这是一个 CMOS 与非门（NAND）。
*   **输入 B：** 电压为 $0.4V$。已知 $V_{IL(\max)} = 0.8V$，因为 $0.4V < 0.8V$，所以输入 B 被逻辑门判定为逻辑 **0**。
*   **输入 A：** 电压为 $1.65V$。处于 $0.8V \sim 2.0V$ 之间，属于逻辑电平不确定区域。
*   **逻辑判断：** 对于与非门（$Y = \overline{A \cdot B}$），只要有一个输入为逻辑 **0**，输出就被强制为逻辑 **1**（高电平），无论另一个输入是什么状态（即使是不确定状态）。
    从电路结构上看，输入 B 为低电平会使得对应的 NMOS 截止，对应的 PMOS 导通，从而直接将输出拉高到 VDD。

### **7. 答案与解析**
**答案：** **同或门** （或 **XNOR**）

**解析：**
根据波形图列出真值表：
*   $T_1$: $A=0, B=0 \rightarrow F=1$
*   $T_2$: $A=1, B=0 \rightarrow F=0$
*   $T_3$: $A=1, B=1 \rightarrow F=1$
*   $T_4$: $A=0, B=1 \rightarrow F=0$

可以看出逻辑关系为：当输入相同（00或11）时输出为1，输入不同时输出为0。
这是**同或**逻辑（Exclusive-NOR）。

### **8. 答案与解析**
**答案：** **`L = (~EN) ? A : 1'bz;`**

**解析：**
*   **电路符号识别：** 图中符号是一个三态缓冲器（Tri-state buffer）。控制端（EN）接入位置有一个小圆圈，表示**低电平有效**。
*   **功能描述：**
    *   当 $EN = 0$（低电平）时，缓冲器导通，输出 $L = A$。
    *   当 $EN = 1$（高电平）时，缓冲器输出高阻态（High-Z）。
*   **Verilog HDL 表达：**
    使用条件运算符 `? :` 来描述三态门。
    条件是“使能有效”，即 `~EN`（或 `!EN`）。
    `assign L = (条件) ? 导通值 : 高阻态;`
    即：`assign L = (~EN) ? A : 1'bz;`
    (注：`1'bz` 代表 1 位的高阻态)。

### **9. 答案与解析**
**答案：** **$XXXX0111$** （或 $11110111$）

**解析：**
1.  **分析编码器特性：**
    *   这是一个 8-3 线优先编码器。
    *   输入是**低电平有效**（即输入为 0 表示有效，1 表示无效）。
    *   $D_0$（LSB）具有**最高优先级**，这意味着优先级顺序为 $D_0 > D_1 > D_2 > \dots > D_7$。
    *   输出为原码，即直接输出对应输入下标的二进制码。
2.  **分析输出结果：**
    *   输出 $Y_2Y_1Y_0 = 011$。对应的十进制数是 3。
    *   这说明编码器响应的是下标为 3 的输入端，即 $D_3$。
3.  **推导输入状态：**
    *   为了使编码器响应 $D_3$，比 $D_3$ 优先级更高的输入端必须处于**无效**状态。
    *   比 $D_3$ 优先级高的端口是 $D_0, D_1, D_2$。因为是低电平有效，所以它们必须为高电平（1）。即 $D_0=1, D_1=1, D_2=1$。
    *   目标端口 $D_3$ 必须处于**有效**状态，即低电平（0）。即 $D_3=0$。
    *   比 $D_3$ 优先级低的端口（$D_4, D_5, D_6, D_7$）的状态不影响输出结果，可以是任意值（Don't Care，记为 X）。
4.  **组合输入值：**
    *   输入信号 $D_7D_6D_5D_4D_3D_2D_1D_0$ 的取值为：$XXXX0111$。
    *   （注：如果题目要求给出确定的数值，通常将无关项 X 视为无效电平 1，则为 $11110111$）。

### **10. 答案与解析**
**答案：** **竞争** （或 **传输延迟**）

**解析：**
*   **现象描述：** 在数字逻辑电路中，由于信号经由不同的路径传输，到达汇合点（如门电路输入端）的时间有先有后，这种现象称为**竞争**（Competition）。
*   **后果：** 竞争可能导致电路输出端出现瞬间的错误脉冲（毛刺），这种现象称为**冒险**（Hazard）。
*   **填空分析：** 题目问的是出现冒险现象的主要原因。根本原因是电路中存在**信号传输延迟时间不同**（或简称为**竞争**）。通常填“竞争”或“传输延迟”。

### **11. 答案与解析**
**答案：** **3**

**解析：**
*   在二进制运算中，将一个数左移 1 位相当于乘以 2。
*   题目要求将数值放大 8 倍。
*   因为 $8 = 2^3$，所以需要将二进制数向左移动 3 位。
*   每个移位时钟脉冲对应移位 1 次，因此需要 **3** 个移位时钟脉冲。

### **12. 答案与解析**
**答案：** **2**

**解析：**
1.  **确定计数规则：**
    *   模 7 减法计数器（Down Counter）。
    *   模值为 7，意味着计数值在 7 个状态中循环（通常为 $6, 5, 4, 3, 2, 1, 0$）。
    *   减法计数：每来一个脉冲，计数值减 1。
2.  **计算有效脉冲数：**
    *   总脉冲数 $N = 2022$。
    *   计算 $2022$ 对模 $7$ 的余数：$2022 \div 7 = 288 \dots 6$。
    *   这意味着经过 288 个完整循环后，还多走了 6 步。
3.  **计算最终值：**
    *   初始值为 1。
    *   减去 6 步：
        *   $1 \xrightarrow{-1} 0$
        *   $0 \xrightarrow{-1} 6$
        *   $6 \xrightarrow{-1} 5$
        *   $5 \xrightarrow{-1} 4$
        *   $4 \xrightarrow{-1} 3$
        *   $3 \xrightarrow{-1} 2$
    *   或者使用同余运算公式：
        $\text{当前值} = (\text{初始值} - \text{脉冲数}) \pmod 7$
        $= (1 - 6) \pmod 7 = -5 \pmod 7$
        $= 2$ （因为 $-5 + 7 = 2$）
    *   结果为 **2**。

### **13. 答案与解析**
**答案：** **13**

**解析：**
1.  **计算单片 DRAM 的地址总数：**
    *   DRAM 芯片规格为 $4M \times 4\text{bit}$。
    *   存储单元数量为 $4M = 4 \times 1024 \times 1024 = 2^2 \times 2^{20} = 2^{22}$。
    *   这意味着需要 **22 位** 地址线来寻址所有的存储单元。
2.  **行列地址分配：**
    *   DRAM 采用地址复用技术，总地址位 = 行地址位 + 列地址位。
    *   已知列地址有 9 位。
    *   则行地址位数 = 总地址位 - 列地址位 = $22 - 9 = 13$。
3.  **扩展后的影响：**
    *   用 4 片构建 $4M \times 16\text{bit}$ 的存储空间，这是**位扩展**。
    *   位扩展不改变地址线的数量（深度不变，宽度增加），因此行地址位数仍然是基于 $4M$ 深度计算得出的 13 位。

### **14. 答案与解析**
**答案：** **施密特触发器** （或 **Schmitt Trigger**）

**解析：**
*   题目描述了一个电路用于将“易畸变的周期性波形整形成为较为理想的矩形波”。
*   这是**施密特触发器**的典型应用。施密特触发器具有滞回特性（Hysteresis），能够有效地抗干扰，并将边缘缓慢变化的信号（如正弦波、三角波或受干扰的波形）转换为边沿陡峭的矩形波（脉冲波）。

### **15. 答案与解析**
**答案：** **1400**

**解析：**
1.  **理解线性 D/A 关系：**
    *   题目指出是单极性线性 D/A。即输出电压 $V_{out}$ 与输入的数字量 $D$ 成正比：$V_{out} = k \times D$。
2.  **计算比例系数或直接比例换算：**
    *   **校准点：** $V_1 = 0.5\text{V}$ 对应数字量 $D_1 = 0\text{xFA}$。
    *   将十六进制 $0\text{xFA}$ 转换为十进制：
        $F \times 16 + A = 15 \times 16 + 10 = 240 + 10 = 250$。
    *   即 $0.5\text{V} \leftrightarrow 250$。
3.  **计算目标值：**
    *   目标电压 $V_2 = 2.8\text{V}$。
    *   设对应的数字量为 $x$。
    *   根据比例关系：$\frac{x}{250} = \frac{2.8\text{V}}{0.5\text{V}}$。
    *   $x = 250 \times \frac{2.8}{0.5} = 250 \times 5.6$。
    *   计算：$250 \times 5 = 1250$，$250 \times 0.6 = 150$。
    *   $1250 + 150 = 1400$。
    *   所以对应的数字量为 **1400**。
