## 知识点详解

### 知识点 1：定时/计数器的计数应用

**定义**：计数是指8253/8254对CLK端输入的外部脉冲进行减1计数，每来一个脉冲计数值减1；记录脉冲个数，进而测量频率、位移、速度、流量等物理量。

**理解**：计数功能的构成要素有三个：计数初值（写入计数通道的起始数值）、CLK端的外部脉冲序列（每个脉冲使计数值减1）、计数值的读取（CPU通过输入指令获得当前数值）。脉冲个数等于初值与当前计数值之差。外部事件（工件通过、齿轮转过、流量计输出）先由传感器转换为电脉冲，脉冲个数乘以每个脉冲对应的物理量单位（例如每个脉冲对应1个工件），就得到被测物理量。频率测量是计数的直接应用形式：在固定的门控时间内对输入脉冲计数，计数值除以门控时间即为输入频率。

**作用**：8253三大基本应用（计数、定时、PWM）之一，与定时应用共用同一计数机制，两者只是输入脉冲的来源不同（定时用已知频率的时钟，计数用外部事件产生的脉冲）。是7.2.2节流水线产品计数系统的核心基础，与"输出锁存器/软件锁存""方式0中断联动"两个知识点构成前后衔接关系。

### 知识点 2：定时/计数器的定时应用

**定义**：定时是指通过对已知频率脉冲的计数，实现精确定时和分频；在微机系统中产生精确的步调，协调系统各任务间的协同工作（结合中断系统）。

**理解**：当CLK端接入固定频率 $f_{CLK}$ 的时钟时，每个时钟脉冲的周期 $T_{CLK}=1/f_{CLK}$ 是确定不变的。写入初值N后，计数器经过N个时钟周期计到0，所经历的时间恒为 $T = N \times T_{CLK}$，因此对已知频率脉冲的计数过程同时就是定时过程。OUT端输出信号的频率为 $f_{OUT} = f_{CLK}/N$，这就是分频。定时结果的两种使用方式：由OUT引脚输出定时波形（例7.2、例7.3），或由OUT触发中断、由CPU在中断服务程序中累计时间（PC/XT实时时钟）。定时精度取决于输入时钟频率的精度。

**作用**：8253三大基本应用之一，是例7.2（2kHz方波、480μs单脉冲）和例7.3（LED 10s亮灭）的共同基础；与计数应用并列，前置知识点为8253的计数机制，后置知识点为计数初值计算与通道级联。

### 知识点 3：PWM波形的产生

**定义**：8253/8254使用两个定时/计数器产生不同占空比的PWM（脉宽调制，Pulse Width Modulation）波形，实现数/模转换，进而可以对电机、开关电源等设备进行控制。

**理解**：PWM波形是周期固定、高电平宽度可变的矩形波，占空比定义为高电平时间与周期的比值。用两个定时/计数器配合：一个计数器决定输出周期，另一个决定高电平宽度，两个输出组合后得到占空比可调的波形。PWM信号在一个周期内的平均电压与占空比成正比，改变占空比就改变了等效的平均输出电压，这一平均输出实现数字量到模拟量的转换（数/模转换），模拟量作用于电机（调速）或开关电源（调压）即可实现控制。

**作用**：8253三大基本应用之一，与计数、定时并列。课件（第2页）仅给出概念性介绍，未展开具体电路与编程，属于概念性知识点。

### 知识点 4：计数初值（时间常数）N

**定义**：计数初值（时间常数）是CPU在初始化8253时写入计数通道、作为减1计数起始值的数值。对频率为 $f_{CLK}$ 的时钟，若要求输出频率为 $f_{OUT}$（周期 $T_{OUT}$）的信号，计数初值取

$$N = \frac{f_{CLK}}{f_{OUT}} = \frac{T_{OUT}}{T_{CLK}}$$

**理解**：计数器从初值N递减到0，共经历N个时钟周期，因此输出频率被除以N。计算的直接含义：分子是每秒钟的时钟脉冲数，分母是每秒钟希望输出的脉冲数，相除得到每输出一个脉冲需要计数的时钟脉冲个数，这个个数就是初值N。使用时必须先统一分子分母的单位（如把1MHz换算为 $10^6$ Hz 再除以 2kHz）。当所需N超过16位上限65536时，单通道无法装入，必须采用通道级联。若采用BCD计数（控制字D0=1），初值按十进制数的BCD码分字节写入（例如500的BCD为0500，写入低字节00H、高字节05H）。在PC/XT机中，二进制计数时写入0000H代表 $2^{16}=65536$，n=0并不表示"不计数"。

**作用**：所有8253定时/计数应用的核心计算量，课件原文指明"软件设计——关键：控制字和计数初值"，是例7.2、例7.3、例7.5及PC/XT三个计数器初始化解题的第一步；与"控制字"并列为8253软件设计的两要素。

### 知识点 5：通道级联

**定义**：通道级联是指把一个通道的输出OUT接到另一个通道的时钟输入CLK，使两级计数分频串联，总的分频系数等于两级计数初值之积 $N = N_1 \times N_2$，从而成倍扩大可实现的定时（分频）范围。

**理解**：单个通道初值上限为65536（二进制计数），最大定时周期为 $65536 \times T_{CLK}$。当所需定时周期超过该上限时，一个通道无法完成。级联拆解了这一限制：第一级把高频时钟分频为中间频率脉冲序列（方式2输出负脉冲序列），第二级再对该中间频率分频，两级分频系数相乘。例7.3中：2MHz时钟经第一级N0=5000后得到 $2\text{MHz}/5000=400\text{Hz}$（周期2.5ms）的中间信号；第二级N1=8000后得到 $400\text{Hz}/8000=0.05\text{Hz}$（周期20s）。两级总效果为 $2\text{MHz}/(5000\times8000)=0.05\text{Hz}$，相当于分频系数 $4\times10^7$，超过单通道16位范围，因此级联是唯一方案。判断是否级联的依据：所需N大于65536（或单通道最大定时周期不足）时必须级联。

**作用**：解决单通道定时能力不足的标准方法，是例7.3的核心知识点。前置知识点：计数初值计算、8253各工作方式；后置知识点：多通道联合使用的系统设计。

### 知识点 6：输出锁存器与软件锁存

**定义**：8253每个计数通道内部有一个16位输出锁存器。软件锁存是指CPU先向控制口写入锁存控制字（D7D6=指定锁存的计数器号，D5D4=00，低4位清0），把当前计数值锁存到该通道的输出锁存器，然后再读出该稳定值；计数值读出后锁存状态自动解除。

**理解**：计数进行过程中直接读取计数器，读到的数值处于变化中，可能得到错误读数（例如读完低字节后计数又减了几次，高字节与低字节不属于同一时刻）。锁存命令的作用是：在命令执行瞬间把计数值复制到输出锁存器并保持不变，此后计数器本身继续计数，输出锁存器内容不再变化，CPU随后分两次（先低字节后高字节）读出的就是锁存瞬间的稳定值。锁存操作由8253内部完成，不干扰计数过程，这是软件锁存优于硬件暂停的根本原因。锁存命令的位格式：D7D6=通道号（00/01/10），D5D4=00，D3~D0=0000；例如锁存计数器1的命令为01000000B。

**作用**：读取现行计数值的标准方法，是例7.4以及流水线计数系统"未装满时查询已装箱数量"的基础；与"硬件暂停"并列构成7.2.2节"计数值的读取"知识点，前置知识点为8253控制字格式，后置知识点为从现行值反推已计数量。

### 知识点 7：方式0的批量计数与中断联动

**定义**：方式0（计数结束中断）中，写入初值n后OUT为低电平，计数器从n开始每来一个CLK脉冲减1，经 $n+1$ 个脉冲计数值减到0时OUT输出正跳变；将OUT接到中断控制器8259A的中断请求端（如IR0），即可每计满 $n+1$ 个事件向CPU请求一次中断，由中断服务程序累计事件总数，实现大批量事件统计。

**理解**：拆解其工作过程：第一步，向通道写入控制字（方式0）和初值n，OUT变低；第二步，每发生一个外部事件，CLK端输入一个正脉冲，计数值减1；第三步，第 $n+1$ 个脉冲使计数值减到0，OUT跳变为高电平；第四步，OUT的正跳变送到8259A的IR0，8259A向CPU发中断请求；第五步，中断服务程序把事件总数加上 $n+1$；第六步，中断返回前必须重新写入初值n，否则计数值已耗尽（已减到0），下一批事件无法再按 $n+1$ 个一批产生中断。计数初值取"每批事件数减1"的原因：方式0从写入初值到OUT跳变共经历 $n+1$ 个时钟脉冲，每批500个事件对应初值499。课件第17页"为什么？"（为什么中断返回后要重新装入初值499）的答案即第六步所述。

**作用**：8253计数功能与8259A中断系统结合的标准方法，是7.2.2节流水线自动计数系统的核心知识点；前置知识点为8253工作方式（方式0）与中断概念，后置知识点为计数值的读取。

### 知识点 8：PC/XT时代背景与"PC"一词的由来

**定义**：PC 是 Personal Computer（个人电脑）的缩写。IBM 在 XT 时代（1980 年代）将其个人电脑产品命名为"个人电脑"（Personal Computer），此后缩写 PC 成为所有个人电脑产品的代名词。

**理解**：直接陈述事件过程：IBM 在 1980 年代推出 XT 系列机型，并将该产品命名为 Personal Computer；该名称的缩写 PC 随后被业界广泛使用，其指代范围从 IBM 的单一产品扩展为对全部个人电脑产品的统称。这一页位于 7.2.3 节开头，交代了本节约 8253 应用实例所选机型（PC/XT）的历史背景，即 PC/XT 是早期在系统板中使用 8253-5 作计数器/定时器的典型机型。

**作用**：背景性知识，为 7.2.3 节"8253 在 PC/XT 机中的应用"提供历史语境，说明选用 PC/XT 作为应用实例的原因。基础概念，独立知识点。

### 知识点 9：PC/XT机中8253-5的硬件电路连接

**定义**：PC/XT 机使用 8253-5 作计数器/定时器（8253-5 为 8253 的 5 MHz 时钟版本型号）。8253 三个通道的时钟 CLK 由 PCLK 经 D 触发器二分频获得，即 CLK = PCLK/2。系统中与 8253 配合工作的器件包括中断控制器（8259A）、DMA 控制器、并行接口（8255A-5）以及 D 触发器（图 7.14）。

**理解**：拆解连线关系：时钟产生器输出的 PCLK 经过一个 D 触发器二分频后，作为统一时钟送入 8253 的各通道 CLK 端，保证系统内各计数器具有同一时钟基准；8253 各通道的输出接到系统中其他器件，例如计数器 0 的输出经系统总线 IRQ0 接到 8259A 的 IR0（第 24 页）；DMA 控制器与并行接口 8255A-5 在系统中与 8253 协同工作。二分频后的时钟频率为 1.19318 MHz，该频率是本节所有计数初值计算的统一基准 f。

**作用**："8253 在 PC/XT 机中的应用"的第 1 个分解部分（硬件电路）。它规定了三个通道的时钟来源与系统连接关系，是后续"三个计数器的功能"及所有初始化程序的前提。前置：7.2.1/7.2.2 中 8253 的 6 种工作方式与编程方法；后置：三个计数器的具体功能与初始化程序。

### 知识点 10：计数器0——实时时钟

**定义**：计数器 0 用作系统定时器：GATE0 接 +5V，使计数器 0 处于常开状态，开机初始化后就一直计数，提供系统时间基准。初始化时选方式 3、二进制计数，计数初值 n = 0（即 $2^{16} = 65536$）。时钟频率 f = 1.19318 MHz（由 8284A 时钟产生器的 2.38636 MHz 信号经 2 分频获得，分频器件为 D 触发器 U21；源文写作 2.39636 MHz，数值注记见补充知识点总结）。OUT0 形成方波，频率为 $f/n = 1.19318\,\text{MHz}/65536 = 18.2\,\text{Hz}$。此方波经系统总线 IRQ0 送到 8259A 的 IR0，使 CPU 每秒产生 18.2 次中断（55 ms/次）。CPU 以此为时间基准，在中断服务程序中对中断次数计数，就可形成实时时钟，例如中断 100 次即为 5.5 s；若用 16 位计数器对中断次数计数，每次中断后计数器 +1，计满后进位表示产生了 65536 次中断，所经过的时间为 $65536/18.2 \approx 3600\,\text{s} = 1$ 小时。适用于对时间精度要求不是很高的场合。

**理解**：拆解工作过程：GATE0 接 +5V 使计数不受门控限制、持续进行；方式 3 使 OUT0 输出方波；初值写入 0000H，二进制计数时 0 代表 65536，因此分频比为 65536，把 1.19318 MHz 降为 18.2 Hz。该 18.2 Hz 方波作为周期中断源送入 8259A，使 CPU 每 55 ms 被中断一次。CPU 把"中断次数"当作时间单位累计：中断次数 × 55 ms 即经过的时间。由于最小时间单位约 55 ms，时间分辨率受中断周期限制，所以只适用于时间精度要求不高的场合。

**作用**："三个计数器的功能"的第 1 部分，为整个 PC/XT 系统提供时间基准（系统时钟节拍、实时时钟）。它同时是 7.2.1 定时功能应用在整机系统中的实例。前置：方式 3 的特性（n 为偶数时输出对称方波）、初值 n = 0 的约定（代表 $2^{16}$）；后置：中断系统（8259A）与中断服务程序设计。

### 知识点 11：计数器1的初始化

**定义**：计数器 1 的初始化：控制字 01010101B（计数器 1、只写低字节、方式 2、BCD 计数）写入控制口 43H；计数初值为 BCD 数 18（即 18H），写入数据口 41H。

**理解**：控制字 01010101B 逐字段拆解：D7D6 = 01 选择计数器 1；D5D4 = 01 只读写低字节；D3D2D1 = 010 方式 2（分频器，输出周期负脉冲）；D0 = 1 为 BCD 计数。初值 18H 在 BCD 计数制下表示十进制 18。方式 2 下每计满 18 个时钟，OUT1 输出一个宽度为一个时钟周期的负脉冲，然后自动重新装入初值，因此 OUT1 输出周期性的负脉冲序列，其周期为 $18 \times T_{CLK} = 18/(1.19318\,\text{MHz}) = 18 \times 0.8381\,\mu s \approx 15.09\,\mu s$。第 26 页（"2）计数器 1"的功能说明）提取文本为空，功能描述未能获得（依据 PC/XT 体系结构的通用知识，计数器 1 用于动态存储器刷新定时，输出周期约 15.09 μs 的定时请求信号，此为教材通用知识，非源课件文字）。

**作用**："三个计数器的功能"的第 2 部分。方式 2 产生的周期性负脉冲在系统中用作定时请求信号；其具体用途的说明位于第 26 页（该页文本未提取到）。

### 知识点 12：计数器2——扬声器音调控制

**定义**：计数器 2 工作于方式 3，计数初值 n = 533H = 1331，从 OUT2 输出的方波频率为 $1.19318\,\text{MHz}/1331 = 896\,\text{Hz}$。GATE2 不接 +5V，而是受 8255A-5 的 PB0 控制：当 PB0 = 1 时允许计数，使 OUT2 端输出方波。该方波与 8255A-5 的 PB1 信号相与后，使扬声器发声。发声频率由预置初值 n 决定，发声时长受 PB1 控制，只有 PB1 = 1 才允许发声。控制 PB1 与 PB0 的电平，就可形成各种音调的声音。因 8255A-5 还控制其它设备，在控制扬声器发声程序中，还要保护 B 端口的原状态。

**理解**：拆解控制量与输出量的分工：初值 n 决定频率（$n = f_{CLK}/f = 1193180/896 \approx 1331$，取 1331 即 533H）；PB0 控制计数允许与否（门控信号）；PB1 控制方波能否通过与门到达扬声器。因此"音调"由 8253 的初值决定，"发声与否与发声时长"由 8255A-5 的 PB1 决定。由于 B 口其余位控制别的设备，修改 PB0/PB1 时必须用读—改—写方式保护原状态（IN 61H → OR 03H → OUT 61H）。

**作用**："三个计数器的功能"的第 3 部分。计数器 2 是 PC/XT 扬声器系统的音频信号源，其频率、门控、输出使能三者分离的控制方式是例7.5 通用发声程序的基础。前置：方式 3、计数初值公式、8255A-5 端口按位操作；后置：扬声器接口电路、例7.5。

### 知识点 13：PC/XT扬声器接口电路

**定义**：PC/XT 的扬声器接口电路中，8253-5 是音频信号源，8255A-5 作控制器，驱动器 75477 增大 8253-5 输出信号的驱动能力（产生 1/2 W 驱动功率），低通滤波器将脉冲信号转换成近正弦波的音频信号，去驱动扬声器发声（图 7.15）。具体连接：8253-5 的 CLK2 加 1.19318 MHz 时钟，可根据要求的声音频率算出定时常数，编程让计数器 2 输出指定频率波形；8255A-5 的 PB0 接 8253-5 的 GATE2，作计数器门控信号，允许或禁止 8253 计数；8255A-5 的 PB1 接与门 U87，PB1 = 1 时，OUT2 输出才能通过与门加到驱动器 75477 的 A 端，产生 1/2 W 驱动功率，再经 RC 低通滤波器滤除高次谐波后，送扬声器发声，PB1 = 0 时波形不能通过与门，扬声器不发声；对 PB1 电平的设置，可控制扬声器发声时间的长短；当 PB1PB0 = 11 时扬声器能连续发声。OUT2（T/C 2 OUT）同时送 8255A-5 的 PC5，供 CPU 读取来了解计数器输出状态；驱动器 U85 的输出端 Y 接到 8255A-5 的 PC4，供 CPU 了解加到扬声器的信号状态。

**理解**：按信号流拆解：8253 计数器 2 产生方波 → 与门 U87（受 PB1 控制是否放行）→ 驱动器 75477（功率放大）→ RC 低通滤波（滤除高次谐波，得到近似正弦波）→ 扬声器。控制路径：8255A-5 的 B 口承担双重控制——PB0 控 GATE2（决定 8253 是否计数），PB1 控与门（决定波形是否输出）。监视路径：PC5 反映计数器 2 的输出状态，PC4 反映实际加到扬声器的信号状态，供 CPU 程序读取判断。扬声器系统能产生一定音调的声响，进行报警和提示，也可编程控制信号频率，奏出乐曲。

**作用**：为计数器 2 的功能提供具体电路实现，是例7.5 程序的硬件基础；同时是 8253 与 8255A 并行接口芯片协同工作的典型实例。前置：8255A 的端口结构与按位操作、8253 的 GATE 门控作用；后置：例7.5 通用发声程序。

### 知识点 14：通用发声程序的计数初值计算——32位被除数的字除法

**定义**：令计数器 2（方式 3）输出频率为 f 的方波，必须向计数器 2 写入的计数初值为 $n = f_{CLK2}/f = 1193180/f = 1234DEH/f$，其中 f 应为人耳能听到的音频，范围约为 20 Hz ~ 20000 Hz，可以 16 进制数先存入 DI 寄存器。因被除数 1193180 的十六进制形式 1234DEH 超过 16 位，程序中求 n 时用字除法：先将被除数的高字节（12H）送到 DX，低字节（34DEH）送到 AX，再除以 DI 中的数，AX 中的商就是初值 n。

**理解**：拆解公式与除法安排：初值公式与普通分频公式相同（n = 时钟频率/输出频率）。特殊之处是被除数：1193180 Hz 的十六进制形式为 1234DEH（精确值为 1234DCH，教材近似写作 1234DEH，差 2），超过 16 位寄存器能表示的最大值 65535，因此必须拆成高位字（0012H）和低位字（34DEH）分别放入 DX 和 AX，构成 32 位数 001234DEH，再用 DIV 指令做 32 位数除以 16 位数的字除法。商 n 的取值范围检查：f = 20 Hz 时 $n = 1193180/20 = 59659$；f = 20000 Hz 时 $n = 1193180/20000 \approx 59.7$，均不超过 65535，所以在给定音频范围内除法不会溢出。

**作用**：例7.5 的核心计算公式，使发声频率可在 20 Hz ~ 20000 Hz 范围内由程序参数任意指定。前置：计数初值公式、DIV 字除法指令格式；后置：例7.5 完整程序。

### 知识点 15：扬声器发声的另一种方法——软件延时方波法

**定义**：不利用 8253 计数器 2 的输出，而由程序控制 8255A-5 的 PB1 输出产生方波：先置 OUT2 = 1，然后连续改变 8255 的 PB1 输出，也能使 U87 送出一定频率的方波。做法是先使 PB0 置 0，再编程使 PB1 输出的电平在 1 和 0 之间来回变化。依据是：PB0 接 GATE2，在 8253 工作于方式 3、GATE = 0 时，输出 OUT 恒为 1，这样就允许 PB1 产生的方波通过 U87 输出（引例 3.94）。

**理解**：拆解原理：方式 3 下 GATE = 0 时 OUT2 固定为高电平 1；与门 U87 的一个输入端（OUT2）恒为 1 之后，U87 的输出完全等于另一输入端 PB1 的电平。因此程序只需在 0 与 1 之间反复切换 PB1，就能在扬声器上得到方波。每次切换之间用 CX = 320 的 LOOP 循环延时，方波一个周期等于 PB1 两次切换加两次延时的总执行时间，音调由延时长短决定（改变 CX 初值即改变音调）。与前一种方法（例7.5）的比较：前一种由 8253 硬件分频产生方波，频率精确稳定，CPU 初始化后无需干预；本方法由 CPU 执行循环产生方波，CPU 全程被占用，频率精度受指令执行时间与中断的影响，但不依赖 8253 计数器 2 的输出。

**作用**：与前一种方法并列的备选发声方案，展示 8253 门控特性（方式 3 下 GATE = 0 时 OUT 恒为 1）的另一种应用方式，体现同一硬件电路上的多种软件实现途径。

### 流水线计数系统接口电路（第 14–16 页）

- 应用背景：自动化工厂流水线上产品数量的统计，用8086和8253（或8254）芯片实现自动计数系统。
- 系统组成：由8086 CPU控制；8253的通道1进行计数；1片8259A中断控制器管理中断请求；电路还包含1个红外LED发光二极管、1个复合型光电晶体管、2个施密特触发器74LS14。
- 连线要点：A1A0与CPU地址总线A2A1相连保证偶地址；GATE1接+5V始终允许计数器工作；OUT1输出到8259A请求中断。
- 检测原理（直接陈述）：
  1. 无工件通过时：LED光照到光电管上使其导通，集电极变低电平，经施密特触发器整形后使CLK1=0。
  2. 有工件通过时：LED光被挡住，光电管截止，集电极为高电平，使CLK1=1；工件通过后，CLK1又回0。
  3. 结果：每通过1个工件，CLK1就输入1个正脉冲，用8253对此脉冲计数，即可统计出工件个数。

### 计数系统初始化编程（第 17 页）

- 计数器1设为方式0，BCD计数，先读/写低字节，控制字为01110001B。
- 若选计数初值n=499，则经500个脉冲（n+1），OUT1将输出1个正跳变；它作用于8259A的IR0端后，向CPU发中断请求，由中断服务程序让工件总数+500。
- 中断服务程序执行完后返回主程序，程序应把初值499再次装入计数器1，才能继续计数（原因：方式0计到0后初值耗尽，不重装则下一批500个工件无法再产生中断）——即第17页"为什么？"的答案。
- 端口地址为F0H、F2H、F4H和F6H，初始化程序：

```
MOV  AL，01110001B  ；控制字
OUT  0F6H，AL       ；写入控制字
MOV  AL，99H
OUT  0F2H，AL       ；先写入计数值低字节
MOV  AL，04H
OUT  0F2H，AL       ；后写入高字节
```

### 计数值的读取（第 18–19 页）

- 应用场景：流水线上工件自动装箱时，装满1000个后就移走箱子，开始下次装箱。可用8253对进箱工件计数：从初值n=999开始，每进1个工件减1，减为0时向CPU发中断请求，通知控制系统移走箱子。
- 查询方法：若在未装满箱子时想了解箱中已装了多少工件，可先读取计数器现行值，再用1000减去现行值，就可求得已入箱的工件数。即：已入箱数 = 1000 − 现行值。
- 问题：读现行值时仍在计数，数值不稳定，会导致错误的读数。为此，必须在读数前终止计数，或锁存计数器输出端现行值。
- 方法一（硬件暂停）：在读数前用外部硬件切断计数脉冲信号，或者使门控信号变为低电平，迫使8253停止计数。缺点：需硬件电路配合，切断外部事件源或禁止正常计数过程，干扰了计数过程，不宜采用。
- 方法二（软件锁存）：每个计数通道中都有1个16位输出锁存器，可先用锁存命令锁存现行计数值，然后将它读出。
  - 锁存：向8253送锁存控制字，其中的D7D6位指定要锁存的计数器号，D5D4位=00，低4位清0。
  - 读取：初始化编程时已置为先读写低字节，后高字节。在写入的锁存命令执行后，只要执行2条IN指令就可读取计数值。
- 锁存状态的解除：锁存命令发出后，锁存的计数值将保持到读出为止。读出后，锁存状态即自动解除，输出锁存器的值又将随计数器的值而变。

### 计数器0——实时时钟（第 24–25 页）完整数据与程序

- 硬件条件：GATE0 接 +5V，计数器 0 常开，开机初始化后一直计数，提供系统时间基准；f = 1.19318 MHz = 1193180 Hz。
- 初始化：方式 3、二进制计数；初值 n = 0（写入 0000H，二进制计数时代表 $2^{16} = 65536$）。
- 输出：OUT0 形成方波，频率 $f_{OUT0} = f/n = 1.19318\,\text{MHz}/65536 = 18.2\,\text{Hz}$；经系统总线 IRQ0 送 8259A 的 IR0；CPU 每秒产生 18.2 次中断（每次约 55 ms，$1/18.2\,\text{Hz} \approx 0.0549\,\text{s}$）。

| 1 | 55 ms（1/18.2 Hz ≈ 54.9 ms） |

## 解题方法汇总

### 方法 1：计数初值（时间常数）N的计算

- **适用场景**：已知CLK时钟频率，要求输出指定频率波形、指定周期方波、指定宽度单脉冲，或批量计数按批产生中断的一切定时/分频/计数应用（例7.2、例7.3、7.2.2计数系统、PC/XT计数器0、计数器2、例7.5均使用）；也可用于已知初值反求输出频率。
- **已知条件**：CLK频率 $f_{CLK}$（或时钟周期 $T_{CLK}$）；目标输出频率 $f_{OUT}$（或目标周期 $T_{OUT}$、单脉冲宽度 $T_W$）；计数制（二进制/BCD）。本课件出现的时钟：1MHz（例7.2）、2MHz（例7.3）、工件脉冲（7.2.2计数系统）、1.19318MHz = 1193180Hz（PC/XT及例7.5）。
- **计算步骤**：
  1. 统一单位：频率全部换算为Hz（1MHz=$10^6$Hz，2kHz=$2\times10^3$Hz，2MHz=$2\times10^6$Hz），时间全部换算为同一单位（480μs 与 $1\mu\text{s}$）。
  2. 频率分频定时：$N = f_{CLK}/f_{OUT}$。例7.2通道0代入 $N_0=10^6/2000=500$；例7.3通道0（第一级）代入 $N_0=2\times10^6/400=5000$；例7.3通道1（第二级，分母用第一级输出频率400Hz）代入 $N_1=400/0.05=8000$；PC/XT计数器2代入 $n=1193180/896\approx1331.47$，取整得 $n=1331=533\text{H}$。
  3. 周期给定时先换算频率：$f_{OUT}=1/T_{OUT}$。例7.3代入 $f_{OUT1}=1/20\text{s}=0.05\text{Hz}$。
  4. 单稳态脉冲宽度定时：$N = T_W/T_{CLK}$。例7.2通道1代入 $N_1=480\mu\text{s}/1\mu\text{s}=480$。
  5. 已知初值反求输出频率：$f_{OUT}=f_{CLK}/N$。PC/XT计数器0代入 $f_{OUT}=1193180/65536=18.206\approx18.2\text{Hz}$（初值65536以0000H写入）；计数器2代入 $f_{OUT}=1193180/1331\approx896.5\approx896\text{Hz}$。
  6. 批量计数每批M个事件：$n=M-1$（方式0从写入初值到OUT跳变共经历 $n+1$ 个脉冲）。7.2.2计数系统代入 $n=500-1=499$。
  7. 被除数超过16位时用字除法（例7.5）：$n=f_{CLK2}/f=1193180/f=1234\text{DEH}/f$；把被除数高位字0012H送DX、低位字34DEH送AX，执行DIV DI（DI存放音频频率f，16进制），商（AX中）即初值n。范围检查：f=20Hz时 $n=1193180/20=59659$，f=20000Hz时 $n\approx59.7$，均不溢出。
  8. 十进制N按计数制写字节：BCD计数（控制字D0=1）按十进制N的BCD码分字节写入——500→(00H,05H)，480→(80H,04H)，5000→(00H,50H)，8000→(00H,80H)，499→(99H,04H)，26→26H，18→18H；二进制计数按十六进制N拆分写入——533H→先33H后05H；只写低字节时仅写一个字节（26→26H，18→18H）。
  9. 结果：得到写入计数通道的时间常数N及其字节表示与写入次序。
- **常见错误**：单位不统一直接相除（1MHz/2kHz误算为0.5）；把n=0当作"不计数"（二进制计数时0000H代表 $2^{16}=65536$，BCD计数时0000代表10000）；颠倒公式写成n=输出频率/时钟频率，得到小于1的错误结果；BCD方式下把N按二进制十六进制写入（500写成01F4H拆为01H、F4H）；单稳态定时误用频率公式而不按"脉宽除以时钟周期"计算；级联时第二级误用原始CLK频率（2MHz）而不使用第一级输出频率（400Hz）；商超过65535时未检查除法溢出（被除数1193180已超16位，必须用32位÷16位字除法）；商有小数时未说明取整造成的频率偏差（如1193180/896=1331.47，取1331后实际输出约896.5Hz）。

### 方法 2：8253控制字的确定与通道初始化编程

- **适用场景**：初始化任一通道：先确定控制字（通道号、读写方式、工作方式、计数进制），再把控制字写入控制口、把计数初值按约定次序写入该通道数据口。本课件所有通道初始化均使用。
- **已知条件**：使用的通道号（0/1/2）、初值位数与读写次序（8位只写低字节；16位先低后高）、要求的工作方式（0~5）、BCD或二进制计数、控制口地址与通道数据口地址。本课件地址：例7.2（控制口316H，通道口310H/312H/314H）；例7.3（控制口87H，通道口81H/83H/85H）；7.2.2计数系统（控制口0F6H，通道1口0F2H）；PC/XT（控制口43H，通道口40H/41H/42H）。
- **计算步骤**：
  1. D7D6写入通道号：通道0=00，通道1=01，通道2=10。
  2. D5D4写入读写方式：00=锁存命令，01=只读写低字节，10=只读写高字节，11=先低字节后高字节。
  3. D3D2D1写入方式码：000=方式0，001=方式1，010=方式2，011=方式3，100=方式4，101=方式5。
  4. D0写入进制：1=BCD计数，0=二进制计数。
  5. 拼接控制字：例7.2通道0（通道0+先低后高+方式3+BCD）= 00+11+011+1 = 00110111B；通道1 = 01+11+001+1 = 01110011B；通道2（只低字节+方式5）= 10+01+101+1 = 10011011B；例7.3通道0（方式2）= 00+11+010+1 = 00110101B、通道1 = 01+11+011+1 = 01110111B；7.2.2计数系统（通道1+方式0）= 01+11+000+1 = 01110001B；PC/XT计数器0 = 00+11+011+0 = 00110110B；计数器1 = 01+01+010+1 = 01010101B；计数器2 = 10+11+011+0 = 10110110B。
  6. `MOV AL,控制字`；`OUT 控制口,AL`：把控制字写入控制口（316H/87H/0F6H/43H）。
  7. 按D5D4规定的字节次序把初值送到通道数据口：
     - 先低后高（16位初值）：例7.2通道0（310H）先00H后05H；例7.3通道0（81H）先00H后50H；PC/XT计数器0（40H）先00H后00H；PC/XT计数器2（42H）先33H后05H；例7.5中n由DIV求出后，`OUT 42H,AL` 先送低8位、`MOV AL,AH` 后 `OUT 42H,AL` 送高8位。
     - 只写低字节（8位初值）：例7.2通道2（314H）写26H一次；PC/XT计数器1（41H）写18H一次。
  8. 结果：通道按指定方式与初值开始工作。
- **常见错误**：控制字写入通道口而不是控制口；控制口（43H）与数据口（40H/41H/42H）地址写反；16位初值却选"只读写低字节"导致高字节无法写入；字节次序与D5D4约定不符（控制字为"先低后高"却先送高字节）；"只写低字节"却写两次，或反之；方式码位序写错（方式3=011误写为110）；控制字D0位（BCD/二进制）与初值的书写格式不一致。

### 方法 3：通道级联扩展定时/分频范围

- **适用场景**：所需时间常数N>65536（16位装不下），或单通道最大定时周期小于要求的定时周期。
- **已知条件**：CLK频率 $f_{CLK}$、目标输出周期 $T_{OUT}$（或频率 $f_{OUT}$）。
- **计算步骤**：
  1. 计算单通道能力上限：$T_{max}=65536/f_{CLK}$，例7.3代入 $T_{max}=0.5\mu\text{s}\times65536=32768\mu\text{s}=32.768\text{ms}$。
  2. 比较：要求的20s > 32.768ms，单通道无法实现，必须级联。
  3. 第一级选方式2（输出负脉冲序列），任取初值N1使中间频率便于第二级处理，例7.3取 $N_0=5000$，中间频率 $f_{mid}=2\text{MHz}/5000=400\text{Hz}$（周期2.5ms）。
  4. 第二级选方式3（方波），初值 $N_2=f_{mid}/f_{OUT}$，例7.3代入 $N_1=400\text{Hz}/0.05\text{Hz}=8000$（其中 $f_{OUT}=1/20\text{s}=0.05\text{Hz}$）。
  5. 接线：第一级OUT接第二级CLK。
  6. 结果：输出频率 $f_{CLK}/(N_1\times N_2)$，例7.3代入 $2\times10^6/(5000\times8000)=0.05\text{Hz}$，周期20s。
- **常见错误**：不检查单通道上限，直接用超过65536的初值；第二级初值用 $f_{CLK}$（2MHz）而不是 $f_{mid}$（400Hz）计算；两级分频系数误用相加（$N_1+N_2$）而不是相乘。

### 方法 4：软件锁存读取现行计数值

- **适用场景**：计数进行中（尤其是方式0连续计数）需要读取当前计数值，且不允许停止计数。
- **已知条件**：控制口地址、通道口地址、该通道初始化时配置的读写次序（先低字节后高字节）。
- **计算步骤**：
  1. 构造锁存命令：D7D6=目标通道号，D5D4=00，D3~D0=0000；例7.4锁存计数器1代入：01+00+0000 = 01000000B。
  2. 写入控制口：MOV AL,01000000B；MOV DX,0F6H；OUT DX,AL。
  3. 从通道口读低8位：MOV DX,0F2H；IN AL,DX（AL=现行值低8位）。
  4. 暂存低8位：MOV AH,AL（AH=低8位）。
  5. 再读高8位：IN AL,DX（AL=现行值高8位）。
  6. 交换拼装：XCHG AH,AL（此后AH=高8位，AL=低8位）。
  7. 结果：AX=锁存瞬间的现行计数值；锁存状态在读出后自动解除。
- **常见错误**：不锁存直接读（读数不稳定）；锁存命令写入通道口（应写控制口）；读取次序与初始化时设定的读写次序不一致；只读一个字节就结束（锁存保持，后续数值仍为旧值）。

### 方法 5：方式0批量计数与中断累计（n+1脉冲计数法）

- **适用场景**：大批量事件（如流水线产品）的自动计数统计，需要CPU按批累计总数。
- **已知条件**：每批事件数M（例：500）、8253通道口与控制口地址、8259A的中断入口。
- **计算步骤**：
  1. 选方式0、BCD计数、先读写低字节；控制字例：01110001B（通道1+先低后高+方式0+BCD）。
  2. 初值取 $n=M-1$：每批500个事件，代入 $n=500-1=499$。
  3. 写入控制字到控制口（0F6H），再写初值低字节99H、高字节04H到通道1口（0F2H），此时OUT1为低电平。
  4. 每个事件产生1个CLK正脉冲，计数值减1；第 $n+1=500$ 个脉冲使计数值减到0，OUT1输出1个正跳变。
  5. OUT1接8259A的IR0，正跳变触发8259A向CPU发中断请求。
  6. 中断服务程序执行：工件总数 = 原总数 + 500。
  7. 中断返回前重新写入初值499（低字节99H、高字节04H），才能继续下一批计数。
  8. 结果：每500个工件CPU获得一次中断并累计一次。
- **常见错误**：初值取M（500）而不是M−1（499），造成实际501个脉冲才跳变、计数错1；中断服务程序返回前忘记重装初值；用不断读计数值代替中断累计，使程序频繁执行I/O。

### 方法 6：由现行计数值反推已计数量

- **适用场景**：从满量程初值开始递减计数、中途需要知道已发生的事件数（如装箱容量1000个，未装满时查询已装数）。
- **已知条件**：满量程容量C（例：1000）、锁存读出的现行值V。
- **计算步骤**：
  1. 用方法 4（软件锁存）读出稳定现行值V。
  2. 计算已计数量：已入箱数 = C − V = 1000 − V（V是剩余计数值，即还需发生的事件数）。
  3. 若V=0，表示已装满，计数器向CPU发中断，通知控制系统移走箱子，开始下次装箱。
  4. 结果：得到已发生事件数的当前值。
- **常见错误**：直接把V当作已计数量（V是尚未发生的脉冲数，不是已发生的）；读取时不锁存，导致V不正确。

### 方法 7：8255A端口按位修改（读—改—写，保护原状态）

- **适用场景**：只改变 8255A 某端口部分位而不影响其余位。PC/XT 中 B 口除 PB0、PB1 外还控制其他设备，接通/关闭扬声器必须使用本方法。
- **已知条件**：端口地址（61H）、要置 1 或清 0 的位、需要保护的原值。
- **计算步骤**：
  1. `IN AL, 61H`：读入端口当前值。
  2. `MOV AH, AL`：保存原值（需要恢复时使用）。
  3. 置位：`OR AL, 03H`（03H = 00000011B，使 PB1、PB0 置 1，其余位不变）；清位：`AND AL, 11111100B`（0FCH，使 PB0、PB1 清 0，其余位不变）。
  4. `OUT 61H, AL`：把修改后的值写回端口。
- **常见错误**：直接 `MOV AL, 03H` 后 `OUT 61H`，覆盖 B 口其他位，影响 8255A-5 控制的其他设备；忘记保存原状态（源文强调"还要保护 B 端口的原状态"）；置位/清位掩码算错（03H 对应 PB1PB0；02H 只对应 PB1；0FCH = 11111100B 清 PB1PB0）。

### 方法 8：定时中断累计实现长时间定时（软件时钟换算）

- **适用场景**：用 8253 产生周期性中断（如 18.2 Hz），CPU 在中断服务程序中累计中断次数，得到秒级/小时级时间，用于对时间精度要求不高的场合（实时时钟）。
- **已知条件**：中断频率 $f_{int} = 18.2\,\text{Hz}$（每次中断约 55 ms）、累计的中断次数 N。
- **计算步骤**：
  1. 求单次中断时长：$T = 1/f_{int} = 1/18.2 \approx 0.0549\,\text{s} \approx 55\,\text{ms}$。
  2. N 次中断经过的时间 $= N \times T$。例：100 次 → 100 × 55 ms = 5.5 s。
  3. 16 位计数器计满（每次中断 +1，进位表示 65536 次中断）：$65536/18.2 = 3600.9 \approx 3600\,\text{s} = 1$ 小时。
  4. 结果：以中断次数为时间单位累计，得到系统时间基准。
- **常见错误**：用 18 Hz 代替 18.2 Hz 计算（65536 次中断按 18 Hz 得 3640.9 s，与按 18.2 Hz 得的 3600.9 s 相差约 40 s，长时间累计误差明显）；忽略该方法的精度限制（最小时间单位约 55 ms，不适用于高精度定时场合）；忘记在中断服务程序中累计中断次数并检测 16 位计数器进位。

### 方法 9：软件延时方波发声法（PB1翻转 + LOOP延时）

- **适用场景**：不利用 8253 计数器 2 的输出波形，用程序切换 8255A-5 的 PB1 电平产生方波驱动扬声器（图 7.15 电路，8253 工作于方式 3 且 GATE = 0 时 OUT2 恒为 1）。
- **已知条件**：B 口地址 61H；PB0 接 GATE2；与门 U87 的两个输入为 PB1 与 OUT2。
- **计算步骤**：
  1. `IN AL, 61H`：读入 B 口状态。
  2. `AND AL, 11111100B`：PB0 清 0（同时 PB1 清 0）。GATE2 = 0，方式 3 下 OUT2 恒为 1，与门 U87 的 OUT2 输入端恒为 1。
  3. `XOR AL, 02H`：02H = 00000010B，异或只翻转 bit1（PB1），PB1 在 1 与 0 之间来回切换。
  4. `OUT 61H, AL`：输出翻转后的电平，经 U87（OUT2 端恒 1）送到驱动器与扬声器。
  5. `MOV CX, 320`；`HERE: LOOP HERE`：延时——LOOP 每执行一次 CX ← CX − 1，CX ≠ 0 转 HERE，共 320 次循环，决定 PB1 每个电平的保持时间。
  6. `JMP BEEP`：无条件返回继续翻转，形成方波；一个周期 = PB1 为 1 的保持时间 + PB1 为 0 的保持时间 = 2 × 延时时间；音调由延时长短决定（改变 CX 的初值 320 即改变音调）。
- **常见错误**：未先置 PB0 = 0：OUT2 不为恒 1，PB1 的方波被与门 U87 阻断或受 OUT2 状态干扰；延时常数被中断打断时，方波频率不稳定；该方法 CPU 全程执行延时循环，无法同时执行其他任务。

### 例题 1：例7.2 用8253产生各种定时波形

**题干**：
某8086系统中，8253基地址为310H，时钟频率1MHz，要让3个计数通道实现如下功能：
1）通道0，输出占空比约50%的2kHz方波；
2）通道1，产生宽度为480μs的单脉冲；
3）通道2，硬件触发，输出1周期宽度的单脉冲，时间常数26。
试设计电路，并编写各通道初始化程序。

**解**：

第 1 步（硬件电路设计）：8253的4个端口地址分别为310H、312H、314H和316H（基地址310H）。3个通道的CLK连在一起，均由频率1MHz时钟驱动。

第 2 步（通道0方案）：通道0要求输出2kHz连续方波，选方式3（方波发生器）。GATE0接+5V（常开，始终允许计数）。计算计数初值：
$$N_0=\frac{f_{CLK}}{f_{OUT}}=\frac{1\text{MHz}}{2\text{kHz}}=\frac{10^6\text{Hz}}{2000\text{Hz}}=500$$
控制字各字段：D7D6=00（通道0），D5D4=11（先读写低字节，后高字节），D3D2D1=011（方式3），D0=1（BCD计数）。拼接得控制字 00110111B。初值500的BCD码为0500，低字节00H，高字节05H。

第 3 步（通道1方案）：通道1要求产生宽度480μs的单脉冲，选方式1（可编程单稳态），由GATE1的正跳变触发。计算计数初值（时钟周期 $T_{CLK}=1/1\text{MHz}=1\mu\text{s}$）：
$$N_1=\frac{T_W}{T_{CLK}}=\frac{480\mu\text{s}}{1\mu\text{s}}=480$$
控制字各字段：D7D6=01（通道1），D5D4=11（先低后高），D3D2D1=001（方式1），D0=1（BCD）。拼接得控制字 01110011B。初值480的BCD码为0480，低字节80H，高字节04H。

第 4 步（通道2方案）：通道2要求硬件触发、输出1周期宽度的单脉冲，时间常数N2=26，选方式5（硬件触发选通），GATE2的正跳变触发计数，计到0时输出1个负脉冲。控制字各字段：D7D6=10（通道2），D5D4=01（只读写低字节），D3D2D1=101（方式5），D0=1（BCD）。拼接得控制字 10011011B。初值26的BCD码为26H，只写低字节。

第 5 步（通道0初始化程序，控制口316H、通道0口310H）：

```
MOV  DX，316H      ；控制口地址
MOV  AL，00110111B ；通道0控制字，先读写低字节，方式3，BCD计数
OUT  DX，AL        ；写入方式字
MOV  DX，310H      ；通道0口地址
MOV  AL，00H       ；低字节
OUT  DX，AL        ；先写入低字节
MOV  AL，05H       ；高字节
OUT  DX，AL        ；后写入高字节
```

第 6 步（通道1初始化程序，控制口316H、通道1口312H）：

```
MOV  DX，316H      ；控制口
MOV  AL，01110011B ；通道1方式字，先读写低字节，方式1，BCD计数
OUT  DX，AL
MOV  DX，312H      ；通道1口地址
MOV  AL，80H       ；低字节
OUT  DX，AL
MOV  AL，04H       ；高字节
OUT  DX，AL
```

第 7 步（通道2初始化程序，控制口316H、通道2口314H）：

```
MOV  DX，316H
MOV  AL，10011011B ；通道2控制字，只读写低字节，方式5，BCD计数
OUT  DX，AL
MOV  DX，314H      ；通道2口地址
MOV  AL，26H       ；低字节
OUT  DX，AL        ；只写入低字节
```

第 8 步（用原始数据验证）：
- 通道0：方式3、N0=500，输出频率 = 1MHz/500 = 2000Hz = 2kHz，与题设2kHz一致；N=500为偶数，方式3下高低电平各占250个时钟周期，占空比 = 250/500 = 50%，满足"占空比约50%"。
- 通道1：方式1、N1=480，单脉冲宽度 = 480 × 1μs = 480μs，与题设一致。
- 通道2：方式5、N2=26，与题设"时间常数26"一致；GATE2正跳变触发，计到0输出宽度为1个时钟周期（1μs）的负脉冲，满足"输出1周期宽度的单脉冲"。

**答案**：
通道0：方式3，N0=500，控制字00110111B；通道1：方式1，N1=480，控制字01110011B；通道2：方式5，N2=26，控制字10011011B；电路按310H/312H/314H/316H四个端口连接，三通道CLK并接1MHz时钟；初始化程序如上三组。

### 例题 2：例7.3 用8253控制LED的点亮与熄灭

**题干**：
用8253控制LED发光管的点亮和熄灭，要求点亮10s，熄灭10s，再重复。画出硬件图并编写初始化程序。
8253各端口地址为81H、83H、85H和87H；数据线D7~D0与CPU的D15~D8相连，以选中奇地址口；OUT1连到LED，高电平点亮LED，低电平熄灭LED。（图7.10）

**解**：

第 1 步（需求分析）：点亮10s、熄灭10s、再重复，即要求OUT1输出周期20秒、占空比1∶1的方波。LED由OUT1直接驱动：高电平点亮，低电平熄灭。

第 2 步（判断能否单通道实现）：若将2MHz时钟加到CLK1端，时钟周期为 $1/2\text{MHz}=0.5\mu\text{s}$。单通道最大计数初值为65536，OUT1输出的脉冲周期最大为
$$T_{max}=0.5\mu\text{s}\times65536=32768\mu\text{s}=32.768\text{ms}$$
32.768ms 达不到要求的20秒，单通道无法实现，需采用通道级联方案。

第 3 步（第一级：通道0，方式2）：CLK0输入2MHz时钟信号，置通道0为方式2（分频器），取计数初值 $N_0=5000$。则OUT0输出负脉冲序列，频率为
$$f_{OUT0}=\frac{2\text{MHz}}{5000}=400\text{Hz}$$
周期为 $1/400\text{Hz}=2.5\text{ms}$。

第 4 步（第二级：通道1，方式3）：把OUT0接到CLK1（级联），并设通道1为方式3（方波发生器）。要求OUT1输出周期为20秒的方波，即频率为
$$f_{OUT1}=\frac{1}{20\text{s}}=0.05\text{Hz}$$
计数初值取
$$N_1=\frac{f_{OUT0}}{f_{OUT1}}=\frac{400\text{Hz}}{0.05\text{Hz}}=8000$$

第 5 步（确定控制字）：
- 通道0：D7D6=00（通道0），D5D4=11（先低后高），D3D2D1=010（方式2），D0=1（BCD）→ 00110101B。
- 通道1：D7D6=01（通道1），D5D4=11（先低后高），D3D2D1=011（方式3），D0=1（BCD）→ 01110111B。

第 6 步（初值的BCD字节编码）：
- N0=5000 → BCD码5000 → 低字节00H，高字节50H。
- N1=8000 → BCD码8000 → 低字节00H，高字节80H。

第 7 步（初始化程序；控制口87H，通道0口81H，通道1口83H）：

```
     MOV  AL，00110101B
；通道0控制字，先读写低字节后高字节，方式2，BCD计数
       OUT  87H，AL
       MOV  AL，00H      ；计数初值低字节
       OUT  81H，AL
       MOV  AL，50H      ；计数初值高字节
       OUT  81H，AL
；
       MOV  AL，01110111B
；通道1控制字，先读写低字节，后高，方式3，BCD计数
       OUT  87H，AL
       MOV  AL，00H      ；计数初值低字节
       OUT  83H，AL
       MOV  AL，80H      ；计数初值高字节
       OUT  83H，AL
```

第 8 步（硬件图说明，图7.10）：8253数据线D7~D0接CPU数据总线的D15~D8，因此4个端口取奇地址81H（通道0）、83H（通道1）、85H（通道2）、87H（控制口）；CLK0接2MHz时钟；OUT0接CLK1；OUT1接LED。

第 9 步（用原始数据验证）：级联后总输出频率为
$$\frac{f_{CLK}}{N_0\times N_1}=\frac{2\times10^6\text{Hz}}{5000\times8000}=0.05\text{Hz}$$
周期 = 1/0.05Hz = 20s，与题设周期20秒一致。方式3且N1=8000为偶数，高电平与低电平各占10s，占空比 = 10s/20s = 1∶1。高电平10s点亮LED、低电平10s熄灭LED，交替重复，与题设"点亮10s，熄灭10s，再重复"一致。

**答案**：
级联方案：通道0方式2、N0=5000、控制字00110101B（OUT0输出400Hz负脉冲序列接CLK1）；通道1方式3、N1=8000、控制字01110111B（OUT1输出0.05Hz、占空比1∶1方波，周期20s，接LED）。初始化程序如上。

### 例题 3：例7.4 对计数器1发锁存命令并读出计数值

**题干**：
对计数器1发锁存命令，然后读出计数值存进AX。
（背景：流水线计数系统，端口地址为F0H、F2H、F4H和F6H；计数器1初始化时已置为先读写低字节、后高字节。）

**解**：

第 1 步（构造锁存命令）：锁存控制字格式为 D7D6=计数器号、D5D4=00、低4位清0。锁存计数器1：D7D6=01，D5D4=00，D3~D0=0000，得 01000000B。

第 2 步（发出锁存命令）：控制口地址0F6H。
```
MOV  AL，01000000B ；锁存计数器1命令
MOV  DX，0F6H      ；控制口
OUT  DX，AL        ；发锁存命令
```

第 3 步（读低8位并暂存）：通道1口地址0F2H。执行 IN AL,DX 后 AL=计数器1现行值的低8位；MOV AH,AL 把低8位暂存到AH。

第 4 步（读高8位）：再次执行 IN AL,DX，AL=计数器1现行值的高8位。

第 5 步（拼装）：XCHG AH,AL 交换AH与AL，交换后 AH=高8位、AL=低8位，计数值完整置于AX中。

完整程序：

```
       MOV  AL，01000000B ；锁存计数器1命令
       MOV  DX，0F6H      ；控制口
       OUT  DX，AL        ；发锁存命令
       MOV  DX，0F2H      ；计数器1
       IN   AL，DX        ；读取计数器1的低8位
       MOV  AH，AL        ；保存低8位
       IN   AL，DX        ；读取计数器1的高8位
       XCHG AH，AL        ；将计数值置于AX中
```

第 6 步（验证与说明）：锁存命令发出后，锁存的计数值将保持到读出为止；本例中第 3、4 步的两次IN指令完成了对锁存值的读出，读出后锁存状态即自动解除，输出锁存器的值又将随计数器的值而变。读取次序（先低8位后高8位）与初始化时设定的读写次序一致，读出的AX即为锁存瞬间计数器1的稳定现行值。

**答案**：
程序如上。执行后 AX 中为计数器1锁存瞬间的现行计数值；锁存状态在两次IN指令读出后自动解除。

### 例题 4：例7.5 产生指定频率f的音频信号的通用发声程序

**题干**：

根据图7.15介绍的扬声器接口电路，编写一个产生指定频率为 f 的音频信号的通用发声程序。首先把 8253-5 的计数器 2 编程为工作方式 3。由于 $f_{CLK2} = 1.19318\,\text{MHz} = 1193180\,\text{Hz}$，为使 OUT2 输出频率为 f 的方波，必须向计数器 2 写入初值 n，其值为：

$$n = f_{CLK2}/f = 1193180/f = 1234DEH/f$$

这里，f 应为人耳能听到的音频，范围约为 20 Hz ~ 20000 Hz，可以 16 进制数先存入 DI 寄存器。程序中求 n 时要用字除法，即先将被除数的高字节（12H）送到 DX，低字节（34DEH）送到 AX，再除以 DI 中的数，AX 中的商就是初值 n。

**解**：

第 1 步：确定计数初值公式。计数器 2 工作于方式 3（方波发生器），分频比等于初值 n，因此 $n = f_{CLK2}/f = 1193180/f$，其中 $f_{CLK2} = 1193180\,\text{Hz}$ 为已知时钟频率。

第 2 步：换算被除数。1193180D 的 16 进制形式为 1234DEH（注：精确值 1193180 = 1234DCH，教材写作 1234DEH，二者相差 2，相对误差约 $2/1193180 \approx 1.7 \times 10^{-6}$，不影响使用）。该数超过 16 位，必须按 32 位数放入 DX:AX：高位字 0012H 送 DX，低位字 34DEH 送 AX，即被除数 = 001234DEH。

第 3 步：执行字除法 `DIV DI`。操作：DX:AX（= 001234DEH ≈ 1193180）除以 DI（= 音频频率 f）。结果：商（即计数初值 n）在 AX 中，余数在 DX 中。

第 4 步：写 8253 控制字。`MOV AL, 10110110B`（字段：D7D6 = 10 计数器 2；D5D4 = 11 先写低字节后写高字节；D3D2D1 = 011 方式 3；D0 = 0 二进制计数），`OUT 43H, AL` 写入控制口。

第 5 步：写入计数初值。`OUT 42H, AL` 先送 AX 低字节（n 的低 8 位）；`MOV AL, AH`，`OUT 42H, AL` 后送 n 的高 8 位。

第 6 步：接通扬声器（读—改—写 B 口）。`IN AL, 61H` 读入 8255A 端口 B 当前内容；`MOV AH, AL` 保护 B 口原状态；`OR AL, 03H` 使 PB1PB0 置 1（03H = 00000011B，其余位不变）；`OUT 61H, AL` 接通扬声器，使它发声。

完整程序（源程序）：

```asm
    MOV  AL, 10110110B      ; 8253控制字: 通道2，先写低字节，方式3，二进制计数
    OUT  43H, AL            ; 写入控制字
    MOV  DX, 0012H          ; 被除数高位（32位数除以16位的数）
    MOV  AX, 34DEH          ; 被除数低位
    DIV  DI                 ; 求计数初值 n，AX=结果
    OUT  42H, AL            ; 送出低8位
    MOV  AL, AH
    OUT  42H, AL            ; 送出高8位
    IN   AL, 61H            ; 读入8255A端口B的内容
    MOV  AH, AL             ; 保护B口的原状态
    OR   AL, 03H            ; 使PB1PB0置1，其余不变
    OUT  61H, AL            ; 接通扬声器，使它发声
```

**答案**：程序对任意 f（20 Hz ~ 20000 Hz，预先以 16 进制数存入 DI）计算 $n = 1193180/f$，把 n 写入计数器 2（方式 3、二进制计数），再置 PB1PB0 = 1 接通扬声器，即可产生频率为 f 的音频信号。

**验证（用原始数据）**：

- 取 f = 896 Hz（第 28 页计数器 2 的已知实例）代入公式：$n = 1193180/896 = 1331.47$，取整得 n = 1331 = 533H；实际输出频率 $= 1193180/1331 \approx 896.5 \approx 896\,\text{Hz}$，与第 28 页"计数初值 n = 533H = 1331，输出方波频率 1.19318 MHz/1331 = 896 Hz"一致。

### 例题 5：引例3.94 扬声器发声的另一种方法（软件延时方波法）

**题干**：

在 PC/XT 扬声器接口电路（图 7.15）中，扬声器发声的另一种方法：先置 OUT2 = 1，然后连续改变 8255 的 PB1 输出，也能使 U87 送出一定频率的方波。做法：先使 PB0 置 0，再编程使 PB1 输出的电平在 1 和 0 之间来回变化。因为 PB0 接 GATE2，在 8253 工作于方式 3、GATE = 0 时，输出 OUT 恒为 1，这样就允许 PB1 产生的方波通过 U87 输出。试写出实现这种发声方案的程序（见例 3.94），并回答：音调怎么决定的？与前一种方法比较怎么样？

**解**：

第 1 步：`IN AL, 61H`——读入 8255A B 口的当前状态。

第 2 步：`AND AL, 11111100B`——11111100B = 0FCH，按位与操作使 bit0（PB0）与 bit1（PB1）都清 0。PB0 = 0 使 GATE2 = 0；8253 工作于方式 3 且 GATE = 0 时，OUT2 恒为 1；于是与门 U87 的一个输入端（OUT2）恒为 1。

第 3 步：`BEEP: XOR AL, 02H`——02H = 00000010B，按位异或只翻转 bit1（PB1）：PB1 由 1 → 0、由 0 → 1，循环切换。

第 4 步：`OUT 61H, AL`——把翻转后的电平写回 B 口，经 U87（OUT2 端恒 1，输出跟随 PB1）送到驱动器与扬声器。

第 5 步：`MOV CX, 320`；`HERE: LOOP HERE`——延时：LOOP 每执行一次 CX ← CX − 1，CX ≠ 0 转 HERE，共 320 次，决定 PB1 每个电平的保持时间。

第 6 步：`JMP BEEP`——无条件转回第 3 步继续翻转，形成方波：一个周期 = PB1 为 1 的保持时间 + PB1 为 0 的保持时间 = 2 × 延时时间。音调由延时长短决定（改变 CX 初值 320 即改变音调）。

完整程序（源程序）：

```asm
            IN     AL, 61H           ; 读入B口状态
            AND    AL, 11111100B     ; PB0=0，使OUT2=1
BEEP:       XOR    AL, 02H           ; PB1由1→0，由0→1
            OUT    61H, AL
            MOV    CX, 320
HERE:       LOOP   HERE              ; 延时
            JMP    BEEP
```

**答案**：程序通过翻转 PB1，并经恒为 1 的 OUT2 与门 U87 输出方波使扬声器发声；音调由软件延时长短决定。

**验证（用原始数据与条件）**：

- 前置条件核对：题目给定"8253 工作于方式 3、GATE = 0 时，输出 OUT 恒为 1"。程序中 `AND AL, 11111100B` 把 PB0 清 0，而 PB0 接 GATE2，因此 GATE2 = 0、OUT2 = 1；此时 U87 的输出完全跟随 PB1，PB1 方波可以通过——与题目给定条件一致。
- 音调决定：方波周期 = 2 ×（切换指令 + 320 次 LOOP 循环）的执行时间；改变 `MOV CX, 320` 中的 320 即可改变音调。
- 与前一种方法（例7.5）比较：例7.5 由 8253 计数器 2 硬件分频产生方波，频率由初值 n 决定，精确稳定，CPU 初始化完成后可执行其他任务；本方法由 CPU 执行延时循环控制 PB1 翻转，CPU 全程被占用，音调精度受指令执行时间和中断影响，且改变频率需改延时常数，但不依赖 8253 计数器 2 的输出。
