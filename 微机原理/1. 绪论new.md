## 知识点详解

### 知识点 1：进位计数制（Positional Numeral System）

**定义**：用一组固定的数字符号和特定的规则来表示数的方法，称为进位计数制。一个进位计数制由两个要素决定：数码集合（一组固定的数字符号，如十进制使用 0～9）与进位规则（每满基数进一，如十进制逢十进一）。一个 r 进制的数 $N$ 可表示为各位数码 $a_i$ 乘以位权 $r^i$ 之和，即 $N = \sum_i a_i \times r^i$（按权展开再相加），其中 $r$ 为基数，$a_i$ 为第 $i$ 位的数码，$i$ 为位序号（最低位 $i=0$）。

**理解**：进位计数制的构成可以拆解为两部分：一是数码集合，确定每个位置上允许出现的符号（十进制为 0～9 共 10 个符号）；二是进位规则，确定满多少进一位（十进制逢十进一）。在进位计数制中，同一个符号写在不同的位置表示不同的数值，因为每个位置有一个权值（基数的幂），因此一个数可以通过"按权展开再相加"还原为实际值。日常生活中除了习惯使用的十进制之外，还存在其他进位计数制，例如计时使用 60 进制（时/分/秒，逢 60 进 1）和 24 进制（天/小时，逢 24 进 1）。

**作用**：是 §1.1"计算机中数的表示方法"体系的基础框架；十进制、二进制以及十六进制（知识点 6）、八进制（知识点 7）都是它的具体实例。该知识点给出的"按权展开再相加"规则是后续所有进制换算方法的理论依据。后置知识点：十进制数、二进制数、十六进制数、八进制数。

### 知识点 2：计算机中数据的三个层面（状态 / 表示 / 意义）

**定义**：数据在计算机中存在三个层面。（1）状态：数字在计算机里面的实际状态是一串"0 和 1"，对应电路状态，即高低电平。（2）表示：如何来表示这一串"0 和 1"，即选用二进制、八进制、十进制或十六进制书写。（3）意义：程序员赋予这串"0 和 1"意义，即编码，例如 C 语言的 int 和 unsigned int。

**理解**：对数据在计算机中的存在方式做拆解分析，得到依次递进的三个层面。第一个层面回答"实际是什么"：计算机内部一切数据最终只以两种电路电平状态存在，对应符号 0 和 1。第二个层面回答"怎么书写"：同一串 0 和 1 可以选用不同的进制书写，进制的选择只改变书写形式，不改变数据本身。第三个层面回答"代表什么"：同一串 0 和 1 可以被赋予不同的含义（编码），例如在 C 语言中同一串二进制位既可解释为 int，也可解释为 unsigned int，解释方式不同，代表的数值就不同。三个层面相互独立：进制解决书写问题，编码解决含义问题，两者不能混淆——计算机里面就只有 0 和 1，关键是赋予它什么意义。

**作用**：位于 §1.1 开篇，是全节的统领性说明。它的作用是划定"进制（表示）"与"编码（意义）"两个概念的边界，为 1.1.1 进位计数制（解决表示问题）和 1.1.2 二进制编码（解决意义问题）两部分提供划分依据，避免学习者将二者混淆。可视为本节的基础概念。

### 知识点 3：计算机采用二进制的原因与十六进制折中方案

**定义**：计算机中采用 0 和 1 来表示数字、字母、符号、图形等。原因：数字计算机是电子设备（由数字逻辑电路组成），电路只有 0 和 1 两种状态。缺点：从人的观点来看，二进制太长，不便书写和记忆。解决方案：在人和计算机之间折中，使用十六进制书写。

**理解**：该知识点是一条因果链。原因：数字计算机由数字逻辑电路组成，电路中基本单元只区分两种状态（0 和 1，对应高低电平），因此计算机内部只能用两个符号 0 和 1 表示所有信息。直接后果：同样的数值用二进制书写位数很长（例如十进制 22 写为二进制需要 5 位：10110B），人书写和记忆困难。解决措施：采用十六进制作为中介写法——十六进制有 16 个数码，书写同一数值所需的位数比二进制少，便于人书写和记忆，同时它仍然是对同一串 0 和 1 的书写表示，与计算机内部的二进制状态不冲突。

**作用**：解释整个 §1.1 为什么以二进制为核心、以及为什么必须掌握十六进制；是十进制数、二进制数等并列知识点的前置说明，为后续学习十六进制数、进制间转换提供动机。前置知识点：计算机中数据的三个层面。

### 知识点 4：十进制数（Decimal / Denary）

**定义**：十进制数使用 10 个数字 0～9，基数为 10，各位权值为 $10^i$（$i$ 为自右向左、从 0 开始的位序号）。实际值等于各位数字按权展开再相加：$N = \sum_i d_i \times 10^i$，其中 $d_i$ 为第 $i$ 位的十进制数码。书写十进制数可加后缀 D，如 347D、15D 等，但后缀 D 通常可以省略不写。

**理解**：十进制数由三个要素构成：数码集合 {0, 1, …, 9}、基数 10、位权 $10^i$。举例说明：347 中，3 位于百位（权 $10^2=100$），4 位于十位（权 $10^1=10$），7 位于个位（权 $10^0=1$），按权展开再相加得 $3\times100+4\times10+7\times1=347$。"按权展开再相加"的含义是：把每一位的数码乘以该位的权值，再把所有乘积加起来，所得结果即该数的实际值。十进制是人的习惯数制，书写时后缀 D 可省略。

**作用**：是 1.1.1"不同进制的数"中的第一个具体实例，与二进制数并列；提供了"按权展开"方法的第一个计算范例，也是其他进制换算结果（实际值）的参照形式。前置知识点：进位计数制。后置知识点：二进制数、十六进制数。

### 知识点 5：二进制数（Binary）

**定义**：二进制数只包含 0、1 两个数字，基数为 2，各位的权值为 $2^i$（$i$ 为自右向左、从 0 开始的位序号）。二进制数必须加后缀 B。实际值等于各位按权展开再相加：$N = \sum_i b_i \times 2^i$，其中 $b_i$ 为第 $i$ 位的二进制数码（0 或 1）。

**理解**：二进制数只使用 0 和 1 两个数码，每一位的权是 2 的幂，自右向左依次为 $2^0=1$、$2^1=2$、$2^2=4$、$2^3=8$、$2^4=16$……举例说明：10110B 共 5 位，按权展开再相加得 $1\times16+0\times8+1\times4+1\times2+0\times1=22$，因此 10110B 与 22 是同一个数的两种写法：22 是十进制写法，10110B 是二进制写法。二进制数与十进制数在外观上可能相同（都由 0～9 中部分符号组成），所以二进制数必须加后缀 B 标识。二进制是计算机内部数据实际采用的表示形式。

**作用**：是 1.1.1"不同进制的数"中的核心实例（计算机内部真实使用的数制），与十进制数并列；其"按权展开"过程是后续十六进制数、八进制数、进制间转换（知识点 6–10）的前置内容。前置知识点：进位计数制、十进制数（按权展开方法）。

### 知识点 6：16 进制数（Hexadecimal）

**定义**：16 进制数由 0～9、A、B、C、D、E、F 共 16 个数字组成，其中数字 A～F 分别表示 10 进制的 10～15；其基数为 16，各位权值为 $16^i$（$i$ 为位序号，最低位 $i=0$）。16 进制数必须加后缀 H。若是字母开头的十六进制数，在编写程序时还需在前面加 0，如 AFH 应写为 0AFH（为了和变量的命名相区分）。

**理解**：十六进制是二进制的紧凑书写形式。因为 $16 = 2^4$，一位十六进制数字恰好等于 4 位二进制数（例：0AH = 1010B，0FH = 1111B），所以十六进制数的长度只有等值二进制数的 1/4，两者互相转换只需按 4 位分组替换，不涉及算术运算。十六进制与十进制互转则需要算术运算：十六转十按权展开求和，十转十六连续除以 16 取余。例：3A0FH 中，最低位 F 的位权为 $16^0$，次低位 0 的位权为 $16^1$，A（=10）的位权为 $16^2$，最高位 3 的位权为 $16^3$，按权展开求和得 14863。

**作用**：属于 1.1.1 进位计数制中继 10 进制、二进制之后的第三个进制知识点。它是课件指出的解决"二进制太长、不便书写和记忆"问题的方案：编写汇编语言程序（如表示存储器地址和数据）以及打印程序清单时常用 16 进制数。前置知识：二进制数；后置知识：不同进制间的转换、BCD 码与 ASCII 码（其码值以十六进制表示）。

### 知识点 7：8 进制数（Octal）

**定义**：8 进制数由 0～7 共 8 个数字组成，基数为 8，各位权值为 $8^i$（$i$ 为位序号）。8 进制数必须加后缀 O 或 Q。

**理解**：因为 $8 = 2^3$，一位八进制数字恰好等于 3 位二进制数，八进制与二进制互相转换只需按 3 位分组替换。例：627Q = 110 010 111B（6→110，2→010，7→111）。八进制转十进制按权展开：$753Q = 7\times8^2 + 5\times8^1 + 3\times8^0 = 7\times64 + 5\times8 + 3\times1 = 448 + 40 + 3 = 491$。历史使用情况：1970、1980 年代的小型机上常用 8 进制数编写汇编语言程序和打印程序清单；当代计算机采用 16 进制计数法，通常不再使用 8 进制数（课件标注"略"）。

**作用**：与十六进制并列的二进制紧凑书写形式之一，课件为略讲内容。前置：二进制数；后置：不同进制间的转换。

### 知识点 8：二进制/16 进制 → 10 进制（按权展开法）

**定义**：把某进制数展开为"各位数字 × 对应位权"之和，再在十进制下求和，即 $N = \sum_{i} d_i r^i$，其中 $r$ 为基数，$d_i$ 为第 $i$ 位的数字，$i$ 为位序号（最低位 $i = 0$）。

**理解**：位权 $r^i$ 是每一位所乘的固定因子，只由该位的位置决定：最低位乘 $r^0$，向左每移一位指数加 1。转换分两步：先把每位数字换算成十进制值（十六进制的 A～F 换成 10～15），再逐位乘位权后相加。例：$3A0F_{16} = 3\times16^3 + 10\times16^2 + 0\times16^1 + 15\times16^0 = 3\times4096 + 10\times256 + 0 + 15 = 12288 + 2560 + 0 + 15 = 14863$。

**作用**："不同进制间的转换"（课件标注"熟练掌握！"）的第一种方法，也是所有进制转十进制的通用方法；十进制是人的参照进制，其他进制数均可经按权展开得到十进制值。

### 知识点 9：10 进制 → 二进制（除 2 求余法）

**定义**：将十进制整数反复除以 2，依次记录每次的余数，直到商为 0 为止；将所得余数按"先得者为低位、后得者为高位"（即逆序）排列，即为对应的二进制数。

**理解**：一个数每除以 2 一次，得到的余数就是其二进制展开中当前最低位的值（0 或 1），商则继续携带高位信息，所以反复除 2 直至商为 0 可逐位求出全部二进制位。例：将 25 转换——$25\div2 = 12$ 余 1；$12\div2 = 6$ 余 0；$6\div2 = 3$ 余 0；$3\div2 = 1$ 余 1；$1\div2 = 0$ 余 1。商为 0 停止。余数按得到顺序为 1、0、0、1、1，逆序排列为 11001，故 25 = 11001B。课件备注：做题时逐次除 2 计算太麻烦（实际可借十六进制中转：先转十六进制，再按 4 位分组转二进制）。

**作用**："不同进制间的转换"的第二种方法（十进制到二进制的方向），与按权展开法互为逆运算。

### 知识点 10：二进制 → 16 进制（每 4 位一组替换法）

**定义**：从二进制数的最低位（LSB）开始，每 4 位分为一组，最高位一组不足 4 位时在左侧补 0；然后把每一组 4 位二进制数替换为对应的 1 位 16 进制数字。

**理解**：由表 1.1 知，每 4 位二进制数可用一个 16 进制数来表示：0000～1001 对应 0～9，1010～1111 对应 A～F。转换过程只做分组与查表替换，不做算术运算。例：1000 1010B = 8AH（1000→8，1010→A）；1011 0100 1101 1001B = B4D9H（1011→B，0100→4，1101→D，1001→9）。书写规范：为便于阅读，书写 2 进制数时从最低位开始每 4 位用空格隔开，但数据输入计算机时不能留空格。反向转换（16 进制 → 二进制）是把每位 16 进制数字展开为 4 位二进制数。

**作用**："不同进制间的转换"的第三种方法；是汇编语言编程中阅读、书写二进制地址与数据的日常操作。

### 知识点 11：Bit（比特）、Byte（字节）、Word（字）

**定义**：Bit（比特，简称位，简写为 b）是二进制数的每 1 位（0 或 1）；Byte（字节，简写为 B）是由 8 位二进制信息组成的信息单位，$1\ \text{byte} = 8\ \text{bit}$；Word（字，简写为 W）是包含 16 位二进制数的信息单位，即两个字节。

**理解**：三个单位是逐级包含关系：1 字 = 2 字节 = 16 位。一个 16 位的字 D15～D0 由高字节 D15～D8 与低字节 D7～D0 拼接而成：字的高 8 位是高字节，低 8 位是低字节。Bit 只能取 0 或 1，是最小单位；Byte 是计算机存储的基本单位；Word 是 16 位机的数据处理单位。

**作用**：计算机中信息量的基本计量单位，属于"计算机中的信息单位"知识点。后续课程中存储容量、寻址空间、指令与数据长度均以字节/字为单位计算。基础概念，独立知识点。

### 知识点 12：字长（Word Length）

**定义**：字长决定计算机一次可处理的二进制数据的位数；它取决于计算机的运算器、通用寄存器和数据总线的位数。

**理解**：根据字长将计算机分为 8 位机、16 位机、32 位机和 64 位机等机型，现在主流的 CPU 为 64 位。字长的直接含义是运算器、通用寄存器、数据总线一次并行处理的位数。字长越长，计算机一次能传送和处理的数据就越多，运算速度越快，精度也越高，但制造工艺也越复杂。

**作用**：与 Bit/Byte/Word 并列构成"计算机中的信息单位"知识点；是理解 8086 属于 16 位机（16 位数据总线与 16 位寄存器）的前置概念。

### 知识点 13：二进制编码（编码的概念）

**定义**：计算机中，数都用二进制表示，因此各种数字、英文字母、运算符号等，都要用特定的二进制码的组合来表示，这种用二进制码组合表示信息的方式即二进制编码。最常用的编码有 BCD 码和 ASCII 码等。

**理解**：编码与进制数必须区分开。计算机里面只有 0 和 1 两种状态；同一串 0/1 位模式可以有两种解释：作为数值解释时是进制数（二进制、八进制、十进制、十六进制），作为符号/字符解释时是编码。关键在赋予这串 0/1 什么意义：赋予的意义对应编码，其二进制数的表示对应进制数。例：C 语言的 int 与 unsigned int 对同一串位模式给出不同的数值解释。

**作用**：§1.1.2 二进制编码的总领概念，BCD 码与 ASCII 码两个具体编码均建立在该概念之上。前置：进位计数制；后置：BCD 码、ASCII 码。

### 知识点 14：BCD 码（8421 码）

**定义**：BCD（Binary Coded Decimal，二进制编码的十进制数）码用 4 位二进制数表示 1 位十进制数字，取 0000～1111 中的前 10 个码（即 0000～1001）表示 0～9，各位的权值是 8、4、2、1，因此也称 8421 码，也叫 BCD 码。BCD 码表示的数逢 10 进 1。

**理解**：BCD 码逐位编码十进制数字，每一位十进制数字独立对应一组 4 位二进制码，因此十进制与 BCD 之间是按位替换，不是整体换算。例：327 = (0011 0010 0111)BCD（3→0011，2→0010，7→0111）；反向，(1001 0101 1000)BCD = 958（1001→9，0101→5，1000→8）。区分：4 位组 1001 作为 BCD 是十进制 9；若把整个位串当作一个二进制数整体换算，结果会不同（如 (0011 0010 0111)BCD 整体按二进制算是 807，而其 BCD 值是 327）。

**作用**：与 ASCII 码并列的最常用编码之一，用于十进制数的逐位二进制表示；压缩/非压缩 BCD 码是后续 8086 十进制调整指令的数据表示基础。

### 知识点 15：压缩 BCD 码与非压缩 BCD 码

**定义**：压缩的 BCD 码用 4 位二进制表示一个十进制位（一个字节存放两个十进制位）；非压缩的 BCD 码用 8 位表示一个十进制位，如用 01H 表示 1，用 09H 表示 9，十进制数 91 即为 0901H。

**理解**：两种形式的区别在于每个十进制位占用的位数：压缩 BCD 每字节放 2 个十进制位（高 4 位与低 4 位各放一个），非压缩 BCD 每字节只放 1 个十进制位（低 4 位为数字，高 4 位为 0）。因此同一十进制数用非压缩 BCD 存储占用的字节数是压缩 BCD 的 2 倍。例：十进制 91 的压缩 BCD 为 91H（1001 0001B）；非压缩 BCD 为 0901H（高字节 09H 表示 9，低字节 01H 表示 1）。

**作用**：BCD 码的两种具体存储形式，直接用于第 32 页"试题实战"（X=0603H 的类型判断与转换，见例题 11），并是后续十进制运算（如 AAA、DAA 等调整指令，后续章节）的数据基础。

### 知识点 16：ASCII 码

**定义**：ASCII（American Standard Code for Information Interchange，美国标准信息交换码）用 7 位代码 00H～7FH 表示计算机中存储的字母、数字及符号，共可表示 128 个字符；其中数字 0～9 的 ASCII 码为 30H～39H，大写字母 A～Z 为 41H～5AH，小写字母 a～z 为 61H～7AH，并包含若干控制字符（如 CR 回车、LF 换行）。ASCII 码表见附录 B。

**理解**：ASCII 是字符（而非数值）的编码：键盘键入的数、字母，送到 CRT 显示的字符，都必须用 ASCII 码表示。7 位代码的 128 个组合（00H～7FH）与 128 个字符一一对应；数字、大写字母、小写字母各占一段连续区间，区间内码值按字符顺序递增（如 '0'=30H，'1'=31H，…，'9'=39H；'A'=41H，'B'=42H，…；'a'=61H，…）。课件注明 ASCII 码表无需记忆（第 34 页实战练习提示查附录 A，page 490）。

**作用**：计算机中字符的标准编码，与 BCD 码并列；是后续 I/O 章节中键盘输入、显示器输出字符处理的基础。

### 知识点 17：符号表示法：机器数与真值

**定义**：带符号位数以最高位做符号位：对于长度 8 位的数（D7～D0），用 D7 位作符号位，D7=1 表示负数，D7=0 表示正数；对于长度 16 位的数（D15～D0），用 D15 位作符号位，D15=1 表示负数，D15=0 表示正数。带符号位的数称为机器数，它表示的实际数值称为机器数的真值。

**理解**：机器数是符号位与数值位拼接成的位串，真值是该位串代表的带符号十进制数。求真值分两步：先看最高位定符号（0 正 1 负），再看其余位定绝对值。例 1.4：0101 1101B 的 D7=0，为正数，数值位 101 1101B = 64+16+8+4+1 = 93，真值为 +93；1101 1101B 的 D7=1，为负数，数值位同为 101 1101B = 93，真值为 −93。同一组数值位配上不同符号位，得到绝对值相同、符号相反的两个真值。

**作用**：§1.1.3 带符号数的表示方法（课件标注"重难点！"）的总领概念；"最高位做符号位"的规则是原码、反码、补码三种表示法共同遵守的约定。前置：进位计数制、进制转换；后置：原码、反码、补码。

### 知识点 18：原码

**定义**：正数的符号位用 0 表示，负数符号位用 1 表示，其余位为二进制数值，这种表示方法称为原码。

**理解**：原码 = 符号位 + 真值的绝对值（二进制）。例 1.5：X=+105 时，|X| = 105 = 110 1001B，符号位填 0，[X]原 = 0110 1001B；X=−105 时，数值位相同，符号位填 1，[X]原 = 1110 1001B。原码有两个问题：第一，0 有 +0 和 −0 之分，即 0000 0000B 与 1000 0000B 两个码同时表示 0；第二，进行两个异号数相加或两个同号数相减的运算时要做减法操作，而一般的计算机中没有减法运算部件。由此产生需求：找到一种办法让计算机的减法也可以用加法器实现，从而简化 CPU 设计——这是引入反码、补码的原因。

**作用**：三种机器数表示法中最直观的一种，与真值换算很方便；同时是引出反码、补码的出发点（正数的原码、反码、补码三者相同；负数的反码与补码由原码派生）。

### 知识点 19：反码

**定义**：正数的反码与原码相同，最高位为符号位用 0 表示，其余位为数值；负数的反码为它的正数按位取反，即连符号位一同取反。

**理解**：负数反码的求法分两步：先写出其正数的原码（含符号位 0），再把每一位（包括符号位）取反。例 1.6（正数）：[+4]反 = 0000 0100B，[+31]反 = 0001 1111B，[+127]反 = 0111 1111B（最大值）。例 1.7（负数）：[−4]反 = 0000 0100B 按位取反 = 1111 1011B；[−31]反 = 0001 1111B 取反 = 1110 0000B；[−127]反 = 0111 1111B 取反 = 1000 0000B（最小值）。8 位二进制数的反码范围为 −127～+127。反码求真值规则：最高位为符号位；符号位为 0（正数）时后 7 位为真正的值；符号位为 1（负数）时后 7 位要取反后才能得到真正的值。例 1.8：[X]反 = 1001 0100B，符号位 1 为负，后 7 位 001 0100B 取反得 110 1011B = 107，故 [X]真值 = −107。

**作用**：原码与补码之间的中间表示：负数的补码 = 其反码 + 1。前置：原码；后置：补码。

### 知识点 20：补码（重点）——定义与求法（第 40 页）

**定义**：正数的补码同原码，符号位为 0；负数的补码为其反码加 1，符号位为 1。

**理解**：负数补码的求法分三步：写原码 → 按位取反得反码 → 反码最低位加 1。例 1.9：+4 时 [+4]原 = 0000 0100B = [+4]反 = [+4]补；−4 时 [−4]原 = 1000 0100B，[−4]反 = 1111 1011B（正数 0000 0100B 按位取反），[−4]补 = 1111 1100B（反码加 1）。+127 时 [+127]原 = 0111 1111B = [+127]反 = [+127]补；−127 时 [−127]原 = 1111 1111B，[−127]反 = 1000 0000B，[−127]补 = 1000 0001B。补码比原码、反码多表示一个数：[−128]补 = 1000 0000B。课件就此提问"为什么补码多出来一个数？"——解答见知识点 21。

**作用**：§1.1.3 的重中之重。用补码表示带符号数，可使减法运算转换为加法运算（呼应第 38 页"计算机中没有减法运算部件"的问题），从而简化 CPU 设计。它是后续所有带符号数运算、溢出判断等内容的表示基础。（补码的表示范围、数学表达、本质与意义分别见知识点 21–24。）

### 知识点 21：补码的表示范围（第 41 页）

**定义**：字长为 $k$ 位（含 1 位符号位）的补码能表示的数值范围为 $-2^{k-1} \sim +2^{k-1}-1$。8 位二进制数能表示的补码范围为 $-128 \sim +127$（即 $-2^7 \sim 2^7-1$）；16 位二进制数能表示的补码范围为 $-32768 \sim +32767$（即 $-2^{15} \sim 2^{15}-1$）。带符号数用补码表示时，最高位是符号位：符号位 $=0$ 表示正数，此时后 7 位就是其真正的数值；符号位 $=1$ 表示负数，此时需要经过换算才能得到真值。

**理解**：8 位二进制数共有 $2^8=256$ 种不同组合，补码把这 256 种组合中的 128 种用于表示负数（$-128\sim-1$），其余用于表示 0 和正数（$0\sim+127$）。负数多出一个（$-128$）而正数只到 $+127$，原因是 0 只占用一种组合（0000 0000B），不像原码那样用 $+0$ 和 $-0$ 两种组合表示同一个 0；省出的这个组合被用来表示 $-128$，所以 8 位补码的负数比正数多一个。

**作用**：补码表示范围是后续所有有符号数运算的边界依据；8 位范围 $-128\sim+127$ 与 16 位范围 $-32768\sim+32767$ 是本课程（16 位 8086 系统）最常用的两个数据宽度。它是后续"溢出判断""符号扩展"等知识点的前置概念，也是本章试题（如第 47 页实战题，见例题 22）中判断结果正确性的标准。

### 知识点 22：补码的数学表达（按权展开求值，第 42 页）

**定义**：可将补码连同符号位看成一个数，各位的权都是 $2^i$；最高位 $=0$ 时为正、$=1$ 时为负，其余各位为数值位。设字长为 $k$，第 $i$ 位的数值为 $b_i$（$i=0,1,\cdots,k-1$），则补码所表示的真值为：

$$X = \left(\pm\, b_{k-1}\right) \cdot 2^{k-1} + b_{k-2} \cdot 2^{k-2} + \cdots + b_1 \cdot 2^1 + b_0 \cdot 2^0$$

其中最高位 $b_{k-1}=0$ 时最高位项取正号、$b_{k-1}=1$ 时最高位项取负号（即最高位按负权 $-2^{k-1}$ 参与计算）。对 8 位数，最高位的权为 $2^7 = 128$。

**理解**：该公式与无符号二进制数按权展开求和的做法相同，唯一的区别是最高位按负权处理：$b_7=1$ 时最高位这一项贡献 $-128$ 而不是 $+128$。例如 1000 0000B 按此规则展开为 $-128+0=-128$，恰为 8 位补码的最小值。这一规则直接说明了为什么补码的最高位既能当符号位、又能与其余各位一起参加算术运算：最高位承担双重功能（表示符号、提供负权），因此整个补码可以当作一个数整体参与运算。

**作用**：提供从补码的二进制形式直接计算真值的方法，是检验补码加减运算结果正确性的依据（如例 1.11、例 1.12 的验证，见例题 19、21），也是理解"补码本质为模 $2^k$ 运算"这一事实的数学基础。前置概念为按权展开（§1.1.1）；后置概念为第 2 章 8086 的二进制算术运算。

### 知识点 23：补码的本质：取反加一求相反数（第 43 页）

**定义**：$[X]_{\text{补}} = [-X]_{\text{补}}$ 带符号位一起取反再加 1，即对一个补码进行"取反加一"操作，就得到其相反数的补码。等价地，8 位补码满足 $[X]_{\text{补}} + [-X]_{\text{补}} = 2^8 = 256$（模 $2^8$ 意义下互为相反数）。

**理解**：以 $[X]_{\text{补}} = 1001\,0100\mathrm{B}$ 为例：把它按无符号数看，其值为 $128+16+4=148$；而它的真值是 $-108$；两者满足 $108 + 148 = 256 = 2^8$。这说明 8 位补码中负数 $-N$ 是以无符号数形式 $2^8-N$ 存储的，即 $256-108=148$。反过来，已知某负数补码的无符号值为 148，其真值就是 $148-256=-108$。而"取反加一"正是实现"由 $N$ 的补码得到 $256-N$"这一关系的位运算技巧：对任意 8 位二进制数 $M$，有 $M + (M\text{ 取反}) = 1111\,1111\mathrm{B} = 255$，再加 1 即为 $256$，所以 $M$ 取反加一的结果是 $256-M$。已知负数补码求真值（取反加一得绝对值）和求原码（符号位不变、其余位取反加一）两种操作，依据的都是这一关系。

**作用**：是全部补码换算规则的核心：真值求补码、补码求真值、求相反数的补码、减法转加法，最终都归结为"取反加一"这一个操作。本课程后续章节（指令系统、汇编程序设计）中所有有符号数的处理都建立在这一规则之上。

### 知识点 24：补码的意义：符号位参加运算、减法转加法（第 44 页）

**定义**：补码可看成"带符号位的数"，符号位也参加运算；要减去一个数，只要加上其补码，即 $[X-Y]_{\text{补}} = [X]_{\text{补}} + [-Y]_{\text{补}}$。

**理解**：在原码表示下，两个异号数相加或两个同号数相减时，必须执行真正的减法操作，而一般的计算机中没有减法运算部件。采用补码后，减法被转换为"加相反数的补码"：先对减数 $Y$ 的补码取反加一得到 $[-Y]_{\text{补}}$，再与 $[X]_{\text{补}}$ 做普通的二进制加法，符号位与数值位一起相加，最高位产生的进位被丢弃，得到的结果就是差的补码。例 1.12 中 $7-19$ 的计算即为 $0000\,0111\mathrm{B} + 1110\,1101\mathrm{B} = 1111\,0100\mathrm{B} = \mathrm{F4H}$，其真值为 $-12$，与直接计算 $7-19=-12$ 的结果一致。

**作用**：说明计算机采用补码表示有符号数的根本原因——只需一个加法器即可同时完成加法和减法，从而简化 CPU 的硬件设计。同时确立了"符号位参加运算、最高位进位丢弃"的运算规则，是后续学习 8086 指令（ADD、SUB 等）执行后结果与标志位变化规律的语义基础。

### 知识点 25：浮点数（实数的表示）【不考】

**定义**：实数（带小数点的数）通常用浮点数（Floating Point Number）表示。此前各节（§1.1）涉及的整数用原码、反码、补码表示。

**理解**：浮点格式把一个数拆成尾数与指数两个部分组合表示，从而可以用有限长度的二进制位表示带小数点的数和绝对值很大或很小的数。本节之前所有表示方法只适用于整数，不能表示小数点后的部分。

**作用**：划定本课程编码知识的边界。原课件明确标注"不做考试要求"，只需掌握"实数用浮点数表示"这一事实即可。基础概念，独立知识点。

### 知识点 26：冯·诺依曼结构

**定义**：冯·诺依曼结构（von Neumann Architecture），又称普林斯顿结构（Princeton Architecture），其特点是程序总线和数据总线混合编址，即程序与数据存放在同一存储器中、共用同一套存储空间与总线。X86 CPU 属于冯·诺依曼结构。

**理解**：在这种结构中，指令（程序）和数据被放在同一个存储器里，通过同一条总线访问。因为取指令和取数据共用同一条总线，二者在同一时刻只能执行其一：执行指令时，指令的读取与数据的读写依次占用总线，而不能并行进行。

**作用**：主流的两种计算机结构之一，也是本课程主线 CPU（8086，X86 系列）所采用的结构。理解该结构是学习第 2 章 8086 CPU 内部结构、总线分时复用机制的前置知识。

### 知识点 27：哈佛结构

**定义**：哈佛结构（Harvard Architecture）的特点是程序总线和数据总线独立编址，即程序存储器和数据存储器相互独立，各自使用独立的存储空间与总线。

**理解**：在哈佛结构中，取指令与取数据使用两条相互独立的总线。由于两条总线互不占用，取指令和存取数据可以在同一时刻进行，不会相互冲突，指令的执行效率更高。

**作用**：与冯·诺依曼结构并列的另一种主流计算机结构。第 55 页指出微型计算机除冯·诺依曼结构外"还有一种常见的结构：哈弗结构"。它与冯·诺依曼结构构成对比知识点，区别集中在"程序总线和数据总线是否独立编址"这一点上。

### 知识点 28：存储器（Memory）

**定义**：存储器是以二进制形式存放原始数据、中间结果和程序的部件。

**理解**：存储器保存三类内容：待加工的原始数据、运算过程中产生的中间结果、以及指挥运算进行的程序。这三类内容一律以二进制形式存放。存储器自身只保存信息，不执行运算。

**作用**：冯·诺依曼计算机五大组成部分之一；与 CPU 一起构成主机（见第 53 页归并）。它是本课程第 5 章"存储器"章节内容的起点，也是第 3、4 章中内存寻址概念的硬件对应物。

### 知识点 29：运算器（Arithmetic Unit）

**定义**：运算器是执行算术运算（$+$、$-$、$\times$、$\div$）、逻辑运算（与、或、非、异或）和移位等操作的部件。

**理解**：运算器负责对数据执行加工处理，其操作类型包括四则算术运算、四种基本逻辑运算（与、或、非、异或）以及移位操作。运算器只执行操作本身，不负责决定何时执行何种操作；操作的调度由控制器完成。

**作用**：冯·诺依曼计算机五大组成部分之一；与控制器集成在同一块芯片上构成中央处理器（CPU）。它是第 2 章 8086 CPU 中 ALU（算术逻辑单元）部分的前置概念。

### 知识点 30：控制器（Control Unit）

**定义**：控制器是指挥和控制各部件协调工作的部件，其工作包括取指令、译码、形成控制命令，让计算机按程序设定的步骤自动操作。

**理解**：控制器的工作可拆分为三步：第一步取指令，从存储器取出当前要执行的指令；第二步译码，解释该指令要求执行什么操作；第三步形成控制命令，产生相应的控制信号发往相关部件。通过不断重复这三步，计算机即可按程序中设定的步骤自动运行。

**作用**：冯·诺依曼计算机五大组成部分之一；与运算器一起构成中央处理器（CPU）。控制器是"存储程序控制"这一核心思想得以实现的部件，是第 2 章 8086 指令执行过程（取指、译码、执行）的前置概念。

### 知识点 31：输入设备（Input Device）

**定义**：输入设备是输入原始数据和程序的设备。

**理解**：输入设备把外部信息（原始数据和程序）转换成计算机能够接收的二进制形式，送入计算机内部。输入设备与 CPU 之间不能直接相连，必须经过 I/O 接口电路。

**作用**：冯·诺依曼计算机五大组成部分之一；与输出设备同属 I/O 设备。它是第 55 页"所有外设都应通过 I/O 接口电路才能连到 CPU"这一规则的适用对象，是第 6 章 I/O 接口知识的前置概念。

### 知识点 32：输出设备（Output Device）

**定义**：输出设备是输出运算结果的设备。

**理解**：输出设备把计算机处理得到的运算结果，以人或其他设备可以接收的形式送出计算机。与输入设备一样，输出设备也必须通过 I/O 接口电路才能与 CPU 相连。

**作用**：冯·诺依曼计算机五大组成部分之一；与输入设备同属 I/O 设备，同属第 6 章 I/O 接口知识的前置概念。

### 知识点 33：微处理器（Microprocessor）

**定义**：微处理器是把运算器和控制器集成在一块大规模集成电路芯片上的中央处理器（CPU）；在微型计算机中，CPU 采用集成化的微处理器（第 55 页表述）。

**理解**：把中央处理器的两个核心部件——运算器和控制器——集成到一片集成电路芯片上，得到的产品就是微处理器。微型计算机以微处理器作为 CPU，配合存储器、I/O 接口和外设构成完整系统。第 54 页以 5 张图片展示微处理器实物（芯片外观），该页无其他文字内容。

**作用**：微型计算机的核心部件。本课程的主线 8086 就是 Intel 公司 1978 年 6 月推出的 16 位微处理器（第 5 页）。第 2 章将详细展开 8086 微处理器的内部结构，本知识点为其引入性概念。

### 知识点 34：微型计算机基本结构（1.3.1）

**定义**：微型计算机一般采用冯·诺依曼结构：CPU 采用集成化的微处理器，各部件通过总线相连；所有外设都应通过 I/O 接口电路才能连到 CPU。其基本结构由微处理器（CPU）、存储器、I/O 接口、I/O 设备四类部件经总线——地址总线、数据总线、控制总线——连接而成。此外还有一种常见的结构：哈弗结构（哈佛结构）。

**理解**：微型计算机的结构可以从两个层面拆解。部件层面：微处理器负责运算和控制；存储器保存程序和数据；I/O 接口是外设与系统总线之间的连接电路；I/O 设备完成输入输出。连接层面：所有部件通过总线连接，其中地址总线传送地址信息（选择要访问的存储单元或接口）、数据总线传送数据、控制总线传送控制信号。外设不能直接接到 CPU 上，必须先经过 I/O 接口电路。

**作用**：给出全课程硬件框架的总览：后续各章（第 2 章 8086 CPU、第 5 章存储器、第 6 章 I/O 接口与 8255A、第 7 章 8253/8254、第 8 章中断与 8259A）都是这张结构图中某类部件的展开。属于顶层总括知识点，是全书的"地图"。

### 三、进制书写规则与后缀汇总（第 19–25 页）

| 进制 | 名称（英文） | 基数 | 数字符号 | 后缀 | 是否可省略 | 位权 | 实际值（按权展开） | 示例 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 十进制 | Decimal / Denary | 10 | 0～9 | D | 通常可省略 | $10^i$ | $\sum_i d_i \times 10^i$ | 347D、15D |
| 二进制 | Binary | 2 | 0、1 | B | 必须加 | $2^i$ | $\sum_i b_i \times 2^i$ | 10110B |
| 十六进制 | Hexadecimal | 16 | 0～9、A～F（A～F 表示 10～15） | H | 必须加 | $16^i$ | $\sum_i h_i \times 16^i$ | 0AFH（字母开头前加 0） |
| 八进制 | Octal | 8 | 0～7 | O 或 Q | 必须加 | $8^i$ | $\sum_i o_i \times 8^i$ | 627Q |

- 字母开头的十六进制数在编写程序时前面加 0（如 AFH 应写为 0AFH），目的是和变量的命名相区分（第 21 页备注）。

- 8 进制数的历史：1970、1980 年代的小型机上常用 8 进制数编写汇编语言程序和打印程序清单；当代计算机采用 16 进制计数法，通常不再使用 8 进制数（第 23 页，课件标注"略"）。

### 五、计算机中信息单位补充（第 26–27 页）

- Bit（比特，简称位，简写 b）：二进制数的每 1 位（0 或 1），是信息的最小单位。
- Byte（字节，简写 B）：8 位二进制信息组成的信息单位，$1\ \text{byte} = 8\ \text{bit}$。
- Word（字，简写 W）：包含 16 位二进制数，即两个字节；一个 16 位的字 D15～D0 = 高字节 D15～D8 + 低字节 D7～D0。
- 字长决定计算机一次可处理的二进制数据的位数；它取决于计算机的运算器、通用寄存器和数据总线的位数。
- 机型分类：根据字长将计算机分为 8 位机、16 位机、32 位机和 64 位机等机型；现在主流的 CPU 为 64 位。
- 字长的影响：字长越长，计算机一次能传送和处理的数据就越多，运算速度越快，精度也越高，但制造工艺也越复杂。

### 六、编码与进制数辨析（第 29 页）

- 计算机中数都用二进制表示，各种数字、英文字母、运算符号等都要用特定的二进制码的组合来表示，即二进制编码。
- 编码与进制数不可混淆：计算机里面就只有 0 和 1；关键是赋予这串 0/1 什么意义——赋予的意义（作为符号/字符）对应编码，其二进制数的表示（作为数值）对应进制数。
- 最常用的编码有：BCD 码和 ASCII 码等。
- 举例：C 语言的 int 和 unsigned int（同一串位模式的不同意义解释）。

### 七、BCD 码补充（第 30–32 页）

- 压缩的 BCD 码：用 4 位二进制表示一个十进制位；非压缩的 BCD 码：用 8 位表示一个十进制位。
- 非压缩 BCD 码实例：用 01H 表示 1，用 09H 表示 9，十进制数 91 即为 0901H。

### 八、ASCII 码补充（第 33–34 页）

- ASCII 用 7 位代码 00H～7FH 表示字母、数字及符号，共 128 个字符；ASCII 码表见附录 B（第 33 页）。

### 九、带符号数表示补充（第 35–40 页）

- 第 28 页与第 35 页均为节内目录页，列出三个小节：1.1.1 进位计数制、1.1.2 二进制编码、1.1.3 带符号数的表示方法；第 35 页并标注"重难点！"。
- 符号位规则：8 位数（D7～D0）用 D7 作符号位；16 位数（D15～D0）用 D15 作符号位；符号位为 1 表示负数，为 0 表示正数。
- 机器数与真值：带符号位的数称为机器数，它表示的实际数值称为机器数的真值。
- 原码的特点：简单易懂，与真值换算很方便；0 有 +0 和 −0 之分，即 0 有两个码同时表示。
- 原码的运算缺陷：两个异号数相加或两个同号数相减的运算要做减法操作；一般的计算机中没有减法运算部件。由此引出问题：能否找到一种办法，让计算机的减法也可以用加法器实现——简化 CPU 设计。
- 反码的范围：8 位二进制数的反码范围为 −127～+127；[+127]反 = 0111 1111B 为最大值，[−127]反 = 1000 0000B 为最小值。
- 反码求真值规则：最高位为符号位；为正数时后 7 位为真正的值，为负数时后 7 位要取反后才能得到真正的值。
- 补码（重点）：正数的补码同原码（符号位为 0）；负数的补码为其反码加 1（符号位为 1）。[−128]补 = 1000 0000B。第 40 页末提问"为什么补码多出来一个数？"——解答见知识点 21（8 位补码范围 −128～+127、16 位 −32768～+32767）与例题 19。

### 十、补码补充（第 41–47 页）

1. **重要说明：有符号整数一律用补码（第 46 页）**：以后的学习中，所有计算机内的有符号整数都是用补码表示的，不再特别说明。因此后续章节中指令（如加减、比较、移位、条件转移）的语义都应按照补码的思维去理解：凡涉及符号数的运算，其结果按补码规则解释。

2. **补码小结（第 45 页，三条换算规则）**：
   1. **已知真值，求补码**：正数——补码即其原码，把十进制转二进制即可；负数——如求 $[-23]_{\text{补}}$，先把 23 转成二进制，再取反加一。
   2. **已知补码，求真值**：正数——二进制直接转十进制；负数——如求补码 $\mathrm{FAH}$ 的真值，步骤为：①对 $\mathrm{FAH}$ 取反加一；②把结果转换为十进制；③加上负号。
   3. **求和、差的补码**：减法转换为加其负数的补码（不管被加数、加数是正数还是负数，规则统一适用）。

   （详细展开见下方"解题方法汇总"的方法 9、10、14。）

3. **补码数学表达式的符号含义（第 42 页）**：

   | 符号 | 含义 |
   |---|---|
   | $k$ | 字长（二进制总位数，含符号位） |
   | $b_i$ | 第 $i$ 位的数值（取值 0 或 1），$i = 0, 1, \cdots, k-1$ |
   | $b_{k-1}$ | 最高位（符号位），$=0$ 为正、$=1$ 为负 |
   | $2^i$ | 第 $i$ 位的权 |
   | $2^{k-1}$ | 最高位的权（8 位数时为 $2^7 = 128$） |

4. **补码本质的数值关系（第 43 页）**：$[X]_{\text{补}} = 1001\,0100\mathrm{B}$ 按无符号数计为 148，其真值为 $-108$，满足 $108 + 148 = 256 = 2^8$。即 8 位补码中，负数 $-N$ 的码按无符号数读为 $256 - N$。

## 解题方法汇总

### 方法 1：按权展开求和法（任意 r 进制 → 十进制/实际值）

- **适用场景**：已知一个以任意进制（r 进制）书写的数，需要求它的实际数值（即十进制值）；或比较不同进制数的实际大小。本课用于十进制 347、二进制 10110B、十六进制 3A0FH、八进制 753Q 的换算。
- **已知条件**：该数的进制（基数 $r$）；该数的各位数码；该数的位数 $n$（从而确定各位位权 $r^i$，最低位 $i=0$，最高位 $i=n-1$）。
- **计算步骤**（以 3A0FH 为例，$r=16$，$n=4$）：
  1. 写出基数 $r$，并从最低位起为各位标位权 $r^0, r^1, r^2, \dots$：3A0FH 中最低位 F 的位权为 $16^0$，次低位 0 的位权为 $16^1$，A 的位权为 $16^2$，最高位 3 的位权为 $16^3$。
  2. 把每位数字换算成十进制值（十六进制的 A～F 换成 10～15）：A = 10，F = 15。
  3. 逐位相乘：$3\times16^3 = 3\times4096 = 12288$；$10\times16^2 = 10\times256 = 2560$；$0\times16^1 = 0\times16 = 0$；$15\times16^0 = 15\times1 = 15$。
  4. 全部乘积相加：$12288 + 2560 + 0 + 15 = 14863$。
  5. 结果：3A0FH = 14863（十进制）。
  （二进制例 10110B：共 5 位，位权自右向左为 $2^0=1$、$2^1=2$、$2^2=4$、$2^3=8$、$2^4=16$；逐位相乘 $1\times16=16$、$0\times8=0$、$1\times4=4$、$1\times2=2$、$0\times1=0$；求和 $16+0+4+2+0=22$，故 10110B = 22。）
- **常见错误**：
  - 位权指数编号错误：最低位的权应为 $r^0=1$，误从 $r^1$ 开始编号。
  - 十六进制数字 A～F 未换算成 10～15 就相乘。
  - 把位权 $r^i$ 的指数与数字 $d_i$ 相乘（$d_i \times r^i$ 误写成 $d_i \cdot r \cdot i$）。
  - 漏项：数码为 0 的位被漏掉，导致展开式缺项。
  - 只展开不求和：写出展开式后没有把各项相加。
  - 进制混淆：把二进制数 10110 按十进制读成"一万零一百一十"；或误用十进制的权 $10^i$ 去展开二进制数。
  - 后缀遗漏：书写二进制数时漏加后缀 B（二进制必须加 B；十六进制必须加 H；十进制后缀 D 可省略）。

### 方法 2：除 2 求余法（十进制 → 二进制）

- **适用场景**：十进制整数转换为二进制数（无符号数或真值的绝对值部分）。
- **已知条件**：十进制整数。
- **计算步骤**：
  1. 用待转换数除以 2，记下余数。以 25 为例：$25\div2 = 12$ 余 1（此余数为二进制最低位）。
  2. 用上一步的商继续除以 2 并记余数：$12\div2 = 6$ 余 0；$6\div2 = 3$ 余 0；$3\div2 = 1$ 余 1；$1\div2 = 0$ 余 1（此余数为最高位）。
  3. 当商为 0 时停止。
  4. 把余数按"先得低位、后得高位"逆序排列：余数顺序为 1、0、0、1、1 → 排列为 11001。
  5. 结果：25 = 11001B（加后缀 B）。
- **常见错误**：余数正序排列（把 10011 当作答案）；商为 0 时的最后余数 1 遗漏（少写最高位）；只除到商为 1 就停止（缺最后一步 $1\div2=0$ 余 1）。

### 方法 3：分组替换法（二进制 ↔ 十六进制，4 位一组；二进制 ↔ 八进制，3 位一组）

- **适用场景**：二进制与十六进制（每 4 位一组）或二进制与八进制（每 3 位一组）的互相转换；十进制转二进制时为避免逐次除 2（课件备注"太麻烦"）可借十六进制中转。
- **已知条件**：二进制位串（方向 1）或十六/八进制数字串（方向 2）。
- **计算步骤**（二进制 → 十六进制）：
  1. 从最低位（LSB）开始，每 4 位分为一组；最高位一组不足 4 位时在左侧补 0。以 1000 1010B 为例：分组为 1000 | 1010。
  2. 每组替换为对应十六进制数字：1000→8，1010→A。得 8AH。
  3. 再例 1011 0100 1101 1001B：分组 1011 | 0100 | 1101 | 1001；替换 1011→B，0100→4，1101→D，1001→9。得 B4D9H。
  4. 反向（十六进制 → 二进制）：把每位十六进制数字展开为 4 位二进制数（如 0AH = 1010B，0FH = 1111B）。
  5. 八进制方向同理按 3 位一组：627Q → 6→110，2→010，7→111 → 110 010 111B。
- **常见错误**：从最高位开始分组（应从 LSB 开始）；最高位一组不足 4 位时没有在最前面补 0；把书写时每 4 位的分隔空格带入计算机输入（数据输入计算机时不能留空格）。

### 方法 4：十进制 ↔ BCD 码转换

- **适用场景**：十进制数与压缩 BCD 码、非压缩 BCD 码之间的互相转换。
- **已知条件**：十进制数字串（方向 1）或 BCD 码位串（方向 2）。
- **计算步骤**（十进制 → 压缩 BCD，以 327 为例）：
  1. 逐位替换：每位十进制数字换成 4 位 8421 码——3→0011，2→0010，7→0111。
  2. 按原顺序拼接：327 = (0011 0010 0111)BCD。
  3. 反向（BCD → 十进制）：每 4 位一组替换回十进制数字——(1001 0101 1000)BCD → 1001→9，0101→5，1000→8 → 958。
  4. 非压缩 BCD：每位数字放一个字节的低 4 位，高 4 位填 0——十进制 91 → 高字节 09H + 低字节 01H → 0901H；反向——X=0603H → 高字节 06H→6，低字节 03H→3 → 十进制 63。
- **常见错误**：把 BCD 位串当作普通二进制数整体换算（如 (0011 0010 0111)BCD 按二进制算成 807，而正确 BCD 值是 327）；非压缩 BCD 中把高 4 位的 0 当作数值参与计算；压缩与非压缩形式混淆（如把 0901H 误读为 2305 之类）。

### 方法 5：压缩 BCD 码加法（每位和不超过 9 的情形）

- **适用场景**：两个压缩 BCD 码相加，且对应各位（半字节）相加结果均不超过 9。
- **已知条件**：两个压缩 BCD 数。
- **计算步骤**（以 36H + 23H 为例）：
  1. 把两个数按半字节拆位：36H = 0011 0110B（高半字节 3、低半字节 6），23H = 0010 0011B（高半字节 2、低半字节 3）。
  2. 低半字节相加：6 + 3 = 9。
  3. 高半字节相加：3 + 2 = 5。
  4. 每位结果均不超过 9，无需修正，组合结果：高半字节 5、低半字节 9 → 0101 1001B = 59H。
  5. 结果：36H + 23H = 59H（压缩 BCD 码），对应十进制 59。
- **常见错误**：把两个字节当作二进制数相加后直接按十六进制读出（本题结果恰好相同，但当某位和超过 9 时二者将产生分歧——BCD 逢 10 进 1，某位和超过 9 时需加 6 修正，该修正方法属后续内容，本课范围外）。

### 方法 6：真值 → 原码

- **适用场景**：把带符号十进制真值写成 8 位（或 16 位）原码机器数。
- **已知条件**：真值 X（含符号）与机器字长（8 位或 16 位）。
- **计算步骤**（以 X=+105 与 X=−105，8 位字长为例）：
  1. 取绝对值 $|X| = 105$。
  2. 把 105 转成二进制：105 = 64 + 32 + 8 + 1 = 110 1001B（7 位数值位；8 位字长时最高位留作符号位）。
  3. 符号位：正数填 0 → [X]原 = 0110 1001B；负数填 1 → [X]原 = 1110 1001B。
- **常见错误**：符号位与数值位总数超过字长（忘记符号位占 1 位，数值位只能有 7 位）；负数只改符号位而数值位算错；忘记 0 有 +0（0000 0000B）和 −0（1000 0000B）两个原码。

### 方法 7：真值 → 反码

- **适用场景**：把带符号十进制真值写成 8 位（或 16 位）反码。
- **已知条件**：真值 X（含符号）。
- **计算步骤**：
  1. 若 X 为正数：反码 = 原码（符号位 0 + 数值位）。例：[+4]反 = 0000 0100B，[+31]反 = 0001 1111B，[+127]反 = 0111 1111B（最大值）。
  2. 若 X 为负数：先写出其正数的原码，再连同符号位每一位取反。以 −4 为例：+4 的原码为 0000 0100B → 按位取反 → 1111 1011B = [−4]反。同理：[−31]反 = 0001 1111B 取反 = 1110 0000B；[−127]反 = 0111 1111B 取反 = 1000 0000B（最小值）。
- **常见错误**：负数取反时漏掉符号位（只对数值位取反）；把正数的反码也取反；忘记 8 位反码范围为 −127～+127（不存在 −128 的反码）。

### 方法 8：反码 → 真值

- **适用场景**：已知机器数的反码，求其真值。
- **已知条件**：反码位串 [X]反。
- **计算步骤**（以 [X]反 = 1001 0100B 为例）：
  1. 看最高位（符号位）：最高位为 1 → 负数；最高位为 0 → 正数。本例最高位为 1。
  2. 取后 7 位：001 0100B。
  3. 后 7 位按位取反：001 0100B → 110 1011B。
  4. 把取反结果转为十进制：110 1011B = 64 + 32 + 8 + 2 + 1 = 107。
  5. 加回符号：真值 = −107。
- **常见错误**：负数求真值时对后 7 位不取反直接用（本例会错得 −20）；取反时把符号位也一起取反参与数值计算。

### 方法 9：真值 → 补码（已知真值求补码）

- **适用场景**：题目给出十进制真值（正数或负数）与字长，要求写出其补码（8 位或 16 位）。
- **已知条件**：真值 X（含符号）与机器字长（8 位或 16 位）。
- **计算步骤**：
  1. 判断符号：$X \geq 0$ 执行第 2 步；$X < 0$ 执行第 3 步。
  2. 正数：补码 = 原码（符号位 0 + 数值位），把 X 转成二进制，不足字长的位在前面补 0。例：[+4]原 = 0000 0100B = [+4]反 = [+4]补；[+127]原 = 0111 1111B = [+127]反 = [+127]补。结束。
  3. 负数：先对 $|X|$ 做十进制转二进制，不足字长在前面补 0，得到含符号位 0 的完整机器数。例：$|-23| = 23 = 0001\,0111\mathrm{B}$（8 位）。
  4. 把第 3 步得到的机器数连同符号位一起按位取反（0 变 1、1 变 0），得反码。例：$0001\,0111\mathrm{B}$ 取反得 $1110\,1000\mathrm{B}$。
  5. 对取反结果加 1，即得 $[X]_{\text{补}}$。例：$1110\,1000\mathrm{B} + 1 = 1110\,1001\mathrm{B} = \mathrm{E9H}$，故 $[-23]_{\text{补}} = \mathrm{E9H}$。
  6. 同理求 −4 与 −127：[−4]原 = 1000 0100B → 其正数 0000 0100B 按位取反得 [−4]反 = 1111 1011B → [−4]补 = 1111 1011B + 1 = 1111 1100B；[−127]原 = 1111 1111B → [−127]反 = 1000 0000B → [−127]补 = 1000 0000B + 1 = 1000 0001B。
  7. 特例：[−128]补 = 1000 0000B（该码在 8 位原码/反码中不存在，由 8 位补码范围 $-128\sim+127$ 直接给出）。
- **常见错误**：
  - 取反时漏掉符号位（负数求补码必须对含符号位的完整机器数取反）；
  - 忘记取反后加 1（把反码当成补码）；
  - 正数也去取反加一（正数补码与原码相同，不做任何变换）；
  - 把"反码 +1"误作"原码 +1"（−4 会错成 1000 0101B）；
  - +1 时最低位进位处理错误（如 1111 1111B + 1 应得 0000 0000B，而不是保留 8 位之外的进位 1）；
  - 忘记负数的补码符号位仍为 1；
  - 位数不足时未在前面补 0 对齐字长。

### 方法 10：已知补码求真值（取反加一法）

- **适用场景**：题目给出补码（如 $\mathrm{FAH}$），要求写出其十进制真值。
- **已知条件**：补码的二进制形式及字长。
- **计算步骤**：
  1. 看最高位（符号位）：$=0$ 为正数，执行第 2 步；$=1$ 为负数，执行第 3 步。
  2. 正数：把各位按权展开求和（二进制转十进制），所得即真值。结束。
  3. 负数：把补码连同符号位一起按位取反，再加 1，得到 $|X|$ 的二进制形式。例：$\mathrm{FAH} = 1111\,1010\mathrm{B}$，取反得 $0000\,0101\mathrm{B}$，加 1 得 $0000\,0110\mathrm{B}$。
  4. 把第 3 步结果按权展开转成十进制。例：$0000\,0110\mathrm{B} = 6$。
  5. 在结果前加负号。例：真值 $= -6$，即补码 $\mathrm{FAH}$ 的真值为 $-6$。
- **常见错误**：
  - 负数补码直接按最高位为正权（$+128$）展开，未按负权处理也未取反加一；
  - 只取反不加一，或取反时漏掉符号位；
  - 最后忘记加负号。

### 方法 11：已知补码求相反数的补码（取反加一）

- **适用场景**：需要 $[-X]_{\text{补}}$ 而手头只有 $[X]_{\text{补}}$（补码减法中求减数相反数的补码、以及任何"求相反数"的场合）。
- **已知条件**：$[X]_{\text{补}}$。
- **计算步骤**：
  1. 把 $[X]_{\text{补}}$ 的每一位（含符号位）取反：0 变 1、1 变 0。
  2. 对取反结果加 1。
  3. 所得即为 $[-X]_{\text{补}}$。例：已知 $[19]_{\text{补}} = 0001\,0011\mathrm{B}$：取反得 $1110\,1100\mathrm{B}$；加 1 得 $1110\,1101\mathrm{B}$，即 $[-19]_{\text{补}} = 1110\,1101\mathrm{B}$。
- **常见错误**：
  - 取反时漏掉符号位（求相反数必须连符号位一起取反）；
  - 与"已知负数补码求原码"（方法 12，符号位不变）混淆：求相反数的补码时符号位要参与取反，求原码时符号位保持不变。

### 方法 12：已知负数补码求其原码

- **适用场景**：题目给出负数补码（符号位为 1），要求写出其原码形式。
- **已知条件**：$[X]_{\text{补}}$（负数）。
- **计算步骤**：
  1. 最高位（符号位）保持 1 不变。
  2. 其余各位（数值位）按位取反。例：$[X]_{\text{补}} = 1001\,0100\mathrm{B}$，数值位 $001\,0100\mathrm{B}$ 取反得 $110\,1011\mathrm{B}$。
  3. 对取反结果加 1。例：$110\,1011\mathrm{B} + 1\mathrm{B} = 110\,1100\mathrm{B}$。
  4. 符号位 1 与第 3 步结果拼合即为原码。例：原码 $= 1110\,1100\mathrm{B}$，即 $-108$。
- **常见错误**：
  - 把符号位也取反（符号位必须保持不变）；
  - 只取反忘记加 1；
  - 把求得的原码直接当作真值而忘记按符号位为负处理（本例真值为 $-108$ 而非 $+108$）。

### 方法 13：补码按权展开法求真值（数学表达法）

- **适用场景**：需要直接从补码的二进制位算出真值，或用权值关系验证补码加减结果的正确性。
- **已知条件**：字长 $k$ 与补码各位 $b_{k-1} \cdots b_0$。
- **计算步骤**：
  1. 写出公式 $X = \pm b_{k-1} \cdot 2^{k-1} + b_{k-2} \cdot 2^{k-2} + \cdots + b_0 \cdot 2^0$（$k=8$ 时最高位权为 $2^7=128$）。
  2. 判断最高位：$b_{k-1}=0$ 取正号，$b_{k-1}=1$ 取负号。
  3. 把其余各位中为 1 的位的权相加。例：$1111\,1100\mathrm{B}$ 中 $b_6,b_5,b_4,b_3,b_2=1$，其权之和为 $64+32+16+8+4=124$。
  4. 最高位项与第 3 步之和相加。例：$b_7=1$ 取负，$X = -128 + 124 = -4$。
- **常见错误**：
  - 最高位按正权 $+128$ 相加（对负数得到错误结果，如 $1111\,1100\mathrm{B}$ 被误算成 252 而非 $-4$）；
  - 遗漏权为 0 的位对应项或遗漏为 1 的位的权值。

### 方法 14：补码加减法（减法转加法）

- **适用场景**：求两个有符号数的和或差的补码（题目只给 $[X]_{\text{补}}$、$[Y]_{\text{补}}$）。
- **已知条件**：$[X]_{\text{补}}$、$[Y]_{\text{补}}$ 及字长。
- **计算步骤**：
  1. 求和：$[X+Y]_{\text{补}} = [X]_{\text{补}} + [Y]_{\text{补}}$，两个补码直接二进制相加（符号位一起加）。
  2. 求差：先用方法 11 求 $[-Y]_{\text{补}}$（对 $[Y]_{\text{补}}$ 取反加一）。
  3. 再计算 $[X-Y]_{\text{补}} = [X]_{\text{补}} + [-Y]_{\text{补}}$，二进制相加。
  4. 逐位相加时逢 2 进 1；最高位产生的进位丢弃（按字长截断，8 位运算保留低 8 位）。
  5. 结果即为和（或差）的补码；若题目要求真值，再用方法 10 换算。
- **常见错误**：
  - 求差时忘记先对减数取反加一，直接拿 $[X]_{\text{补}}$ 减 $[Y]_{\text{补}}$；
  - 相加时未丢弃最高位进位（把 9 位结果当 8 位答案）；
  - 把结果的补码直接当作十进制真值，忘记符号位为 1 时需经取反加一换算。

### 方法 15：补码的字长扩展（8 位 → 16 位符号扩展）

- **适用场景**：题目要求把 8 位补码结果表示为 16 位数（如第 47 页实战题第二空）。
- **已知条件**：一个 8 位补码。
- **计算步骤**：
  1. 看该 8 位补码的最高位（符号位）。
  2. 符号位 $=0$：在高位补 8 个 0。例：$35\mathrm{H} = 0011\,0101\mathrm{B} \to 0000\,0000\,0011\,0101\mathrm{B} = 0035\mathrm{H}$。
  3. 符号位 $=1$：在高位补 8 个 1。例：$85\mathrm{H} = 1000\,0101\mathrm{B} \to 1111\,1111\,1000\,0101\mathrm{B} = \mathrm{FF85H}$。
- **常见错误**：
  - 负数扩展时高位补 0（得到 $0085\mathrm{H} = +133$，与 $-123$ 不等）；
  - 正数扩展时高位补 1。

### 例题 1：十进制数 347 的按权展开（第 19 页）

**题干**：已知十进制数 347。写出它的按权展开式，并将各位按权展开的结果相加，求出实际值（"实际值 = 按权展开再相加"）。

**解**：

第 1 步：确定基数与各位位权。十进制基数 $r=10$；347 共 3 位，自右向左位权依次为 $10^0=1$、$10^1=10$、$10^2=100$。

第 2 步：逐位相乘。百位：$3\times10^2=3\times100=300$；十位：$4\times10^1=4\times10=40$；个位：$7\times10^0=7\times1=7$。

第 3 步：求和。$300+40+7=347$。

**答案**：$347 = 3\times10^2+4\times10^1+7\times10^0 = 300+40+7 = 347$。

**验证**：将展开式代回原始数据验算：$3\times10^2=3\times100=300$，$4\times10^1=4\times10=40$，$7\times10^0=7\times1=7$；三项之和 $300+40+7=347$，与题干给出的数 347 一致，验证正确。

### 例题 2：二进制数 10110B 换算为实际值（第 20 页）

**题干**：已知二进制数 10110B。写出它的按权展开式，并按权展开再相加，将 10110B 换算成实际值（十进制数）。

**解**：

第 1 步：确定基数与各位位权。二进制基数 $r=2$；10110B 共 5 位，自右向左位权依次为 $2^0=1$、$2^1=2$、$2^2=4$、$2^3=8$、$2^4=16$。

第 2 步：逐位相乘。最高位：$1\times2^4=1\times16=16$；次高位：$0\times2^3=0\times8=0$；第 2 位：$1\times2^2=1\times4=4$；第 1 位：$1\times2^1=1\times2=2$；最低位：$0\times2^0=0\times1=0$。

第 3 步：求和。$16+0+4+2+0=22$。

**答案**：$10110B = 1\times2^4+0\times2^3+1\times2^2+1\times2^1+0\times2^0 = 16+0+4+2+0 = 22$。即 10110B 与十进制数 22 是同一个数的两种写法，可用 22 或 10110B 表示计算机里的同一个数。

**验证**：将结果 22 拆解为 2 的幂之和：$22=16+4+2=2^4+2^2+2^1$。说明二进制中位权为 $2^4$、$2^2$、$2^1$ 的位取 1，位权为 $2^3$、$2^0$ 的位取 0；按位权从高到低（$2^4,2^3,2^2,2^1,2^0$）排列各位置数码，得 $1\ 0\ 1\ 1\ 0$，即 10110B，与题干的原始数据 10110B 一致，验证正确。

### 例题 3：16 进制数按权展开转 10 进制（第 21 页）

**题干**：3A0FH = ?

**解**：

第 1 步：识别每位数字与位权——最低位 F 的位权为 $16^0$，次低位 0 的位权为 $16^1$，A 的位权为 $16^2$，最高位 3 的位权为 $16^3$。

第 2 步：把字母数字换成十进制值：A = 10，F = 15。

第 3 步：逐项相乘：$3\times16^3 = 3\times4096 = 12288$；$10\times16^2 = 10\times256 = 2560$；$0\times16^1 = 0\times16 = 0$；$15\times16^0 = 15\times1 = 15$。

第 4 步：求和：$12288 + 2560 + 0 + 15 = 14863$。

**答案**：3A0FH = 14863。

**验证**（代回原始数据）：把 14863 连续除以 16 取余：$14863\div16 = 928$ 余 15（F）；$928\div16 = 58$ 余 0；$58\div16 = 3$ 余 10（A）；$3\div16 = 0$ 余 3。余数逆序为 3、A、0、F，即 3A0FH，与原题数据一致。

### 例题 4：一位 16 进制数字与 4 位二进制对照（第 22 页）

**题干**：一位 16 进制数字可用 4 位二进制数表示。例如：0AH = ?，0FH = ?（16 进制数的长度只有二进制数的 1/4，两者转换方便。）

**解**：

第 1 步：A 表示十进制 10，10 = 8 + 2 = 1010B，所以 0AH = 1010B。

第 2 步：F 表示十进制 15，15 = 8 + 4 + 2 + 1 = 1111B，所以 0FH = 1111B。

**答案**：0AH = 1010B，0FH = 1111B。

**验证**：1010B = $1\times2^3 + 0\times2^2 + 1\times2^1 + 0\times2^0 = 8 + 0 + 2 + 0 = 10$ = A，与原题数据一致；1111B = $8 + 4 + 2 + 1 = 15$ = F，与原题数据一致。

### 例题 5：8 进制数按权展开转 10 进制（第 23 页）

**题干**：753Q = ?

**解**：

第 1 步：基数 $r = 8$，位权从低到高依次为 $8^0, 8^1, 8^2$。

第 2 步：逐项相乘：$7\times8^2 = 7\times64 = 448$；$5\times8^1 = 5\times8 = 40$；$3\times8^0 = 3\times1 = 3$。

第 3 步：求和：$448 + 40 + 3 = 491$。

### 例题 6：8 进制转二进制（第 23 页）

### 例题 7：10 进制转二进制（第 24 页）

**题干**：将 25 转换成二进制。（方法：用除 2 求余数的方法。）

**解**：

第 1 步：$25\div2 = 12$ 余 1（此余数为二进制最低位）。

第 2 步：$12\div2 = 6$ 余 0。

第 3 步：$6\div2 = 3$ 余 0。

第 4 步：$3\div2 = 1$ 余 1。

第 5 步：$1\div2 = 0$ 余 1（商为 0，停止；此余数为最高位）。

第 6 步：余数逆序排列：1、1、0、0、1。

**答案**：25 = 11001B。

**验证**：11001B = $1\times2^4 + 1\times2^3 + 0\times2^2 + 0\times2^1 + 1\times2^0 = 16 + 8 + 0 + 0 + 1 = 25$，与原题数据一致。课件备注：做题时逐次除 2 太麻烦（可用分组法借十六进制中转）。

### 例题 8：二进制转 16 进制（第 25 页）

**题干**：由表 1.1 知，每 4 位 2 进制数可用一个 16 进制数来表示。例如：1000 1010B = ?；1011 0100 1101 1001B = ?

**验证**：8AH 展开为 1000 1010B（8→1000，A→1010），与原题数据一致。B4D9H 按权展开：$11\times16^3 + 4\times16^2 + 13\times16^1 + 9\times16^0 = 11\times4096 + 4\times256 + 13\times16 + 9 = 45056 + 1024 + 208 + 9 = 46297$；原二进制数 1011 0100 1101 1001B = $2^{15} + 2^{13} + 2^{12} + 2^{10} + 2^7 + 2^6 + 2^4 + 2^3 + 2^0 = 32768 + 8192 + 4096 + 1024 + 128 + 64 + 16 + 8 + 1 = 46297$，两值相等，与原题数据吻合。

### 例题 10（例 1.3）：求 BCD 码的 10 进制数（第 30 页）

### 例题 11：试题实战——非压缩/压缩 BCD 码（第 32 页）

**题干**：非压缩的 BCD 码数据 X=0603H，代表十进制数据____，如果表示为压缩的 BCD 码应为____。压缩的 BCD 码数据 36H 和 23H 相加结果应为压缩的 BCD 码：____。

**解**：

第 1 步（第一空）：非压缩 BCD 码每个字节表示一个十进制位（低 4 位有效，高 4 位为 0）。X=0603H 的高字节 06H 表示 6，低字节 03H 表示 3，故 X 代表十进制数 63。

第 2 步（第二空）：把十进制 63 换成压缩 BCD——每位数字用一个 4 位 8421 码：6→0110，3→0011。

第 3 步：拼接：0110 | 0011 = 0110 0011B。

第 4 步：写成十六进制形式：0110 0011B = 63H。即压缩的 BCD 码为 63H。

第 5 步（第三空）：36H 的压缩 BCD 拆位：高半字节 3（0011）、低半字节 6（0110）；23H 拆位：高半字节 2（0010）、低半字节 3（0011）。

第 6 步：低半字节相加：6 + 3 = 9。

第 7 步：高半字节相加：3 + 2 = 5。

第 8 步：每位结果均不超过 9，无需修正，拼接：高半字节 5、低半字节 9 → 0101 1001B = 59H。

**答案**：X=0603H 代表十进制数据 63；表示为压缩的 BCD 码为 63H（0110 0011B）；36H 和 23H 相加结果为压缩的 BCD 码 59H。

**验证**：第一空——63 = 6×10 + 3，其非压缩形式为高字节 06H（=6）、低字节 03H（=3），与题目给出的 0603H 一致。第二空——压缩形式 0110 0011B 分组为 0110→6、0011→3，即 63，与第一空的十进制 63 一致。第三空——十进制验算 36 + 23 = 59；压缩 BCD 结果 59H 拆位为 5 和 9，分别等于第 6、7 步的半字节和 9 与 5，一致。

### 例题 12：实战练习——查 ASCII 码表（第 34 页）

**题干**：查表附录 A（page 490）：'a' 的 ASCII 码是____；'A' ASCII =____；'1' 的 ASCII 码是____；'9' 的 ASCII 码是____。（注：ASCII 码表无需记忆。）

### 例题 13（例 1.4）：符号位表示法求真值（第 36 页）

**题干**：例 1.4 对于长度 8 位的数（D7～D0），用 D7 位作符号位，D7=1 表示负数，D7=0 表示正数。0101 1101B = ?；1101 1101B = ?

第 3 步：真值 = +93。

第 4 步（第二数 1101 1101B）：最高位 D7 = 1，为负数。

第 5 步：数值位同为 101 1101B = 93。

### 例题 14（例 1.5）：求原码（第 38 页）

**题干**：例 1.5 正数的符号位用 0 表示，负数符号位用 1 表示，其余位为二进制数值。X=+105，[X]原 = ?；X=−105，[X]原 = ?

**解**：

### 例题 15（例 1.6）：正数的反码（第 39 页）

**题干**：例 1.6 正数的反码与原码相同，最高位为符号位用 0 表示，其余位为数值。[+4]反 = ?；[+31]反 = ?；[+127]反 = ?

### 例题 16（例 1.7）：负数的反码（第 39 页）

**题干**：例 1.7 负数的反码为它的正数按位取反，即连符号位一同取反。[−4]反 = ?；[−31]反 = ?；[−127]反 = ?

**解**：

第 1 步：−4：其正数 +4 的原码为 0000 0100B。

第 2 步：连同符号位按位取反：0000 0100B → 1111 1011B，故 [−4]反 = 1111 1011B。

第 3 步：−31：+31 的原码 0001 1111B 取反 → 1110 0000B，故 [−31]反 = 1110 0000B。

第 4 步：−127：+127 的原码 0111 1111B 取反 → 1000 0000B，故 [−127]反 = 1000 0000B（8 位反码的最小值）。

**答案**：[−4]反 = 1111 1011B；[−31]反 = 1110 0000B；[−127]反 = 1000 0000B（最小值）。

**验证**：对 [−4]反 = 1111 1011B 求真值——符号位 1 为负，后 7 位 111 1011B 取反得 000 0100B = 4，真值 = −4，与原题数据一致。同理可验 −31 与 −127。

### 例题 17（例 1.8）：反码求真值（第 39 页）

**题干**：例 1.8 带符号数用反码表示时，最高位为符号位，当它为正数时，后 7 位为真正的值，它为负数时，后 7 位要取反后才能得到真正的值。[X]反 = 1001 0100B，[X]真值 = ?

**解**：

第 1 步：最高位为 1，X 为负数。

第 2 步：取后 7 位：001 0100B。

第 3 步：后 7 位按位取反：001 0100B → 110 1011B。

第 4 步：把 110 1011B 转为十进制：$1\times2^6 + 1\times2^5 + 0\times2^4 + 1\times2^3 + 0\times2^2 + 1\times2^1 + 1\times2^0 = 64 + 32 + 0 + 8 + 0 + 2 + 1 = 107$。

第 5 步：加负号：[X]真值 = −[110 1011] = −107。

**答案**：[X]真值 = −107。

**验证**：把 −107 的反码算回——107 = 110 1011B，+107 的原码 = 0110 1011B，按位取反 = 1001 0100B，与原题给出的 [X]反 完全一致。

### 例题 18（例 1.9）：求补码（第 40 页，重点）

**题干**：例 1.9 正数的补码同原码，符号位为 0；负数的补码为其反码加 1，符号位为 1。求 [+4]、[−4]、[+127]、[−127] 的原码、反码、补码，以及 [−128]补。

**解**：

第 1 步（+4）：[+4]原 = 0000 0100B；正数反码、补码同原码，故 [+4]反 = 0000 0100B，[+4]补 = 0000 0100B。

第 2 步（−4 的原码）：符号位 1 + 数值位 000 0100B → [−4]原 = 1000 0100B。

第 3 步（−4 的反码）：其正数 0000 0100B 按位取反 → [−4]反 = 1111 1011B。

第 4 步（−4 的补码）：反码加 1——1111 1011B + 1 = 1111 1100B → [−4]补 = 1111 1100B。

第 5 步（+127）：[+127]原 = 0111 1111B = [+127]反 = [+127]补。

第 6 步（−127 的原码）：符号位 1 + 数值位 111 1111B → [−127]原 = 1111 1111B。

第 7 步（−127 的反码）：0111 1111B 取反 → [−127]反 = 1000 0000B。

第 8 步（−127 的补码）：反码加 1——1000 0000B + 1 = 1000 0001B → [−127]补 = 1000 0001B。

第 9 步（−128 的补码）：[−128]补 = 1000 0000B（课件给出；该码为补码特有的额外表示。"为什么补码多出来一个数？"的解答见知识点 21 与例题 19。）

**答案**：

| X | [X]原 | [X]反 | [X]补 |
|---|---|---|---|
| +4 | 0000 0100B | 0000 0100B | 0000 0100B |
| −4 | 1000 0100B | 1111 1011B | 1111 1100B |
| +127 | 0111 1111B | 0111 1111B | 0111 1111B |
| −127 | 1111 1111B | 1000 0000B | 1000 0001B |
| −128 | —（8 位反码范围为 −127～+127，无其原码/反码） | — | 1000 0000B |

**验证**：[−4]补 = 1111 1100B：减 1 得 1111 1011B = [−4]反，再取反得 0000 0100B = +4 的原码，即真值 −4，与原题数据一致。[−127]补 = 1000 0001B：减 1 得 1000 0000B = [−127]反，取反得 0111 1111B = +127 的原码，即真值 −127，与原题数据一致。[−128]补 = 1000 0000B 无法通过"原码 → 反码 → 补码"流程得到（其数值位 128 超出 7 位数值位的表示范围 127），这正是补码比原码、反码多表示一个数的体现（解释见知识点 21 与例题 19）。

### 例题 19（例 1.11）：用按权展开法求补码的真值（第 42 页）

**题干**：可将补码连同符号位看成一个数，各位的权都是 $2^i$；最高位 $=0$ 时为正、$=1$ 时为负，其余为数值。设字长为 $k$，每位数值为 $b_i$，其值为 $X = \left(\pm\, b_{k-1}\right) \cdot 2^{k-1} + b_{k-2} \cdot 2^{k-2} + \cdots + b_0 \cdot 2^0$。8 位数最高位的权为 $2^7 = 128$。用该公式求 $[-128]_{\text{补}} = 1000\,0000\mathrm{B}$、$[-4]_{\text{补}} = 1111\,1100\mathrm{B}$、$[+4]_{\text{补}} = 0000\,0100\mathrm{B}$ 的真值。

**解**：

第 1 步：写出 8 位（$k=8$）补码的按权展开公式：$X = \pm b_7 \cdot 2^7 + b_6 \cdot 2^6 + b_5 \cdot 2^5 + b_4 \cdot 2^4 + b_3 \cdot 2^3 + b_2 \cdot 2^2 + b_1 \cdot 2^1 + b_0 \cdot 2^0$，其中 $b_7 = 0$ 取正号、$b_7 = 1$ 取负号，最高位权 $2^7 = 128$。

第 2 步：计算 $[-128]_{\text{补}} = 1000\,0000\mathrm{B}$。最高位 $b_7 = 1$ 取负，其余各位全为 0，$X = -1 \times 128 + 0 = -128$。

第 3 步：计算 $[-4]_{\text{补}} = 1111\,1100\mathrm{B}$。最高位 $b_7 = 1$ 取负；其余位中为 1 的是 $b_6,b_5,b_4,b_3,b_2$，其权之和为 $64+32+16+8+4 = 124$；$X = -128 + (64+32+16+8+4) = -128 + 124 = -4$。

第 4 步：计算 $[+4]_{\text{补}} = 0000\,0100\mathrm{B}$。最高位 $b_7 = 0$，最高位项为 $+0 \times 128 = 0$；为 1 的位只有 $b_2$，$X = +0 \times 128 + 1 \times 2^2 = 4$。

第 5 步：用原始数据验证：$-128$、$-4$、$+4$ 均在 8 位补码范围 $-128 \sim +127$ 之内，且 $1000\,0000\mathrm{B}$ 按公式算得 $-128$，恰为 8 位补码最小值（第 40 页 $[-128]_{\text{补}} = 1000\,0000\mathrm{B}$ 的唯一表示），各结果与真值一致。

**答案**：$[-128]_{\text{补}} = 1000\,0000\mathrm{B}$ 的真值为 $-128$；$[-4]_{\text{补}} = 1111\,1100\mathrm{B}$ 的真值为 $-4$；$[+4]_{\text{补}} = 0000\,0100\mathrm{B}$ 的真值为 $+4$。

### 例题 20（例 1.10）：已知负数补码求原码（第 43 页）

**题干**：若已知 $[X]_{\text{补}} = 1001\,0100\mathrm{B}$，求 $X$ 的原码。（提示：对一个补码取反加一，就得到其相反数的补码；已知负数补码求真值时，符号位不变、其余位取反加一即得原码。）

**解**：

第 1 步：观察 $[X]_{\text{补}} = 1001\,0100\mathrm{B}$，最高位（符号位）为 1，故 $X$ 为负数，其原码符号位应为 1。

第 2 步：按"符号位不变，其余位取反加一"操作。符号位取 1 保持不变；其余 7 位为 $001\,0100\mathrm{B}$。

第 3 步：对其余位取反：$001\,0100\mathrm{B} \to 110\,1011\mathrm{B}$。

第 4 步：对取反结果加 1：$110\,1011\mathrm{B} + 1\mathrm{B} = 110\,1100\mathrm{B}$。

第 5 步：符号位 1 与第 4 步结果拼合，得原码 $1\,110\,1100\mathrm{B}$，即 $1110\,1100\mathrm{B}$。

第 6 步：验证原码的数值：$1110\,1100\mathrm{B}$ 除去符号位后为 $110\,1100\mathrm{B} = 64 + 32 + 8 + 4 = 108$，故 $X = -108$。

第 7 步：用补码本质的原始数据关系验证：$[X]_{\text{补}} = 1001\,0100\mathrm{B}$ 按无符号数读为 $128 + 16 + 4 = 148$；$148 + 108 = 256 = 2^8$，符合"8 位补码中 $-N$ 的码按无符号数读为 $256 - N$"，结果正确。

**答案**：$[X]_{\text{原}} = 1110\,1100\mathrm{B}$，即 $X = -108$。

### 例题 21（例 1.12）：用补码做减法 7 − 19（第 44 页）

**题干**：要做减法 $[7-19]_{\text{补}}$，可用 $[7]_{\text{补}} + [-19]_{\text{补}}$ 来完成。已知 $[7]_{\text{补}} = 0000\,0111\mathrm{B}$，$[+19]_{\text{补}} = 0001\,0011\mathrm{B}$。求 $[7-19]_{\text{补}}$，并验证其真值为 $-12$。

**解**：

第 1 步：写出被减数的补码：$[7]_{\text{补}} = 0000\,0111\mathrm{B}$。

第 2 步：写出减数的补码：$[+19]_{\text{补}} = 0001\,0011\mathrm{B}$。

第 3 步：用"取反加一"求 $[-19]_{\text{补}}$：$0001\,0011\mathrm{B}$ 逐位取反得 $1110\,1100\mathrm{B}$；再加 1 得 $1110\,1101\mathrm{B}$，即 $[-19]_{\text{补}} = 1110\,1101\mathrm{B}$。

第 4 步：把减法转换为加法，逐位相加：

```
  0000 0111B    ← [7]补
+ 1110 1101B    ← [−19]补
-----------
  1111 0100B
```

逐位过程：bit0：$1+1=0$ 进 1；bit1：$1+0+1(\text{进位})=0$ 进 1；bit2：$1+1+1(\text{进位})=1$ 进 1；bit3：$0+0+1(\text{进位})=1$ 无进位；bit4：$0+1=1$；bit5：$0+1=1$；bit6：$0+1=1$；bit7：$0+1=1$，最高位无进位产生。

第 5 步：得到和的补码 $1111\,0100\mathrm{B} = \mathrm{F4H}$。

第 6 步：求真值。符号位为 1，是负数：$1111\,0100\mathrm{B}$ 取反得 $0000\,1011\mathrm{B}$；加 1 得 $0000\,1100\mathrm{B} = 8+4 = 12$；加负号，真值为 $-12$。

第 7 步：用原始数据验证：$7 + (-19) = -12$，与第 6 步结果一致，答案正确。

**答案**：$[7-19]_{\text{补}} = \mathrm{F4H} = 1111\,0100\mathrm{B}$，其真值为 $-12$。

### 例题 22：试题实战——补码加减运算与符号扩展（第 47 页）

**题干**：8 位数据 $[X]_{\text{补}} = \mathrm{BAH}$，$[Y]_{\text{补}} = 35\mathrm{H}$，$[X-Y]_{\text{补}} =$ ______，将结果 $[X-Y]_{\text{补}}$ 表示为 16 位数则为 ______。$[X+Y]_{\text{补}} =$ ______。（本页含 1 张图片，为原题配图，题干数据以文字为准。）

**解**：

第 1 步：把十六进制补码写成二进制：$[X]_{\text{补}} = \mathrm{BAH} = 1011\,1010\mathrm{B}$；$[Y]_{\text{补}} = 35\mathrm{H} = 0011\,0101\mathrm{B}$。

第 2 步：求 $X$、$Y$ 的真值（供最后验证使用）。$X$：$1011\,1010\mathrm{B}$ 符号位为 1，取反得 $0100\,0101\mathrm{B}$，加 1 得 $0100\,0110\mathrm{B} = 64+4+2 = 70$，故 $X = -70$。$Y$：$0011\,0101\mathrm{B}$ 符号位为 0，直接按权展开 $= 32+16+4+1 = 53$，故 $Y = +53$。

第 3 步：求 $[-Y]_{\text{补}}$（减法转加法用）：对 $[Y]_{\text{补}} = 0011\,0101\mathrm{B}$ 取反得 $1100\,1010\mathrm{B}$；加 1 得 $1100\,1011\mathrm{B} = \mathrm{CBH}$。核对：$-53 = 256 - 53 = 203$，而 $203 = 1100\,1011\mathrm{B}$，一致。

第 4 步：计算 $[X-Y]_{\text{补}} = [X]_{\text{补}} + [-Y]_{\text{补}} = 1011\,1010\mathrm{B} + 1100\,1011\mathrm{B}$，逐位相加：

```
  1011 1010B    ← [X]补 = BAH
+ 1100 1011B    ← [−Y]补 = CBH
-----------
  1000 0101B
```

逐位过程：bit0：$0+1=1$ 无进位；bit1：$1+1=0$ 进 1；bit2：$0+0+1(\text{进位})=1$ 无进位；bit3：$1+1=0$ 进 1；bit4：$1+0+1(\text{进位})=0$ 进 1；bit5：$1+0+1(\text{进位})=0$ 进 1；bit6：$0+1+1(\text{进位})=0$ 进 1；bit7：$1+1+1(\text{进位})=1$ 进 1，最高位进位 1 丢弃，保留低 8 位。

第 5 步：得 $[X-Y]_{\text{补}} = 1000\,0101\mathrm{B} = 85\mathrm{H}$。

第 6 步：验证 $[X-Y]_{\text{补}}$ 的真值。$1000\,0101\mathrm{B}$ 符号位为 1，取反得 $0111\,1010\mathrm{B}$，加 1 得 $0111\,1011\mathrm{B} = 64+32+16+8+2+1 = 123$，真值为 $-123$。用原始数据核对：$X - Y = -70 - 53 = -123$，一致。

第 7 步：把 $[X-Y]_{\text{补}}$ 表示为 16 位数。8 位结果 $1000\,0101\mathrm{B}$ 符号位为 1，做符号扩展：高位补 8 个 1，得 $1111\,1111\,1000\,0101\mathrm{B} = \mathrm{FF85H}$。

第 8 步：验证 16 位形式。$\mathrm{FF85H}$ 按无符号数读为 $65536 - 123 = 65413$（核对：$15 \times 4096 + 15 \times 256 + 8 \times 16 + 5 = 61440 + 3840 + 128 + 5 = 65413$）；按 16 位补码求真值：取反得 $0000\,0000\,0111\,1010\mathrm{B}$，加 1 得 $0000\,0000\,0111\,1011\mathrm{B} = 123$，真值 $-123$，与第 6 步一致。

第 9 步：计算 $[X+Y]_{\text{补}} = [X]_{\text{补}} + [Y]_{\text{补}} = 1011\,1010\mathrm{B} + 0011\,0101\mathrm{B}$，逐位相加：

```
  1011 1010B    ← [X]补 = BAH
+ 0011 0101B    ← [Y]补 = 35H
-----------
  1110 1111B
```

逐位过程：bit0：$0+1=1$ 无进位；bit1：$1+0=1$；bit2：$0+1=1$；bit3：$1+0=1$；bit4：$1+1=0$ 进 1；bit5：$1+1+1(\text{进位})=1$ 进 1；bit6：$0+0+1(\text{进位})=1$ 无进位；bit7：$1+0=1$。结果 $1110\,1111\mathrm{B} = \mathrm{EFH}$。

第 10 步：验证 $[X+Y]_{\text{补}}$ 的真值。$1110\,1111\mathrm{B}$ 符号位为 1，取反得 $0001\,0000\mathrm{B}$，加 1 得 $0001\,0001\mathrm{B} = 16+1 = 17$，真值为 $-17$。用原始数据核对：$X + Y = -70 + 53 = -17$，一致。

**答案**：$[X-Y]_{\text{补}} = 85\mathrm{H}$（$1000\,0101\mathrm{B}$）；表示为 16 位数为 $\mathrm{FF85H}$（$1111\,1111\,1000\,0101\mathrm{B}$）；$[X+Y]_{\text{补}} = \mathrm{EFH}$（$1110\,1111\mathrm{B}$）。
