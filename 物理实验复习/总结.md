# 光电效应与普朗克常数测量 (Photoelectric Effect and Planck's Constant Measurement)

## 预备问题 (Preparatory Questions)

1. **光电效应的物理原理**  
   光电效应是指当光照射到某些金属表面时，金属中的电子吸收光子能量，如果光子的能量（hν）大于金属的逸出功（A），电子会逸出表面形成光电子。爱因斯坦解释为光具有粒子性，光子能量E = hν，其中h为普朗克常数。光电子的最大初动能为(1/2)mv_max^2 = hν - A。

2. **光电效应实验的设计思路**  
   实验使用光电管，入射不同频率的光，测量饱和光电流和反向截止电压Us。通过Us计算光电子最大动能eUs = (1/2)mv_max^2，验证爱因斯坦方程hν = (1/2)mv_max^2 + A。改变光频率，绘制Us-ν曲线，斜率确定h，截距确定红限频率ν0。

3. **普朗克常数的引入和意义**  
   普朗克常数h由普朗克在黑体辐射研究中引入，假设能量以hν为单位量子化，h = 6.626 × 10^{-34} J·s。它标志着量子论的诞生，连接经典物理与量子物理，应用于原子能级、光电效应、波粒二象性等领域，是基本物理常数。

# 交直流电桥的原理及应用 (AC and DC Bridge Principles and Applications)

## 预备问题 (Preparatory Questions)

1. **电桥电路具有何种基本特征？直流电桥和交流电桥有什么区别？**  
   电桥电路的基本特征是四个桥臂形成闭合回路，一对角线接电源，另一对角线接检测器（如检流计），平衡时输出为零。直流电桥使用直流电源，桥臂为电阻，用于测电阻等；交流电桥使用交流电源，桥臂可为电阻、电容或电感，用于测阻抗、电容、电感等，需考虑相位平衡。

2. **何为平衡电桥？何为非平衡电桥？**  
   平衡电桥是通过调节桥臂使输出为零（检流计无电流），从而计算未知量，如惠斯通电桥的R_x = (R1/R2) * R3。非平衡电桥不调节到平衡，而是测量输出电压或电流，通过计算求未知量，适用于动态测量如温度变化。

3. **铜电阻和热敏电阻的温度特性是否相同？为什么选用不同的电桥形式测量？**  
   不相同。铜电阻温度系数小，阻值随温度线性小变化；热敏电阻温度系数大，阻值随温度非线性大变化。铜电阻用平衡电桥精确测静态值；热敏电阻用非平衡电桥测动态变化，便于连续监测。

4. **为什么在交流电桥中至少需要两个可调参数？应如何调节才能使电桥趋于平衡？**  
   因为交流电桥需同时满足幅度平衡和相位平衡，至少需调节电阻和电容/电感两个参数。先粗调一个参数使输出最小，再调另一个交替迭代，直至输出为零。

# 偏振与双折射 (Polarization and Birefringence)

## 开篇设问 (Thinking Questions)

1. **什么是自然光、部分偏振光、线偏振光、椭圆偏振光、以及圆偏振光？**  
   自然光：光矢量在垂直传播方向的平面内各方向等概率分布，无偏振。  
   部分偏振光：光矢量在某些方向概率较大，其他方向较小。  
   线偏振光：光矢量沿固定方向振动，轨迹为直线。  
   椭圆偏振光：光矢量旋转，轨迹为椭圆，由两垂直线偏光合成（位相差非0或π/2）。  
   圆偏振光：特殊椭圆偏振，光矢量旋转轨迹为圆，振幅相等、位相差π/2。

2. **怎样用实验方法来区分自然光、部分偏振光、线偏振光、椭圆偏振光、以及圆偏振光？**  
   使用偏振片（起偏器和检偏器）：自然光通过起偏器强度减半，转动检偏器强度不变；部分偏振光强度有变化但不灭；线偏振光转动检偏器有明暗灭绝（马吕斯定律）；椭圆/圆偏振光通过检偏器强度不变，但用1/4波片可转为线偏光再区分（圆偏光转为线偏光，椭圆偏光转为不同振幅线偏光）。

3. **如何获得椭圆偏振光和圆偏振光？**  
   椭圆偏振光：线偏光通过各向异性晶体（如波片），或两垂直线偏光合成（位相差Δφ ≠ nπ 或 nπ ± π/2）。  
   圆偏振光：线偏光通过1/4波片（快轴与振动面成45°），或两振幅相等、位相差π/2的垂直线偏光合成。

# 迈克尔逊干涉仪 (Michelson Interferometer)

## 预备问题 (Preparatory Questions)

1. **迈克尔逊干涉仪调节的要点是什么？如何确定两光束等光程时 M1 的位置？根据什么现象来判断 M1 和 M2 平行？**  
   调节要点：先粗调使两镜平行，再微调光程差。等光程时M1位置通过观察白光干涉条纹中央暗纹确定（光程差为零）。判断M1和M2平行根据条纹清晰、直线且等间距（不平行时条纹弯曲或消失）。

2. **何为非定域干涉？何为定域干涉？对非定域干涉和定域干涉观察方法有何不同？**  
   非定域干涉：干涉条纹在空间任意位置可见（如激光源）。定域干涉：条纹仅在特定区域可见（如扩展源）。观察非定域用屏幕或眼睛直接看；定域需在交点附近观察，调整焦距。

3. **怎样利用迈克尔逊干涉仪的干涉条纹的“涌出”或“淹没”来测量光波波长？**  
   移动M1，计数条纹移动数N（涌出或淹没），光程差变化Δd = Nλ/2，λ = 2Δd/N。通过微动鼓轮读Δd，计算λ。
